# 炼器配方体系扩展（P1）- 任务记忆

**日期**：2026-09-07
**任务**：S46 P1 炼器配方体系全面扩展（20种武器 + 11种装备部位 × 7品阶 = 217个配方）

## 实现内容

### 1. 配置表驱动
- 新建配置表：`config/forge_recipe_config.csv`
- 共218个配方（140武器 + 78装备）
- 字段：recipe_id, 名称, 品阶, 产出名, 产出类别, 产出穿戴位, 材料1名, 材料1数量, 材料2名, 材料2数量, 基础成功率, 需求境界序, 描述

### 2. 武器类型（20种）
剑、刀、枪、棍、扇、拂尘、琴、印、塔、鼎、钟、镜、珠、环、索、鞭、锏、锤、斧、钩

### 3. 装备部位（11种）
衣袍、头盔、护腕、护腿、靴子、腰带、项链、戒指、手镯、玉佩、披风

### 4. 品阶（7阶）
凡阶、灵阶、宝阶、王阶、圣阶、仙阶、道阶

### 5. 修改的文件
1. **forge.gd**
   - 新增 `static var 配置表扩展配方` 变量
   - 新增 `设置配置表配方()` 函数
   - 新增 `获取配方()` 函数（优先配置表，回落硬编码）
   - 修改 `炼器()` 函数使用 `获取配方()`
   - 修改 `检查材料()` 函数使用 `获取配方()`

2. **game_state.gd**
   - 新增 `配置表配方` 变量
   - 新增 `_加载炼器配方配置表()` 函数
   - 修改 `全部配方()` 函数，优先配置表
   - 修改 `_初始化领悟配方()` 使用新配方ID
   - 修改 `领悟配方()` 支持配置表配方
   - 修改 `_炼器成功触发领悟()` 支持配置表配方

3. **ui/page_building.gd**
   - 修改配方详情使用 `ForgeSystem.获取配方()`
