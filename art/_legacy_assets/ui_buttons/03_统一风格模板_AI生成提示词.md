## 给 Godot 的落地备注

1. **底板与图标分离**：AI 只出底板；图标（太极、飞剑、丹炉等）用本目录 `icon_*.png`，在 Godot 中作为 `TextureRect` 子节点叠在底板中央。
2. **文字用 Label**：所有中文文字（经营、弟子、确认、升级…）都通过 Godot `Label` 显示，颜色 `#F4EFE3`，**绝不烧进底板图**。
3. **MipMap 关闭**：UI 纹理在 Godot Import 设置中 `Filter` 用 `Nearest` 或 `Linear`，`Mipmaps` 关闭。
4. **压缩**：PC 用 BC7，移动用 ASTC 4×4。
5. **如意云角底板**：拉伸时优先固定宽度；若必须可变宽度，请用 Godot `NinePatchRect` 并手调 Patch Margins，保护四角云头不拉伸。
