# 太玄宗门录·产品形态与四层架构落地规格

> 本规格把"三条核心设定 + 老板 2026-09-01 新定的产品方向"收敛为可实现的系统规格。
> 全文仅用正式名《太玄宗门录》。落地原则沿用总览：**纯增量、零改号、零碰数值**（不破坏存档、不重写数值平衡、不碰战斗数学）。

## 1. 概述

### 1.1 产品定位（新方向，2026-09-01 拍板）
- **品类**：全自动长线修仙宗门模拟养成（放置挂机 + 深度策略）——与总览一致，本次明确"策略游戏"权重。
- **玩家角色**：宗主。定**策略与方向**，系统**智能执行**。
- **双重目标**：① 经营管理深度（策略骨架）；② 市面手游爽点（抽卡 / 收藏 / 外观 / 成就 / 持续成长）+ 暗黑式**刷刷刷**（rng 掉落驱动）。
- **反千篇一律**：随机性（奇遇 / 世界事件 / 掉落词缀 / 性格分歧人生）+ 趣味性 + 暗黑式刷刷刷快感。

### 1.2 三条核心设定（合规基线）
1. 游戏内大部分操作由系统智能完成；核心是经营管理，玩家扮演宗主深度模拟经营。
2. 弟子是玩法最重要一环，每个弟子是独立个体、高度自主，行为受性格/命格/经历影响，模拟"真实的人"。
3. 内容涵盖修真世界所有会发生的事件和内容。

### 1.3 范围
- 本规格**不修改**战斗数学（BattleCalculator/BattleManager）、不修改数据层数值平衡、不破坏存档兼容。
- 所有扩展通过"新增字段/新增函数/接已设计未加载的 CSV"完成，严守 pre_f5 8 闸 + 72 战斗断言红线。

## 2. 锁定的三个设计岔路口（2026-09-01 已拍板）

| # | 岔路 | 决策 |
|---|---|---|
| 策略层形态 | 方针面板 + 关键目标（推荐） | ✅ 选定 |
| 刷刷刷落点 | 自动刷 · 玩家定方向（推荐） | ✅ 选定 |
| 抽卡载体 | 弟子为主 + 外观限定卡池 | ✅ 选定（非推荐项，老板自定） |

**对抽卡决策的明确解释**：抽卡主轴 = **弟子**（测灵大典主池，抽到的是"活人"后系统模拟其一生）；**外观/皮肤单独限定卡池**（付费向清晰）；灵兽作为常规可获取养成单位（非主轴 gacha，避免稀释"抽到活人"的叙事重量）。

### 2.1 续锁定的三个设计岔路口（2026-09-01 续，老板全选推荐项）

| # | 岔路 | 决策 |
|---|---|---|
| 目标突变频率 | 事件驱动·中等（偶发重大转折，修真味浓、系统稳） | ✅ 选定 |
| 奏折敏感度 | 可调敏感度滑杆（默认仅重大+存亡弹我，寻常按推荐自动） | ✅ 选定 |
| 私库张力 | 完全自主私库（野心/魔道型囤积甚至盗宗门，守护/仁心型散财；宗门总盘另设补偿机制） | ✅ 选定 |

**对三项决策的明确解释**：
- 目标突变取"事件驱动·中等"——弟子多数守志，但关键修真桥段（家族危机/师尊陨落/道侣背叛/大机缘/走火入魔）会触发可观测的目标转移，既有人生跌宕味又不频闪失稳。
- 奏折取"可调敏感度"——玩家握最终打扰权；系统常规自理，只把分水岭（存续/重大）与无默认方针者呈上，带 AI 推荐+后果预览，最贴三国志"主公定方向"。
- 私库取"完全自主"——弟子是真正经济独立个体，人性张力最大化；代价是宗门总盘需设计补偿（如自动供给阈值、关键资源战略储备），避免野心型掏空宗门。

## 3. 四层架构与职责边界

| 层 | 名称 | 职责 | 当前状态 |
|---|---|---|---|
| ① | 玩家策略层 | 定方针（修炼/历练/供给/外交/建造）+ 关键目标；保留每个节点介入权 | 未建（本规格 B 阶段） |
| ② | 系统智能执行层 | 推演引擎把方针翻译为每日自动模拟：自动派遣/供给/结算 | 部分（推演至现在 `game_state.gd:7811` + 在线心跳 `main.gd:3895` 已存在，需"读方针"） |
| ③ | 弟子自主层 | **目标驱动**（主目标=修成大道，可突变）+ 性格/命格/关系/私库/心境调制，方针边界内自主决策 | 弱（审计 3.5/10，属性驱动无优先级；本规格 §4.0 目标模型 + A0-A3 子系统） |
| ④ | 爽点/收集层 | 抽卡/词缀装备/成就/图鉴/外观皮肤，把成长兑现为可收集多巴胺 | 部分（成就145 placeholder、师徒/子嗣假展示待修，本规格 C 阶段） |

**数据流**：①方针 → ②解析为自动行为参数 → ③弟子在参数边界内自主执行 → ④产出（掉落/传奇/收集）反馈回①新目标。离线也在转（②心跳）。

## 4. 阶段 A：弟子真人地基（最高优先，设定2 是"最重要一环"）

### 4.0 目标驱动行为模型（核心升级：从"属性驱动"到"目标驱动"）

**问题升级**：审计结论"性格≈摆设、履历只写不读"的根因是——弟子行为由**静态属性**驱动，属性间无优先级、无演化。老板 2026-09-01 新定：弟子应有**最终目标**（正常=修成大道），目标决定大部分行为，且**中途受其他影响会改变目标**。这把"假人"变"真人"的开关从"让属性生效"升级为"让目标生效 + 演化"。

**模型**：每个弟子是带**目标栈**的自主智能体。
- **主目标（人生目标）**：默认 `修成大道`（证道/长生/飞升）。可突变。
- **行为由主目标主导**：目标决定修炼策略/历练偏好/资源投入/社交倾向/风险承担/对宗门贡献/叛离可能——占行为权重主体（≈60~70%）。
- **其余因素为调制器（modulators，≈30~40%）**：性格（如何激进地 pursuit）、命格（命运修正）、关系网（为谁/抗谁）、个人资源（能否负担）、心境/心魔（扰动）、经历惯性（路径依赖）。

**目标分类（取自修真小说典型人生弧）**：

| 目标 | 来源/常态 | 自主行为特征 |
|---|---|---|
| 修成大道 | 默认终极 | 最优修炼、按需用资源、均衡贡献、低叛离 |
| 复仇 | 家族/师尊被害事件 | 偏战斗历练/高危、自购攻击丹、遇仇必出手、可能私离寻仇、低宗门贡献 |
| 守护 | 家族/道侣/宗门大恩 | 留守保护对象、降风险历练、资源投保护对象、高忠诚 |
| 证明自己 | 受辱/被排挤 | 揽功、争任命、接可见风险任务、高产出博关注 |
| 权力野心 | Ambition | 结交高层/同门、构陷对手、囤私库、争掌门/自立 |
| 情劫 | 道侣牵绊 | 与道侣同历、为其冒险、资源投道侣 |
| 问道 | 大机缘/悟性 | 避世钻研、追秘境秘闻、低社交 |
| 避世 | 看破/创伤后 | 闭关避责、低贡献、拒社交 |
| 魔道 | 走火入魔/背叛后 | 偷习禁术、可能盗宗门资源、高心魔、高风险 |

**目标突变（关键机制，"中途改变目标"）**：非随机，由**事件触发 + 性格调制**。
- 突变事件（修真桥段）：家族危机→守护/复仇；师尊陨落→复仇/避世；道侣背叛→魔道/避世；大机缘→问道/ reaffirm 大道；受辱→证明自己/野心；走火入魔→魔道；看破→避世；宗门大恩→守护宗门。
- 性格调制突变方向：杀伐果断弟子心魔破时更快入魔；仁心济世弟子受创偏向守护而非复仇；孤僻清修弟子更易避世。
- 突变写入 `目标栈`（保留旧目标为"执念"，可后续冲突/和解），履历记 `类型:目标突变` 形成因果链（呼应 A2）。
- **数值红线**：突变不改变弟子硬数值（仍走 `disciple.gd` 生成）；只改"目标→行为选择"，不碰 `突破成功率修正()`。

**多因素决策（回答"能不能更复杂"= 能）**：每次自主决策按加权评分：
```
行为分 = 目标权重·行为基向量
       + 性格偏移·激进/保守系数
       + 命格修正·命运项
       + 关系网拉力(护/抗)
       + 个人资源约束(买不买得起)
       + 心境/心魔扰动
       + 经历惯性(历史路径)
```
落点：A0/A1/A2 不再是平行三块，而是**本目标模型的三个子系统**——A0=性格调制器、A1=关系调制器、A2=突变触发源。目标栈为编排层。

### 4.1 A0 修性格双系统冲突 + 让性格真正驱动选择

**问题（审计实证）**：
- `disciple.gd:50` 定义 12 型性格表（沉稳守道/锐意争先/恬淡悟道/桀骜不羁/仁心济世/杀伐果断/谨慎多疑/豪迈仗义/孤僻清修/贪心逐缘/守礼尊师/狂傲绝世）。
- `game_state.gd:11217-11226` 招募（测灵大典）时按阵营**覆盖**为另一套值（正直/邪恶/孤僻/聪慧…），导致常规弟子 `性格` 落入阵营池。
- 所有行为分支引用 12 型字符串（`game_state.gd:8879` 孤僻清修降历练概率、`8918` 降奇遇、`10420` 谨慎多疑/贪心逐缘成败+0.1、`10834` 洗髓清负面性格），**对常规弟子永不命中 → 性格零作用**。

**规格**：
- **数据模型**：统一为**单一 12 型性格主轴**。`game_state.gd:11217` 的阵营覆盖**改为**"阵营→12型性格的映射"（正道→沉稳守道/仁心济世/守礼尊师；魔道→桀骜不羁/杀伐果断/狂傲绝世；中立→恬淡悟道/谨慎多疑/贪心逐缘；妖兽→豪迈仗义；遗泽→孤僻清修）。删除阵营覆盖分支，保留 `disciple.gd:50` 为唯一来源。
- **接口**：新增 `personality_config.csv`（总览 §11.26 已设计 7 行）承载"性格→行为权重"查表，由 `DestinyDataLoader` 同类加载器读取，避免硬编码。
- **行为驱动清单（让性格真生效）**：
  - 历练倾向：孤僻清修/恬淡悟道 → 主动回避高风险秘境、降历练频率；杀伐果断/桀骜不羁/狂傲绝世 → 偏好高危高收益；谨慎多疑 → 偏稳健。
  - 突破风格：锐意争先/狂傲绝世 → 接近瓶颈即尝试突破（激进）；沉稳守道/谨慎多疑 → 打磨满+心境高才突破（保守）。
  - 社交/奇遇：仁心济世 → 奇遇抉择偏助人；贪心逐缘 → 偏利己/机缘；孤僻清修 → 降社交/双修意愿。
  - 抉择文案：`lore.gd:293` `取历练(等阶, 性格)` 当前**声明性格参数却未使用**，改为按性格取不同抉择分支文本。
- **数值红线**：性格只改**行为概率/倾向**，不注入属性乘区（避免破 §4.1 通用增益 ≤25% 红线）。激进/保守的突破差异通过"何时触发 `尝试突破()`"实现，不碰 `突破成功率修正()` 公式。

### 4.2 A1 弟子关系网 + 自主社交/羁绊演化

**问题**：`disciple.gd` 仅有单个 `道侣:String`（`disciple.gd:149`），grep `好感/师徒/关系` = 0 命中（PunchList 已确认）；社交全玩家驱动（道友系统 `game_state.gd:3820+`，但弟子间无网络）。

**规格**：
- **数据模型**（disciple.gd 新增字段，纯增量）：
  - `关系网: Dictionary` = {弟子ID: {好感:int, 类型:"挚友/嫌隙/师徒/道侣"}}。
  - `师父ID: int` / `徒弟列表: Array[int]`。
  - 现有 `道侣:String` → 改为 `道侣ID: int`（与其他关系一致，便于反查）。
- **接口**：
  - `建立关系(甲,乙,类型)` / `调整好感(甲,乙,delta)` —— 在推演月内按性格+共事频率自动演化（非玩家触发）。
  - `自主社交(d)`：每月小概率触发弟子间论道/结善缘/生嫌隙，写入关系网；关系反作用于 `心境/心魔`（挚友降心魔、死敌升心魔、师徒传承加成）。
- **UI**：`disciple_detail_page.gd` 现有假展示 `师父:"—"/"+8%"`（`:1825/1869`）改为真实关系网面板。
- **数值红线**：关系加成计入 §4.1 通用增益乘区，封顶 25%，师徒传承单独占 §11.8 既定额度，不新增乘区。

### 4.3 A2 经历→因果链 + 心魔真实事件

**问题**：`履历: Array`（`disciple.gd:194`）只写不读（全代码唯一读处 `game_state.gd:9046` 仅拼展示）；心魔只降效率/降突破率，`disciple.gd:1038` 突破() 内走火入魔仅是注释端口，`inner_demon.csv`（§11.26 已设计 4 行）未加载。

**规格**：
- **履历驱动演化**：`履历` 每一项带 `类型` 标签（奇遇/战斗/突破成败/社交），新增 `_演化性格命格(d)` 在关键事件后按履历统计微调性格倾向/命格品质（如多次死战→更杀伐；多次助人→更仁心）。形成"经历→性格→未来行为"因果链。
- **心魔事件**：接 `inner_demon.csv`（总览 §11.26 已设计），心魔值超阈值时按表触发走火入魔事件（温和惩罚：心境降/属性震荡/小概率重伤），不再只是数值折扣。
- **接口**：`game_state.gd` 新增 `加载心魔事件表()` + 突破钩子 `disciple.gd:1038` 接真实判定。
  - **数值红线**：走火入魔惩罚不造成永久属性崩坏（保底可恢复），不破 §4.x 战力公式。

### 4.4 A3 弟子个人资源库（经济自主 + 人性张力）

**问题**：现有模型弟子只消耗宗门共享库（自动嗑药只读 `仓库`）。老板 2026-09-01 定：弟子本身能**保留灵石和修炼资源**，是独立经济个体——这既贴合"真人"，也让宗门坊市购丹成为弟子自养主渠道（呼应"坊市是宗门赚灵石主渠道+弟子多元获取"）。

**数据模型**（disciple.gd 纯增量）：
- `私库灵石: int`（月俸 + 历练分成 + 卖闲 + 奖励 − 自购 − 纳贡）
- `私库丹药/材料/装备: Array`（自购/奇遇/分成所得）
- `纳贡比例: float`（宗门贡献度，性格/目标驱动：仁心/守护高、野心/魔道低）

**经济自主（系统智能体现）**：
- 弟子自主决定：用私库灵石在坊市自购丹药自服（→ 减少宗门库依赖）；给道侣/师父送礼（关系网投入）；为自身目标囤积；偶尔捐宗门（守护/仁心型）。
- 与自动嗑药耦合升级：`_弟子自动服用丹药` 优先级改为 **私库丹药 → 私库灵石够则坊市买 → 最后动宗门库**。弟子"自己养自己"，玩家可见资产曲线（收集/成就线）。
- 人性张力：野心/魔道型囤私库不纳贡甚至盗宗门；守护/仁心型散私财护人——这是"真人"而非"公式载体"的体现。

**数值红线**：私库不影响宗门总盘平衡（仅是内部分配）；纳贡比例计入 §4.1 通用增益，封顶 25%。

## 5. 阶段 B：策略层（方针面板 + 关键目标）

### 5.1 B1 方针数据模型 + 面板 UI

**数据模型**（game_state.gd 新增 `方针: Dictionary`，存盘键 `policy`，纯增量）：
```
方针 = {
  修炼: {风格:"稳健"/"均衡"/"激进"},
  历练: {风险偏好:0.0~1.0, 目标掉落表:[关卡ID...], 自动派遣:bool},
  供给: {丹药自动炼制:bool, 丹药囤积线:int, 装备自动锻造:bool, 装备囤积线:int},
  外交: {阵营姿态:"正道"/"魔道"/"中立"/"均衡"},
  建造: {优先殿阁:[殿阁ID...], 自动升级:bool}
}
```
**UI**：新增 `ui/page_policy.gd`（主界面一级入口），分域滑杆/开关 + 一键预设（"种田流/战争流/丹道流"三套模板，呼应总览 1.1 沙盒路线）。复用 UITheme 既有组件，0 臆造。

### 5.2 B2 方针接入自动执行层

**接口**（在 `推演一月` `game_state.gd:7947` 循环内读取方针）：

### 5.4 奏折决策系统（三国志式长老顾问层）

**定位**：系统自主运转宗门，但**重大/模糊决策由长老或职能负责人以"奏折"呈玩家定夺**——玩家不微操，只做"有意义的关键 call"。这是"策略定方向"的具象：方针(policy)管常规，奏折管分水岭。（老板 2026-09-01 明定："重大抉择由长老或职能负责人交由玩家决定，多参考三国志系列"。）

**参照**：三国志系列——重臣（郭嘉/荀彧）呈事件+建议，主公择之，抉择设定方向。本作映射：长老=重臣、奏折=事件弹窗、推荐=AI 顾问、后果预览=决策影响预估；玩家可设"奏折敏感度"决定哪些层级弹自己（呼应三国志可设自动）。

**数据模型**（game_state.gd 新增 `待决奏折: Array[Dictionary]`，存盘键 `memorials`，纯增量）：
```
奏折 = {
  提议人: "战堂主"/"丹堂主"/"商队掌柜"/"长老X",
  事由: 事件描述(常接 D1 世界事件/秘境暴动/宗门危机),
  选项: [{文本, 推荐:bool, 后果预览:String}],
  重大性: "寻常"/"重大"/"存亡",
  默认处置: 按方针.某域 自动(若玩家设了默认)
}
```
**接口**：

- `裁决奏折(id,选项)`：玩家抉择 → 落地为一次性决策或更新 `方针` 先例（如"今后边境袭扰一律派新兵历练"）。
- `方针.奏折敏感度` 滑杆：全弹 / 仅重大 / 仅存亡。

**触发样例**：
- 战堂主：「边境魔修袭扰，派精锐/派新兵历练/按兵」（推荐派新兵赚战功）

- 长老：「弟子 X 道心异动/心魔深，干预(耗资源渡化)/静观？」
- 存亡级：秘境暴动/仙人降临/敌对宣战 → 必弹

**UI**：升级 §7.3 离山简报 为「奏折决策中心」单页 `ui/page_memorial.gd`：列表(提议人+事由+重大性标色) + 详情(选项带推荐标记+后果预览) + 一键按默认处置。复用 UITheme。

**数值红线**：奏折只驱动既有系统参数/方针，不新增战斗数学；后果预览由既定公式预估，不暗改数值。
