# 战斗系统 · 毕业装设计

> 配套文档：`战斗系统_build多样性接入规范.md`、`战斗系统_铁律放开治理与S2路线图.md`、ADR-003。
> 本文定义「毕业装」的定位、原则、具体提案与落地改动，作为 S2 战斗深度大版本的终局目标设计。

## 1. 背景与问题

当前套装体系（截至 S2 套装扩展后）存在三个结构性缺陷，使「毕业装」无法成立：

1. **完全扁平**：23 套效果数值在 3%~20% 区间（5 件最高仅攻击+20%），无任何一套是终局级，玩家爬到道阶后没有追求目标。
2. **与品阶解耦**：`item.gd:300` 生成逻辑为「品阶∈{宝王圣仙道} 且 randf()<0.15 → 套装ID = 套装库.keys().pick_random()」——**任何套装都可能随机贴到任何高阶装备**，道阶神兵也可能贴「青云套（修炼+5%）」这种垃圾，无「毕业=顶级专属」语义。
3. **无获取稀缺性**：套装纯随机掉落，最强套和过渡套概率相同，终局无成就感。

策划伏笔已存在：材料库 `item.gd:263`「九天玄陨：打造**毕业道阶装备**核心」——但仅为文案，无对应实现。

## 2. 设计四原则

| 原则 | 含义 |
|---|---|
| **境界绑定** | 毕业装仅在仙阶/道阶装备出现，低阶装备永不带毕业套 ID |
| **强度梯度** | 5 件明显高出现有（建议攻击+25~30% / 全属性+15% 量级），但受「词缀不破资质天花板」约束（item.gd:7）——给乘区/特效而非无限堆数值 |
| **复合特效** | 双特效或「属性+特效」复合，特效档位更狠（冷却更短/数值更高），让 build 成型 |
| **获取稀缺** | 来自最难关卡（道阶 BOSS / 终局秘境 / 合成链），非随机池 |

## 3. 套装品阶分层（系统性重构生成逻辑）

| 品阶 | 套装池 | 定位 |
|---|---|---|
| 宝阶 | 青云 / 紫霞 / 玄冰 / 赤焰 / 太一 | 基础套（养成过渡） |
| 王阶 | 流光 / 玄龟 / 饕餮 / 寒铁 / 惊雷 | 数值套（流派雏形） |
| 圣阶 | 血煞 / 破军 / 天罡 / 玄龟… | 数值高阶 + 特效入门 |
| 仙阶 | 寒霜 / 焚天 / 玄震 / 战神 / 太虚 / 青龙 / 破甲 / 金刚 / 疾风 | 特效套（单特效） |
| 道阶 | 混元 / 诛仙 / 太玄 / 无量（新毕业套） | 毕业装（双特效·终局） |

生成逻辑由 `pick_random()` 全池随机改为**按装备品阶从分层池抽取**（详见 §5）。

## 4. 毕业套装提案（新增 4 套，仙/道阶专属）

数值显著高出现有套，且采用双特效（套装库条目同时带 `5技能` 与 `5技能2` 两键）。

| 套装 | 品阶 | 2件 | 3件 | 5件 | 双特效 | 定位 |
|---|---|---|---|---|---|---|
| **混元套** | 道阶 | 气血+10% | 防御+15% | 全属性+15% | 护盾(set_shield) + 回春(set_regen) | 不死前排·续航终极 |
| **诛仙套** | 仙阶 | 攻击+12% | 暴击+12% | 攻击+30% | 破甲(set_defdown) + 灼烧(set_burn) | 秒杀流·极致爆发 |
| **太玄套** | 仙阶 | 速度+12% | 速度+18% | 速度+20% | 冰冻(set_freeze) + 眩晕(set_stun) | 控场流·双控终极 |
| **无量套** | 道阶 | 攻击+10% | 吸血+12% | 攻击+20% 吸血+15% 穿透+15% | 破甲(set_defdown) | 站撸流·吸血穿透 |

> 双特效实现：扩展 `disciple.套装技能()` 支持单档位多技能键（`5技能` / `5技能2`），注入两个技能数组元素。增强引擎 `_skill_buff映射` 已支持全部 9 种 buff，零红线改动。

## 5. 系统性改动（让毕业装成立）

1. **套装品阶分层池**：`item.gd` 套装生成改为按装备品阶从分层池抽取（宝→基础 / 王→数值 / 圣→特效入门 / 仙道→毕业），替代 `pick_random()` 全池。
2. **毕业专属标记**：套装库条目加 `"毕业": true`，生成时仅仙/道阶可带；低阶装备永不出现毕业套 ID。
3. **双特效支持**：`disciple.套装技能()` 扩展支持 `5技能2` 键（同档位第二特效）。
4. **（可选增强）5 件同套共鸣**：`disciple.套装战斗加成` 加同套计数，5 件同套额外 +10% 全属性，鼓励整套而非跨套混搭（对抗当前跨套累加惯性）。
5. **获取途径**：毕业套绑定道阶 BOSS / 终局秘境掉落或合成链（需在副本/秘境掉落表接入，属 S2-P4 大场景验证）。

## 6. 数值安全

- 所有加成走现有快照字段（攻/防/血/速/暴击/反伤/穿透/减伤/吸血/闪避 + 技能数组），**零碰 BattleCalculator 红线**。
- 毕业套强度受「词缀不破资质天花板」约束：套装给的是乘区/特效，弟子四维仍由 `资质系数 × 境界战斗倍率` 封顶（disciple.gd 算属性 / get_final_combat_attr）。

## 7. 落地范围（待确认）

- **最小**：套装库加 4 套毕业装定义。
- **核心**：+ 品阶分层池生成 + 毕业专属标记 + 双特效支持。
- **增强**：+ 5 件同套共鸣机制。
