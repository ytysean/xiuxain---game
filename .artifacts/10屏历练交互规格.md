## 3. 信息架构

1. **顶部栏**：统一深青底 `#11212A`，返回 + 标题 + 进度（日常已领/总数 · 周常状态）。
2. **头部面板**：一句话说明派发玩法。
3. **锁条**：当 `宗门 Lv.3` 或 `引导阶段 < 6` 时显示，提示未开启；开启后隐藏。
4. **日常历练**：≤3 张差事卡，每张含 名称·类型·难度、目标、赏赐、领取按钮。
5. **周常历练**：1 张差事卡，结构同日常。
6. **领取按钮三态**：已领（置灰「已领」）/ 锁定期（置灰「🔒 领取」+ tooltip）/ 可领（金色「领取」可点）。

## 4. 交互规则

| 区域 | 操作 | 响应 |
|---|---|---|
| 领取日常按钮 | 点击（可领态） | emit `领取日常请求(i)` |
| 领取周常按钮 | 点击（可领态） | emit `领取周常请求()` |
| 锁条 | 纯展示 | 无点击 |
| 领取按钮（已领 / 锁定期） | 点击 | disabled，无响应，tooltip 提示开启条件 |

## 6. 与代码映射

- `ui/page_explore.gd`：`_build` 搭顶部栏 / 锁条 / 滚动区；`_populate` 按 `Game.当前日常`(Array) 与 `Game.当前周常`(Dict) 生成卡片。
- 信号：`领取日常请求(序号)` / `领取周常请求()`。
- 数据来源：
  - `Game.当前日常`（≤3 条差事字典：quest_name / quest_type / difficulty / target_desc / target_num / reward_lingjing / reward_lingqi）
  - `Game.当前周常`（单条差事字典）
  - `Game.日常已领` / `Game.周常已领`（布尔数组 / 布尔）
  - `Game.门派等级` / `Game.引导阶段`（决定 `_is_locked()`）
  - `Game.差事赏赐系数()`（缩放赏赐显示）
- 零写入：所有读数经 `is_instance_valid(Game)` + `.get()` 守卫；领取按钮仅 emit 占位信号。
