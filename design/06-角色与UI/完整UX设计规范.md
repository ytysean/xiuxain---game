# 《太玄宗门录》完整 UX 设计规范

> **一句话定位**：本规范把用户提供的「导航路由交付清单」与「统一交互反馈规范」原样收编为权威章节，并补齐信息架构、屏幕级 UX、组件状态库、无障碍与工程/美术落地映射，使工程与美术可零歧义落地。**5 个底部 Tab 已锁定（宗门/弟子/殿阁/历练/纪事），御兽不作 Tab；四级反馈已规范；首页 6 宫格的锚点滚动为本期新增行为。**

> **【实现要点 · 本期新增】锚点滚动**：当前 `game_ui.gd._on_首页入口(entry_id)` 仅执行 `_show_page(target)`（切 Tab），**不含滚动**。落地时必须扩展为：`target` 切换完成后，若 `entry_id ∈ {灵植, 秘境, 库藏}`，则令目标页的 `ScrollContainer` 平滑滚动至对应分区锚点控件（hall_lingtian / trial_secret / hall_warehouse）。动效时长见 §3（数值/位置过渡 300ms，页面滚动建议 ≤400ms 平滑 tween）。其余三入口（殿阁/弟子/纪事）`entry_id == target`，直接切 Tab、无滚动。
> **命名提示**：宫格入口「灵植」语义 ≡ 殿阁·灵田分区（hall_lingtian）；「库藏」≡ 殿阁·库藏分区（hall_warehouse）；「秘境」≡ 历练·秘境分区（trial_secret）。三者均为「别名路由 + 锚点」。

### 2.4 全局返回栈强制规则【原样收编】+ 代码映射说明

**规则原文：**
1. 底部Tab切换不压入返回栈，始终以当前Tab为栈底，跨Tab跳转无返回记录。
2. 仅二级弹窗、详情面板压入返回栈；物理返回键优先关闭弹窗，无弹窗时执行页面级逻辑。

## 3. 统一交互反馈规范

> 本章**原样收编**用户「统一交互反馈规范」（§3.1 通用准则 / §3.2 核心模块细则 / §3.3 信息提示层级），并**扩展为可执行规范**（§3.4）：每类反馈给出 触发条件、视觉参数（缩放比/时长/颜色 token 引用 UITheme）、层级（z_index）、音频钩子占位（注明需 audio-director 后续补）。

### 3.1 通用交互反馈准则【原样收编】
- 点击态：按下缩放至 0.95、亮度微降，松开回弹，动效 100ms，无生硬突变。
- 有效操作：轻量 Toast，居中偏下（拇指舒适区上方），2 秒消失，不阻断操作。
- 无效操作：不可点击按钮统一置灰，点击无反馈；禁止操作时 Toast 简短说明原因。
- 数值变动：资源数值变化采用数字滚动过渡，增量高亮金色，动效 300ms。

### 3.2 核心模块反馈细则【原样收编】

| 模块 | 交互形式 | 反馈规则 |
| --- | --- | --- |
| 顶部资源栏 | 点击资源图标 | 底部弹出收益明细弹窗，高度不超屏幕 60%，点遮罩关闭 |

| 收益收取 | 点击收取 | 增量数字从收取位向上飘移，收敛到顶部资源图标 |

### 3.3 信息提示层级规则【原样收编】
1. L1 强提示：全屏弹窗（里程碑/重要奖励），手动确认，不自动消失

- **L2 底部弹窗**：从底部上滑入（tween 200–300ms），高 ≤ 屏 60%（资源明细类）/ 自适应（详情类）；点遮罩或返回键关（压栈，§2.4 规则 2）。

### 5.5 Toast（L3）
- 居中偏下（拇指舒适区上方），圆角 6，底 `COLOR_STATUSBAR_BG`@0.9 + 文 `COLOR_TEXT_TITLE2`，成功点缀 `COLOR_STATUS_SUCCESS`；2s 自动消失；z=200；不阻断。

### 5.6 RedDot / Badge（L4）
- 红点：小圆环 `COLOR_TEXT_RED`，置于宿主右上角（z=300）；角标：圆底 `COLOR_TEXT_RED` + 文 `COLOR_TEXT_TITLE2`。操作后自动消除。
- 仅标异常/可领（待突破/资源告急/可领赏赐），正常系统静默。

### 5.7 Loading / Error / Empty
- **Loading**：居中转环（`COLOR_BORDER_GOLD`），不阻断底层（或全屏模态 L1 仅首屏/读档）。
- **Error**：L2 弹窗，警示红 `COLOR_TEXT_RED` 文字 + 重试按钮；不静默失败。
- **Empty**：各页空状态文案（§4），暗金弱色，配主操作引导按钮。

## 6. 操作习惯与无障碍

1. **单手拇指热区**：竖屏单手，拇指可达弧 ≈ 圆心 (240,700)、半径 ≈280 的下半圆。底部 5 Tab（y 794–854）与首页 6 宫格（y 332–632）均落该弧内；高频操作（收取/进入/派遣）固定页面底部操作条（Tab 之上 y≈742–790）。
2. **最小命中区**：所有可点目标 ≥44×44px（ACCESSIBILITY Standard）。底部 Tab 与页面底操作条物理分离，避免切页误触。
3. **误触二次确认**：危险操作（遣散/出售/强冲/重开宗门）用二次确认弹窗（L1）或长按，不一步直达。
4. **返回路径统一**：一级 Tab 间整页切换、无返回栈；二级弹窗统一「返回键关闭 / 点遮罩关闭」；非首页 Tab 返回→回宗门首页；首页返回→退出确认（§2.4）。
5. **对比度**：文字与底对比度达标（WCAG AA）；`COLOR_TEXT_BODY_GOLD`/`COLOR_TEXT_TITLE1` 用于深底；`COLOR_TEXT_TITLE2` 用于深底浅字；**禁止** `COLOR_TEXT_BODY_GOLD` 作浅底文字（约 1.9:1 不及格，见 `UI硬性约束规范 §3.5`）。
6. **字号下限**：正文/数值 ≥15px；辅助（角标/提示）≥13px；**禁止 <13px**。锁定字号集 {22,18,17,16,15,13}。
7. **色盲友好**：状态不只靠颜色区分——红点配 🔒/数字角标；选中态配下划线+文字金色+图标切换；成功/失败配图标+文字，不只靠红绿。
8. **安全边距**：左右 8px，内容不贴屏边；锁态项 `disabled + 🔒 + tooltip`，点击不产生跳转。
