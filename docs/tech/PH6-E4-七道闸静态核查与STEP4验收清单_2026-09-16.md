## 2. 直接回答：哪几道能在「Godot 存活期间」跑，哪几道绝对不能

| 场景 | 结论 |
|---|---|
| 七道闸 可否与「Godot 存活」并存 | **可以（7/7）**。不 spawn Godot、不读 `.godot`、写盘目标与引擎不争用 |
| 是否需要独占引擎 | **不需要**。闸门自身零引擎占用 ⇒ 不违反「同一时刻只有一个 Godot 持有者」 |
| 真正「绝对不能与引擎并存」的 | **uifa 离屏真实渲染验收**（`ui_full_accept.tscn`）——它**本身就是引擎调用**，必须独占，不得与任何门并行 |
| 推荐操作口径（非硬约束，但建议遵守） | 闸门跑在**冻结快照**上：**导入结束 → Godot 退出 → 冻结 `.gd/.csv` → 跑七门 → uifa → 出包**。理由：避免读到「半导入态」，并保证闸门结论与出包内容**同源** |

> 一句话：**门不占引擎，故技术上都能并存；但按流程应把闸门安排在「导入后、uifa 前」的冻结窗口，以确保判定对象 = 出包对象。**

## 3. STEP-4 验收清单（落纸版）

### 3.1 闸门次序（锁定）

```
step 1  art-director  回滚 hq=false（#27）            ← 已/正在由 art 线执行
step 2/3  导入（team-lead 单车道持有引擎）★ 冻结 .gd/.csv
──────────────── 以下为 step 4（本人 + team-lead）────────────────
step 4a  跑七道闸：python .workbuddy/gate_all.py       ← 冻结快照上跑，须 EXIT=0
step 4b  uifa 离屏真实渲染（ui_full_accept.tscn）       ← 独占引擎，禁止与 4a 并行
step 4c  A/B 比对（见 §3.3）
──────────────────────────────────────────────────────────────
step 5   release-ops-lead 导出 Win 包 / APK
```

**次序铁律**：`导入 → 闸门(4a) → uifa(4b) → 出包(step5)`。闸门必须**先于** uifa 且**先于**出包；uifa **不得**与 4a 并发（同一时刻引擎唯一持有者）。

### 3.2 uifa 前置条件（4b 开关前必须全部满足）

1. **4a 已 EXIT=0**（七门全 PASS）。任一门 FAIL ⇒ 不进 uifa。
2. **`.gd/.csv` 已冻结**：4a 与 4b 之间**不允许任何 Write/Edit**（编辑会使 uifa 验证的代码 ≠ 闸门验证的代码）。
3. **引擎通道已点名**：uifa 持有者 = team-lead（step 4 由 team-lead 起引擎）；本人只做**只读**证据评审，不碰引擎。
4. **无其它 Godot 进程**：`--headless --import` 等已退出；会话回收不会连带杀 uifa（长任务不挂成员会话）。
5. **uifa 唯一例外**：仅 `ui_full_accept.tscn` 允许真实渲染；其余一切验证保持 `--headless` 无窗口。

### 3.3 A/B 比对基准

| 维度 | A（基准 / before） | B（候选 / after） | 判据 |
|---|---|---|---|
| 闸门 | 导入前 7 门快照（若有） | 导入后 7 门结果 | 门**只许由 FAIL→PASS，不许 PASS→FAIL**；门6 必须 `P0=0`（E3 后基线） |
| uifa 渲染 | 导入前 ui_full_accept 截图 | 导入后 ui_full_accept 截图 | 关键页面像素级/结构级一致；无缺失立绘、无空白背景、无错位 |
| 资源完整性 | 导入前 `.import` 状态 | 导入后 `.import` 状态 | 见 §3.4；`valid=false` 项不得增加 |
| CSV/数值 | 冻结基线 | 出包前 | 门2/门3 数值红线不得回退 |

### 3.4 失败判据（任一命中 ⇒ step-4 FAIL，阻断出包）

1. **七门判定非全 PASS**（gate_all 汇总 `存在失败 [FAIL]`，EXIT≠0）。
2. **门6 `P0 ≠ 0`**（确诊双参 `.get` 打在 Object 上 ⇒ 运行期中断整个函数）。
3. **uifa 渲染异常**：关键 UI 页缺失/空白/错位、立绘或图标不显示、贴图显存超预算。
4. **`.gd/.csv` 在 4a↔4b 之间被改动**（快照不一致）。
5. **uifa 与闸门并发**，或引擎通道同时存在 >1 持有者（违反单车道）。
6. **回归回退**：`tests/combat/test_combat.py` 的 72/93 条断言被触碰或失败。

> 质量门为**建议性门控（advisory）**：本人给 PASS/CONCERNS/FAIL 判定，最终放行由 **用户** 决定。
