#### 血脉觉醒机制
- 血脉纯度≥30%才能觉醒
- 觉醒后解锁血脉功法和血脉加成
- 觉醒初始觉醒度10%，可通过修炼/机缘提升
- 未觉醒时只有30%效果，觉醒后效果翻倍
- 觉醒度越高，血脉功法威力越大

#### 血脉加成计算
```
纯度系数 = 血脉纯度 / 100
效果系数 = 0.3（未觉醒）或 1.0 + 觉醒度/100（觉醒后）
修炼加成 = 基础修炼加成 × 纯度系数 × 效果系数
战力加成 = 基础战力加成 × 纯度系数 × 效果系数
突破加成 = 基础突破加成 × 纯度系数 × 效果系数
```
**数值红线**：所有血脉加成单源子帽≤1.5%（全局等效）

### 2.3 家族功法叠加系统

#### 叠加规则
- 最多叠加3套家族功法
- 每多叠加1套，额外+2%修炼速度
- 3套全叠加时，额外+5%战力（套装效果）
- 家族功法只有家族成员能学习（不外传）
- 学习家族功法需要家族职位权限（内门及以上）

#### 叠加效果计算
```
叠加数 = min(已学家族功法数, 3)
修炼加成 = 0.02 × (叠加数 - 1)  （叠加数≥2时）
战力加成 = 0.05  （叠加数≥3时）
```
**数值红线**：家族功法叠加单源子帽≤1%（全局等效）

### 2.4 功法不外传机制

#### 家族功法保护
- 家族功法只有家族成员能学习
- 学习家族功法需要家族职位权限（内门及以上）
- 退出家族时，自动清除所有家族功法
- 家族解散时，所有成员的家族功法自动清除
- 泄露家族功法者，逐出家族并追杀（修真世界家规）

#### 宗门功法保护（预留）
- 宗门功法只有宗门弟子能学习
- 学习宗门功法需要宗门职位权限
- 叛出宗门时，自动清除所有宗门功法
- （P1阶段实现，当前预留接口）

## 四、接入点

### 4.1 战力系统接入
`disciple.gd` 计算战力()函数：
```
主体 = base × 资质系数 × 灵根系数 × 道途系数 
     × (1 + 通用增益) × (1 + 道心增益) 
     × (1 + 血脉共鸣增益) × (1 + 血脉增益) × (1 + 家族功法增益)
     × (1 + 套装增益)
```

```
宗门加成pct = clamp(灵脉加成pct + 负责人修炼pct + 藏经阁pct 
                + 彩蛋修炼加成 + 大阵pct + 血脉共鸣pct + 血脉pct, 0, 1)
```

## 八、经验教训

### 8.1 修真世界设定的重要性
- 家族系统必须符合修真世界设定：家族传承、血脉觉醒、功法不外传、家规森严
- 血脉类型参考修真小说常见设定：龙族、凤凰、麒麟、玄武、白虎、剑修、丹道、阵法、太古
- 家族职位体系参考修真世界：老祖、长老、核心、内门、外门、附庸

### 8.2 数值红线的严格遵守
- §6.16明确规定血脉类单源子帽≤1.5%，家族功法叠加≤1%
- 实现时所有加成都有上限检查，不突破红线
- 教训：任何新增加成系统都必须先查数值红线，不能凭感觉设数值

### 8.3 功法不外传机制的设计
- 家族功法只有家族成员能学习，退出家族自动清除
- 学习家族功法需要家族职位权限（内门及以上）
- 这符合修真世界"传内不传外"的家规设定
- 教训：修真世界的规则必须严格执行，不能为了方便而破坏设定

### 8.4 分阶段实施的重要性
- 家族系统很大，不能一次全部实现
- P0先实现基础架构+血脉加成+家族功法叠加
- P1/P2/P3逐步实现宝库/秘宝/阵法/社交等高级功能
- 教训：大型系统必须分阶段实施，每阶段都要可玩、可验证

### 8.5 Edit工具的局限性
- Edit工具在匹配含特殊缩进/中文的行时频繁失败
- 改用PowerShell直接修改文件更可靠
- 教训：对于大文件的复杂修改，优先用PowerShell
