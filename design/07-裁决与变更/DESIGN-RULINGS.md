## 二、R-003 交易与商路系统口径统一（7 条裁决）

> 生效日期：2026-07-18 ｜ 裁决方：主理人（终裁）｜ 影响文档：GDD-交易系统.md / 数值体系-经济平衡.md（太玄宗门录_核心设定总览.md）

| 编号 | 矛盾点 | 最终裁决 | 设计理由 |
|---|---|---|---|
| C03 | 坊市解锁节点三方冲突（宗门经营「宝阶·金丹」/ 调参表「宗门 3 级」/ 投稿「练气开放基础坊市」） | 分层解锁：① 基础通用坊市（买卖低阶材料、基础丹药）**开局 / 练气期自动解锁** ② 坊市高阶栏 + 周限购稀有商品 **宗门 3 级解锁** ③ 阵营商店、黑市、跨服商栈 **金丹期逐步解锁** | 新手期必须有基础变现渠道；高阶内容随成长逐步放出 |
| C04 | 动态价浮动上限两版冲突（投稿 ±20% vs 上一轮 ±50% 对齐全局） | 分场景执行：① 日常基础材料、通用消耗品浮动上限 **±20%** ② 稀有道具、事件刷新商品、黑市商品浮动上限 **±50%** | 基础民生品严控波动保新手体验；稀有品放开弹性制造惊喜 |
| C05 | 青峰商路税后纯收益（243 vs 公式 270） | 统一按公式：青峰基础税后纯收益 = **270**（1000 × 30% × (1 − 10%) = 270）；243 为笔误 | 以通用公式为准，修正笔误 |
| C06 | 商路「品阶 ×2」与实际梯度不符 | 「品阶 ×2」为**基础材料基准倍率参考**，商路收益不严格遵循 2 倍；实际相邻商路收益倍率约 **2.5~3 倍**，随风险 / 耗时 / 解锁门槛同步提升 | 符合高风险高收益原则 |
| C07 | 商路时间基准双版本 + 解锁不一致 | ① 时间基准：全文档统一以**现实时间**为唯一权威，删除所有游戏时间表述 ② 解锁条件统一：青峰 = 宗门 3 级 + 筑基期；黑风 = 金丹初期 + 卷二通关；后续以此递进 | 口径唯一、绑定「境界 + 主线 + 宗门等级」三维度 |
| C08 | 系统回收价 60% 待核准 | 全局铁则：所有可交易道具系统回收价统一为**基准售价 60%**；特殊活动 / 限时道具如需例外单独标注，默认全部遵循 | 经济铁则执行，杜绝套利 |
| C09 | 疗伤丹 / 九转 / 碎片偏离品阶 ×2 | 分层规则：① 基础原材料严格遵循品阶 ×2 ② 成品丹药、装备碎片可按功能 / 稀缺度在基准值 **±50% 浮动** ③ 疗伤丹 4、九转还魂丹 300 均属合理设计 | 基础材料统一标尺，成品按功能价值浮动 |
| **C10** | 商店高阶栏解锁规则双锚点（C03 宗门 3 级 vs 配置表境界条件） | **双层逻辑**：① **宗门 3 级为栏位总闸**（高阶栏整体开启）② 栏内商品仍按各自**弟子境界**细分解锁（筑基 / 金丹 / 筑基圆满等），见 `GDD-交易系统.md` §四.1「解锁条件」列；两套规则并行，不构成冲突 | 兼顾宗门经营与弟子境界两条成长线，内容释放更平滑，设计健康度更高；玩家理解成本通过 UI 信息传达消化 |

## 三、R-003 入库片段（权威文本）

# DESIGN-RULINGS 交易与商路系统口径统一
裁决编号：R-003
生效版本：v1.2
涉及文档：GDD-交易系统.md / 数值体系-经济平衡.md（太玄宗门录_核心设定总览.md）
## 裁决内容
1. 坊市采用分层解锁机制，基础功能开局开放，高阶内容随成长逐步放出；其中高阶栏以宗门 3 级为总闸，栏内商品按弟子境界细分解锁，解决三节点冲突问题（详见 C10）。
2. 动态价格分两档执行：基础品±20%、稀有品±50%，分别对应不同商品池。
3. 青峰商路基础税后收益统一为270灵石，以通用公式为准，修正笔误。
4. 商路收益梯度不强制遵循×2倍率，按大境界成长匹配2.5~3倍梯度，符合高风险高收益原则。
5. 商路耗时统一以现实时间为唯一基准，解锁条件绑定「境界+主线+宗门等级」三维度。
6. 全局系统回收价统一为基准售价的60%，作为经济铁则执行。
7. 品阶×2倍率仅适用于基础原材料，成品道具可根据功能价值上下浮动，疗伤丹、九转还魂丹定价保留为合理设计。
