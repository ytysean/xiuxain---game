# 五、弟子四级分层 + 晋升机制（来源：接引堂方案 · 外门弟子晋升机制完整设计）

## 5.1 两阶段落地
- **S1 赛季**：先落「外门→内门」基础机制（开发量可控、体感明显）。
- **S2 赛季**：扩展「核心→亲传」高阶体系（配套深度玩法）。

## 5.2 四级分层（方案原文）

| 层级 | 定位 | 准入门槛基准 | 核心权限差异 |
| --- | --- | --- | --- |
| 外门弟子 | 底层储备、杂役主力 | 接引堂新招募默认外门，无境界要求 | 仅驻守灵田 / 矿洞等基础资源建筑；不可上阵历练、不可学中高级功法、不可任执事 |
| 内门弟子 | 正式成员、玩法主力 | 境界达标 + 贡献足够 + 晋升考核通过 | 可上阵历练、驻守所有常规建筑、学良品及以上功法、参与日常事务 |
| 核心弟子 | 中坚、高阶人才 | 金丹 + 高额贡献 + 宗门大比入选 | 可任建筑主事、学上品功法、触发专属奇遇、享资源倾斜 |
| 亲传弟子 | 顶级战力、掌门嫡系 | 元婴 + 特殊机缘 + 手动收录 | 全功法解锁、专属加成、顶级机缘、代掌门处理事务 |

**旧档兼容**：版本更新前已有弟子默认认内门；新招募从外门起步。

## 5.3 核心晋升规则
- **基础条件（多维）**：境界门槛（内门=筑基初 / 核心=金丹初）+ 宗门贡献 + 功法掌握（内门≥1 基础吐纳 / 核心≥3 中阶）+ 心性考核（隐性）。
- **考核机制**：手动发起（非自动）；基础成功率 60%、满配 90%；失败扣少量贡献 + 7 天冷却 + 「考核心得」buff（下次 +10%）；支持批量考核。
- **名额限制**：与宗门等级绑定（例：1 级内门上限 5，每升 1 级 +N）；满员须淘汰或升宗门等级。

## 5.4 系统联动
对接接引堂（新徒默认外门）/ 建筑驻守（基础建筑外门可驻、功能建筑内门+、主事核心+）/ 历练战斗（仅内门+可上阵、核心+全队加成）/ 宗门贡献（外门打杂赚贡献→攒条件晋升→解锁玩法）/ 命格灵根（极品命格降门槛、极品灵根晋升加属性）。

## 5.5 进阶补充
破格晋升（极品命格/灵根/大功无视部分门槛）、降级与淘汰（主动贬回外门腾名额）、晋升仪式感（专属通知 + 纪事永录 + 全宗士气临时加成；核心/亲传额外庆典）。

## 5.6 数值平衡
权限差异为主、数值加成为辅（晋升属性加成控 5%~10% 内，不冲击已验证战斗基线）；节奏平滑随宗门等级放名额；新手前 3 名招募默认内门（防卡进度）。

## 5.6 弟子分层定调：已裁决「方案 B · 双轴并行」（2026-07-21 拍板）

**结论**：保留现有 5 级 `身份` 轴（境界驱动、只升不降）**完全不动**；新增独立 `阶位` 轴（功绩/考核驱动权限分层）。双轨并行、互不破坏，S1 动手前统一以此为准。

### 双轴明确定义（避免后续概念混淆）

| 维度 | 身份轴（现有保留） | 阶位轴（新增独立） |
| --- | --- | --- |
| 驱动逻辑 | 境界自动晋升，只升不降 | 功绩 / 考核驱动，玩家手动任命、考核通过后晋升 |
| 层级划分 | 外门→内门→核心→亲传→长老（5 级，对应炼气→化神） | 执事→堂主→长老→供奉（4 级，对应权限层级） |
| 核心作用 | 基础身份标签、修炼 / 玩法准入门槛 | 宗门管理权限、俸禄待遇、负责人优先级 |
| 绑定关系 | 与境界强绑定，境界达标自动晋升 | 与身份弱关联，至少内门弟子才可授阶，境界不足无法任高阶 |

### 选择理由
1. **工程风险最低**：完全不动现有 `身份` 字段与关联逻辑（堂口入队 `_注册入堂`、破格提拔、纪事、buff 全部保留），零底层改动风险，旧存档无缝兼容。
2. **世界观自洽**：修真体系里「修为境界」与「宗门职位」本就是两套体系——境界高未必职位高，职位高需境界打底，双轴并行符合宗门管理常识。
3. **玩法策略性更强**：玩家既要培养境界提升身份，又要通过功绩/考核授阶，两条成长线互补，比单轴分层更深。

> ⚠️ **双轴同名「长老」消歧**：身份轴「长老」= 化神修为层级（最高）；阶位轴「长老」= 第三阶管理职位。S1 实现时 UI/存档须加轴前缀区分（如 `身份·长老` / `阶位·长老`），避免混用。
> 当前代码 `const 身份层级序`（disciple.gd L131）保留 5 级身份轴；阶位轴 4 级（执事→堂主→长老→供奉）为 S1 新增 `阶位` 字段 + 晋升考核逻辑（见第七章端口与 §九 优先级）。代码侧 5 级常量用带「弟子」后缀名（内门弟子/核心弟子/亲传弟子），与本章决策表称谓一致，无冲突。

# 九、依赖关系链与 S1 启动优先级（防顺序颠倒）

## 9.1 依赖关系链（先行底层、后行上层）
- **建筑等级体系** → 依赖：堂口 `等级` 字段（已预留 `"等级":1`）+ 门派等级扩展 + 产出乘区桩（`_建筑等级_乘区`）。
- **任期政绩玩法** → 依赖：负责人锁定机制（P0 已落）+ 建筑等级体系（政绩需挂在已升级的建筑上）。
- **独立资源体系（丹元/器魂/悟道点）** → 依赖：资源结算层（当前全折灵石，须先拆出独立资源账本）。
- **制式装备/入职包** → 依赖：最轻量，仅 `举办测灵根` hook（已预留）；可独立于上列先行。
- **俸禄福利** → 依赖：公库/货币 + 宗门贡献系统 + 独立资源体系；须后置。
- **弟子阶位轴（新）** → 依赖：身份轴（现有 5 级）已就绪 + 至少内门才可授阶的边界判定。
- **接引堂三机制** → 依赖：声望系统（特殊登门）+ 负责人/主事机制（接引执事复用）+ 弟子分层（外门体系）。
- **走火入魔 / 药毒** → 依赖：突破链路（已预留 hook）+ 丹药服用函数（须先建，见 §四 药毒）。

## 9.2 S1 启动优先级（按依赖顺序，与现有 P0 平滑衔接）
1. **弟子阶位体系基础框架**（与现有身份轴对接，新增 `阶位` 字段 + 授阶边界判定；见 §5.6 方案 B）
2. **建筑等级体系**（联动宗门等级，接入 `_建筑等级_乘区` 桩；见 §一）
