# 经济基线锚定与「产耗±15%红线」闸门设计（ECON-01）

> 本审计为「路径乙：排雷优先」的首项关键工作。结论前置：**当前版本经济已结构性偏离零通胀基线**——自动产出确定存在，自动消耗（刚性消耗）几乎全为 STUB，总产/总耗分母≈0。闸门须先锁系数与硬上限，待刚性消耗落地后再启用总产/总耗比值红线。

---

## 一、零通胀基线定义摘录（权威锚点，引用数值体系细则）

以下为 `design/04-数值体系/数值体系细则.md` 中构成零通胀基线的**硬约束**。它们是后续冲击测算(ECON-02)与闸门的共同标尺。

### 1.1 产出效率池（§4.1，独立非战力乘区）
- 建筑/任职带来的**资源产出速率**、高阶出率、任务效率加成，单独归入「产出效率池」。
- **单建筑产出效率 ≤ +20%**；**全建筑合计 ≤ +30%**（同类型建筑任职超 5 人边际衰减 50%）。
- 该池「仅作用于资源产出速率/数量，不进入弟子最终战力公式」，与通用战力 25% 软上限互不占用。

### 1.2 乘区归属帽（§4.6，战力口径，列此以全口径不遗漏）
- 通用增益乘区：**软上限 ≤25%，绝对硬上限 ≤30%**（溢出部分按 20% 衰减）。
- 道心独立乘区：**总增益 ≤10%**（独立乘算，不占通用 25%）。
- 强制规则：任意新增益须先在此表登记归属乘区；单乘区超限线性衰减；禁止加算/乘算混用。

### 1.3 经济轴硬上限（§4.7，经济口径，本审计主锚）
- **事件渠道占比硬上限：事件渠道（机缘 + 秘境隐藏）占全渠道 < 5%**。
  - broken 判定：任一时段「机缘 + 秘境隐藏」占比 ≥ 5% → 立即降权回退至 <5%。
- 通胀阈值（[PLACEHOLDER] 校准靶）：货币/日/人 超基线 1.5× 触发平衡 pass；俸禄入不敷出致破产率 > [阈值] → 触发节俭令/回退。

### 1.4 月度盈余上限（§4.8，闭环口径，本审计主锚）
- **月度总产出 = 月度刚性消耗 + 15%~25% 盈余**（即盈余率 15%~25%）。
- 刚性消耗定义（对齐 §11.9）：**弟子俸禄、建筑维护、修炼耗材、制式装备配发**。
- 盈余用途：宗门扩张/建筑升级/风险储备；超盈余上限时由 §11.11 负向事件伤害自动提升（动态消耗阀门 `event_damage_rate`）消化冗余，防囤积通胀。
- 预留全局调节阀门（§4.8 二(3)，**当前代码未接线，见第五节缺口 F4**）：`global_income_rate` / `global_cost_rate` / `event_damage_rate` / `trade_profit_rate`，默认 1.0。

> **锚点数字汇总（零通胀基线的精确锚）**
> | 锚点 | 数值 | 出处 |
> |---|---|---|
> | 单建筑产出效率帽 | ≤ +20% | §4.1 |
> | 全建筑产出效率帽 | ≤ +30% | §4.1 |
> | 通用增益软/硬帽 | 25% / 30% | §4.6 |
> | 道心独立帽 | ≤ 10% | §4.6 |
> | 事件渠道占比硬上限 | < 全渠道 5% | §4.7 |
> | 月度盈余率 | 15%~25%（总产 = 刚性耗 ×1.15~1.25） | §4.8 |

## 三、基准产耗数据表 + 零通胀锚点

### 3.1 自动产出基底（确定性、零玩家输入，主锚）

每月(`推演一月`)自动结算的灵石产出 = P1+P2+P3+P10+P12(期望)。取**代表性标准局**假设（明确声明，ECON-02 可替换）：

> **标准局假设**：门派等级 L=4；弟子数 N=48（≈4人/建筑，12建筑）；各建筑等级 BL=2；经营加成均 +10%；气运关（floor）；lingtian 负责人 BL=2 → 产出buff +1%；彩蛋产=0。

| 组分 | 计算 | 月产(灵石) |
|---|---|---|
| P1 建筑灵石产出 | Σ(n_k×base_k)=48×(27/12)=108；M=(1.10)×(1.01)×1.06×1.02≈1.201 → 108×1.201 | **≈130** |
| P2 弟子基础津贴 | 48 × 2 | **96** |
| P3 建筑保底津贴 | 12 × (2×5) | **120** |
| P10 探微阁(期望) | 0.10 × randi_range(30,80) 期望55 | **≈5.5** |
| P12 被动翻倍(期望) | 见注 | **≈15**（按各建筑产出×触发率加权，量级小） |
| **自动总产(月)** | | **≈366** |

> 自动总产随 (N, L, BL, 经营加成) 单调缩放：∝ N×(base均值)×等级乘区×建筑等级乘区×(1+经营加成)。**公式完全确定，ECON-02 可直接代入任意场景**。

### 3.4 零通胀锚点数字（ECON-02 直接引用）

| 锚点 | 当前版本实测 | 基线要求 | 判定 |
|---|---|---|---|

## 四、「产耗±15%红线」闸门设计方案

### 4.1 设计原则（对齐 check_rating_inflation.py 接法）
- **纯 stdlib、subprocess 子进程**，退码非0即阻断（与现有24闸一致）。
- **三层校验 + 配置层**：A) 基线清单层；B) 公式镜像层；C) 硬上限静态层；D) 事件渠道占比层。
- **不破坏既有逻辑**：作为 `CHECKS` 列表新增一项（紧接「七载奖励零通胀校验」之后），复用 `run_check` 编排与总判定。

### 4.2 校验规则

**Layer A — 基线清单层（anchors manifest）**
- 读取 ECON-01 产出的基线清单 `config/经济基线.csv`（字段见 4.5）：含各产出系数、刚性消耗系数、标准局月产/月耗、各渠道占比。
- 从 `game_state.gd` / `config/*.csv` **静态提取当前同名系数**，逐系数比对：
  `|当前值 − 基线值| / 基线值 > 0.15` → FAIL。
- 覆盖系数：`经营基数`(Σbase)、`建筑保底津贴`、`_升级消耗_灵石`基数/指数、`任务奖励系数`上限(3.0)、`随机事件奖励系数`(1.8)、`招徒基础概率/上限`、`气运产出加成`(+0.02)、`等级乘区/建筑等级乘区`步进(0.02)。

**Layer B — 公式镜像层（总盘 ±15%）**
- 在 Python 中镜像 `预估月产出()`（game_state.gd:1810-1838）与消耗公式，对**固定参考场景**(L,N,BL 写死于清单)复算 `基线月产/月耗`。
- 断言：`|复算月产 − 清单月产| / 清单月产 ≤ 0.15`（系数/总盘红线，始终生效）。
- **激活条件**：当 `经济基线.csv` 中 `F2_阀门_接线==1` 且 `F3_经营加成_封顶==0.30`（即 F2 三阀门 + F3 clamp + 刚性耗已落地），Layer B 升级为**可算比值红线**：断言 `总产/总耗(=月产/月耗目标305) ∈ [1.15, 1.25]`（§4.8 盈余率窗口）。
- **特征冲击卡位（ECON-02 §2.3/§2.4，始终生效）**：读 `config/新功能冲击声明.csv`（仅新增 D 类功能提供），断言 `月产增量 ≤ 55`（≤15%×366，±15% 输出红线）、`灵石冲击 ≤ 62`（≤17%×366，不转负盈余）、`产业链吞吐 ≤ 55`（S1 子集上限）；缺文件则跳过。

**Layer C — 硬上限静态层 + F2/F3 接线守（§4.1/§4.6/§4.7，ECON-02 跨功能强约束）**
- 产出效率池(F3)：静态校验 `game_state.gd` 中 `经营加成` 累加处**存在 clamp(单建筑≤0.20 / 全建筑≤0.30)**；未封顶 → FAIL（违反 §4.1，且抵消运维闭环）。
- F2 阀门接线（方案B·双兜底）：静态校验 `trade_profit_rate` / `global_cost_rate` / `event_damage_rate` 三阀门均须由 `economy_balance.gd` 从 `config/经济阀门.csv` 读取（**运行时 ±15% 强制钳制**），非硬编码字面量；`pre_f5` 第11闸（`check_resource_redline.py`）**静态守**（校验 `economy_balance.gd` 引用 `经济阀门.csv` + 含三旋钮键 + ±15% 硬范围 + `period_settlement.gd` 调用 `平衡()`）；任一硬编码 → FAIL（运行时无纠偏旋钮，违背 §4.8）。
- 乘区帽：校验增益相关乘区不突破 §4.6（复用既有 buff_redline 测试，本闸仅做串联确认）。
- 事件系数：校验 `随机事件奖励系数` 来自 `config/节奏校准.csv`（`_校准浮("随机事件奖励系数")`），非硬编码字面量。

**Layer D — 事件渠道占比层（§4.7 <5%）**

- 断言：`事件月均产 / 全月均产 < 0.05`；≥5% → FAIL（触发 broken 回退逻辑提示）。

# 三层 + 渠道层：A)基线清单系数±15%  B)公式镜像总盘±15%  C)硬上限静态(§4.1/§4.6/§4.7)  D)事件渠道<5%

import os, re, sys
ROOT = os.path.dirname(os.path.abspath(__file__))

def fail(msg):
    print("FAIL: " + msg); sys.exit(1)

def read_kv_csv(path):
    d = {}
    if not os.path.exists(path): return d
    with open(path, encoding="utf-8") as f:
        lines = [l.rstrip("\n") for l in f if l.strip()]
    for line in lines[1:]:
        p = line.split(",")
        if len(p) >= 2: d[p[0].strip()] = p[1].strip()
    return d

def main():
    # ---- A) 基线清单层：当前系数 vs config/经济基线.csv ----
    base = read_kv_csv(os.path.join(ROOT, "config", "经济基线.csv"))

    gs = open(os.path.join(ROOT, "game_state.gd"), encoding="utf-8").read()

    def coeff_current(regex, cast=float, grp=1):
        m = re.search(regex, gs)
        return cast(m.group(grp)) if m else None

    # 例：建筑保底津贴(const 建筑保底津贴: int = 5)
    保底 = coeff_current(r"const 建筑保底津贴:\s*int\s*=\s*(\d+)")

    if abs(保底 - float(base["建筑保底津贴"])) / float(base["建筑保底津贴"]) > 0.15:
        fail("建筑保底津贴=%d 偏离基线±15%%(基线%s)" % (保底, base["建筑保底津贴"]))
    # （其余系数：经营基数Σ、升级消耗基数/指数、任务奖励系数上限、随机事件奖励系数、
    #   招徒参数、气运产出加成、等级/建筑等级乘区步进 —— 同法逐项比对，略）

    # ---- C) 硬上限静态层 + F2/F3 接线守(ECON-02 跨功能强约束) ----
    # C1) F3 经营加成须 clamp(单建筑≤0.20 / 全≤0.30)，否则无封顶放大抵消闭环
    if not re.search(r"经营加成\s*=\s*clamp\([^,]+,\s*0\.0,\s*0\.20?\)", gs):
        fail("经营加成未封顶至≤0.20/单建筑（违反§4.1 产出效率池，F3 未落地）")
    if not re.search(r"经营加成_total\s*=\s*clamp\([^,]+,\s*0\.0,\s*0\.30\)", gs):
        fail("全建筑经营加成未封顶至≤0.30（违反§4.1 产出效率池，F3 未落地）")
    # C2) F2 三阀门须由 economy_balance.gd 从 config/经济阀门.csv 读取（运行时±15%强制钳制）
    #     静态(本闸) + 运行时(钳制) 双兜底；pre_f5 第11闸校验：
    eb = open(os.path.join(ROOT, "economy_balance.gd"), encoding="utf-8").read()
    if '经济阀门' not in eb:
        fail("economy_balance.gd 未引用 config/经济阀门.csv（F2 运行时钳制缺失）")
    for v in ("trade_profit_rate", "global_cost_rate", "event_damage_rate"):
        if ('"%s"' % v) not in eb:
            fail("经济阀门.csv 缺 F2 旋钮键 %s（运行时不可纠偏）" % v)
    ps = open(os.path.join(ROOT, "period_settlement.gd"), encoding="utf-8").read()
    if '平衡()' not in ps:
        fail("period_settlement.gd 未调用 EconomyBalance.平衡()（F2 双兜底未接出）")

        fail("随机事件奖励系数未从配置读取（疑似硬编码，通胀不可控）")

    复算月产 = float(base["复算月产"])  # 由脚本内镜像公式得出

        fail("公式镜像月产=%.1f 偏离基线±15%%(基线%s)" % (复算月产, base["标准局月产"]))
    # B2) 比值红线（仅当 F2+F3+刚性耗 已落地：base["F2_阀门_接线"]=="1" 且 base["F3_经营加成_封顶"]=="0.30"）
    f2 = base.get("F2_阀门_接线", "0")
    f3 = base.get("F3_经营加成_封顶", "0")
    if f2 == "1" and f3 == "0.30":
        月耗 = float(base["标准局月耗_目标"])
        比值 = float(base["标准局月产"]) / 月耗
        if not (float(base["盈余率窗口下"]) <= (比值 - 1.0) <= float(base["盈余率窗口上"])):
            fail("总产/总耗=%.3f 超出盈余率窗口[%.2f,%.2f]" % (比值, 盈余率窗口下, 盈余率窗口上))
    # B3) 新功能冲击静态卡位（ECON-02 §2.3/§2.4）：Δ产≤55、负面影响灵石冲击≤62
    #     这些值由 config/新功能冲击声明.csv 提供，缺失即跳过（仅对新增 D 类功能生效）

    if 特征Δ:
        if float(特征Δ.get("月产增量", "0")) > float(base["特征Δ产上限"]):
            fail("新功能月产增量=%s > 特征Δ产上限%s（击穿±15%%输出红线）" % (特征Δ["月产增量"], base["特征Δ产上限"]))

        if float(特征Δ.get("产业链吞吐", "0")) > float(base["产业链吞吐上限"]):

    print("ALL ASSERTIONS PASSED · 产耗红线 OK · 系数偏差≤15%% · 产出效率池/事件渠道合规")
    sys.exit(0)

if __name__ == "__main__":
