# 系统统筹设计 · 四柱咬合与复兴主线

> 本文档不新增任何系统、不改任何数值。它解决一个更根本的问题：**《太玄宗门录》已有 40+ 子系统，但它们各自成型、横向不咬合，玩家实际在玩几十个互不相干的小游戏，而不是「一个宗门」。**
>
> 定位：与 `UX基线-信息架构裁决与冻结_v1.0`（架构层）、`UX体验设计-宗主复兴体验主线_v1.0`（体验层）**并行**，本文是**系统层**的唯一统筹依据。三者互补：架构层管"东西放哪"、体验层管"为什么想打开"、本文管"系统之间怎么互相咬合、资源怎么守恒"。

---

## 0. 诊断：为什么"系统多"反而变差了

### 0.1 项目经历的是「系统堆积」，不是「系统生长」

盘点全项目 40+ 子系统后，一个结构性事实浮现：**几乎每个系统都是一个"自给自足"的完整小闭环**。以灵钓（S46，最成熟的样本）为例，它自带：

> 触屏小游戏 + 四分层掉落 + 独有境界成长线（钓道五重）+ 独有 sink（灵饵/钓具强化）+ 周常大赛 + 图录收集 + 奇遇通道 + 产出反哺

**这本身是极好的范式**——单个系统耐玩、闭环完整。但问题是：这套范式被**同构复制**到了休闲六件套、经商、王朝、派系、历练……每个系统都长出了一条**自己的境界线、自己的产出、自己的周常、自己的 sink**。结果：

- **横向失联**：钓的鱼 → 只进库房；库房的鱼 → 没有下游消费方。系统之间靠"库房"这一个共享垃圾桶草草连接，没有真正的**因果咬合**。
- **纵向失焦**：50 条系统自带 50 个目标。玩家不知道自己"整体在干什么"——因为没有一条**唯一主线**把它们的意义串起来。

**一句话概括病根：项目擅长做「系统」，还没做过「体系」。**

### 0.2 三个可量化的病症（均有代码证据）

| 病症 | 证据 | 后果 |
|---|---|---|
| **产出无下游（断链）** | `fragment_system` 碎片合成的"装备/功法/灵兽"分支 `pass` 丢失；`chest_system` 开箱同样丢非材料产出；`herb_garden_system` 收获不带年份 → S40 年份链断头 | 玩家辛苦产出→凭空蒸发，信任感崩塌 |
| **消耗无上游（假 sink）** | 傀儡"制作"检查了妖兽材料却只扣矿石（假消耗）；休闲六玩法 sink 仅"灵石直购"且无每日上限；宗主威望只增不减 | 通胀 + 空转，系统像摆设 |
| **决策密度两极** | 高决策：商路/王朝/宗门管理/历练；零决策：宗门任务（3 条随机·点领）、负向事件（纯随机扣）、成就、弟子养成（全自动） | 大半界面玩家只是"看 + 领"，没有"玩" |

### 0.3 设计-代码漂移（统筹必须裁决的第一批）

| 设计条目 | 代码现状 | 处置建议 |
|---|---|---|
| §16 主线五卷（青峰立宗→浩劫重临） | 仅 §16 文案，未落码；`stage_main.csv` 是战斗关卡 | 见 §7 落地 P0 |
| §11.14 宗门掌籍（数据看板） | 无任何代码 | 降级或后置 |
| §11.19 异步多人互动 | 仅 `friend_system.gd` 本地假道友，无服务端 | **降级为「本机道友」**，不承诺异步多人 |
| §8.4 傀儡（耐久/维护/部署/图纸） | 仅"制作 + 升级"，效果字段="待实现" | 补真消耗或并入炼器 |
| §11.9 公库五库/维持线/俭省令 | 仅单一灵石 + 欠俸忠诚链 | 保留现状、文档回退 |
| 秘境：`secret_config.csv` vs 代码 `secret_*` 关卡 ID | 两套命名未打通，CSV 无读取方 | 二选一收敛 |
| 任命：`game_state.司职列表` vs `sect_manager._殿阁负责人` | 两套任命系统并存 | 合并为一 |
| 炼丹：`炼制丹药` vs `炼制丹方` | 双实现并存，字段口径不同 | 收敛到 CSV 新路径 |

> **原则**：文档不得高于代码现实。凡"文档写了、代码没有"的，要么排进落地计划，要么**把文档同步回退**，绝不允许长期双份事实。

## 1. 唯一主线：太玄复兴

### 1.1 主线命题

把散落的 40 个系统全部挂到**一条主轴**上：**太玄宗从「前任宗主战死、道基尽毁、库房空空」的废墟，到重开山门、传承万代、甚至飞升证道。**

一切系统都必须能回答一个问题：**「我为太玄复兴贡献了什么？」** 答不上来的系统，就是孤儿系统（见 §6 治理）。

### 1.2 三衡（复兴的三个量化面）

对外名《开局接手太玄宗》本身就是一条复兴叙事。三衡把它变成可量化的目标：

| 衡 | 修真化命名 | 量化载体 | 回答的问题 | 挂载系统 |
|---|---|---|---|---|
| **立宗** | 宗门品级 | `Game.门派等级`（1–7 品）+ 建筑/产业规模 | 我的宗门**多大**？ | 建筑、财政、任务、四方贸易、掌管 |
| **传世** | 世代薪火 | 辈分序 + 先贤堂人数 + 家族血脉 | 我的宗门**多久**？ | 弟子寿命、家族、通婚子嗣、先贤堂、史册 |
| **证道** | 宗主境界 | `宗主.境界` + 宗门大典评级 | 我**自己**修到哪了？ | 掌门体系、渡劫、心魔誓、闭关、天劫 |

**三衡恒常可见**（对齐体验层 P1 长线目标）：首页顶部常驻一条「太玄复兴」进度带——立宗 x 品 / 传世 x 代 / 证道 x 境。玩家任何时候打开游戏，一眼看到"我离复兴还有多远"。

### 1.3 短中长三层目标牵引（对齐体验层 P1，落到系统）

| 层 | 周期 | 载体 | 牵引机制 |
|---|---|---|---|
| **短**（今日） | 1 游戏日 ~ 1 现实日 | 宗门任务 · 门派差事 · 弟子突破提示 | 情境触发（RimWorld 式主动 alerts），完成 → **回指中层** |
| **中**（本月/本年） | 1 季 / 1 年 | 宗门大计（对应宗门品级晋升链）· 岁末考评 | 进度条常驻，完成 → **回指长层** |
| **长**（本世/传世） | 1 世 / 七载 | 太玄复兴三衡 · 主线五卷 | 恒常可见 + 阶段性高光（七载大典/飞升） |

## 2. 四柱：把 40 个系统归位

系统不能再平铺成一张 50 行的清单。按"它在复兴里扮演什么角色"，全部归入**四柱**：

```
                        ┌───────────── 太玄复兴（唯一主线）─────────────┐
                        │   立宗 · 传世 · 证道                            │
                        └───┬──────────┬──────────┬──────────┬─────────┘
                            │          │          │          │
        ┌───────────────────┘          │          │          └───────────────────┐
        ▼                              ▼          ▼                              ▼
   ┌─────────┐                   ┌─────────┐  ┌─────────┐                   ┌─────────┐
   │ 一·门下 │──战力/司职/血脉──▶│ 二·征伐 │  │ 三·百工 │◀──材料/碎片/传承──│ 四·四方 │
   │  人柱   │                   │  战柱   │  │  产柱   │                   │  世柱   │
   └─────────┘                   └─────────┘  └─────────┘                   └─────────┘
        ▲                              │          │                              ▲
        │      丹药/装备/符箓反哺      │          │        灵石/声望/苗子          │
        └──────────────────────────────┴──────────┴──────────────────────────────┘
```

### 2.1 一·门下（人柱）—— 「谁在修炼」

| 系统 | 角色 | 输入 | 输出（喂给谁） |
|---|---|---|---|
| 弟子生成/灵根/职业 | 人口基数 | 测灵/招收/子嗣 | 战力、司职 → 征伐/产出 |
| 弟子养成/修炼/突破 | 主力成长 | 丹药、灵气、时间 | 境界、战力 → 征伐 |
| 弟子自主 AI | 自动运转 | — | 司职产出、奇遇 |
| 层级/任职/技艺 | 组织 | 任命 | 宗门全局 buff → 三柱效率 |
| 掌门体系 | 玩家化身 | 突破/闭关/炼丹 | 全局增益、权柄 |
| 家族/通婚/子嗣 | 世代纵深 | 声望、血脉 | 后代弟子、血脉加成 |
| 寿命/坐化/先贤堂 | 时间张力 | 年龄、心魔 | 先贤增益、换代压力 |
| 道友/社交 | 关系网 | 送礼、结义 | 悟道点、好感 → 道侣/家族 |

**门下是唯一的「战力供给侧」**——所有战斗系统都从这里取人。

### 2.2 二·征伐（战柱）—— 「去哪打、打谁」

| 系统 | 角色 | 输入 | 输出（喂给谁） |
|---|---|---|---|
| 战斗结算 | 底层引擎 | 战力快照（来自门下） | 胜负 → 各战斗系统 |
| 历练/推演 | 主资源入口 | 弟子占用、毒药、誓约 | 灵石/材料/碎片/传承 → 三柱 |
| 秘境 | 高阶掉落 | 每周次数、弟子 | 高阶装备/材料 → 三柱 |
| 灵兽养成/饲灵 | 战力放大器 | 灵草、丹药、内丹 | 战斗四维 → 门下的战力 |
| 宗门战/领地战/正魔大战 | 对外扩张 | 编制、丹药、战功 | 领地月产、战功、声望 → 四柱 |
| 渡劫/天劫/心魔誓 | 境界闸门 | 渡劫道具、因果 | 突破、道伤 → 门下 |
| 休闲六玩法（探秘/卜算/论道/饲灵/药圃部分） | 轻量资源入口 | 进阶耗品、灵石 | 灵材/悟性/运势 → 三柱 |

### 2.3 三·百工（产柱）—— 「把材料变成战力」

| 系统 | 角色 | 输入 | 输出（喂给谁） |
|---|---|---|---|
| 炼丹（丹纹/因子/品级） | 丹药产线 | 灵草、矿、内丹、丹炉 | 丹药 → 门下（服食）/征伐（战斗消耗） |
| 符箓（符纹/因子） | 符箓产线 | 符纸、灵墨 | 符箓 → 征伐（每场 3 张） |
| 炼器（因子/词条/套装） | 装备产线 | 矿石、灵铁、图纸 | 装备 → 门下（战力） |
| 灵植/药圃 | 原料产线 | 灵石、种子、灵肥 | 灵草（带年份）→ 炼丹 |
| 傀儡 | 辅助产线 | 矿石（应补真消耗） | 修炼/产出/战力加成 |
| 财政/俸禄/资源回收 | 循环与守恒 | 灵石 | 维持门下忠诚、卡通胀 |

### 2.4 四·四方（世柱）—— 「宗门之外的世界」

| 系统 | 角色 | 输入 | 输出（喂给谁） |
|---|---|---|---|
| 地图（驻地内图 + 大地图） | 空间导航 | 迁移成本 | 区域加成 → 商路/历练 |
| 商路贸易/商队/灵舟/商道 | 灵石主产线 | 货物、启动资金、载具 | 灵石、稀有商品 → 全柱 |
| 凡人王朝 | 长线内容刷新器 | 灵石、香火、弟子 | 灵石、香火、苗子 → 门下/财政 |
| 派系/阵营声望 | 路线分化 | 任务行为 | 声望（招募权重/折扣）→ 门下/四方 |
| 拍卖行/全服拍卖/玩家交易 | 高阶流通 | 灵石、物品 | 物品/灵石再分配 |
| 传送阵/飞行道具 | 流通加速 | 传送费、仙玉 | 商路时效 |

## 3. 咬合链：把四柱焊起来（核心交付）

**这是本文档最重要的一节。** 柱不是四个平行盒子，它们必须**首尾相咬**，形成一条主循环。下面是**唯一主循环**：

```
   ┌──────────────────────────────────────────────────────────────────────────┐
   │                        《太玄宗门录》唯一主循环                             │
   │                                                                          │
   │   [推演前进] ──▶ 门下修炼/突破 ──耗丹药/灵气──▶ 战力↑ ──编入──▶ 征伐         │
   │       ▲              ▲                              │                    │
   │       │              │                              ▼                    │
   │       │          丹药/装备/符箓 ◀──百工炼制◀── 材料/碎片/传承             │
   │       │              ▲                              │                    │
   │       │              │                              ▼                    │
   │       │          原料/图鉴                      灵石/声望/苗子              │
   │       │              ▲                              │                    │
   │       └──── 俸禄/建筑/复兴 ◀──财政◀── 四方贸易 ◀────┘                    │
   │                                                                          │
   │   每完成一圈：立宗↑ · 传世↑ · 证道↑ → 解锁更深内容（洋葱解锁）              │
   └──────────────────────────────────────────────────────────────────────────┘
```

### 3.1 咬合矩阵（谁喂谁 —— 通/断 一览）

| # | 上游 | → 下游 | 当前状态 | 修法 |
|---|---|---|---|---|
| L1 | 门下·弟子 | → 征伐·历练/秘境/宗门战 | ✅ 通（`get_final_combat_attr`） | 保持 |
| L2 | 百工·装备/丹药/符箓 | → 门下·战力 | ✅ 通 | 保持 |
| L3 | 百工·丹药/符箓 | → 征伐·战斗消耗 | ✅ 通（符箓每场 3 张） | 保持 |
| L4 | 征伐·历练/秘境 | → 百工·材料 | ✅ 通 | 保持 |
| L5 | 征伐·灵兽 | → 门下·战力 | ✅ 通（主宠 100%/副宠 30%） | 保持 |
| L6 | **休闲·灵钓** | → 百工·炼丹/炼器料 | ⚠️ **半通** | 鱼获处置已有 5 路，需把"入药/炼器"接进炼丹/炼器因子 |
| L7 | **休闲·药圃** | → 百工·炼丹（带年份） | ❌ **断** | 药圃收获改为产出带年份灵材（接 S40） |
| L8 | **碎片合成/宝箱** | → 百工/门下 | ❌ **断**（非材料分支 `pass` 丢失） | 补全发放分支（装备/功法/灵兽/宝物） |
| L9 | 四方·商路/王朝 | → 财政·灵石 | ✅ 通 | 保持 |
| L10 | 财政·灵石 | → 全柱·俸禄/建筑/启动金 | ✅ 通 | 保持 |
| L11 | 四方·派系声望 | → 门下·招募权重 | ✅ 通（加权抽取阵营） | 保持 |
| L12 | 征伐·功德/业力 | → 征伐·渡劫倍率 | ✅ 通（因果天劫倍率） | 保持 |
| L13 | **休闲六玩法产出** | → 各柱 | ⚠️ **弱**（仅进库房当垃圾） | 见 §3.2 交叉联动补强 |
| L14 | **傀儡** | → 百工·成率 | ❌ **空转**（假消耗） | 补真消耗 + 部署位 |
| L15 | **图鉴收录** | → 全柱·产出加成 | ⚠️ 部分接通（封顶 0.30） | 补齐 13 类来源 |

### 3.2 交叉联动补强（让休闲不再是孤岛）

休闲六玩法目前"各自闭环、只进库房"。把它们的产出**互相咬合**，六个玩法立刻从"6 个独立小游戏"变成"1 张渔猎农卜棋圃网络"：

| 玩法 | 产出 | 新增咬合去向（修真化） | 闭环意义 |
|---|---|---|---|
| 灵钓 | 灵鱼、灵材、秘匣 | 鱼 → 灵池饲养（饲灵）· 鱼骨 → 炼器 · 鱼鳞 → 炼丹 | 钓的鱼不再只当垃圾 |
| 药圃 | 灵植（带年份） | 灵植 → 炼丹（主料）· 异种 → 卜算（灵材） | 补上 S40 断头 |
| 饲灵 | 灵兽、兽魂、变异蛋 | 灵兽 → 征伐（战力）· 兽魂 → 驭兽/论道 | 与灵兽系统真正合流 |
| 卜算 | 运势、天机修为 | 运势 → 修炼/突破/奇遇率全域 buff | 从"独立占卜"变"全局调节器" |
| 论道 | 悟性、棋谱 | 悟性 → 门下修炼速度 | 直接服务主循环 |
| 探秘 | 天材地宝、残卷、秘藏 | 残卷 → 藏经阁（功法）· 天材 → 百工 | 补上功法/材料入口 |

> **设计原则**：**任何玩法的产出，必须至少有 1 个"跨柱下游"+ 1 个"自己的 sink"**。只有"自己的 sink"（例如只用灵石买耗品）就是封闭循环，玩家玩两次就腻。

### 3.3 门下 × 家族的世代咬合（对齐核心标签「世代宗门传承」）

核心差异化标签是"百年宗门，薪火相传"。这条链必须显式化：

```
弟子修炼 ──寿元耗尽──▶ 坐化 ──▶ 先贤堂（永久增益）
   │                                    ▲
   └── 好感/道侣/通婚 ──▶ 子嗣 ──▶ 新一代弟子（继承血脉）──┘
                              │
                              └──▶ 辈分序+1 ──▶ 家族传承 ──▶ 宗门史记
```

**当前断点**：子嗣 15 岁自动入宗、测灵不 roll 种族（恒人族）、先贤堂增益仅归档无结算。补上后，"传世"这一衡才真正可玩。

## 4. 资源恒等式：三层货币 + 材料守恒

### 4.1 三层货币总账（对齐 §11.20，但明确 source/sink）

| 层 | 货币 | Source | Sink | 状态 |
|---|---|---|---|---|
| **基础** | 灵石 | 商队/商铺/供奉/拍卖/传送/任务 | 俸禄 · 建筑 · 启动金 · 迁移 · 丹炉/灵田升级 | ✅ 健康 |
| **基础** | 灵材（灵草/矿石/碎片/内丹） | 历练/秘境/休闲/灵田/狩猎 | 炼丹/炼器/符箓/傀儡 | ⚠️ 部分断链（L7/L8） |
| **专属** | 贡献点 | 宗门任务 | 藏经阁技能/试炼/渡劫护法 | ✅ 闭环 |
| **专属** | 战功 | 宣战/领地/赛季 | 战功商店 | ✅ 闭环 |
| **专属** | 香火/愿力 | 王朝信仰 | 悟道点/灵气 | ✅ 闭环 |
| **专属** | **宗主威望** | 贸易大赛 +30 · 灵钓大赛 | 转世仅保留 50% | ❌ **只增不减 → 通胀** |
| **高阶** | **仙玉** | 充值/成就/签到/赛季 | 传送 50 · 加速 30 · 迁移灵晶 | ⚠️ sink 偏少 |

### 4.2 三条通胀红线（必须在 P1 关闭）

1. **宗主威望无出口** → 新增"威望 sink"：以威望发布宗门法旨（临时全局 buff）· 威望兑换限定图录边框 · 高威望解锁外交手段（拉拢/离间派系）。**威望必须能被花掉。**
2. **休闲产出无日上限** → 六玩法统一加"每日参与次数上限"（修真化：每日灵渊/药圃/观星配额），且**产出必须先进库房，再由百工消费**，而不是直发资源。
3. **商队"独占红利 ×1.2"无差别生效** → 改为"首访城 + 一次性红利"，而非"每趟恒定 +20%"，避免全局基础收益外溢。

### 4.3 消耗守恒原则（防止再次出现"假 sink"）

> **凡新增产出，必须同时指明它的消费方；凡新增消费，必须同时指明它的来源。** 无消费方的产出 = 通胀，无来源的消费 = 假系统。

已有反例（傀儡只扣矿石、宝箱产出 `pass`）须在 P1 修掉。

玩家觉得"玩着没意思"，一半来自**大面积界面无事可做**。按"每系统是否有真实取舍"分级，把零决策系统升级：

| 系统 | 现状决策 | 升级方向（修真化） |
|---|---|---|
| 宗门任务 | 0（3 条随机点领） | 改为**宗门法旨**：每日 3 道法旨，玩家**选择派谁去/用何策略**，奖励随选择浮动 |

## 6. 时间节律统一（双轨归一）

### 6.1 现状：游戏日轴 vs 真实日轴 双轨撕裂

| 轴 | 流速 | 挂载 | 问题 |
|---|---|---|---|
| **游戏日轴** | 1 游戏日 = 240 真实秒（1 现实天 ≈ 1 游戏年） | 修炼/产出/历练/事件/月结/年结/七载 | 世界演化轴，合理 |
| **真实日轴** | 滚动 86400 秒 | 日常任务/周常/战令 | 与设计「每日 08:00 刷新」不符 |

### 6.2 归一方案

**双轨本应各司其职**——但刷新口径必须统一：

- **世界演化**（修炼/产出/月结/年结/七载）→ 走**游戏日轴**（保留真实时间感）。
- **玩家日常**（每日法旨/周常/日供/坊市）→ 走**真实日轴，统一每日 08:00 刷新**（对齐用户既定规则），不再用"上次执行时间 + 86400s"滚动。
- **战令赛季**：当前 90 游戏日 ≈ **6 真实小时**一季，严重失衡 → 改为**真实周/月**口径（对齐赛季应有的节奏）。

> **✅ 刷新口径收敛裁决（2026-09-16 · D2 · 唯一事实源）**
> 全项目唯一刷新时刻 = **每日 08:00**（周常 = **每周一 08:00**）。
> 实施层此前并存的 `00:00`（日供按现实日期跨天，`game_state.gd:4013`）/ `04:00`（旧重置锚点，`game_state.gd:2273`）/ `05:00`（旧设定稿，`核心设定总览` §11.25.2.2）**三处旧口径一律作废**，统一改由 `config/` 一行配置驱动，UI 文案统一为「每日 08:00 更替」。
> **勿再新增第二口径。**

## 7. 系统接入四问（治理框架 · 防止再次失焦）

> 这是本文档最可复用的一条。**此后任何新系统，写代码前必须先书面回答四问，答不全不许开工。**（对齐 UX 基线 U8）

1. **归位**：你属于四柱中的哪一柱？（不属于任何柱 = 孤儿系统）
2. **上咬**：你从谁那里取输入？（无上游 = 假系统）
3. **下咬**：你的产出喂给谁？（无下游 = 通胀源）
4. **守恒**：你的 sink 与 source 是否配平？（配不平 = 破坏经济）

**四问样例·灵钓（合格）**：归位=征伐·轻量入口；上咬=灵草/灵石；下咬=炼丹/炼器料+灵池饲养+图录；守恒=灵饵/钓具强化配平。→ 因四问全通，灵钓是当前唯一"完整体面"的范式，**推广为全项目模板**。

## 8. 表现层：特效 / 动效 / 音效（从玩家感受出发 · 个人开发者可落地）

> 本节回答三个问题：**哪些要特效、哪些要动起来、哪些要音效、特效怎么做**——并且全部按「**个人开发 + 小白 + 由 AI 落地**」的前提设计。每一项都标注**依赖等级**，凡是"零依赖"的，现在就能做，不需要等美术。

### 8.1 一条铁则：反馈必须「配得上」事件的分量

玩家觉得"不爽"，往往不是缺特效，而是**反馈平均**——突破、领奖、钓到鱼，反馈强度都差不多，所以都不爽。当前项目正是如此：突破只弹一个字。

**分频原则**（对齐体验层 P3）：
- **大事件**（突破 / 渡劫 / 飞升 / 七载大典 / 首次钓到传说鱼）→ **全屏级仪式**，独占屏幕 2~4 秒。
- **中事件**（炼丹 / 钓获 / 入职 / 战斗胜负）→ **局部动效 + 音效**，不打断操作。
- **小事件**（资源入账 / 红点消除 / 按钮）→ **轻反馈**（数字飞字 / 微缩放）。
- **重复递减**：同一件事**第一次最隆重，之后克制**（避免第 50 次突破还要看 4 秒动画）。

### 8.3 特效怎么做 —— Godot 4.7 纯代码「五件套」（零美术素材）

这是本节的关键：**个人开发者不用等美术，用引擎内置能力就能做出全部上面这些效果。**

**① Tween（万能，零素材）** —— 位移 / 缩放 / 透明 / 颜色，覆盖 80% 需求：
```gdscript
var t := create_tween()
t.tween_property(境界字, "scale", Vector2(1.4, 1.4), 0.15)
t.tween_property(境界字, "scale", Vector2.ONE, 0.20)
t.parallel().tween_property(遮罩, "modulate:a", 0.0, 0.35)
```

**② 粒子（GPUParticles2D + GradientTexture2D）—— 零素材的秘诀**：用一个**径向渐变生成的圆点**当粒子贴图，改颜色/方向就能做出灵气、星光、落英、水花、火花——**一张美术图都不用**：
```gdscript
var 贴图 := GradientTexture2D.new()
贴图.gradient = Gradient.new()          # 白 → 透明
贴图.fill = GradientTexture2D.FILL_RADIAL
var 材质 := ParticleProcessMaterial.new()
材质.emission_shape = ParticleProcessMaterial.EMISSION_SHAPE_SPHERE
材质.direction = Vector3(0, -1, 0)      # 向上飘 = 灵气；向下 = 落英
材质.color = Color(0.85, 0.75, 0.35)    # 金色 = 突破；青色 = 灵雾
```

**③ 屏幕级效果**：根 `Control.position` 做**震动**；全屏 `ColorRect` 做**闪白 / 转场**（改 alpha 即可）。

**④ Shader（进阶可选）**：`ShaderMaterial` + 代码字符串，做水面波纹 / 发光描边。**小白阶段可跳过**，不阻塞上面任何效果。

**⑤ 数字飞字 / 飘字**：`Label` 对象池 + Tween（位移 + 渐隐 + 缩放），做资源入账、伤害数字。

> **性能红线**（对齐 §15.4）：粒子总数受限、锁 30fps、避免每帧重算；手机端优先 CPUParticles2D 做小规模、GPUParticles2D 做全屏仪式。

### 8.4 音效怎么做 —— 小白的零成本路径

- **素材来源（全部免费商用，无需授权）**：
  - **Kenney.nl** 的 `UI Audio` / `Impact Sounds` / `Interface Sounds`（**CC0**，一套几十个，覆盖 90% 反馈音）← **首选**
  - **freesound.org**（筛选 CC0）补特殊音（雷声 / 水声 / 钟鸣）
  - 爱给网 / Pixabay Sound（中文站，商用需看授权）
- **接入方式**：建一个 `SfxPlayer` 自动加载单例，`SfxPlayer.播放("突破")` 一行调用；音频文件预加载。
- **降级策略**：**音效没到位前，用动效兜底，不阻塞**。音效可以最后一次性批量挂上。
- **BGM**：不必早做；可用免费 CC0 国风循环曲，或后期再补。

### 8.5 「活起来」的首页（世界存在感 · 零美术也能做）

首页从"功能面板"变"活的宗门"，**分四层，前三层零依赖**：

| 层 | 内容 | 实现 | 依赖 |
|---|---|---|---|
| 底层 | 天色随时间渐变（晨/昼/暮/夜 四色循环） | 全屏 ColorRect + Tween 循环 | **零** |
| 中层 | 云 / 灵雾缓慢横移 | 半透明 ColorRect 或粒子 | **零** |
| 前景 | 灵田 / 堂口微动（呼吸缩放） | Tween 循环 | **零** |
| 顶层 | 背景立绘 / 场景图 | 豆包美术 | 需美术 |

→ **即使豆包美术为零，也能立刻做出"会动的宗门"**；美术到位后再替换底层为立绘。

### 8.6 我 / 豆包 分工与落地顺序

| 类型 | 谁做 | 依赖 | 何时做 |
|---|---|---|---|
| 全部 Tween / 粒子 / 飘字 / 震屏 / 转场 | **我**（纯代码） | 零 | **现在** |
| 首页程序化动态背景 | **我** | 零 | 现在 |
| 音效接入框架 + 免费音效下载挂载 | **我**（代码）+ 老大下素材 | 免费素材 | UI 布局后 |
| 页面专用图标 | **豆包** | 美术 | UX 冻结后 |
| 立绘 / 图鉴 / 场景图 / BGM | **豆包** | 美术 | UI 定稿后 |

**落地顺序建议**：**零依赖项（8.2 表里 12 项）与 UI 布局重构并行**，先把"反馈配得上事件"做出来（治"不爽"），再等美术/音效收口。

### 8.7 成本与风险（诚实评估）

- **可实现性**：8.2 清单中 **12/14 项零依赖**，纯代码可交付，**不阻塞**。这是给小白的关键保障——**不必等美术、不必买素材、不必会做美术**。
- **风险 1 · 性能**：粒子过多会让手机卡 → 必须锁 30fps + 限粒子数（对齐 §15.4）。
- **风险 2 · 版权**：音效务必用 **CC0**（Kenney / freesound CC0 筛选），避免商用纠纷。
- **风险 3 · 过载**：全屏仪式做太重，重复时反而烦 → 坚持"首次隆重、后续克制"。
- **风险 4 · 风格漂移**：程序化特效颜色必须取自 UITheme 真实 const（对齐 UITheme 红线），不得硬编码。

## 10. 一句话总结

**《太玄宗门录》不缺系统，缺的是「体系」。** 统筹的全部工作就是三件事：

1. **给一条主线**——太玄复兴（立宗/传世/证道），让每个系统都回答"我为复兴贡献了什么"。
2. **把柱焊起来**——四柱（门下/征伐/百工/四方）首尾相咬，任何产出必有下游、任何消耗必有来源。
3. **把节奏对准**——双轨归一，让"每日 08:00"和"游戏日推进"各就各位。

做到了，"系统多"就从负担变成护城河；做不到，系统越多，玩家越迷失。
