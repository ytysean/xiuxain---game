### 2. 装备战力加成差异化
不同武器类型和装备部位有不同战力系数，让装备更有差异化。

**武器类型战力系数**：
| 类型 | 系数 | 代表武器 |
|---|---|---|
| 高攻击型 | 1.3 | 刀、锤、斧 |
| 平衡型 | 1.0 | 剑、枪、棍 |
| 敏捷型 | 0.9 | 环、鞭、钩 |
| 法术型 | 1.1 | 扇、珠、琴 |
| 防御型 | 0.8 | 塔、钟、鼎 |
| 辅助型 | 0.85 | 拂尘、镜、印 |
| 控制型 | 0.9 | 索、锏 |

**装备部位战力系数**：
| 部位 | 系数 |
|---|---|
| 衣袍 | 1.0 |
| 头盔 | 0.8 |
| 护腿 | 0.75 |
| 护腕/项链 | 0.7 |
| 腰带/戒指/披风 | 0.65 |
| 靴子/手镯 | 0.6 |
| 玉佩 | 0.55 |

**品阶基础战力**：
凡阶10 → 灵阶30 → 宝阶80 → 王阶200 → 圣阶500 → 仙阶1200 → 道阶3000

**计算公式**：
`装备战力 = 品阶基础战力 × 武器类型系数 × 装备部位系数`

**修改文件**：`forge.gd`
- 新增函数 `计算装备战力()`
- 修改装备创建逻辑，使用差异化战力加成
