# GDD-凡人王朝系统（S34）

> 前置文档：`GDD-凡人香火.md`（本系统为其升级替代，香火链路保留复用）
> 设计目标：**把凡人世界从「数值管道」改造为「会自己生长的引擎」**，解决可玩但不好玩、易腻弃游的问题。
> 命名规范见 `design/01-总纲/§0-命名体系与双名制规范.md`

---

## 1. 概述

### 1.1 现状诊断（改动前真实代码状态）

| 项 | 现状 | 问题 |
|---|---|---|
| 凡人城镇 | `game_state.gd:14014` 由 `信徒数` 派生：`{"名":"信众镇%d","人口":100+i*50}` | **死数据**，无玩法、不可交互 |
| 香火月产 | `game_state.gd:10766`：`门派等级*8 + 弟子列表.size()*2` | **与凡人世界完全脱钩**，纯宗门派生 |
| 玩家操作 | 仅 `供奉香火()`（10788）一个按钮 | **零决策**，点了就完 |
| 世界变化 | 无 | **零变化**，没有回来看的理由 |
| 长线目标 | 无 | **零愿景**，不知道要把它变成什么样 |

**根本病因**：玩家对凡人世界**零输入** → 没有决策 → 没有玩法 → 变成看数字 → 腻。

### 1.2 设计目标（三条，按优先级）

1. **从「收租」变成「养蛊」**：投入越多，王朝长得越大，同时带来的麻烦也越多。有经营感。
2. **装一台会自己转的引擎**：王朝会兴衰、皇帝会换代、会改朝换代。世界在动，玩家才有理由回来看。
3. **每个阶段换焦点**：正统 → 经营 → 站队 → 割据。对抗操作疲劳，防止「每天做同一件事」。

### 1.3 范围边界

**做**：王朝实体 / 四阶段生命周期 / 12 郡关系网 / 朝堂派系 / 朝廷委托 / 册封位阶 / 改朝换代 / 正邪三分支终局 / 王朝反制机制。

**不做**（明确划出，防范围蔓延）：玩家自定义国号与国策、称帝建国沙盒、王朝内政微观管理（税赋/官员任免明细）。这些留待 V2 评估。

## 2. 设计总纲：五条原则

| # | 原则 | 说明 | 违反后果 |
|---|---|---|---|
| P1 | **玩家必须有输入** | 每个王朝状态量都要有玩家可影响的手段 | 退回「看数字」 |
| P2 | **两难优于最优解** | 盛世/乱世各有不可兼得的好处，无全局最优 | 玩家找到最优解后不再思考 |
| P3 | **危机可预期、可对冲** | 因果 70/30（引 §11.11），玩家看到预警来得及救 | 随机掉血 = 挫败弃游 |
| P4 | **世界自演化** | 无人干预时王朝也会推进生命周期 | 玩家不上线=世界静止=没理由上线 |
| P5 | **复用不重造** | 全部复用既有基建，新建仅限王朝实体/关系值/换代状态机 | 工期爆炸、回归风险 |

## 3. 核心循环：双向经营循环

```
        ┌──────────────────────────────────────────┐
        │                                          ▼
   王朝世界状态                                宗门收益
  (民心/国祚/派系/皇帝)  ──供奉·苗子·危机──▶  (香火/灵石/苗子/战功)
        ▲                                          │
        └──────────册封·差事·站队·平叛─────────────┘
                      （玩家决策）
```

- **顺向（世界 → 宗门）**：王朝阶段与郡县状态决定供奉量、苗子质量、危机频率。
- **逆向（宗门 → 世界）**：玩家通过册封、派差事、扶持派系、平叛赈灾改变王朝状态。
- **自演化（无玩家输入也转）**：皇帝衰老、国祚自然涨跌、阶段推进、派系互相倾轧。

## 4. 数据模型

### 4.1 王朝实体（新建，持久化）

```gdscript
var 王朝: Dictionary = {
    "国号": "大胤",           # 随机生成，改朝换代时刷新
    "朝代序": 1,              # 第几代王朝（跨代累加，不重置）
    "开国年": 0,              # 累计游戏日
    "阶段": "开国",           # 开国 / 盛世 / 中衰 / 乱世
    "阶段进度": 0,            # 当前阶段已持续（游戏月）
    "国祚": 100,              # 0-100 王朝寿命条，归零则改朝换代
    "民心": 60,               # 0-100
    "国策": "崇道",           # 开国随机特质，见 4.2
    "皇帝": {
        "名": "胤昌", "年龄": 42, "寿元": 60,
        "性格": "守成",        # 影响对宗门态度衰减速率
        "对宗门": 20           # -100(必欲除之) ~ 100(言听计从)
    },
    "对宗门关系": 50,          # 0-100 双边关系主值
    "宗门爵位": "未册封",      # 见 §7
    "派系": [],               # 见 4.4
    "皇子": []                # 继承人候选，中衰期后解锁押注
}
```

**⚠️ 三铁律之一**：新增持久字段必须同时改 **存档 / 读档 / `new_game()`** 三处（S31 血泪：漏 new_game 导致切账号继承上一宗门版图）。

### 4.2 国策特质（开国随机，驱动重玩）

| 国策 | 供奉 | 苗子 | 兵力 | 对宗门态度 | 玩法倾向 |
|---|---|---|---|---|---|
| 崇道 | +30% | 供给+ | 弱 | 天然亲近 | 正道最舒服的档 |
| 重文 | 持平 | 资质+ | 弱 | 中立 | 苗子流最优 |
| 尚武 | -20% | 持平 | 强 | 疏远 | 战功流，但香火少 |
| 奢靡 | +50% | - | 中 | 依赖供奉 | 短期暴利，民心崩得快 |
| 猜忌 | 持平 | 持平 | 中 | 衰减×2 | 需要持续维护关系 |
| 灭法 | -100% | 断绝 | 强 | 敌视 | **最难档**，奖励最高，逼玩家掀桌 |

**设计意图**：每个档开局的国策不同 → 玩法最优解不同 → 玩家见过「崇道」会想试试「灭法」怎么处理。**收集驱动 = 长线动力**。

### 4.3 郡县（复用 `city_config.csv` 12 城，补列）

**新增列**：`人口 / 兵力 / 是否凡俗 / 所属王朝 / 忠顺度 / 感恩度 / 灾情`

**关键设计：忠顺度与感恩度是两条独立的轴**

| 轴 | 对象 | 含义 | 玩法后果 |
|---|---|---|---|
| **忠顺度** | 郡 → 王朝 | 该郡对朝廷的忠诚 | 低 → 该郡可能叛乱 → 王朝国祚↓ |
| **感恩度** | 郡 → 宗门 | 该郡对宗门的感激 | 高 → 供奉加成、优先供给苗子 |

**双轴是割据路线的核心**：玩家同时推高感恩度、压低忠顺度 = **挖王朝墙角**，为「自立为王」铺路。这是中立路线的专属玩法。

| 城邦等级 | 人口 | 月灵石 | 月香火 | 兵力 |
|---|---|---|---|---|
| L1（村镇） | 8,000 | 6 | 15 | 200 |
| L2（县城） | 30,000 | 10 | 25 | 800 |
| L3（郡城） | 120,000 | 15 | 40 | 3,000 |
| L4（王都） | 500,000 | 20 | 60 | 12,000 |

### 4.4 朝堂派系（批次 2）

四大固定派系 + 各自诉求与掌权后果：

| 派系 | 诉求 | 掌权后果（对宗门） |
|---|---|---|
| 士族 | 要功名、要灵根苗子 | 苗子质量 +，供奉持平 |
| 边将 | 要战功、要丹药 | 战功机会 +，但兵祸频发 |
| 宦官 | 要灵石、要控制 | 供奉 +30%，民心 -（埋民变雷） |
| 外戚 | 要联姻、要庇护 | 关系值 +，但会索要弟子入赘 |

派系权重随事件与玩家干预变动，权重最高者掌权 → 施加对应后果。**玩家站队是可逆的，但背叛有代价**（掌权派系对背叛者记仇）。

## 5. 四阶段生命周期（防腻核心引擎）

| 阶段 | 国祚区间 | 供奉 | 灵根苗子 | 玩家焦点 | 主要危机 |
|---|---|---|---|---|---|
| **开国** | 80-100 | 低 | 少而杂 | 确立正统（别被当邪教剿了） | 灭法诏、邻国入侵 |
| **盛世** | 55-80 | 高且稳 | 多而平庸 | 经营郡县、平衡派系 | 奢靡索贡、继位之争 |
| **中衰** | 25-55 | 下滑 | 中等 | 站队、押注继承人 | 民变、藩镇割据 |
| **乱世** | 0-25 | 断绝 | 少但出天才 | 平叛、割据、自立 | 流民潮、妖魔趁乱 |

### 5.1 核心两难：盛世 ≠ 最优（P2 原则）

- **盛世**：供奉高且稳定 → 缺灵石时最优。但苗子**多而平庸**，资质集中在中档。
- **乱世**：供奉断绝 → 财政重伤。但流民中出高资质苗子的概率**显著提升**（「乱世出英杰」），且方差极大，可能出「道胎」。

**玩家要根据当前缺什么来决定扶持还是放任**：缺灵石 → 保盛世；缺天才弟子 → 放任甚至推动乱世。
同一个系统产生相反的最优解 → 玩家才有得想，才不会无脑刷一个状态。

### 5.2 阶段推进与改朝换代

- 阶段推进由 `国祚` 驱动，国祚每月按 `民心/灾情/兵祸/宗门干预` 涨跌（P4 自演化）。
- `国祚 ≤ 0` → **改朝换代**：新国号、新皇帝、新国策、版图忠顺度重掷 → 回到「开国」阶段。
- **改朝换代 = 内容刷新**，这是对抗「内容消耗完」的最强机制（无限内容，零美术成本）。

## 6. 四大玩法支柱

### 6.1 国运兴衰（经营层）
玩家手段：赈灾（消耗灵石/粮草 → 民心+）、平叛（复用 `宣战()`）、传道（推感恩度）、强征（供奉×2 但民心暴跌）。

### 6.2 朝堂博弈（政治层，批次 2）
扶持派系（消耗灵石/贡献）、调停倾轧、站队押注。**站队可逆，背叛有代价**。

### 6.3 凡间差事（任务层，批次 1 主内容）
复用 `宗门任务榜` 全套机制（招募中 → 执行中 → 到期结算 + 弟子请命），仅新增「发布方」字段（宗门/朝廷）。

委托类型（复用 `sect_bounty_config.csv` 的 `bounty_type`，新增 diplomacy 型模板）：

| 类型 | 内容 | 成功 | 失败 |
|---|---|---|---|
| 赈灾 | 派弟子开仓放粮 | 该郡感恩 +20、民心 +10 | 感恩 -15、弟子忠诚 -5 |
| 除妖 | 清剿为祸妖兽（真实战斗） | 感恩 +15、战功 | 弟子重伤/陨落 |
| 平叛 | 镇压叛军（复用 `宣战()`） | 王朝国祚 +15、关系 +20 | 关系 -25、被扣「平叛不力」 |
| 寻访灵根 | 在郡内搜寻有灵根孩童 | 获得苗子候选（引 §11.6 下山测灵） | 无 |
| 护送 | 护送贡品/官员 | 灵石 + 感恩 +5 | 贡品被劫、赔偿 |
| 监国 | 高阶，稳定某郡局势 | 该郡忠顺度可控 | 反噬 |

**后果永久留存**：办得好 → 该郡感恩度上升，永久供奉加成；办砸 → 该郡记恨，触发报复事件链。**玩家留下的是自己经营出的关系网，不是一堆数字**（COC 式「建设→结果→复盘→调整」闭环）。

**弟子请命联动**（接 S30 情感系统）：弟子会主动请命并给出性格驱动的理由，玩家批准/驳回影响忠诚与心境。

### 6.4 册封位阶（长线身份爬升，批次 2）

| 位阶 | 门槛 | 解锁能力 |
|---|---|---|
| 未册封 | — | 仅被动收供奉 |
| 护国宗 | 关系≥60 且 3 郡感恩≥50 | 接朝廷委托、派差事 |
| 国师 | 关系≥75 且 门派等级≥5 | 荐举官员（影响派系权重）、调停民变 |
| 帝师 | 关系≥90 且 正道功德≥300 | 押注继承人 |
| 监国 | 正道终局 | 废立皇帝（不可逆大事件） |
| 摄政 | 邪道终局：业力≥300 | 供奉×2，民心持续下滑 |
| 自立为王 | 中立终局：3 郡感恩≥80 且 3 郡忠顺≤20 | 脱离王朝，永久敌对 |

## 7. 王朝有牙齿：反制机制

**原则（P3）**：所有反制必须**条件可预期、手段可对冲**，绝不做纯随机掉血。

| 反制 | 触发条件（玩家可预见的） | 对冲手段 | 后果 |
|---|---|---|---|
| 强征供奉 | 国祚<40 且 关系≥交好 | 缴纳 / 拒绝（关系 -15） | 财政失血 vs 关系恶化 |
| 扣押弟子 | 弟子在郡办差失败 | 赎回（灵石）/ 营救（宣战） | 该郡感恩 -10 |
| 断供 | 该郡感恩≤20 或 关系≤疏远 | 派差事修复 | 该郡供奉归零 |
| 禁传道 | 关系≤敌视 或 国策=灭法 | 改国策（需操控派系上位） | 该郡不再供给苗子 |
| **灭法令** | 业力≥200 且 关系≤敌视 且 国策=灭法 | 正面迎战 / 迁宗（弃领地）/ 扶持叛军推翻 | 宗门防守战（复用 `宣战()`，敌方=王朝禁军） |

**灭法令是最强的牙齿**：触发前给足预警（关系值逐月下滑 + 纪事警告），玩家有时间补救。触发后三条路都能走通，不会被逼死。

## 8. 正邪三分支终局

复用既有 `选择正邪路线()`（game_state.gd:10825）+ 功德/业力门槛，凡间终点三分：

| 路线 | 终局 | 专属机制 | 代价 |
|---|---|---|---|
| **玄门正道** | 帝师 → 监国 | 王朝气运与宗门气运绑定，可废立皇帝 | 王朝亡则宗门重伤（共存亡） |
| **九幽邪道** | 操控 → 傀儡皇帝 | 供奉×2，可操控国策 | 民心持续归零，随时改朝换代翻车 |
| **逍遥中立** | 割据 → 自立为王 | 挖墙角（推感恩压忠顺），脱离王朝 | 与王朝永久敌对，无朝廷委托 |

三条路各有**专属事件池与结局文案**，重开档驱动力最强。

## 9. 防腻机制专章（本系统的核心诉求）

| # | 机制 | 对抗的「腻」 | 实现要点 |
|---|---|---|---|
| 1 | **王朝自演化引擎** | 世界静止，没理由上线 | 皇帝衰老换代、国祚自然涨跌、派系倾轧、阶段推进，全部在月度结算中自动跑 |
| 2 | **每阶段换焦点** | 每天做同一件事 | 正统 → 经营 → 站队 → 割据，四阶段玩家操心的事完全不同（引《三国冰河时代》「资源焦点随阶段移动」） |
| 3 | **改朝换代 = 内容刷新** | 内容消耗完 | 新国号/新皇帝/新国策/版图重掷，零美术成本的无限内容 |
| 4 | **有意义的两难** | 找到最优解后停止思考 | 盛世 vs 乱世、供奉 vs 苗子、缴纳 vs 拒绝，无全局最优 |
| 5 | **不可逆抉择** | 存档缺乏独特性 | 立储站队、是否弑君、是否割据，选了不能改，每档不一样 |
| 6 | **可预期可对冲的危机** | 随机掉血的挫败感 | 因果 70/30，预警先行，永远给第三条路 |
| 7 | **弟子-凡间情感绑定** | 凡人世界是抽象数字 | 弟子有故乡/家人字段，派回故乡办事有特殊加成与专属事件（接 S30 情感系统） |
| 8 | **国策随机 = 收集驱动** | 玩过一次就不想玩 | 6 种国策 × 4 阶段 × 3 终局，玩家会想「灭法档怎么处理」 |

## 10. 数值与配置

### 10.1 月度经济核算（S32 铁律三：先算频率再定数）

> **⚠️ 口径勘误（2026-09-03 落地时实测，本节原内容有误，以下为修正版）**
> 原文写的「`推演一月` 频率 = 12 次/现实天」是错的。实测真源：
> - `main.gd:3901` 心跳间隔 = `现实秒每游戏日 = 240`（game_state.gd:21）
> - `推演一月(月)` 末尾 `累计游戏日 += 1`（game_state.gd:10300）→ **每次调用只推进 1 游戏日**
> - ⇒ 真实频率 = 86400 / 240 = **360 次推演/现实天**（= 12 个「30 游戏日的王朝月」/现实天）
> - **12 这个数字的正确含义是「每月产出 → 每现实天产出」的折算系数，不是推演次数。**
>
> 更关键的连锁结论：**`_结算香火_S1` / `_结算运维成本_S1` / `_结算宗门领地_S1` 全部挂在
> `推演一月()` 内，因此它们是【日频】而非月频。** 项目里所有叫「月产」的数值
> （运维封顶 318、S32 领地月灵石 70/90/45/35）其实都是**每次推演全额加**。
> S34 所有新增产出必须对齐这个口径，否则要么印钞要么无感。

- 宗门运维封顶 = **318 灵石/推演**（既有基准，S32 已校准，日频）

**凡间供奉灵石（日频实加，`_郡县供奉灵石_S34`）**

| 阶段 × 国策 | 满版图 9 郡 | 占运维 318 | 判定 |

#### 批次 2 落地过程中诊断并修正的 6 个真问题

1. **纯零和模型在数学上退化为轮值表** —— 掌权者保持第一需 `W > 25 + D`，初始 W=25 则首月必下台。
   网格搜索 16 组参数，零干预易主恒 121/120 月、最长连续恒 1，**调参完全无效（模型问题非参数问题）**。
   解法：双机制（权柄红利 `ruling_power` + 反对派压力 `ruling_decay`，净差驱动）+ 铁律 `power < decay`
   + 抑强扶弱逆序分配（在野三派按权重升序依次得 2/1/0 份）+ 新朝气象一次性加成。
   实测：零干预 240 月易主 57 次、平均在位 4.3 月、最长 7 月、四派系全覆盖。

2. **`growth` 参数全面失效** —— 递增项加在流失量上、随后被 `/3` 整数截断，而派系在位仅 2~4 月
   永远够不着「每在朝 N 月」门槛（网格 9 组参数结果完全一致）。解法：递增项改作用到步长上。

3. **「压制积怨」机制被移除**（立论被证伪）—— 补丁 11 曾加「在野派系被压到权重 ≤ 阈值则每月积怨」，
   用来惩罚梭哈。但它是**补丁 7 前缺资源约束的探针造出的假象**：加上资源约束后梭哈外戚第 65 月就
   因弟子耗尽断供，根本不存在「躺赢」。且阈值 10 是死代码（全场景 0.00 触发）、阈值 14 误伤分散押注
   （关系 85.2 → 32.5）。按「2 次优化无效换方案」铁律，调第三次之前直接删除。

4. **外戚全线垫底 → 入赘从纯牺牲变成投资** —— 外戚付出最痛的代价（弟子，宗门命脉）却回报最平庸，
   实测断供最早（65 月）、无人问津。CSV 承诺的「掌权则关系易修」代码未实现。
   解法：`外戚掌权关系修`（+0.1/月，0.3 太强会把零干预基线从 50 抬到 67 稀释策略差异）

   谁都能接）、护国宗义务「不可拒朝廷征调」（未实现）、国师「荐举左右派系权重」（只扣钱、零效果）。
   **玩家一算账就永远不会受封**。
   解法（补丁 18）：爵位从成就徽章改为**解锁玩法层** ——
   `decree_slots`（差事榜容量：未册封 4 / 护国宗 5 / 国师 7 / 帝师 9）

   荐举费 200 → 60，且义务从「每月无条件扣费」改为「不荐举才罚」（罚 5 关系，爵位不革除留补救窗口）。
   收益曲线（满版图，统一折算到每王朝月）：**3024 → 3378 → 4048 → 4791**，每级净正且递增。

6. **荐举没有 UI 入口** —— 补丁 18 加了「每月须荐举，逾期罚关系」的义务却没给按钮，

### A.1 身份差别（一句话）

- **引擎版**：玩家是**客卿** —— 影响别人的王朝，权力终点 帝师 / 摄政 / 自立为王。
- **沙盒版**：玩家是**庄家** —— 推翻旧朝、自建王朝、宗门升格为国教，兼任掌门与皇帝。

### A.2 三层增量

| 层 | 内容 | 治的「腻」 |
|---|---|---|
| 增量一 · 开国自定义 | 三条掀桌路线（兵变夺都 / 禅让 / 受命于天）+ **开国六问**（国号自打字 · 国策×2 · 都城 · 官制 · 律法 · 国教） | 重玩动力从「被动抽卡（随机国策）」升级为「主动解题（build 组合）」。国策 6 选 2 × 官制 × 律法 × 军制 = 上百种组合 |
| 增量二 · 朝廷经营层 | 新资源轴：国库（灵石·粮）/ 民力（徭役）/ 官僚；官员实体（能力·贪腐·派系·忠诚·出身）；政策卡（可换但有民心震荡）；军制三选一（府兵/募兵/藩镇）；邻国外交 | 凡人侧的人力资源管理。**风险最高：易变成第二个弟子系统** |
| 增量三 · 国教与信仰网络 | 香火庙网络按人口覆盖产信仰度 → 愿力；宗门升国教；**信仰竞争**（佛门/魔门/民间淫祀争夺信徒） | 唯一不可替代的增量，把现有单向链接成四段闭环 |

### A.3 国教信仰闭环（沙盒核心）

```
① 信众（人口 × 信仰度）→ ② 香火·愿力产出 → ③ 宗门实力 → ④ 护国实绩（平叛/赈灾/除妖）→ 回哺 ①
                ↑ 干扰：异端信仰（佛门 / 魔门 / 淫祀）争夺未覆盖郡县的信徒
```

- 香火庙有辐射半径，覆盖人口决定信仰度上限（复用建筑系统，需先解决 §14 硬编码三处）。
- 信仰度影响：香火月产、灵根苗子出现率、下山测灵成功率。
- **愿力复用现有字段，不新建货币**（项目已有 香火/功德/业力/战功/贡献点/贡献账户）。
- 异端不主动扩张则自增长；玩家可传教（慢）/ 辩法（中）/ 镇压（快但民心暴跌）。

### A.5 风险（牛马的反对意见）

1. **注意力稀释**：同时经营宗门 + 王朝，可能两边都做不深，反而不如引擎版聚焦。
2. **官员 = 第二个弟子系统**：能力/贪腐/派系/忠诚与弟子高度同构，玩家会觉得重复操作。**建议降级：一郡一员，只留 能力/贪腐/忠诚 三个数，不做性格、不做互动、不做详情弹窗。**
3. **数值通胀**：国教香火 × 12 郡供奉 × 政策加成 三重叠乘，极易突破运维封顶 318（S32 铁律三：月产 ×12 才是日入）。
4. **竖屏 UI 装不下**：1080×1920 放复杂王朝面板，至少需要 3–4 屏与新的二级导航。
5. **终局烂尾风险**：飞升后王朝四种归宿（禅让 / 留傀儡 / 带国飞升 / 国崩）需要额外收尾文案与结算，是典型的「做了前面忘了后面」。
