## 0. 摘要与决策

**范式切换**（v2 → v3 宗主玉牒国风版）：
- v2 极简理性版（单立绘 + 信息卡堆叠）→ **v3 国风玉牒版**（全身立绘 + 4 列概览 + 7 个权责按钮 + 玉牒履历时间线）。
- **重大修改**：Hero 区 **取消圆形玉玦金框 + 裁切立绘**，回归**全身立绘**占 38-42% 屏高，左侧叠加竖向身份信息条。圆形头像框仅作「编辑」入口内的外观选项，**不**在本页主视觉出现。
- 权责按钮 7 个固定：① 宗门规制 ② 职司任免 ③ 功勋赏罚 ④ 闭关设置 ⑤ 宗门纪事 ⑥ 物资调配 ⑦ 阵堂布置。
- 玉牒履历：仅 `Game.宗门纪事` 中 `category=="宗门大事件"`，按日倒序取最近 5 条。
- 宗主境界：S1 三段兜底（Game 宗主键 → 宗门最高弟子境界 → 「—」），**S2 再补宗主独立境界**；本期显示文案标注「宗门当前最高境界」。
- 编辑入口：右上角「编辑」按钮弹二级弹窗，收纳**改宗主称号 / 换全身立绘 / 头像选择**三类外观操作。
- 实施阶段：F1 白皮书 patch（本文）→ F2 .gd 重写 → F3 pre_f5 全绿 → F4 memory 同步。

## 1. 概述与红线重申

### 1.1 目标
宗主详情页从 v2 极简理性版**范式切换**为 v3 国风玉牒版（重交互·卷轴·权责·履历），使宗主身份在视觉权重与功能入口上都与"通用详情"形成清晰区隔。

### 1.2 硬红线（绝不可破）
1. **UI 层零 GameState 写入**：所有操作（权责按钮/编辑/头像选择）仅 `emit` 占位信号或经由 `main.gd` 子页路由；本页**绝不**直接 `Game.宗主名 = ...` 等写入。
2. **数据只读**：所有字段通过 `is_instance_valid(Game) + Game.get()` 守卫读取；缺失即 `"—"` 不崩。
3. **动态色一律走 `UITheme` getter + `UIThemeConfig`**（品级/境界/状态），静态色走 `main_theme.tres` + `ui_theme.gd`；禁止散落硬编码 `Color(#...)`。
4. **组件复用优先**：复用现有 `BasePanel` / `ListItem` / `PanelContainer` / `TextureRect` / `Button`；不新建重复组件。
5. **触摸目标 ≥ 44×44px**（权责按钮、行级触发区），正文/数值 ≥ 15px（ACCESSIBILITY Standard）。
6. **一页一滚**：单 `ScrollContainer` 包裹全内容；不嵌套 ScrollContainer（IA §3.2 硬性约束）。

## 4. Hero 立绘区（修订后的硬需求）

> 老大 2026-08-21 审批硬修正：取消圆形玉玦金框 + 裁切立绘，回归全身立绘。

### 4.1 布局
- Hero 区高 ≈ 38-42% 屏高（即 320-360px 在 854 屏内）。
- 内部结构：左半（约 35-45% 宽）= 身份信息条（VBox 3 个 Label），右半（55-65% 宽）= 全身立绘。
- 立绘 TextureRect：KEEP_ASPECT_CENTERED，**完整展示**，不裁切。

### 4.2 视觉规范
- 立绘 Panel：`bg_color=透明`、**1px 玉色描边**（`Color(0.85, 0.95, 0.92, 0.4)`，与 P1-详情页 BasePanel 同色阶）、圆角 12。
- **不**叠加任何融合层（外阴影/内阴影/环境光/背景渐变）——立绘是美术画好带光影的完整资源，强行加层反而破坏原画（沿用 v2 注释结论）。
- 身份信息条 Label 颜色：标签灰 `C01_TEXT_TERTIARY`（13px）、值金 `COLOR_TEXT_GOLD`（15px 大字，**仅境界值**）+ 灰（隶属/执掌）。

### 4.3 多分辨率适配（新增测试用例 §7）
- 480×854 标准机：单立绘 + 单身份条。
- 比例 ≤ 0.55 的宽屏：立绘缩小至 40% 高。
- 比例 ≥ 0.6 的窄屏：立绘压至 35% 高，身份条字号 -1px。
- 比例 ≥ 0.7 的极窄屏：身份条字号 -1px，立绘自动 keep aspect。
- 落地由 `control.size` + `custom_minimum_size` 配合实现；**不**用绝对坐标硬编。
