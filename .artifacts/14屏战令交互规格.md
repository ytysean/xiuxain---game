## 3. 信息架构
```
顶栏（返回 + 标题 + 仙玉余额）
等级行（赛季 N · Lv.x / 最大 + 经验进度条）
反馈行
滚动区：
  ├ 免费轨道（标题）
  │   └ Lv.1 … Lv.最大（每行：等级 + 奖励按钮，三态）
  ├ 付费轨道（标题 + 解锁状态）
  │   └ Lv.1 … Lv.最大（每行：等级 + 奖励按钮）
  └ 解锁付费轨按钮（未购）/ 付费轨已解锁（购后 disabled）
```

## 4. 交互规则
- **领奖（轨道, lv）**：`Game.领战令奖励(轨道, lv)` → 反馈 + refresh + emit `战令领取完成`。
- **解锁付费轨**：`Game.购战令付费轨()` → 反馈 + refresh（价格 `BattlePass.付费轨价`）。
- **奖励按钮三态**：
  - 已领 → 前缀「已领·」+ disabled（次按钮灰）。
  - 可领（未领且轨道已解锁/免费轨）→ 主按钮金，点击领奖。
  - 付费轨未解锁 → 前缀「未解锁·」+ disabled。
- **经验进度**：`经验 / 本级所需` → ProgressBar（继承 main_theme 默认绿 fill）。
- **返回**：emit `返回主页`。
- 轨道行数 = `信息.最大等级`，画布示意 Lv.1–3。
