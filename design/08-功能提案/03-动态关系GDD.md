# 《太玄宗门录》人际关系动态演化系统 GDD（提案 B/C · F6/F11/F13）

> **核心定位**：弟子关系从「静态标签」升级为「6 层双向动态网络 + 传导 + 圈层视图」。全部为社交/养成类，**零战斗结算**，S1 可交付；仅「同队羁绊/减益」涉及战斗，标 `[S2-战斗放开]`。
> **诚实标注**：复用现有关系网络字段（disciple.gd `关系网络`，`GDD-弟子养成.md` §二），扩展 6 层双向 + 传导 + 圈层分组，需轻量代码 + CSV。

---

## F6. 人际关系动态演化（6 层双向 + 传导）

### 1. 定位
关系分层（正向 初识→交好→挚友→道侣；负向 生疏→交恶→敌对）+ 演化规则 + 传导规则。

### 2. 核心规则与数值（提案 B·P0 / C 详解）
**6 层双向阈值（关系值 -100~100）**：
| 关系层 | 关系值区间 | 性质 |
|---|---|---|
| 初识 | 0 ~ 20 | 正向·浅 |
| 交好 | 21 ~ 50 | 正向 |
| 挚友 | 51 ~ 80 | 正向 |
| 道侣 | 81 ~ 100 | 正向·羁绊 |
| 生疏 | -1 ~ -30 | 负向 |
| 交恶 | -31 ~ -70 | 负向 |
| 敌对 | -71 ~ -100 | 负向 |

**演化规则**：
- 升温途径：共修/互助/互赠（F1）/ 共历事件 → 关系值↑。
- 降温途径：冲突/争夺/长期不互动（衰减）→ 关系值↓。
- 每日/事件驱动结算，clamp 至 [-100, 100]。

**传导规则（关系网络外溢）**：
| 传导类型 | 加成 |
|---|---|
| 师门传导 | +15 |
| 同辈传导 | +10 |
| 兴趣圈层传导 | +30 |
| 负面传导 | -10 |

**增益/减益上限**：
- 正向增益上限：+8%（关系带来的养成增益，如挚友修炼互助）。
- 负向减益上限：≤ -10%（交恶/敌对带来的效率降）。
- 道侣占比上限：道侣关系增益在总关系增益中占比封顶（防止单一道侣过度放大）。

### 3. 数值与配置
| 项 | 值 | 配置载体 |
|---|---|---|
| 6 层阈值 | 见上表 | `关系分层.csv`（提议新增） |
| 升温/降温速率 | 每事件 ±X（待校准） | 同上 |
| 传导系数 | 师门+15/同辈+10/兴趣+30/负-10 | `关系传导.csv`（提议新增） |
| 增益上限 | +8% / 减益≤-10% / 道侣占比上限 | `关系增益上限.csv`（提议新增） |

### 4. 复用现状 · 诚实标注
- ⚠️ **需轻量代码 + CSV**：复用现有 `关系网络`（师徒/道侣/同门，`GDD-弟子养成.md` §二），扩展为 6 层双向值 + 演化 + 传导逻辑 + 关系矩阵 CSV。**非纯配置**。
- ✅ 道侣/师徒：现有关系字段已含，本批细化分层与传导。

### 5. S1/S2 分期
- **S1 交付**：6 层关系值 / 演化 / 传导 / 增益上限（养成类，S1 生效）。
- **[S2-战斗放开]**：同队羁绊/减益（战斗层）→ S2-2（S2 初期生命周期钩子 on_battle_start / on_round_end，属性等效或扩展接口层）。

### 6. UI 入口规范（对齐 B2）
- 关系展示：弟子详情弹窗「关系网络」行（非首页按钮，B2 合规）。
- 无编辑入口（关系由事件演化），不新增导航项。

### 7. 跨文档一致性
- 关系增益 → `数值体系细则.md` §4.6「羁绊/社交乘区」（通用增益软 25%/硬 30%）；+8% 为单源子帽。
- 道侣 → `GDD-弟子养成.md` §三.2（结为道侣事件）；F13 道侣子嗣衍生。
- 战斗项 → `[S2-战斗放开]`，不接 `BattleManager.gd`。

### 8. 边缘情况（≥3）
- **EC-1 关系值越界**：clamp [-100,100]，防溢出。
- **EC-2 弟子离宗/坐化**：关系网络移除该节点，关联弟子关系值回退一层（不崩）。
- **EC-3 多关系冲突（既师门又同辈）**：传导系数取和但封顶单源子帽（+8%）。
- **EC-4 旧档无关系值**：`.get` 默认 0（初识），不崩。

### 9. 验收标准
- 关系值 6 层演化 + 传导 + 增益上限（+8%/-10%/道侣占比）生效；同队战斗减益仅 S2；旧档兼容；乘区登记。

## F11. 宗门圈层派系（同辈 / 师门 / 兴趣圈层）

### 1. 定位
将弟子关系网络按「同辈 / 师门 / 兴趣」分组为圈层视图（社交结构可视化 + 轻量派系效果）。

### 2. 核心规则
- **师门圈层**：同师尊弟子集合（复用师徒关系）。
- **同辈圈层**：同身份轴层级弟子集合（复用 `身份层级序`）。
- **兴趣圈层**：同副职业/特质倾向弟子集合（复用 F4 特质 / F10 副职业）。
- 圈层为**关系网络的视图分组**，非独立数值系统；可带极轻微圈层内部增益（须登记乘区）。

### 3. 数值与配置
| 圈层 | 来源 | 效果（建议） |
|---|---|---|
| 师门 | 师徒关系 | 内部互助增益（≤ 关系增益 +8% 内） |
| 同辈 | 身份轴 | 同阶社交（无数值或极微） |
| 兴趣 | 特质/副职业 | 同好事件概率 +（待校准） |

### 4. 复用现状 · 诚实标注
- ⚠️ **需轻量代码**：圈层为关系网络/身份轴/特质的**分组视图**，非新数值原点；若带增益须登记乘区（`数值体系细则.md` §4.6）。
- ✅ 复用现状：师徒关系 / 身份轴 / 特质 / 副职业均已有。

### 5. S1/S2 分期
- **S1 交付**：圈层视图 + 轻量内部增益（若有）。无战斗结算。

### 6. UI 入口规范（对齐 B2）
- 圈层展示：弟子详情弹窗「所属圈层」标签 / 纪事阁分组（非首页按钮，B2 合规）。

### 7. 跨文档一致性
- 师门 → F6 师门传导 +15；同辈 → F6 同辈传导 +10；兴趣 → F6 兴趣传导 +30。
- 不新增独立数值系统（对齐 `GDD-活动系统.md` 铁则「不新增第二数值原点」）。

### 8. 边缘情况（≥3）
- **EC-1 弟子跨多圈层**：允许多归属，展示并列。
- **EC-2 圈层为空**：不渲染，不报错。
- **EC-3 增益叠加**：圈层增益与关系增益合并卡 +8% 子帽。

### 9. 验收标准
- 圈层按师门/同辈/兴趣正确分组；轻量增益卡乘区；不新增独立系统。

## F13. 道侣子嗣（关系衍生 · 跨 06 寿元传承）

### 1. 定位
道侣关系触发 → 子嗣继承灵根特质 → 自动生成外门弟子（宗门血脉延续）。

### 2. 核心规则
- 触发：弟子结为道侣（`GDD-弟子养成.md` §三.2 事件）后，按概率/条件诞下子嗣。
- 子嗣：继承双亲灵根特质（F4 特质遗传）+ 随机基础属性 → 自动成为**外门弟子**（接引堂生成链路）。
- 跨系统：前置依赖 F6 道侣关系；后续依赖接引堂（自动外门）+ F12 血脉传承（先贤祠/传承）。

### 3. 数值与配置
| 项 | 值 | 配置载体 |
|---|---|---|
| 道侣诞嗣概率 | 待校准 `[PLACEHOLDER]` | `道侣子嗣.csv`（提议新增） |
| 灵根继承 | 双亲灵根按权重继承 | 复用 `举办测灵根` 生成 |
| 身份 | 自动外门 | 复用接引堂默认外门 |

### 4. 复用现状 · 诚实标注
- ⚠️ **需轻量代码**：道侣关系触发 → 调 `举办测灵根`（game_state）生成外门弟子 + 继承特质字段；复用接引堂生成链路（`GDD-弟子阶位轴.md` §7.1 接引堂）。
- ✅ 复用现状：道侣事件 / 测灵根 / 外门体系已建。

### 5. S1/S2 分期
- **S1 交付**：全功能（生成外门弟子，非战斗）。无战斗结算。

### 6. UI 入口规范（对齐 B2）
- 无入口（事件触发）；子嗣在弟子录/纪事阁可见（主导航「弟子」/「纪事」，B2 合规）。

### 7. 跨文档一致性
- 道侣前置 → F6 / `GDD-弟子养成.md` §三.2。
- 生成外门 → 接引堂（`GDD-弟子阶位轴.md` §7.1）/ `S1-S2功能储备与扩展端口清单.md` §三。
- 血脉传承 → F12 寿元传承（先贤祠/传承体系）。

### 8. 边缘情况（≥3）
- **EC-1 双亲一方已离宗/坐化**：诞嗣取消或归单方，按规则定。
- **EC-2 子嗣灵根冲突**：权重随机或取高，不崩。
- **EC-3 外门名额满**：子嗣仍生成（外门为储备，不卡名额，参考接引堂逻辑）。

### 9. 验收标准
- 道侣触发诞嗣 → 继承特质 → 自动外门；跨 F6/F12 一致；旧档兼容。
