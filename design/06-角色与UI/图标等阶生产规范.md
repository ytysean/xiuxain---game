# 图标等阶生产规范（v1.0 锁定）

> 适用范围：修仙经营手游《太玄宗门录》全部道具/法宝/装备/功法图标。
> 本规范为**长期生产标准**，后续新增图标必须自动遵循，违者按返工处理。
> 状态：**v1.0 已锁定（2026-07-30）**，全量 354 张资产已通过校验并归档。

---

## 1. 双轨阶位体系（核心铁律，不可再改）

图标阶位由**两层独立编码**共同表达，二者信息不冗余：

| 编码层 | 表达什么 | 取值 | 作用 |
|--------|---------|------|------|
| **三层边框** | 快速分高低（3 档） | `low` 细边 / `mid` 中边 / `high` 宽边 | 背包一眼辨品阶 |
| **七级色点** | 精确品级（7 档） | 凡灰 / 灵绿 / 宝蓝 / 王紫 / 圣橙 / 仙金 / 道红 | 编码 7 档真实品阶 |

### 1.1 边框宽度（程序化确定性生成，硬编码于 `tier_system.make_base`）
| 档 | 宽度 | 结构 |
|----|------|------|
| `low`  | **9px**  | 单圈哑光暗铜窄边 + 细内线 |
| `mid`  | **20px** | 双圈亮面金边 + 内侧淡玉环 |
| `high` | **30px** | 三圈暗金宽边 + 浮雕雷纹 + 内圈暗金 |

> 间距已按 P1 拉大（原 12/16/22 → 9/20/30），小图下层级辨识度达标。**禁止**任何图标出现边框粗细与档位不符的情况。

### 1.2 七级色点（徽章体颜色，编码 7 档品阶）
`凡[灰] / 灵[绿] / 宝[蓝] / 王[紫] / 圣[橙] / 仙[金] / 道[红]`

> ⚠️ **绿点合法**：灵品档徽章为绿色，是 7 色阶点之一，**不是非法色标**。
> 不得改成「低阶灰/中阶蓝/高阶金」三色方案——那会丢失 7 档品阶编码。
> 色点由 `tier_config.json` 的 `grade_colors` 权威定义。

### 1.3 tier 映射（CSV → 边框档）
| 品阶 | tier | 边框 |
|------|------|------|
| 凡品 / 灵品 | `low`  | 细边 |
| 宝品 / 王品 / 圣品 | `mid`  | 中边 |
| 仙品 / 道品 | `high` | 宽边 |

## 2. 工程规格（Godot 接入硬约束）

- **画布**：1024 × 1024，正方形，PNG。
- **透明通道**：四角 RGBA = `[0,0,0,0]` 全透明（满足 Godot 透明图标接入）。
- **中心物安全边距**：中心物半幅 `high` 档仅 307px，边框内缘 448px，**余量 141px ≫ 2px 阈值**，无贴边溢出风险，不做收缩。
- **无白边描边**：严禁给道具加白色羽化外框（紧邻透明区的白色像素 = 0 为合格线）。
- **居中摆放**：道具主体居中，上下左右安全边距均等。

## 3. 生产管线（配置驱动，零 ImageGen 返工）

权威配置源：`tools/icon_pipeline/tier_config.json`
批量合成主脚本：`tools/icon_pipeline/tier_system.py`
中心物来源：ImageGen 生成 → `icon/_centers/`（命名见 `center_prompts.json` 的 slug/target）→ `match_centers.py` 落盘。

```bash
# 全量合成（重合成零 ImageGen 成本，仅 CPU/PIL）
python tools/icon_pipeline/tier_system.py \
  --batch \
  --csv tools/icon_pipeline/asset_batch_template.csv \
  --center-root icon/_centers \
  --out .
```
- 配置驱动：调 `tier_config.json` 或重出某原型中心物 → 重跑即可，**不触发全量返工**。
- 品类清单：`asset_batch_template.csv`（354 行，含 `icon_path` 即 Godot 接入路径 `res://icon/<folder>/<id>.png`）。

## 4. 整包光影凝合（统一氛围、保留个性）

脚本：`tools/icon_pipeline/icon_cohesion.py`
- 方案：**左上 45° 统一顶光 + 微暖白平衡**（全局均值 `[100,97,82]`），轻量统一。
- 只作用不透明像素 RGB，**alpha 通道不变**（透明/中心内容不受影响）。
- 施加前自动备份至 `icon/_validation/cohesion_backup/`（**已 gitignore，本地还原用**），**可逆**。
- 调节参数：`LIGHT_STRENGTH` / `GRADE_STRENGTH`（在 `icon_cohesion.py` 顶部），改后重跑即可。
- 当前强度 **v1.0 已确认保留**，作为正式生效标准。

```bash
# 施加（先备份再原位覆盖）
python tools/icon_pipeline/icon_cohesion.py --apply --root icon --backup icon/_validation/cohesion_backup
```
