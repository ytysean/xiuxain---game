## 〇、设计铁则（绝对遵守）
1. **三维度**：好玩（策略深度 + 成长反馈 + 收集追求）、修真世界观（严格按修真小说设定）、真人操作习惯（手游友好）。
2. **核心玩法**：休闲玩法是宗门运转的有机组成，宗主亲自做 vs 安排弟子做双线。
3. **文案修真化**：禁现代词（任务/商店/金币/进货/解谜/钓鱼），用「行商/坊市/灵石/收货/破阵参悟/卜算/论道」等。
4. **性能前提**：手机端流畅，所有计算按日/按次，禁每帧重算。
5. **复用优先**：图录/秘境/占卜/灵兽/坊市/NPC/功勋堂(S28)/弟子情感(S30) 一律复用，禁新建重复系统。
6. **每玩法独立境界成长线**（类似钓道/商道境界）+ **四分层产出**（普通/稀有/史诗/传说）+ **周常活动** + **进阶消耗品 sink 闭环** + **收集追求（图录）**。
7. **数值占位**：所有概率/数值/阈值用 `[PLACEHOLDER]` 标注，待实机调优。

## 一、统一架构

### 1.1 宗主 vs 弟子分工
| 方式 | 消耗 | 收益 | 说明 |
|------|------|------|------|
| **宗主亲自做** | 消耗精力 | 高收益 / 高稀有概率 | 专属纪事，沉浸感强 |
| **安排弟子做** | 无消耗（弟子 AI 自动） | 稳定收益 / 低稀有概率 | 弟子获成长，产出入库房 |

### 1.2 解锁节奏（常驻常开 + 周期活动轮换）
| 玩法 | 解锁载体 | 修真包装 | 建议门槛 `[PLACEHOLDER]` |
|------|---------|---------|------|
| 灵钓 | 灵渊 | 开辟灵渊，引灵脉之水 | 开局/练气（最轻量，首个休闲） |
| 药圃 | 灵田 | 辟灵田，引地脉 | 筑基/首殿阁 |
| 饲灵 | 育兽栏 | 拓育兽栏 | 筑基 |
| 卜算 | 观星台 | 筑观星台，夜观天象 | 练气末/筑基 |
| 经商 | 商路 | 开商路，遣商队 | 筑基 |
| 探遗迹 | 秘境(探秘子型) | 秘境现世，入而参悟 | 金丹/秘境开放 |
| 论道 | 论道台 | 立论道台 | 金丹/宗门规模 |

> 非纯全开（高级内容过早暴露稀释主线）、非纯轮换（日常缺休闲出口），取「常驻常开 + 周期峰值」。

### 1.3 通胀控制红线（B10）
- 所有「产出型」休闲经 **每日/每周次数上限** + **稀有概率压低** 节流。
- 进阶消耗品是核心 sink：灵石→买耗品→休闲产材→回流库房→灵石再循环。
- 周常奖励**只走威望/图录边框/称号**，不直接暴灵石。
- 宝匣/秘匣类高价值物全进既有 sink（丹/器/功法残篇/突破材），不游离。

### 1.4 实现优先级
| 优先级 | 内容 | 说明 |
|--------|------|------|
| **P0** | 各玩法境界系统 | 核心成长线，每个玩法都要有 |
| **P1** | 和宗门管理联动 | 安排弟子自动做，产出入库房 |
| **P2** | 周常活动 | 排行竞争，激励玩家 |
| **P3** | 深度机制扩展 | 奇遇/变异/化形/秘藏等 |

### 1.5 复用系统总清单（禁新建）
收藏图录（多类）· 已通关秘境存档 · 占卜函数 · 灵兽系统 · S40 灵植年份 · 炼丹 S39 · 坊市 · NPC 体系 · 功勋堂 S28 · 弟子情感 S30 · Item 消耗品范式(S45) · 奇遇受控通道(`_尝试触发奇遇`) · 商队系统(caravan_system.gd)。

## 二、灵钓（模板玩法，深度最完整）

### 2.1 现有基础
- 触屏交互：**单指 hold/release 张力保持**（非 PC 式 QTE，禁精准限时点按）。
- 四分层产出：灵鱼 / 浊物 / 奇巧之物 / 灵渊秘匣。
- 六维修真数值：重量(钧) / 长度(尺) / 灵韵 / 五行 / 品阶 / 钓获难度。
- 图录详情：名称 + 品阶 + 五行 + 灵韵 + 叙事描述 + 用途提示 + 钓获履历（首钓/最重/总数）。
- 周常·灵钓大赛（挂周末，6 类规则轮换：计数/重量/品类/品阶/秘匣/总积分），奖励走威望+限定边框。

### 2.2 钓具三件套（杆+线+饵，非单一灵饵）
- **灵杆**：抛竿距离（深水域才出稀有）+ 张力带宽度（容错）+ 承力上限（最大重量，低杆配重渊饵会断线）。
- **灵线**：张力耐受（超安全值多久崩断）+ 泄力 drag（鱼挣扎张力升速放缓）+ 断线率。
- **灵饵**：引灵/聚宝/五行/稳绪/重渊 5 类（影响钓到什么）。

### 2.3 钓道境界（独立成长线，5 重）
- 初窥 → 小成 → 大成 → 圆满 → 通玄（意象对应练气→元婴+，但独立升级）。
- 获取：钓获次数 / 图录收录种类 / 大赛名次 / 首钓龙鲤（大额）。
- 软门控：主角境界低则深处灵渊未开，钓道境界有上限。

### 2.4 钓具四阶（接装备品阶 凡灵宝仙，每阶杆+线+饵配套 + 套装加成）
| 阶 | 钓道境界门槛 | 灵杆 | 灵线 | 灵饵 | 解锁水域 | 可钓 |
|----|----|----|----|----|----|----|
| 凡器 | 初窥 | 青竹竿 | 麻纶线 | 凡饵 | 浅滩灵池 | 凡鱼 |
| 灵器 | 小成 | 灵木竿 | 灵丝线 | 灵饵 | 灵渊中层 | 灵鱼 |
| 宝器 | 大成 | 玄铁竿 | 蛟筋线 | 宝饵 | 灵渊深处 | 灵兽鱼/龙鲤苗 |
| 仙器 | 圆满/通玄 | 太虚竿 | 虚空丝 | 仙饵 | 虚空灵渊 | 龙鲤/仙鳞 |

- **套装加成**：同阶杆+线+饵集齐 → 额外钓获质量/稀有率（鼓励集齐）。
- **进阶获取**：NPC 渔隐 + 坊市成品；灵材强化升阶（消耗库房灵材）。
- **存档**：`Game.钓具配置 = {阶, 杆品阶, 线品阶, 饵}` + 钓道境界等级，经 `to_dict` 持久化。

### 2.5 鱼类修真化扩展（四分层细化）
| 品阶 | 鱼类 | 描述 | 用途 |
|------|------|------|------|
| 凡品 | 灵鲫、灵鲤、锦鳞 | 普通灵鱼，有灵气 | 食用/售卖 |
| 灵品 | 玄甲龟、银鳞鱼、灵鳗 | 有灵性，可入药 | 炼丹材料 |
| 宝品 | 龙鲤苗、蛟蛇、双头鱼 | 稀有，有灵性 | 炼器材料/坐骑 |
| 王品 | 龙鲤、玄龟、人鱼 | 传说之鱼 | 突破材料/坐骑 |
| 仙品 | 仙鳞、太古龙鱼、鲲鹏苗 | 传说中的传说 | 上古遗物/仙缘 |

### 2.6 钓鱼奇遇系统（对标 WoW 惊喜）
- 会说话的鱼 → 触发奇遇，获功法/机缘。
- 上古遗物 → 功法残篇/法宝碎片。
- 溺水散修 → 救起获报酬/结交道友。
- 水底秘境入口 → 解锁新钓场/秘境。
- 鱼跃龙门 → 龙鲤苗进化，获大量修为。

### 2.7 鱼的用途 + 灵池系统（联饲灵育兽）
- 食用（回精力+修为）/ 炼丹（鱼鳞鱼油）/ 炼器（鱼骨鱼皮）/ 宴请（好感声望）/ 售卖（坊市黑市）/ 饲养（稀有鱼入灵池）。
- **灵池**：钓到的稀有鱼可放入饲养，灵池等级影响成长产出，产鱼籽孵化小鱼，与育兽栏共享体系。

### 2.8 进阶 sink
灵饵（5 类）+ 钓具强化（灵材消耗）→ 双 sink 闭环。

## 三、探遗迹（破阵参悟）

### 3.1 现有基础
- 触屏：引灵连线 / 点亮残碑 / 拖拽卦象入位（无时间窗硬判定，仅「灵机紊乱需重参」软约束）。
- 四分层：天材地宝 / 残破遗物 / 上古奇物 / 遗迹秘藏。
- 复用 `已通关秘境` 存档（新增「探秘型」子类型）。

### 3.2 阵道境界（5 重成长线）
| 境界 | 所需经验 | 破阵加成 | 解锁 | 描述 |
|------|---------|---------|------|------|
| 阵道学徒 | 0 | +0% | 基础遗迹 | 初窥阵道门径 |
| 阵师 | 300 | +10% | 中级遗迹 | 破阵得心应手 |
| 大阵师 | 1000 | +25% | 高级/上古遗迹 | 可破上古大阵 |
| 阵道宗师 | 3000 | +40% | 传说遗迹/秘境 | 天下大阵皆可破 |
| 阵道仙师 | 8000 | +60% | 仙迹/上古仙阵 | 可布仙阵 |

经验：破阵成功/发现秘藏/首破特殊阵法/周常探秘周名次。

### 3.3 遗迹类型 / 破阵加强 / 秘藏
- 类型：上古洞府 / 古战场 / 秘境入口 / 仙人遗迹 / 魔神祭坛（高风险高回报）。
- 阵法：五行阵/八卦阵/九曲阵/诛仙剑阵/万仙阵；难度 1–10 星；失败零惩罚。
- 秘藏：每遗迹 1–3 个，需特殊条件开，低概率出「上古传承」（完整功法/法宝）。

### 3.4 周常·遗迹探秘周 + 进阶 sink
规则池（周序 mod N）：集齐残卷 N / 最古遗存排行 / 品类齐全度 / 秘藏开启数 / 阵法难度积分。奖励威望+边框。
进阶消耗品：**破阵符**（降难度）/ **引灵香**（提秘藏率）；获取：守遗迹散修 NPC + 坊市。

### 3.5 和宗门管理联动
宗主亲探（耗精力，收益高）或弟子组队（AI 自动，稳定）；产出入库房；高风险遗迹概率失踪/受伤；功法残篇入藏经阁。

## 四、饲灵育兽（灵兽养成）

### 4.1 现有基础
- 触屏：拖拽喂食 / 点按抚摸 / 长按驯养（禁连点）。
- 四分层：灵兽产出 / 幼兽变异 / 兽魂 / 灵兽奇遇蛋。
- 复用既有灵兽系统 + 喂养 + `收藏图录`(灵兽志)。

### 4.2 御兽境界（5 重）
| 境界 | 所需经验 | 驯养加成 | 解锁 | 描述 |
|------|---------|---------|------|------|
| 御兽学徒 | 0 | +0% | 基础灵兽 | 初窥门径 |
| 兽师 | 300 | +10% | 中级灵兽/灵兽斗 | 驯养得心应手 |
| 大兽师 | 1000 | +25% | 高级/变异种 | 可驯上古异兽 |
| 御兽宗师 | 3000 | +40% | 传说灵兽/化形 | 万兽臣服 |
| 万兽仙尊 | 8000 | +60% | 仙兽/神兽苗 | 可驯神兽 |

### 4.3 灵兽类型 / 成长 / 技能 / 灵兽斗
- 类型：战斗型/坐骑型/生产型/辅助型/异兽型（龙凤麒麟鲲鹏）。
- 成长：等级 1–100、资质（凡灵宝王仙）、亲密度 0–100、变异、化形。
- 技能：每兽 1–3 个（攻/防/辅/产），耗兽魂升级，稀有血脉觉醒。
- **灵兽斗**（周常）：擂台零死亡，战力公平匹配，胜获威望/兽魂/限定兽栏皮肤。

### 4.4 进阶 sink
**嗜好食**（按兽种提亲密度/成长）/ **驯养鞭**（提服从/战力上限）；获取：兽市 NPC + 坊市。

## 五、卜算星盘（天机卜算）

### 5.2 天机境界（5 重）

### 5.3 卜算类型 / 卦象 / 运势
- 类型：日常吉凶 / 事业 / 姻缘 / 机缘 / 改命 / 天机秘示（消耗递增）。
- 卦象：八卦→六十四卦→变卦（低概率反转）→卦辞沉浸。

### 5.4 周常·观星大会 + 进阶 sink
特殊星象（紫微高照/扫把星/流星），积分排行，奖威望/星盘玉/观星台装饰。
进阶：**星盘玉**（提应验/稀有）/ **卦资**（每次消耗）；获取：观星台 NPC + 坊市。

### 5.5 和宗门管理联动
天机堂弟子每日自动卜算宗门运势；吉兆增修炼/突破/奇遇率，凶兆增灾难/兽潮/敌袭概率；天机堂等级影响准确率。

### 7.3 棋类 / 对手 / 悟道
- 棋类：围棋/象棋/五行棋/八卦棋/珍珑棋局（难度递增）。
- 对手：宗门弟子→长老→散修棋客→棋道大家→上古棋魂→仙人对弈。
- 悟道：赢棋获「悟性」临时增修炼速度（1–7 日，可叠加有上限）；低概率「棋道感悟」永久增悟性。

### 7.4 周常·论道大会 + 进阶 sink
淘汰/循环赛，棋力排行，奖威望/棋谱/论道台装饰，稀有奖上古棋谱/棋道感悟。
进阶：**棋谱**（提胜率/解锁高难）/ **悟道茶**（提悟性幅度）；获取：棋待诏 NPC + 坊市。

### 7.5 和宗门管理联动
弟子论道增悟性/修炼速度；论道台等级影响对手强度；棋道境界高者修炼永久加成；增弟子间好感（和情感联动）。
