## 0. 校验总原则（令牌铁律，违反即 FAIL）

1. **单一数据源**：所有色值/数值取自《UI 设计令牌 v1.0》，禁止在 `.tres`/脚本/场景另立硬编码 hex。
2. **禁止全局主题塞业务样式**：品级框、特定弹窗花纹等业务差异，一律走「组件内主题覆盖」，不进 `main_theme.tres` / `project.godot` 的 theme_override。
3. **禁止动态色硬编码**：任何 `Color(#...)` / 魔法数字散落场景或脚本 → 一律由 `UIThemeConfig（待生成）` 或 `ui_theme.gd` 常量提供，二者皆源自令牌。
4. **文件分区**：美术改 `ui_theme.gd` + `ui/assets/`；工程改 `main_theme.tres` + `components/*.tscn` + `UIThemeConfig.gd`。互不踩。

## 2. 逐组件视觉验收点

### 2.1 BasePanel（基础面板容器）
- [ ] **底色**：`COLOR_PANEL_BG #243439`（panel）；内嵌内容区可用 `COLOR_BG_CONTENT #2C3D43`。
- [ ] **描边**：`COLOR_BORDER_GOLD #C9A865`，`border-w-1`(1px)；选中/强调态升至 `border-w-2`(2px)。
- [ ] **圆角**：`radius-md` 8；若作弹窗外框用 `radius-xl` 16。
- [ ] **内边距**：`space-4`(16)，与 8px 栅格对齐；禁止奇数/非栅格内距。
- [ ] **字体**：标题 `apply_title_font`（title1 `#E6C778`，本次已对齐）；正文 `apply_body_font`（body `#E0D5BE`）。
- [ ] **禁止**：在 panel 内硬编码业务色（品级/境界）；禁止暗纹贴图覆盖 token 底色导致对比度丢失。

### 2.2 ListItem（列表项 / 行）
- [ ] **行底色**：默认透明或 panel；hover/选中行用 `bg.content #2C3D43` 或 `border-w-2` 强调描边。
- [ ] **左侧图标**：`UITheme.load_icon_sized(label, SIZE_SM=48)`；label 须注册于 `ICON_BY_LABEL`。
- [ ] **文字**：主文本 body `#E0D5BE`（`FONT_BODY` 或 `FONT_DENSE` 视密度）；次要文本 body-dim `#C8B896`。
- [ ] **右侧指示**：展开用「箭头」图标（`ICON_BY_LABEL["箭头"]`），右对齐，size 48 或 32。
- [ ] **行内距**：`space-3`(12)；行间距由列表容器控制，**禁止硬编码 y 坐标**。
- [ ] **分割**：行间用 `UITheme.make_divider_control()`（1px 暗金云纹）。

### 2.3 ItemSlot（物品/装备槽位 · 含品级色）
- [ ] **槽底色**：panel `#243439`；内描边 `border-w-1` `#C9A865`。
- [ ] **品级描边/角标**：取 `COLOR_TIER_*` 或 `UIThemeConfig.set_quality_color`（凡 `#D6D6D6` / 良 `#4CAF7A` / **灵 `#3FA9C9`★** / 宝 `#5B8BD9` / 王 `#D9A04C` / 圣 `#B04CD9` / 仙 `#F0E6B0` / 道 `#E8F0FF`）。灵品已与良品区分（青蓝）。
- [ ] **数值**：accent `#FFD77A` 加粗；若负值/异常 → danger `#E07878`。
- [ ] **圆角**：槽 `radius-md` 8；图标 `SIZE_MD`(64) 或 `SIZE_SM`(48)。
- [ ] **禁止**：品级色硬编码 hex；一律走 `COLOR_TIER_*` / 未来 `UIThemeConfig`。

### 2.4 ConfirmDialog（确认弹窗 · 含新增图标）
- [ ] **外框**：`radius-xl` 16；底色 panel `#243439`；1px 金边。
- [ ] **标题**：title1 `#E6C778`，字号 `h2`(26) 或 `display`(40)（核心弹窗主视觉）。
- [ ] **正文**：body `#E0D5BE`，`FONT_BODY`(24)。
- [ ] **按钮区**：确认按钮用「确认」图标（✓）+ 文本；取消按钮用「取消」图标（←带尾栓）+ 文本。
- [ ] **按钮样式**：主按钮 `apply_primary_button_style`（pressed `#141B1C` / 禁用 `#2E3232`），次按钮 `apply_secondary_button_style`；圆角 `radius-sm` 6；主高 64 / 次高 48。
- [ ] **禁止**：在 dialog 主题塞业务样式；图标须注册于 `ICON_BY_LABEL`（已注册 关闭/确认/取消/箭头）。

### 2.5 Toast（轻提示）
- [ ] **容器**：`radius-lg` 12（或 `radius-md` 8）；底色用 success/danger 低透底（~12–18% alpha 派生，令牌只强制基色 `#7ED39A`/`#E07878`）。
- [ ] **文本**：body `#E0D5BE`；成功态可着 success `#7ED39A`，警示态着 danger `#E07878`。
- [ ] **位置**：屏幕底部上方安全区，用视口比例定位（ToastManager 已用 `vp.size.y*0.28` 居中，符合自适应），**禁止硬编码像素 y**。
- [ ] **时长**：由逻辑控制（非美术项，仅标注）。

### 2.6 实然源码核对（基于实际组件 .gd · P0 实测）

- **BasePanel**：正确调用 `UITheme.apply_title_font`（标题已取 title1 `#E6C778`，本次对齐生效）；关闭按钮用文本「关闭」（新增「关闭」图标已注册，可作图标化选项，非必须）。面板边框/圆角/底色由 `main_theme.tres` 提供（见风险 7）。`open_panel()` 的 `create_tween()` 属动画逻辑，不在美术范围。
- **ListItem**：正确调用 `apply_body_font` / `apply_aux_font` / `apply_value_font`（body `#E0D5BE` / aux `#8A7E68` / accent `#FFD77A` 已对齐令牌）；图标走 `UITheme.load_icon_sized(data["icon"], SIZE_SM=48)`，且对 `null` 有隐藏回退（符合图标缺失回退要求）。右值用 accent 金，属强调数字用法，可接受。
- **ItemSlot**：品级染色走 `UIThemeConfig.set_quality_color(self, quality)`（数据驱动，符合令牌 §4）；但 **`UIThemeConfig.gd` 尚未生成 → 运行时阻塞**（风险 6）。数量标签 `count_label` 未在代码中设字体/色，依赖 `main_theme.tres`/主题默认（建议显式 `apply_value_font` 取 accent `#FFD77A`）。
- **ConfirmDialog**：继承 BasePanel；确认/取消按钮用文本「确认」「取消」（新增图标已注册，可图标化）。`content_label` 未在代码中设字体/色（建议 `apply_body_font` 取 body `#E0D5BE`）；按钮主/次样式由 `main_theme.tres` 提供（风险 7）。

## 3. 已知风险

1. **默认字体中文字形**：字体文件 `MaShanZheng-Regular.ttf` / `NotoSerifSC-Regular.otf` 当前未落盘，`apply_*_font` 回退 Godot 默认字体。中文可显示但非毛笔/宋体观感，且默认字体中文覆盖可能缺字 → 须先跑子集化脚本恢复字体（令牌 §2.1）。验收若见「豆腐块」，优先查字体回退。
2. **图标缺失回退**：`load_icon(label)` 在 label 不在 `ICON_BY_LABEL` 时返 `null`；组件须保留文本/占位，不得因 `null` 崩溃或留空白。新增 4 图标已注册，但组件调用前须确保 label 拼写一致（中文精确匹配）。ListItem 已正确实现该回退。
3. **SVG 描边色微差**：图标 SVG 描边 = `#C8A86A`，代码金边 = `#C9A865`（令牌 §6 采 spec）。差 1/255，肉眼难辨；若要求严格一致，后续统一图标描边到 `#C9A865`（本次按任务保持 `#C8A86A` 以匹配既有图标）。
4. **字号迁移布局风险**：令牌字号整体上调（body 16→24 等），但 `ui_theme.gd` 的 `FONT_TITLE/VALUE/BODY/AUX` 暂未放大（防 5 页文字溢出）。组件若直接套用令牌 `h1/h2/display` 需回归布局，避免裁切。
5. **灵品色**：已按主理人裁定取 `#3FA9C9`（青蓝），与良品 `#4CAF7A` 区分；若后续改回 spec 同色，需以图标/描边区分（令牌 §7-B）。
6. **`UIThemeConfig.gd` 缺失（运行时阻塞）**：`ItemSlot` 调用 `UIThemeConfig.set_quality_color` 做品级染色，但 `UIThemeConfig.gd` 截至本产出**未生成** → F5 运行时 Instantiate ItemSlot 即报 `UIThemeConfig` 未定义。属 design-strategist 待办（令牌 §4/§8）；美术已在 `ui_theme.gd` 预置 `COLOR_TIER_*` 视觉基线常量备用，但最终以 `UIThemeConfig` 数据驱动为准（灵品须映射 `#3FA9C9`）。
7. **`main_theme.tres` 缺失（运行时阻塞）**：BasePanel / ItemSlot / ConfirmDialog 的面板边框/圆角/底色、按钮主/次态均委托 `main_theme.tres`（令牌 §4 明确由 engineering-lead 落地）。该文件未生成 → 面板仅有 Godot 默认样式，未对齐令牌（border `#C9A865` / radius 8 / bg `#243439` 等）。属 engineering-lead 待办。
8. **未显式设字体色的标签**：`ItemSlot.count_label`、`ConfirmDialog.content_label` 在代码中未调用 `apply_*_font`，依赖 `.tres`/主题默认。验收时确认其取得 token 正确角色（数量 = accent `#FFD77A`；正文 = body `#E0D5BE`），否则补全 `apply_value_font` / `apply_body_font`。

## 4. 多分辨率适配提醒

- **基准** 480×854；必须在 **720×1280** 与 **1080×1920** 验证（至少截图回归）。
- **禁止硬编码坐标 / 固定像素位置**；一律用锚点（`anchor`）、`Container`（BoxLayout/GridContainer）、`size_flags`、`ThemeOverride` 比例。
- 字号/间距用令牌 px（`space`/`radius`/`font.size`），由引擎缩放；图标用 `load_icon_sized` 按目标尺寸光栅化，不用固定 SVG 像素。
- **全面屏安全区**：底部 Tab 高 `TAB_H`=64，顶栏 `TOPBAR_H`=48，避开刘海/手势条。
- **高 DPI**：图标为 SVG 矢量，天然清晰；位图资产需提供 2x/3x 或 mipmaps。
- **ToastManager 已达标**：`show_tip` 用 `vp.size` 比例定位，随分辨率自适应，无需硬编码。
