# 《太玄宗门录》奇遇系统落地规范
> 版本：v1.0 ｜ 对齐总览v2.2 ｜ 用途：奇遇配置、程序实现依据
> 核心规则：数据驱动、性格四维判定、紫品以上可玩家干预

## 一、基础规则
### 1. 稀有度与权重
- 四档稀有度：普通(绿)、稀有(蓝)、珍稀(紫)、传说(金)
- 总权重10000，具体数值见配置表
- 稀有度规则：低于弟子2个大境界的奇遇自动重roll，保障内容利用率

### 2. 分类与数量
- 8大类各25则，共200则：山林野趣、古洞遗迹、坊市井陌、宗门内事、行路遇人、天象征兆、秘境险地、灵植异兽
- 每则奇遇包含多个分支，由性格四维阈值判定走向

### 3. 抽取流程
触发判定 → 场景匹配池 → 稀有度 roll 点 → 子池等概率抽条目 → 性格四维判定分支 → 奖励结算 → 写入弟子履历

## 二、性格四维判定规则
1. 底层算法：激进度、利他度、聪慧度、贪欲度，每项0-100分
2. 12种标准性格对应固定四维分值，弟子生成时赋值
3. 奇遇正文自由标签统一转换为四维阈值判定
4. 示例：「高风险硬闯」分支判定条件：激进度≥80 且 贪欲度≥70

## 三、玩家干预机制
### 1. 触发规则
- 普通/稀有奇遇全自动，不干扰挂机体验
- 珍稀(紫)及以上奇遇触发掌门干预弹窗
- 每日干预上限：凡阶3次，每升1品+2次

### 2. 三档干预选项
| 选项 | 消耗 | 效果 | 适用场景 |
|------|------|------|----------|
| 放任自流 | 无 | 保持原性格自动判定 | 低价值奇遇、弟子战力充足 |
| 暗中相助 | 宗门贡献/灵石 | 成功概率+15%，奖励品质+1档 | 稳妥保底 |
| 亲自出手 | 高阶道具/声望 | 强制最优分支，奖励拉满，额外道心值 | 传说奇遇、核心弟子 |

> 优先级：玩家选择 > 性格四维判定

## 四、奖励规则
1. 常规奖励：灵石、贡献、灵材、装备、功法、道心值
2. 奇遇版道具：所有奇遇掉落的装备/丹药/灵材均为奇遇版，数值增幅20%-50%，突破率+5%-10%
3. 传说奇遇概率产出：特殊弟子、稀有灵兽、上古传承
4. 奖励结算后自动写入弟子30年履历，圣阶以上计入大道传记

# 从核心总览归位：奇遇系统核心规则
系统核心标准奇遇共 200 则（8 大类各 25 则）；另有 10 + 条通用历练小事件用于填充日常履历，不计入奇遇统计。
触发：弟子外派历练 / 采集 / 巡逻随机触发，玩家事后收禀报；分支由性格自动判定，无需操作。
稀有度：普通 (绿)/ 稀有 (蓝)/ 珍稀 (紫)/ 传说 (金)；权重总 10000（具体各档权重数值见配置表 docx 表格，待录入）。低于弟子境界的稀有度自动重 roll。
8 大类各 25 则：山林野趣 / 古洞遗迹 / 坊市井陌 / 宗门内事 / 行路遇人 / 天象征兆 / 秘境险地 / 灵植异兽。
性格判定（C2 已拍板）：采用四维数值模型为底层算法——
12 标准性格 → 固定四维分值映射表（生成弟子时赋值，详见配置表 docx）。
四维：激进度 / 利他度 / 聪慧度 / 贪欲度，每个 0-100 分；分支标阈值（如 "高风险硬闯：激进度 80+，贪欲度 70+"）。
200 则正文自由标签（莽撞 / 聪慧 / 务实 / 细心 / 刚直 / 热心 / 开明 / 温和 / 长远…）视为对四维倾向的自然语言描述，实现时统一转四维阈值判定。
抽取流程：触发判定 → 场景匹配池 → 稀有度 roll → 子池等概率抽条目 → 性格判定分支 → 奖励结算写履历。
完整 200 则文案见 奇遇系统核心规则.docx；触发条件与性格映射见 奇遇系统配置表及性格判定.docx。

奇遇收录所得带艺修士的初始境界规则详见 6.1.6（三级招募渠道梯度与初始境界差异）。

数量澄清（包含关系，非重复）：200 则为唯一标准核心池（带稀有度 / 性格分支 / 奖励结算的完整事件）；lore.gd 的 "210+ 模板" = 200 则核心奇遇的精简拼接模板 + 10+ 条通用历练小事件（无分支、低奖励，仅用于填充弟子历练履历日常，不属于奇遇系统范畴）。代码侧无需开发两套内容。
- 跨门派交际专属子事件池（20 [PLACEHOLDER] 条）追加规则与四维判定复用见 6.18.3 / 6.18.11。
代码侧落地提示：不要在 lore.gd 写死 200 则全文，单独建立 adventures.json 存储所有奇遇的 ID、分类、稀有度、四维阈值、分支文案、奖励；代码仅做读取和判定逻辑，后续调整文案不用改代码。
## 10.1 玩家干预机制
基础原则：普通（绿）/ 稀有（蓝）奇遇保持全自动判定，不破坏挂机体验；珍稀（紫）及以上奇遇触发玩家干预，兼顾沉浸感与掌控感。
触发时机：弟子历练触发高稀有度奇遇后，宗门推送禀报弹窗，玩家可选择干预或放任。
每日干预上限：凡品 3 次 / 日，每提升 1 个宗门品级 + 2 次，避免过度操作破坏放置节奏。
## 10.1.1 三档干预选项
针对每则珍稀以上奇遇，设置 3 个掌门干预选项，对应不同风险收益梯度。

| 选项 | 消耗 | 效果 | 适用场景 |
| --- | --- | --- | --- |
| 放任自流 | 无 | 保持原性格四维自动判定，结果完全随机 | 低价值奇遇、弟子战力充足 |
| 暗中相助 | 消耗宗门贡献 / 灵石 | 奇遇成功概率 + 15%，奖励品质强制提升 1 档 | 稳妥型玩法，保底收益 |
| 亲自出手 | 消耗高阶道具 / 声望 | 强制触发最优分支，奖励拉满，额外附赠道心值 | 传说奇遇、核心弟子关键机缘 |

优先级规则：玩家干预选择 > 弟子性格四维判定，玩家选择后直接执行对应分支，不再走性格判定逻辑。

## 10.2 稀有度规则优化
修正原「低于弟子境界的稀有度自动重 roll」规则：低于 2 个大境界及以下的奇遇才重 roll。例如金丹弟子不会触发凡品奇遇，但仍可触发灵品普通奇遇，保障低稀有度内容的利用率。
奇遇奖励的装备 / 丹药 / 灵材，默认属于「奇遇版」，数值增幅 20%-50%，突破成功率 + 5%-10%，对齐第 5 章双版本机制。
