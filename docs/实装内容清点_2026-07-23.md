### 产出路径（每月 `_资源建筑产出()`，`game_state.gd:1092`）
通用灵石公式：
```
产 = int( n × base × (1+经营加成) × 气运乘 × (1+产出buff+彩蛋产出加成()) × 等级乘区 )
灵石 += 产
```
- `n` = 堂口成员数；`base`（经营基数）= `{lingtian:5, kuangmai:4, dantang:3, qitang:3, cangjing:2, zhifa:2, gongxun:2, tanwei:2, yuying:1, yushou:1, zhenfa:1, xichi:1}`（`:1098`）
- `经营加成` = 成员经营型命格数值/100 累加（`:1108-1113`）
- `气运乘` = `1 + 气运产出加成`（仅气运 buff 有效期内，`:1115`）
- `产出buff` = 负责人全局 buff 的「产出」维（灵田 +1%/座）
- `等级乘区` = `1 + 0.02 × max(0, 门派等级-1)`（`:1117`，10 级 +18%）
- `彩蛋产出加成()` 封顶 `彩蛋单上限=0.05`（`:460-464`）
- 专属产出：灵田→灵草 + 灵气 `int(ceil(产×0.5))`（减半）；矿脉→矿石；丹堂/器堂仅记本月产出供被动翻倍，不直接产材料（`:1122-1131`）
- 其他：全员底薪 `灵石 += 弟子数×2`（`:1132`）；建筑被动概率事件（灵田 8% 翻倍/矿脉 7%/丹堂 15%+掉丹/器堂 12%+掉宝/探微阁 10% 额外 30–80 灵石，`_建筑被动结算` `:1175-1231`）；周期评定奖励（`:613`）；奇遇奖励；气运 buff（天品突破/招收）

### 消耗路径与量级
- **灵石**：
  - 坊市购买：`灵石 -= 坊市实价`（`:265`，实价 = `原价 × 声望折扣率`）
  - 灵兽兑换队列：`灵石 -= 消耗`（`:1632`，已修复，`if 灵石 < 消耗: continue` 之后正确扣费，不再免费产蛋）
- 灵草 / 矿石 / 灵气 / 贡献点：全工程无任何 `X -=` 扣减语句 → **悬空资源（sink 未实装）**

### 经济闭环判定
- 灵石：有产（建筑/被动/底薪/奖励/奇遇）+ 有耗（坊市；兑换队列按 `消耗` 扣灵石）→ **闭环成立**
- 灵草/矿石/灵气/贡献点：有产无耗 → **悬空，无闭环**
- `config/output_daily.csv` / `sink_cost.csv` / `resource_base.csv` 仅 schema 校验存在，运行时未加载（`csv_validator.gd:545` `resource_loop_check` 标注暂缓）→ 无自动闭环校验
