# 《太玄宗门录》道具与装备系统设计

> 本文件从 `design/01-总纲/太玄宗门录_核心设定总览.md` §5、§8 归位。

道具贡献度 × 奇遇稀有度 终极平衡方案（适配宗门全自动循环）
核心平衡总逻辑（唯一铁律）
掉落概率决定稀有度，品阶基数决定基础贡献，奇遇溢价决定上限价值。三者分层锁死，做到：低阶奇遇不泛滥、高阶奇遇不崩盘、贡献币不通胀、奇遇永远有稀缺优越感、普通掉落永远有基础循环价值。
杜绝两个极端：① 奇遇道具烂大街，和普通道具无差别；② 奇遇道具过强，碾压所有兑换体系，导致普通历练无意义。
一、分层掉落概率（稀有度锁死，体感分层）
适配你现有历练/任务/秘境体系，概率严格梯度递增，高阶奇遇极度稀缺，每一档稀有度对应独立价值定位。
1. 常规掉落概率（稳定产能、支撑基础贡献循环）
凡/灵/宝阶：95%常驻掉落，日常历练保底产出，保证弟子稳定刷贡献、稳定兑换养成，兜底底层循环。
王阶：4%概率常规掉落，高阶道具常规产出极低，避免高阶资源泛滥。
圣/仙/渡劫阶：0%常规掉落，仅奇遇可出，彻底锁死高阶通胀。
2. 奇遇掉落概率（稀缺体感核心）
通用触发基底：普通历练3%、高阶秘境8%、悬赏任务5%（保留你原设定）
奇遇内部品阶掉落权重（关键平衡）：
王阶奇遇道具：70%（奇遇主流产出，性价比最高、流通最多）
圣阶奇遇道具：25%（稀有高阶资源）
仙阶奇遇道具：4.5%（极品稀缺）
渡劫道祖阶奇遇道具：0.5%（天花板绝版资源，极度稀有）
平衡效果：大部分奇遇给「优质提升」，小部分给「稀有跃迁」，极少数给「顶级绝版」，既有高频正反馈，又有顶级稀缺保值。
二、贡献度平衡公式（无通胀、无贬值、精准匹配稀有度）
统一公式：最终贡献 = 品阶基础贡献 + 奇遇固定溢价（不按倍率乱乘）
核心设计：低阶奇遇无溢价，高阶奇遇溢价锁死，彻底杜绝低级奇遇道具刷贡献通胀，同时保证高阶奇遇价值碾压。
全品阶精准平衡数值（落地即用）
凡阶｜常规1贡献｜奇遇0溢价（无高阶奇遇，仅常规掉落）
灵阶｜常规3贡献｜奇遇0溢价（低阶道具，奇遇仅数值变强，不刷贡献）
宝阶｜常规10贡献｜奇遇0溢价（中阶耗材，只服务养成，不做贡献套利）
王阶｜常规30贡献｜奇遇固定+15溢价（中高阶分水岭，开始有稀缺价值）
圣阶｜常规100贡献｜奇遇固定+50溢价（高阶稀有，贡献大幅拉开差距）
仙阶｜常规300贡献｜奇遇固定+150溢价（极品稀缺，高价值资源）
渡劫阶｜常规1000贡献｜奇遇固定+500溢价（绝版天花板，价值封顶）
为什么不用倍率溢价？
如果用「×1.5、×2倍率」，低阶奇遇会批量产出超高贡献，弟子批量套利、贡献泛滥、货币崩盘。固定溢价可以精准控制每一档的价值增量，稀有度越高、溢价含金量越高，完美匹配掉落概率。
三、数值强度与稀有度匹配（杜绝战力崩坏）
严格遵循：掉落越稀有，数值破格越强；掉落越泛滥，数值仅微提升
1. 低中阶（凡/灵/宝）奇遇：只强不贵
数值增幅20%-30%，无贡献溢价。作用是：弟子历练体感更好、打怪更顺、突破更稳，但不能用来刷贡献，只提升养成体验，不破坏经济。
2. 高阶（王/圣）奇遇：强且保值
数值增幅30%-40%，附带小幅专属buff，叠加固定贡献溢价。作用是：核心战力跃迁资源，同时是弟子主要高价值贡献来源，稀缺与收益匹配。
3. 顶阶（仙/渡劫）奇遇：绝版破格
数值增幅40%-50%，附带规则级特效、突破概率额外+10%，高额溢价。极低掉率、顶级战力、巨额贡献三位一体，作为宗门顶级机缘，长期保值、永不贬值。
四、兑换端平衡（卡死出口，闭环稳压）
光控产出没用，必须卡死消耗出口，实现绝对平衡。
1. 境界锁级兑换
弟子只能兑换自身境界及以下道具，高阶奇遇再值钱，低阶弟子也无法超前兑换，杜绝小号刷顶级资源套利。
2. 高阶道具周/日上限
资质、神魂、突破类高阶道具设置每周兑换上限，哪怕弟子堆积大量高阶奇遇贡献，也无法短期堆爆战力，稳住养成节奏。
3. 奇遇专属道具「不可兑换、仅上交」
仙阶、渡劫阶奇遇专属秘宝，宝库无兑换渠道，唯一作用：高额上交贡献+极少专属机缘触发。保证顶级奇遇的独占稀缺性，不会人人都有。
五、最终平衡效果（完全适配你的全自动宗门体系）
1. 普通历练有价值：低阶稳定产出，保证萌新、挂机弟子有基础贡献、有稳定养成，不会无事可做。
2. 奇遇有绝对优越感：奇遇不止数值强，高阶还有高额专属溢价，运气收益实打实，玩家/AI弟子都会主动追求奇遇。
3. 经济零通胀：低阶奇遇不刷贡献，高阶奇遇概率极低，贡献产出可控，不会贬值崩盘。
4. 稀有度分层清晰：泛滥道具、优质道具、稀有道具、绝版道具，四层价值完全区分，体验层层递进。
5. AI适配完美：弟子自动上交、自动兑换的逻辑无需修改，仅通过数值与概率稳压，全自动循环丝滑不崩坏。

## 8. 物品装备系统
5 大类（装备 / 法宝 / 丹药 / 灵材 / 符箓）× 7 大品阶（凡 / 灵 / 宝 / 王 / 圣 / 真 / 道）× 4 细分品级（下 / 中 / 上 / 极品）；暗黑式词缀（前缀 / 后缀）。8 穿戴部位：武器、法袍、头盔、护腕、腰带、靴子、饰品、本命法宝。仙 / 道品传奇极品有专属外观与异色流光。丹药额外标注丹毒数值；装备展示词条与被动。详细图鉴见全装备图鉴.txt、全道具图鉴.txt、道具规则.txt。

> 注（v2.56 品阶统一）：物品品阶全面对齐「7 大品阶 + 4 细分品级」二级标准（详见 §3 / §11.23），废弃旧「凡铁 / 灵纹 / 宝铸 / 珍奇 / 灵宝 / 神器」独立炼器 6 阶命名；丹药 / 符箓 / 装备 / 法宝 / 灵兽 / 傀儡共享此轴。

### 8.1 丹药系统

#### 8.1.1 系统定位
丹药是弟子境界突破、属性提升、状态恢复的核心消耗品，覆盖前期过渡到后期极限养成全周期，是宗门产业体系的核心产出之一。低阶丹药量产供应日常消耗，高阶丹药稀有且具备突破保底功能，与丹堂等级、丹师资质、丹道傀儡深度绑定。

#### 8.1.2 品阶体系
严格遵循「7 大品阶 + 4 细分品级」标准，对应可使用的弟子境界门槛：
- 凡品：练气期使用，基础培元、回血回蓝
- 灵品：筑基期使用，小幅提升属性、辅助突破
- 宝品：金丹期使用，大幅提升属性、突破保底
- 王品：元婴期使用，属性质变、洗髓伐脉
- 圣 / 真 / 道品：化神及以上使用，稀有战略级道具

#### 8.1.3 丹药分类
| 丹药大类 | 核心作用 | 代表丹药 |
| --- | --- | --- |
| 培元类 | 提升修炼效率、补充灵气 | 聚气丹、筑基丹、金丹培元丹 |
| 突破类 | 提升境界突破成功率 | 破障丹、固金丹、婴变丹 |
| 恢复类 | 战斗后恢复气血、治疗伤势 | 回血丹、清毒丹、生肌丹 |
| 属性类 | 永久提升弟子基础属性 | 力丹、体丹、神识丹 |
| 特殊类 | 特殊功能（延寿、洗灵根） | 延寿丹、洗髓丹、破障天丹 |

#### 8.1.4 炼制规则
- 丹堂等级决定可炼制的最高品阶，丹师境界与资质决定炼制成功率与出丹数量
- 炼制消耗对应灵药、灵石，高阶丹药额外消耗稀有主药与丹火
- 炼制成功率 = 基础成功率 + 丹师资质加成 + 丹道傀儡加成 + 聚灵阵加成，强制约束在 5%-95% 区间
- 炼制失败返还 30% 基础材料，高阶丹药可加入保底材料提升成功率

### 8.2 符箓系统

#### 8.2.1 系统定位
符箓是一次性战斗消耗品，提供即时技能、增益、控制效果，是战斗策略的重要补充。低阶符箓量产用于日常历练，高阶符箓可在 BOSS 战、宗门战中逆转战局，由符堂制作，对应弟子符道资质决定出品效率。

#### 8.2.2 品阶体系
与全局品阶完全对齐，品阶越高效果越强、使用门槛越高：
- 凡 / 灵品：低阶一次性符箓，日常历练通用
- 宝 / 王品：中高阶符箓，对应秘境、宗门战场景
- 圣品及以上：战略级符箓，全宗级增益或全屏伤害

#### 8.2.3 符箓分类
| 符箓大类 | 核心作用 | 代表符箓 |
| --- | --- | --- |
| 攻击类 | 即时造成单体 / 群体伤害 | 火球符、雷符、天火符 |
| 防御类 | 提供护盾、减伤效果 | 护盾符、金刚符、玄水符 |
| 辅助类 | 提供增益 buff、解除负面 | 加速符、清心符、聚灵符 |
| 控制类 | 附加控制、减益效果 | 冰冻符、减速符、卸力符 |
| 特殊类 | 特殊场景功能 | 传送符、隐身符、避劫符 |

#### 8.2.4 制作与使用规则
- 符堂解锁制作，消耗符纸、灵墨、妖兽精血等材料
- 单场战斗每名弟子最多使用 3 张符箓，手动战斗可自选时机，自动战斗 AI 自动释放
- 符箓效果归入对应战斗乘区，遵守全局伤害、减伤上限规则

### 8.3 炼器系统

#### 8.3.1 系统定位
炼器是装备、法宝、傀儡部件的核心产出渠道，承接宗门矿石、灵晶等原材料的加工转化，是弟子战力养成的核心支撑模块。器堂等级、器师资质、炼器傀儡共同决定出品效率与品质。

#### 8.3.2 品阶体系
完全对齐全局 7×4 品阶标准，与装备、法宝体系一一对应：
- 凡品：基础凡铁装备，练气期过渡
- 灵品：精铁玄铁装备，筑基期主力
- 宝品：灵器级装备，金丹期核心
- 王品及以上：本命法宝、宗门重器

#### 8.3.3 炼器分类
| 品类 | 产出内容 | 解锁条件 |
| --- | --- | --- |
| 武器防具 | 各职业基础装备 | 器堂 1 级解锁 |
| 饰品配饰 | 戒指、项链等功能饰品 | 器堂 2 级解锁 |
| 法宝炼制 | 普通法宝成品与部件 | 器堂 3 级解锁 |
| 傀儡制作 | 各类傀儡成品与维修部件 | 器堂 3 级解锁 |
| 宗门重器 | 护山大阵核心、全宗增益道具 | 器堂 5 级解锁 |

#### 8.3.4 炼制规则
- 消耗矿石、灵晶、符文核心等材料，对应品级器师驻场制作
- 炼制成功率受器师资质、炼器傀儡、聚灵阵共同影响，区间 5%-95%
- 成功出品有概率额外提升 1 级细分品级，产出极品装备；失败返还 40% 基础材料
- 已产出装备可通过炼器堂强化、重铸，调整随机词条

### 8.4 傀儡系统

#### 8.4.1 系统定位
傀儡是宗门工业体系的自动化辅助单元，为无自主意识的法器造物，核心承担重复性劳作、标准化生产辅助、低阶战斗防御职能，是提升宗门经营效率、释放人力产能的核心模块。低阶傀儡用于替代基础劳作，提升灵田、矿场等基础产业产出；中高阶傀儡可辅助炼丹、炼器流程，提升成率与效率；顶级战斗傀儡可补充护山大阵战力，承担宗门防御职能。
傀儡体系与弟子、灵兽形成明确分层：弟子为核心决策与战斗主体，灵兽为灵活辅助与补充产出，傀儡为固定场景的标准化效率工具，三者互不替代，共同构建宗门完整生产与战斗生态。

#### 8.4.2 核心规则
**品阶体系**
严格遵循全局「7 大品阶 + 4 细分品级」二级标准，大品阶对应可制作的最低器堂等级与使用门槛，细分品级对应同品阶内的效能强度梯度。
- 大品阶：凡 / 灵 / 宝 / 王 / 圣 / 真 / 道，共 7 级
- 细分品级：下品 / 中品 / 上品 / 极品，共 4 级
- 标准命名格式：大品阶 + 细分品级 + 傀儡名，如「宝品上品丹道傀儡」；泛指场景可简化为「宝品丹道傀儡」，默认取中品效果。

**制作与部署规则**
- 傀儡需在器堂制作，解锁对应器堂等级后方可制作对应品阶的傀儡，需持有对应傀儡图纸。
- 制作需消耗矿石、灵晶、符文核心等材料，搭配对应境界的器师驻场，品阶越高制作难度越大、耗时越长。
- 傀儡制作完成后部署至对应岗位方可生效，劳作傀儡部署至产业建筑，丹器傀儡部署至丹堂 / 器堂，战斗傀儡部署至护山大阵。
- 单建筑可部署傀儡数量有上限，品阶越高占用部署位越多，避免堆叠导致数值溢出。

**耐久与维护规则**
- 所有傀儡均带有耐久度，每日运转会消耗耐久，耐久归零后傀儡停止工作，属性失效。
- 可在器堂消耗对应材料维修傀儡，恢复耐久度；高阶傀儡维修成本更高。
- 傀儡每日消耗灵石与灵晶作为维护能耗，维护不足会加速耐久损耗，长期停摆会出现部件锈蚀。

**升级与拆解规则**
- 傀儡可通过消耗核心部件进行升级，提升细分品级，增强效能；不可跨大品阶升级。
- 无用傀儡可拆解回收，返还 40% 基础制作材料，核心部件不返还。

#### 8.4.3 傀儡分类与定位
按功能分为四大类，覆盖宗门核心生产与防御场景。

| 傀儡大类 | 核心作用 | 部署位置 | 价值阶段 |
| --- | --- | --- | --- |
| 劳作傀儡 | 提升基础产业产出效率，替代人力劳作 | 灵田、矿场、灵桑田 | 前期 - 中期核心 |
| 炼丹傀儡 | 辅助炼丹流程，提升成丹率与炼制速度 | 丹堂 | 中期核心 |
| 炼器傀儡 | 辅助锻造流程，提升锻造速度与成功率 | 器堂 | 中期核心 |
| 战斗傀儡 | 补充宗门防御战力，增强护山大阵效果 | 护山大阵、宗门值守 | 中后期防御补充 |

#### 8.4.4 制作与效能规则
**制作条件**
- 器堂等级达标，解锁对应傀儡图纸
- 至少 1 名对应境界的器师参与制作
- 消耗对应矿石、灵晶、符文核心等材料
- 制作成功率 = 基础成功率 + 器师加成 + 聚灵阵加成，强制约束在 5%-95% 区间

**效能叠加规则**
- 同类傀儡效能叠加采用边际衰减，第一只 100% 生效，第二只 80%，第三只及以后 50%，避免无限堆叠。
- 傀儡提供的产业增益归入经营乘区，与聚灵阵、灵兽增益叠加后，全局总产出加成不突破 50% 硬上限。
- 战斗傀儡提供的防御、战力增益归入防御乘区，与护山大阵、法宝叠加后，全局减伤不突破 70% 硬上限。

#### 8.4.5 获取与升级途径
- 器堂自主制作（核心来源）
- 商会购买低中阶傀儡成品
- 秘境掉落高阶傀儡图纸与核心部件
- 阵营声望兑换稀有傀儡图纸
- 奇遇事件获取特殊功能傀儡

#### 8.4.6 数值平衡说明
- 同品阶傀儡的总效能约为同品阶灵兽的 70%，优势为稳定无情绪、无寿命限制、维护成本可控。
- 所有增益严格对齐全局乘区规则，产业类、战斗类分别归入对应乘区，叠加后不突破全局红线。
- 品阶间效能严格对齐全局属性基准倍率，确保数值体系统一，无断层与溢出。

#### 8.4.7 品阶体系详解
傀儡系统严格对齐全局「7 大品阶 + 4 细分品级」二级标准体系，大品阶决定功能上限、解锁门槛与效能量级，细分品级对应同品阶内的强度梯度，命名、数值、解锁规则与装备、丹药等全系统完全统一，杜绝多套标尺冲突。

**七大品阶分层与定位**

| 大品阶 | 解锁器堂等级 | 对应弟子境界 | 核心定位 | 代表傀儡 |
| --- | --- | --- | --- | --- |
| 凡品 | 1 级 | 练气期 | 入门级基础辅助，替代低端人力劳作 | 基础劳作傀儡、辅助炼丹 / 炼器傀儡 |
| 灵品 | 2 级 | 筑基期 | 标准化量产型，覆盖全基础产业场景 | 精工劳作傀儡、丹道傀儡、守卫傀儡 |
| 宝品 | 3 级 | 金丹期 | 宗门主力级，具备完整功能模块，高阶生产辅助 | 宗师劳作傀儡、丹道宗师傀儡、战阵傀儡 |
| 王品 | 4 级 | 元婴期 | 高阶精密型，生产效率登顶，可参与核心防御 | 天工劳作傀儡、破军战傀、丹道大师傀儡 |
| 圣品 | 5 级 | 化神期 | 宗门战略级，圣级符文核心，效能接近真人弟子 | 圣纹劳作傀儡、丹圣傀儡、战争傀儡 |
| 真品 | 6 级 | 炼虚期 | 传承级造物，蕴含法则碎片，效能质变 | 真灵战傀、道工傀儡（预留） |
| 道品 | 7 级 | 合体及以上 | 终极造物，大道级威能，全宗核心战略资源 | 道工傀儡、道兵战傀 |

**四级细分品级规则**
同品阶内分为下品 / 中品 / 上品 / 极品四级，核心差异体现在三个维度：
- 效能梯度：每提升一级细分品级，核心效果线性提升 15%-20%，耐久上限、制作成本同步递增
- 功能解锁：上品及以上解锁附加副效果，例如宝品上品丹道傀儡额外缩短 10% 炼制时长
- 制作难度：品级越高基础成功率越低，稀有材料占比越高，极品傀儡普遍带有专属词条
- 进阶规则：傀儡仅可在同一大品阶内提升细分品级，不可跨大品阶升级；例如凡品傀儡无法进阶为灵品，高阶傀儡需重新制作。

#### 8.4.8 数值平衡建议
围绕「全局乘区约束、堆叠边际衰减、成本收益匹配、定位差异化」四大核心原则设计，从根源避免数值崩盘。

**严格对齐全局乘区红线**
- 产业类增益封顶：劳作、丹器辅助类傀儡的产出 / 效率加成，全部归入「经营增益乘区」；与聚灵阵、灵兽、灵根加成叠加后，全局总增益强制封顶 50%，超出部分触发边际衰减至无效。
- 战斗类增益封顶：战斗傀儡的防御、减伤、战力加成归入「防御乘区」；与护山大阵、法宝、功法叠加后，全局减伤硬上限 70%，攻击加成软上限 80%。
- 基准倍率统一：所有傀儡效能严格遵循全局品阶基准倍率，以凡品下品为 1.0 基准等比增长，与装备、丹药保持同一数值尺度，避免品阶断层。

**同类堆叠采用边际衰减**
同一建筑内部署多只同类傀儡，效能不做线性叠加，从机制上杜绝无限堆叠：
- 第 1 只傀儡：100% 效能生效
- 第 2 只傀儡：80% 效能生效
- 第 3 只及以后：统一按 50% 效能生效
同时设置单建筑部署位上限：低阶建筑最多 3 位，高阶建筑最多 5 位，从容量上控制总增益上限。

**成本与收益正向匹配**
- 维护成本指数递增：品阶越高，单位效能的维护成本越高；王品傀儡的单位产出维护成本约为凡品的 3 倍，避免高阶傀儡性价比碾压，保留低阶量产的价值。
- 稀有材料做门槛：宝品及以上傀儡加入专属核心部件（符文核心、圣晶、道则核心等），通过资源稀缺性控制高阶傀儡的保有量。
- 折旧成本兜底：耐久维修成本随品阶升高而上升，高负荷运转下高阶傀儡综合成本显著高于低阶，引导玩家分层配置，而非全堆最高级。

**跨系统定位差异化**
- 傀儡定位为标准化辅助工具，不可替代弟子的核心地位：同品阶下，傀儡综合效能约为同境界弟子的 60%-70%，弟子始终是生产与战斗的核心主体。
- 傀儡仅能执行重复性劳作，无法承担突破、奇遇、高阶决策等需要主观意识的行为。
- 战斗傀儡仅在宗门防御场景生效，不可随弟子外出历练 / 秘境，不挤压弟子战斗养成的价值。

#### 8.4.9 获取与培养方式
**核心获取途径**
- 器堂自主制作（最主要来源）：解锁对应等级器堂与傀儡图纸后，消耗矿石、灵晶、符文核心等材料，由器师驻场制作；制作成功率受器师境界、聚灵阵、炼器傀儡辅助影响，失败返还 40% 基础材料。低中阶支持批量制作，高阶需单独锻造。
- 图纸与部件获取：低阶图纸随器堂升级自动解锁；中高阶图纸来自秘境掉落、阵营声望兑换、商会购买、宗门任务奖励；稀有核心部件仅高阶秘境 BOSS、顶级奇遇、阵营最高等级兑换产出。
- 成品获取：低中阶成品可直接在商会购买、商路贸易获取；高阶成品为特殊奖励，来自大型活动、传说奇遇、终极阵营兑换；新手期通过任务赠送 1 只凡品基础劳作傀儡，引导上手。

**培养与养成体系**
- 部署上岗：傀儡需部署至对应建筑岗位才生效：劳作傀儡→灵田 / 矿场，丹器傀儡→丹堂 / 器堂，战斗傀儡→护山大阵；部署占用建筑傀儡位，可随时拆卸更换；部署状态每日消耗满额耐久与维护费，闲置状态消耗减半。
- 耐久与维护：每日运转消耗耐久，耐久归零后自动停摆、属性失效；可在器堂消耗材料维修恢复耐久，品阶越高维修成本越高；长期闲置不维护会触发「锈蚀」debuff，永久降低最大耐久上限，需特殊材料修复。
- 品级进阶：同一大品阶内，可消耗对应核心部件与材料提升细分品级（下品→中品→上品→极品）；进阶后核心效能提升、解锁额外功能、耐久上限同步增加；不可跨大品阶进阶。
- 模块拓展（高阶玩法）：宝品及以上傀儡可加装功能模块，拓展额外效果（如增产模块、嘲讽模块、节能模块）；模块可自由拆卸更换，适配不同场景；单傀儡最多装 2 个模块，品阶越高可支持的模块等级越高。
- 拆解回收：无用傀儡可在器堂拆解，返还 40% 基础制作材料，核心稀有部件不返还；拆解产出的傀儡废料可作为低阶傀儡制作的辅助材料。
