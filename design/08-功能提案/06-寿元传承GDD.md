# 《太玄宗门录》寿元传承系统 GDD（提案 B/C · F12）

> **核心定位**：境界绑定寿元，坐化/飞升双路径，传承体系（物品/功法/道统）+ 先贤祠永久加成。强化「世代宗门传承」核心卖点（`00-INDEX.md` §1.1）。**零战斗结算**，S1 可交付。
> **诚实标注**：需轻量代码（寿元字段 + 坐化/飞升逻辑 + 传承/先贤祠写入）；复用 `GDD-弟子养成.md` §三.3 传承机制 + `数值体系细则.md` §4.1 先贤堂（已定 +5% 入通用乘区）。

---

## 一、境界寿元表

| 境界 | 寿元（载） |
|---|---|
| 炼气 | 80 |
| 筑基 | 150 |
| 金丹 | 300 |
| 元婴 | 500 |
| 化神及以上 | 待 `数值体系细则.md` 校准（按同梯度外推，提议 [PLACEHOLDER]） |

> 寿元 = 境界绑定基础值；突破新境界刷新寿元上限（不回退已活年岁）。

## 二、延寿途径
- 延寿丹/天材地宝（引用现有 item_pill / treasure，待 `item_material` 注册表补全后回填具体 ID）。
- 特殊功法/机缘（引用现有 skill / 奇遇奖励）。
- 所有延寿须登记为「受控产出」，守月度盈余上限（`数值体系细则.md` §4.8），不突破经济红线。

## 三、寿元预警
- **预警阈值**：剩余寿元 < 20 载 → 提示弟子「大限将至」，建议突破/延寿。
- 预警不阻断，仅 UI 提示（弟子详情弹窗寿元行高亮）。

## 四、坐化 / 飞升双路径
| 路径 | 触发 | 结果 |
|---|---|---|
| 坐化 | 寿元耗尽未突破/延寿 | 弟子离世，触发传承（见五），写纪事 |
| 飞升 | 达最高境界 + 条件（待定） | 弟子飞升，触发传承 + 全宗声望，写纪事 |

> 坐化/飞升均为非战斗事件结算，S1 生效。

## 五、传承体系
- 坐化/飞升前留传承：传承功法 / 遗物（物品）/ 道统。
- **道统加成**：传承给后辈 → 全宗/受赠弟子 **道统 +5%**（入通用增益乘区，见 §4.1 先贤堂 +5% 口径）。
- 传承物品引用现有 item_id（skill / treasure / item_pill 等），**不新增悬空 ID**。

## 六、先贤祠（微量永久加成叠加有上限）
- 坐化/飞升弟子入先贤祠，提供微量永久加成（灵气/修炼/声望等）。
- **叠加上限**：先贤祠总永久加成有上限（防长线击穿红线），与 `数值体系细则.md` §4.1 先贤堂 +5% 同口径——嵌套入通用增益乘区（软 25%/硬 30%），无独立额度。
- 先贤祠加成 = 长线底蕴补充（非独立加成），单源子帽 + 池总帽双层保险。

## 七、前期保护（防卡进度）
- **前期 20 大考周期内不自然坐化**：新手期（前 20 个大考周期）弟子不自然寿终，防早期宗门断层卡进度。

- ✅ **复用现状**：传承机制（`GDD-弟子养成.md` §三.3 已定义）、先贤堂 +5% 乘区（`数值体系细则.md` §4.1 已定，本批仅对接非重定义）、血脉传承（F13 道侣子嗣衍生）。

## 十、S1/S2 分期
- **S1 交付**：全功能（寿元/预警/坐化/飞升/传承/先贤祠/前期保护）。无战斗结算。

## 十一、UI 入口规范（对齐 B2）
- 寿元展示：弟子详情弹窗「寿元」行（预警高亮）；先贤祠：纪事阁/宗门页二级入口（非首页独立按钮，B2 合规）。
- 无编辑入口（坐化/飞升为事件驱动），不新增导航项。

## 十二、跨文档一致性
- 先贤堂 +5% → `数值体系细则.md` §4.1（通用增益乘区软 25%/硬 30%，先贤堂嵌套同一池，无独立额度）。
- 传承 → `GDD-弟子养成.md` §三.3；血脉 → F13（`03-动态关系GDD.md`）。
- 经济红线 → `数值体系细则.md` §4.7/§4.8（延寿须登记产出源，守月度盈余）。
- item_id → `REPORT-item_id注册表.md`（333 注册），传承物品引用现有 ID，不新增悬空 ID。

## 十三、边缘情况（≥3）
- **EC-1 突破刷新寿元**：突破新境界 → 寿元上限按新境界重置，已活年岁不清零（提示「寿元焕新」）。
- **EC-2 坐化时传承物品为空（清贫弟子）**：仅道统 +5% 入先贤祠，无物品传承不报错。
- **EC-3 前期保护期内寿元耗尽**：屏蔽自然坐化，弟子续存至保护期结束（防卡进度）。
- **EC-4 旧档无寿元字段**：`.get` 默认按当前境界寿元表赋初值，不崩。

## 十四、验收标准
- 境界绑寿元 + 预警<20载 + 坐化/飞升双路径 + 传承(道统+5%)/先贤祠(叠加上限) + 前20大考周期不自然坐化；入通用乘区卡红线；引用现有 item_id 不新增悬空；旧档兼容。
