## 0. 设计目标（G4 验收）

> D5 AC：「降级开启时不白屏不卡死」。开关须在**任意异常态**（资源缺失/低端机掉帧/OS reduce-motion）下保持界面可用，所有美术特效可安全回退到静态基线。

## 1. 开关状态机

| 档位 `QUALITY_MODE` | 触发来源 | 视觉表现 |
| --- | --- | --- |
| `STANDARD`（标准·默认） | 默认 / 用户手动 | §15.4 标准动效（锁 30fps、边缘重绘、GPU 合成、流光/呼吸/微光按规格运行） |
| `LITE`（轻量 / 极简） | 用户手动 / 低端机自动探测 / OS reduce-motion | 关全部循环/流光/呼吸/全屏闪白/微震；仅保留必要位移/淡入淡出（或无动画瞬切）；去背景氛围（全息八卦/祥云/数据云雾） |
| `OFF`（关闭·最低） | 用户手动（三档之「关闭」） | 等同极简，且入场/点击/转场用瞬切，无过渡 |
| `A11Y_SIMPLE`（一键简化·增强） | 用户手动（一键简化总开关） | 同 LITE + 字号 +1 级（或默认 130% 缩放）+ 启用高对比主题 + 关震动 |

- **自动降级链**：OS reduce-motion → 强制映射 `LITE`；低端机 FPS 持续 < 阈值 → 建议 `LITE`（弹一次提示，不强制）；资源缺失 → 节点级回退灰模（见 §4），不升档。
- **持久化**：`QUALITY_MODE` 存入存档（§11.21 元数据），重启保持；首登默认 `STANDARD`，不弹窗打扰。

## 3. 关键令牌（供 eng-lead 接线）

| 令牌 | 值 / 枚举 | 说明 |
| --- | --- | --- |
| `QUALITY_MODE` | `STANDARD` / `LITE` / `OFF` / `A11Y_SIMPLE` | 全局质量档，单一数据源 |
| `HIGH_QUALITY_VFX` | bool（= `QUALITY_MODE != LITE/OFF`） | 控制所有发光/流光/呼吸/震动（ASSET-奇遇弹窗 §8） |
| `REDUCE_MOTION` | bool（监听 OS） | true → 强制 `LITE` |
| `VIBRATION_ENABLED` | bool（独立开关） | 控制线性马达（传说微震/点击轻震） |
| `PLACEHOLDER_FALLBACK` | 资源缺失→`_placeholder_{node_id}` | 节点级灰模回退（§4） |
| `FPS_AUTO_LITE` | 持续 < [PLACEHOLDER 建议 24]fps → 建议 LITE | 低端机自动降级建议 |

- 所有动效组件读取 `HIGH_QUALITY_VFX` + `REDUCE_MOTION` 决定实时降级；**不**为每个特效单独写分支。

## 4. 异常兜底（不白屏不卡死）

1. **资源缺失**：任何美术资源加载失败 → 自动替换为对应灰模占位（`_placeholder_{node_id}` / 空槽占位 `#23262E`），记一条 warning 日志，不抛错、不阻断流程。
2. **动效异常**：某 Tween/Shader 报错 → 捕获并跳过该动效，回退静态表现，不冻结整帧。
3. **低端机兜底**：`FPS_AUTO_LITE` 触发后仅弹一次「已切换轻量模式」提示，用户可手动切回（不强制锁死）。
4. **卡死防护**：任意 UI 帧耗时超 [PLACEHOLDER]ms → 强制 `OFF` 档并上报，保证可操作。

## 5. 可访问性挂钩（引 ACCESSIBILITY.md）

- 降级开关是 ACCESSIBILITY **Standard/Comprehensive** 级的核心使能项；`A11Y_SIMPLE` = 一键达 Comprehensive 基线。
- reduce-motion 自动映射 `LITE`（§5 已载明）；震动独立开关服务前庭/触觉敏感（§7）。
- 文本缩放（100–150% 无破版）、高对比主题均在 `A11Y_SIMPLE` 下启用（ACCESSIBILITY.md §6/§7）。
- UX 流程（design-lead）须引用本分级与开关，不得另立降级规则。

4. `FPS_AUTO_LITE` 阈值与卡死防护阈值标 [PLACEHOLDER]，待 480×854/30fps 低端机实测回填。
