## 3. 信息架构
```

  标题
  双输入（宗门名 / 宗主名）
  性别（男 / 女）
  三Tab（发型 / 五官 / 服饰）
  小预览框（robe 底 + hair_t 中 + features_t 顶 三层叠放，可点击放大）
  选择标签（当前三维编号）
  九宫格滚动区（当前 Tab 维度 9 格，选中格高亮）
  创立按钮
+ 弹窗（CanvasLayer，初始隐藏）：遮罩 + 面板 + 三层组合预览 + 关闭
```

## 4. 交互规则
- **双输入**：`LineEdit` 录入宗门名/宗主名；创立时 `strip_edges()` 校验非空，空则显示错误提示。
- **性别切换**：`Game.宗主性别预设` 循环；切换重置 `_idx` 为 0、清空缩略图缓存、重建网格、刷新预览。
- **Tab 切换**：`发型/五官/服饰` 三维度；仅当前维度九宫格可见，刷新选中态与选择标签。
- **格子点击**：设当前维度 `idx` → 刷新三层预览 + 选择标签 + 选中描边；弹窗开启时同步更新。
- **预览点击**：打开组合预览弹窗（标题含三维编号，robe+hair_t+features_t 三层）。
- **创立**：emit `创建完成(宗门名, 宗主名, 性别, 发型idx, 五官idx, 服饰idx)`。
