# 信息架构与导航硬性约束

> **一句话定位**：把当前 `_ready()` 里「一个 `中区` ScrollContainer 塞进 状态栏 + 四排功能按钮 + 离山汇总 inline + 内滚 Tab(弟子/待抉择/御兽/纪事)」的拥挤结构，拆成「首页只放状态+导航，其余模块各自独立整页」的扁平页面森林。本规范只定结构与行为红线，不动代码、不改数值、不重写视觉参数。

> ⚠️ **架构已作废（2026-07-24 最终定夺）**：本 v1.0 基于**旧 9 页扁平森林模型**撰写，已被 `UI硬性约束规范.md §1`（v2.0+，5-Tab 分级导航：宗门/弟子/御兽/历练/纪事，洞府/修炼下沉宗门页快捷入口，坊市为宗门二级页，历练为独立 Tab）**正式取代**。本文件仅作「信息架构展开版细节」历史参考，**导航架构一律以 `UI硬性约束规范.md §1` 与 `绘图强制规范.md v2.0` 为准**；其页面树 / 灰锁 / 占地预算等章节未对齐 5-Tab，请勿直接照搬。

## 0. 背景与适用范围

### 0.1 现状问题（终裁）
`main.gd::_ready()`（line 157）在 `主布局` 内只建了一个 `中区`（ScrollContainer，line 192），其 `中区内容` (VBox) 顺次塞入：
- 掌教标题 / 别名（line 210–221）
- 状态面板（line 225–229）
- 四排功能按钮群（推演/招收/建筑/快进/存读/历练/坊市/任务/新游戏/推演N日，line 232–277）
- 离山汇总面板 inline（line 280–283）
- 内滚 `滚动` + `页控`（弟子/待抉择/御兽/纪事，line 297–309）

结果：信息拥挤、模块边界模糊、首屏无主次之别。本规范据此重划信息架构。

## 3. 导航机制约束

### 3.1 底部主导航栏（常驻）
- **复用现有 `标签栏`(TabBar) 实例**（line 147/290）作为主导航：把 `add_tab` 列表替换为 §2 的 9 个页面（导航标签用 2 字以适配 480 宽：弟子/纪事/御兽/坊市/任务/历练/建筑/推演/首页）。
- 保留 `tab_changed` 连接，改连到新处理函数 `_on_主导航切换(i)`（替代旧 `_on_切页`，line 360）。
- **常驻**：跨页不释放；固定于屏幕底部；z 序低于弹窗遮罩（弹窗仍可置顶）。
- **灰锁 tab**：对受锁页面调 `set_tab_disabled(i, true)` + `set_tab_title(i, "🔒 "+名)`（沿用 `_刷新功能解锁` 三通道：色+形+字），详见 §5。

### 3.2 页面跳转 = 整页切换（硬性定义）
> 「分页跳转」**必须**是 real page navigation / 整页切换：**隐藏并重建内容容器**，绝非线性滚动容器内切 Tab。

- 每个页面 = 一个独立内容容器（建议 `ScrollContainer` 内含 `VBoxContainer`），记为 `页_X`。
- 全局**同时只有一个**当前页容器挂载在「内容区锚点」(`内容区` Control，固定不滚) 之下。
- 切换流程（伪代码语义，工程据此实现）：
  1. `当前页容器.queue_free()` —— 释放上一页**全部子树**（直接消除旧「`中区` + 内滚」嵌套 ScrollContainer 高度坍塌隐患，旧 `滚动.custom_minimum_size=360` 的 workaround 不再需要）。
  2. 调用 `_建_页_X()` 重新实例化目标页容器并 `add_child` 到 `内容区`。
- **禁止**：在同一个 ScrollContainer 内用 `visible` 切 Tab 显示不同面板（即废除旧 `_on_切页` 的 `页控[k].visible = (k==名)`，line 363）。
- **禁止**：一个 ScrollContainer 内同时堆叠多页内容。
- 跨页常驻 chrome（顶部状态带 W1、目标条 W2、底部导航 W3）**不随页切换释放**。

### 3.3 页间返回规则
- 所有页面为**扁平顶层集**，无深度栈；「返回」语义 = 跳回 **P0 首页**。
- 每个子页在内容区顶部提供「← 返回」控件，点击 = `_on_主导航切换(首页索引)`；同时底部主导航的「首页」tab 亦可一键回首页。
- 弹窗（弟子详情 / 结果弹窗）内的「知悉/归藏/关闭」= 返回**该页自身**，不触发整页切换。
- 引导需要的「自动进入某页」：由 `_引导_刷新()` 调用 `_on_主导航切换(对应页索引)`（替代旧 `标签栏.current_tab = 0` + 页控可见，line 1731–1732）。

### 3.4 复用现有 TabBar 的工程要点（仅说明，不改代码）
| 现有代码 | 新用途 |
| --- | --- |
| `标签栏` (TabBar, line 147/290) | 直接用作底部主导航，承载 §2 九页 |
| `页名` 常量 (line 140) | 扩展为九页导航标签数组（2 字短名） |
| `_on_切页(i)` (line 360) | 改名 `_on_主导航切换(i)` 并重写为「整页切换」 |
| `页控` dict (line 309) | 废除（不再用 visible 切同滚内多面板） |
| `_刷新功能解锁()` 中 `标签栏.set_tab_disabled/set_tab_title` (line 1981–1987) | 改为按「页面索引 → 门名」映射（坊市/任务/历练/御兽 对应新索引） |

## 4. MUST / MUST NOT 硬约束清单（工程逐条核对）

> 语气：**必须** = 实现时硬性满足；**禁止** = 实现时硬性规避。每条可独立勾选。

**【首页结构】**
- [ ] **必须** 首页仅渲染：顶层状态带 + 引导_目标条(条件) + 底部主导航栏 + 安全边距。
- [ ] **禁止** 在首页渲染任何弟子列表 / 弟子卡 / 弟子页头。
- [ ] **禁止** 在首页渲染任何功能按钮群（推演/招收/建筑/快进/存读/历练/坊市/任务/新游戏…）。
- [ ] **禁止** 在首页渲染离山汇总面板 / 战报 的 inline 常驻展示。
- [ ] **禁止** 在首页（及任何单页）出现嵌套 ScrollContainer（一页一滚）。

**【页面独立性】**
- [ ] **必须** 弟子录 / 纪事阁 / 御兽园 / 坊市 / 任务 / 历练 / 建筑 / 推演中心 各自为独立页面容器。
- [ ] **必须** 每个模块页面拥有独立滚动容器与独立返回导航。
- [ ] **禁止** 将「弟子/待抉择/御兽/纪事」做成同一滚动页内的 Tab 切换。
- [ ] **必须** 页面切换时释放上一页全部子树（`queue_free`）后再建新页（整页切换）。
- [ ] **禁止** 用 `visible` 在同一个滚动容器内切换多页面板（废除旧 `页控` 做法）。

**【导航栏】**
- [ ] **必须** 底部主导航栏常驻、跨页不释放。
- [ ] **必须** 底部主导航复用现有 `标签栏`(TabBar) 组件（或视觉等效的常驻导航），不得退化为首页内按钮群。
- [ ] **必须** 所有受锁模块在导航栏**置灰可显**（disabled + 🔒 前缀），**禁止** 隐藏锁定项。
- [ ] **必须** 点击锁定导航项不产生整页跳转（由 `set_tab_disabled` 天然拦截）。

**【灰锁与引导】**
- [ ] **必须** 保留 `_功能解锁()`/`_灰锁提示()`/`_刷新功能解锁()` 判定与提示文案不变。
- [ ] **必须** 灰锁解锁后即时刷新导航（保持 `刷新()`、`_引导_收尾()`、升级后的现有调用点）。
- [ ] **必须** 引导 hook 跟随模块迁移（状态面板点击 hook 留状态带；离山面板 hook 迁推演中心；FTUE 高亮目标改指对应页面入口）。

**【布局占地】**
- [ ] **必须** 底部主导航 tab / 页内主按钮触摸目标 ≥ 44×44px（ACCESSIBILITY Standard）。
- [ ] **必须** 内容区每页独立滚动，且可用高 ≥ 680px（竖屏 480×854，见 §6）。

## 6. 竖屏 480×854 布局占地预算

### 6.1 占地预算表
| 区域 | 高度(px) | 说明 / 锚点 |
| --- | --- | --- |
| 顶部目标条预留 | 48 | FTUE 期占用（`主布局.offset_top=48` 沿用）；非 FTUE 期该条隐藏，状态带上移复用 |
| 顶层状态带（固定，不滚） | 56 | 承载 `状态面板`；常驻于所有页面顶部 |
| 左右安全边距 | 8（每侧） | 内容宽 = 480 − 16 = **464** |
| 顶部安全边距 | 8 | 状态带与内容区上间距 |
| 底部主导航栏（固定，常驻） | 56 | 含 8px 底边距；tab 最小点击 44px |
| **内容区可用高** | **≈ 694** | 854 − 48 − 56 − 56 = 694；非 FTUE 期目标条隐藏可 +40 ≈ **734** |
| 内容区内边距 / 列表 separation | 8 / 6 | 沿用《写实修仙UI可执行规范》§1.3 / §5.1 |

### 6.2 内容区规则
- 每页 = 独立的 `ScrollContainer`（高 = 内容区可用高，约 694/734px），互不堆叠、随页切换重建。
- 触摸目标 ≥ 44×44（导航 tab、页内主按钮）；正文/数值 ≥ 15px（ACCESSIBILITY Standard，与本规范 §0.2 视觉参数文件一致）。

### 6.3 九 tab 宽度可行性
- 2 字导航标签（弟子/纪事/御兽/坊市/任务/历练/建筑/推演/首页）在 464px 内容宽内约 378–443px，**可单行容纳，无需横向滚动**。
- 若未来标签加长到 3 字或增页导致溢出：TabBar 原生支持横向滚动（可用）；若团队认定不可接受，备用方案 = 底部双行 `Button` 导航，但**必须**保持同样的「置灰 + 🔒」灰锁语义（禁止隐藏锁定项）。
