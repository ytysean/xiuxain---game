## 二、核心设计：坐标双轨（把尺度问题关进渲染层）

```
逻辑坐标（玩法权威，±200 域内，不变量）
    │  商队运输 = 距离/15~30 ｜ 行军 = 距离/25
    │  被劫风险 = 距离/500   ｜ 资源衰减 = 距离/1000
    ▼
视觉坐标 = 逻辑 × 世界映射系数(2.4) + 画布中心(2000,2000)
    │  无缝平移 / 缩放 / 边界柔化 / 装饰填充
    ▼
渲染层（4000² 画布，可平移可缩放）
```

- **逻辑坐标一寸未动** ⇒ 上述四条平衡公式**零适配**，**存档零迁移**（`to_dict/from_dict` 不破）。
- 「世界更大」= 画布 ×2 + 映射 ×2.4；五域逻辑范围最大 ±700 → 视觉 ±1680，**铺满画布中央 84%**，四边留 320 供内容继续长。

## 七、已知遗留 / 观察

1. **`_绘制地形()` 有个哑节点**：`块`(ColorRect) 被创建并配置颜色/位置/尺寸，但**从未 `add_child`**（真正上屏的是 `panel`）。属既有小浪费（每帧无影响），本轮未动（避免扩大改动面）。
2. **区域底板仍是平面色块**：符合 §11.10.3 MVP 口径（"深灰地形图底 + 线条勾勒"），细粒度质感属完整版。
3. **内在区域接缝为硬边**：边界柔化只处理**画布四边**；域与域之间的接缝是直角矩形交界。若需要"域-域也柔化"，属后续增强项。
4. **探针会清空 `已探索网格`**：`tests/_t_seamap.gd` 为保证确定性会先清迷雾，**请勿在对真实存档的环境下运行**（仅测试场景使用）。
