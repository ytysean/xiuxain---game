# 《太玄宗门录》弟子养成系统设计

> 版本：v1.0 ｜ 来源：2026-07-18 用户投稿底稿（见 `design/03-系统设计/_inbox/2026-07-18_投稿_交易经营弟子活动.md`）归位整理 ｜ 用途：弟子互动 / 情感养成 / 师徒系统开发依据
> 体系对齐：弟子数据模型（`disciple.gd`）、七境界体系、宗门职位（`GDD-宗门经营.md` §五）、成就系统（待建）。
> 全局红线：数值类正文严禁出现对外宣传名；所有数值保留整数。

## 一、概述

弟子养成系统聚焦于"情感代入与弟子鲜活度"，避免弟子沦为纯数值工具。本 GDD 将投稿底稿中「弟子互动系统」归位为核心章节，并补充「弟子养成总览」说明其与 `disciple.gd` 数据实现的对应关系（仅引用，不重写代码逻辑）。

设计目标：通过日常互动、随机事件、个人列传、师徒羁绊，让每个弟子具备辨识度与情感锚点，提升长线留存与代入感；所有互动数值影响轻微、不破坏核心平衡。

---

## 二、弟子养成总览（与 disciple.gd 对应）

《太玄宗门录》的弟子数据模型由 `disciple.gd` 实现，本 GDD 仅声明其承载的养成维度，不重写代码逻辑。投稿「弟子互动系统」的操作对象即 `disciple.gd` 中如下核心字段（引用，非重定义）：

- **身份与归属**：弟子 ID、职位（`GDD-宗门经营.md` §五 四级架构）、招募来源、是否记名/稀有弟子；
- **成长属性**：境界（练气→道祖七阶）、资质、灵根、性格、职业（对齐 `太玄宗门录_调参速查表.md` §1.1-§1.5）；
- **情感状态**：好感度、忠诚度（投稿 §三 日常互动 / 随机事件驱动）；
- **关系网络**：师徒关系、道侣、同门关系（投稿 §三.4 / §三.2 生活类事件）；
- **叙事载体**：弟子列传章节进度、传承遗物（投稿 §三.3）。

> 引用约定：本 GDD 所有互动效果（好感/忠诚/修炼效率变动）写入 `disciple.gd` 对应字段；具体数值公式与升级曲线以 `disciple.gd` 现有实现与 `核心设定总览` 为准，本层不再重复定义。

## 三、弟子互动系统（核心章节 · 投稿归位）

定位：强化情感代入与弟子鲜活度，避免弟子沦为纯数值工具；通过日常互动、随机事件、个人列传，让每个弟子具备辨识度与情感锚点。

### 1. 日常互动玩法

| 互动方式 | 冷却时间 | 效果 | 解锁条件 |
|---|---|---|---|
| 论道交流 | 每日 1 次 / 每位弟子 | 小幅提升弟子修炼效率与好感度 | 开局解锁 |
| 指点修为 | 每日 1 次 / 每位弟子 | 弟子立即获得少量修炼进度 | 掌门筑基期解锁 |
| 赠送礼物 | 无冷却（有额度） | 大幅提升好感度与忠诚度 | 开局解锁 |
| 赐下道号 | 永久 1 次 | 弟子归属感提升，永久小幅提升修炼速度 | 弟子筑基期解锁 |
| 赏赐宝物 | 无冷却 | 大幅提升忠诚度，弟子战力临时提升 | 宗门 3 级解锁 |
| 责罚训诫 | 无冷却 | 降低好感度，提升纪律性（减少闯祸概率） | 执法长老解锁 |

- 好感度 / 忠诚度作用：好感度越高，弟子修炼效率越高、越不容易叛逃；忠诚度满值的弟子会触发"舍身护宗"事件，宗门遇袭时主动拼死抵挡。
- 境界联动：弟子突破大境界时，掌门可进行"破关赐礼"，大幅提升好感并小幅提升突破成功率，强化仪式感。

### 2. 随机弟子事件

日常经营中随机触发弟子个人事件，丰富宗门生活感，事件结果受玩家选择影响。
1. 成长类：弟子下山历练归来，带回奇遇线索 / 稀有材料；弟子悟道，修为大进；弟子遇到瓶颈，求助掌门指点。
2. 生活类：弟子结为道侣，全宗送贺礼，两人修炼效率共同提升；弟子家属来投，可招募为新弟子；弟子闯祸损坏丹房 / 器堂，需要赔偿灵石。
3. 抉择类：弟子被其他宗门挖角，选择挽留 / 放行；弟子触犯门规，选择严惩 / 轻罚；弟子想下山游历，选择同意 / 拒绝。
- 所有事件均对应少量数值影响与剧情文案，不破坏核心平衡，核心作用是提升弟子的鲜活度与宗门生活感。

### 3. 弟子列传与传承

1. 弟子列传：每位可招募的弟子都有独立背景故事、性格设定、人生目标，招募后解锁列传第一章，随成长逐步解锁后续章节，对应探索 / 成就系统。
2. 传承机制：高阶弟子坐化 / 飞升前，会留下传承功法、遗物，赠予宗门后辈，形成宗门传承感，呼应"香火不绝"的修仙主题。
3. 记名弟子：普通弟子无列传，仅作为基础劳动力；稀有 / 特殊弟子带完整列传与专属立绘，是弟子收集与情感代入的核心目标。

### 4. 师徒系统

- 掌门可收徒，弟子也可拜入门下，师徒组队历练、论道可获得额外加成。
- 徒弟出师后，师父可获得"传道值"，可兑换特殊道具与称号，对应"桃李满天下"成长成就。
- 师徒羁绊：师徒同场战斗有属性加成，弟子叛逃概率大幅降低。
