2.2 弟子阵营倾向（v2.8 新增，v2.12 统一口径）
弟子阵营倾向分为正道倾向、中立倾向、魔道倾向三类（上古妖兽族群、远古遗泽无对应弟子阵营，分别对应灵兽体系与高阶机缘）。12 种固定性格直接映射三大阵营倾向，代码复用性格四维模型，无需新增字段，与奇遇判定逻辑完全对齐。

**口径澄清（v2.12）**：阵营倾向是弟子永久固定的「行事风格」属性，不等同于「身份归属」。弟子加入宗门后身份变为「宗门弟子」，其阵营倾向保持不变，仅影响行为逻辑、奇遇抉择与阵营声望增减，不与宗门归属冲突。「散修」是无宗门弟子的身份状态（招贤阁访客），多数中立倾向弟子出身于散修，但不作为阵营分类命名。宗门阵营声望与弟子倾向互相影响：正道声望高则招贤阁刷新正道倾向弟子概率更高；魔道倾向弟子占比高则宗门魔道声望增长快、正道声望增长慢；倾向与宗门主流不符的弟子离职概率略高（道不同不相为谋）。UI 显示：弟子详情页统一显示「道途：守正道 / 尚中立 / 行异道」（列表页缩写「守正 / 尚中 / 行异」），详见 15.1 弟子标签命名与分层规则；「散修」仅用于招募界面描述未入宗访客身份，入宗后该标签消失。

2.2.4 招贤阁刷新概率联动（v2.13 数值化）
将 2.2 口径澄清中的「宗门声望 ↔ 弟子倾向互相影响」落为可实现的加权抽取规则。本机制仅影响招募概率，与战斗增益乘区无关，不触碰第 4 章 25% / 10% 数值红线。

设计目标（player-first）：
- 玩家通过声望投资塑造宗门身份后，应更易匹配到同倾向弟子（正反馈 / 承诺机制，强化长期投入感）。
- 必须保留「最低概率红线」，保证异倾向弟子始终可招募（支持转型 / 混搭的玩家 agency），避免声望锁死阵容。

刷新模型：
- 每次刷新生成 N 名访客，N = [PLACEHOLDER]（建议 3–5，随招贤阁建筑等级 +1）。
- 每名访客的阵营倾向由加权随机抽取决定，权重池 = {正道, 中立, 魔道}。
- 单名访客权重 = 基础权重 × 声望修正系数（取乘积，禁止线性加算，避免后期失控）。

基础权重（全声望为「中立」级，即 L=0 时）：
| 倾向 | 基础权重 | 设计 rationale |
| --- | --- | --- |
| 正道 | [PLACEHOLDER] | 正统路线为玩家主流，略高于魔道 |
| 中立 | [PLACEHOLDER] | 招贤阁访客多出身散修（对齐 2.1：中立散修为招贤阁基础刷新主体），中立占比基准最高 |
| 魔道 | [PLACEHOLDER] | 魔道弟子本就稀缺，基准最低 |

声望修正系数（对齐 2.1「正魔此消彼长、散修独立计算」规则）：
- rep_factor[正道] = (1 + k_pos × L_正) × (1 − s × L_魔)
- rep_factor[魔道] = (1 + k_neg × L_魔) × (1 − s × L_正)
- rep_factor[中立] = 1 + k_neu × L_中
- L = 对应阵营声望等级（中立 0 / 友善 1 / 尊敬 2 / 崇敬 3 / 崇拜 4）
- k_pos、k_neg = 每级声望对该倾向权重的加成系数 [PLACEHOLDER]
- s = 正魔此消彼长交叉抑制系数 [PLACEHOLDER]（魔道声望越高，正道访客越难刷出，反之亦然）
- 中立声望独立计算，不受正魔交叉抑制影响（2.1 规则）

最低概率保障（玩家 agency 红线）：
- 任一倾向单次刷新出现概率不低于 P_min [PLACEHOLDER]（建议 15%），即使声望极端偏向另一端，仍保证可招募异倾向弟子。
- 实现：加权归一化后，对低于 P_min 的倾向概率强制抬至 P_min，多出的权重按原比例分摊回其余倾向；过滤后仍受此约束，不会刷出 0 名结果。

完整抽取公式：
plaintext
weights = {
  正道: base_正 × (1 + k_pos×L_正) × (1 − s×L_魔),
  中立: base_中 × (1 + k_neu×L_中),
  魔道: base_魔 × (1 + k_neg×L_魔) × (1 − s×L_正)
}
p = normalize(weights)        # 归一化得原始概率
p = apply_floor(p, P_min)     # 强制最低概率红线
for i in 1..N: 访客_i.倾向 = weighted_random(p)

与现有机制的关系：
- 招贤阁「筛选条件设置」（11.2）为玩家主动杠杆：设置「仅看正道倾向」时从已抽出访客中过滤显示，不改变底层加权抽取，过滤后仍受 P_min 约束。
- 与 2.1 数值细则一致：高正道声望触发「正道问责」会临时压低刷新质量（降 N 或 k_pos），不在此公式重复处理。
- 不新增字段：访客倾向读取弟子性格四维模型映射（2.2），无需额外存储。

数值校验示例（[PLACEHOLDER]，仅演示公式走向，非定稿）：
假设 base = {正:30, 中:45, 魔:25}、k_pos=k_neg=0.25、k_neu=0.15、s=0.20，L_正=3(崇敬)、L_魔=0、L_中=1：
→ 正道 = 30×(1+0.75) = 52.5；中立 = 45×1.15 = 51.75；魔道 = 25×1 = 25
→ 归一化 p ≈ {正:0.42, 中:0.41, 魔:0.17}，均高于 P_min，宗门身份与刷新结果同向，且魔道仍保留 17% 刷新空间，符合 agency 红线。
