# 《太玄宗门录》主线世界观与剧情卷

> 本文件从 `design/01-总纲/太玄宗门录_核心设定总览.md` §16 归位。包含世界背景、宗门起源、主线五卷、文案示例、落地绑定与集成裁决。


> **设计目标**：构建完整的世界观基底与长线剧情脉络，通过「宗门成长 + 上古秘辛 + 阵营博弈」三线交织，给玩家明确的长期目标与情感锚点；剧情节点与玩法解锁深度绑定（玩法推进 = 剧情推进），避免剧情与玩法脱节。
> **对齐标准**：全局境界体系（§3 / §4.7）｜ 五大阵营设定（§2.1 / §11.26 / §11.27.5，faction_id 严格 fz_*）｜ 秘境 / 历练地图（§11.27.3 map_config / §11.27.4 secret_config）｜ NPC 人设体系（§11.27.5 npc_config）。
> **铁律遵循**：本文档不新建并行数值表；所有具体数值（清颜露成本、多结局阈值、玄极令权重等）均标 `[PLACEHOLDER]`，待实测校准，禁止写入「魔法数字」。

## 16.1 世界背景设定

## 16.1.1 玄洲大陆概览
玄洲，上古灵脉汇聚之地，自天地初开便灵气充盈，滋生万千修士与妖族。大陆以中部「中州灵域」为核心，四方分设东荒林海、西漠戈壁、南疆十万大山、北原冰境，灵脉密度从中州向四周逐级递减。
- **中州灵域**：五大阵营核心势力盘踞之地，灵脉最盛，高阶修士聚集区，玩家宗门后期扬名的核心舞台。
- **青峰山麓**：玩家宗门所在地，位于中州边缘，曾是上古大宗山门外围，灵脉稀薄但暗藏上古传承，是新手起点。
- **四大边域**：对应各阶段历练、秘境地图，散落上古遗迹、妖族据点与隐世势力，是中期探索核心区域。

> **地图层级裁定（v2.65，对应审计 Q1）**：本章「中州灵域 + 四大边域」为**宏观地域层（剧情 / 世界观层）**；具体历练地图以 `map_config.csv` 为准（青峰山麓 / 黑风峡谷 / 赤炎荒漠 / 玄冥冰原），视为各宏观地域内的具体历练点，**不重命名 config 地图以保单一数据源**。地域与地图的归属：青峰山麓、黑风峡谷 ∈ 中州灵域及周缘；赤炎荒漠 ∈ 西漠戈壁；玄冥冰原 ∈ 北原冰境；南疆十万大山为万灵古族领地（详见 §16.3 卷三节点 3）。大地图导航壳见 §11.10.2。

## 16.1.2 核心史诗伏笔：上古玄洲天倾
三千年前，玄洲仙道鼎盛，以「太玄宗」为首的正道七宗统御全洲。直至域外「幽魔族」破界入侵，掀起灭世之战。
- **战争结局**：太玄宗宗主玄极天尊带领七宗修士血战百年，以自身兵解为代价将幽魔族主力封印于地底「幽渊」，布下「九天玄极封印」。
- **后世影响**：大战后灵脉崩碎大半，上古传承十不存一，太玄宗残部退守青峰山脚逐渐没落；七宗其余派系分化为正道盟、散修盟等势力；幽魔族封印随时间松动，魔气溢出滋生妖邪与邪修，是贯穿全剧的终极危机。
- **核心悬念**：正史记载七宗合力抗魔，实则暗藏隐秘——封印代价、玄极天尊下落、太玄宗快速没落真相，随历史尘封，待玩家逐步揭开（见 §16.3 卷四颠覆性真相）。

## 16.1.3 当世势力格局
承接上古战后分化，对应全局五大阵营（taxonomy 见 §11.26 / §11.27.5，faction_id 已映射，npc_config 已落位）：
1. **玄洲正道盟**（`fz_zhengdao`）：继承上古七宗正统，除魔卫道；内部派系林立，部分高层知晓上古秘辛，对太玄宗传承既忌惮又想拉拢。关键 NPC：玄清真人（`npc_zq001`）、苏晚（`npc_zq003`）。
2. **散修同盟会**（`fz_zhongli`）：战后散修抱团，逍遥自在，掌握大量野史秘闻与上古遗迹线索，是玩家获取剧情信息的重要渠道。关键 NPC：酒剑仙（`npc_zl001`）、胡不归（`npc_zl002`）。
3. **丹器师公会**（`fz_danqi`）：中立技术势力，传承上古丹器技艺，守护部分上古阵法 / 傀儡图纸，知晓部分封印相关技术细节。关键 NPC：墨玄丹尊（`npc_dq001`）、欧冶石（`npc_dq002`）。
4. **玄幽魔宗**（`fz_mo`）：信奉幽魔族的邪修势力，以解封幽渊、迎接魔族回归为目标，是前中期直接反派。关键 NPC：血影魔尊（`npc_mo001`）、厉锋（`npc_mo003`）。
5. **万灵古族**（`fz_yaozu`）：隐居南疆的上古族群，身具灵兽血脉，曾在大战中辅助太玄宗布防，是封印真相的活见证者，世代守护南疆封印节点。关键 NPC：青鸾圣姑（`npc_yz001`）。

> 注：远古遗泽（`fz_yuan`）按 §11.26.6 TODO-③ 暂缓，不在主线五卷核心博弈版图内，留作后期扩展。

## 16.2 玩家宗门起源

## 16.2.1 宗门根基：太玄宗残脉
玩家所继承的「青峰观」，实为上古太玄宗外门山门旧址。
- **鼎盛时期**：太玄宗以青峰山脉为山门，主峰设内门，外围青峰观为外门弟子居所，统御千里灵脉。
- **没落过程**：大战后宗门主力尽毁，传承断层，残存弟子守外门旧址苟延，沦为凡间小道观，后人不知祖上曾是玄洲顶级大宗。
- **玩家身份**：老掌门临终前将破败青峰观托付于你，以重振宗门为初始目标，逐步发现祖上辉煌与尘封使命。

## 16.2.2 情感锚点设定
两个陪伴型核心 NPC 贯穿全剧情，承载情感代入（已落 `npc_config.csv`，`faction_id=neutral`，见 §16.7 集成裁决）：
1. **苏清禾**（`npc_sec001`）：老掌门孙女，筑基修为，温柔坚韧，精通内务与丹道；开局与玩家同守破败宗门，负责日常事务与剧情引导；太玄宗血脉直系后人，后期解锁自身家族剧情线（联动 §6.16 家族血脉传承）。
2. **吴伯**（`npc_sec002`）：宗门老执事，练气后期，亲历宗门没落，知晓部分残缺宗门历史，前期剧情信息提供者，对玩家忠心耿耿，代表老一代传承与期盼。

## 16.2.3 开局剧情钩子
老掌门病逝前，留下半块「玄极令」与遗言：「守住山门，待令符合一，玄洲浩劫将至，太玄一脉，责无旁贷。」
- **玄极令**：太玄宗宗主信物，共两半，另一半藏于宗门秘境深处（§16.3 卷二节点 2 获取），合二为一可解锁上古传承与封印权限。
- **遗言作用**：既是初始目标（重振宗门），也埋下终极悬念（浩劫将至、太玄责任），让玩家从「为生存经营宗门」逐步转向「为使命承担责任」。

> 玄极令已转为**数据驱动**：任务追踪 / 合成判定由 `config/quest_item.csv` 承载（实体与合成机制规范见 §16.2.4），不再依赖剧情层硬编码。合成完成的信物本体置 `unlock_event=ml_xuanji_united` 主线旗标，由主线推进系统消费（工程域），解锁卷三+「上古传承 / 封印权限」相关节点。

## 16.2.4 玄极令实体与合成机制（quest_item 配置）

**实体定位**：玄极令为太玄宗宗主信物，分「左残片」（开局·苏清禾托付）与「右残片」（卷二·玄灵秘境三层·玄灵守将掉落）两枚碎片，于秘境核心石台合成「玄极令」本体。由叙事 MacGuffin 转为 `config/quest_item.csv` 数据驱动，承载任务追踪与合成判定。

**配置 schema（quest_item.csv，10 列）**
| 字段 | 含义 | 取值 / 规则 |
|---|---|---|
| item_id | 主键 | 唯一，如 `q_xuanji` / `q_xuanji_frag_l` / `q_xuanji_frag_r` |
| item_name | 显示名 | 玄极令 / 玄极令·残片（左）/ 玄极令·残片（右） |
| item_class | 类别 | 枚举 `主线信物`（合成本体）/ `任务碎片`（合成组件） |
| combine_group | 合成组 | 同组碎片 + 本体共享，如 `grp_xuanji` |
| combine_target_id | 合成目标 | 碎片→本体 item_id；本体留空 |
| fragment_total | 所需碎片数 | 本体=该组碎片总数（玄极令=2）；碎片=0 |
| obtain_hint | 获取线索 | 叙事文案（开局托付 / 秘境获取），仅展示用 |
| unlock_event | 合成完成旗标 | 本体合成后置主线旗标（如 `ml_xuanji_united`），碎片留空 |
| related_volume | 归属卷 | 来源卷标记（vol1 / vol2），追踪用 |
| is_counted_in_balance | 经济计入 | 恒 `false`（剧情信物非经济资源） |

**合成判定（工程域，数据由本配置驱动）**
- 任务追踪：同 `combine_group` 下 `item_class=任务碎片` 且 `combine_target_id` 指向本体的碎片，集齐 `fragment_total` 枚即满足合成条件。
- 合成触发：在卷二秘境核心石台（§16.3 节点 2）播放合一动画（示例 2）+ 残影留言，置 `unlock_event` 旗标。
- 旗标消费：卷三青鸾圣姑（`npc_yz001`）认令、卷四玄清真人（`npc_zq001`）索令、终局封印权限，均读取该旗标；未合成前这些节点不解锁（门控）。

**边界与失败态**
- 重复获取碎片：同一碎片不可二次掉落（掉落表仅挂一次），防溢出。
- 提前合成：卷二前仅持左残片，合成 UI 不可点（门控前置未达成）。
- 旗标幂等：合成仅触发一次，重复进入石台不重复置旗 / 不重复发奖励。

**校验约束（csv_validator.gd + validate_all.py 镜像）**
- 单行：item_class 枚举、fragment_total≥0、is_counted_in_balance∈{true,false}。
- 关系：① 同 `combine_group` 内「任务碎片」数 == 对应「主线信物」的 `fragment_total`；② 每枚碎片的 `combine_target_id` 必须指向存在的「主线信物」行。违反即报错。

## 16.3 主线剧情五卷完整脉络
主线与玩家成长阶段深度绑定，每一卷对应一个大境界周期，剧情节点同步解锁对应玩法系统（「玩法推进 = 剧情推进」）。

**卷一：青峰立宗（练气期 → 筑基期）**
- 核心目标：接手破败宗门，解决生存危机，站稳脚跟，初步接触宗门历史。
- 对应玩法：基础建筑解锁、弟子招募、一阶灵田、青峰山麓历练（§11.27.3 map_config）。
- 关键节点：
  1. 托孤继位（§16.4 示例 1）：老掌门病逝，玩家接掌门位，立重振誓言，开启基础经营。
  2. 首徒入山：宗门起色后第一名弟子慕名而来，触发首次邪修骚扰，玩家指挥弟子击退，站稳脚跟。
  3. 筑基启阵：培养出第一名筑基弟子，聚灵阵意外激活，显露地下秘境入口线索（苏清禾古籍发现「青峰之下，藏有玄门」）。
- 卷末解锁：玄灵秘境玩法（secret_config `secret_001`）、宗门阵法系统（§11.16 / spirit_array_config）。

**卷二：秘境遗踪（筑基期 → 金丹期）**
- 核心目标：探索宗门地下秘境，发现太玄宗传承，确认宗门身份，获第一波上古遗产。
- 对应玩法：玄灵秘境、装备体系、功法体系、阵营初步接触。
- 关键节点：
  1. 秘境初入：带队进入玄灵秘境（3 层），遭遇守阵傀儡与残存禁制，石碑「太玄外门秘境」字样首次印证上古身份。
  2. 玄极令半块：秘境三层击败守将玄灵守将，获另一半玄极令；令牌合一触发玄极天尊残影留言（§16.4 示例 2），首次抛出终极危机（幽渊封印松动）。
  3. 正道来访：秘境异动引来正道盟，传令使苏晚（`npc_zq003`）登门试探，玩家可选择交好 / 中立 / 敷衍，初步影响正道盟声望。
- 卷末解锁：金煌秘境（`secret_002`）、阵营声望系统（§11.26.2）、玄洲大地图（§11.10.2）。

**卷三：玄洲扬名（金丹期 → 元婴期）**
- 核心目标：宗门跻身玄洲主流势力，深度参与阵营博弈，接触更多上古线索，拼凑历史真相。
- 对应玩法：全地图历练、阵营任务、宗门战、丹器 / 灵兽 / 傀儡高阶系统。
- 关键节点：
  1. 四方会盟：正道盟举办玄洲宗门大会，玩家与各阵营 NPC 正式交锋，获取上古大战零散信息。
  2. 魔宗发难：玄幽魔宗针对玩家宗门破坏灵脉、刺杀弟子、抢夺资源，玩家发现魔宗在破坏封印节点，意图解封幽渊。
  3. 古族会晤：玩家前往南疆寻找封印线索，青鸾圣姑（`npc_yz001`）认出玄极令，告知大战真相（太玄宗非单纯胜利，封印非永久）。
- 卷末解锁：太虚秘境（`secret_003`）、宗门战（§11.4）、高阶阵营权益。

**卷四：上古秘辛（元婴期 → 化神期）**
- 核心目标：揭开上古大战全部真相，明确自身使命，整合各方势力，准备应对浩劫。
- 对应玩法：上古战场秘境、跨阵营合作、终极养成线。
- 关键节点：
  1. 战魂遗迹：进入上古战场秘境（`secret_004`），见战魂魔尊残影，得知颠覆性真相——上古之战非幽魔族主动入侵，而是玄洲修士为求飞升破界主动引来魔族，玄极天尊亦为破界参与者之一。
  2. 正道隐秘：正道盟高层（玄清真人 `npc_zq001`）得知玩家知晓真相，试图拉拢 + 威逼，要求封存真相、交出玄极令；玩家可选择妥协 / 对抗 / 虚与委蛇，阵营关系重大转折。
  3. 天尊传承：集齐线索，于太玄宗主峰旧址开启核心传承，见玄极天尊完整残魂，忏悔过错，授修为与封印之法，嘱玩家弥补过错、守护玄洲。
- 卷末解锁：跨阵营联合玩法、终极副本、化神突破剧情（§11.8.11）。

**卷五：浩劫重临（化神期及以后）**
- 核心目标：统领玄洲势力对抗幽魔族，修复封印，决定玄洲最终走向，长线终局目标。
- 对应玩法：跨服宗门战（§11.4 扩展）、终极 BOSS、多结局系统 `[PLACEHOLDER]`。
- 核心分支结局（终局 `[PLACEHOLDER]`，详见 §16.7 TODO）：
  1. **守序结局**：联合正道修复九天玄极封印，永久镇压幽魔族，太玄宗成玄洲新领袖。
  2. **逍遥结局**：联合散修与古族另辟蹊径封闭幽渊通道，代价是灵脉进一步衰退、再无飞升，但永世和平。
  3. **霸道结局**：吸收魔族力量以魔制魔，一统玄洲，成魔道共主，亦正亦邪。
  4. **飞升结局**：借封印之力以玄极令为引破开飞升通道，率核心弟子飞升，留宗门传承守护玄洲。

## 16.4 关键节点剧情文案示例

**示例 1：开局・托孤继位（旁白 + 对话）**
【旁白】青峰山脉的秋风吹过破败的山门，老掌门的灵堂设在大殿中央，香火寥落。你站在阶下，看着眼前只剩三两个人的小道观，想起半月前老人躺在床上攥着你手的模样。

## 16.6.6 捏脸 - 剧情连贯性保障（五层机制，合并去重提案重复段）
通过「叙事嵌入 → 文案泛化 → 成长绑定 → 视觉统一 → 兜底机制」五层闭环，确保捏脸服务代入感、绝不割裂主线：
1. **叙事层全嵌入**：所有塑颜均有剧情触发点（开局继位前整仪容由苏清禾引出；大境界突破脱胎换骨顺势解锁；重大活动前可主动整理仪容），前后均有 NPC 对话承接。
2. **文案层泛化**：主线涉及掌门外貌的描述全部使用气质 / 气度 / 神态类通用词（「气度沉凝」「神色坚毅」），禁用具体五官词（「高鼻梁」「丹凤眼」「皮肤白皙」），从根源避免与捏脸冲突。
3. **成长层强绑定**：捏脸解锁进度 = 主线境界推进进度；关键剧情事件触发临时容貌反馈（重伤面色苍白、渡劫衣衫破损、获传承周身微光），随剧情自动恢复。
4. **视觉层全同步**：所有出现掌门形象的场景 100% 调用捏脸数据实时渲染（立绘 / 对话头像 / 剧情演出 / 宗门战 / 阵营交互）；关键 CG 优先远景 / 背影 / 侧影，必须露脸时直接调捏脸模型。
5. **兜底层机制**：敏感词与违和名称拦截重命名；气质仅轻微影响 NPC 初始语气（温润更亲近、冷峻更恭敬），绝不改变主线走向 / 数值 / 核心分支；极少量彩蛋对话（如与某 NPC 眉眼相似）不牵扯核心剧情。
