## §1 画布与坐标基准

| 项 | 值 | 说明 |
|---|---|---|
| 逻辑分辨率 | **480 × 854** | 竖屏；原点左上；**x 向右为正，y 向下为正** |
| 左右安全边距 | **各 12px** | 内容区 x ∈ [12, 468]，内容宽 = 456（见 §0 #2 偏差提示） |
| 顶部状态栏高 | **48px** | y ∈ [0, 48]（见 §0 #3 偏差提示） |
| 底部 Tab 栏高 | **80px** | y ∈ [774, 854]，顶边 y=774（见 §0 #4 偏差提示） |

| 中心呼吸区（红线条） | x ∈ [144, 336]，y ∈ [299, 555] | = 横向 30%–70% × 纵向 35%–65%；**禁放无衬底高对比文字**（见 §7） |
| 坐标单位 | px | 所有 x/y/w/h 均为逻辑像素，小白直接照填 `position` / `size` 或 anchor offset |

> **锚定约定（Godot）**：根节点用 `Control`（Full Rect，480×854）。顶栏 `PRESET_TOP_WIDE`；底 Tab `PRESET_BOTTOM_WIDE`；内容区用 `ScrollContainer` 锚定「上=48 / 下=-80 / 左=0 / 右=0」。

## §2 层级与 z 序（背景三层 + 屋顶蒙版 + UI）

严格遵循 `UI硬性约束规范.md` §2.1 的 z 序铁律（背景永远在 UI 之下，且 `mouse_filter = IGNORE`）：

```
[z=-100] ColorRect      墨青兜底底色（color.bg.page），FULL_RECT，IGNORE
   └ [z=-100] TextureRect  景 = home_bg_season_spring.png
                       STRETCH_KEEP_ASPECT_COVERED，modulate.a = 0.30，FULL_RECT，IGNORE
       └ [z=-99] ColorRect 暗罩 = #16221D @ alpha 0.50，FULL_RECT，IGNORE
           └ [z=-98] TextureRect/ColorRect  顶部渐变蒙版（y 0..180，上深下透明，α≈0.55），IGNORE  ← 压暗主殿屋顶
               └ [z≥0]  UI 根 Control（顶栏 / 内容 / 底 Tab 全部在此层之上）
```

- **背景三节点 + 渐变蒙版** 一律 `mouse_filter = IGNORE`，永不接收点击。
- 推荐把背景三节点挂入独立 `CanvasLayer(layer = -1)`，使任何后续 UI 在 z 序上必然在其上，杜绝「背景覆盖面板」。
- **顶部渐变蒙版**（对应任务书约束②）：覆盖 y[0,180]，竖直渐变（`#16221D` α0.55 → 透明），用于压暗主殿屋顶区，保证顶栏与上方内容可读。
- 弹窗遮罩（未来用）统一 `弹窗遮罩 #0E1714 @ 0.62`，不在本页范围。

## §6 「照着拖」操作清单（Godot 小白逐步）

1. **新建场景**：`场景 → 新建场景 → Control`（根），命名为 `宗门首页`。在检查器设 `Layout = Full Rect`，确认尺寸 **480×854**。
2. **放背景层**：
   - 加 `ColorRect`（命名 `BgBase`），`Layout=Full Rect`，`color = color.bg.page`，`mouse_filter=Ignore`，`z_index=-100`。
   - 加 `TextureRect`（命名 `BgScene`），`texture=res://art/backgrounds/home_bg_season_spring.png`，`Stretch Mode=Keep Aspect Covered`，`Layout=Full Rect`，`modulate.a=0.30`，`Ignore`，`z_index=-100`。
   - 加 `ColorRect`（命名 `BgMask`），`#16221D` `alpha=0.50`，`Full Rect`，`Ignore`，`z_index=-99`。
   - 加 `TextureRect`/`ColorRect`（命名 `RoofFade`），覆盖 y0..180、竖直渐变上深下透、`alpha≈0.55`、`Ignore`、`z_index=-98`。
   - （可选）把上述 4 个节点归入一个 `CanvasLayer(layer=-1)`，确保永远在 UI 下。
3. **放顶部状态栏**：
   - 加 `Control`（命名 `TopBar`），`Layout=Top Wide`，`Custom Minimum Size = (480,48)`。
   - 其内加 `ColorRect` 铺满作半透明底（`color.bg.immersive`）。
   - 加 `MarginContainer`（左/右 margin=16）→ `HBoxContainer`；左放 `Label`「太玄宗门录」(17px, title1)，右放 3 个 `HBoxContainer` 资源槽（各= `TextureRect`20×20 + `Label`16px accent）。
   - 底加 `ColorRect` 480×1 金色分隔线。
4. **放主内容区**：
   - 加 `ScrollContainer`（命名 `Content`），锚定 `上偏移=48 / 下偏移=-80 / 左=0 / 右=0`。
   - 其内加 `MarginContainer`（左/右=12，上/下=8）→ `VBoxContainer`（separation=8）。
   - 依次加 5 个 `Panel`（C1–C5），按 §3.2 坐标设 `position`/`size`，套用「墨青填充+暗金描边2px+圆角8」stylebox；每个 Panel 内放 `VBoxContainer` 与对应 `Label`/`HBoxContainer`/`TextureButton`。
   - **C3、C4 必须保留 Panel 衬底**（落在呼吸区）。
5. **放底部 5 Tab 栏**：
   - 加 `Control`（命名 `BottomTab`），`Layout=Bottom Wide`，`Custom Minimum Size=(480,80)`。
   - 其内加 `ColorRect` 近不透明底（`color.bg.page`@0.95）+ 顶部 1px 金色分隔线。
   - 加 `HBoxContainer` → 5 个 `VBoxContainer`（每个宽 96）：内放 `TextureButton`(图标 40×40) + `Label`(13px 名称)；选中态加 2px 金色下划线 `ColorRect`。
   - 5 个 Tab 图标按 §3.3 表填 `normal`/`selected` 路径（建筑=grid_jz 单张）。
6. **套主题 token**：所有 Label/Panel/Button 的颜色与字号**只引用 Theme token**（color.text.*、color.border.gold、color.bg.panel、font.size.*），不手写 hex；最终视觉以并行 Theme 任务产出的 `main_theme.tres` 为准（见 §0 #7）。
7. **自测红线**：对照 §7 勾选——中心呼吸区内无裸高对比文字、顶栏有屋顶蒙版、底 Tab 不压主体。

## §7 红线速查（醒目 · 不可违反）

> 🔴 **红线 1 — 中心呼吸区禁放无衬底高对比文字**
> 区域：**x ∈ [144, 336]，y ∈ [299, 555]**（横向 30%–70% × 纵向 35%–65%，亮度硬栅 ≤0.304）。
> 规则：该区**禁止**直接放置高对比文字于明亮背景上；文字须靠边/顶栏/底 Tab，或落在 **Panel 衬底**之上（本线框 C3/C4 已带 Panel）。
> 违反示例：在 x240,y427 的亮背景上直接写白色标题 → ❌。

> 🔴 **红线 2 — 顶栏重叠主殿屋顶须避让/蒙版**
> 顶部状态栏（y0–48）压到主殿屋顶；必须叠 **半透明渐变蒙版**（§2 屋顶渐变蒙版，y0–180 上深下透）或顶栏自带半透明深底，保证可读。裸顶栏直接压亮屋顶 → ❌。

> 🟢 **绿线 — 底部 Tab 栏安全**
> 验收结论：底部 Tab 栏压不到主体（前景岩石+迎客松在下），Tab 栏本身安全；只需保证 Tab 背景近不透明（@0.95）即可。
