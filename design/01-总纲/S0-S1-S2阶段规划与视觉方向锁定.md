# 一、UI 视觉方向锁定（2026-07-22 老大拍板）

## 1.1 核心方向

**优先采用「1 + 2」视觉语言**：
- **方向 1 · 主界面**：仙山、云雾、玉石面板、鎏金按钮
- **方向 2 · 角色详情**：白玉卡片、弟子属性、装备槽

**整体关键词**：
玉石面板、鎏金描边、青铜纹样、宣纸肌理、云雾仙气、古建木石、低饱和青黛色、暗金点缀、朱砂印章少量使用。

**气质**：高级、克制、古朴、东方幻想，同时保证 UI 信息可读。

## 1.2 推荐主色体系（已锁定）

| 类型 | 色名 | 色值 | 用途 |
| --- | --- | --- | --- |
| 主色 | 青黛 | `#6E8F88` | 主面板、按钮、导航 |
| 背景色 | 宣纸米白 | `#F4EFE3` | 浅色界面底 |
| 深色背景 | 墨青 | `#1E2B28` | 战斗、秘境、弹窗 |
| 强调色 | 暗金 | `#C8A86A` | 标题、按钮高光、边框 |
| 警示色 | 朱砂红 | `#B3423D` | 伤害、危险、提示 |
| 成功色 | 玉石绿 | `#8FBF9F` | 治疗、增益、完成 |
| 文字主色 | 墨黑 | `#2E2B28` | 正文 |
| 文字辅色 | 石灰 | `#7D7568` | 说明、次要信息 |

## 1.3 材质与组件规范

- **面板**：玉石半透明质感 + 宣纸纤维纹理 + 旧金描边 + 轻微浮雕边缘 + 底部极淡云纹/回纹。
- **按钮**：
  - 主按钮：暗金边框 + 青玉底
  - 次按钮：木石纹理 + 浅金描边
  - 危险按钮：朱砂红底 + 金色描边
- **字体**：标题用加粗古风黑体/宋黑；正文用清晰宋黑结合字体，不用毛笔字做正文。
- **图标**：扁平写实、古风器物感（玉佩、铜钱、卷轴、宝剑、丹瓶、符箓），线性描边 + 轻微质感，不建议 Q 版。

## 1.4 弹窗统一结构

```
顶部：鎏金标题栏
内容区：玉石/宣纸半透明面板
底部：按钮区
关闭：右上角小铜钱/朱砂印章按钮
```

推荐尺寸：

| 弹窗类型 | 宽度建议 | 高度建议 |
| --- | --- | --- |
| 详情弹窗 | 屏幕宽度 85% | 内容自适应 |
| 战斗日志 | 屏幕宽度 90% | 屏幕高度 60% |
| 角色详情 | 屏幕宽度 88% | 屏幕高度 70% |
| 确认弹窗 | 屏幕宽度 75% | 紧凑内容高度 |

## 1.6 明确不做（写进铁律防发散）

| 风格 | 原因 |
| --- | --- |
| 赛博朋克 | 与修仙题材冲突 |
| 过度霓虹 | 破坏古朴气质 |
| 全毛笔字正文 | 可读性差 |

| 纯玻璃拟态 | 缺少东方材质感 |
| 每个弹窗换风格 | 维护成本高、体验割裂 |

- 本方向锁定后，**旧文档中的风格基调、色卡、光效、立绘 Prompt 全部失效**，但以下章节仍有参考价值：
  - 模块化建模拆分架构（§1.1）
  - 装备外观槽位与差异化规则（§2.1~2.3）
  - 年龄段形变逻辑（§3）
  - 性能优化方案（§5）
  - AI 生产工作流方法（§8.3）
- **必须后续动作**：由 `art-director` 基于本方向重写美术圣经，替换色卡、材质、Prompt、风格关键词，版本号升级为 v2.0。

# 三、S0 阶段：核心闭环・已收口

**状态**：所有内容已落地、验收、过 **13 道 pre_f5 闸门**（原文档写「九道」，已随灵兽/弟子终局/彩蛋三类断言子进程扩容至 13）；S0 定义范围内的功能不再追加。

> **与代码现状对齐注记（2026-07-23 补）**：自本规划 07-22 立档后，工程在 S0 之上**前瞻叠做了部分 S1 域 P0 地基**——灵兽战斗生效（属性映射/战斗日志/头像标识）、弟子终局机制（资质天花板硬锁 + 寿元坐化闭环）、彩蛋第一批（配置底座 + 9 条彩蛋）。这些属按裁决提前启动的 S1 工作，**叠加于 S0 之上、非 S0 缺口**，不否定 S0 收口判定；§3.1–3.4 所列项全部仍在代码中且过闸。奇遇总数经实算为 203 条（普通74/优秀89/稀有30/传说10），与本文一致；`quest.gd` 头部注释「200则」为近似笔误，以本文 203 为准。彩蛋第一批为独立「边角填充」定位，不计入 S0/S1/S2 任一阶段。

## 3.1 核心经营循环

- 时间推演（240 秒 = 1 游戏日）
- 12 堂口（玩家可见称「建筑」）产出与负责人机制
- 资源体系：灵石、灵草、矿石、灵气
- 弟子招募、测灵根、修炼、突破、装备 9 槽、自动穿戴/一键最优
- 门派等级、声望、繁荣
- 存档读档 + 版本升级自动备份 + 坏档兜底

## 3.2 基础玩法模块

- 奇遇系统：203 条 event_quest，三档拆四档（普通/优秀/稀有/传说），传说硬上限 10 条，冷却与权重机制落地
- 坊市（商店）系统：周限购、声望折扣、宗门库房
- 随机事件/周常：月度概率 + 周刷新
- 日常任务：极简 3 条 + 一键领取 + 奖励缩放
- 历练：CSV 数据驱动节点关卡、战斗结算

## 3.3 UI / 交互 Phase A

- 详情弹窗统一外壳：`_new_detail_popup` + `_弹出物品详情` + `_弹出弟子属性弹窗`
- 多渠道关闭、品阶七档染色、入场动画、长内容滚动、快速点击防抖
- S1 预埋：`open_detail` / `open_detail_by_url` / `_解析实体` / `_attr_line_pool`
- 战斗日志 Phase A：字段 8→13（`log_type`/`tags`/`ref_*`）、RichTextLabel 分层渲染、标签自动映射、50 条折叠 + 展开/收起切换
- 规范文档：`ASSET-详情弹窗规范.md`、`ASSET-战斗视觉全规则手册.md`

## 3.4 视觉状态

- 纯代码 UI（灰模 + 水墨文字），无写实贴图。
- 新视觉方向**不属于 S0 已落地内容**，是 S1 视觉统一工作的输入。
