# 休闲玩法体系扩展设计（S46+ 储备）

> 设计铁则（沿用灵钓，全项目一致）：
> 1. **触屏优先**：单指手势（长按/拖拽/点按），禁 QTE、禁精准限时点按。
> 2. **丰富度**：每玩法 ≥3 品类分层，每物带详细说明（叙事 + 用途 + 履历）。
> 3. **周常活动**：挂现有「每日 08:00 刷新 / 周末」周期，规则轮换，奖励走威望/图录不暴灵石。
> 4. **进阶机制**：每玩法一个专属消耗品形成 source→sink 闭环，防免费产出通胀。
> 5. **复用**：图录 / 秘境 / 占卜 / 灵兽 / 坊市 / NPC / 功勋堂(S28) / 弟子情感(S30) 一律复用，禁新建重复系统。
> 6. **数值**：占比、概率、奖励量、次数上限一律 `[PLACEHOLDER · 待实机调]`。

## 一、探遗迹（解谜 / 破阵参悟）

**Fun Hypothesis**：在战斗之外提供「动脑不动手」的破阵参悟，收集上古遗珍、反哺功法/突破材，零失败惩罚。

**触屏交互**：单指拖拽「引灵连线」连通阵眼、点按点亮残碑、拖拽卦象入位。无时间窗硬判定，只有「灵机紊乱需重参」软约束。

**四分层产出（对标灵钓四层）**

| 类别 | 修真命名 | 示例 | 价值 | 占比 rationale |
|---|---|---|---|---|
| 天材地宝 | 遗迹生灵/地脉 | 玄晶、地乳、残玉 | 入库房→丹/器/突破 | ~35% 主产 |
| 残破遗物 | 凡尘旧物 | 碎陶、锈器、残简 | 卖店微量/分解，0 实用 | ~45% 衬托稀有 |
| 上古奇物 | 红尘遗珍 | 会语之磬、浮空灯 | 0 实用，图录收录+叙事 | ~12% 收集 |
| 遗迹秘藏 | 玄古秘匣 | 低几率开功法残篇/突破材/灵石 | 低几率高价值 | **[PLACEHOLDER] 0.5%–1.5%** |

**数值维度**：品阶 / 五行 / 灵韵 / 年代 / 阵法难度 / 残损度。

**图录**：复用 `收藏图录`，加「遗迹」类，首次获得自动 `_记录图录`。

**周常·遗迹探秘周**：规则池（周序 mod N 抽 1–2）：① 集齐残卷 N 卷 ② 最古遗存排行（年代）③ 品类齐全度 ④ 秘藏开启数 ⑤ 阵法难度积分。奖励走功勋堂威望 + 限定图录边框。

**进阶·破阵符 / 引灵香**（消耗品，sink 闭环）：
- 破阵符：降低阵法难度（手感友好）。
- 引灵香：提高遗迹秘藏几率。
- 获取：NPC 守遗迹散修 + 坊市上架（复用双入口范式）。

**复用系统**：`已通关秘境` 存档结构（新增「探秘型」子类型）、`收藏图录`、`Item` 消耗品范式（同 S45 符箓）。

## 二、饲灵育兽

**Fun Hypothesis**：慢养成 + 收集驱动，灵兽从幼崽养成战力/产材/坐骑，亲密度给情感反馈。

**触屏交互**：单指拖拽喂食、点按抚摸、长按蓄力驯养。禁连点。

**四分层产出**

| 类别 | 命名 | 示例 | 价值 |
|---|---|---|---|
| 灵兽产出 | 妖兽材/坐骑 | 兽牙、鳞、鞍 | 主产→丹/器/骑乘 |
| 幼兽/变异种 | 灵兽异种 | 双尾狐、赤羽鹰 | 收集+战力变异 |
| 兽魂 | 驯化结晶 | 兽魂珠 | 进阶突破材 |
| 灵兽奇遇蛋 | 孵卵秘匣 | 低几率孵稀有 | **[PLACEHOLDER]** |

**数值维度**：资质 / 成长 / 亲密度 / 战力 / 五行 / 变异概率。

**图录**：复用「灵兽志」（既有灵兽系统应已有志）。

**周常·育兽评比 / 灵兽斗**：评比（资质/亲密度排行）或擂台（战力，零死亡惩罚），奖励威望 + 限定兽栏皮肤。

**进阶·灵兽嗜好食 / 驯养鞭**（sink）：

**复用系统**：既有灵兽系统 + 喂养动作、`收藏图录`(灵兽志)、`Item` 消耗品。

## 六·补、灵钓钓具三件套与钓道境界（基础模板补充）

> 灵钓为其余玩法之模板；其钓具不止灵饵，须「杆+线+饵」三槽 + 钓道境界等级进阶，严格修真化。

**钓具三槽**
- **灵杆**：抛竿距离（深水域才出稀有）+ 张力带宽度（容错）+ 承力上限（最大重量，低杆配重渊饵会断线）。
- **灵线**：张力耐受（超安全值多久崩断）+ 泄力 drag（鱼挣扎张力升速放缓）+ 断线率。
- **灵饵**：引灵/聚宝/五行/稳绪/重渊 5 类（影响钓到什么）。

**钓道境界（灵钓等级，修真化命名，独立成长线）**
- 境界阶：初窥 → 小成 → 大成 → 圆满 → 通玄（意象对应练气→元婴+，但独立升级）。
- 获取：钓获次数 / 图录收录种类 / 大赛名次 / 首钓龙鲤（大额）。
- 软门控：主角境界低则深处灵渊未开，钓道境界有上限（实力决定能去哪）。

**钓具四阶（接装备品阶体系 凡灵宝仙，每阶杆+线+饵配套 + 套装加成）**

| 阶 | 钓道境界门槛 | 灵杆 | 灵线 | 灵饵 | 解锁水域 | 可钓 |
|---|---|---|---|---|---|---|
| 凡器 | 初窥(Lv1) | 青竹竿 | 麻纶线 | 凡饵 | 浅滩灵池 | 凡鱼 |
| 灵器 | 小成 | 灵木竿 | 灵丝线 | 灵饵 | 灵渊中层 | 灵鱼 |
| 宝器 | 大成 | 玄铁竿 | 蛟筋线 | 宝饵 | 灵渊深处 | 灵兽鱼/龙鲤苗 |
| 仙器 | 圆满/通玄 | 太虚竿 | 虚空丝 | 仙饵 | 虚空灵渊 | 龙鲤/仙鳞 |

- **套装加成**：同阶杆+线+饵集齐 → 额外钓获质量/稀有率加成（鼓励集齐）。
- **进阶获取**：NPC 渔隐 + 坊市成品；灵材强化升阶（消耗库房灵材）。
- **存档**：`Game.钓具配置 = {阶, 杆品阶, 线品阶, 饵}` + 钓道境界等级，经游戏存档 `to_dict` 持久化（复用存档框架，禁新建）。
- 数值（各阶阈值/强化所需灵材/套装幅度/水域解锁条件）全 `[PLACEHOLDER]`。

## 六·补二、休闲玩法解锁时机与形式（推荐方案）

**结论**：常驻玩法**全开**（按成长里程碑渐进解锁入口），周常活动**轮换**（规则/主题周轮换）。既非纯全开也非纯轮换，而是「常驻常开 + 周期活动轮换」。

**解锁形式（接现有系统，修真化包装）**

| 玩法 | 解锁载体 | 修真包装 | 建议门槛(PLACEHOLDER) |
|---|---|---|---|
| 灵钓 | 灵渊 | 开辟灵渊，引灵脉之水 | 开局/练气（最轻量，首个休闲） |
| 卜算 | 观星台 | 筑观星台，夜观天象 | 练气末/筑基 |
| 药圃 | 灵田 | 辟灵田，引地脉 | 筑基/首殿阁 |
| 饲灵 | 育兽栏 | 拓育兽栏 | 筑基 |
| 探遗迹 | 秘境(探秘子型) | 秘境现世，入而参悟 | 金丹/秘境开放 |
| 论道 | 论道台 | 立论道台 | 金丹/宗门规模 |

**周常轮换**：灵钓大赛 / 遗迹探秘周 / 育兽评比 / 观星大会 / 灵植博览 / 论道大会 轮流挂周末，规则 pool 周轮换（呼应各玩法周常设计）。

**为什么不全开/不纯轮换**：全开则高级内容过早暴露、稀释主线且缺资源支撑；纯轮换则日常缺休闲出口、收集追求无日常落点。常开+轮换兼顾「日常憩息」与「周期峰值」。数值门槛全 `[PLACEHOLDER]`。

## 七、统一通胀控制红线（B10）

- 所有「产出型」休闲均经 **每日/每周次数上限** + **稀有概率压低** 节流。
- 进阶消耗品（破阵符/嗜好食/星盘玉/灵肥/棋谱…）是核心 sink：灵石→买耗品→休闲产材→回流库房→灵石再循环。
- 周常奖励**只走威望/图录边框/称号**，不直接暴灵石。
- 宝匣/秘匣类高价值物全进既有 sink（丹/器/功法残篇/突破材），不游离。
