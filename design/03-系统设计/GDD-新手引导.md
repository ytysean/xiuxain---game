# 《太玄宗门录》新手引导系统设计

> 版本：v1.0 ｜ 来源：2026-07-18 用户投稿底稿（见 `design/03-系统设计/_inbox/2026-07-18_投稿_新手引导与风云榜.md` §18 归位整理）｜ 用途：新手引导系统开发依据
> 体系对齐：主线世界观剧情、宗门 / 弟子 / 秘境 / 交易全系统、成就体系、境界成长线（`design/01-总纲/太玄宗门录_核心设定总览.md`）。
> 全局红线：正文统一使用正式名《太玄宗门录》；严禁在数值 / 配置 / 正文出现对外宣传名；全部数值保留整数，未做"优化"改写；本系统依赖但 design/ 暂无 GDD 的系统见 §六。

## 一、定位与原则

新手引导系统是《太玄宗门录》新手期体验的核心保障，设计原则为「以宗门传承指引为核心，由苏清禾、吴伯等原生 NPC 承载全部引导内容，完全融入开局剧情，无生硬系统弹窗」；采用「阶段解锁 + 分层提示 + 全链路兜底」结构，既保证新手快速上手，又不干扰自由探索，同时杜绝卡关、迷茫、误操作等劝退点。

对齐标准：主线世界观剧情 ｜ 宗门 / 弟子 / 秘境 / 交易全系统 ｜ 成就体系 ｜ 境界成长线。

核心原则：

1. **剧情推进 = 功能解锁**：所有功能解锁严格绑定「主线剧情节点 + 境界成长 + 宗门等级」，解锁节奏与玩家成长完全同频，绝不超前投放功能；每个阶段由对应 NPC 承接引导，剧情推进即功能解锁，无缝衔接。
2. **NPC 承载，人设统一**：全部引导台词、提示文案均由苏清禾、吴伯、各阵营 NPC 输出，语气符合人物设定，绝不出现统一的"系统音"或生硬弹窗。
3. **可跳过、不强制**：除序章强引导支持一键跳过外，后续引导均为非强制；玩家可自主探索，遇到新功能自动触发提示，老玩家 / 熟悉品类玩家可直接跳过全部序章引导。

## 二、分阶段功能解锁指引

所有功能解锁严格绑定「主线剧情节点 + 境界成长 + 宗门等级」，解锁节奏与玩家成长完全同频；每个阶段由对应 NPC 承接引导，剧情推进 = 功能解锁，无缝衔接。

### 2.1 阶段总览

| 阶段名称 | 对应成长周期 | 预计时长 | 核心解锁内容 | 引导 NPC |
|---|---|---|---|---|
| 序章・继位入门 | 练气初期 | 0~10 分钟 | 角色创建、宗门定名、主界面认知、基础灵田 | 苏清禾 + 吴伯 |
| 第一章・山门初建 | 练气中期 | 10~30 分钟 | 弟子招募、丹房炼制、历练战斗、坊市基础 | 苏清禾（内务）+ 吴伯（外事） |
| 第二章・宗门运转 | 练气后期 | 30~60 分钟 | 器堂锻造、聚灵阵、成就系统、背包分解、日常任务 | 吴伯 + 苏清禾 |
| 第三章・筑基启秘 | 筑基期（卷二开启） | 对应主线推进 | 玄灵秘境、阵营系统、基础商路、护山阵 | 苏清禾 + 对应阵营 NPC |
| 第四章・金丹扬名 | 金丹期（卷三开启） | 对应主线推进 | 宗门战、全商路、1v1 论剑、高阶阵营权益 | 各阵营 NPC 登门拜访 |

### 2.2 序章・继位入门（0~10 分钟，练气初期）

- **触发条件**：玩家首次进入游戏，承接老掌门托孤剧情。
- **核心目标**：完成角色自定义，熟悉主界面，掌握最基础的经营循环。
- **引导规则**：
  1. **剧情承接引导**：开局播放继位剧情，依次弹出捏脸界面、掌门命名界面、宗门定名界面，全程由苏清禾的台词承接，每一步都有对应的剧情文案说明，而非凭空弹出系统窗口。定名完成后，苏清禾引导玩家点击大殿匾额，确认宗门名生效，同步解锁第一个成就「初入仙途」。
  2. **主界面认知引导**：苏清禾依次高亮主界面核心区域：宗门大殿、灵田入口、弟子入口、任务面板，每处配 1-2 句说明，点击后高亮自动跳到下一处。引导玩家点击「灵田」，完成第一次灵田建造，随后引导收获第一波灵草，让玩家快速体验「投入 → 产出」的正向循环。
  3. **收尾与过渡**：首次收获后，触发吴伯汇报："掌门，灵田收成不错，咱们总算有第一笔家底了。接下来可以招募弟子，把宗门撑起来。"阶段收尾目标：建成 1 级灵田，收获首波灵草，达成首个成就，解锁弟子招募功能。
- **引导形式**：全程强制光圈高亮 + NPC 对话，支持一键跳过，老玩家 / 熟悉品类的玩家可直接跳过全部序章引导。

### 2.3 第一章・山门初建（10~30 分钟，练气中期）

- **触发条件**：灵田升至 2 级，宗门等级达到 1 级。
- **核心目标**：掌握弟子管理、基础生产、基础战斗三大核心玩法。
- **引导规则**：
  1. **弟子系统引导**：吴伯引导玩家前往「弟子招募」，讲解弟子灵根、职业、资质的基础规则，引导招募第一名弟子；招募完成后，引导玩家安排弟子前往灵田劳作，演示「弟子劳作 → 产出提升」的逻辑。
  2. **丹房与炼制引导**：苏清禾提议建造丹房，引导玩家完成丹房建造，随后演示「放入材料 → 开始炼制 → 收取丹药」的完整流程，炼制出第一炉聚气丹；同步引导玩家给弟子使用丹药，体验属性提升的效果。
  3. **历练与战斗引导**：吴伯提醒："山下青峰山脚有妖兽作乱，正好可以让弟子前去历练，积攒经验还能捡回材料。"引导玩家进入历练地图，演示战斗基础操作、五行克制规则、奖励结算，首次战斗自动播放，玩家可围观学习。
  4. **坊市基础引导**：引导玩家前往坊市，演示出售多余灵草、购买基础材料的操作，讲解基础买卖规则，同步提示回购栏的存在。
- **引导形式**：光圈高亮 + NPC 气泡提示，每完成一个模块自动解锁下一个，不强制连续引导；玩家可中途退出，后续通过红点提示继续完成。

### 2.4 第二章・宗门运转（30~60 分钟，练气后期）

- **触发条件**：第一名弟子达到练气圆满 / 宗门升至 2 级。
- **核心目标**：掌握完整经营循环，熟悉辅助系统，建立日常玩法习惯。
- **引导规则**：
  1. **器堂锻造引导**：解锁器堂时弹出气泡提示，吴伯讲解锻造规则，引导锻造第一件凡品装备，演示装备穿戴与属性加成；同步引导「装备分解」功能，说明无用装备的回收路径。
  2. **聚灵阵引导**：苏清禾提示聚灵阵升级，讲解阵法对修炼速度的加成作用，引导升级到 2 级，演示生效后的收益变化。
  3. **成就与任务引导**：首次达成 3 个成就后，自动弹出提示："掌门，宗门成就阁已记录您的功绩，可前往领取奖励。"引导玩家进入成就界面，讲解点数里程碑与奖励规则；同步解锁日常任务面板，说明每日任务的刷新与奖励，引导玩家形成每日清任务的习惯。
  4. **背包与基础操作补全**：背包道具数量达到阈值时，引导玩家使用筛选、排序、批量出售功能，讲解道具类型与用途。
- **引导形式**：红点标记 + 气泡说明，点击后弹出功能介绍，全部为非强制引导；玩家可自主探索，遇到新功能自动触发提示。

### 2.5 第三章・筑基启秘（筑基期，卷二主线开启）

- **触发条件**：第一名弟子突破筑基 / 玄灵秘境解锁。
- **核心目标**：解锁中高阶玩法，接触阵营与社交，推进主线剧情。
- **引导规则**：
  1. **秘境探索引导**：伴随秘境开启的剧情演出，苏清禾讲解秘境规则、层数与 BOSS 机制，引导首次进入玄灵秘境；秘境中遇到机关、宝箱、精英怪时，弹出简短提示，讲解对应玩法，不打断探索节奏。
  2. **阵营系统引导**：正道盟传令使苏晚登门剧情触发，同步解锁阵营界面，讲解声望等级、阵营任务、阵营商店规则；引导玩家接取第一个阵营任务，完成首次声望获取。（苏晚为**新增 NPC，待 lore 角色表确认 / 补建**，详见 §六 C-N3。）
  3. **基础商路引导**：解锁青峰商路时，吴伯讲解商路玩法，引导首次派遣商队，演示收益结算与劫道事件处理。
  4. **护山阵引导**：提示护山大阵解锁，讲解宗门防守规则，引导升级到 1 级。
- **引导形式**：剧情节点自然引出，配合 NPC 对话与功能说明弹窗，剧情与引导完全融合，无割裂感。

### 2.6 第四章・金丹扬名（金丹期，卷三主线开启）

- **触发条件**：第一名弟子突破金丹 / 宗门升至 4 级。
- **核心目标**：解锁长线玩法与 PVP 内容，明确终局目标。
- **引导规则**：
  1. **宗门战引导**：解锁宗门战时弹出规则说明，引导首次匹配参战，讲解胜负规则与奖励。
  2. **全商路解锁**：伴随地图开放，逐步解锁黑风、南疆、西漠商路，每解锁一条弹出对应玩法与收益说明。
  3. **论剑 PVP 引导**：解锁 1v1 论剑时，讲解段位、匹配、赛季奖励规则，引导首次匹配。
  4. **长线目标提示**：弹出玄洲大地图与主线进度，明确后续成长方向，引导玩家选择阵营倾向与发展路线。
- **引导形式**：里程碑式气泡提示，附详细规则说明，玩家可自主选择是否深入了解，不强制引导。

## 三、分层交互提示体系

采用「强引导 → 中引导 → 弱引导 → 可回溯」四级分层机制，既保证首次操作有指引，又避免日常游戏被频繁打扰，兼顾新手友好与老玩家体验。层级越高强制性越强、覆盖功能越核心；层级越低越轻量化、越尊重玩家自主探索。全程没有"系统提示"的生硬感，所有提示都来自宗门内部的指引与典籍。

### 3.1 四级提示规则（强引导 → 中引导 → 弱引导 → 可回溯）

| 提示层级 | 修仙化命名 | 触发场景 | 表现形式 | 消除 / 跳过规则 | 示例 |
|---|---|---|---|---|---|
| 一级强引导 | 宗门亲传指引 | 首次解锁核心功能、开局关键操作、主线必过节点 | 屏幕光圈高亮目标区域 + 苏清禾 / 吴伯对话气泡 + 下一步箭头指引；玩家必须点击目标区域才能推进 | 支持「一键跳过全部引导」，仅首次触发，跳过直接解锁对应功能 | 开局灵田建造、首次炼制丹药、首次进入历练 |
| 二级中引导 | 山门传讯提醒 | 新功能解锁、有可领取奖励、活动开启、成就达成 | 入口红点标记 + 悬浮气泡提示（NPC 头像 + 简短文字）；点击进入对应界面后红点消失 | 非强制，查看即消除；奖励类红点必须领取后才消除 | 新建筑解锁、成就可领取、限时活动开启 |
| 三级弱引导 | 典籍注解提示 | 复杂功能、属性规则、玩法详情 | 按钮旁「?」图标，点击 / 悬停弹出文字说明；说明采用古籍注解风格，附带修仙设定 | 常驻不消失，主动查看才显示，不主动打扰玩家 | 灵根属性说明、五行克制规则、阵法效果详情 |
| 四级回溯引导 | 入门心法总览 | 玩家主动回看教程、遗忘规则时 | 藏书阁「入门指引」分类，按系统整理图文说明，附带 NPC 讲解语音 | 永久可查阅，随时翻阅，支持按系统搜索 | 弟子培养指南、商路玩法详解、阵营规则说明 |

### 3.2 红点机制规范

红点是二级（中）引导的核心载体，严格遵循「不滥用、分优先级、可一键清理」原则，杜绝红点焦虑。

| 红点类型 | 优先级 | 消除规则 | 展示位置 |
|---|---|---|---|
| 奖励类红点 | 最高 | 必须手动领取奖励后才消除 | 主界面直接显示数字角标 |
| 新内容类红点 | 中等 | 点击进入对应界面即消除，无需完成全部内容 | 对应功能入口显示红点 |
| 提示类红点 | 最低 | 查看一次自动消除，24 小时后自动消失 | 仅进入对应界面时显示 |

- **红点聚合展示**：主界面仅展示最高优先级的红点总数，细分红点进入对应功能后再展示，避免主界面密密麻麻全是红点。
- **一键清理功能**：设置「全部已读」按钮，可一键消除所有非奖励类红点，满足不想被打扰的玩家需求；奖励类红点不可一键清理，避免玩家遗漏收益。

### 3.3 智能个性化提示「掌门小贴士」

主界面侧边常设「掌门小贴士」栏，基于玩家当前状态推送场景化提示，不弹窗打扰，玩家可主动查看，替代生硬的通用引导：

- **资源短缺提示**：灵石不足时提示「掌门灵石紧张，可前往坊市出售多余灵草换取灵石」，附带快捷跳转按钮。
- **弟子闲置提示**：有弟子长时间闲置时提示「还有弟子处于闲置状态，可安排前往丹房效力」。
- **成长瓶颈提示**：弟子卡境界多日时提示「弟子修为已满，可尝试使用突破丹冲击更高境界」。
- **活动收尾提示**：限时活动即将结束时提示「XX 活动还有 2 天结束，别忘了领取档位奖励」。

### 3.4 交互体验细节原则

1. **不打断操作**：除一级强引导外，所有提示均不阻塞玩家当前操作，弹窗、气泡均支持后台加载。
2. **老玩家减负**：创建角色时可选择「熟悉修仙品类，跳过新手引导」，直接解锁全部基础功能，仅保留红点提示。
3. **逐步释放**：引导内容随玩家进度逐步放出，不一次性全部堆给玩家，避免信息过载。
4. **反馈即时**：操作完成后立即给出结果反馈（成功特效、奖励弹窗、数值变化），强化正向感知。

## 四、异常兜底方案

围绕新手期最容易劝退的「迷茫、卡关、误操作、系统故障」四大类问题，建立「目标 → 资源 → 操作 → 系统 → 专属保护」五层兜底机制，从规则上杜绝劝退点，所有兜底均有修仙化包装，不破坏世界观沉浸感。

### 4.1 目标兜底：永远有明确的下一步

解决玩家「不知道做什么、往哪发展」的核心迷茫问题，全程目标清晰。

- **常驻「当前目标」面板**（主界面左侧）：分三类展示——
  - 主线目标：当前阶段核心剧情目标，如「培养第一名筑基弟子」，附带进度条与推荐路径；
  - 日常目标：当日推荐完成的操作，如「完成 3 次历练、炼制 5 炉丹药」，自动同步每日任务进度；
  - 推荐操作：根据玩家当前资源、弟子状态智能推荐最优成长方向。
- **成长路线图（宗门传承图）**：解锁「宗门传承图」功能，可视化展示从练气到化神的完整成长线，每个阶段的解锁内容、核心目标、对应奖励一目了然，玩家可随时查看长期目标。
- **卡进度主动问询**：玩家超过 30 分钟无核心成长推进时，苏清禾会主动触发对话：「掌门，眼下宗门可以往 XX 方向发展，要不要去看看？」，附带快捷跳转按钮，温和引导不强制。

### 4.2 资源兜底：新手期不卡资源、不卡关

避免玩家因资源短缺、战斗失败无法推进主线，保障基础成长节奏。

- **宗门储备・七日补给**：新手前 7 天，每日登录发放「宗门储备补给」，包含灵石、基础材料、修炼丹药、体力药水，量级覆盖当日基础成长需求，绝不会出现无资源升级的死局。
- **突破保底・护心丹效果**：
  - 首次大境界突破失败，返还 50% 消耗材料，同时邮件补发 1 颗对应品级的突破丹；
  - 连续失败 2 次后，第三次突破成功率临时提升 10%（对应「护心丹稳心境」设定），避免连续挫败打击信心。
- **战斗护道・新手阵法**：
  - 前 3 次秘境 / 历练失败，怪物属性自动衰减 10% / 20% / 30%（对应「护山大阵护持新手弟子」设定），保证玩家最终能通关；
  - 失败后弹出苏清禾的分析提示，明确失败原因与提升方向（如「弟子装备不足，可前往器堂锻造」），附带快捷跳转。
- **紧缺自动补给・宗门应急库**：若玩家因核心资源不足，无法推进主线目标超过 24 小时，系统自动触发「宗门应急库」邮件，发放少量紧缺资源，同时附信说明该资源的常规获取路径，授人以渔。

### 4.3 操作兜底：误操作可挽回

针对新手手滑、误操作的高频场景，提供完整挽回路径，避免一次失误导致玩家弃游。

- **坊市回购・悔购栏**：出售给坊市的道具，可在「悔购栏」找回最近 10 件，24 小时内有效，回购价格等于出售价格，无任何损耗。
- **建造撤销・回心诀**：建筑升级、建造开始后的 1 分钟内，支持「撤销」操作，返还 100% 资源，对应「回心诀撤掉禁制」设定；超过 1 分钟则不可撤销。
- **分解找回・重炼炉**：误分解的装备、丹药，可在「重炼记录」中找回最近 5 件，24 小时内有效，返还全部对应材料。
- **关键操作二次确认・心魔警讯**：所有高价值、不可逆操作强制二次确认，包括：驱逐弟子、分解稀有装备、消耗大额灵石、退出宗门、解除联盟；确认弹窗采用「心魔警讯」修仙包装，明确标注风险后果。

### 4.4 系统异常兜底：故障不损失、可追溯

- **掉线重连・传讯续接**：战斗、历练、秘境、商路进行中掉线，重连后自动恢复到掉线前的进度，不扣除次数、不损失奖励；若战斗已结束，奖励自动发放到邮件，对应「传讯玉符自动续接」设定。
- **异常补发・天道补偿**：因系统 bug、服务器故障导致的奖励未到账、次数未刷新、进度丢失，后台核实后自动补发；全服范围故障发放全服「天道补偿」邮件，补偿力度不低于正常玩法收益。
- **数据备份・玉册留底**：玩家数据定时备份，出现严重数据异常时，可回滚到异常前的存档；所有关键操作全留痕，出现争议可追溯核查。

### 4.5 新手保护与防呆设计

- **免战护罩・山门禁制**：新手前 7 天自动开启「山门护罩」，不会被其他宗门发起宗门战、抢夺资源，安心发展基础。
- **新手增益・引气阵**：新手前 14 天，全体弟子修炼速度 + 20%，历练掉落 + 15%，帮助玩家快速跟上大部队节奏。
- **防呆交互・玉牌提示**：条件不足的按钮直接置灰，点击弹出友好提示（如「灵石不足，可前往坊市出售灵草获取」），永远附带解决路径，不说生硬的「操作失败」。

## 五、修仙化包装方法

核心原则是把所有引导功能转化为修仙世界的原生事物，让玩家感觉是「在宗门里接受传承、学习修仙」，而不是「在玩游戏、过教程」，从叙事、角色、剧情、术语、细节五个维度全面贴合。

### 5.1 叙事包装：所有引导功能都有修仙原生设定

绝不出现「新手教程」「系统提示」这类出戏表述，全部对应修仙世界里的合理事物：

| 游戏功能 | 修仙化包装 | 设定说明 |
|---|---|---|
| 新手引导 | 宗门传承指引 | 老掌门留下的宗门规制，由苏清禾、吴伯代为主持，教新掌门打理宗门 |
| 功能解锁 | 开启禁制 / 领悟传承 | 宗门建筑、阵法、秘境都有上古禁制，境界达标、剧情推进后逐步解锁 |
| 红点提示 | 山门传讯 | 弟子、访客、商队传来的消息，对应不同的事务提醒 |
| 玩法教程 | 宗门典籍 / 心得注解 | 藏书阁里的宗门古籍、前辈留下的修炼心得，记载各系统的规则 |
| 成就系统 | 宗门功勋碑 | 记录宗门与掌门的功绩，刻在功勋碑上，对应奖励与荣誉 |
| 阶段目标 | 宗门发展规划 | 历代掌门定下的发展路线，分阶段实现重振宗门的目标 |

### 5.2 角色承载：全引导由原生 NPC 承接，人设高度统一

所有引导台词、提示文案都由苏清禾、吴伯、各阵营 NPC 输出，不同系统对应不同的引导人，语气完全符合人物设定，绝不出现统一的系统音：

- **内务类玩法**（灵田、丹房、资源、弟子生活）：苏清禾引导，语气温柔细心，讲解细致。
- **外事 / 战斗类玩法**（历练、秘境、宗门战、商路）：吴伯引导，语气沉稳老道，经验丰富。
- **阵营类玩法**：对应阵营 NPC 首次登门时引导，符合各自阵营立场，如正道盟苏晚语气倨傲、散修胡不归语气豪爽。
- **高阶传承类玩法**：玄极天尊残影、秘境守护灵引导，语气悠远威严，符合上古传承设定。

> ⚠️ NPC 缺口（C-N3）：苏晚（正道盟传令使）、胡不归（散修）、玄极天尊残影、秘境守护灵均为**新增 NPC，待 lore 角色表确认 / 补建**，本 GDD 仅按投稿口径引用，不擅自补全人设设定。详见 `GDD-风云榜.md` §十一 CONCERN-03。

### 5.3 剧情嵌入：引导节点 = 剧情节点，功能解锁伴随事件

所有新功能解锁都嵌入主线剧情，由剧情事件自然引出，绝不凭空弹出「恭喜解锁 XX 功能」：

- **丹房解锁**：对应「苏清禾整理古籍，发现祖传丹方，提议重开丹房」剧情，顺势引导玩家炼制第一炉丹药。
- **秘境解锁**：对应「聚灵阵异动，发现地下秘境入口」剧情，由吴伯佐证古籍记载，引导玩家首次探索。
- **阵营系统解锁**：对应「正道盟听闻秘境异动，派人登门探查」剧情，顺势引出阵营声望与阵营商店。
- **商路解锁**：对应「宗门站稳脚跟，山下城镇提议通商」事件，引导玩家开启第一趟商路。

### 5.4 术语统一：全链路使用修仙语境，消除游戏黑话

所有引导文案、提示、说明全部使用修仙术语，替换现代游戏黑话：

- 不说「升级」，说「突破境界 / 提升禁制等级」
- 不说「抽卡 / 招募」，说「收录弟子、广招门徒」
- 不说「体力」，说「灵气值、历练精力」
- 不说「任务」，说「宗门事务、师门嘱托」
- 不说「背包」，说「储物袋、储物戒」
- 不说「充值 / 付费」，说「供奉仙玉」

### 5.5 细节沉浸：用仪式感与成长感强化代入

- **继位仪式感**：开局定名、继位、更换匾额都有完整动画与仪式流程，让玩家从一开始就进入「掌门」身份，而非单纯开新号。
- **突破祝贺感**：弟子每次突破大境界，全宗门触发祝贺事件，苏清禾、吴伯上门道喜，对应宗门小庆典，强化成长仪式感。
- **古籍伏笔呼应**：引导中提到的宗门历史、古籍记载，都会在后续主线剧情中得到印证，如开局提到的玄极令、太玄宗传说，在秘境剧情中一一对应，让引导本身就是世界观的一部分。
- **门派定制化**：玩家自定义的宗门名、掌门名，会出现在所有引导文案、典籍、牌匾、NPC 对话中，全程自洽，强化专属感。
