## 设计方案（修真世界观）

### 核心设定
丹方不是一开始就全部知道的，需要通过各种方式领悟：

| 领悟方式 | 触发条件 | 修真世界观解释 |
|---|---|---|
| **师承传授** | 新档自动领悟3个基础丹方 | 入门时师父传授基础丹方 |
| **炼丹反推** | 炼制某丹后，概率领悟更高阶同类丹方 | 炼得多了，对药性理解加深，触类旁通 |
| **随机顿悟** | 每次炼丹成功1%概率触发，随机领悟 | 丹炉霞光万道，于炼丹中顿悟 |

### 丹方三态
- **未领悟**：显示"???"，灰色不可点击，看不到材料
- **已领悟**：完整显示，可炼制
- （领悟中状态暂未实现，后续可加进度条）

### 初始领悟丹方
新档自动领悟3个凡品基础丹方：
- juqi（聚气丹方）
- ip_002（养元丹·凡品）
- ip_006（清毒丹·凡品）

### 反推领悟概率
- 基础概率：凡品5% → 灵品4% → 宝品3% → 王品2% → 圣品1.5% → 仙品1% → 道品0.5%
- 加成：丹堂等级+5%/级，每炼制10次+1%
- 上限：30%，下限：0.5%
- 领悟范围：当前境界+2品阶以内的未领悟丹方

### 随机顿悟
- 每次炼丹成功1%概率触发
- 领悟范围：当前境界+3品阶以内的未领悟丹方
