## 3. 信息架构
```
任务
├ 日常差事（section）
│  ├ 采集灵草（目标+奖励+领取[可领]）
│  ├ 巡守山门（目标+奖励+领取[已领·灰锁]）
│  └ 讲经授道（目标+奖励+领取[可领]）
└ 周常差事（section）
   └ 秘境探幽（目标+奖励+领取[可领]）
```

## 4. 交互规则
- **领取日常**：点击 `35:247/259` → emit `任务领取完成` → `Game.领取日常(序号)` → 刷新（按钮转「已领取」灰锁）。
- **领取周常**：点击 `35:266` → `Game.领取周常()` → 刷新。
- **三态按钮**：可领（金底 `#C8A86A` 黑字）/ 已领（灰底 `#182D37` 灰字·disabled）/ 锁定（未来引导未达成时灰锁，样式同已领）。
- 领取同时按 `page_quest.gd` 加战令经验（日常+20 / 周常+60，[PLACEHOLDER]）。
