# ACCESSIBILITY · 可访问性分级与特性矩阵（赛博国风·形赛博魂传统）

> 版本：v1.0 ｜ 域：美术 / 技术美术 / 可访问性 ｜ 阶段：Phase 4 收口

## 1. 分级定义（Basic / Standard / Comprehensive）

| 分级 | 定位 | 默认档 | 目标用户 |
| --- | --- | --- | --- |
| **Basic** | 最低合规基线 | 关 | 极低端设备 / 极端性能受限；仅保证信息可读、操作可达 |
| **Standard**（推荐默认） | 均衡体验 | 开（标准） | 绝大多数玩家；色盲辅助 + 动效可选 + 字号下限 + 一键简化 |
| **Comprehensive** | 完整无障碍 | 开（增强） | 视障/色盲/动效敏感/前庭敏感/精细动作受限用户；全特性开启 |

> 设置项结构：①「高品质动效」三档（极简/标准/关闭，引 §15.4）②「一键简化模式」总开关 ③「增强可访问性」子项（高对比/文本缩放/字幕/重映射/震动开关）。

---

## 2. 小屏字号下限（竖屏 480×854 逻辑分辨率）

| 文本类型 | 最小字号（逻辑 px） | 说明 |
| --- | --- | --- |
| 正文 / 数值 / 描述 | **15px** | 480 宽下可读底线；DPR≥2 真机等效 30px 物理，清晰 |
| 标签 / 角标 / 品质名 | 13px（仅辅助信息） | 关键信息不得仅用 13px 承载 |
| 标题 / 关键反馈（战力 delta/克制系数） | 16–18px Bold | 强调可读 |
| 最小可点击目标 | 44×44 px（Apple HIG 基线） | 所有按钮/槽位触摸区 ≥ 44px（含内边距） |

- 文本缩放：支持 100%–150% 无破版（竖屏安全区内 reflow，不截断）；缩放影响上述下限的实际上屏尺寸。
- 禁用艺术字体于数值/道具说明（§15.4 五·绝对禁忌）。

## 3. 色盲友好（不只靠颜色区分）

> 核心原则：品质 / 五行 / 职业 / 敌我 的判定**必须叠加 ≥1 种非颜色冗余编码**（形状 / 纹理 / 文字标签）。

| 维度 | 颜色（基线） | 冗余编码（形状/纹理/文字） | 来源 |
| --- | --- | --- | --- |
| 装备品质（7 阶） | csv_validator.gd `VALID_GRADES` 色卡（凡品→道品） | 边框纹样差异（素框/符文/云纹/宝石/流光/数据流/双纹）+ 品质名文字 + 词条角标数 | ASSET-装备穿戴 §2/§3/§5 |
| 奇遇稀有度（3 档） | 灰/金/紫 | 角标形状（方/圆/菱形）+ 文字标签（普通/稀有/传说） | ASSET-奇遇弹窗 §2/§9 |
| 五行（金木水火土） | 五色微光 | 唯一字形（金木水火土）+ 唯一形状（◈/▲/~/▲/▭）+ 文字标签 | ASSET-战斗 §2 |
| 三职业（道/体/法） | 青霓/鎏金/蓝紫 | 图形语言（飞剑盾/拳山/八卦）+ 文字标签 | ASSET-战斗 §3 |
| 敌我（玩家/敌方血条） | 青霓绿/朱砂红 | 文字标签（气血/战力）+ 位置（左己右敌）+ 形状（盾形己/尖角敌） | ASSET-战斗 §1 |
| 克制关系 | 青霓箭头 + 朱砂「克」字 | 「克」字 + ▲20%/▼20% 箭头形状 + 战斗日志文字回显 | ASSET-战斗 §4 |

- 红系歧义消解：火橙 `#EC6A3C` vs 朱砂警示 `#E05A4C` 靠形状（焰▲）+ 标签区分，不单纯依赖色相。
- 建议额外纹理：低饱和档（凡品灰/灵品白）文字加深色描边，确保深墨灰底上对比度 ≥ 4.5:1（AA）。

## 4. 对比度约束

- 文本/背景对比度 ≥ **4.5:1**（WCAG AA 普通文本）；大文本（≥18px 或 14px Bold）≥ **3:1**。
- 霓虹发光/模糊**不得**降低主体文字可读性——发光仅用于边框/背景层，文字层保持实色高对比。
- 底色恒定深墨灰 `#14161C` / 面板 `#1B1E26`，亮色（白/浅绿/湛蓝/亮金）文字须满足上表对比度；不满足时加描边或降亮度。

## 5. 动效敏感降级（引 §15.4 七·性能约束 + 可开关三档）

| 档位 | 行为 |
| --- | --- |
| 极简 | 关全部循环/流光/呼吸/全屏闪白/微震；仅保留必要位移/淡入淡出（或无动画瞬切） |
| 标准 | 常驻氛围/流光/呼吸按 §15.4 运行（锁 30fps、边缘重绘、GPU 合成） |
| 关闭 | 等同极简，且入场/点击/转场用瞬切，无过渡 |

- **系统 reduce-motion**：检测到 OS 级「减弱动态效果」时，自动映射至「极简」档（不依赖玩家手动设置）。
- **震动（线性马达）**：独立开关（前庭/触觉敏感用户可关）；传说奇遇微震、点击轻震均受此开关约束。
- 所有发光/流光/呼吸降级为静态角标（对齐 §15.4 降级开关），仅保留识别信息。

---

## 6. 一键简化模式

- 单一开关，开启后同时：① 高品质动效→极简 ② 字号 +1 级（或默认 130% 缩放）③ 启用高对比主题 ④ 关背景氛围（全息八卦/祥云虚影/数据云雾）⑤ 关震动。
- 目标：认知负荷高/老年/低视力用户一键获得最清晰稳定界面，不丢失任何功能信息。

## 8. 与 UX 流程对齐要求（给 design-lead）

1. **UX 规格必须引用本分级**：所有交互流程文档在可访问性章节标注所遵循的分级（默认 Standard），不得自行定义新的无障碍规则。
2. **新手引导遮罩/高亮（handoff 可选项）**须满足：高亮区对比度 ≥ 4.5:1、遮罩半透明不阻读、高亮元素 ≥ 44px 触摸目标、动效受降级开关约束。
3. **信息架构**须保证色盲用户在无颜色输入下仍可完成核心循环（品质/五行/职业/敌我均有形状+文字冗余，见 §3）。

## 9. 工程实现备注（待 eng-lead 确认）

1. 纯代码 Control UI 下：文本缩放需布局 reflow（非简单 scale，避免模糊）；高对比主题需主题变量切换（非重绘资源）。
2. reduce-motion 监听：Godot 4.7 需通过 OS 接口或引擎设置读取，映射到「极简」档。
3. 触摸目标 44px、字号下限须在布局代码强制约束，防止美术资源压缩导致破版。
