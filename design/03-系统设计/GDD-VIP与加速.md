# 《太玄宗门录》VIP 与加速系统设计（分阶段落地，v2.9 新增）

设计定位：VIP 与战斗加速是套在核心玩法外壳上的「权限判断 + 数值倍率 + 奖励发放」层，本质是商业化与体验优化，不进入核心数值体系。分阶段落地节奏严格对应项目里程碑——核心数值（声望经济 / 修炼周期 / 丹毒平衡）未定型前不做任何权益实装，避免后期全推翻返工。

## 12.1 分阶段开发节奏（对应项目里程碑）
- 第一阶段：当前 MVP 开发期（核心玩法落地前）——只做「接口预留」，不写具体功能逻辑
  - game_state.gd 全局存档预留 `vip_level`、`vip_exp` 两字段，默认 0 级，存档同步读写 [PLACEHOLDER]。
  - 通用工具方法 `is_vip_unlock(level: int) -> bool`，后续所有 VIP 权限判断统一走此接口，禁止各处硬编码。
  - 战斗系统底层留 `speed_multiplier` 参数，默认 1.0，不做任何倍速逻辑，仅占位。
  - 不现在做全量的原因：声望经济 / 修炼周期 / 丹毒平衡仍在纸面模拟，VIP 权益高度绑定「产出节奏、消耗缺口、玩家痛点」，核心数值一调 VIP 价值即失衡，返工成本极高。
- 第二阶段：Beta 测试前（核心玩法全落地、数值初版定型）——优先做「加速战斗」，搭好 VIP 基础框架
  - 加速战斗全量实装：放置游戏基础体验功能，优先级高于 VIP 付费；先免费 2 倍速，再接 VIP 解锁更高倍速钩子。
  - VIP 基础框架落地：等级经验表、充值对应经验、升级奖励发放、基础权益生效；权益仅做「无数值影响的便利类」（背包扩容、招募额外次数、每日免费礼包），不碰任何战力 / 修炼速度类加成。
- 第三阶段：上线前调优期（有测试留存数据后）——补全 VIP 高阶权益，调平衡
  - 按测试数据补高价值权益：如玩家普遍卡丹毒 → 加 VIP 每日免费洗髓；嫌历练慢 → 加 VIP 历练加速。
  - 开放高阶 VIP 专属外观 / 专属播报 / 跳过战斗等特权；接入 TapTap 内购 SDK，做支付流程。
- 第四阶段：上线后版本迭代——新增 VIP 专属玩法、限定内容
  - VIP 专属灵兽、专属建筑皮肤、限定弟子名号、月度 VIP 活动等，作为长线商业化补充。

## 12.2 为什么早期不建议做完整 VIP 系统
- 数值返工成本极高：VIP 核心价值完全绑定核心产出节奏（修炼加速值取决于正常修炼周期、额外秘境次数值取决于掉落与升级缺口、丹毒清除特权值取决于丹毒惩罚强度）；核心数值每动一次，VIP 性价比全部重算，早做等于白做。
- 容易带偏核心设计：提前把氪金系统做进去，设计玩法时易不自觉「为卖 VIP 故意恶心玩家」（放慢修炼、卡背包、加繁琐操作倒逼氪金），直接毁掉放置修仙核心乐趣；TapTap 用户对「逼氪」容忍度极低，易口碑崩盘。
- 架构上完全没必要前置：VIP 本质是「权限判断 + 数值倍率 + 奖励发放」，是套在核心玩法外的壳；核心系统做好后加 VIP 只需加判断、加倍率，一周可完；核心未做好先做 VIP 无用且拖慢进度。

## 12.3 VIP 权益设计原则（不碰数值红线）
对接第 4 章红线（25% 通用增益封顶 / 道心 10% 独立乘区）：VIP 绝对不碰直接战力 / 属性加成，全程走「便利、加速、扩容、外观」路线，既不破坏平衡又有付费价值。
- 绝对不能做的红线：直接增加弟子属性 / 战力 / 突破率 / 道心值；提供专属超模装备 / 丹药（突破数值体系）；解锁专属强战力弟子（破坏招募平衡）。
- 数值增益特权上限：所有涉及数值增益的特权，全部计入通用增益乘区、遵守 25% 封顶，且 VIP 单独占比不超过 5% [PLACEHOLDER]。
- 推荐权益方向（贴合现有系统）：

| 权益类型 | 具体内容 | 适配 VIP 等级 | 对核心数值影响 |
| --- | --- | --- | --- |
| 战斗加速 | 2 倍 / 3 倍 / 4 倍战斗速度、碾压局跳过战斗 | 低 - 中 | 无，仅加速播放 |
| 时间加速 | 修炼速度 +10%/20%、历练冷却缩短、建筑升级加速 | 中 - 高 | 仅加速周期，不提升最终数值，不突破乘区 |
| 额外次数 | 每日招募刷新 +N 次、秘境额外次数、试炼塔重置、洗髓池次数 | 低 - 中 | 仅增加机会，不改变单次结果 |
| 功能便利 | 自动收取奖励、批量遣散弟子、批量炼丹炼器、离线收益上限提升 | 低 - 中 | 纯便利，无数值影响 |
| 容量扩容 | 弟子上限 +、灵兽栏位 +、背包容量 +、仓库扩容 | 中 - 高 | 仅扩容，不提升单角色强度 |
| 每日福利 | 每日领取灵石、贡献、基础丹药、清毒丹 | 全等级 | 产出占日常产出 ≤20% [PLACEHOLDER]，不破坏经济 |
| 外观专属 | 专属弟子边框、建筑皮肤、头像框、稀有播报特效、宗门铭牌 | 高 | 纯外观，无数值影响 |
| 专属玩法 | VIP 专属历练地图、月度 VIP 专属奇遇池 | 高 | 专属内容，不影响主生态平衡 |

## 12.4 加速战斗功能落地建议
- 档位设计（免费 + VIP 分层）：

| 档位 | 解锁条件 | 效果 |
| --- | --- | --- |
| 1 倍速 | 默认 | 原始速度 |
| 2 倍速 | 免费（灵品宗门解锁） | 战斗播放 2 倍速 |
| 3 倍速 | VIP3 | 战斗播放 3 倍速 |
| 4 倍速 | VIP6 | 战斗播放 4 倍速 |
| 跳过战斗 | 战力超敌 200% 免费跳；VIP5 降为 150% | 直接出结算结果 |

- 实现原则：
  - 只加速播放，不改变结算逻辑：倍速仅加快动画播放速度，战斗判定 / 伤害计算 / 概率事件完全与 1 倍速一致，避免「倍速掉率不一样」恶性 bug。
  - 全玩法通用：试炼塔 / 宗门战 / 秘境战斗 / 历练遭遇战全部复用同一套倍速逻辑，不单独做。
  - 挂机推演（非战斗时间流逝）的加速，单独做「全局修炼加速」特权，与战斗倍速分开，避免数值混乱。
