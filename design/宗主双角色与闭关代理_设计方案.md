## 〇、一句话 Fun Hypothesis

> **这个游戏好玩的核心是：玩家同时经营"一个门派的百年兴衰"和"一个修士的一生修行"，而这两件事抢夺同一份时间和资源。**

双角色的价值不在"多了个角色"，在于**制造取舍**：宗主闭关则门派无人理政，宗主理政则修为停滞。没有这个张力，就只是多了一个按钮。

## 一、Design Pillars（不可妥协的四条）

| # | 支柱 | 判据（不满足就是设计失败） |
|---|---|---|
| **P1** | **下线不是惩罚，是闭关** | 玩家下线 8 小时后回来，感觉"赚了"，而不是"亏了" |
| **P2** | **时间流速不一致要被叙事合理化** | 离线大步推进、在线精细操作，玩家心智里不觉得是 bug |
| **P3** | **代理质量可见、可培养** | 玩家能说出"我的副宗主不擅长外交"这种话 |
| **P4** | **宗主会死，但死得有价值** | 传位是一次高潮，不是一次挫败 |

## 三、核心循环（三层）

### 3.1 Moment-to-moment（0–30 秒）：在线 = 理政
玩家在宗主管理页 19 个 Tab 里的核心动作循环：
**看请示/奏折 → 做选择 → 立刻看到门派数值变化 → 下一个**

现有现成内容（**不需要新做**）：
- `弟子请示` / `宗主批阅` / `奏折决策` 三个 Tab
- 奏折数据结构已完备：`{提议人, 事由, 选项, 重大性, 日}`（:7615）
- `议事会` Tab

**新增决策点**：每份奏折同时显示「宗主亲自处理」vs「交副宗主处理」两个按钮 —— 前者效果好但消耗宗主精力，后者效果取决于副宗主能力。**这就是双角色的 moment-to-moment 落点**。

### 3.2 Session loop（5–30 分钟）：上线一次的完整节奏
```
① 出关结算（若上次闭关）→ ② 消化积压（请示/奏折/纪事）
→ ③ 门派经营（任命/建造/历练派遣）→ ④ 宗主修行（修炼/突破/闭关设定）→ ⑤ 设定方针 → 下线
```
第 ⑤ 步是本方案的**仪式感出口**：玩家主动设定方针 = 主动授权代理，心理上完成"这次上线结束了"。

### 3.3 Long-term（数周–数月）
- **宗主成长线**：练气→…→渡劫，与弟子共用一套 `Disciple` 逻辑（复用，不重写）
- **传承线**：宗主寿终/战死 → 传位 → `_传承事件`(:12356) 已有钩子
- **门派线**：12 殿阁升级、领地、王朝、正魔大战（均已生效）

## 四、系统架构（四块）

### A. 宗主实体（SectMaster）

**决策：宗主复用 `Disciple` 类，不新建类。**
理由：修炼/突破/渡劫/心魔/命格全部现成，重写等于把已验证的逻辑推倒重来。

| 项 | 设计 | rationale |
|---|---|---|
| 载体 | `Game.宗主: Disciple`（新增持久字段） | 复用 disciple.gd 全部成长逻辑 |
| 兼容 | 旧档迁移：`宗主名/性别/头像` → 生成默认宗主（境界=金丹） | 不升 SAVE_VERSION，缺字段时懒迁移 |
| 差异点 | 宗主 `不参与` 弟子列表、不受俸禄/差事/派遣影响 | 避免污染既有弟子系统 |
| 独有属性 | `精力`（见 C）、`威望`（影响政令效果）、`寿元`（见 B） | 制造与弟子不同的资源维度 |

**新增玩家决策**：宗主每日有限的**精力**如何分配（亲自理政 / 修行 / 闭关）——这是双角色的核心张力来源。

### B. 闭关系统（Seclusion）

闭关 = **下线的叙事包装 + 长周期成长**，解决 P1/P2。

| 输入 | 输出 | 边界 |
|---|---|---|
| 闭关时长档位（短/中/长 = 1/3/7 现实日 [PLACEHOLDER]）、灵气预付、方针配置 | 宗主修为/瓶颈打磨/神通解锁；门派按方针自动运转 | 闭关中不可主动操作宗主；可被「重大奏折」打断（见 `奏折敏感度`） |

**核心机制三条**：
1. **闭关期间时间流速与在线一致**（离线 1 现实日 = 360 游戏日，与在线相同）—— 这直接治好"离线 1/30"，且**叙事上合理**：闭关本就该"洞中方一日"。
2. **闭关产出 = 在线操作的 1.2~1.5 倍效率** [PLACEHOLDER]，但**无决策收益**（不出奇遇、不处理奏折、不响应危机）。
   → rationale：让"在线精细操作"始终优于"离线挂机"，但离线不亏。挂机游戏的老规矩：挂机是保底，不是最优解。
3. **提前出关**需付出代价（损失已投入灵气的 50% + 心魔 +5）[PLACEHOLDER] —— 制造"闭关前想清楚"的决策重量。

**宗主寿命平衡（老大明确要求）**：
- 问题：时间流速 360 游戏日/现实天，若宗主金丹（寿元 500 年）→ 500 现实天 ≈ 1.4 年才传位，玩家很难体验到传承。
- 方案：宗主寿元 = 境界寿元 × **掌门系数 0.3** [PLACEHOLDER]，金丹 ≈ 150 年 ≈ 5 个月现实时间。
  → rationale：目标是让玩家在**建立情感连接之后、腻之前**（约 3–6 个月）遇到第一次传承抉择。
- 寿命**可被消耗与延长**：闭关冲刺/渡劫/负伤/心魔 → 减寿；延寿丹/秘境/神通 → 加寿。
  → **把寿命从"倒计时"变成"资源"**，玩家有决策权，这才不挫败（P4）。

### C. 管理者层级（代理链）

现状已有 12 殿阁负责人。升级为三级链：

```
宗主
 └─ 副宗主（1 名）  ← 新增：代管理政、离线期间的最高裁决者
     └─ 堂主/长老（3–5 名）  ← 新增：分管 战/政/商 三条线
         └─ 殿阁负责人（12 名）  ← 已有：司职负责人存档
```

**每级管理者的能力维度**（决定是否值得培养）：
`政务` / `战力` / `威望` / `忠诚` / `派系`

**管理者质量如何真的影响结果**（这是 C 的关键，否则只是换皮）：

| 场景 | 低能力管理者 | 高能力管理者 |
|---|---|---|
| 离线期间奏折 | 按方针默认选项执行，效果 -30% | 按最优解执行，效果 100%，偶尔超预期 |
| 危机（兽潮/宣战） | 损失放大 1.5 倍 | 损失 -40%，可能反杀 |
| 弟子忠诚 | 每月 -1 | 每月 +0.5 |
| 贪腐/结党（负面） | 概率触发，中饱私囊 | 低概率，且可被"戒律裁决"处置 |

**新增玩家决策**：任命谁当副宗主（能力强 vs 忠诚高 vs 派系平衡）——这是**人事政治**玩点，与现有「宗门派系」Tab 天然咬合。

### D. 方针执行引擎（离线代理）

**直接复用现有 `Game.方针`**（:76），不新建配置。需要补的是「执行器」：

| 方针键 | 现有值 | 离线执行逻辑（需新增） |
|---|---|---|
| `历练.自动派遣` | false | 按 `风险偏好` + `目标掉落表` 自动派遣历练（复用 ExpeditionSystem） |
| `供给.丹药自动炼制` | false | 库存 < `丹药囤积线` 时自动炼制（复用 alchemy_forge_system） |
| `供给.装备自动锻造` | false | 同上（复用 forge） |
| `建造.自动升级` | false | 按 `优先殿阁` 顺序升级，灵石留安全线 |
| `外交.阵营姿态` | "均衡" | 影响离线期间外交事件判定 |
| `奏折敏感度` | "仅重大" | **决定什么会打断闭关通知玩家** ← 这是 P1 的关键开关 |
| `修炼.风格` | "均衡" | 弟子离线修炼风格（已有 `_修炼风格乘区()`） |

**关键设计**：`奏折敏感度` 三档（仅重大 / 含中等 / 全部），决定玩家会不会被频繁叫回来。
→ rationale：这是**唯一的"打扰频率"开关**，直接决定玩家愿不愿意闭关。默认「仅重大」保护玩家时间。

## 十、失败信号定义（playtest 前先写，否则等于没做）

| 信号 | 表现 | 判为 |
|---|---|---|
| **A** | 玩家从不主动闭关，或闭关后觉得亏 | 闭关收益不足 / 错过内容焦虑 → 调高离线产出或增加"闭关专属奖励" |
| **B** | 玩家闭关后再也不上线（因为没事干） | 在线理政内容不足 → 增加奏折/请示密度 |
| **C** | 玩家从不更换副宗主，或随便任命 | 管理者能力影响不可感知 → 拉大能力差距 / 增加反馈可见性 |
| **D** | 玩家对宗主传位感到愤怒 | 传承惩罚过重 → 提高延寿手段可得性，或提供"兵解传承"保底收益 |
| **E** | 灵气永远不够 / 永远用不完 | 闭关消耗定价错误 → 重新校准 |

## 十一、风险清单

1. **🔴 时间流 S1 是最大风险**：`推演一月` 内日频/月频口径混乱（本轮已查实 3 处矛盾），重构必须一次做完并单独验收。
2. **🔴 宗主进 `弟子列表` 会污染 12 个既有子系统** —— 必须显式排除。
3. **🟡 旧档兼容**：无宗主实体的旧档需懒迁移，不升 SAVE_VERSION（项目铁律）。
4. **🟡 月度内容 30 倍触发**（本轮发现的新 P0）：在线每游戏日跑一次月结。S1 必须一并修，否则经济数值全盘失真。
