## 一、现状总览

| 维度 | 现状 |
|---|---|
| 架构模式 | **六套并行样式来源，互相打架**：①设计令牌文档 v1.0（SSOT 纸面）②`ui_theme.gd`（Autoload，代码层常量+helper）③`ui_theme_config.gd`（Autoload，数据驱动色表）④`main_theme.tres`（项目基础主题）⑤`taixuan_theme.tres`（被 project.godot 挂为 `theme/custom`，墨绿旧调）⑥Ardot 设计稿（46 个独立 token） |
| 核心问题 | **项目级同时挂了两个色板冲突的 .tres**；代码层 8 阶品阶 vs 设计稿/新 SOP 7 阶；字体决策 4 方不一致（MaShanZheng / NotoSerifSC / LXGWWenKai / Source Han Sans）；散点硬编码色值遍布 .gd 与 .tscn |
| 分裂程度 | **高（HIGH）**。不是零散漂移，而是「项目级主题双挂 + 品阶阶数不一致 + 字体未收敛」三重结构性分裂 |

**一句话总结**：样式体系表面有「令牌文档→ui_theme.gd→main_theme.tres」三层理论闭环，但实际被 `taixuan_theme.tres` 的项目级 `theme/custom` 注入、8/7 阶品阶分叉、字体四方割据三处硬冲突击穿，且 Ardot 设计稿另起炉灶用了完全不同的色板与字体，整体离散度极高。

## 二、冲突清单（逐条标注文件+行号，含风险等级）

### 🔴 高（HIGH）— 结构性冲突，必须优先解决

**H1 · 项目级双主题并行（根因）**
- `project.godot:37` → `theme/custom="uid://cdacbo1s6f55c"`
- `project.godot:38` → `theme="res://theme/main_theme.tres"`
- `ui/themes/taixuan_theme.tres:1` → `uid="uid://cdacbo1s6f55c"`（即 taixuan_theme.tres 本身）
- 冲突：`main_theme.tres` 是暗青+鎏金（正确，对齐令牌文档）；`taixuan_theme.tres` 是墨绿青调（bg `Color(0.173,0.373,0.322)`=#2C5F52、gold `Color(0.784,0.659,0.416)`、字体 `LXGWWenKai-Regular.ttf`）。两者色板完全不兼容，且 `taixuan_theme.tres` 被作为 `theme/custom` 项目级生效，墨绿旧调会向下渗透所有未显式覆盖的控件。
- 风险：全项目基础观感可能被旧调覆盖，新界面与旧界面色板割裂。

**H2 · 品阶阶数分叉（8 阶 vs 7 阶）**
- 代码侧 8 阶：`ui_theme.gd:32-39`（fan/liang/ling/bao/wang/sheng/xian/dao 含**良品 liang**）、`ui_theme_config.gd:14-23`（QUALITY_COLOR 8 键含 liang）
- 设计文档 8 阶：`design/06-角色与UI/UI设计令牌v1.0.md §1.5`（含 tier.liang 良品）
- 设计稿/新 SOP 7 阶：Ardot 设计稿 tier-fan~tier-dao **无 liang**；用户 2026-08-08 SOP 明确「七阶凡/灵/宝/王/圣/仙/道，无良」
- 冲突：代码与令牌文档维持 8 阶，设计稿与新 SOP 为 7 阶。**直接后果**：背包/商店/装备槽的品阶色与边框在「有无良品」上分叉，且若新 SOP 为真，则 `liang` 成为孤儿阶，所有引用 `liang` 的取色（UIThemeConfig.get_quality_color("liang")）将悬空或复用旧值。
- 风险：品阶色体系全局不一致，商店/背包对齐 bug 的深层原因。

**H3 · 字体决策四方割据**
- `ui_theme.gd:83` `FONT_TITLE_PATH=".../MaShanZheng-Subset.ttf"`（毛笔楷体）
- `ui_theme.gd:84` `FONT_BODY_PATH=".../NotoSerifSC-Subset.otf"`（宋体）
- `ui/themes/taixuan_theme.tres:3` `LXGWWenKai-Regular.ttf`（霞鹜文楷）
- `MEMORY.md`（2026-08-06 定稿）全局字体已重锁 **Source Han Sans CN（思源黑体）**，`ui_theme.gd::FONT_TITLE_PATH/FONT_BODY_PATH` 应改指 `SourceHanSansCN-Regular.otf`
- Ardot 设计稿字体：**Source Han Sans CN**
- 冲突：`ui_theme.gd` 仍指向旧 MaShanZheng/NotoSerifSC，未同步 2026-08-06 的思源黑体决策；`taixuan_theme.tres` 用第三套；设计稿用第四套。四方不一致。
- 风险：实机字体与"全局唯一字体"红线冲突，且 `ui_theme.gd` 是 STALE（未按最新决策更新）。

## 三、合并方案（单 Theme 权威 + 全量 Token 常量化）

### 3.1 总体架构（落地后）
```
project.godot
  └─ theme = "res://theme/main_theme.tres"   （唯一项目级主题，删除 theme/custom）
       └─ 仅放原生控件基础样式（StyleBox + 默认文字色），来源于令牌文档
ui_theme.gd  (Autoload: UITheme)
  └─ 字体 helper + 图标(ICON_BY_LABEL) + 间距/圆角/尺寸常量 + 动态色 getter
       └─ 色值常量统一从 UIThemeConfig 取（不再自留 Color 浮点常量）
ui_theme_config.gd  (Autoload: UIThemeConfig)
  └─ 以令牌 ID 为键的色值表（COLOR 浮点常量 → 改为引用令牌 hex，或直接消费令牌文档值）
设计文档 UI设计令牌v1.0.md
  └─ 唯一定稿数据源（修正 7 阶 + 思源黑体后）
Ardot 设计稿
  └─ 作为视觉参考；落地时其色板/字体/阶数向上述权威对齐（不反向改代码）
```

### 3.2 保留 / 废弃
| 项 | 处置 |
|---|---|
| `theme/main_theme.tres` | **保留**为唯一项目主题；按令牌文档收口数值 |
| `ui/themes/taixuan_theme.tres` | **废弃**：解除 project.godot `theme/custom` 引用；文件移入 `_legacy_assets/` 或删除（确认无场景引用后） |
| `ui_theme.gd` | **保留**；删浮点 Color 常量，改为引用 UIThemeConfig；同步字体路径至 SourceHanSansCN |
| `ui_theme_config.gd` | **保留**；品阶表由 8 键收为 7 键（去 liang），补七阶规范；字体键同步 |
| 设计令牌 v1.0 文档 | **修订**：8 阶→7 阶（删良品）、字体表改为 Source Han Sans、同步灵品青蓝值 |
| Ardot 设计稿 token | **参考用**；不写入代码，仅作为设计师对齐基准 |

### 3.3 七阶品阶平滑迁移（不破坏现有界面）
1. 决策：采用用户 2026-08-08 SOP 的 **7 阶凡/灵/宝/王/圣/仙/道**（删良品）。
2. `ui_theme_config.gd` QUALITY_COLOR 删除 `"liang"` 键，其余 7 键色值对齐令牌文档：
   - fan=#D6D6D6 / ling=#3FA9C9（青蓝升档，沿用主理人裁定）/ bao=#5B8BD9 / wang=#D9A04C / sheng=#B04CD9 / xian=#F0E6B0 / dao=#E8F0FF
3. `ui_theme.gd` COLOR_TIER_* 常量同步删 liang、对齐上述 hex。
4. 业务数据层：检查 `item.gd`/`disciple.gd` 等是否有物品被标 `良品`，若有则批量映射（良品→灵品 或 凡品，按数值就近），并出迁移清单。
5. 组件层 `ItemSlot.gd`/`page_storage.gd`/`page_shop.gd` 走 UIThemeConfig 取色，无需改逻辑，仅数据源变了。

### 3.4 字体统一（收敛到思源黑体）
1. `ui_theme.gd` `FONT_TITLE_PATH`/`FONT_BODY_PATH` 改为 `res://art/fonts/SourceHanSansCN-Regular.otf`（与 MEMORY 2026-08-06 决策一致）。
2. `main_theme.tres` 暂不绑字体（令牌文档 §2.4 规则：字体由 ui_theme.gd 探测加载，缺失回退）；如已落盘思源黑体子集，可由 engineering-lead 补 `default_font` 绑定。
3. 删除 `taixuan_theme.tres` 的 LXGWWenKai 引用（随文件废弃一并解决）。
4. Ardot 设计稿字体本就是思源黑体，天然对齐。

### 3.5 散点硬编码批量整改
- 写扫描脚本（Python/GDScript）遍历 `ui/**/*.gd` 与 `**/*.tscn`，抓取所有 `Color(` 字面量与 `theme_override_colors` 写死值，输出偏离清单。
- `.gd`：将 M1 的 `Color(0.6,0.58,0.52)` 等改为 `UITheme.COLOR_TEXT_AUX` 之类 getter；遮罩/弹窗底等用 `UITheme` 派生色或新增 token。
- `.tscn`：M2 的写死值改为引用 `main_theme.tres` 的 StyleBox/颜色（或直接删场景内 override，让项目主题生效）；M3 墨绿旧调场景确认引用后统一改色或淘汰。
