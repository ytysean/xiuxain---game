## 一、设计参考（主流垂钓品类 · 上鱼结算）

| 游戏 | 结算形态 | 本项目采纳 |
|---|---|---|
| **Stardew Valley** | 上鱼即弹出「鱼名 ＋ 长度」；**首次捕获**显示 `First catch!`；破纪录播放 `新记录!` 动画；完美收线额外 `Perfect!` | **信息三件套**：名号 / 尺寸 / 首见与纪录徽记 |
| **Call of the Wild: The Angler** | 收杆后出**稀有度色框 ＋ 光效**的结算面板，含品种、重量、XP | **品阶色框 ＋ 光效 ＋ 经验结算** |
| **Fishing Planet** | 重量 / 长度 ＋ `New Record` 标记 ＋ 经验条填充 | 数值行 ＋ 纪录徽记 |
| 手游品类（明日之后 / 原神垂钓等） | 居中卡片：品质色 ＋ 星数 ＋ 单一「获得」按钮 | **居中卡片 ＋ 单一主出口** |

## 二、从参考中提炼的六条共性

1. **立绘占视觉中心** —— 一条鱼独占画面中部，悬在氛围底之上；
2. **稀有度即颜色** —— 品阶决定主色与光效强度，一眼判价值；
3. **元数据极简** —— 名号 ＋ 尺寸/重量，最多再加一行用途；
4. **徽记做情绪峰值** —— 首见 / 新纪录 / 突破，是发给玩家的「值得截图」时刻；
5. **入场动画不可省** —— 缩放弹入 ＋ 淡入，是「仪式感」的主要来源；
6. **出口唯一** —— 一个明确主按钮，不制造选择困难。

## 三、本项目落地（修真口径）

### 3.1 结构（自上而下）

```
全屏遮罩（深墨 88%，mouse_filter=STOP 防穿透）
└─ 居中内容
   ├─ 品阶横幅      — 灵阶 · 水属 · 灵鱼 —     （品阶色，H2）
   ├─ 立绘          430 高，STRETCH_KEEP_ASPECT_CENTERED（**抠底通道**）
   ├─ 名号          「锦鲤」                    （品阶色，H1）
   ├─ 徽记行        ★ 图录首见　★ 新纪录　◆ 钓道突破　✦ 得回溯符
   ├─ 数据行        灵韵 3 · 重 2.4 钧 · 长 1.8 尺 · 难度 5
   ├─ 用途行        用途：入药、炼丹辅材
   ├─ 来处行        钓自 浅滩灵池 · 钓道经验 +12
   ├─ 赐名框（仅混沌孑遗分支）
   └─ 按钮行        [赐名收录] [继续垂钓] [使用回溯符]
```

### 3.2 修真化对照

| 通用做法 | 本项目 |
|---|---|
| Length（厘米/英寸） | **长 X 尺**（后端 `长度` 字段，已是尺） |
| Weight（克/磅） | **重 X 钧**（后端 `重量` 字段，已是钧） |
| First catch! | **★ 图录首见** |
| New record! | **★ 新纪录**（复用既有纪事「灵钓纪录」同一判定） |
| Level up! | **◆ 钓道突破** |
| 稀有度色 | **品阶色**（凡/灵/宝/王/圣/仙/道 → `UIThemeConfig.QUALITY_COLOR` 唯一色源） |
| 神秘遭遇 | **◆ 神 秘 遭 遇 ◆**（走金色，不在七品阶内） |

### 3.3 色与尺寸的合规口径（重要）

- **品阶色**：一律经 `_品阶色()` → `UIThemeConfig.get_quality_color(stem)`，**不在本页造任何色值**（`audit_ui.py` 棘轮第 1 项）；
- **遮罩基色**：`UITheme.获取场景压暗色()`（`Color8(10,17,21)` 深墨）—— **铁律 14：禁用 `获取面板底色()`**；
- **尺寸**：新增 `UITheme.RESULT_PANEL_W / RESULT_ART_H / RESULT_INPUT_H / RESULT_BTN_W / RESULT_BTN_H` 五枚语义 token，调用方不再散落裸数字（棘轮「魔法数字尺寸」只减不增）；
- **入场动画**：`Tween` 并行 —— 层 `modulate.a` 0→1（0.22s）＋ 外框 `scale` 0.86→1.0（0.34s，`TRANS_BACK / EASE_OUT` 回弹）。

## 五、资产依赖与降级

- 立绘走**抠底通道**：`Game.灵钓系统.获取灵鱼立绘(名, 变体ID, true)` → 读 `art/characters/fish_cut/`；
- **该目录当前为空**（豆包抠底图未交付）→ 后端 `_载立绘()` **自动回退原图目录**，弹窗行为与旧版一致，**不白屏、不报错**；
- 抠底图到位后**零代码改动**即生效。规格见 `美术资源补充清单_2026-09-14.md` §一（1024²、原位、真 RGBA）。

## 六、边界与铁律遵守

- **铁律 11（宗主不做点收）**：弹窗只做「展示 ＋ 赐名 ＋ 导航」，**无任何收取/领取按钮**；
- **不影响既有流程**：页内原「最近结果」展示保留，关弹窗后仍可查看，零回归；
- **切换 Tab 自动收起**（`_切换标签` 调 `_关收杆结算`），避免残留遮挡。
