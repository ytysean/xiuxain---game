---

## 1. 沿用框架（与《毕业装设计》一致）

| 原则 | 含义 |
|---|---|
| **境界绑定** | 毕业仅仙阶/道阶（及传说层）出现，低阶永不带毕业语义 |
| **强度梯度** | 明显高出现有品类顶配，但受「词缀不破资质天花板」约束——给乘区/特效而非无限堆数值 |
| **复合特效** | 双特效或「属性+特效」复合，让 build 成型 |
| **获取稀缺** | 来自最难关卡（道阶 BOSS / 终局秘境 / 合成链），非随机池 |

**品阶分层金字塔**：凡 < 灵 < 宝 < 王 < 圣 < 仙 < 道。毕业物带专属标记（`毕业:true` / `独一无二:true`），生成时仅高品阶/传说层可携。

## 2. 接入点（已具备，零红线改动）

| 子系统 | 现有能力 |
|---|---|
| **增强引擎** | `BattleCalculator._skill_buff映射` + `_buff模板`：bf_burn / freeze / stun / shield / regen / defdown / atkup / defup / spdup 共 9 种 |
| **物品技能注入** | `disciple` 战斗快照支持 `技能` 数组（套装双特效已验证注入） |
| **灵宠** | `beast` 已有 主动 / 被动 / 羁绊 / 天赋 字段；道途适配加成已生效 |
| **功法** | `gongfa` 已有 技能名 / 技能类型 / 伤害倍率 / 冷却 / 特殊效果 + 等级倍率；功法→战斗技能注入链路已存在 |
| **法宝/神兵** | `item` 已有 词缀 / 极品 / 特殊 / 套装ID / 穿戴位（含"本命法宝"独占位） |

> 结论：**所有「特效/特殊技能」均可经增强引擎注入，无需触碰 BattleCalculator 红线。**
> 仅「真实伤害 / 复活 / 全队光环」三类标志性能力需在引擎侧新增 1–3 个 buff 模板（纯增量，不破坏既有断言）。

## 3. 分品类毕业提案

### 3.1 灵宠毕业（双路径，均为毕业级）

> 用户裁定：始祖完美血脉觉醒 与 新增独立超道阶神兽 **二者并存**，各有千秋，同属毕业级。

#### 路径 A · 始祖完美血脉觉醒（复用道阶三祖）
- **载体**：道阶三大始祖神兽（祖龙 / 元凤 / 始麒麟）。
- **觉醒机制**：孵化时 `神兽血脉` 由当前 5% 概率 → **100% 完美血脉**（带 `毕业:true` 标记），并解锁【专属契约技】。
- **羁绊终极化**：三祖专属全队光环，替代通用「天地灵契」。
- **三维毕业**：

| 始祖 | 类型 | 专属契约技（注入增强引擎） | 血脉增益 |
|---|---|---|---|
| **祖龙** | attack | 「龙吟九霄」= set_defdown(敌) + bf_atkup(全队) | 攻击 +30% |
| **元凤** | support | 「涅槃之火」= set_regen(己) + 每场复活 1 次（bf_revive） | 续航 + 全属性 +15% |
| **始麒麟** | defense | 「镇世之盾」= set_shield(己) + bf_defup(全队) | 防御 +30% |

- **获取稀缺**：仅「终局秘境·万兽渊」道阶 BOSS 极低概率孵出完美血脉祖兽；或 99 级 + 满忠诚 + 满羁绊解锁。

#### 路径 B · 独立超道阶神兽（新增品类）
- **新增品阶**：在 `beast.品阶序` 道阶之上扩一档 **「混沌阶 / 神阶」**（如 `hun_jie`），等级上限随之抬升（如 100）。
- **新增名录**（超道阶，独立于七阶 39 种之外）：
  - 「混沌祖龙」(attack)、「太初元凤」(support)、「玄黄始麒麟」(defense) —— 三祖之"源初形态"。
  - 每只为**唯一/极稀有**，自带 100% 神兽血脉 + 更强专属契约技（可附带 bf_true_dmg / bf_aura 等终极能力）。
- **定位差异**：始祖觉醒 = "养成到顶的成就感"；超道阶神兽 = "唯有终局秘境/世界 BOSS 才能现世的传说级"，二者不冲突，共同构成灵宠毕业双极。

### 3.2 功法毕业
- **载体**：道阶功法（天道诀 / 混沌真经）之上新增【无上功法】档（仍为道阶品阶，带 `无上:true` 标记）。
- **两条路径**：
  1. **悟道圆满**：道阶功法可突破 Lv.10 → Lv.15（圆满），每级追加特殊效果（真实伤害 / 吸血光环）。
  2. **新增无上功法**：2–3 部带【特殊技能】的终极功法，注入增强引擎。
- **三维毕业（示例）**：

| 无上功法 | 类型 | 特殊技能（注入） |
|---|---|---|
| 《鸿蒙道典》 | 心法 | 「鸿蒙紫气」= set_shield(己) + bf_regen(己) + 每回合真实伤害（需新 buff） |
| 《太上忘情录》 | 内功 | 「忘情斩」= set_defdown(敌) + 真实伤害（需新 buff） |
| 《混沌无极功》 | 外功 | 「无极崩」= set_stun(敌) + 吸血 + 穿透（已支持） |

### 3.3 法宝·本命法宝毕业
- **现有升级**：「道祖·天道轮」由"随机传奇词条"升为**固定唯一传说本命法宝**（非随机词缀）。
- **新增【神器传说层】**（独立于七阶 `法宝名` 之外，单独 const `神器库`）：
  - 东皇钟：控制链（set_stun 敌 + bf_defup 全队）
  - 太极图：反弹 + 护盾（set_shield 己 + 反伤率）
  - 山河社稷图：吸血光环 + 减速（吸血 + bf_spdup 敌）
  - 诛仙阵图：三连控（set_defdown + set_burn + set_stun）
- **唯一性**：每样全服唯一（生成时从 `神器库` 取，标记 `独一无二:true`，**不入随机池**）；装备于"本命法宝"槽（1 件）。

### 3.4 神兵毕业（独一无二神兵）
- **现有保留**：「道祖·」tier = 巅峰随机神兵（满词条 + 随机传奇极品），维持现状。
- **新增【神兵传说库】**（`神兵名` 之外，独立 const）：
  - 轩辕剑：攻击 + 真实伤害 + 破甲
  - 弑神枪：吸血 + 穿透 + 斩杀（低血脉敌人即死判定）
  - 昆仑镜：闪避 + 复活 1 次
- **唯一性**：每样全服唯一，固定属性 + 专属技能（注入增强引擎），不入随机神兵池。

### 3.5 变异小极品 / 奇物系统（装备 · 法宝 · 神兵通用）

> 用户裁定：装备和法宝（及神兵）可概率获得**变异小极品**——同类物品概率附加 特殊属性 / 特殊特效 / 附带特殊技能，
> 且**文字描述与普通装备不同**，须符合修真世界观逻辑事实（如"沾染神兽之血的剑""某邪修持用多年的法宝""炼制掺入天外陨铁的法袍"）。

- **定位**：介于「普通随机装」与「独一无二神器」之间——**概率出现**（远高于神器的全服唯一），带叙事与实战双重增益，是日常的"惊喜毕业感"。
- **触发**：装备 / 法宝 / 神兵 生成时按概率（建议 3%~8%，随品阶递增）标记为 `奇物:true`，并从【奇物类型库】抽一种。
- **奇物类型 → 增益映射（须逻辑自洽）**：

| 奇物类型 | 修真逻辑 | 附带效果（示例） |
|---|---|---|
| **神兽遗泽**（沾染神兽之血/毛/鳞） | 神兽精血淬体 → 攻伐/血脉共鸣 | 攻击 +12% / 暴击 +10% / 附带 set_burn 或 bf_atkup |
| **邪修遗物**（魔修持用多年的法宝） | 久浸煞气 → 凶戾但带反噬 | 攻击 +15% / 吸血 +10% / 附带 bf_burn，可能微降防御 |
| **天外奇材**（掺入未知天外陨铁/星髓） | 星髓坚逾精钢 → 防御/未知属性 | 防御 +15% / 减伤 +8% / 附带 set_shield |
| **古修遗珍**（上古大能陨落之器） | 岁月沉淀道韵 → 全能微增 | 全属性 +8% / 附带 bf_regen |
| **丹毒淬炼**（以丹毒反复淬炼之法袍） | 丹毒入器 → 持续侵蚀 | 穿透 +12% / 附带 bf_true_dmg（真实伤害，小额） |

- **文字描述差异化**：物品 `名称` 加前缀/后缀（如「【神兽血染】青锋剑」「【天外陨铁】玄铁法袍」），`描述` 用对应奇物文案模板生成（见上表逻辑），与普通装备文案明显区分。
- **技能/特效注入**：奇物的 特殊特效/特殊技能 通过新增字段 `奇物技能`（复用增强引擎 `set_*`/`bf_*` 映射）注入战斗快照，与套装双特效同链路。
- **数值安全**：奇物增益仍走现有快照字段 + 增强引擎，**受「词缀不破资质天花板」约束**，不无限堆数值；概率与上限在生成逻辑中锁死。

## 4. 增强引擎扩展（已锁定：启用新 buff）

纯增量 buff 模板（零红线，仅 `_buff模板` + `_skill_buff映射` 加分支）：

| 新 buff | 效果 | 用途 |
|---|---|---|
| `bf_true_dmg` | 每回合按最大生命 % 真实伤害（无视防御） | 无上功法 / 轩辕剑 |
| `bf_revive` | 致命伤时恢复 X% 生命 1 次 | 元凤 / 昆仑镜 |
| `bf_aura` | 全队光环（1v1 退化自身；3v3 队伍快照已支持聚合） | 神器 / 始祖羁绊 |

> 注意：全队光环在 1v1 时退化为自身增益；3v3 队伍快照已实现聚合，可直接承接。

## 5. 数值安全 & 品阶分层

- 全部走现有快照字段（攻/防/血/速/暴击/反伤/穿透/减伤/吸血/闪避 + 技能数组）+ 增强引擎，**零碰 BattleCalculator 红线**。
- 毕业强度受「词缀不破资质天花板」约束：套装/神器给的是乘区/特效，弟子四维仍由 `资质系数 × 境界战斗倍率` 封顶。
