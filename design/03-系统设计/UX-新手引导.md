## 一、设计支柱对齐（防认知过载/支柱漂移）

| 支柱 | 落点 |
| --- | --- |
| 分层解锁（§13.1） | 7 天新手周期按日拆阶段释放，未解锁建筑灰色「次日解锁」 |
| 目标体系（§13.1） | 替代泛功能指引，阶段性目标 + 完成奖励 + 自动续下一个 |
| 术语悬浮（§13.1 + §15.1.8） | 专业术语点/长按弹 1–2 句极简解释，首次出现自动弹 |
| 核心循环（§13.2） | 瞬间(30s)/单局(5–30m)/长线(时–周) 三级节奏对齐留存钩子 |
| 极简主界面（§11.22） | 引导不新增主界面区块，复用现有布局空位 |

### 1.1 可访问性分级（强制引用 `design/gdd/art/ACCESSIBILITY.md`）

- 本 UX 所有交互挂载可访问性分级，默认 **Standard（默认开启·推荐）**；设置可切 Basic / Standard / Comprehensive。
- **最小触控**：跳过/收起 小字、目标卡按钮、术语悬浮触发区 ≥44×44px（Basic 亦须满足，底线）。
- **色盲冗余**：术语/目标状态仅靠颜色区分时，须叠加 **形状 + 文字** 双通道（解锁灰锁带「次日解锁」字 + 锁形轮廓，不纯色编码）。
- 特性矩阵对齐见 ACCESSIBILITY.md；本文件「三、竖屏单手布局」热区 ≥44px 即基线落实。

## 二、信息架构（IA）

```
[首次登录]
   └─ 章节式引导状态机（§13.1 7 天周期；B 文档「1–8 阶」作引导章节序号口语化）
        ├─ 顶部：当前章节进度条（第 N 日 / 目标 X/Y）
        ├─ 目标卡：当前阶段核心目标 + 进度 + 奖励预览
        ├─ 引导气泡：指向解锁功能入口（首次出现）
        └─ 术语悬浮：点/长按专业词弹解释（§15.1.8 全局 Tooltip）

[每日解锁闸]
   ├─ D1：宗门大殿+招收弟子+弟子修炼（其余灰「次日解锁」）
   ├─ D2：灵田/丹房等基础产出建筑
   ├─ D3：宗门任务+历练玩法
   └─ D5–D7：阵营声望/宗门战/财政俸禄等深度系统
```

**章节序号约定**：B 文档「数字 1–8 阶」对应每次晋阶节点（§11.1.1 七品宗门晋升），作引导章节口语化序号，不另立数字阶体系（§11.1 注记）。

## 四、核心流程（触发节点 → 章节推进）

### 4.1 触发节点（关键事件驱动）

| 节点 | 触发条件 | 引导动作 |
| --- | --- | --- |
| 首次登录 | 无存档 / 新档 | 开场叙事（§2 前任宗主战死→接掌没落宗门）+ 章节 1 启 |
| 首次测灵根 | 点「招收弟子/测灵根」 | 测灵根过场文本（lore.取测灵根过场）+ 章节 2 收徒 |
| 首次突破 | 弟子修炼进度满 | 突破四步流程提示（§11.8.11）+ 境界术语悬浮 |
| 首次解锁建筑 | 门派等级/游戏日达阈 | 灰锁→点亮动画（§15.4 七·升级脉冲）+ 功能讲解气泡 |
| 首次历练/秘境 | D3 解锁后首次进入 | 玩法说明 + 目标卡「开首秘境」 |
| 首次宗门战/阵营 | D5–D7 解锁 | 深度系统引导 + 风险预警 |
| 首次奇遇禀报 | 珍稀+ 奇遇触发 | 弹窗教学（见 UX-奇遇触发）+ 干预三档说明 |

### 4.2 章节推进状态机（§13.1 + §13.2 7 日漏斗）

```
[章节 N] 目标卡显「核心目标 + 进度 + 奖励」
   ├─ 目标达成 → 弹奖励 + 自动续 [章节 N+1]
   ├─ 流失预警（§13.2 三）：
   │     D1 30 分钟未完成 → 弹简化引导
   │     D3 灵材日产未破百 → 触发产出加速 buff
   │     D7 未升阶 → 赠送过渡资源包
   └─ D3 后允许「跳过引导」（保留术语悬浮常驻）
```

### 4.3 目标体系（§13.1 数值约束）

- 每目标附完成奖励（小额资源），总价值 ≤ 新手期 7 天产出 10% [PLACEHOLDER]，仅作引导不破坏经济（§13.1 / §13.2 五）。
- 示例目标（§13.1 / §11.1.1）：
  - D1：招收 3 名弟子 / 首名弟子突破炼气三层
  - D3：大殿升 2 级 / 每日灵材产出破百
  - D7：开启首个秘境 / 宗门品级升至下阶

### 4.4 术语悬浮（§13.1 + §15.1.8）

- 全域专业术语（道心/灵根/寿元/宗门品级/乘区等）点/长按弹 1–2 句极简解释。
- 首次出现自动弹（一次性教学），其后转手动。
- 全局单例 Tooltip（§15.1.8 节点结构：半透墨黑圆角 + 白字 12 号，上移防裁切，移动端按下 0.3s 显）。

## 五、核心循环钩子（§13.2，对齐留存）

| 节奏 | 钩子 | 引导衔接 |
| --- | --- | --- |
| 瞬间(0–30s) | 一键收取/禀报/派遣/突破 | 引导教学「首次收取」即触发正反馈 |

| 每日 | 登录礼+宗门任务刷新+丹道大典 | D1–D7 每日解锁闸驱动回归 |
| 每周 | 宗门战赛季+排行榜 | D5–D7 深度系统引导承接 |

## 八、边缘情况（≥3 类）

1. **断档回归**：玩家 D3 登录但中间离线多日。→ 按 累计游戏日 推进章节，补齐漏过解锁（不回退）；流失预警按当前章节阈值判。
2. **跳过引导**：D3 后玩家点跳过。→ 保留术语悬浮常驻（全局 Tooltip 不关），目标卡收起，后续深度系统仍可在首次进入时弹一次性讲解。
3. **旧档无引导字段**（§11.21 兼容）：老存档读入无 `引导进度`。→ 按字段三原则补默认（视作已跳过/按当前门派等级推导章节），不报错。
4. **目标卡奖励超阈**：配置奖励合计 > 7 天产出 10% [PLACEHOLDER]。→ 数值层拦截（§13.1 红线），UI 仅显最终值，不破经济。
5. **术语悬浮裁切**：贴近屏幕顶/底触发。→ Tooltip 上移/内偏移防裁切（§15.1.8 边界适配）。
6. **解锁阈值未达但功能被点**：玩家提前点灰锁入口。→ 灰锁拦截 + 气泡「次日解锁（第 N 日）」，不进功能。
