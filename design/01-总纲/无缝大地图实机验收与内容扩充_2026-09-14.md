## 三、本轮修掉的 3 个真 bug（根因）

### Bug 1 ★视觉大 bug：两套坐标口径被混用，33 个点位全挤在中州板

**现象**：地图上中州板被 21 宗门 + 12 城镇挤爆，其余四域几乎空着 —— 直接抵消了「内容密度」的观感。截图肉眼可见。

**根因**：工程里并存两套逻辑坐标口径，而渲染层只认一套：

| 口径 | 数据 | 说明 |
|---|---|---|
| **域内口径**（±200 + `区域` 字段） | `城镇坐标表` / `生成模拟宗门` / `随机分配宗门位置` / `宗门坐标` | 距离公式（商队/行军/宗门战）也按此口径算 |
| **全局口径**（`区域逻辑范围` 铺在画布上的绝对坐标） | `区域秘境` / 资源点 / 钓点 | 渲染层只认这个 |

`_逻辑转视觉(lx, ly)` 只有 x,y 两个参数、按全局口径解释，于是域内 ±200 的 33 个点全部落在**同一个**中州板上（±200 → 视觉 1520~2480，恰好在中州板 1400~2600 内）。

**修复**（**零平衡影响**，符合项目自己的「尺度问题只关在渲染层」原则）：
- `world_map_system.gd` 新增 **`域内坐标转全局(域, x, y)`** —— 唯一换乘站（先加该域画布框中心）。
- `page_world_map_visual.gd` 新增 **`_域内转视觉(域, lx, ly)`**；凡点位数据带 `区域` 字段的（玩家宗门 / 城镇 / 模拟宗门）改走它。
- `_ready` 初始揭示中心、`_派遣队伍` 起点、`_定位到宗门` 一并纠正（否则会去错地方）。

**验证**：`[分布] 标记按域画布框归类：南疆=29, 中州=14, 东域=16, 西域=14, 北域=10`（修复前 33 个全在中州）；`[附·抬升] 宗门域=南疆 域内=(−43,44) → 全局=(−43,519) 落在本域框内=true`。

### Bug 2 ★图例空头承诺：96 个资源点首屏显示 0 个

**现象**：地图页图例列了「灵脉 / 矿脉 / 灵草丛 / 妖兽领 / 灵泉」五类，首屏却一个资源点都不显示；新宗主也没有任何「采集」目标。

**根因**：`初始化周边资源点()` 里 96 个点一律 `已发现=false`，而 `_生成地点标记()` 只画已发现的 → 图例成了永远兑现不了的承诺。

**修复**：新增 **`勘明山门左近(半径=320)`** —— 修真逻辑上「开宗立派之时，山门方圆数百里本宗早已勘明，无需再遣弟子探查」。
- `初始化周边资源点()` 末尾调用；`from_dict()` 里对**老档**补调一次（幂等，老档自愈）。
- 只翻距宗门 320（逻辑单位）以内的点，其余仍须探索揭示 ⇒ **不削弱探索奖励闭环**。
- 附带修：`初始化周边资源点` 的五域点「距离」原先用**跨口径相减**（域内坐标 − 全局坐标）算出无意义的大数，使采集的 `距离衰减 = clamp(1−距/1000, 0.5, 1.0)` **恒落到 0.5 下限**；现统一在全局口径下量。

**验证**：首屏资源点由 **0 → 20~31 个**（视宗门落域与随机分布），5 类资源全部至少出现 1 个，图例兑现。

### Bug 3：宗门左近点位溢出本域板（3 个孤儿点）

**现象**：3 个点位落在所有域板**之外**的水墨底上，像浮在虚空里的孤儿点。

**根因**：宗门左近点以 50~300 半径围绕宗门撒点，而宗门可能离本域板边缘很近（东域/西域画布框半宽仅 225）。

**修复**：① `随机分配宗门位置()` 的域内采样上限按本域画布框半宽/半高**收敛（留 60 余量）**，宗门不再贴板边（顺带避免初始揭示圈一半落在板外）；② 宗门左近点**夹回本域板内（留 24 余量）**，并按夹取后实际落点重算 `距离` 字段保持自洽。

**验证**：`框外=3` → **`框外` 归零**。

## 五、顺手查清：那个「金色游离元素」不是 bug

上一轮截图里所有画面同一位置 (720 尺度 659,944) 都有一枚金色圆形图标，曾疑为渲染残留。本轮用像素聚类 + 全树扫描定位：

- 全树可见 Label **含 emoji 码点者 0 条**（排除「emoji 文字掉出容器」）。
- 命中节点：`HideUIBtn(Button) z_index=1000 rect=(965.25,1395,49.5×49.5)`，子节点 `EyeIcon` 贴图 `art/icons/hd/ui_hide_36.png`。

**结论：它就是「隐藏UI」眼睛按钮**，屏幕固定、全局可见（挂在 `_scene_root` 上，故不受 chrome 隐藏影响）。位置恰好是铁律 14 规定的 y=620（设计稿）→ `×UI_SCALE 2.25 = 1395px`，**完全正确，无需改动**。地图页上它可用来一键隐藏 UI 全屏看图，属正常功能。

## 六、遗留 / 建议（未做）

1. **域间「接缝」**：域板已改**径向晕光**（单节点椭圆衰减），结构上不可能再出现矩形色块；但板与板之间的水墨底留白仍是硬边对留白，若老大要更「连绵」的观感，下一步可做「域间过渡带」（在两板之间插一条渐变过渡）。
2. **老档坐标口径**：`城镇坐标表`/`模拟宗门` 仍是域内口径（逻辑层不动以保证商队/行军公式不变）。若将来要统一成全局口径，属**平衡改动**，需单独排期。
3. **`删除账号` 依赖回收站**：`OS.move_to_trash` 在无头/无回收站环境报 `SHFileOperation error 124` 且**档案残留**（游戏侧 `_删目录递归` 兜底没兜住）。本轮探针改为自己硬删并复验（`[清档] 硬删后存在? false`）。**建议**：游戏侧把「回收站失败即硬删」的判定改成**删除后复验存在性**，否则玩家点「删除账号」可能是伪成功。
