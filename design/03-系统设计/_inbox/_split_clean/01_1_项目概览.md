### 1.1 核心差异化标签与品类心智（v2.22 新增，对应短板六「玩法标签传统」）

**设计定位**：把现有深度内容包装成清晰差异化标签，从「又一款宗门修仙游戏」变成「有独家卖点的细分品类」，纯产品定位 / 心智，零数值。

- **核心标签锚定·世代宗门传承**：把「弟子寿命（6.10）+ 家族血脉（6.16）+ 先贤堂（6.10.4）+ 宗门史记（11.2.3）」整套体系包装为核心卖点，slogan：「百年宗门，薪火相传，你的宗门能传承多少代？」——与「弟子是工具人、无限成长」类产品形成区隔。
- **阵营路线差异化**：突出正道 / 魔道 / 中立三条完全不同的玩法路线（事件 / 剧情 / 玩法倾向全不同，见 2.1），打出「没有标准答案的修仙路」标签。
- **沙盒式经营心智**：强调「无固定最优解」，军事扩张 / 丹道致富 / 隐逸修仙 / 商业世家等路线皆可顺利玩通（对应不同宗门结局），对标《环世界》《矮人要塞》沙盒经营心智。
- **后续版本**：新增「宗门结局」系统，依玩家选择与发展路线触发不同结局（飞升仙界 / 传承万代 / 中道覆灭 / 归隐山林），增加宿命感与话题性。
