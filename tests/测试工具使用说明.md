# 《太玄宗门录》测试工具使用说明

## 一、工具概述

本次开发了三个测试工具，用于数值平衡分析：

1. **数值统计工具** (`tests/numerical_stats.gd`)
   - 功能：记录玩家的资源收入、消耗、成长速度
   - 用途：收集实际游戏数据，用于数值平衡分析

2. **战斗模拟器** (`tests/battle_simulator.gd`)
   - 功能：模拟不同配置下的战斗结果
   - 用途：测试境界平衡、道途平衡、属性敏感度

3. **经济模拟器** (`tests/economy_simulator.gd`)
   - 功能：模拟长期的经济运行情况
   - 用途：测试经济平衡、通货膨胀、不同玩家类型对比

4. **测试工具主入口** (`tests/test_tools_main.gd`)
   - 功能：运行所有测试，生成综合报告
   - 用途：命令行运行测试

## 三、使用方法

### 3.1 命令行运行测试

在项目根目录下运行：

```bash
godot --headless --script tests/test_tools_main.gd
```

这会运行所有测试，并生成以下报告：
- `user://数值统计报告.txt`
- `user://战斗模拟报告.txt`
- `user://经济模拟报告.txt`
- `user://综合测试报告.txt`

### 3.2 在游戏中使用数值统计工具

#### 初始化

在游戏启动时创建数值统计实例：

```gdscript
var 数值统计: NumericalStats

func _ready():
    数值统计 = NumericalStats.new()
```

#### 记录资源收支

```gdscript
# 记录资源收入
数值统计.记录资源收入("灵石", 1000)
数值统计.记录资源收入("灵气", 500)

# 记录资源支出
数值统计.记录资源支出("灵石", 300)
数值统计.记录资源支出("灵气", 200)
```

#### 记录弟子成长

```gdscript
# 记录突破
数值统计.记录突破("筑基", true)   # 成功
数值统计.记录突破("金丹", false)  # 失败

# 更新境界分布
数值统计.更新境界分布(弟子列表)

# 记录修炼天数
数值统计.记录修炼天数(100)
```

#### 记录战斗

```gdscript
数值统计.记录战斗("筑基", "练气", true, 5)  # 攻方境界, 守方境界, 胜利, 回合数
```

#### 更新游戏时间

```gdscript
数值统计.更新游戏时间(365)  # 游戏总天数
```

#### 记录系统使用

```gdscript
数值统计.记录系统使用("灵田种植次数")
数值统计.记录系统使用("炼丹次数")
```

#### 导出报告

```gdscript
# 导出报告文本
var 报告 = 数值统计.导出报告()
print(报告)

# 保存报告到文件
数值统计.保存报告到文件("user://数值统计报告.txt")

# 重置统计
数值统计.重置统计()
```

### 3.3 使用战斗模拟器

#### 初始化

```gdscript
var 战斗模拟器: BattleSimulator

func _ready():
    战斗模拟器 = BattleSimulator.new()
```

#### 境界对比模拟

```gdscript
# 模拟筑基vs练气，100次
var 结果 = 战斗模拟器.模拟境界对比("筑基", "练气", 100)
print("胜率: %.1f%%" % 结果["胜率"])
print("平均回合数: %.1f" % 结果["平均回合数"])
```

#### 跨境界碾压测试

```gdscript
# 以金丹为基准，测试与前后2个境界的对战
var 结果 = 战斗模拟器.模拟跨境界碾压("金丹", 50)
for 对比境界 in 结果.keys():
    var 数据 = 结果[对比境界]
    print("金丹vs%s: 胜率%.1f%%, 平均%.1f回合" % [对比境界, 数据["胜率"], 数据["平均回合数"]])
```

#### 道途平衡测试

```gdscript
# 测试同一境界下各道途之间的平衡性
var 结果 = 战斗模拟器.模拟道途平衡("筑基", 100)
for key in 结果.keys():
    print("%s: 胜率%.1f%%" % [key, 结果[key]])
```

#### 属性敏感度测试

```gdscript
# 测试攻击力变化对胜率的影响
var 基准配置 = 战斗模拟器.标准配置["筑基"]
var 变化范围 = [0.5, 0.8, 1.0, 1.2, 1.5, 2.0]
var 结果 = 战斗模拟器.模拟属性敏感度(基准配置, "攻", 变化范围, 50)
for 变化率 in 结果.keys():
    var 数据 = 结果[变化率]
    print("攻击力%s: 胜率%.1f%%, 平均%.1f回合" % [变化率, 数据["胜率"], 数据["平均回合数"]])
```

#### 导出境界对比报告

```gdscript
var 报告 = 战斗模拟器.导出境界对比报告(100)
print(报告)
战斗模拟器.保存报告到文件("user://战斗模拟报告.txt", 报告)
```

### 3.4 使用经济模拟器

#### 初始化

```gdscript
var 经济模拟器: EconomySimulator

func _ready():
    经济模拟器 = EconomySimulator.new()
```

#### 单日经济模拟

```gdscript
var 结果 = 经济模拟器.模拟单日经济(经济模拟器.基准玩家)
for 资源类型 in 结果.keys():
    var 数据 = 结果[资源类型]
    print("%s: 产出%d, 消耗%d, 净收入%d" % [资源类型, 数据["产出"], 数据["消耗"], 数据["净收入"]])
```

#### 长期经济模拟

```gdscript
# 模拟365天的经济运行
var 结果 = 经济模拟器.模拟长期经济(经济模拟器.基准玩家, 365)
var 累计收支 = 结果["累计收支"]
for 资源类型 in 累计收支.keys():
    var 数据 = 累计收支[资源类型]
    print("%s: 总产出%d, 总消耗%d, 总净收入%d, 日均净收入%.1f" % [资源类型, 数据["总产出"], 数据["总消耗"], 数据["总净收入"], 数据["日均净收入"]])
```

#### 不同玩家类型对比

```gdscript
var 结果 = 经济模拟器.模拟不同玩家类型(30)
for 类型名 in 结果.keys():
    var 数据 = 结果[类型名]
    var 收支 = 数据["累计收支"]
    var 灵石净收入 = 收支.get("灵石", {}).get("总净收入", 0)
    print("%s: 灵石净收入%d" % [类型名, 灵石净收入])
```

#### 通货膨胀模拟

```gdscript
var 结果 = 经济模拟器.模拟通货膨胀({}, 12, 0.02)
print("月通胀率: %.1f%%" % (结果["月通胀率"] * 100))
print("年通胀率: %.1f%%" % (结果["年通胀率"] * 100))
print("最终物价指数: %.2f" % 结果["最终物价"])
```

#### 导出经济报告

```gdscript
var 报告 = 经济模拟器.导出经济报告(365)
print(报告)
经济模拟器.保存报告到文件("user://经济模拟报告.txt", 报告)
```

## 四、接入建议

### 4.1 数值统计工具接入点

建议在以下位置接入数值统计：

1. **资源变化**：在灵石、灵气、灵草、矿石等资源变化时记录
2. **弟子突破**：在弟子突破成功/失败时记录
3. **战斗结束**：在每场战斗结束时记录
4. **系统使用**：在灵田种植、矿脉开采、炼丹、炼器等操作时记录
5. **游戏时间**：在游戏时间推进时更新

### 4.2 战斗模拟器使用场景

1. **境界平衡测试**：测试各境界之间的胜率是否合理
2. **道途平衡测试**：测试各道途之间的平衡性
3. **属性敏感度测试**：测试各属性对战斗的影响程度
4. **装备影响测试**：测试装备对战斗强度的影响

### 4.3 经济模拟器使用场景

1. **长期经济测试**：模拟长期运行后的经济情况
2. **玩家类型对比**：对比不同类型玩家的经济状况
3. **通货膨胀测试**：测试通货膨胀对经济的影响
4. **产出消耗平衡**：测试资源产出与消耗是否平衡

## 六、注意事项

1. 测试工具中的数值配置是简化版，实际游戏中的数值可能更复杂
2. 战斗模拟器使用的是简化版战斗逻辑，实际战斗可能有更多因素
3. 经济模拟器中的产出消耗配置是基准值，实际游戏中可能有更多变量
4. 建议先使用模拟器进行初步测试，然后在实际游戏中收集数据进行验证
