# 《太玄宗门录》赠送物品系统 GDD（提案 A · 3 场景）

> **核心定位**：自动事件模拟为主体，玩家轻量干预为点缀；**零通胀底线**——NPC 互赠不产不耗全局库存，玩家赠送真实扣库存且收益转化率 < 直接使用；入口全部下沉二级页（B2 硬约束：无首页独立按钮）。
> **铁律**：S1 零战斗触碰。本系统全程非战斗（社交/养成/经济），无战斗结算；仅「师徒同场战斗加成」「仙侣信物双防」涉及战斗属性，已分别标 `[S2-战斗放开]` / S1 属性聚合口径。

---

## 〇、身份阶对齐（关键一致性裁决）

> ⚠️ 提案 A 用「身份阶（外门 / 内门 / 亲传）」为 **3 档设计简称**，与权威 5 级身份轴不一致。本 GDD 统一映射，禁止直接使用 3 档简称做逻辑判定。

| 提案简称 | 权威身份轴（`身份层级序`，disciple.gd L149） | 阶别对齐（礼物大品阶上限） |
|---|---|---|
| 外门 | `外门`（index 0） | ≤ 凡品（凡阶） |
| 内门 | `内门弟子`(1) · `核心弟子`(2) | ≤ 灵品（灵阶） |
| 亲传 | `亲传弟子`(3) · `长老`(身份)(4) | ≤ 宝品（宝阶） |

- **判定函数**：`var 阶索引 := 身份层级序.find(d.身份)`；礼物大品阶上限 = `f(阶索引)`（外门→凡品 / 内门弟子+→灵品 / 亲传弟子+→宝品）。
- **对齐红线**：`数值体系细则.md` §4.1「佩戴限制：弟子仅可使用自身境界及以下品阶道具」——本系统阶别对齐复用同一规则（按身份/境界映射大品阶）。

## F1. 弟子社交互赠（全自动）

### 1. 定位
两弟子有「好友 / 仙侣」关系时，每日自动触发互赠模拟；玩家零操作，仅接收反馈（好感↑ / 修炼微增益 / 纪事 + 轻量弹窗）。**非消耗型**：不触碰全局背包，零通胀。

### 2. 核心规则
- **触发**：每日结算扫描弟子关系网络，命中「好友 / 仙侣」则触发。
- **好感增益**：基础 `5%` / 满好感 `12%` / **仙侣翻倍**（×2）。
  - 满好感阈值 = 好感度达上限（现有 `好感度` 字段，见 `GDD-弟子养成.md` §二）。
- **修炼增益**：双方当日修炼 `+3%~5%`，持续 `1 游戏日`。
- **反馈**：双方好感↑ + 纪事 + 轻量弹窗（弱提示，不阻断）。
- **仙侣信物馈赠（永久羁绊）**：仙侣关系概率触发「信物馈赠」→ 双防 `+2%` 永久；**每名弟子仅 1 次**（幂等，重复仙侣不叠加）。

### 3. 数值与配置
| 项 | 值 | 配置载体 |
|---|---|---|
| 基础好感增益 | +5% | `社交互赠.csv`（提议新增，纯配置） |
| 满好感增益 | +12% | 同上 |
| 仙侣翻倍系数 | ×2 | 同上 |
| 修炼增益 | +3%~5% / 1 日 | 同上（应用走 `设置气运buff(修炼加,产出加,天数)` 的修炼加分量） |
| 信物双防 | +2% 永久 / 每弟子 1 次 | 同上（→ S2-4 属性聚合口径） |

### 4. 复用现状 · 诚实标注
- ✅ **纯逻辑 + CSV 配置**：复用现有 `好感度` / `关系网络`（师徒/道侣/同门，`GDD-弟子养成.md` §二）、`宗门纪事.append`（game_state L59）、`_加推演条目`、`设置气运buff`（L937）。
- ✅ **零库存触碰**：本场景不移动任何物品，无 item_id 需求，零通胀。
- ⚠️ **需轻量代码**：每日关系扫描 + 好感增减 + 修炼 buff 应用 + 信物幂等判定（每弟子 1 次标记）。

### 5. S1/S2 分期
- **S1 交付**：互赠逻辑 / 好感 / 修炼增益 / 纪事 / 弹窗。
- **[S2-战斗放开] 不涉及**：F1 无战斗结算。仙侣信物「双防 +2%」走 **S1 属性聚合接口**（经 `get_final_combat_attr`，与阶位轴战力加成同处理，见索引 S2-4），仅 S2 战斗放开后体感，不灰化。

### 6. UI 入口规范（对齐 B2）
- **全自动，无入口按钮**。反馈为轻量弹窗（弱提示），不从首页/主导航进入。
- 关系状态展示：弟子详情弹窗内「关系」行（复用现有详情弹窗，见 `GDD-弟子阶位轴.md` §6.3）。

### 7. 跨文档一致性
- 好感/关系 → `GDD-弟子养成.md` §二（字段现状）。
- 修炼增益 → `设置气运buff`（game_state L937）复用，入通用增益乘区（软 25%/硬 30%），单源子帽不破。
- 双防 → `数值体系细则.md` §4.4 防御溢出治理，S2 战斗放开后计入。

### 8. 边缘情况（≥3）
- **EC-1 一方好感已满、另一方未满**：按「双方各自满好感判定」分别结算，不强制取低。
- **EC-2 仙侣关系解除/再结**：信物每弟子仅 1 次，解除不回收标记；再结不二次触发。
- **EC-3 弟子当日已离宗/坐化**：关系扫描跳过已离宗弟子，不报错。
- **EC-4 好感度字段缺失（旧档）**：`.get` 默认 0，走基础 5% 档。

### 9. 验收标准
- 每日扫描命中好友/仙侣 → 双方好感↑ + 当日修炼 +3~5% + 纪事一条；仙侣信物每弟子仅触发 1 次；不触碰全局背包（零通胀验证）。

## F2. 师徒馈赠（NPC 自动 + 玩家手动）

### 1. 定位
- **(1) NPC 师尊自动馈赠**：弟子突破大境界 / 年度考评获优时，师尊自动发丹药·功法残页·阵纹碎片·低阶法宝；**不耗全局库存**（受控产出）。
- **(2) 玩家手动馈赠**：入口「弟子详情页 → 更多操作 → 馈赠宝物」（二级按钮弱处理）；从全局背包真实扣；自然月每弟子最多接受 1 次；赠送物品阶 ≤ 弟子身份上限；收益转化率固定 `80%`。

### 2. 核心规则
- **NPC 自动触发点**：复用现有 `突破()`（game_state L969 道心通明）、`岁末考评`（L1082）；命中即发放。
- **NPC 发放物（引用现有 item_id，不耗全局库存）**：
  - 丹药 → `item_pill`（44 注册 ID）
  - 功法残页 → `skill` / `skill_cultivation`（15 / 39 注册 ID）
  - 阵纹碎片 → `item_015`（array_items，复用器堂 `器堂赠宝_优化GDD.md` §1.3）
  - 低阶法宝 → `treasure_normal`（36 注册 ID）
- **玩家手动**：真实扣 `全局背包`；自然月每弟子 ≤ 1 次（月限闸）；阶别对齐见 §〇；收益转化率 `80%`（即馈赠给弟子的养成收益 = 直接使用该物品的 80%）。

### 3. 数值与配置
| 项 | 值 | 配置载体 |
|---|---|---|
| NPC 自动触发 | 突破大境界 / 年度考评获优 | 复用现有结算点 |
| NPC 发放物阶 | 按弟子身份上限（§〇） | 引用现有 item_id |
| 玩家手动月限 | 每弟子自然月 ≤ 1 次 | `馈赠宝物.csv`（提议新增） |
| 收益转化率 | 80%（固定） | 同上 |
| 阶别对齐 | 礼物大品阶 ≤ 身份上限（§〇） | 同上 |

### 4. 复用现状 · 诚实标注
- ✅ **玩家手动 = 真实消耗 sink（反通胀）**：从全局背包真实扣，引用现有 item_id，**不新增悬空 ID**。需轻量代码（背包扣减 + 月限闸 + 阶别校验 + 80% 转化率应用）。
- ⚠️ **NPC 自动 = 受控产出源**：不耗全局库存但向弟子发放 = **产出**，须登记为「弟子养成产出」口径，纳入月度盈余 15%~25% 上限（`数值体系细则.md` §4.8）；触发极稀发（突破大境界/年度考评优）故占比可忽略，但需数值 GDD 登记为产出源，不得伪装成「零通胀」。引用现有 item_id，不新增悬空 ID。
- ✅ 入口下沉：弟子详情页 → 更多操作 → 馈赠宝物（二级按钮，B2 合规）。

### 5. S1/S2 分期
- **S1 交付**：NPC 自动发放（受控产出登记）、玩家手动消耗（月限/阶别/80%）、入口。
- **[S2-战斗放开]**：师徒同场战斗属性加成（`GDD-弟子养成.md` §三.4）→ 见索引 S2-3，S2 扩展接口层经 `get_final_combat_attr` 聚合。

### 6. UI 入口规范（对齐 B2）
- **玩家手动入口**：`弟子详情弹窗` → 底部操作区「更多操作」→「馈赠宝物」（二级按钮，弱处理样式，参考 `UI硬性约束规范.md` 次按钮）。
- **无首页独立按钮**（B2 合规）；NPC 自动无入口，仅纪事/弹窗反馈。

### 7. 跨文档一致性
- 阶别对齐 → §〇 + `数值体系细则.md` §4.1 佩戴限制。
- item_id → `REPORT-item_id注册表.md`（333 注册）；材料类礼物若需，待 `item_material` 注册表补全后回填，**本批不新增悬空 ID**。
- 产出登记 → `数值体系细则.md` §4.8 经济闭环（NPC 馈赠计入弟子养成产出）。

### 8. 边缘情况（≥3）
- **EC-1 玩家手动月限已用**：按钮置灰 + tooltip「本月已馈赠」；跨自然月重置。
- **EC-2 全局背包不足**：馈赠前校验物品存在，不足则禁用并提示。
- **EC-3 礼物阶 > 弟子身份上限**：阶别校验拒绝，提示「弟子境界不足，无法受此阶宝物」。
- **EC-4 NPC 发放时弟子已坐化**：发放前校验弟子在职，跳过不报错。

### 9. 验收标准
- 玩家手动：真实扣全局背包、月限 1 次、阶别对齐、收益 80%；NPC 自动：突破/考评触发、引用现有 item_id、登记为产出源；零悬空 ID。

## F3. 宗门荣誉嘉奖（活动结算弹窗内可选按钮）

### 1. 定位
活动结算弹窗内的**可选按钮**，与标准奖励并列；玩家点击 = 追加嘉奖（真实扣库存）+ 全宗士气 buff。计入纪事 + 声望 + 凝聚力。

### 2. 核心规则
- **入口**：活动结算弹窗（复用现有 `七载大考` game_state L1151 / 常规活动结算）内「荣誉嘉奖」可选按钮，与标准奖励并列。
- **消耗**：追加嘉奖真实扣全局背包（消耗 sink，反通胀✓）。
- **全宗士气 buff**：
  - 嘉奖 1 人：`+3%` 持续 `3 天`
  - ≥3 人：`+5%` 持续 `7 天`
  - 七载大考：`+8%` 持续 `15 天`
  - **叠加上限 +10%**（多轮嘉奖累加不超 +10%）。
- **计入**：纪事 + 声望 + 凝聚力。

### 3. 数值与配置
| 项 | 值 | 配置载体 |
|---|---|---|
| 嘉奖 1 人 buff | +3% / 3 天 | `荣誉嘉奖.csv`（提议新增） |
| ≥3 人 buff | +5% / 7 天 | 同上 |
| 七载大考 buff | +8% / 15 天 | 同上 |
| 叠加上限 | +10% | 同上 |
| 消耗 | 真实扣全局背包 | 引用现有 item_id |

### 4. 复用现状 · 诚实标注
- ✅ **真实消耗 + 全宗 buff**：复用 `设置气运buff(修炼加,产出加,天数)`（game_state L937）做全宗士气；复用 `七载大考` 结算点（L1151）；引用现有 item_id，不新增悬空 ID。
- ⚠️ **需轻量代码**：活动结算弹窗内挂可选按钮 + 扣库存 + 叠加闸（+10%）+ 纪事/声望/凝聚力写入。

### 5. S1/S2 分期
- **S1 交付**：全功能（消耗 + 士气 buff + 叠加闸 + 纪事）。无战斗结算。

### 6. UI 入口规范（对齐 B2）
- **入口**：活动结算弹窗内「荣誉嘉奖」可选按钮（与标准奖励并列），**非首页独立按钮**（B2 合规）。
- 弹窗归属：复用 `GDD-活动系统.md` 活动结算流程；七载大考场景复用 game_state L1151 结算弹窗。

### 7. 跨文档一致性
- 士气 buff → `设置气运buff`（L937），入通用增益乘区（软 25%/硬 30%）；叠加闸 +10% 为单源子帽。
- 声望/凝聚力 → `GDD-宗门经营.md` / `GDD-阵营系统.md`。
- 活动结算 → `GDD-活动系统.md` §三。

### 8. 边缘情况（≥3）
- **EC-1 全局背包不足**：嘉奖按钮禁用 + tooltip「库存不足」，不阻断标准奖励领取。
- **EC-2 多轮嘉奖叠加超 +10%**：叠加闸截断，超出部分不生效（提示「已达嘉奖上限」）。
- **EC-3 活动无嘉奖资格（如非七载大考）**：按钮按活动类型显隐，仅支持嘉奖的活动显示。
- **EC-4 七载大考与常规活动同月**：各自独立叠加计算，统一卡 +10% 总上限。

### 9. 验收标准
- 点击嘉奖 → 真实扣库存 + 全宗 buff（按人数/七载大考分档）+ 叠加≤+10% + 纪事/声望/凝聚力写入；入口仅在活动结算弹窗内（B2 合规）。

## 八、文档级诚实标注与战斗灰占位汇总

| 功能 | 诚实标注 | 战斗标记 |
|---|---|---|
| F1 社交互赠 | 纯逻辑+CSV，零库存触碰，复用好感/关系/纪事 | 无战斗；仙侣信物双防=S1 属性聚合（S2-4） |
| F2 NPC 师徒 | 受控产出源（须登记产出口径），引用现有 item_id | 师徒同场加成 → `[S2-战斗放开]`（S2-3） |
| F2 玩家手动 | 真实消耗 sink，引用现有 item_id，需轻代码 | 无战斗 |
| F3 荣誉嘉奖 | 真实消耗 + 全宗 buff，复用设置气运buff/七载大考 | 无战斗 |

> **零通胀结论**：F1（零库存）+ F2 手动（消耗）+ F3（消耗）均为非通胀；F2 NPC 为受控产出，须登记弟子养成产出口径并守月度盈余上限，不得宣称「零通胀」。
> **item_id**：全部引用现有注册池，**本批不新增任何悬空 item_id**；材料类待 `item_material` 注册表补全后回填。
> **S1 交付确认**：F1/F2/F3 全部 S1 可交付（非战斗）；仅 F2 师徒同场战斗加成标 `[S2-战斗放开]`。
