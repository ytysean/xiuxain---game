## 二、工程落地骨架规范（适配Godot UI重构）

### 1. 基础栅格规则
全局以 8px 为最小单位，所有边距、尺寸、间距均为8的倍数，保证全界面对齐统一。

### 2. 垂直分区占比（竖屏480×854有效区域）
| 区域 | 高度 | 固定规则 | 内边距 |
|---|---|---|---|
| 顶部状态栏 | 48dp | 固定顶部，不随滚动消失 | 左右16dp |
| 经营概览面板 | 120dp | 固定在状态栏下方 | 上下12dp，左右16dp |
| 核心操作宫格区 | 240dp | 首屏核心视觉区 | 上下16dp，左右16dp，按钮间距12dp |
| 次功能滚动区 | 剩余高度 | 可上下滑动，收纳低频功能 | 左右16dp，模块间距16dp |
| 底部主导航Tab | 64dp | 固定底部，层级最高 | 无额外内边距 |

### 3. 全局字体层级
| 层级 | 字号 | 颜色 | 用途 |
|---|---|---|---|
| 面板大标题 | 24号 | 暗金色，加粗 | 模块标题、页面主标题 |
| 核心数值 | 18号 | 亮金色，加粗 | 灵石、灵气、弟子数等核心资源 |
| 正文信息 | 16号 | 浅米色 | 常规说明、数据正文 |
| 辅助文字 | 12号 | 浅灰色 | 次要标注、说明文字 |

### 4. 通用组件规范
- 面板：统一圆角12dp，1px暗金描边，内边距16dp，底色带极淡水墨纹理
- 主功能按钮：统一高度64dp，圆角8dp，图标+文字上下排布，有常态/按下/禁用三态
- Tab按钮：统一高度64dp，图标+文字上下排布，选中态暗金高亮
- 分割线：1px暗金色，模块间分隔使用，避免粗线、多线

### 5. 信息层级铁律
- P0核心信息+操作：首屏常驻，视觉权重最高
- P1次频信息：默认精简展示，点击/下滑查看详情
- P2低频设置/说明：收纳到二级页面，不占用主界面空间
所有二级页面统一复用「顶部状态栏+底部Tab栏」的骨架，仅替换中间内容区，保证全局结构一致。

### 优化核心原则
不推翻A版「沉稳厚重、宗门经营感」的核心定位，也不改动基础骨架，只围绕**「强化掌教管理视角、提升信息效率、降低认知负担、低干扰融入古风调性」**做分层优化，开发成本可控，且能明显提升布局的专业度与贴合度。

## 一、分模块优化方案（从上到下对应A版骨架）

### 1. 顶部状态栏：从「罗列信息」→「核心优先，按需展开」
当前问题：信息平铺，核心资源与次要信息权重一致，异常状态无直观反馈。
优化点：
- **资源分级，主副分离** 首屏只保留P0核心资源：灵石、灵气、弟子总数，横向紧凑排列；灵草、矿石、贡献等次资源收纳进「展开箭头」，点击下拉显示，避免顶部信息过载。
- **等级进度可视化** 把「距Lv2还差声望0」从纯文字改成微型进度条，嵌在宗门等级文字下方，玩家一眼就能看懂成长进度，不用读文字计算。
- **异常状态弱预警** 资源为负、即将耗尽时，对应数字自动变为暗红色（不刺眼，仅做视觉提示），比如你当前灵石-6094的状态，无需弹框就能直观感知经营风险，贴合掌教实时把控宗门状态的视角。

### 2. 经营概览面板：从「数据陈列」→「强化经营体感」
当前问题：只是堆数据，玩家看不出宗门运营的好坏趋势。
优化点：
- **增加趋势反馈** 在「月产出+95灵石」旁加极细的上升/下降箭头，对比上月产出变化；同时补充「月消耗」数据，玩家一眼就能算出宗门是赚是亏，不用自己翻账册。
- **宗门状态标签** 面板右上角加一个微型状态标签：正常运营时为「宗门安定」（暗金色），入不敷出时为「财政吃紧」（暗红色），弟子不足时为「人手短缺」，用极简文字给玩家明确的经营结论。
- **核心指标拆解** 把笼统的「月产出」拆分为「产业产出+坊市收益」，对应你的核心玩法模块，让玩家清晰知道钱从哪来，优化经营决策有依据。

### 3. 核心操作宫格区：从「平权按钮」→「权重分级，状态可见」
当前问题：6个按钮完全等大，没有区分高频/低频操作，视觉上平乏，且功能状态无提示。
优化点：
- **按钮权重分级，高频放大** 不做全部等大的2×3宫格，改成「3个大主按钮 + 3个小次按钮」的组合：
  - 大按钮（高频核心）：建筑、坊市、弟子，占满一行，视觉权重最高，对应玩家最常操作的经营模块；
  - 小按钮（次频功能）：洞府、修炼、账册，放在第二行，尺寸缩小1/3，不抢视觉重心。 既保留了功能入口的完整性，又符合玩家的操作频率习惯，点击效率更高。
- **弱状态提示，不破坏古风感** 有可升级建筑、新弟子可招募、账册有未读结算时，按钮角落加一个极小的暗金色圆点提示，不用现代感的强红点，既传递状态，又不破坏整体沉稳的调性。
- **语义化图标统一** 所有按钮图标统一用「线稿古风图标」，比如建筑对应殿宇、坊市对应算盘、弟子对应道冠，避免用现代扁平化图标，强化世界观沉浸感。

### 4. 次功能滚动区：从「平铺堆砌」→「分类折叠，降低密度」
当前问题：所有低频模块全部平铺，首屏信息冗余，且未解锁内容占位感强。
优化点：
- **分类聚合+折叠收纳** 把零散模块按玩法分类，做成可折叠的标题栏：
  - 「凡世香火」：收纳香火值、信徒、城镇经营；
  - 「宗门规制」：收纳谱系礼制、门规严格度；
  - 「道统传承」：收纳正邪路线、宗门要务。 默认全部折叠，只显示分类标题，首屏大幅清爽；玩家需要时点击展开，符合「低频功能不占用核心视觉」的原则。
- **未解锁内容弱处理** 「正邪路线」这类未解锁功能，不要直接整行灰掉，只在标题旁加极小的「Lv3解锁」标注，保持视觉整洁，同时告知解锁条件，不会让玩家觉得是空内容。
- **模块视觉分层** 折叠面板用「标题栏+内容区」的两级视觉差，标题用暗金色加粗，内容用浅米色正文，层级比核心操作区低一级，视觉上不会喧宾夺主。

### 5. 底部Tab导航：从「基础切换」→「层级清晰，反馈明确」
优化点：
- **选中态强化** 选中Tab不只是变色，增加一条极细的暗金下划线（位于Tab顶部或底部），同时图标+文字同步高亮，玩家不用仔细看就能明确当前在哪个页面。
- **顺序按使用频率排序** 调整为「宗门 → 弟子 → 历练 → 御兽 → 纪事」，从首页到核心玩法再到辅助内容，符合玩家从左到右的操作习惯，把最高频的弟子模块放到次位，降低点击成本。

## 二、全局体验优化（低开发成本，提升质感）
1. **轻量交互反馈，贴合古风调性** 按钮按下不要做弹动、放大这类现代强反馈，改成「底色加深、描边变亮」的微变化，面板切换用淡入淡出，整体动效时长控制在200ms以内，沉稳不花哨，符合宗门经营的厚重感。
2. **低干扰古风细节点缀** 不在面板上堆大量花纹，只做极简点缀：面板四角加1px的回纹/云纹角饰，分割线用细云纹替代直线，标题旁加微型法器、道符类小图标，用量控制在5%以内，提升沉浸感又不杂乱。
3. **信息去重，消除冗余** 删掉顶部状态栏与宗门全景里重复的信息，同一数据只在最合理的位置出现一次，避免玩家反复看到相同内容，降低认知负担。

## 三、落地优先级建议
**P0 必做（开发成本极低，收益最高）**
1. 顶部资源分级 + 异常状态标色
2. 核心按钮权重分级
3. 次功能区分类折叠
4. 全界面信息去重

**P1 锦上添花（功能稳定后补充）**
1. 经营趋势与状态标签
2. 按钮弱状态提示
3. 古风细节点缀与动效优化

整体优化完全复用A版的基础骨架与主题模块，不需要重构UI结构，只调整组件排布、增加少量状态逻辑，工程侧改动量小，且能明显提升布局的专业度与经营感。

## 一、优化UI布局时保持古风特色：克制融入，而非堆砌装饰
核心原则：古风感来自世界观统一的细节，不是满屏花纹。布局优化时，先保证信息效率，再用低占比的古风元素做氛围锚点，避免为了风格牺牲易用性。

### 1. 组件形制：统一古风载体语义
- **面板**：参考古籍、木牌、殿宇匾额的形制，不用现代大圆角，用小圆角+直角过渡；边角加极简回纹/云纹角饰（仅四角，无边框满铺）；一级标题用"匾额式"排版（文字居中+两侧短装饰线），对应宗门殿宇的牌匾感。
- **按钮**：主按钮参考"木质令牌/玉牌"质感，次按钮参考"古籍书签"样式；不用现代渐变投影，用暗纹+描边体现层次，贴合修真宗门的器物感。
- **分割线**：不用纯直线，用极简云纹、卷草纹细线条，或者直接用留白+深浅底色分区，比画线更有高级古风感。

### 2. 文案体系：全链路替换现代术语
这是成本最低、古风感提升最强的方式，布局优化时同步替换，完全不增加美术成本：
- 操作按钮："确定"→"办妥""谨遵掌教令"；"返回"→"退下""回宗门"；"升级"→"升格""修葺"
- 状态提示："成功"→"规制已更新""产业已落成"；"失败"→"灵力不足""宗门暂无力兴办"
- 模块命名："设置"→"宗门规制"；"背包"→"储物阁"；"任务"→"宗门要务"；"邮件"→"飞符传信"

### 3. 信息呈现：贴合古代阅读习惯
- 重要标题、核心模块名优先居中排版，对应古籍、匾额的阅读逻辑；正文左对齐，保证可读性。
- 数值单位全程贴合世界观：统一用灵石、灵气、声望等设定内表述，绝不出现金币、体力、经验等现代游戏术语。

### 4. 避坑红线
- 装饰元素占比控制在5%以内，禁止满铺花纹、浮雕、复杂边框，会严重干扰信息阅读，让界面显脏。
- 正文禁用生僻字、过度扭曲的书法字体，标题可用书法体强化风格，正文必须用清晰的印刷类古风字体，保证可读性优先。
- 拒绝强炫光、满屏粒子特效，古风的核心是"雅致、沉稳"，对应掌教的沉稳视角，花哨特效会直接破坏调性。

## 二、提升沉浸感的古风交互反馈：微动作、弱反馈、强代入
核心原则：所有反馈贴合"宗门掌教处理事务"的体感，拒绝现代弹窗、强弹跳、夸张动效，用克制的反馈强化代入感，且开发成本极低。

**按落地优先级排序：**
**P0 必做（零/低成本，体感提升最明显）**
- **按钮按压反馈**：不用放大缩小，改成「按压下沉+底色加深」，模拟按压木质令牌的触感；主按钮可增加极淡的金色微光闪过，对应法器质感，动效时长150ms，快且不拖沓。
- **页面切换反馈**：一级页面切换用「淡入淡出+轻微卷帘动效」（从上到下或从左到右轻扫过渡），模拟翻古籍、开殿门的体感，时长200ms，比直接切页更有沉浸感。
- **操作结果文案反馈**：不用现代Toast弹窗，改成页面顶部/底部的轻量字条提示，文案统一用古风表述，比如招募弟子成功提示"新弟子已入宗门名册"，升级建筑提示"殿宇修葺完毕"，2秒后自动消失，不打断操作。

**P1 建议做（中成本，强化世界观）**
- **状态变化微动效**：宗门升级、资源增加时，对应数字旁出现极淡的灵气粒子上浮效果，量少且淡，不抢视线，贴合修真设定。
- **重要操作确认**：更改门规、启用重大产业时，确认框做成"玉牒/法旨"样式，确认按钮为"掌教印"，点击有盖印的微动效，强化掌教身份的仪式感。
- **轻量音效反馈**：点击主按钮加极轻的木质敲击声，切换页面加轻微的卷轴展开声，音量控制在很低的水平，仅做潜意识氛围补充，不干扰玩家。

**P2 锦上添花（高成本，后续版本补充）**
- **全局环境微动效**：主界面背景有极淡的云雾缓慢流动，远处山影轻微移动，模拟宗门山巅的氛围感，透明度极低，完全不影响UI信息阅读。
- **时辰/季节联动**：不同时辰、不同季节，UI整体色调做轻微冷暖变化，比如清晨偏暖、深夜偏暗，对应宗门真实时间流逝。

## 三、底部Tab栏按使用频率重排：左高右低、聚类相邻、符合操作习惯

### 1. 排序核心原则
- **左高右低**：移动端左手拇指操作最顺手，使用频率越高的Tab越靠左；最左侧固定为首页（宗门），作为所有操作的锚点。
- **功能聚类**：属性相近的模块放在相邻位置，避免玩家跨大区域点击，降低操作成本。
- **记忆稳定**：首页永远在最左，最低频辅助模块在最右，中间按频率递减排列，形成稳定的操作记忆，不频繁改动。

### 2. 适配你项目的推荐排序（从左到右）
**宗门 → 弟子 → 建筑 → 历练 → 纪事**
排序逻辑对应频率与玩法闭环：
1. 宗门（最左）：首页锚点，访问频率最高，所有玩家默认进入页，固定在最左符合通用操作直觉。
2. 弟子（次位）：宗门经营核心，招募、培养、分配弟子是最高频的管理操作，放在左手最顺手的次位，点击成本最低。
3. 建筑（中位）：核心经营模块，建造、升级产业，和弟子管理同属核心经营玩法，聚类相邻，玩家管理完弟子直接切建筑，操作路径最短。
4. 历练（次右）：玩法类模块，频率低于核心经营，放在次右侧，属于主动探索内容，不抢占核心位置。
5. 纪事（最右）：最低频，查看日志、历史事件、系统通知，放在最右侧，符合辅助功能的定位。

### 3. 备选调整方案（后续模块扩容时）
如果后续把坊市从二级入口升为一级Tab，排序调整为： 宗门 → 弟子 → 建筑 → 坊市 → 更多 把历练、纪事、设置等收纳进「更多」，保证底部Tab始终不超过5个，避免拥挤。

### 4. 验证与迭代方法
- 上线前：按核心玩法循环走查，统计完成一个完整经营循环（看资源→管弟子→升建筑→看结果）的点击次数，路径越短排序越合理。
- 上线后：通过埋点统计各Tab的日点击次数、人均点击频次，每1-2个大版本微调一次，不频繁改动，避免破坏玩家操作记忆。

# 《太玄宗门录》UI交互规范（古风经营A版）

## 文档信息
- 版本：V1.0
- 适用范围：S1全量UI界面重构
- 核心定位：竖屏古风修真宗门经营，掌教第一视角管理体验
- 设计铁律：信息效率优先，古风氛围克制嵌入，零战斗逻辑触碰

## 一、核心设计原则
1. **信息效率优先**：先保证玩家一眼获取核心信息、一键触达高频操作，再做风格化装饰，绝不因视觉牺牲易用性。
2. **古风克制嵌入**：装饰元素占比≤5%，以形制、文案、细节传递调性，拒绝满屏堆砌花纹、炫光。
3. **掌教视角统一**：所有文案、交互、信息排布贴合宗门管理者身份，无现代游戏术语带来的违和感。
4. **架构稳定可扩展**：基础骨架一次定型，后续新增模块仅在收纳区扩展，不破坏全局结构与玩家操作记忆。

## 二、视觉布局基础规范

### 2.1 基础栅格与基准分辨率
- 基准分辨率：竖屏 480×854（适配移动端等比缩放）

## 四、交互反馈规范

### 4.1 P0 必做基础反馈（开发成本极低，体感提升显著）

  - 触发：手指按下时同步触发
  - 效果：按钮底色加深15%，描边亮度提升20%，无缩放弹动，模拟按压木质令牌的沉实感
  - 时长：150ms线性过渡，松手即恢复常态
- **页面切换反馈**
  - 触发：一级Tab切换、二级页面跳转
  - 效果：新页面淡入（透明度0→100%）+ 轻微右移（10dp→0），模拟翻卷古籍的体感
  - 时长：200ms缓动过渡，无重叠闪烁
- **操作结果提示**
  - 触发：资源变更、操作成功/失败
  - 样式：页面顶部轻量字条，无弹窗边框，统一使用古风文案
  - 时长：2秒自动淡出，不打断玩家连续操作

### 4.2 P1 进阶沉浸反馈（功能稳定后落地）
- **数值变化反馈**
  - 触发：资源增加、等级提升
  - 效果：数字高亮闪烁一次，伴随极淡的金色粒子上浮（粒子数量≤8，透明度≤30%）
  - 时长：300ms完成，不遮挡其他界面信息
- **重要操作仪式感**
  - 触发：更改门规、落成核心建筑、宗门等级提升
  - 效果：确认弹窗为玉牒样式，确认按钮点击触发"盖印"微动效，伴随极轻的印章音效

- **轻量音效反馈**
  - 主按钮点击：极轻木质敲击声，音量-20db
  - 页面切换：极短卷轴展开声，音量-25db
  - 规则：仅做潜意识氛围补充，默认音量极低，玩家可在设置中关闭

### 4.3 P2 氛围增强反馈（后续版本迭代）
- **全局环境微动**：主界面背景云雾缓慢流动，远山轻微位移，透明度≤20%，完全不干扰UI阅读

## 七、架构约定与决策基线（2026-07-28 拍板收敛）

> 本节为落盘时检出的 6 项冲突点的最终拍板，作为工程与美术的统一执行依据。所有决策兼容 A 版基础骨架，不推翻既有规范。

### 7.1 底部主导航：混合 5-Tab + 更多（分阶段）
- **固定 5-Tab 排序（左→右）**：宗门 → 弟子 → 建筑 → 历练 → 纪事。
- **S1 阶段**：不启用「更多」实体 Tab，预留扩展位；底部 Tab 严格保持 5 个。
- **既有真实系统落点（S1 已落地，精确落点见 §7.5）**：
  - 坊市、任务 → 下沉「宗门」页核心操作宫格，作为二级入口（匹配 S1 操作频率）。
  - 御兽 → 下沉「宗门」页次功能收纳区（BeastSlot 占位槽，默认折叠，归属「宗门规制」分类），非宫格模块（裁决 #3 收敛，区别于 坊市/任务）。
  - 推演 → 顶部状态栏最右侧全局常驻古风按钮（「推演时日」），全页面可见，不占 Tab 名额。
- **扩容规则（S2）**：模块超出二级入口承载时，将最右侧「纪事」替换为「更多」，收纳纪事/设置/推演等低频模块，保证底部 Tab ≤ 5。

### 7.2 核心操作宫格：3 大 + 3 小（权重分级）
- **上排大按钮（高频核心）**：建筑、坊市、修炼 —— 视觉权重最高。
- **下排小按钮（次频）**：洞府、任务、账册 —— 尺寸缩小 1/3。
- **去重**：弟子已有底部 Tab 一级入口，宫格不再放置，避免同级冗余。
