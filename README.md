# xiuxian-game

> TapTap 修仙手游 · 从零开始的项目仓库。
> 这是第 1 天的练习工程：**Dodge the Creeps**（官方入门教程），用来熟悉 Godot 的「场景 / 节点 / 脚本」三大概念。

## 怎么打开
1. 下载并安装 [Godot 4.7](https://godotengine.org/download)（免费，绿色版，无需安装器，最新稳定版）。
2. 启动 Godot → **Import（导入）** → 选择本仓库里的 `project.godot` → 打开。
3. 按 **F5**（或右上角 ▶ 播放）运行，用 **方向键 / WASD** 移动，躲开妖兽，点「开始」重生。
