## 1. 页面定位与入口
- 一级入口：主界面侧边入口「库藏」（或商驿采购后跳转），进入本二级页。
- 返回：左上「← 宗门」返回主页（emit `返回主页`）。
- 性质：**只读展示**，零 `GameState` 写入；读数经 `is_instance_valid(Game)` + `.get()` 守卫。

## 3. 信息架构
```
顶栏（返回 + 标题）
计数行（物品总数 + 实时数值）
滚动区：
  └ 物品行 ×N（名称 / 品阶 / 类别）【每条 Panel + 分隔】
空态：库房空空如也，去商驿采购吧
```

## 4. 交互规则
- **展示**：`_populate()` 读 `Game.宗门库房` 数组，逐条 `_add_item_row()` 渲染。
- **每物品字段**：`名称` / `品阶` / `类别`（直接读 Item 实例）。
- **空态**：库房为空 → 显示提示「（库房空空如也，去商驿采购吧）」。
- **返回**：emit `返回主页`。
- 物品行只读，无点击详情（当前源码未实现点击）；后续可加详情二级视图。
