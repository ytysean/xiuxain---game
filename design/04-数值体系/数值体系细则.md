# 《太玄宗门录》数值体系细则
> 版本：v1.0 ｜ 对齐总览v2.2 ｜ 用途：数值策划、程序实现的底层依据
> 核心原则：严格遵守全局红线，所有增益分层乘算，不突破封顶阈值

## 一、全局增益乘区规则
### 1. 乘区划分与封顶
| 乘区分类 | 包含内容 | 封顶规则 | 计算层级 |
|----------|----------|----------|----------|
| 基础属性乘区 | 境界基础值、资质系数、灵根系数、职业主辅修系数 | 无封顶 | 第1层（最底层） |
| 通用增益乘区 | 功法、装备词缀、灵兽羁绊、宗门大阵、羁绊效果 | 总增益≤25% | 第2层 |
| 道心独立乘区 | 道心等级全属性/修炼/突破加成 | 总增益≤10% | 第3层 |
| 临时战斗乘区 | 战斗丹药、符箓、法宝主动效果、阵法触发 | 单局生效，同类取最高 | 战斗内实时计算 |
| 减耗专属乘区 | 熟练度、心法、装备词条减耗 | 常驻减耗≤40% | 独立计算，不影响战力 |

### 2. 计算规则
- 同乘区内百分比增益为加算，跨乘区为独立乘算，无稀释效应
- 职业主辅修系数、灵根系数、资质系数为基础属性，不占用25%通用增益额度
- 灵兽战力按30%比例叠加到弟子最终战力，不参与前端乘区放大

## 二、弟子战力完整公式
弟子最终战力 =
境界基础战力
× 资质系数
× 灵根属性系数
× 职业综合系数（主 1.0 + 辅 0.7 + 三修 0.4）
× (1 + 通用增益总和) -- 上限 0.25
× (1 + 道心增益) -- 上限 0.10
灵兽契约战力加成 -- （主宠战力 ×1.0 + 副宠战力 ×0.7）× 30%

4.1 全局增益乘区划分
所有增益划分为 5 个独立乘区，严格区分「基础系数」与「增益乘区」，从根源避免数值突破红线。

| 乘区分类 | 包含内容 | 封顶规则 | 计算层级 |
| --- | --- | --- | --- |
| 基础属性乘区 | 境界基础值、资质系数、灵根系数、职业主辅修系数 | 无封顶（随成长自然提升） | 最底层，优先计算基础值 |
| 通用增益乘区 | 功法加成、装备词缀、灵兽羁绊 / 共鸣、护山大阵、聚灵大阵、掌门加成（聚灵 / 护山大阵效率放大） | 软上限≤25%，绝对硬上限≤30%（溢出部分按 20% 衰减），详见 11.8.3 | 基础值 × (1 + 通用增益总和) |
| 道心独立乘区 | 道心等级提供的全属性 / 修炼速度 / 突破率加成 | 总增益≤10% | 上一步结果 × (1 + 道心增益) |
| 临时战斗乘区 | 战斗内丹药、符箓、法宝主动效果、阵法触发效果 | 单局生效，同类取最高值 | 战斗内实时乘算，不影响面板战力 |
| 减耗专属乘区 | 技能熟练度、心法减耗、装备词条减耗 | 常驻减耗总≤40% | 单独计算灵力消耗，不作用于战力 |
| 产出效率池（独立，非战力乘区） | 丹堂 / 器堂 / 灵田 / 矿场产出速度、高阶物品出率、建筑任职技艺加成、掌门丹器加持 | 单建筑最高 +20%，全建筑合计最高 +30%（同类型建筑任职超 5 人边际衰减 50%） | 仅作用于资源产出速率 / 数量，不进入弟子最终战力公式（4.2） |

定案说明：职业主辅修衰减（主 100%/ 辅 70%/ 三 40%）、灵根系数、资质系数均属于基础属性乘区，不占用 25% 通用增益额度，保障高阶灵根 / 多职业的成长价值。

全局铁则（v2.17 补充，v2.18 追加两条）：所有常驻通用增益（掌门、护山 / 聚灵大阵、先贤堂传承、装备 / 灵兽 / 常规养成）共享同一软上限 25% 与绝对硬上限 30%（溢出 20% 衰减），**无任何系统拥有独立额度**。掌门的价值是「放大建筑生效上限」而非「额外叠加」，先贤堂是「长线底蕴补充」而非「独立加成」，二者均嵌套入同一池，杜绝双算击穿红线（数值校验详见 11.8.3）。

- **闭关类修炼加速取最高档不叠加（v2.18）**：离线被动闭关（+5%，见 6.10.8）与手动闭关悟道（+10%，见 11.8.7）属同一子类，同一时间仅生效最高档（手动 > 离线被动），绝不叠加，从根源排除双算击穿红线；其余战力类增益仍按本铁则边际叠加卡 25% / 30%。
- **产出效率池独立于战力池（v2.18）**：建筑任职 / 技艺加成仅缩短资源积累周期，归入独立的「产出效率池」（单建筑≤20%、全建筑≤30%，详见 4.1 乘区表），不占用通用战力 25% 软上限；弟子最终境界 / 属性天花板仍由战力池锁死（详见 6.12.3 / 6.13）。
- **新增增益源归类（v2.19，对齐家族 / 血脉 / 自创功法 / 灵兽）**：血脉共鸣（组队修炼 +5% / 战力 +3%，仅组队等效全局约 1%~1.5%）、家族气运（单家族≤1% 全局属性、多家族边际衰减、全局合计≤2%，占用先贤堂 5% 额度内）、家族传承功法参悟 +30%（仅单一家族功法、非全局加速）、自创功法（单功法≤3% 单属性、主修 1 + 辅修 2、等效全局约 2%）均计入通用战力池，各设单源子帽、边际乘算衰减，叠加现有大阵 / 聚灵 / 先贤 / 常规养成后总等效约 23%~24.5%，卡 25% 软上限不击穿；灵兽辅助修炼（修炼部分计通用池单只≤3%、道心部分归道心独立乘区）、灵兽生产劳作类（单只≤5% 产出、归入对应建筑效率池、单建筑≤20%）分别入池，详见 6.16 / 6.17 / 7.。


4.2 弟子面板战力计算公式
plaintext
弟子最终战力 =
  境界基础战力
  × 资质系数
  × 灵根属性系数
  × 职业综合系数（主职业1.0 + 辅修职业0.7 + 三修职业0.4，按激活职业数量计算）
  × (1 + 通用增益总和)  -- 软上限≤0.25，硬上限≤0.30（0.25~0.30 区间溢出部分按 20% 衰减折算），详见 11.8.3
  × (1 + 道心增益)      -- 增益≤0.10，独立乘算
  + 灵兽契约战力加成    -- 主战灵兽战力×1.0 + 助战灵兽战力×0.2（助战仅提供被动属性加成，不主动释放技能）
主战灵兽战力全额计入战斗结算；助战灵兽仅提供其被动属性加成的 20% 作为全局增益，不参与前端乘区放大、不主动释放技能，避免数值后期膨胀失控。
**叠加口径统一（v2.20 定案，消歧）**：通用增益乘区内，各「来源子类」（功法 / 装备 / 大阵 / 聚灵 / 先贤堂 / 常规养成 / 血脉 / 家族 / 自创功法 / 灵兽）先各自**边际乘算衰减**收敛到单源子帽（各子帽见 4.1 v2.19 条：功法类全局等效 ≤2%、血脉类 ≤1.5%、大阵 / 聚灵 / 先贤堂 / 常规各有上限），收敛值再**加算**汇入「通用增益总和」 feeding (1 + 总和)，最终强制卡软上限 25% / 绝对硬上限 30%（溢出 20% 衰减）；**跨乘区**（通用 / 道心 / 产出效率 / 减耗 / 临时战斗）为独立乘算层，永不加算合并。单源子帽 + 池总帽双重保险——禁止任何来源「裸线性加算到上限」绕过子帽，杜绝总和击穿 25%。

4.3 减耗体系分层规则
将减耗划分为常驻减耗和临时减耗两类，既守住零蓝底线，又保留战斗策略空间。
常驻减耗（计入 40% 封顶）：
技能熟练度：每级 - 4%，满级 5 级共 - 20%
心法被动：最高 - 15%
装备词条：单条最高 - 8%，叠加上限 - 15%
以上三类加总后，常驻减耗上限 40%，超出部分无效。
临时减耗（不计入封顶，单局有限制）：
聚灵符：单局使用 1 次，持续 3 回合，技能消耗 - 30%
灵兽羁绊技能：触发后 1 回合内消耗 - 50%
丹药 buff：单局 1 次，持续 2 回合，消耗 - 25%
额外规则：辅修技能耗蓝 + 20%，不受减耗抵消；符箓消耗固定为同阶功法的 70%，不享受熟练度减耗。

4.4 防御属性溢出治理红线
设计意图：闪避 / 招架 / 减伤 / 免疫类属性本质是「防御端数值溢出」，与攻击端战力膨胀同源。根治 = 统一叠加规则 + 硬上限兜底 + 边际收益衰减 + 对应属性制衡，并严格区分「常驻属性」与「临时技能效果」。本节省略设计原理与公式，详见 9.4。
※ 以下硬上限均为设计假设初值，未经战斗实测，实装前标 [PLACEHOLDER] 调优。

| 红线 | 规则 |
| --- | --- |
| 规避类属性封顶 | 闪避 ≤ 70%、招架/格挡 ≤ 75%；规避类效果互斥，单次伤害仅判定一次（优先级 招架 > 闪避 > 命中） |
| 减伤类属性封顶 | 常驻全减伤 ≤ 70%、常驻单系减伤（物理/法术）≤ 75%；战斗临时减伤 ≤ 90% 且持续 ≤ 3 回合，不可全程覆盖；单次伤害最低强制扣 1 点气血 |
| 状态抵抗封顶 | 所有负面状态抵抗率 ≤ 85%；禁止常驻 100% 免疫，免疫效果仅限 临时技能 / 境界压制 / 低阶豁免 三种形式 |
| 叠加规则 | 所有概率类、减免类属性采用乘算衰减叠加，禁止线性加算；同类属性先加算到阈值后进入衰减区 |
| 制衡规则 | 闪避对应命中、减伤对应穿透、抵抗对应效果命中，防御属性永远有对应对抗属性 |

4.5 性能预算与复杂度上限（v2.40 新增，对应评审「逻辑侧性能炸弹」预警）

设计意图：本文档为设计层，数值不会被「算崩」（见 4.4 / 9.4 免伤·免疫·减伤硬上限，只会失衡不会机制崩）。但**逻辑侧存在三个隐性性能炸弹**，必须在设计层立铁则，否则上线后玩家回归 / 读档会出现卡死、GC 抖动、甚至 OOM 崩溃：

1. **离线追赶推演（最大隐患）**：§6.10.8 规定「离线期间所有时间推演、任务派遣、建筑产出、事件触发全部正常执行」。道品宗门可达 500 正式弟子 + 大量记名，且弟子含自主 AI（§6.13）、履历自动更新（§6.10）、传记动态刷新、随机生成。若按「逐秒模拟」重放 N 天 × 上千弟子，回归瞬间主线程冻结。
2. **存档膨胀**：上千弟子 × 多层属性 × 履历数组，无上限约束 → 读档慢、内存抖动。
3. **时间倍率 × 实时产出**：现实 1 天 = 游戏 1 年（§11.7.1），任何「每秒产出」逻辑都会指数爆量。

**铁则一 · 区间批量结算（禁逐秒模拟）**：所有时间推进（修炼 / 突破 / 产出 / 事件 / 自主 AI / 传记生成）一律以「区间结算」执行——仅计算区间起止的**终点状态**，不重放中间每一秒。回归时调用 `game_state.gd` 统一时间轴，一次性结算「离线 N 游戏年」的资源净增量与关键事件列表，弟子履历仅在**关键节点**（突破 / 死亡 / 重大事件）落一条记录，不逐帧写。

**铁则二 · 离线推演步长软上限 + 快照降级**：单次回归结算的「等效推演步数」设软上限 `[PLACEHOLDER：建议单宗门 ≤ 2000 步 / 次回归]`；超限时走「快照插值」——只结算资源总量 + 关键事件，跳过精细履历与自主 AI 微行为，保证回归 ≤ 1 帧预算。

**铁则三 · 同屏与单宗门软上限**：① 驻地同屏渲染弟子软上限 `[PLACEHOLDER：建议 ≤ 60 实时模型，余量走剪影 / 实例化]`，对齐美术规范 §5.1；② 单宗门推演预算：正式弟子 ≤ 500（§11.1.1）+ 记名独立上限，超出部分进入「休眠批次」仅参与异步产出结算，不参与实时 AI。

**铁则四 · 存档体积预算 + 履历滚动归档**：① 单存档序列化字节预算 `[PLACEHOLDER：建议 ≤ 8MB / 档]`；② 每弟子履历条数滚动上限 `[PLACEHOLDER：建议 ≤ 50 条，超出归档最旧 80% 进「生平传记」压缩摘要]`，避免数组无限增长；③ 对象池复用弟子实例 / UI 卡片（对齐美术规范 §5.2）。

**铁则五 · 事件堆积上限统一**：复用 §6.13.5 巡察「7 天累计上限」规则，扩展至全事件类型（奇遇禀报 / 产出告警 / 外交来信），回归时仅保留最近 `[PLACEHOLDER：建议 30 条]` 待处理事件，防消息洪流。

**铁则六 · 时间倍率一致性**：全游戏只允许 `game_state.gd` 单一时间轴驱动；任何「每秒产出」类逻辑必须改写为「每游戏年产出 × 时间倍率」，禁止在渲染帧里直接累加现实时间，杜绝倍率错位。

**失败态 / 边缘处理**：① 结算超时 → 自动降级为「仅结算资源总量 + 关键事件」，跳过精细履历，保证不卡死；② 存档超预算 → 自动归档最旧履历并提示「传记已压缩」；③ 推演步数超限 → 截断非关键 AI 行为，标注「本次离线部分微行为未模拟」。

4.7 平衡基准与目标曲线（v2.41 新增，对应评审「全数值 [PLACEHOLDER] 无校准靶心 / 未定义 broken」缺口）

设计意图：本作全数值均标 [PLACEHOLDER] 待实测，但实测必须有一把「靶尺」——本节约定义三轴（战力 / 经济 / 时间）的目标数学曲线与「broken（失衡）」判定阈值，让所有 [PLACEHOLDER] 有校准方向，避免盲调。

**一、战力轴（战斗平衡，对齐 §4.1 / §4.4 / §9.4）**
- 目标曲线：同境界弟子战力方差 ≤ [PLACEHOLDER：建议 30%]（资质 / 灵根 / 养成差异，不含 buff 堆叠）；越阶击杀上限 = 跨 1 大境界可胜、跨 2 大境界仅险胜、跨 3+ 不可胜（守 §9.4 境界压制机制层）
- 等效战力折算：防御溢出按 §4.4 乘算衰减 + 硬上限，等效战力不超过攻击侧 [PLACEHOLDER：建议 1.2×]
- **broken 判定**：任一弟子稳定越 2+ 大境界击杀同练度对手；或单乘区突破 §4.1 软 / 硬上限未衰减；或某 buff 组合等效战力 > 基准 3× → 立即回退并锁该增益

**二、经济轴（通胀防护，对齐 §11.9）**
- 目标曲线：灵石 / 日 / 活跃玩家随宗门品级单调增，但增速 ≤ 产业封顶（§6.12.3 思路）；各进项占比（产业 / 任务抽成 / 奇遇掉落 / 坊市）目标 [PLACEHOLDER]
- 通胀阈值：货币 / 日 / 人超 [PLACEHOLDER：建议基线 1.5×] 触发平衡 pass；全服高阶弟子总产出守 §6.1.6 宏观调控上限
- **broken 判定**：任一资源单价 / 日跌幅超 [PLACEHOLDER]；或日获取上限形同虚设（可无限刷取）；或俸禄体系入不敷出致宗门破产率 > [PLACEHOLDER] → 触发节俭令 / 回退

**三、时间轴（挂机 / 在线平衡，对齐 §13.2）**
- 目标曲线：炼气 → 化神零付费目标天数 [PLACEHOLDER：建议 60~120 天]；各境界突破耗时梯度递增
- 在线溢价：当前离线保底 +5%、在线仅少 5~10%（§13.2），目标维持「在线操作溢价 ≥ [PLACEHOLDER：建议 15%]」——手动干预奇遇 / 配队 / 限时事件必须显著更高收益
- **broken 判定**：离线收益 ≥ 在线收益（收菜党碾压沉浸党）；或单日可推进游戏年数超推演步长软上限（§4.5 铁则一）导致结算卡顿 → 强制区间批量结算降级

**校准流程（强制）**：① 纸面模拟跑通三轴目标曲线 → ② MVP 实测采集真实数据 → ③ 任一轴触 broken 即回退对应 [PLACEHOLDER] 至上一稳定值 → ④ 灰度放开。所有数值上线前必须至少有 1 次纸面模拟记录。

4.8 数值平衡落地保障体系（v2.42 新增，扩展 §4.7；对应评审「平衡校准靶心 / 单人快速调平衡」+ 用户提案落地）

设计意图：§4.7 定义了三轴目标曲线与 broken 判定（"测什么"），本节定义"怎么保证平衡可落地、可单人快速调"的方法论与工具契约（经济闭环公式 / 成长节奏卡点 / 表格驱动 / 全局阀门 / AI 模拟验证），与 §4.7 互补、不重复。

**一、三层平衡核心框架**
- **（1）经济系统平衡：闭环可控**
  - 核心公式：**月度总产出 = 月度刚性消耗 + 15%~25% [PLACEHOLDER] 盈余**。
  - 刚性消耗（固定消耗出口、不提供增益，对齐 §11.9）：弟子俸禄、建筑维护、修炼耗材、制式装备配发。
  - 盈余用途：宗门扩张 / 建筑升级 / 风险储备；控制盈余率避免恶性通胀（守 §4.7 经济轴 broken）。
  - **动态消耗阀门**：玩家盈余过高（超盈余上限）时，§11.11 负向事件伤害自动提升（局部放大 event_damage_rate），消化冗余资源——事件既是风险也是平衡器，防囤积通胀。
- **（2）成长节奏平衡：指数级卡点**
  - 资源需求指数增长：每提升 1 大境界，所需核心资源 = 上一境界 ×3.2 [PLACEHOLDER] 倍。
  - 突破失败回撤：成功率梯度（初版建议值待实测，对齐 §6.3 突破机制）——金丹 70% → 元婴 55% → 化神 40% → 炼虚 28% → 合体 15% [PLACEHOLDER]；失败掉落 1 个小境界、需重新积累，形成"再投资"压力。
  - 硬性门槛：高阶突破需对应宗门等级（§11.1）、气运（§6 血脉/机缘）、声望（§2.1 阵营），无法仅靠资源堆砌——守 §4.1「不靠单一数值维度破局」。
- **（3）玩法强度平衡：动态适配**
  - 负向事件（§11.11）/ 秘境怪物 / 敌对宗门强度，均与宗门总战力、等级挂钩：**实际强度 = 基础值 × 宗门等级系数 [PLACEHOLDER]**，避免前期过难、后期过简单（守 §4.7 战力轴 broken）。

**二、单人开发可用平衡方法论**
- **（1）基准锚定法**：先定 1 个核心基准单位，所有数值同比例推导，从根源避免凭空拍数。
  - 示例基准锚（对齐 §8.1 丹药系统）：1 名炼气期弟子，1 天修炼消耗 1 瓶聚气丹；1 瓶聚气丹材料成本 5 灵石，坊市售价 6 灵石。
  - 向上推导：筑基/金丹/元婴的修炼消耗、丹药成本、俸禄标准（§11.9.2）均按此基准同比例缩放，跨系统数值同源（呼应 §6.1.5 弟子属性同源公式）。
- **（2）全表格驱动，零硬编码**：所有数值（物品价格、修炼速度、突破概率、事件伤害、建筑产出）全部存入 CSV 配置表，代码不写死任何数值；调平衡仅改表不改码，AI 可辅助批量生成/修改数值表（与 §11.11 events.csv 同源思路）。
- **（3）预留全局调节阀门**：全局配置表设 4 个总控系数，上线后一键快速修正整体平衡（守 §4.7 校准流程）：
  - `global_income_rate`：全局产出系数，默认 1.0，通胀则调低、通缩则调高；
  - `global_cost_rate`：全局消耗系数，默认 1.0，控制整体消耗压力；
  - `event_damage_rate`：事件伤害系数，默认 1.0，整体调整 §11.11 负向事件强度（亦作动态消耗阀门的执行旋钮）；
  - `trade_profit_rate`：商路收益总控系数，默认 1.0，专门压制 §11.15 贸易玩法整体收益率，商路收益溢出/通胀时一键下调（如 0.8）即快速修正，不影响其他系统。

**三、快速验证方法（AI 辅助模拟）**
用 AI 辅助编写简易模拟脚本，输入初始数值后自动模拟宗门长期运行，替代手工纸面推算：
- **单系统验证**：分别验证丹房/矿场/坊市等单系统产出−消耗是否闭环；
- **跨系统验证**：模拟「产出→售卖→发俸禄→弟子成长→更多产出」完整循环；
- **长线验证**：模拟 365 天运行，输出最终资源总量、弟子境界分布、通胀率，对照 §4.7 三轴 broken 判定，确认未崩数值。
- 模拟脚本本身不入 GDD 代码库（守纯增量/不写游戏代码铁律），仅作为开发期平衡验证工具使用。
