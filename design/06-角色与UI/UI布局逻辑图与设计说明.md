## 1. 竞品范式提炼（竖屏单手操作视角）

对标《一念逍遥》《想不想修真》《修仙家族模拟器》《放置修仙》《我欲修仙》《以仙之名》等同类修仙经营手游，提炼 5 条共性规律：

1. **底部 3–5 个主 Tab + 常驻跨页**：核心域（主城/弟子/历练/社交/更多）固定在屏幕底部，跨所有一级页不释放，单手拇指一触即达。
2. **核心操作集中在屏幕下半「拇指区」**：高频操作（收菜、突破、派遣、抽卡/奇遇）落在 y≈480–800 的拇指可及弧内；主屏首页用**宫格/列表**承载次级功能入口，重要资源/货币**常驻顶部状态带**。
3. **「主界面 = 经营总览 + 快捷入口」范式**：主城页只做「全景概览 + 异常提醒 + 快捷宫格」，深度功能进二级页；对应本项目 §11.22「主界面极简、信息架构三级收纳」。
4. **养成/详情用二级页、从右/底部滑入、左上角返回**：一级 Tab 之间整页切换无返回；Tab 内的子系统用顶部二级标签（chip）切换；详情页默认折叠高级属性，降低首屏认知负荷。
5. **异常才提醒 + 渐进解锁**：红点/角标仅标异常（待突破/资源告急/商队遇袭）；新系统按等级阶梯解锁（§11.22.3 / §13.1），开局不信息爆炸。

## 4. 底部主导航方案

### 4.1 推荐方案（主推）
**底部 5 Tab = `宗门 / 弟子 / 殿阁 / 历练 / 御兽`**

| Tab | 名称 | 承载功能域 | 解锁/来源 |
| --- | --- | --- | --- |
| T0 | **宗门** | 主屏首页：状态带 + 目标条 + 全景概要 + 快捷宫格（洞府/修炼/坊市/任务/账册/御兽/地图/奇遇）+ 宗门动态 | 常开（默认选中） |
| T1 | **弟子** | 养成核心：名录/接引/派遣/师徒/本命/转职/转生 | 常开 |
| T2 | **殿阁** | 经营核心：12 堂口/建造升级/阵法/灵植/炼器丹房 | 常开 |
| T3 | **历练** | 探索战斗：秘境/副本/世界事件/大比/派遣/商队贸易 | 常开（独立 Tab，非弹窗） |
| T4 | **御兽** | 灵兽：孵化/驯养/出战 | 🔒 Lv.3 或 FTUE（灰锁可显） |

- **纪事**（低频浏览型）→ 降级为「宗门页 W3 宗门动态区块」+ 右上角抽屉二级入口，不占核心 Tab。
- **设置/社交/商店/邮件/排行** → 右上角轻量抽屉（对齐 §11.22「更多」），不堆主界面。
- **推演/存读** → 正式版移除主动入口（§1.6）；离线收益改「上线简报 + 周期结算 + 账册」。

### 4.2 为何优于现有 5 Tab（A/B 方案的 宗门/弟子/殿阁/历练/纪事）
1. **第 5 位 纪事 → 御兽更合理**：御兽（灵兽养成 + 出战）是差异化玩法，且有 Lv.3 解锁的期待感，比低频浏览的纪事更值得常驻核心位（对齐硬约束 §1.3 把御兽列为核心 Tab 的意图）。
2. **修复首页双重入口**：现状 `sect_home_page.tscn` 宫格含「弟子」「纪事」，与底部 Tab 完全重复，违反 §11.22「内容再多不堆主界面」。本方案宫格只放二级/快捷功能。
3. **修复断链**：现状首页缺「御兽/坊市/任务/账册/地图/奇遇」高频入口，玩家需绕路；本方案在宫格 + 抽屉统一收口。
4. **对齐单手范式**：御兽作为第 5 Tab 仍是最易触的底部位；纪事降为宗门页区块后，玩家每次回首页即可见近期大事，反而提升信息触达。

### 4.3 若保留现有 5 Tab（宗门/弟子/殿阁/历练/纪事）的最小微调建议
若主理人坚持保留「纪事」核心 Tab（即方案 A/B/E），则微调为：
- 首页宫格移除「弟子」「纪事」两个与 Tab 重复的入口；
- 宫格补「御兽」「坊市」「任务」「账册」「地图」入口（御兽可先以宫格二级形式存在，Lv.3 后可选提升为 Tab）；
- 纪事 Tab 内整合「成就/图鉴/传记」避免功能碎片化。

## 6. 操作习惯优化清单（单手 / 拇指操作）

1. **拇指热区优先**：竖屏单手，拇指可达弧 ≈ 圆心 (240, 700)、半径 ~280 的下半圆。底部 5 Tab（y 794–854）与首页宫格（y 308–588）均落在该弧内，最高频操作零位移可达。
2. **高频操作下沉**：一键收取/突破/派遣/发车等主操作按钮固定在页面底部（Tab 之上 y≈742–790 的常驻操作条），不藏在页面深处。
3. **返回路径统一**：一级 Tab 间整页切换、无返回键；二级页统一「左上角 ← 返回」+ 右滑返回（§11.22.6）；详情弹窗用底部「退下」条（S1 wireframe §1.5）。
4. **误触规避**：
   - 所有可点目标 ≥44×44px（§1.8 / ACCESSIBILITY）；底部 Tab 与页面底操作条物理分离，避免切页误触。
   - 危险操作（遣散/出售/强冲）用二次确认或长按，不一步直达。
   - 左右安全边距 8px，内容不贴屏边；锁态项 `disabled+🔒+tooltip`，点击不产生跳转（§1.5）。
5. **二级页滑入方向**：同级 Tab 整页切换（queue_free + 重建，§1.4）；Tab 内子系统用顶部 chip 切换；详情/二级页从**右侧滑入**或**底部上滑**，符合右手拇指手势。
6. **异常才提醒**：仅异常状态（待突破/资源告急/商队遇袭/重伤）出红点/数字；正常系统静默，通知收右上角抽屉（§11.22.1/§11.22.4）。
7. **渐进解锁降低首屏负荷**：新系统按宗门等级阶梯解锁，首次进页出轻量气泡提示核心按钮，看完自消（§11.22.3 / §13.1）。
