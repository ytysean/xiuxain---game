# 《太玄宗门录》凡人香火系统设计（GDD · 基础框架）

> 本批次定位：搭建 S1 赛季主题核心系统的**基础框架**（核心循环 / 香火值机制 / 信徒体系 / 与首发经济·声望线接入点）。事件、剧情、数值梯度为内容填充项，可并行推进，不阻塞其他系统开发。数值阈值、事件表、信徒属性标 `[PLACEHOLDER]`。
> 本 GDD 对应 `00-INDEX.md` 缺口⑦（S1 核心系统之一）。强关联 `GDD-辈分礼制.md`（沉浸补充，延后）、`GDD-阵营系统.md`（正邪路线承接宗门3级后成长溢出）。

## 1. 概述

### 1.1 系统定位
- **S1 赛季主题核心玩法**：承接宗门 3 级后的成长溢出（《版本内容拆分与路线图》二.1）。
- **关联核心经济**：深度挂钩首发资源体系（灵石/灵气/草药/矿石）与宗门声望线，提前定规则可在首发数值配置时预留接入点，避免后续返工改核心经济表。

### 1.2 设计目标
- 给「修仙宗门庇佑凡人」以正反馈闭环，强化沉浸感与长线目标。
- 香火值作为新型「软货币」，不直接进入兑换链（引 `§11.20.4` 特殊属性类货币定位），仅通过玩法行为积累/衰减。

### 1.3 范围
- **首发 v1.0**：不开放；仅预留接入点（声望线、资源产出钩子）。
- **S1 v1.1**：完整开放核心循环 + 基础事件 + 信徒增益。

## 2. 核心循环

```
凡世城镇交互 → 香火值获取 → 信徒增益（宗门 buff）→ 凡人事件（正/负反馈）→ 回流香火值
```

| 环节 | 说明 | 接入点 |
| :--- | :--- | :--- |
| 凡世城镇交互 | 解锁凡人城镇节点（2D 节点地图，引路线图一.1 历练探索） | 历练系统扩展 |
| 香火值获取 | 庇护/布施/降妖护民等行为积累 | `global_vars.incense`（引 §11.19 全局变量入口） |
| 信徒增益 | 香火值转化宗门 buff（产出加成/弟子悟性） | 资源体系 / 弟子养成 |
| 凡人事件 | 信徒祈愿、城镇灾厄、妖患求援等 | EventManager（§11.11） |

## 3. 香火值机制

### 3.1 获取来源 `[PLACEHOLDER]`
- 庇护凡人城镇（周期结算）
- 布施/济贫行为
- 降妖护民事件成功
- 弟子游历凡间功德转化（关联 `§11.18` 功德）

### 3.2 消耗 / 转化 `[PLACEHOLDER]`
- 信徒增益 buff 激活消耗
- 城镇建设/赈灾投入
- 不直接兑换灵石（避免通胀，引 `§11.20.4` 边界）

### 3.3 衰减规则 `[PLACEHOLDER]`
- 久不交互是否衰减、衰减速率 —— 待数值组校准。
