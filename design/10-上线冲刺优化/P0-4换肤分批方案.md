## 4. 排序依据（4 条，写死）

1. **依赖序**：token 层（波 1）**先于**任何站点层。否则站点改完 token 又变 ⇒ 返工。依据 `ui_theme.gd:1459-1461`。
2. **枢纽序**：被 **≥2 页复用**的非页面文件（顶栏/底栏/容器/共享组件/弹窗）先于页面（波 2）。改一次多页受益、文件少易验。
3. **风险序（同层内）**：**低频页先练手**（波 3）→ 中频（波 4）→ **高频/主视觉后动**（波 5）→ **最大单文件 + 战斗最后**（波 6）。到达频次越低，回归的玩家可见面越小、可逆性越高。
4. **隔离序**：逻辑层（波 7）与非生产（`tests/`）**单列/排除**，不裹进 UI 换肤（避免把调试色/数据色误当 UI token）。

## 6. 验收判据（每波统一）

1. **截图差分（真实渲染 · 主判据）**：`ui_full_accept` 出 64 页 → `diff_shots.py` 比对：
   - 本波**涉及页** = `COLOR_DELTA` 且主改 `from→to` **命中** token 目标色（`--expect` 填本波期望表）；
   - 本波**未涉及页** = `IDENTICAL`（**跨页零污染**，硬判据）；
   - 无 `LAYOUT_SHIFT`、无 `SIZE_MISMATCH`、无缺页。
2. **棘轮（静态）**：`audit_ui.py --strict` —— 硬编码 Color / 裸 StyleBoxFlat **单调下降、不得上升**。
3. **门禁**：`.workbuddy/gate_all.py` 全绿。
4. **语义出口（静态）**：本波换掉的站点**不再含对应色系字面量**（如金系只剩 `color.gold.*` 三/四出口）。

> **每波独立可通过/独立可回滚**；任一判据 FAIL ⇒ **整波回滚**，不带入下一波。
