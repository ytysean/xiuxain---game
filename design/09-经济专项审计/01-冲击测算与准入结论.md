# 经济冲击测算与准入结论（ECON-02）

> 本审计为「路径乙：排雷优先」第二截，接 ECON-01 基线数字，对 4 个 D 类高风险功能做冲击测算并给准入结论。
> **核心约束**：当前版本 总产/总耗 比值 ≈ ∞（刚性消耗全 STUB），红线不可算；改用「月度盈余率 15%~25% 窗口」作为**可算红线**，其余硬上限（产出效率池 ±20%/±30%、事件渠道 <5%、通用增益软25%/硬30%、道心10%）照常静态守。

---

## 一、测算方法论与可算红线

### 1.1 为什么比值红线不可算，改用盈余率窗口
- ECON-01 已确认：自动月度总产 ≈ **366**，自动月度总耗 ≈ **0**（C4~C7 全 STUB，仅 T03 微量）。分母≈0 → 比值 ≈ ∞，**不可算、不可守比值红线**。
- 退而求其次：以 §4.8 闭环口径「**月度总产出 = 月度刚性消耗 ×(1.15~1.25)**」即**盈余率 15%~25%** 作为可算红线。只要把刚性消耗校准进 [293, 318] 区间，比值就收敛到 [1.15, 1.25] 可见区间。

### 1.2 比值收敛测算逻辑（运维成本引入后）
- 目标窗口换算：刚性耗下限 = 366 ÷ 1.25 = **292.8**（盈余 25%，耗最小）；刚性耗上限 = 366 ÷ 1.15 = **318.3**（盈余 15%，耗最大）。
- 即：要使闭环成立，**新增刚性消耗必须落在 [293, 318] 灵石/月**（中心 ≈ 305）。
- 引入后：比值 = 366 ÷ 305 ≈ **1.20** ∈ [1.15, 1.25] ✓ 收敛、可算、可守。

### 1.3 基准与场景定义
- **基准（标准局）**：L=4 / N=48 / 12建筑各 BL=2 / 经营加成均+10%；自动总产=366、自动总耗≈0、净值=366、盈余率=未定义。
- **红线标尺**：
  - 系数/总盘 ±15%（ECON-01 Layer A/B）；
  - 单建筑产出效率 ≤+20%、全建筑 ≤+30%（§4.1）；
  - 事件渠道（机缘+秘境）占全渠道 <5%（§4.7）；
  - 月度盈余率 15%~25%（§4.8，本审计主可算红线）；
  - 通用增益软25%/硬30%、道心独立10%（§4.6）。
- **每个功能测两场景**：【常规触发】（典型运行）vs【极端满触发】（全部杠杆拉满）。均显式列出对总产/总耗/净值的 ±%。

## 二、逐功能冲击测算

### 2.1 坊市动态行情（价格浮动 ±10% / 事件联动 / 限购规则）
**性质**：交易机制，**影响玩家卖出收益与购买成本，不触碰自动 366 基底**（任务原文确认"非自动产出"）。

| 场景 | Δ总产 | Δ总耗 | 净值变化 | 比值/盈余率 | 红线判定 |
|---|---|---|---|---|---|
| 常规触发（±5% 价格漂移） | 0% | 0（自动基底未动） | 366 → 366（不变） | 比值仍 ∞（auto 未动） | ±10% 系数 < ±15% ✓ |
| 极端满触发（±10% 锁价 + 事件联动） | 0% | 0 | 366 → 366 | 比值仍 ∞ | ±10% < ±15% ✓；事件联动不计入 <5% 事件渠道（坊市为独立交易渠道）✓ |

**关键说明**：
- 坊市 price float 是**交易系数**层面的 ±10% 摆动，落在 ECON-01 Layer A「系数偏差 ≤±15%」内，**不破红线**。
- 它不增加自动产出、不增加自动消耗，对零通胀闭环**中性**；玩家主动层（P4 日常≈34600）的卖出收益随 ±10% 浮动，但那是玩家流动性，不计入自动基底 366。
- **限购规则**反而是通胀抑制器（限制可刷取的坊市收益），应保留并做强。
- **唯一隐患**：事件联动若让"事件"经坊市发放灵石，可能被误计入事件渠道。须确保事件本身的机缘/秘境灵石产出仍守 <5%，坊市联动仅调价不新增灵石源。

---

### 2.2 宗门运维成本（建筑维护 / 人员俸禄固定消耗）—— 缺失的 C4/C5/C6/C7
**性质**：正是 ECON-01 F1 缺口的**补闭环功能**。引入后使比值收敛，但尺寸必须卡死到 [293, 318] 窗口。

| 场景 | Δ总产 | Δ总耗(绝对) | 净值 | 比值 | 盈余率 | 红线判定 |
|---|---|---|---|---|---|---|
| 常规触发（刚性耗=305，校准中心） | 0% | +305 | 366→61 | 1.20 | **20.0%** ✓ | 落入窗口；新消耗基线建好后 ±15% 适用 |
| 极端满触发（N↑/BL↑/成本通胀，刚性耗=318） | 0% | +318 | 366→48 | 1.15 | **15.1%**（贴 15% 下沿） | 仍合规，但无余量 |
| 极端破产（刚性耗=366） | 0% | +366 | 366→0 | 1.00 | 0%（broken 边缘） | >366 即负盈余 → 破产 broken |

**关键说明**：
- **这是唯一能补上缺失消耗闭环的功能**（F1 直接修复）。
- 校准是硬前提：刚性耗必须锁在 **[293, 318]**。低于 293 → 盈余 >25%（囤积通胀，需 §4.8 动态阀门吃冗余）；高于 318 → 盈余 <15%（宗门吃紧）；≥366 → 负盈余（破产 broken）。
- 它同时**对冲 F6**：C4 俸禄是 P2 弟子津贴（N×2=96，纯产出）的对冲项，使每弟子净贡献转负，消除"N 增长→灵石无界"的隐患。
- 必须由 **F2 全局阀门 `global_cost_rate`** 接线，便于运行时微调，避免改表重发。

---

### 2.3 建筑产业链（上游原料消耗 → 中游加工 → 下游变现，原料消耗字段预留）
**性质**：**同时增消耗（原料 sink）与增产出（变现 source）**。净值取决于二者平衡，且产出走同一产出管线，与 F3/F5 通胀杠杆叠加风险最高。

净零模型（变现值 V_o = 原料耗 C_r = 吞吐 T），须与运维成本(305)共存：

| 场景 | Δ总产 | Δ总耗(绝对) | 共存运维后 总产/总耗 | 净值 | 盈余率 | 红线判定 |
|---|---|---|---|---|---|---|
| 常规触发（T=50，净零） | **+13.7%** (+50) | +50（C_r） | 416 / 355 | 61 | 17.2% ✓ | Δ产 +13.7% < +15% ✓ |
| 极端满触发（T=100，净零） | **+27.3%** (+100) | +100 | 466 / 405 | 61 | 15.1% ✓ | 盈余在窗内，但 **Δ产 +27.3% > +15% → Layer B 总盘红线 FAIL** |
| 单独运行（无运维，常规 T=50） | +13.7% | +50 | 416 / 50 | 366 | **732%（通胀 broken）** | 无闭环则比值爆掉 |

**关键说明**：
- **单独运行必破窗**：无运维成本时，任何正产出都使盈余率飙到数百 %，直接通胀 broken。
- **与运维共存时，吞吐必须被卡死**：净零模型下盈余 = 61/(305+T)。要保持盈余 ≥15%，需 T ≤ ~100；要保持 Δ产 ≤+15%（Layer B），需 V_o ≤ 54.9。二者交集 → **吞吐 T ≤ ~55** 才能 S1 安全。
- **极端满触发（T=100）Δ产 +27.3% 击穿 ±15% 输出红线**，故"全链满吞吐变现"不可进 S1。
- **叠加 F3/F5 风险最高**：产业链变现若计入「产出效率池」，会叠 F3（经营加成无封顶）；其终端变现收益又叠 F5（日常任务不封顶，玩家流动性已≈自动基底 100×）。两条通胀杠杆同时被放大。

---

### 2.4 负面影响经济侧（资源减产 -10/-20/-35%、坊市价差、消耗增加）
**性质**：§4.8 定义的**动态消耗阀门（event_damage_rate）**——既降产出又增消耗，本意"吃冗余防囤积"，但极端满触发会击穿窗口。

| 场景 | Δ总产 | Δ总耗(绝对) | 共存运维后 总产/总耗 | 净值 | 盈余率 | 红线判定 |
|---|---|---|---|---|---|---|
| 常规触发（-10% 产出，+运维305） | **-10%** (-36.6) | +0~+小 | 329.4 / 305 | 24.4 | **8.0%**（低于 15% 窗口，吃缓冲） | 不破产但跌破盈余下沿 |
| 极端满触发（-35% 产出 + 消耗+30%，+运维305） | **-35%** (-128) | +30 | 237.9 / 335 | -97 | **-29%（破产 broken）** | 负盈余 → 破产红线击穿 |

**关键说明**：
- 运维成本(305) 仅留 20% 盈余缓冲（≈61 灵石）。负面影响是"吃缓冲"的阀门，应**只吃缓冲、不啃本金**。
- **卡阈值硬约束**：负面影响对灵石的**总经济冲击必须 ≤ 盈余缓冲 ≈ 17% 月产出（≈62 灵石）**，即无论如何不让盈余转负。
- 提议的 -35% 单档远超缓冲（吃 128 灵石 > 61），**必须砍/卡**：-35% 档下调至 ≤-17%，或后置于高门派等级/稀有事件。
- 应**主要打击非灵石资源**（灵草/矿石/丹材），灵石侧仅经"坊市价差（卖价↓）+ 消耗增加"间接作用，且总额卡在 ≤17% 缓冲内。
- 须由 **F2 阀门 `event_damage_rate`** 接线，作为动态阀门执行旋钮。

## 三、准入结论汇总（4 功能各一行）

| # | 功能 | 准入结论 | 核心理由（对照 ±15% 红线 / 硬上限） |
|---|---|---|---|
| 1 | 坊市动态行情 | **① 直接进 S1** | ±10% 系数 < ±15% 红线；非自动产出，对闭环中性；限购规则反抑通胀。前置：事件联动不得新增计入 <5% 事件渠道的灵石源；接线 `trade_profit_rate`(F2)。 |

## 四、结合 F1~F6 的联动标注

### 4.1 能顺带补上缺失消耗闭环的功能
- **宗门运维成本 → 直接补 F1（刚性消耗全 STUB）与 F6（弟子津贴 N×2 无对冲）**。这是唯一的闭环钥匙，不进则零通胀永远不成立。
- **建筑产业链（原料 sink 子集）→ 微弱辅助**：仅当吞吐≤55 的净零 sink 进 S1 时，贡献少量消耗，但**不能替代**运维成本的主闭环。

### 4.2 会击穿红线、需卡阈值的功能
- **负面影响经济侧（极端满触发）**：-35% 产出 + 消耗增加 → 盈余 -29% 破产 broken。须卡总冲击 ≤17% 缓冲，且主要打非灵石资源。
- **建筑产业链（极端满触发）**：Δ产 +27.3% > ±15% 输出红线。须卡吞吐 T≤55（S1 子集）或延后全链。
- **坊市动态行情**：±10% 在红线内，无需卡阈值；仅事件联动须守 <5% 事件渠道不串味。

### 4.3 与 F3 / F5 通胀杠杆叠加风险最高的功能
- **建筑产业链（风险最高）**：变现产出若入「产出效率池」叠 **F3（经营加成无封顶）**；终端变现收益叠 **F5（日常任务不封顶，玩家流动性≈自动基底 100×）**。两条最大通胀杠杆同时被放大 → 必须延后或卡吞吐。
- **坊市动态行情（次高）**：玩家卖出收益 ±10% 与 F5 日常任务奖励同属玩家流动性层，叠加推高可刷取收益；但限购规则可抑制，风险可控。
- **宗门运维成本 / 负面影响**：消耗侧/减产出侧，方向与 F3/F5 相反，叠加风险低。

> **跨功能强约束**：F2（全局阀门未接线）是 坊市/运维/负面影响 三者共同的运行期前提——三者进 S1 都必须先接线对应阀门（`trade_profit_rate` / `global_cost_rate` / `event_damage_rate`），否则无法运行时纠偏。F3（经营加成无封顶）须在运维成本落地的同一 PR 内补 clamp(≤0.20/≤0.30)，否则新基线产出仍会被无封顶放大、抵消闭环。

## 五、S1-P0 最终落地范围建议

**进 S1-P0（带前置条件）**：
1. **宗门运维成本** —— 强制进。刚性耗锁 [293,318]，接线 `global_cost_rate`(F2)；同 PR 补 F3 经营加成 clamp。
2. **坊市动态行情** —— 进。±10% 合规、限购做强；事件联动守 <5% 事件渠道；接线 `trade_profit_rate`(F2)。
3. **负面影响经济侧** —— 进（卡阈值）。总灵石冲击 ≤17% 缓冲（≈62）、主打非灵石资源、-35% 档下调/后置；接线 `event_damage_rate`(F2)。

**延后 S2（全链变现）**：
4. **建筑产业链** —— 全链变现延后 S2（避开 ±15% 输出红线与 F3/F5 叠加）。S1 仅允许**小吞吐净零原料 sink 子集**（T≤55，接线 `trade_profit_rate`），作为运维闭环的可选辅助，而非必带。

**S1-P0 落地优先级**：先落 **宗门运维成本（闭环钥匙）+ F3 clamp + F2 三阀门接线**，再落 **坊市** 与 **负面影响（均卡阈值）**；建筑产业链全链留待闭环稳定、阀门可用后再开。

**阻断依赖**：若 F2 阀门在 S1 无法接线，则 坊市/运维/负面影响 三者均降级为 ②（需砍强度/改实现）——因失去运行时纠偏旋钮，任何偏差只能改表重发，违背 §4.8「一键快调」原则。

## 六、附录：测算假设与边界

- **标准局假设**（同 ECON-01）：L=4 / N=48 / 12 建筑各 BL=2 / 经营加成均+10%；自动总产 366 为确定性公式 366 ∝ N·L·BL·(1+经营加成)，可整体代入任意场景重算。
- **运维成本拆分参考**（落入 [293,318] 的示例）：弟子俸禄 C4 ≈ 48×4.5≈216 + 建筑维护 C5 ≈ 12×3≈36 + 修炼耗材 C6 ≈ 35 + 制式装备 C7 摊销 ≈ 18 → 合计 ≈ 305。具体数值以校准 PR 锁定，本表仅示结构。
- **建筑产业链净零假设**：变现值=原料耗（不额外净增产出），吞吐 T 为单月流经金额；S1 子集 T≤55 使 Δ产≤+15% 且盈余≥15%。
- **负面影响缓冲口径**：盈余缓冲 = 运维后净值 = 总产−刚性耗 ≈ 61（20% 盈余）；任何负面影响总灵石冲击须 ≤ 此值，等价于 ≤17% 月产出。
- **事件渠道 <5%**：坊市/运维/产业链均为独立渠道（产业/交易/任务抽成），不计入"机缘+秘境"事件渠道；仅事件联动发放的灵石须回算守 <5%。
- **本报告未改动任何代码/配置**；涉及的 clamp、阀门接线、阈值卡位均以 diff/伪代码在 ECON-01/本报告中示意，落地由对应实现 PR 执行。

*审计铁律遵守：仅分析+报告。ECON-03（如有）可基于本准入结论推进具体实现与闸门联动。*
