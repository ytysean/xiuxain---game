## 0. 接入点总原则

1. **灰模可降级（D3 AC）**：每个真实美术节点都保留一个灰模占位实现；替换真实立绘/动画时**不崩溃、不白屏**，缺失资源自动回退灰模。
2. **节点命名契约**：每个接入点有唯一 `node_id`，代码侧按 `node_id` 挂载/替换资源；美术侧按本文件令牌产出资源，资源路径与 `node_id` 绑定。
3. **统一画布比例**：所有立绘/过场资源产出时统一比例，避免运行时拉伸变形（见各节点 `ASSET_RATIO`）。
4. **动效受控**：真实动画接入后须复用 §15.4 全局动效组件 + §15.5 令牌，受「高品质动效」降级开关约束（见 ASSET-降级开关.md）。

## 1. 接入点 A：测灵根过场（lingen_intro）

> 弟子首次测灵根触发；当前为预留接口（ADR-002），灰模为「灵气汇聚」占位光效 + 文字。

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| `node_id` | `node_lingen_intro` | 接入点唯一 id |
| 画布 | 全屏 480×854，竖屏 | 过场覆盖层 |
| `ASSET_RATIO` | 9:16（竖屏全屏） | 立绘/背景统一比例 |
| 灰模占位 | 深墨灰底 `#14161C` + 中心青霓 `#3FD0E0` 呼吸光球（blur 12px，周期 1500ms）+ 文案「灵根测度中…」 | 无真实资源时显示 |
| 真实资源 | 五行灵根对应色微光（见 ASSET-战斗 §2 五行微光 RGB）+ 灵根标识流光特效 | 五色流转（§总览 442） |
| 降级 | 关闭高品质动效→静态光球+瞬显文案，无呼吸/流光 | 对齐 §15.4 |
| 文案锚点 | design-lead 章节式新手指引文案.doc（测灵根章节） | 美术不写文案 |

## 3. 接入点 C：弟子卡（disciple_card）

> 弟子名册/详情头像卡；灰模为占位头像框 + 资质色边框（§4.4）。

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| `node_id` | `node_disciple_card` | 接入点唯一 id |
| 画布 | 卡片 自适应（名册虚拟滚动列表，见 UX-弟子名册） | 头像 64×64 起 |

| 灰模占位 | 头像占位 `#23262E` 圆角框 + 资质色边框（§4.4 七档色：凡俗 `#E0E0E0`→道胎 `#FF4400`）+ 名称条占位 | 颜色+边框双编码（色盲安全，见 ACCESSIBILITY.md §3） |

| 文案锚点 | design-lead 弟子卡字段（境界/灵根/职业/状态角标） | — |

## 4. 资源产出与降级契约

| 项 | 约定 |
| --- | --- |
| 资源路径 | `res://assets/ui/intro/{node_id}.png` 等，与 `node_id` 绑定 |
| 缺失回退 | 资源不存在→自动加载灰模占位（`_placeholder_{node_id}`），不抛错 |
| 比例保护 | 加载时按 `ASSET_RATIO` 等比缩放 + 居中裁切，禁止拉伸变形 |
| 动效令牌 | 真实动画须引用 §15.5 / §15.4 令牌，禁自定义；受降级开关约束 |
| 主题 | 赛博国风为默认；水墨主题（§15.4 九）为可选皮肤，同布局换皮 |
