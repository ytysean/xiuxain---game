# 场景动画 · 全项目美术风格总纲 v1.1

> 立项目标：**所有游戏系统的场景动画长在同一套视觉语言里**（炼丹/炼器/灵田/藏经/矿脉/阵法/执法/功勋/坊市/洗池/御兽/测灵）。
> 丹房＝第一个试验田。**本纲是所有系统场景动画的验收基线。**
> 日期：2026-09-13　｜　状态：气质口径已实证，待老大确认　｜　实测脚本：`.workbuddy/rig_art3/*.py`

> **v1.1 变更（老大两条纠偏）**：
> ① 真正的差距是**气质**（电影级质感 + 修仙感），**不是亮度参数** → 新增 §零「气质三支柱」，并把量化指标**降格为校准辅助**。
> ② **场景本身也要修仙宗门气派**，不是古代作坊 → 新增 §三「场景原画模板」。

## 零、★ 结论先行：什么叫「修仙感」（验收第一关，先过这关再谈数字）

项目现有弟子立绘 = **电影级厚涂 + 仙气**；上一版丹房产出 = **棚拍写实 + 古代工装** ⇒ 「不对味」。
差距是**三支柱全线缺失**，亮度只是收尾：

| 支柱 | 电影级立绘（必须继承） | 上一版产出（错在哪） |
|---|---|---|
| ① **渲染语言** | 厚涂油画笔触、有体积肌理、半写实、无描边 | 平涂写实、无笔触、产品目录照感 |
| ② **光语言** | **冷暖戏剧分光**（冷青轮廓光勾边 ＋ 暖调主光打在受光面）＋ 体积光 | 棚拍**均匀柔光**、无轮廓光、无体积 |
| ③ **气质/氛围** | 珠宝色调 ＋ 灵气氛围（雾/光点）＋ 通透五官 ＋ **超凡脱俗** | 纯灰无缝底、零氛围、**凡人烟火气** |
| ④ 亮度/饱和度 | 收尾校准 | ← 上一版只在追这个 |

> **铁律：先过气质关，再谈数字。** 三支柱缺一，无论色值多准都读作「格格不入」。

**实证锚点**：出图前**必读**一张项目电影级立绘（`art/characters/disciples/samples/写实国漫油画风修仙弟子立绘_*`），
用它作 `image1` 且 **`input_fidelity=high`**（**勿用 low —— 实测 low 会把质感稀释成平涂**）。

## 一、跨类别视觉 DNA（量化 · 保留作校准基线）

口径：lum=Rec709 亮度｜sat=HSV 饱和度｜R−B=色温（正=暖）｜白%=近白像素占比。

| 资产类别 | lum | sat | R−B | 白% | 结论 |
|---|---|---|---|---|---|
| **建筑场景** 12 张 | 50–128 | 0.24–0.59 | **+25~+33** | <3 | 低明度、**暖调**、暗部近墨；单张内部明暗对比极大 |
| **弟子立绘** depth | **53–57** | **0.56–0.57** | **−18~−20** | **0.2–0.4** | 中低明度、**中等饱和**、**冷青基调**、**几乎无白** |
| **NPC** 6 张 | 57–103 | 0.32–0.72 | −26~+61 | <3 | 暖冷两系（丹房/藏经长老偏青碧，坊市商人偏暖赭） |
| **宗主立绘** masters | 58–193 | 0.09–0.40 | −21~+50 | <10 | 低饱和、暗部厚重 |
| **建筑图标** icons/building | ~175 | 0.35 | **+46** | ~49 | 亮底符号、**暖金** |
| **入口图标** icons/entry | ~117 | 0.41 | **+27** | ~22 | 暖、符号化 |
| **UI 主题** ui_theme.gd | — | — | 冷(#1B272B)＋暖金(#C9A656/#E8CE8A) | — | 深青黛底 + 暗金点缀 |

### ★ 三条项目级视觉公约（所有新资产必须服从）
1. **暗青黛底 + 暗金点缀**：底色冷青（丹房/藏经偏青碧，坊市偏暖赭），**金/朱砂只作点缀**（朱砂 #B3423D = 伤害/危险/印章，少量）。
2. **"低饱和"= 中等饱和（sat 0.45–0.60）**，不是真·灰。→ 见 §六陷阱词。
3. **几乎无纯白**：立绘白像素 <0.4%，场景 <1%。**纯白 = 自发光 = 越界**。

## 二、★ 角色精灵出图 prompt 模板（v1.1 修正 · 继承电影级）

> 与 v1.0 的关键差别：**加回"厚涂/电影海报质感"、加回"冷暖分光"、删掉"纯灰底压平"倾向**。
> 技术参数：`image1` = 项目电影级立绘，**`input_fidelity=high`**；`quality=high`；`revise=false`。

```
【风格】写实国漫油画风，厚涂油画笔触质感，电影海报级质感，电影级戏剧打光，东方修仙意境；笔触感强，明暗对比强烈，厚涂体积感。
【人物】<门派>弟子，<青年男/女>，<清瘦挺拔/端方/英挺>；写实正常人体比例，约六头身，绝对不要Q版、不要大头娃娃。五官清俊细致、眼神<沉静内敛/有神>；<束发戴木簪>，身着<主色>素面交领道袍，<罩短褂/腰束布带>。
【姿态】全身像，从头到脚完整可见，双脚踩地站立；侧身背向镜头，身体朝向画面<左/右>前方约60度，3/4背影视角；<持蒲扇垂于身侧>；绝对不要正视镜头、不要正面站姿。
【光线】主光源来自<左下>（丹炉炉火方位），暖橙红光照亮面部下缘、颈侧、袍摆与袖口内侧；<右后上方>有一道冷青色环境轮廓光，勾亮发丝边缘、肩线与背脊轮廓，冷暖分光对比。
【色调】珠宝色调：松青、黛青、暖褐、鎏金，墨发泛冷青高光，肤色暖润通透有血色层次。
【要求】厚涂油画笔触明显，布褶有笔触与体积；不要棚拍式均匀柔光、不要平涂色块、不要产品目录写真、不要廉价3D渲染感、不要现代元素。
【背景】单一纯色中灰 #CFCFCF，无环境物体、无投影、无渐变，便于抠图。
```
> ⚠️ 背景从 v1.0 的 #E8E8E8 改 **#CFCFCF**（中灰）：纯浅灰底会把模型带向"棚拍产品照"，中灰更容易被模型读成"氛围暗调"。
> ⚠️ **不要再写**「低饱和」「青白灵气微光」「无高光」（致灰/致发光/致平涂）。

**实证样张**（`.workbuddy/rig_art3/_raw/`）：
- 半身 `..._14-34-16.png`（首验，风格成立）
- 全身 `..._14-34-50.png`（进场景版，前景 L=48.3 / 抠底前景占比 32.0%）

## 三、★ 场景原画出图 prompt 模板（v1.1 新增 · 修仙宗门 ≠ 古代作坊）

> 旧 `dantang.png` 的问题：**土黄木柜 + 藤蔓果蔬 + 烟火气 = 凡间丹房**，缺仙门气派。
> 新场景要：**仙光体积光 + 灵火 + 悬浮法器 + 阵法光纹 + 灵雾粒子**。

```
【风格】写实国漫油画风，厚涂油画笔触质感，电影海报级质感，电影级戏剧打光；东方修真仙侠意境，宏大神秘，灵气氤氲。
【场景】<门派>·<殿阁>内部，宏伟的修仙宗门洞天秘境。强纵深：前景<青玉石阶与周天法阵光纹>，中景<巨大的八卦玄铁丹炉，炉身镌刻发光符箓与星图，炉口腾起青金色灵火并缭绕丹烟>；四周<环列博古药柜>、半空<悬浮的玉葫芦与药玉瓶>、飘浮的灵气光点。
【光】主光源来自<丹炉灵火>（青金冷暖交织），自下方与中心升腾照亮；另有自上而下几道淡金仙光（洞天天窗漏光）形成体积光束；整体冷青为底、暖金为点，电影级分光对比。
【色调】珠宝色调：松石绿、黛青、碧玉、鎏金、玄铁墨色；灵火青金；通透仙光。
【氛围】灵气流动、似有若无的雾气、悬浮灵光粒子，超凡脱俗的修仙炼丹圣地，绝非凡间烟火作坊。
【要求】厚涂笔触明显、明暗对比强烈、体积与纵深感强；不要写实历史感的老旧古代作坊、不要土气朴实、不要现代工业元素、不要廉价3D渲染感。
【构图】纯场景无人物，横构图，中心对称，两侧与上方留白用于后置角色与特效。
```

**改造前/后实证**：`.workbuddy/rig_art3/_out/scene_ab.png`（左旧作坊 / 右新洞天）。

### 场景「修仙感」清单（逐项对照）
| 项 | 古代作坊（禁） | 修仙宗门（要） |
|---|---|---|
| 主光 | 炉火 + 环境漫射 | **灵火（青金）+ 顶部落下的仙光体积光束** |
| 陈设 | 土黄木柜、藤蔓、葫芦堆、果蔬 | **博古药柜 + 悬浮玉器/法器 + 药材玉瓶** |

| 色调 | 土黄铜绿为主 | **松石绿/碧玉/鎏金珠宝色调** |

## 四、五条硬指标（**降格为「校准辅助」** · 通过气质关后再跑）

| # | 指标 | 目标区间 | 备注 |
|---|---|---|---|
| 1 | 精灵亮度 | 匹配所站地面 `×0.90`；暗场景 ≤90 | 实测新精灵 L=48.3 ✓ |
| 2 | 精灵饱和度 | **0.45–0.62**（项目"低饱和"的真值） | 上一版 0.16–0.19 ✗ |
| 3 | 色温 R−B | 净 **−12 ~ +12**（冷青基准 + 暖边缘光） | |
| 4 | 白像素占比 | **< 1%** | 纯白=自发光 |
| 5 | 暗像素占比 | 15–35%（有体积，不是黑块） | |

> **验收顺序：先人眼过 §零 三支柱 → 再跑数字。** 数字只用于「同一风格内的横向一致性」，不用于定义风格。

## 五、融入场景 · 五步口径（数值化，落代码直接可用）

| 步 | 做法 | 参数 |
|---|---|---|
| 1 抠底 | 双判据 `(S<0.13) OR (dist<34)` ＋ 形态学闭运算桥接噪点 ＋ 连通域取「与四边连通」为底；残留边用「距底色软 alpha」 | **前景占比落 30–40% 为合理**；=100% 即抠底失效 |
| 2 亮度 | `k = clamp(地面L×0.90 / 精灵L, 0.10, 1.30)` | 暗场景白袍先压高光 |
| 3 色调 | `blend(精灵, 地面色, 0.14)`，**必须 merge 回原 alpha** | ≤0.20，否则洗成灰 |
| 4 边缘光 | 朝主光侧暖 `#FFD098` → 远端冷 `#3A3730` 乘性方向渐变 | 光在场景哪边就亮哪边 |
| 5 接地影 | `rx≈0.34w / ry≈0.032h / blur≈ry×0.9 / α≈155 / #090805`（v1.1 实测调小，比 v1.0 的 0.44h 更自然） | **留 pad 再 blur** |

**动作**：单频正弦＝钟摆感 ⇒ 主频 0.72 ＋ 泛音 0.28(1.63×)；包络脚底归零（不滑步）；**禁原地踏步**；同屏 ≤5 角色。

## 六、陷阱词清单（v1.1 更新）

| 陷阱 | 后果 | 正解 |
|---|---|---|
| 「低饱和」 | 出 sat 0.16 真·灰 | 改「中等饱和，保留材质固有色」 |
| 「青白灵气微光 / 周身微光」 | 自发光 + 褪色 | 删；改「无自发光，光来自环境」 |
| 「无高光 / 无描边」当主调 | 抹平体积 → 平涂产品照 | 保留「厚涂/体积/笔触」，仅「无描边」 |
| 背景 `#E8E8E8` 纯浅灰 | 模型读成棚拍产品照 | 改中灰 `#CFCFCF` |
| `input_fidelity=low` | **把电影级质感稀释成平涂**（v1.1 实锤） | 改 **high** |
| 场景写「朴素/写实历史/作坊」 | 出凡间烟火气 | 写「洞天秘境/仙光/灵火/法阵光纹」 |
| prompt 写「可爱/3.5头身」 | 带向 Q 版大头 | 写「写实正常人体比例、约六头身、绝对不要Q版」 |
