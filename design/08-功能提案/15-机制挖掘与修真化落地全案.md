## 第一部分：核心借鉴原则与四大品类系统

### 核心借鉴原则
所有内容均严格遵循「宗主全局调控、系统自动运转、玩家轻量干预、复用现有框架」四项原则，不引入任何高频微操、单弟子操控类设计，全部转化为自动模拟+全局开关+数值加成的形式，完全适配放置修仙的核心玩法，且所有入口严格下沉二级页面，符合 B2 硬约束。

以下按系统维度分类，全部来自经典模拟经营作品的成熟机制，经修真世界观改造后可直接落地。

### 一、基建与经营深度类

#### 1. 宗门分区与梯度基建解锁
**来源**：《城市：天际线》分区规划 + 基建解锁线
**核心逻辑**：参考“先通路、再分区、后升级”的城建节奏，将宗门从山脚到主峰按功能划区，随宗门品级梯度解锁，避免开局内容堆砌，成长体感清晰。
**修真化落地规则**
- **四大功能分区**：外门生活区（山脚）、工坊产出区（山腰）、内门修炼区（半山）、主峰核心区（山顶）；
- **解锁梯度**：每个区域按「宗门步道 → 灵脉铺设 → 配套建筑 → 大阵覆盖」四步解锁，前一级达标后自动开放下一级；
- **区域专属 buff**：修炼区聚灵效果+8%，产出区材料产出+10%，生活区心境恢复速度+12%，大阵覆盖后 buff 翻倍。
**系统联动**：与宗门品级、宗门大阵、居所系统深度绑定，区域解锁直接对应弟子身份晋升节奏；复用现有建筑升级框架，仅新增分区字段与区域 buff 计算逻辑，开发量极低。
**开发优先级：P1**

#### 2. 堂口专精等级体系
**来源**：《双点医院》专科科室 + 技能连锁加成
**核心逻辑**：参考“专科升级→全医院对应科室收益提升”的设计，将宗门生产类功能整合为五大堂口，堂口等级越高，全宗对应产出越强，同时解锁高阶配方。
**修真化落地规则**
- **五大堂口**：丹堂、符堂、器堂、御兽堂、藏经阁；
- **等级成长**：堂口等级由「任职弟子副职业等级 + 配套建筑等级」共同决定，自动匹配天赋最高的弟子担任首座，玩家可手动调整；
- **核心收益**：等级提升对应产出效率提升、高阶配方解锁、副职业经验获取加速。
**系统联动**：与弟子副职业、职位系统、物品配方体系完全对接，复用现有职位逻辑，无需新增底层模块；与宗门考评联动，堂口评级纳入七载大考评分维度。
**开发优先级：P1**

#### 3. 公共建筑规格加成
**来源**：《监狱建筑师》房间功能规格机制
**核心逻辑**：参考“满足房间配套条件→触发额外功能/加成”的设计，给丹房、演武场、藏经阁等公共建筑设置配套设施要求，达标自动触发增益，无需手动摆放装修。
**修真化落地规则**
- 丹房：配齐药柜、通风阵、火种台 → 丹药产出+15%，出极品概率+5%；
- 演武场：配齐木人桩、测灵石、观战台 → 修炼效率+10%，大比成绩提升；
- 藏经阁：配齐古籍架、悟道蒲团、静心阵 → 功法研究速度+12%，走火入魔概率降低。
- 所有配套设施随建筑等级自动解锁，达标即生效，无额外操作。
**系统联动**：与建筑升级、副职业、修炼系统直接联动，纯数值扩展，开发成本极低。
**开发优先级：P2**

### 二、事件与生态叙事类

#### 1. 自适应事件链系统
**来源**：《环世界》叙事者系统 + 多阶段事件链
**核心逻辑**：参考“根据殖民地状态动态调整事件强度、事件间存在因果连锁”的设计，替代孤立随机事件，让宗门运转更像真实的生态，而非零散弹窗。
**修真化落地规则**
- **因果连锁**：事件存在上下游触发关系，例如：连日暴雨 → 灵草减产 → 丹药供给不足 → 低心境弟子走火入魔概率上升；妖兽袭扰 → 护山大阵消耗加剧 → 灵石储备不足 → 大阵威力下降 → 更易遭遇入侵；
- **动态难度**：系统实时检测宗门资源、战力、心境状态，顺境时适度提升挑战强度，逆境时增加机遇事件，避免玩家崩盘或无聊；
- **阻断机制**：玩家可通过提前储备资源、升级大阵、发放丹药等方式，在任意节点打断事件链，体现经营策略性。
**系统联动**：深度对接现有事件系统、资源体系、心境系统、护山大阵，仅新增事件关联字段与触发权重计算，复用全部弹窗与日志框架。
**开发优先级：P1，体验提升幅度最大，开发成本可控**

#### 2. 宗门派系动态诉求
**来源**：《王国风云》派系政治机制
**核心逻辑**：参考“不同利益群体有不同诉求，诉求满足增益、不满则内耗”的设计，让宗门内部形成自然的理念分化，强化经营真实感。
**修真化落地规则**
- **自然形成派系**：随弟子数量增加，自动形成丹道派、剑修派、保守派、革新派等小团体，由对应长老/亲传弟子作为核心；
- **派系诉求**：剑修派要求扩建演武场、提升历练资源倾斜；丹道派要求升级丹房、增加药圃配额；保守派要求稳扎稳打、降低风险；革新派要求探索新秘境、研究新功法；
- **效果规则**：诉求满足则派系满意度提升，对应领域产出+5%~+10%；长期不满则触发内耗事件，修炼效率下降、凝聚力降低。
- 玩家通过建筑升级、资源分配、人事任免间接调控，不直接操控派系。
**系统联动**：与弟子关系、长老系统、建筑升级、宗门凝聚力深度绑定，丰富宗门生态深度。
**开发优先级：P2，适合 S1 后期补全生态**

#### 3. 云游访客交互体系
**来源**：《星露谷物语》村民来访 + 《动物园之星》游客评价体系
**核心逻辑**：参考“随机访客带来交易、剧情、增益，评价影响后续访客质量”的设计，补充宗门的对外交互体感。
**修真化落地规则**
- **访客类型**：散修、行商、云游长老、秘境探险者，随机到访停留 1-3 天；
- **交互内容**：行商带来稀有物品交易、云游长老可传功提升弟子修为、探险者可分享秘境线索解锁新地图；
- **评价机制**：访客对宗门的评价由宗门品级、环境、接待规格决定，评价越高，宗门声望上涨越快，后续到访的访客资质/商品品质越好。
- 玩家仅可选择是否接待、是否赠予物资提升好感，其余交互自动进行。
**系统联动**：与坊市交易、声望系统、奇遇系统、心境系统直接联动，复用现有奇遇事件框架。
**开发优先级：P1**

### 三、资源与经济闭环类

#### 1. 全资源循环闭环体系
**来源**：《缺氧》元素转化 + 资源循环链
**核心逻辑**：参考“资源单向消耗→副产物→再加工→回到生产链”的闭环设计，解决放置游戏后期资源溢出、经济失效的问题。
**修真化落地规则**：构建三条核心循环链，全程自动运转，玩家仅需升级建筑提升转化效率：
1. **药草循环**：灵草种植 → 炼丹产出丹药 + 药渣 → 药渣制作灵肥 → 灵肥提升灵草产量；
2. **妖兽循环**：历练斩杀妖兽 → 产出妖兽材料 + 兽尸 → 兽尸加工为兽粮 + 炼器材料 → 兽粮喂养灵兽；
3. **灵气循环**：弟子修炼排出浊气 → 聚灵阵净化浊气 → 转化为基础灵气 → 反哺修炼环境。
**系统联动**：与种植、炼丹、炼器、灵兽、大阵系统深度对接，完善经济闭环，消化后期溢出资源。
**开发优先级：P2，S1 中期解决资源通胀问题时落地**

#### 2. 物品品质四级体系
**来源**：《星露谷物语》作物品质 + 《环世界》物品品质分级
**核心逻辑**：参考“同物品分不同品质，效果与价值差异显著，高品质依赖技能/运气产出”的设计，快速丰富物品深度，提升副职业价值。
**修真化落地规则**
- 所有材料、丹药、符箓、法宝统一分为：下品、中品、上品、极品 四个品质；
- 品质由「生产者副职业等级 + 建筑规格 + 随机概率」共同决定，等级越高出高品质概率越大；
- 效果差异：下品为基础值，中品+20%效果，上品+50%效果，极品+100%效果；高阶配方必须使用中品及以上材料。
**系统联动**：仅需在物品表新增 `quality` 字段，效果按品质倍率计算，全系统复用，开发量极小；与副职业、炼丹、炼器、坊市交易系统完全兼容。
**开发优先级：P0，性价比最高，零重构成本**

#### 3. 宗门福利全局调控
**来源**：《城市：天际线》税收与福利滑块机制
**核心逻辑**：参考“全局调节福利水平，收益与成本此消彼长”的设计，给玩家一个全局经营杠杆，强化宗主调控的身份感。
**修真化落地规则**
- 设置低、中、高三档福利，玩家可一键切换，每月结算生效：
- 低福利：丹药供给减半、居所维护降级 → 资源消耗-30%，但弟子归属感下降、叛逃概率提升；
- 中福利：标准供给，平衡消耗与收益；
- 高福利：丹药充足、居所优待 → 资源消耗+40%，修炼速度+8%，归属感大幅提升。
- 入口下沉至宗门设置页，非常驻显示。
**系统联动**：与资源消耗、归属感、修炼速度、叛逃机制直接对接，纯数值调控，开发成本极低。
**开发优先级：P2**

### 四、长线仪式感与目标类

#### 1. 二十四节气与宗门庆典
**来源**：《星露谷物语》季节节日体系
**核心逻辑**：参考“季节对应不同玩法、固定节日提供仪式感奖励”的设计，对齐游戏内时间线，强化修真世界观的时间体感。
**修真化落地规则**
- **节气常驻 buff**：二十四节气与游戏内日期绑定，自动触发对应效果：春分/秋分灵气最盛，修炼速度+15%；冬至/夏至适合闭关，突破成功率+10%；梅雨季节心境下降、药草增产；
- **固定宗门庆典**：岁末大典、宗门成立日、接引大典，每年固定触发，玩家可选择是否举办，消耗少量资源，获得全宗心境 buff + 凝聚力提升 + 声望奖励。
**系统联动**：与游戏时间系统、修炼、心境、凝聚力完全对齐，和七载大考时间线无缝衔接；纯配置即可落地，无需新增核心代码。
**开发优先级：P0，仪式感拉满，开发量趋近于零**

#### 2. 宗门里程碑与传承树
**来源**：《文明》系列科技树 + 世代传承机制
**核心逻辑**：参考“达成里程碑解锁永久增益、形成文明发展线”的设计，给长线游玩提供清晰的目标锚点，强化宗门的历史厚重感。
**修真化落地规则**
- 设置数十项宗门里程碑，例如：首位筑基弟子、首次攻破高阶秘境、首位长老飞升、宗门晋升三品、解锁全部基础阵法；
- 达成后自动解锁永久全局微量 buff，同时计入宗门史册，先贤祠加成同步提升；
- 传承树按时间线展示所有里程碑，玩家可随时回顾宗门发展历程。
**系统联动**：复用现有纪事、先贤祠、全局 buff 框架，新增成就触发条件即可。
**开发优先级：P1**

#### 3. 失传技艺与秘法解锁
**来源**：《缺氧》远古科技 + 《环世界》远古遗迹
**核心逻辑**：参考“探索获取失传科技，解锁特殊强力玩法”的设计，作为长线探索的核心奖励，持续给玩家惊喜。
**修真化落地规则**
- 高阶秘境、稀有奇遇、古籍残卷中，可概率获得失传技艺，例如：上古炼丹术（提升丹药品质上限）、失传阵道（解锁高阶宗门大阵）、御兽古法（可收服稀有灵兽）；
- 每个失传技艺对应一个独特玩法增益，无重复，作为中后期的核心探索目标。
**系统联动**：与秘境、奇遇、阵法、副职业系统深度联动，丰富长线内容深度。
**开发优先级：P2**

### 第一部分·落地总览与避坑提醒

**优先级排序**
- **P0 必做（开发量极小，收益极高）**：物品品质四级体系、二十四节气与庆典
- **P1 推荐（S1 阶段可落地）**：梯度基建分区、堂口专精体系、自适应事件链、云游访客、宗门里程碑
- **P2 长线（S2 及以后）**：资源循环闭环、派系诉求、福利调控、失传技艺

**绝对避坑原则**
1. 绝不引入单弟子微操、手动摆放建筑、实时拖拽类操作，始终保持宗主全局调控的视角；
2. 所有新增系统入口全部下沉二级页面，首页、一级导航绝不新增按钮，严格遵守 B2 硬约束；
3. 所有增益严格控制数值上限，单系统加成不超过 15%，守住零通胀基线，避免数值崩坏。

## 第二部分：三大品类游戏机制挖掘与修真化落地全案

所有机制均严格对齐「宗主全局调控、系统自动运转、入口二级下沉、数值零通胀」四项核心原则，100% 复用现有系统框架，无新增底层核心模块，按开发性价比分级呈现。

### 一、《动物园之星》×《星露谷物语》：生态养成与收集目标向

#### （一）来自《动物园之星》的可借鉴机制

**1. 灵兽栖息地适配与福利体系**
**核心逻辑**：不同灵兽对洞府环境、配套设施有专属要求，适配度越高，灵兽成长、产出、忠诚度越强，替代“统一兽栏养所有灵兽”的粗放设计。
**修真化落地规则**：每类灵兽对应属性适配要求：火属性灵兽需火脉洞府、水属性需灵泉洞府、飞禽类需浮空栖木；适配度分四级：不适→合格→良好→完美，对应梯度加成，完美适配额外解锁专属稀有产出；洞府升级自动解锁配套设施，适配度同步提升，无需玩家手动摆放装饰。
**联动系统**：灵兽系统、宗门基建分区、材料产出系统
**开发优先级**：P1，复用现有灵兽与建筑框架，仅新增适配度字段与加成公式，养成体感提升显著。

**2. 灵兽育种与天赋提纯**
**核心逻辑**：同种灵兽可自动繁衍后代，天赋随机继承父母属性，多代选育可逐步提纯高阶天赋，形成长线养成目标。
**修真化落地规则**：同种雌雄灵兽按周期自动繁衍，后代灵根、天赋随机继承双亲，低概率触发变异天赋；高阶灵兽繁衍周期长、成功率低，低阶灵兽繁衍快，适合批量选育打底；连续多代高天赋选育可稳定产出极品灵兽，对应御兽师副职业等级越高，繁育成功率越高。
**联动系统**：灵兽系统、御兽副职业、坊市交易
**开发优先级**：P2，长线深度内容，S1 后期补充养成维度。

**3. 访客满意度与声望传导体系**
**核心逻辑**：到访的散修、商队、云游修士生成体验评分，满意度直接影响宗门声望，高口碑反向吸引更高质量的访客与人才，形成正向循环。
**修真化落地规则**：访客按宗门环境、接待规格、交易诚意生成满意度，分差、中、良、优四档；满意度越高，单次声望奖励越多，后续到访的访客资质、商品品质、交易优惠越好；连续高评价触发「美名远扬」buff，接引弟子平均资质提升，持续 7 天。
**联动系统**：云游访客系统、声望系统、接引系统、坊市交易
**开发优先级**：P1，复用现有访客框架，新增评分与传导逻辑，快速完善对外交互闭环。

#### （二）来自《星露谷物语》的可借鉴机制

**1. 宗门收藏图鉴体系**
**核心逻辑**：设置多类收集目标，完成后解锁永久全局增益，消耗冗余库存的同时，给长线游玩提供清晰的收集锚点。
**修真化落地规则**：六大收藏分类：灵草图鉴、妖兽图鉴、功法残卷、阵法图谱、天材地宝、先贤事迹；首次获得对应物品、解锁对应内容自动计入图鉴，集齐整套解锁永久微量增益（如全丹药产出+5%、秘境掉落+3%）；稀有物品可捐赠入宗门藏宝库，额外提升声望与凝聚力。
**联动系统**：物品系统、秘境系统、功法阵法系统、纪事系统
**开发优先级**：P0，纯配置化内容，新增收集表与增益触发即可，开发成本极低，长线留存提升显著。

**2. 秘境分层递进探索**
**核心逻辑**：秘境按深度分层，层数越高难度与奖励同步提升，每数层设置 checkpoint，解锁后可直达，逐步推进探索深度。
**修真化落地规则**：每个秘境分 20 层，每 5 层设节点 BOSS，击杀后解锁下一段传送权限；层数越深，妖兽等级越高，掉落材料、阵图、残卷的品质上限越高；弟子队伍自动匹配可探索最高层数，每日自动推进，卡关则停留在当前最高层稳定刷取，无需手动操作。
**联动系统**：历练秘境系统、战斗系统、掉落系统
**开发优先级**：P1，复用现有秘境框架，新增分层与传送逻辑，探索目标感大幅增强。

**3. 节气作物轮作加成**
**核心逻辑**：不同节气适配不同灵草，当季种植产量翻倍，错季减产，与二十四节气体系深度结合，强化种植策略性。
**修真化落地规则**：灵草分春生、夏长、秋收、冬藏四大类，对应节气种植产量+50%，错季产量-30%；高阶聚灵阵可弱化季节影响，实现全年稳定产出；春分、秋分、冬至等特殊节气额外加成，概率收获极品品质作物。
**联动系统**：灵植系统、二十四节气体系、丹堂系统
**开发优先级**：P1，复用现有种植与节气框架，新增季节适配字段，种植策略深度大幅提升。

### 二、《环世界》×《双点医院》×《城市：天际线》：经营模拟与系统深度向

#### （一）来自《环世界》的可借鉴机制

**1. 弟子工作优先级自动分配**
**核心逻辑**：玩家设置全局优先级规则，系统根据弟子天赋、身份、副职业等级自动匹配岗位，无需手动逐个分配，兼顾放置轻量化与策略调控。
**修真化落地规则**：宗门工作分六大类：修炼、丹堂、符堂、器堂、御兽、杂务；玩家可全局调整各类工作的权重优先级，系统自动按人岗匹配度调度；默认规则：亲传弟子优先修炼，内门弟子优先对口堂口，外门弟子优先杂务与基础生产。
**联动系统**：弟子系统、副职业系统、五大堂口体系
**开发优先级**：P1，复用现有职位与副职业框架，新增优先级调度逻辑，大幅降低操作负担，贴合放置定位。

**2. 正邪宗门外交关系体系**
**核心逻辑**：与周边宗门、邪修势力存在动态关系值，友好则贸易互通、危难互助，敌对则频繁袭扰、封锁资源，丰富宗门外部生态。
**修真化落地规则**：初始周边存在 3-5 个中立宗门与 1 个邪修势力，关系值区间 -100~+100；友好行为（通商、互助、赠礼）提升关系，敌对行为（抢秘境、攻伐）降低关系；友好宗门定期互通商队、共享秘境线索；敌对宗门会唆使妖兽入侵、劫杀历练弟子；关系以事件自动推进为主，玩家仅可通过「遣使赠礼」「宣战」等全局操作干预，入口下沉至宗门纪事-外交页。
**联动系统**：坊市交易、妖兽入侵、历练秘境、事件系统
**开发优先级**：P2，S2 阶段补充外部生态，前期先做基础贸易与入侵联动即可。

**3. 事件链因果与动态难度（深化点）**
**核心深化点**：在既有事件链基础上，新增权重动态调节——宗门顺境时增加机遇与挑战并存的事件，逆境时增加救助、奇遇类缓冲事件；事件链增加多分支结局，不同选择走向不同结果。
**联动系统**：事件系统、全局状态检测
**开发优先级**：P1，复用现有事件框架，新增权重计算与分支逻辑，叙事体验提升极大。

#### （二）来自《双点医院》的可借鉴机制

**1. 堂口星级评价体系**
**核心逻辑**：每个堂口按综合指标评定星级，升星解锁高阶配方与专属 buff，给生产系统提供清晰的阶梯成长目标。
**修真化落地规则**：五大堂口各分三星，评级维度：弟子平均副职业等级、建筑配套规格、累计产出量、高阶配方解锁数；升星后自动解锁对应阶别的高阶配方、提升产出效率、触发堂口专属 buff；全堂口达到指定星级，额外提升宗门整体评级，解锁全局增益。
**联动系统**：五大堂口体系、副职业系统、配方系统、宗门品级
**开发优先级**：P1，复用现有堂口框架，新增评级字段与解锁规则，目标感极强，开发成本低。

**2. 求道者/求医客接待体系**
**核心逻辑**：随机到访的求道少年、受伤散修、求医老者，宗门可选择接待或拒绝，接待消耗资源但返还声望、功法残卷等稀有奖励，丰富访客交互维度。
**修真化落地规则**：三类核心访客：求道少年（可收入宗门成为弟子）、受伤散修（疗伤后赠功法/材料）、求医老者（耗高阶丹药换稀有传承）；访客有品质分级，品质越高奖励越好，消耗资源也越多；接待成功率与丹堂水平、医师弟子配置挂钩，失败则声望下降。
**联动系统**：云游访客系统、接引系统、丹药系统、事件系统
**开发优先级**：P1，复用现有访客框架，扩展接待分支，交互体感大幅提升。

#### （三）来自《城市：天际线》的可借鉴机制

**1. 灵气覆盖梯度衰减机制**
**核心逻辑**：聚灵大阵并非全域均匀生效，离阵眼越近效果越强，越远越弱，引导玩家按功能规划宗门分区，强化基建策略性。
**修真化落地规则**：以主峰阵眼为中心，分核心区、内圈、外圈、边缘区四档，聚灵效果分别为 100%、80%、60%、40%；核心区布置主峰洞府、藏经阁，内圈布置内门居所、修炼区，外圈布置工坊、外门居所，边缘区布置药圃、兽栏；升级大阵可扩大覆盖范围、提升边缘区效果，对应宗门品级解锁。
**联动系统**：宗门大阵、基建分区、居所系统、修炼系统
**开发优先级**：P2，基建深度内容，配合分区系统同步落地，策略性更强。

**2. 宗门政策全局开关**
**核心逻辑**：提供数项全局政策，每项有明确收益与代价，玩家可根据宗门当前状态切换，强化宗主经营调控的身份感。
**修真化落地规则**：闭关令：全宗修炼速度+10%，所有生产产出-20%，适合冲境界、冲考评阶段；开源令：全宗生产产出+15%，修炼速度-5%，适合缺资源、攒材料阶段；厉兵令：历练伤害+10%，弟子受伤概率提升，适合冲秘境深度阶段；安民令：心境恢复速度+20%，修炼效率-3%，适合稳定运营、安抚人心阶段；每月仅可切换一次，入口下沉至宗门设置页。
**联动系统**：全局 buff 系统、修炼系统、生产系统、历练系统
**开发优先级**：P1，纯数值配置，新增全局政策开关即可，开发量极小，策略感拉满。

### 三、《王国风云》×《牧场物语》：人际传承与长线沉浸向

#### （一）来自《王国风云》的可借鉴机制

**1. 宗门职位传承顺位**
**核心逻辑**：长老、堂口首座等高阶职位预设传承顺位，任职者坐化/离任后自动递补，避免权力真空，强化宗门世代交替的仪式感。
**修真化落地规则**：每个高阶职位预设 3 位顺位继承人，系统按身份、修为、副职业等级自动排序，玩家可手动调整；任职者坐化、离任后，顺位第一者自动接任，触发职位传承事件，全宗获得对应 buff；传承顺畅则凝聚力提升，传承纷争则触发派系矛盾事件。
**联动系统**：弟子职位系统、寿元传承系统、派系系统、事件系统
**开发优先级**：P2，配合寿元系统同步上线，完善世代迭代体验。

**2. 血脉天赋与家族传承**
**核心逻辑**：高阶修士的后代有概率继承家族专属血脉特质，多代叠加可形成修仙世家，强化长线情感沉淀与世界观厚度。
**修真化落地规则**：亲传及以上阶别的道侣子嗣，有概率继承父母专属血脉特质（如剑修世家「剑骨」、丹道世家「丹瞳」）；血脉纯度逐代叠加，纯度越高效果越强，纯血后代天赋显著优于普通接引弟子；传承多代形成宗门世家，对应堂口产出额外加成。
**联动系统**：道侣子嗣系统、弟子特质系统、副职业系统
**开发优先级**：P2，长线沉浸内容，S2 阶段配合子嗣系统实装。

**3. 密谋与渗透事件链**
**核心逻辑**：低概率触发邪修卧底、派系争权等负面事件链，多阶段推进，每个阶段都有化解机会，增加经营风险维度与策略性。
**修真化落地规则**：事件分三阶段推进：渗透潜伏→暗中破坏→爆发损失，每个阶段都有概率被察觉，可通过执法弟子、大阵排查化解；未及时处理会导致资源失窃、弟子叛逃、大阵受损；成功化解则提升凝聚力、获得反制奖励；宗门凝聚力越高、护山大阵等级越高，触发概率越低。
**联动系统**：事件系统、护山大阵、凝聚力系统、执法弟子职位
**开发优先级**：P2，中后期补充风险维度，避免游戏过于平顺无聊。

#### （二）来自《牧场物语》的可借鉴机制

**1. 灵兽亲密度与专属互动**
**核心逻辑**：每只灵兽与负责照料的御兽弟子绑定亲密度，亲密度越高产出、战力越强，满级解锁专属能力，强化养成情感联结。
**修真化落地规则**：灵兽绑定 1 名对应御兽弟子，每日自动互动提升亲密度；亲密度分 5 级，等级越高，灵兽战力、产出效率、忠诚度越高；满级解锁灵兽专属技能，战斗中自动触发；更换照料弟子会导致亲密度缓慢下降。
**联动系统**：灵兽系统、御兽副职业、战斗系统
**开发优先级**：P1，复用现有灵兽框架，新增亲密度字段与加成，情感体验提升明显。

**2. 定期宗门集市**
**核心逻辑**：每月固定日期举办宗门集市，商队、散修聚集，商品种类远超常驻坊市，稀有物品概率刷新，给玩家提供明确的时间期待点。
**修真化落地规则**：每月十五固定开市，持续 3 天，期间坊市商品数量翻倍，新增随机稀有商队；集市期间交易手续费降低，宗门声望获取提升；概率刷新神秘商人，售卖失传阵图、天材地宝等稀有物品。
**联动系统**：坊市交易系统、云游访客系统、声望系统
**开发优先级**：P0，复用现有坊市框架，新增定时刷新规则，开发量极小，节奏体感大幅提升。

### 第二部分·落地优先级总览与避坑原则

**优先级梯队**
- **P0（零重构高收益，S1 必做）**：宗门收藏图鉴、定期宗门集市、宗门政策全局开关
- **P1（开发量小体验提升大，S1 全量落地）**：灵兽栖息地适配、访客满意度体系、秘境分层探索、节气作物轮作、弟子工作优先级、堂口星级评价、求道者接待、灵兽亲密度、事件链动态难度
- **P2（长线深度，S2 逐步补充）**：灵兽育种提纯、正邪外交体系、灵气覆盖衰减、职位传承顺位、血脉家族传承、密谋事件链

**核心避坑原则**
1. 所有机制均为「自动运转+全局调控」，绝不引入单弟子微操、实时拖拽、手动摆放类操作，坚守宗主经营视角；
2. 所有入口全部下沉二级页面，首页、一级导航绝不新增按钮，严格遵守 B2 硬约束；
3. 所有增益严格锁死数值上限，单系统最高加成不超过 15%，守住零通胀基线；
4. 优先复用现有系统框架，不新增独立底层模块，控制开发成本，快速迭代验证。
