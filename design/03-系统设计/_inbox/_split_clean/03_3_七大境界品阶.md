**品阶体系（7 大品阶 × 4 细分品级 二级架构，全系统唯一标尺，v2.56 裁定）**
- 一级大品阶（核心字根，无后缀）：`凡 / 灵 / 宝 / 王 / 圣 / 真 / 道`——覆盖所有物品、阵法、建筑、功法、灵兽、宗门品级、弟子境界等全部系统。
- 二级细分品级（精细梯度）：`下品 / 中品 / 上品 / 极品`——用于同大品阶内的数值分层。
- 标准命名格式：`大品阶 + 细分品级 + 物品名`（例：灵品上品筑基丹）；无细分需求的场景简化为 `大品阶 + 物品名`（例：灵品筑基丹），默认取中品效果。
- **彻底废弃带「阶」后缀表述**（凡品 / 灵品 / 宝品 / 王品 / 圣品 / 真品 / 道品 等），全文 tier 统一用「品」（凡品 / 灵品 / … / 道品）。

**大品阶 — 境界 — 细分品级 标准映射（兼容 9 境界）**

| 大品阶 | 对应境界 | 细分品级对应 |
| --- | --- | --- |
| 凡品 | 练气期 | 下品→练气前三层，中品→练气中期，上品→练气后期，极品→练气巅峰 |
| 灵品 | 筑基期 | 下品→筑基初期，中品→筑基中期，上品→筑基后期，极品→筑基巅峰 |
| 宝品 | 金丹期 | 下品→金丹初期，中品→金丹中期，上品→金丹后期，极品→金丹巅峰 |
| 王品 | 元婴期 | 下品→元婴初期，中品→元婴中期，上品→元婴后期，极品→元婴巅峰 |
| 圣品 | 化神期 | 下品→化神初期，中品→化神中期，上品→化神后期，极品→化神巅峰 |
