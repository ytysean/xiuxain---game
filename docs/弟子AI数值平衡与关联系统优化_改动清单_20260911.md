## 二、突破失败代价加重

**文件**：`disciple.gd`

### 新增惩罚项

1. **心魔增加**：5-15 + 境界序×2（境界越高心魔越多）
2. **寿元损耗**：折寿1-3年 + 境界序×0.5年（除以种族寿元系数）
3. **死亡风险**：渡劫期及以上突破失败5%×种族天劫难度系数概率死亡
4. **保命道具**：致命伤害时消耗1枚保命符替死，重伤但不死（受伤剩余90天）

### 修真化文案

- 渡劫陨落：`【渡劫陨落】XX冲击XX失败，天劫加身，魂飞魄散，陨落道消。`

## 五、弟子AI行为决策（新增4个函数）

**文件**：`disciple.gd`

### 新增函数

#### 1. `计算突破成功率预估() -> float`
- 计算当前突破成功率，用于AI风险评估
- 不实际执行突破，仅返回预估值

#### 2. `AI决定是否突破() -> bool`
- **性格驱动决策阈值**：
  - 天才/妖孽/旷世：25%成功率就敢冲（激进）
  - 普通：40%以上才尝试
  - 凡俗/平庸：55%以上才尝试（谨慎）
  - 懦弱性格：阈值+20%
  - 激进性格：阈值-10%
  - 谨慎性格：阈值+10%
- **寿元压力**：寿元<50年且元婴及以上，阈值-20%（拼死一搏）
- **连败谨慎**：突破失败次数≥3，阈值+10%

#### 3. `AI主动准备突破() -> void`
- 主动服用对应品阶突破丹药（筑基丹/凝金丹/破婴丹/化神蕴神丹）
- 天才弟子30%概率请求宗主护法（+15%成功率）
- 闭关打磨（瓶颈打磨值+0.1）

#### 4. `AI主动寻机缘() -> String`
- 大圆满但决定不突破时，选择行为：
  - 40%概率：外出历练寻机缘
  - 20%概率：闭关打磨心境
  - 15%概率：找同门论道
  - 25%概率：继续修炼

### 月度推演接入

**文件**：`game_state.gd` → `推演一月()`

在弟子推进修炼前添加AI决策：
```gdscript
if d.层数 >= 10 and d.瓶颈打磨值 >= 1.0 and d.突破冷却剩余 <= 0:
    if d.AI决定是否突破():
        d.AI主动准备突破()
    else:
        var 行为 = d.AI主动寻机缘()
        if 行为 == "历练" and randf() < 0.3:
            # 30%概率外出历练寻机缘
```

## 六、关联系统优化

### 6.1 弟子招募优化

**文件**：`game_state.gd` → `推演一月()`

| 参数 | 旧值 | 新值 | 说明 |
|------|------|------|------|
| 招徒周期 | 3月 | **2月** | 缩短招徒间隔，弥补高死亡率 |
| 招徒基础概率 | 0.75 | **0.8** | 提高招徒成功率 |
| 每次招徒数量 | 1-2人 | **1-3人** | 40%概率2人，10%概率3人 |

### 6.2 突破失败陨落处理

**文件**：`game_state.gd` → `推演一月()`

- 新增陨落弟子检测：`if str(d.状态) == "陨落"`
- 陨落弟子复用坐化处理逻辑：
  - 灵兽解绑归还御兽堂
  - 装备/背包/私库归还宗门库房
  - 加入先贤堂（事迹载入史册）
  - 宗门史馆入册弹窗
  - 从弟子列表移除

### 6.3 天才陨落传承机制（情感缓冲）

**文件**：`game_state.gd` → 新增 `_天才陨落传承(d)`

**触发条件**：天才/妖孽/旷世资质弟子，或天骄弟子陨落

**传承内容**：
- **功法心得**：根据已学功法数量，留下1-2部功法心得物品（品阶：宝品）
- **灵石**：(境界序+1)×500灵石
- **悟道点**：(境界序+1)×100悟道点

**修真化文案**：
- `【天才陨落】XX冲击大道失败，陨落道消。临终前留下毕生传承：功法心得X部、灵石X、悟道点X，尽数归入宗门，以遗后人。`
- 弹窗：`XX 陨落留传承`

### 6.4 弟子主动申请洞府

**文件**：`game_state.gd` → 新增 `_弟子主动申请洞府()`

**触发条件**：
- 金丹及以上境界
- 贡献点≥500
- 无洞府
- 宗门有空闲洞府

**分配规则**：
- 按贡献点排序，优先分配给高贡献弟子
- 消耗弟子500贡献点
- 初始分配1级洞府
- 每月最多分配3个（避免灵石消耗过快）

**修真化文案**：
- `【洞府分配】XX修为已达金丹，贡献卓著，主动向宗门申请洞府，获赐1级洞府，闭关修炼效率提升。`

## 七、对UX的影响分析

### 7.1 需要新增UI展示的内容

1. **弟子突破成功率预估**：弟子详情页显示当前突破成功率（含所有加成）
2. **弟子AI决策状态**：显示弟子当前是"准备突破"还是"外出寻机缘"
3. **种族特性展示**：弟子详情页显示种族特性（寿元/入魔/业力/天劫/悟性系数）
4. **天才陨落传承弹窗**：已有宗门史馆弹窗，可复用
5. **弟子主动申请洞府通知**：推演条目中已有，可考虑增加弹窗提醒

### 7.2 需要调整的现有UI

1. **突破成功率显示**：旧的成功率显示可能不准确，需更新为新的严酷型数值
2. **招徒频率提示**：招徒周期从3月改为2月，相关提示需更新
3. **洞府分配界面**：可增加"自动分配"开关，让玩家选择是否允许弟子主动申请

### 7.3 性能影响

1. **弟子AI决策计算**：每月为每个大圆满弟子计算AI决策，计算量较小，不影响性能
2. **陨落弟子处理**：复用坐化处理逻辑，无额外性能开销
3. **弟子主动申请洞府**：每月最多处理3个，性能影响可忽略

### 7.4 存档兼容性

- 所有新增字段都有默认值，旧存档可正常加载
- 种族系数为const配置，无需存档
- 弟子AI函数为纯计算，无新增持久化字段
- 天才陨落传承为触发时即时处理，无需额外存档字段

## 十、设计理念总结

**三维度标准**：
- **好玩**：突破更严酷→策略深度提升→法财侣地搭配更重要
- **符合修真世界观**：天才陨落留传承、弟子主动寻机缘、种族特性差异
- **符合真人玩家操作习惯**：弟子AI自动决策→减少手动操作→玩家专注战略层面

**核心玩法**：仿真修仙宗门深度沉浸模拟管理
- 弟子是独立人格，不是工具人
- 宗门传承是修真文化核心
- 修真世界逆水行舟，不进则退
