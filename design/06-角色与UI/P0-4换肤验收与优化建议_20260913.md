## 三、★ 成就弹窗"每次进都重弹" 根因（老大报告的问题）

**结论：不是"没存档"，而是存档恢复顺序 bug。**

1. `成就_已达成`（已解锁成就 id 数组）**确实存盘了** —— `achievement_system.gd` 的 `to_dict`(393-397) 存、`from_dict`(400-402) 取。
2. **真因**：`game_state.gd` 的 `_ready()`(4517) 在**存档读入之前**就把 `成就配置[i]["已达成"]` 回填了一次（那时 `成就_已达成` 是空数组 → 全部填 `false`）。
3. 玩家读档走 `from_dict`：`成就系统.from_dict`(24764) 恢复了 `成就_已达成`，但**之后没有重新回填** `成就配置` 定义表。
4. 到 line 24907 `_复检成就()` 时，定义表里所有成就的 `已达成` 仍是 `false` → 复检把它们当成"新达成" → `show_achievement` 全部重弹。

**修复**（`from_dict` 的 `成就系统.from_dict` 之后补 3 行，与 `_加载成就配置` 9930-9931 完全等价）：
```gdscript
for a in 成就配置:
    a["已达成"] = 成就系统.成就_已达成.has(a.get("achievement_id") if "achievement_id" in a else "")
```
修复后已得成就正确 `continue`、不再重弹；**实时新达成仍正常弹一次**（事件触发，不受影响）。不碰战斗红线、新旧存档格式兼容。
