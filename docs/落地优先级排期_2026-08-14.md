## 分阶段明细

### 阶段一 · S1 批0（P0：补页面承接现存数据）
- **① 成就里程碑独立页**：`里程碑配置`/`里程碑_已达成` 数据已就绪，仅缺展示页与"成就"Tab 实体。做只读展示页 + 接入底部 Tab 预留位。
- **② 阵法独立二级页**：`zhenfa` 数据已有、当前内嵌殿阁。抽成独立二级页，殿阁内保留入口跳转。
- **③ 宗规说明页**：Ardot 已占位"系统即将开放"，实为纯规则展示页，无数值，最低成本填补占位。

### 阶段二 · S1 批1（P1：核心养成缺口）
- **④ 丹房交互炼丹**：目前仅丹殿被动赠丹。需炼丹 UI + 丹药配方数据 + 产出接入产出池轴（受 ≤30% 红线 clamp）。
- **⑤ 招募抽卡系统**：审计原误将 `xianyu_shop_library` 标为招募库，实际它是仙玉商店（月卡/礼包）已落地；**真正的招募抽卡若数据未备则属新功能**，需建弟子池/权重/抽卡结算。

### 阶段三 · S1 批2（P1：经济/社交深化）
- **⑥ 商队完整经济**：需设计商队/车辆/成员经济循环；**须遵守数据层不可动红线**，在零经济改动前提下扩展或新增隔离经济节点。
- **⑦ 阵营声望轴**：多阵营声望，区别于通用声望；接声望展示与权益。
- **⑧ 托管深化**：自动推演托管（度假式核心卖点），扩展托管策略与结算。
- **⑨ 装备强化**：⚠️ **可能触碰战斗红线**——装备→战力，须设计为不修改 `BattleCalculator`/`BattleManager` 的纯养成呈现，或推迟至 S2。

### 阶段四 · S2（P2：社交生态）
- **⑩ 道友完整互动**：当前 `page_daoyou.gd` UI 已建但交互=开发中占位，需好友/私信/互助真实逻辑。
- **⑪ 仙盟**：联盟架构、联盟任务、联盟资源。
- **⑫ 排行榜/玄榜**：Ardot 占位入口，需排名计算 + 榜单层。
- **⑬ 灵讯**：邮件/信件系统，Ardot 占位。
- **⑭ 论道切磋**：⚠️ **战斗相关**——S1 铁律"零战斗触碰"禁止改战斗核心；可复用已落地的自动推演战斗展示而非改 `BattleCalculator`。

### 阶段五 · S3（P3：内容扩展）
- **⑮–⑲** 新境界/飞升、传承、大型秘境、外观系统、器堂锻造，均为大型内容，依赖前序架构稳定后开展。

## 红线与约束（落地时必守）

1. **S1 零战斗触碰**：装备强化(⑨)、论道切磋(⑭) 不得修改 `BattleCalculator.gd`/`BattleManager.gd`；前者走纯养成呈现，后者复用推演战斗展示。
2. **数据层不可动**：商队(⑥) 等新增经济须在红线内（不新增 灵石/产出/消耗 核心节点，或隔离新节点）。
3. **增益红线**：单 buff ≤5%、永久全局 ≤3%、限时全局 ≤8%；彩蛋/付费/活动 buff 共享封顶。
4. **仙玉体系已落地**：付费入口（月卡/礼包）优先接 `page_premium`，数值占位待真机平衡校准（S1 竖切）。
5. **pre_f5 门禁**：每次落地须 `python pre_f5_check.py` 全绿（EXIT 0）方可提交。
