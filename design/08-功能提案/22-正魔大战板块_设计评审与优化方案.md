# 《太玄宗门录》正魔大战板块 · 设计评审与优化方案

> 评审对象：散落在 §2.1 五大阵营 / §2.2 弟子倾向 / §11.4.5.3 阵营与援军 / §11.5.2 阵营声望 / §10.3 天道异动 / §16 主线伏笔 中的全部正魔对抗内容。
> 定位：**不重定义任何已有章节**，仅做跨章节的整合评审 + 增量优化提案。
> 铁律遵守：全程使用正式名《太玄宗门录》；不触碰 §4.1 数值红线（通用增益 25% / 道心 10% / 产出效率池独立）；不新增第 16 座建筑；不新增并行数值表；所有未定数值标 `[PLACEHOLDER]`。

## 1. 概述

### 1.1 一句话结论

**当前「正魔」不是一块内容，是四块互不相干的碎片**：一条单向累积的声望数值、一层对称的战斗克制皮、一个惩罚性的围剿事件、一组被数值红线压扁的微弱增益。玩家体感是「刷条 → 到线挨打 → 继续刷」，没有「大战」。

更严重的是：§16 主线已经埋了**域外幽魔族封印松动**这条终局级伏笔，而现有正魔设计完全没接上它——表层正魔互撕与里层灭世危机是两条断掉的线。

### 1.2 优化总纲

把「正魔大战」从**数值路线选择**升级为**双层战争结构**：

| 层级 | 名称 | 玩家体验 | 时间尺度 |
| --- | --- | --- | --- |
| 表层 | **正魔博弈**（正道盟 vs 魔道邪宗） | 谍战、站队、投机、被围剿、反杀 | 日常 / 周常 |
| 里层 | **幽魔潮汐**（域外幽魔族封印松动） | 正魔被迫停战联手、全服危机、终局 | 赛季 / 主线卷五 |

**里层是表层的意义来源**：玩家在表层争得你死我活的正魔双方，在幽魔潮汐面前必须低头联手。这一层把「选正还是选魔」从功利计算变成叙事抉择，是本次优化的最高价值点。

### 1.3 三层落地结构

```
L1 声望层（个人·长期）   双面声望 + 曝光度     ← 改造现有 faction_base
L2 战线层（世界·中期）   地域控制度           ← 新增，挂 §16 宏观地域层
L3 战役层（单局·短期）   四类战役改造         ← 改造现有 §11.4
```

### 2.2 缺失项（本次要补的）

- ❌ 无「战场」载体：正魔对抗是纯数值，没有空间/领地/战线概念
- ❌ 无「时间压力」：声望条不会衰减，玩家可无限期骑墙或无限期拖延
- ❌ 无「战果持久化」：打赢只涨数字，没有可记忆的据点/称号/史记条目

- ❌ 无「终局指向」：表层正魔对抗与里层幽魔危机完全脱钩

## 3. 结构性诊断（按严重度排序）

### 🔴 P0-1 对称克制 = 零策略

**现状**（§11.4.5.3）：「正道弟子对阵魔道弟子时，**双方**伤害额外 +10%」。

**问题**：对称加成是纯数值通胀。玩家看到的是「哦，两边都变强了」，而不是「我该选哪边」。选择不产生策略差异，就不产生玩法。

**根因**：把阵营差异做在了**属性层**，而属性层被 §4.1 红线（25%/10%）锁死，抠不出差异空间。

**修正方向**：阵营差异必须搬出属性层，落到**玩法权限 / 资源通道 / 风险收益曲线**。属性只做点缀（≤5% 量级）。详见 §5.2 非对称收益矩阵。

### 🔴 P0-2 「此消彼长」是零和陷阱，消灭了中间态

**现状**（§2.1）：正魔声望此消彼长，加正必减魔。

**问题**：
1. 玩家不敢两头下注 → 只会一路走到黑，**最有戏剧性的「两面派 / 摇摆 / 背叛」状态被机制禁止**
2. 中间态（正魔接近）在数值上是最劣解，但叙事上最有趣——机制与叙事背离
3. §10.3 天道异动却用「任意两阵营差 <5%」触发「阵营·对峙」事件，**奖励对峙，但基础机制惩罚对峙**——内部矛盾

**修正方向**：改为**双轴独立累积 + 曝光度裁决**。正魔可以双高（两面派，收益最大风险最大）、可以双低（隐世）、可以单高（站队）。由「声望差」决定表面立场，由「曝光度」决定是否被揭穿。详见 §5.1。

### 🔴 P0-3 围剿战是惩罚，不是玩法

**现状**（§11.4.5.3 / §11.4.6）：
- 魔道声望过高 → 定期触发「正道联盟围剿」（被动挨打）
- 正道声望过高 → 可主动发起「邪宗围剿」（主动出击）

**问题**：
1. **严重不对称**：魔道玩家只有被动挨打，正道玩家有主动玩法。魔道路线在玩法量上天然吃亏
2. 「声望高 = 挨打」是负反馈，玩家最优解是**卡住声望不越线**，而不是享受战斗。机制在惩罚投入
3. 无预警、无备战窗口、无谈判选项——纯被动承受

**修正方向**：改造为**危机经营闭环**：预警期 → 备战窗口（多条应对路线）→ 多波车轮战 → 战后结算（败则失据点，胜则反杀夺地）。详见 §5.3。

### 🟡 P1-4 声望条单调累积，无衰减 = 无时间压力

**现状**：声望只增不减（除特定惩罚行为），0→20000 是一条上坡路。

**问题**：没有衰减就没有紧迫感，玩家可以无限期搁置正魔内容，回来时状态不变。放置游戏里，**时间压力是唯一的稀缺资源制造机**。

**修正方向**：引入**声望衰减**（长期不做该阵营任务则缓慢衰减）+ **曝光度自然增长**（藏不住的秘密会自己败露）。详见 §5.1.3。

### 🟡 P1-5 战功有出口无入口

**现状**：`battle_merit_shop.csv` 已配置 11 项战功商品（聚气丹/赤焰战鼓/玄龟护盾…），§11.20 也把战功列为四层货币之一。但**没有任何 CSV 或规则定义战功的产出来源**。

**修正方向**：战役层（L3）全部产出统一接到战功，形成「打 → 战功 → 买 → 更强地打」闭环。这是**零新增表、纯接通**的高性价比改动。

### 🟡 P1-6 战果无持久化、无叙事化

**现状**：打赢宗门战 → 涨声望数值。结束。

**问题**：玩家不会记得「我打下了哪座魔道分坛」。§11.2.3 宗门史记（三级里程碑）已经建好，却没接正魔战果。

**修正方向**：正魔大战的关键战果（首杀、夺据点、被围剿守住、揭穿后洗白）自动写入宗门史记，复用现有回调（§11.2.3 已定义为「复用各系统结算回调」）。

### 🟢 P2-7 数据一致性缺陷（顺手抓到，建议立即修）

| # | 位置 | 问题 | 风险 |
| --- | --- | --- | --- |
| A | `faction_quests.csv` | 阵营列写「魔道邪宗」但 quest_id 前缀为 `fz_modao_`，而 `faction_base.csv` / `npc_config.csv` 用 `fz_mo`。**三处命名不一致** | 代码 join 需要硬编码映射表，违反「单一数据源」 |
| B | `faction_base.csv` | `global_buff_1` / `global_buff_2` 存的是**中文文案**（「正道弟子好感」「魔道功法加成」），不是数值列 | 程序无法消费，只能手抄进代码，后续改数值要改代码 |
| C | `faction_base.csv` | 六个阵营的 `unlock_content` 完全相同（初级坊市/中级坊市+专属差事/高级坊市+阵法权限/至臻坊市+秘传） | 阵营辨识度为零，六个阵营换来一样的解锁物 |
| D | `faction_shop.csv` (20 行) | 六阵营 × 5 档 = 30 格位，只填了 20 行 | 部分档位无货，玩家升到该档无感 |

**建议**：A/B/C 列入 P0 修复（纯数据层，不动代码逻辑）；D 补齐留待内容批次。

## 4. 重构方案总览

```
                    ┌─────────────────────────────┐
                    │  里层 · 幽魔潮汐（赛季/终局）  │
                    │  域外幽魔族封印松动 → 全服危机  │
                    │  强制停战 · 正魔联手 · 主线卷五 │
                    └──────────▲──────────────────┘
                               │ 意义来源（玩家为何而战）
    ┌──────────────────────────┼──────────────────────────┐
    │                          │                          │
┌───┴────────┐        ┌────────┴────────┐        ┌────────┴────────┐
│ L1 声望层   │──────▶ │  L2 战线层       │──────▶ │  L3 战役层       │
│ 双面声望    │ 决定   │  地域控制度      │ 产生   │  四类战役        │
│ + 曝光度    │ 立场   │  （中州+四边域） │ 战役   │  → 战功/声望/史记 │
│ P0          │        │  P2             │        │  P0-P1           │
└────────────┘        └─────────────────┘        └─────────────────┘
```

**关键**：三层不是并列功能，是**因果链**。声望决定你为谁而战，战线决定你在哪打，战役决定你打不打得赢，战果回流到声望与史记。

## 5. 核心机制详设

### 5.1 机制 A｜双面声望 + 曝光度（改造 L1，P0）

> 替换 §2.1「正魔此消彼长」规则。**纯增量**：不改声望门槛，不改阵营 ID，只在 `faction_base.csv` 增列 + 增一张关联表。

#### 5.1.1 双轴独立

正道声望 `rep_zheng` 与魔道声望 `rep_mo` **独立累积，不再互相扣减**。

派生量：

```plaintext
立场值 stance   = rep_zheng − rep_mo            # 决定表面站队
立场判定：
  stance > +T1   → 守正（正道待遇）
  |stance| ≤ T1  → 骑墙（中立待遇，可双头接任务）
  stance < −T1   → 行异（魔道待遇）        T1 = [PLACEHOLDER]
```

#### 5.1.2 曝光度 Exposure（0–100）

新增单一字段 `exposure`，**不属于任何乘区，不是增益，是风险计量器**。

| 行为 | 声望变化 | 曝光变化 | 说明 |
| --- | --- | --- | --- |
| 公开阵营任务（巡山/讲经/血祭大典） | +rep 该阵营 | +E_pub [PLACEHOLDER] | 光明正大，涨得快也藏不住 |
| 隐秘阵营行为（黑市交易/暗投供奉/夜间掠夺） | +rep 该阵营 | +E_sec（E_sec ≪ E_pub） | 闷声发财，但声望效率打折 |
| 跨阵营行为（正道宗门开黑市） | +rep 对方阵营 | +E_cross（最高） | 最危险的投机 |
| 时间自然流逝 | — | +E_decay / 游戏月 | 秘密会自己败露 |

**曝光阶位**：

| 曝光 | 状态 | 效果 |
| --- | --- | --- |
| 0–30 | 隐秘 | 无影响，可安全骑墙 |
| 31–60 | 风声 | 敌对阵营 NPC 委托减少；奇遇出现「试探」分支 |
| 61–85 | 动摇 | 触发「问责前兆」事件；己方弟子道心动摇概率上升 |
| 86–100 | 败露 | **强制触发「揭穿」大事件**（见下） |

#### 5.1.3 揭穿事件（玩家高光时刻）

曝光达 100 时强制触发，玩家三选一（复用 §10.4 奇遇全选项化框架，零新增 UI）：

| 选项 | 结果 |
| --- | --- |
| **剖白**（公开站队） | 立场值强制推向该阵营；对面阵营声望清半；弟子按倾向大规模离职/留下（道不同不相为谋，对齐 §2.2）；解锁「明旗」标识 |
| **献祭**（交投名状） | 损失大量资源 + 派核心弟子执行一次高危任务；**两面声望保留**，曝光清零；解锁「双面」隐藏路线 |
| **转投**（叛变） | 全部声望平移到新阵营 ×0.6；原阵营立即触发一次围剿（§5.3）；获得「反正」史记条目 |

**设计 rationale**：把「被揭穿」从惩罚变成**玩家最想要的高光时刻**——三种活法，都是故事，都能写进宗门史记。这是本方案里玩家记忆点最强的一处。

#### 5.1.4 声望衰减（P1，可选开关）

```plaintext
每游戏月结算：
  若该阵营本月任务完成数 = 0：rep × (1 − decay_rate)    decay_rate = [PLACEHOLDER]（建议 3%~5%）
  曝光度：exposure += E_decay
```
总控开关 `enable_faction_decay`，默认**关**（MVP 不引入焦虑），待声望层跑通后灰度开启。

### 5.2 机制 B｜非对称阵营收益矩阵（替换对称 +10%，P0）

> **核心原则**：阵营差异**不靠属性，靠玩法权限 / 资源通道 / 风险曲线**。属性增益统一压到 ≤5% 量级，全部计入现有乘区，不申请任何独立额度。

| 维度 | 正道宗门 | 魔道邪宗 | 中立散修 |
| --- | --- | --- | --- |
| **经营通道** | 正道商路（安全、低价）、凡人香火供奉（§11.18 功德/香火） | 黑市（高倍率、高风险）、掠夺商队、血祭速成 | 拍卖行低佣金、坊市客流、两头通吃 |
| **养成通道** | 心魔增长率 −20%、突破稳定、丹药纯度 | 修炼速度 +15%、攻击基础值高、走火入魔概率翻倍 | 特殊命格高发、资质上下限极大 |
| **专属玩法** | 讲经法会、除魔卫道、正道问责（约束自己） | 血祭修炼、魔道大典、妖兽斗场竞猜 | 散修悬赏、情报网、居中调停 |
| **风险源** | **问责**（自己阵营约束你，扣声望/降招募质量） | **围剿**（外部敌人来打你，多波车轮战） | 无专属风险，但声望增长最慢 |
| **属性点缀** | 道心成长 +5%（道心乘区） | 攻击 +5%（通用乘区） | 无 |
| **爽点** | 名门正派、万人敬仰、稳 | 快意恩仇、以力破巧、快 | 投机、套利、自由 |

**战斗克制改为非对称**（替换 §11.4.5.3 对称 +10%）：

| 攻方 \ 守方 | 正道 | 魔道 | 中立 |
| --- | --- | --- | --- |
| **正道** | — | 伤害 +12% `[PL]`（除魔有加成，道心收益 +5%） | 伤害 +3% `[PL]` |
| **魔道** | 伤害 +8% `[PL]`（正道防御体系强，但魔道有心魔狂暴补偿） | — | 伤害 +5% `[PL]` |
| **中立** | 伤害 +3% `[PL]` | 伤害 +3% `[PL]` | — |

**rationale**：正道打魔道收益更高（12% > 8%），但魔道修炼快、攻击底子高、有心魔爆发——**前期魔道强，后期正道强**，形成节奏差而非数值差。中立是安全但平庸的第三选项。三者构成「快 vs 稳 vs 灵」的三角，而非数值高低。

### 5.3 机制 C｜围剿战 → 危机经营（改造 L3，P1）

> 改造 §11.4.5.3「阵营围剿事件」。**正魔对等化**：双方都有主动围剿与被动围剿。

#### 五阶段闭环

```
① 预警期（3 游戏日，对齐 §6.13.4 叛逃预警期时长）
   ↓ 战报/传讯符通知，列出预计敌军波次与强度
② 备战窗口（玩家唯一的决策点）
   ├─ 死守：修护山大阵（消耗灵石，耐久 +X%）
   ├─ 求援：消耗战功/人情，召唤友军援军（复用 §6.18.6 友好援军）
   ├─ 纳贡：缴纳资源换取敌方可否（减波次，但扣己方阵营声望）
   ├─ 假意投诚：曝光度 +大量，换取敌军退兵（接 §5.1 揭穿线）
   └─ 弃守：主动放弃据点，保全部队（失据点，弟子道心 −）
   ↓
③ 多波车轮战（复用 §11.4.5.2 状态继承，无新增战斗逻辑）
   ↓
④ 战后结算
   ├─ 守住：大量战功 + 阵营声望 + 宗门史记「XX 之守」条目
   └─ 失守：据点易主、灵材产地停产 N 日、弟子重伤（无陨落，守 §11.4.5.4）
   ↓
⑤ 反攻窗口（7 日内可发起反攻夺回，否则据点固化）
```

**关键设计**：② 备战窗口是**玩家唯一的操作点**，符合 §11.4.1「战前配置、战后看战报」的操作边界，不引入手动战斗。五选一的决策本身就有策略深度，且每条路都接已有系统（护山大阵 / 跨门派社交 / 财政 / 曝光度 / 宗门史记）。

**命名规范**：统一术语为「围剿」（防守方视角）/ 「讨伐」（进攻方视角），全文档禁用「征讨 / 讨伐战 / 围攻」等变体。

### 5.4 机制 D｜幽魔潮汐（新增里层，P2-P3）

> **本方案最高价值项**：把 §16.1.2 已存在但无人引用的「幽魔族封印松动」伏笔，接成正魔大战的终局形态。

#### 5.4.1 触发

绑定主线卷五（§16.3 卷四颠覆性真相之后）与赛季节奏：

```plaintext
触发条件：主线进度达卷五  AND  全服幽魔值 ≥ 阈值 [PLACEHOLDER]
持续：7 个游戏日（一个完整赛季周期）
```

#### 5.4.2 核心机制：强制停战

潮汐期间，**全服正魔阵营进入「共御外侮」状态**：

| 系统 | 潮汐期间变化 |
| --- | --- |
| 正魔克制矩阵（§5.2） | **全部置 0**——不再互相加成 |
| 阵营任务 | 正魔双方任务池合并为「联军任务」，奖励统一 |
| 围剿战 | 暂停触发，已触发的转为「幽魔来袭」防守战 |
| 声望结算 | 联军贡献**同时**计入正魔双阵营声望（唯一一次合法双涨） |
| 曝光度 | 停止增长（大敌当前，无人追究旧账） |

#### 5.4.3 玩家的核心抉择

潮汐结束时结算，玩家有一次**不可逆的阵营终局抉择**（三选一，写入宗门史记·传奇级）：

| 选项 | 代价 | 奖励 | 后续 |
| --- | --- | --- | --- |
| **殉道**（加固封印） | 献祭 1 名元婴以上核心弟子（入先贤堂，§6.10.4） | 全宗永久微量增益（入先贤堂 5% 池，不新增额度） | 解锁结局分支 A |
| **夺源**（引魔气入体） | 全宗弟子心魔 +大量、道心 − | 短期战力暴涨，解锁魔道终局功法 | 解锁结局分支 B |
| **中立**（保全宗门） | 无代价，但也无特殊奖励 | 联军贡献 ×1.2 | 解锁结局分支 C |

**设计 rationale**：
1. **给表层正魔对抗一个意义**：你争了几十小时的正魔，最终要在灭世危机面前做出选择——这个选择比任何数值都更能定义玩家的宗门。
2. **零新增系统**：全部复用先贤堂（§6.10.4）、心魔道心（§6.9 / §11.16）、结局系统（GDD-结局系统.md）、宗门史记（§11.2.3）、天道异动（§10.3）。
3. **给长线留存一个锚**：潮汐是赛季级事件，可重复（封印每次都会再次松动），每次玩家可以做不同选择，走向不同结局分支。
