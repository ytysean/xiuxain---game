# 27 屏战斗交互规格

## 页面定位

出战确认弹窗：从历练、山门、奇遇等战斗入口点击「前往」后弹出，用于确认敌方信息、我方编队，然后进入 02 屏「战斗推演」自动战斗。

> 设计意向声明：战斗主流程已在设计评审中确定为「S1 自动推演展示」（进入即自动运行、技能区默认折叠、仅留结算预览/跳过/倍速）。本弹窗作为出战前确认层，按该方向构建。

## 信息架构

1. **顶部标题区**：标题 + 关闭
2. **敌方信息区**：敌名 / 等级 / 威胁星级
3. **我方编队区**：最多 3 名上阵弟子卡，显示名称与战力
4. **战力汇总区**：总战力
5. **提示区**：说明进入后自动推演
6. **底部操作**：取消 / 出战

---

## 交互规则

| 元素 | 交互 | 状态/反馈 |
|---|---|---|
| 关闭 ✕ | 点按 | 关闭弹窗，留在入口页 |
| 取消 | 点按 | 关闭弹窗，留在入口页 |
| 出战 | 点按 | 关闭本弹窗，切换到 02 战斗推演屏，自动开始战斗 |
| 弟子卡 | 点按（S2） | 打开编队调整，可替换上阵弟子；S1 仅展示，不可调整 |
| 威胁星级 | 仅展示 | 根据敌方等级与玩家平均战力计算，1–5 星 |

## 代码映射

- 入口：历练页 `page_explore.gd`、山门事件、奇遇弹窗等战斗触发点。
- 出战数据：
  - 敌方：由入口传入（敌人 ID / 等级 / 威胁配置）。
  - 我方：默认取 `Game.当前出战编队`（若无则取战力最高的 3 名弟子）。
  - 战力计算：调用 `disciple.gd::get_final_combat_attr()` 折算计攻防血速后加总。
- 与 02 屏衔接：点击出战后向 `game_state` 写入 `pending_battle = {enemy, squad}`，再由主场景切到 02 战斗推演屏。
- 约束：S1 零战斗触碰——本弹窗仅做展示与入口，不修改 `BattleCalculator` / `BattleManager` 逻辑。

## 验收清单

- [ ] 从历练/山门/奇遇入口可打开出战确认弹窗。
- [ ] 敌方名、等级、威胁星级正确显示。
- [ ] 我方编队默认显示正确的 3 名弟子与各自战力。
- [ ] 总战力按攻防血速折算规则正确汇总。
- [ ] 点击「出战」后切换到 02 战斗推演屏并自动开始。
- [ ] 点击关闭/取消留在原入口页，不触发战斗。
