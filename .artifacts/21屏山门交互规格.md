# 21 屏山门交互规格

## 页面定位

宗门主界面侧边入口「山门」的设计稿，承载「宗门对外门户」功能：展示护山大阵状态、随机来访 NPC（散修求道 / 云游商旅 / 魔修探子），并提供召见/驱逐等交互入口。

> 设计意向声明：本屏无现成 `page_*.gd` 或 GDD 可对照，以下结构按「度假式自动推演 + 事件触发」方向合理假设；实装前需策划/用户确认事件频率、奖励与风险数值。

## 信息架构

1. **顶部导航**：返回 + 标题
2. **宗门状态区**：宗门名 / 山门等级 / 大阵充能
3. **来访事件区**：三类 NPC 卡片（散修、商旅、魔修探子）
4. **底部提示**：滚动引导

---

## 交互规则

| 元素 | 交互 | 状态/反馈 |
|---|---|---|
| 返回按钮 | 点按 | 返回 01 主界面，关闭山门页 |
| 召见按钮（散修/商旅） | 点按 | 打开该 NPC 交互弹窗：散修可能展示「入宗 / 赐丹 / 婉拒」三选一；商旅展示交易列表 |
| 驱逐按钮（魔修） | 点按 | 移除该卡片，可能弹出「成功驱逐，获得少量灵草」或「魔修负伤遁走」提示 |
| 大阵状态条 | 仅展示 | 充能比例随时间与宗门资源自然恢复；低于阈值时增加魔修入侵概率 |
| NPC 卡片 | 左滑/点按 | 点按整张卡也可进入详情；列表超过 3 张时启用垂直滚动 |
