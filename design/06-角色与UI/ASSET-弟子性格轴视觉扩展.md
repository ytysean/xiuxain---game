# 《太玄宗门录》弟子「性格」维度视觉扩展规范 v1.0

> **引用权威文档**：`太玄宗门录_角色与UI美术规范.md` v2.0（写实修仙方向，2026-07-22 锁定）
> **本规范定位**：v2.0 的**纯增量扩展**，不修改 v2.0 任何已锁定章节。v2.0 已设计的随机生成体系按 `资质×职业×灵根×性别×年龄` 组合，但**缺失「性格」维度**——本规范补全该维度，并给出可落地的视觉映射与接入方式。
> **风格铁律**：严格对齐 v2.0「写实修仙 + 清雅低饱和 + 金玉木石材质」。**禁止 Q 版 / 卡通 / 扁平角色脸 / 纯玻璃拟态**（见 v2.0 §4.1.5）。角色美术走 v2.0 §8 既定的 **AI 出图**路线（Stable Diffusion + ControlNet / Midjourney），不在画布用矢量拼脸。

---

## 一、为什么需要「性格」轴

v2.0 §1.1 四层模块化部件 + §8 AI 批量，已实现 `资质(7档) × 职业(体/法/道) × 灵根(五行) × 性别 × 年龄(4段)` 的随机组合。但弟子作为「经营养成」对象，行为、事件、互动强烈依赖**性格**——而现有体系无法让玩家从外观一眼分辨性格。

本规范把 **性格** 作为第 6 个独立随机维度接入，使外观辨识度从「属性组合」进一步细化到「气质区分」，且**不新增建模部件**（复用头部差异化层 + 特质修饰层表达）。

---

## 二、性格维度定义（6 型，可扩展）

取修仙语境下辨识度高、与玩法（派遣/突破/羁绊）强相关的 6 型。后续可按需扩至 8 型，本规范结构不变。

| 序 | 性格 | 玩法语义（参考，非本规范强制） | 视觉难度 |
| --- | --- | --- | --- |
| 0 | 沉稳 | 修炼稳、少失误 | 低（基础端正） |
| 1 | 活泼 | 历练活跃、事件是多 | 中（神态生动） |
| 2 | 孤傲 | 独行、不与俗同 | 中（冷峻疏离） |
| 3 | 暴躁 | 战意盛、易冲突 | 中（张力外放） |
| 4 | 温润 | 亲和、善际、疗愈向 | 中（柔和舒展） |
| 5 | 狡黠 | 机变、投机、商道向 | 中（灵动狡猾） |

> 性格与 **资质（七档稀缺度）** 正交：同一性格可出现在凡俗弟子（量产档）与道胎弟子（典藏档），由 v2.0 §1.2 的 2:3:5 产能分配各自处理。性格只决定「神态气质」，不决定「精度/特效量级」。

| --- | --- | --- | --- | --- | --- | --- |

| 活泼 | 圆润杏眼、眉梢微扬 | 浅弧笑、露三分笑意 | 双髻 / 松散小揪 | 微前倾、头侧、灵动 | 小银铃 / 红绳结 | 神采灵动，眉眼含笑，姿态轻快 |
| 孤傲 | 细长挑眉、半阖凤眼 | 紧抿一线 | 高束长发、一缕披肩 | 侧身、微抬颌、疏离 | 背悬古剑（未见鞘光） | 神情疏冷，目光如刃，姿态孤高 |

## 四、接入 v2.0 §1.1 模块化部件

| v2.0 层级 | 性格轴的落点 | 说明 |
| --- | --- | --- |
| 基础底层（骨架/体型） | **不动** | 性格不改变性别、职业体态 |
| 头部差异化层 | 眉眼参数 / 嘴型参数 / 发型倾向 | 在既有 5~8 套脸型、发型库内，按性格挑参组合，不新增模板 |
| 服饰基底层 | **不动**（仍由职业/宗门品级决定） | 性格不换衣服 |
| 特质修饰层 | 姿态气质参数 / 微配饰挂载 | 新增「性格微配饰」子集（银铃/红绳/药葫芦/折扇等），低模仅保留剪影级辨识 |

- 量产档（凡俗/平庸/优良，占 80%）：性格仅通过**眉眼/嘴型/姿态参数**表达，无额外微配饰建模；
- 进阶档（天才/妖孽，占 15%）：开放性格微配饰挂载 + 神态精修；
- 典藏档（旷世/道胎，占 5%）：性格融入专属面部/服饰叙事，接近独立角色品质。

## 六、头像 = 立绘动态人脸检测裁切（对齐 v2.0 §8.6）

- 弟子头像**不单独建模/出图**，统一由立绘头肩区域裁切得到，保证名册/详情/招募界面与立绘 100% 同源；
- **裁切方式：人脸检测动态裁切**，不再使用固定坐标。AI 出图的头部位置天然不统一（偏上/偏下/缩放差异），固定坐标会切到半张脸。现由 `crop_lib`（OpenCV DNN SSD 人脸检测器）自动定位主脸中心，按自适应留白计算正方形裁切框；检测失败则回退「上中构图」兜底坐标，并在清单中标记 `fallback_upper_center` 强制人工复核；
- **构图锁（量产前必加）**：提示词强制「1024×1536 竖幅，头顶留白约 10%，头位于画面上部 15%–25%，头高占图高 22%–28%，面部无俯仰、头部不歪，发髻/冠饰完整露出且不遮挡眉眼」，从源头收敛头部位置，降低检测兜底率；
- 头像框沿用 v2.0 §四·B「弟子头像框」：白玉圆形画框 + 暗金描边 + 青铜回纹 + **资质色边**（七档色见 v2.0 §4.4）；
- 性格差异在头像内通过眉眼/嘴型/姿态体现，框不变；
- 人工抽检表见 `美术资源/弟子原型套组_A/提示词包/avatar_inspection_table.md`，首批评量 100% 全检，稳定后 30% 抽检，兜底坐标 100% 复核。

## 七、随机生成与 Godot 接入（纯增量，不碰底层）

**外观 seed 组合（新增性格维度）**：

```
appearance_seed = hash(资质档, 职业, 灵根, 性别, 年龄段, 性格)
```

- 弟子创建时由**配置表自动分配外观资源**（v2.0 §5.3 既定原则），原有玩法逻辑完全无感知；
- 性格作为外观参数之一写入弟子外观配置；`TextureRect` 按 `appearance_seed` / 资源路径加载立绘，头像由立绘裁切；
- 组合爆炸由「模块化部件复用 + AI 批量」消化，不做有限原型套组预烘焙（即不走"扁平矢量原型套组"路线，避免与 v2.0 写实方向冲突）。

## 八、前置依赖与边界

1. **前置依赖（工程侧，不在本美术规范范围）**：当前弟子数据层是否含「性格」字段需确认；若未含，须先在 `disciple.gd` 增加 `性格` 属性（数据层），本规范的视觉映射才能驱动。该改动属数据层增量，不触动玩法逻辑。
2. **风格边界**：本规范所有产出必须过 v2.0 §4.1.5 禁止风格清单；角色脸一律写实，禁用扁平/Q 版/卡通。
3. **不与 v2.0 冲突**：本规范仅扩展「性格」维度，不修改资质/职业/灵根/性别/年龄/境界的既有视觉规则与产能分配。
4. **画布工具不适用**：角色美术不在 ardot 设计画布用矢量拼制；画布仅用于 UI/图标/海报（v2.0 §四·A/B/C 类），角色资产走 §8 AI 出图管线。

## 九、资质三维视觉分层（普通 / 精英 / 顶级）

> 与「性格」轴**正交**：性格只管神态气质，资质决定「精度 / 材质 / 特效量级」的稀缺度分层。两者叠加生效，互不替换。

v2.0 §1.2 的资质七档（凡俗 / 平庸 / 优良 / 天才 / 妖孽 / 旷世 / 道胎）在**视觉上聚合为三档稀缺度层级**，对应产能占比 80% / 15% / 5%。玩家须能凭立绘一眼分辨弟子档位。

### 9.1 三档视觉分层总表

| 层级 | 含七档 | 占比 | 服饰材质与纹样 | 头冠 / 发饰 | 灵气光效量级 | 背景层次 | 神态气质精度 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **普通** | 凡俗·平庸·优良 | 80% | 素色简袍 / 粗布短打，无纹或极简暗纹，无镶边 | 无冠 / 粗布带简单束发 | 几乎无灵气光晕（≤1 微弱星点） | 平涂暗背景，无光效 | 面容寻常，五官平实，无额外精修 |
| **精英** | 天才·妖孽 | 15% | 云纹长袍（灵根主色），暗金描边，局部精致纹样 | 玉冠 / 银冠 | 淡灵气光晕（侧逆光 + 小范围灵气） | 微光背景，淡淡灵气弥散 | 眉眼有神采，神态精修，气质出众 |
| **顶级** | 旷世·道胎 | 5% | 繁纹华袍镶宝（灵根主色 + 暗金 + 宝玉），多层衣纹堆叠 | 高冠嵌珠 / 羽饰，宝光流转 | 浓郁多层灵气光环 + 星点爆发，磅礴体积光 | 灵气磅礴背景，光带 / 符文隐现 | 威严从容，面部叙事专属感，材质极致写实 |

### 9.2 区分铁律

1. 资质分层**只改材质 / 纹样复杂度 / 光效量级 / 头饰等级 / 背景层次**，**绝不改体型、不改灵根配色、不改性格神态**——三层（灵根 × 性格 × 资质）正交叠加。
2. 普通档**严禁**出现镶宝 / 多边光环 / 华丽冠饰；顶级档**必须**有多层灵气光环 + 星点爆发，否则稀缺度读不出。
3. 同一弟子（同灵根同性格），仅切换资质档，应能从「素衣无光 → 云纹淡光 → 繁纹磅礴光」一眼分辨档位。

### 9.3 AI 出图关键词（资质层，叠加在 §五 通用风格词与性格词之后）

- **普通**：`plain unadorned robe, no ornament, simple tied hair, minimal spirit aura, flat dark background, ordinary features`
- **精英**：`cloud-patterned robe with dark-gold trim, jade crown, soft golden spirit aura, subtle backlight, refined features`
- **顶级**：`ornate brocade robe inlaid with jewels, high crown with pearls and feathers, radiant multi-layer spirit halo with starlight, majestic aura, hyper-detailed`

## 十、穿戴系统对联立绘的处理（重要）

> 本章为「立绘设计」与「游戏穿戴系统」的对接决策，事实来自 `item.gd`。

### 10.1 游戏穿戴现状（事实）
- **9 个穿戴位**：`法兵 / 道冠 / 法袍 / 灵腕 / 束灵带 / 灵裤 / 云靴 / 灵饰 / 本命法宝`。
- 物品类别 → 穿戴位分配：
  - `fa_qi`（法器，掉落权重 30%）：随机分到 8 个槽之一 —— **含 `法袍`（衣服）、`道冠`（帽子）** 及 灵腕 / 束灵带 / 灵裤 / 云靴 / 灵饰 / 法兵。
  - `shen_bing`（神兵，15%）：`法兵`（按 道修 / 体修 / 法修 命名不同）。
  - `fabao`（法宝，5%）：`本命法宝`。
- `法袍` / `道冠` 各有 **7 阶**（粗布道袍→道祖天袍 / 粗布冠→道祖天盔），即弟子**会真实换衣服、换帽子**。

### 10.2 冲突点
- `法袍` 覆盖弟子袍服 → 冲击立绘「灵根色制式袍 + 资质档纹样」。
- `道冠` 覆盖头冠 → 冲击立绘「资质档头冠」（普通无冠 / 精英玉冠 / 顶级高冠）与头像头肩裁切。
- `法兵 / 神兵 / 法宝` 为手持 / 背负 / 悬浮武器。

### 10.3 决策：立绘锁定「本体基础态」+ 装备走 UI（推荐，唯一务实解）
**理由**：写实厚涂 AI 立绘是整图，无法在运行时把「法袍 / 道冠」贴到已出立绘上而不穿帮（写实分层拼装接缝明显、光影不连续）；要实现「立绘随装备变」，只能走 v2.0 §1.1 模块化 3D / 分层管线，超出当前 2D 写实立绘路线。

**规则**：
1. 立绘画「宗门制式基础态」：**灵根色制式袍**（保灵根辨识）+ **资质档头冠 / 无冠** + 性格神态 + **性格非武器微配饰**（拂尘 / 葫芦 / 折扇等剧情道具，不占装备槽）。
2. **穿戴装备不在立绘上体现**，统一在 **弟子详情 / 装备 UI 面板** 表现：装备图标 + 名称 + 品阶 + 属性词条。立绘保持不变。
3. **头像**（头肩裁切）同样锁定本体，不因实穿戴道冠而变 —— 名册 / 招募 / 头像框稳定统一。
4. **灵根辨识保留**：制式底袍灵根色始终在线；实穿法袍颜色走装备 UI，不作为立绘外观。

### 10.4 轻量联动（可选，增味不增负，低优先级）
- **本命法宝悬浮光效层**：`fabao` 是灵气实体，可做成运行时 2D 悬浮光效贴图叠加在立绘周围（不破坏脸 / 身），体现「本命法宝环绕」修仙感。这是唯一适合运行时叠加的装备维度。
- **高阶装备品质光晕（可选）**：弟子穿戴 ≥ 化神级（第 5 阶起）装备时，立绘可叠加一层淡淡装备品质光晕 / 符文（不改衣服形状，仅光效暗示）。低优先，待主美评估。

### 10.5 预留升级
- 若未来要做「换装立绘」，只能走 v2.0 §1.1 模块化部件（3D 渲染或严格光影统一的分层 2D），不在当前 AI 整图立绘路线内。本规范暂不纳入。

## 附录 A：同质化收敛优化（方案 A / B，验收后落地）

> 验收结论：整套 90 原型提示词包已达工业化批量出图标准。跨组辨识度充足（灵根色系 / 性格姿态神态 / 资质三档 / 性别轮换四维正交）；仅「同灵根 + 同资质 + 同性别」小组内生视觉趋同（服装版型统一、AI 脸趋同、构图框架统一、道具复用率高），属批量生产正常现象，以低成本差异化收敛即可，无需重构。

### A.1 方案 A：差异化变体候选池（低风险，已落 `variants` 字段）
- **不改变确定性主 prompt**（90 条基线仍可直接出图、可审核）；
- 每条原型 JSON 的 `variants` 提供三类候选，批量出图脚本随机选注其一，实现同组差异：
  - `hair`（发型变体，3 选）：替换主发型，如沉稳 高束发加玄色发带 / 束发嵌玉簪 / 半披发；
  - `face_feature`（面部弱特征，5 选）：追加轮廓/骨骼类细节（清晰下颌线 / 高挺鼻梁 / 立体颧骨 / 饱满天庭 / 清瘦面颊），不与性格神态冲突；
  - `accessory_material`（配饰材质，5 选）：追加镶玉 / 鎏金 / 银丝 / 木纹 / 宝石细节，做小区分。
- 批量脚本用法：出同组多张时，随机挑 hair/face_feature/accessory_material 各一项注入 prompt，即可同组不全一样。

### A.2 方案 B：顶级档专属元素（确定性内联，已落顶级档主 prompt）
- 顶级档（30 张）主 prompt **直接内置**性格专属华丽细节，拉开与精英档差距，不占装备槽：
  - 沉稳：肩胸织锦暗纹护肩 + 腰封繁复玉扣；活泼：衣摆流苏飘带 + 多重银铃；
  - 孤傲：肩绕纱质披帛 + 冷银描边；暴躁：皮质护肩嵌铆钉 + 金属护臂；
  - 温润：衣襟刺绣药草纹 + 暖玉腰佩；狡黠：折扇暗金描边 + 耳坠长流苏。
- 普通 / 精英档保持制式统一（符合宗门统一着装世界观），不做专属元素。

### A.3 结合游戏场景的判断
- 列表页小头像：识别冠饰 / 发色 / 灵根底色，现有差异足够；
- 详情页单图：玩家关注质感与神态，不横向对比，单张品质优先于重度差异；
- 「制式同质化」本身契合宗门弟子统一着装设定，仅需给顶级 / 核心角色做专属差异化（即方案 B）。
