## 1. 设计目标

### 1.1 气质表达

参考图传达的核心气质为**「仙山宗门·沉浸式主权展示」**：

| 维度 | 表达 | 设计手段 |
|---|---|---|
| 沉浸感 | 全屏山水宗门背景图，玩家「置身」太玄宗门山门前 | 背景图铺满画布，无留白边框 |
| 主权感 | 一眼可见宗门名、核心资源、弟子规模、繁荣度——「这是我的宗门」 | 顶部信息条 + 右侧悬浮节点 + 宗门动态面板，三重信息锚点 |
| 古朴金青 | 深青底 + 淡金描边 + 毛笔标题，修真宗门质感 | 严格沿用 `UI设计令牌v1.0.md` 色板 |
| 动态呼吸 | 云雾/飞鸟/四季天光变化营造「活着的宗门」氛围 | 背景图为静态交付（四季各一张），动态粒子/视差属 S2 扩展 |

### 1.2 信息优先级（Z 轴从高到低）

```
P0  底部导航 Tab     → 全局路由入口，始终可达
P1  宗门动态面板      → 核心经营指标一览（弟子数 / 繁荣度 / 声望）
P2  顶部信息条        → 宗门名 + 核心资源快览（灵石 / 灵气 / 草药 / 声望）
P3  右侧悬浮资源节点   → 灵气 + 草药 大图标快捷查看（与顶部信息条冗余但增强视觉）
P4  背景主视觉        → 宗门山门沉浸背景（纯装饰，不承载交互）
```

### 2.2 各区域尺寸规格

| 区域 | 高度 (px) | Y 范围 | 锚定方式 | 说明 |
|---|---|---|---|---|
| **顶部信息条 TopBar** | **56** | 0 – 56 | `PRESET_TOP_WIDE` | 含左标题+右资源；比现有 TOPBAR_H(64) 收窄 8px，为主视觉让空间 |
| **主视觉安全区** | **682** | 56 – 738 | FULL_RECT（在 TopBar 与 BottomTab 之间） | 背景图展示区；右侧悬浮节点在此区内绝对定位 |
| **宗门动态面板** | **148**（约） | 居中偏下，底部距 Tab 约 40px | 绝对定位或 VBox 底部对齐 | 圆角金边半透明面板；见 §3.3 详细规格 |
| **底部导航 BottomTab** | **60** | 794 – 854 | `PRESET_BOTTOM_WIDE` | 比 TAB_H(72) 收窄 12px，最大化主视觉 |

> **设计决策说明**：参考图中顶部栏较薄、底部 Tab 也较紧凑。相比现有代码的 TOPBAR_H=64 / TAB_H=72，本规格建议分别收窄至 **56 / 60**，净增 **20px 主视觉高度**。此调整需程基岩同步修改 `ui_theme.gd` 常量（标注为**代码对齐点 A**）。

### 2.3 安全区与内容避让

| 约束 | 值 | 说明 |

#### 3.1.1 四季背景代码化生产规范（长期基准）

> 背景图由「单张夜景」升级为「四季天光体系」，全部参数固化进代码模板 `美术资源/scene_pipeline/scene_template.py`，杜绝批次漂移与人工重写提示词。

| 季节 | 天光 | 关键元素 | 整体亮度 | 中心呼吸区（硬栅 ≤0.304） |
|---|---|---|---|---|
| 春 spring | 黎明粉蓝天光 | 新绿桃樱、飘瓣、晨光 | ≈0.47（最亮） | ✅ 通过 |
| 夏 summer | 澄澈深蓝积云 | 浓绿飞瀑、水雾流光 | ≈0.36 | ✅ 通过（含「中心压暗」约束） |
| 秋 autumn | 琥珀橙紫黄昏 | 金红枫叶、宫灯初亮 | ≈0.29（最沉） | ✅ 通过 |
| 冬 winter | 幽蓝雪夜 + 弯月 | 积雪苍松、冷蓝剑光（**唯一含月色**） | ≈0.31 | ✅ 通过 |

- **四季亮度梯度固化**：春 > 夏 > 冬 > 秋，靠**色温**而非纯明暗区分（故春整体亮度可高于旧规 35%，不冲突）。
- **中心 UI 呼吸区亮度硬栅 = 0.304**：由 `scene_validate.py` 自动检测（PIL 统计中心区 [30%~70% × 35%~65%] 平均亮度），≥0.304 即判「不合格_亮度」并回流重绘。当前 4/4 季全部 ≤0.304 通过。
- **统一负面提示池**（折叠进正向 prompt，因平台 ImageGen 无原生 negative_prompt）：禁止 建筑结构扭曲 / 透视错误 / 构图失衡 / 多只麒麟 / 主殿偏移 / 阶梯错位 / 畸变 / 扁平矢量 / 卡通Q版 / 低质量 / 过曝 / 文字·书法·汉字·字母·数字。强制锁死镜头、构图、结构，杜绝批次漂移。
- **自动校验流程（管线）**：`scene_template.py`（固定基底 + 四季变量）→ `scene_batch_gen.py`（Backend 抽象：DryRun / ComfyUI / A1111 + Emit 队列供串行下发；清单驱动 + 断点续跑）→ `scene_validate.py`（质检）→ `scene_collate.py`（4 合 1 预览 + `scene_godot_config.json`）。管线目录：`美术资源/scene_pipeline/`。
- **资产命名与路径**：`home_bg_{season}.png`（season ∈ {spring, summer, autumn, winter}）；默认 `home_bg.png` = 春覆盖以保既有引用路径有效；游戏按季节 `load("res://art/backgrounds/home_bg_%s.png" % season)` 切换。

#### 3.1.2 恢宏仙山构图准则（v1.2 新增，固化进 scene_template.py 构图锁）

> 针对 v1.1 四季图「恢宏感缺失 / 仙气不足 / 麒麟抢 C 位」三类问题，把构图基线从「建筑占山头」改为「大山托宗门」，全部约束写入 `scene_template.py` 的 `BASE_CONFIG.layout_lock` 与 `SEASONS`，由同一套校验体系（含 0.304 亮度栅）保障不漂移。

**1. 山体与建筑比例（量化）**
- 巨型通天主峰连绵群山占画面垂直高度 **70% 以上**，山体面积 > 建筑总面积。
- 建筑群集中在画面中下部（垂直 1/2 ~ 2/3），建筑群总高 **≤ 主峰高度的 1/3**，确立「山为基底、宗门依山而建」的恢宏感。
- 主殿居中最高，两侧配殿/钟鼓楼逐级降低、向山体两侧错落延伸（避免整排齐平死板）；2-3 层错落云台 + 多重蜿蜒石阶向山体两侧延展，替代单一直梯，强化纵深递进仪式感。

**2. 空间纵深**
- 远景 2-3 层渐隐远山，由云海穿插分隔，形成「近山-中山-远山」三层景深。
- 山体两侧延展悬空回廊、飞索桥、半山偏殿，打破「中间一堆建筑、两边空山体」的对称单调。

**3. 三层云雾体系（硬性关键词锁死）**
山巅流云瀑 / 山腰绵延缠云海 / 檐角绕薄烟；云雾半透明穿过亭台立柱，部分山峰隐于云海之上，远处群山在云雾中若隐若现。中心 UI 区域云雾浓度 ≤30%，不遮挡面板文字。

**4. 仙侠元素标准化（按季微调）**
- 通用：远处零星浮空仙岛、崖壁垂落灵藤、浮空飞桥。
- 春：漫天灵花、柔和瑞霭；夏：流云飞瀑、山间灵光；秋：霞光瑞气、漫山红叶配缥缈云气；冬：星河垂落、檐角灵灯柔光、月华漫云海。

**5. 光影氛围（修真灵性柔光）**
柔和体积光 + 漫射天光 + 大气景深；避免高对比硬阴影；远景群山连绵。动态云雾/飞萤/飘雪/落叶交由 Godot 粒子层叠加，不污染底图（动静分离原则不变）。

**6. 麒麟雕像尺度优化（改动最小、见效最快）**
位置：从前景平台正中央 → 第一层山门台阶左右两侧成对布置（传统守门瑞兽）。尺度：单只高度 ≤ 台阶总宽 1/6，远低于主殿正门；青铜做旧风化质感、无高亮反光、无发光特效，仅作建筑附属装饰，不抢主殿视觉重心。

### 5.3 格式化函数需求

```gdscript
# 建议在 ui_theme.gd 或新建 ui_format.gd 中添加：
static func format_resource(value: int) -> String:
    """资源数值格式化：>=10000 显示 X.X 万，否则显示整数"""
    if value >= 10000:
        var wan := value / 10000.0
        return "%g万" % stepify(wan, 0.1)  # 8.2万, 12.5万, 3.2万
    return str(value)

# 示例：
# format_resource(82000) → "8.2万"
# format_resource(125000) → "12.5万"
# format_resource(8600) → "8600"
# format_resource(3400) → "3400"
# format_resource(32000) → "3.2万"
```
