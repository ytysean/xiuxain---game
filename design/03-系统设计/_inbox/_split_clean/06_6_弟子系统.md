#### 初始宗主设定 · 开局掌门特殊天赋（v2.33 新增，纯增量）

> 落点说明：本小节描述「开局掌门（玩家化身）」入宗时的特殊生成属性，属 6.1 弟子生成规则的特例分支；掌门入宗后的持续机制（寿命 / 升品 / 化身 / 突破等）统一归属 **11.8 掌门体系**，本节仅定义开局初始态，不做重复定义，避免同一规则两处书写。

**设计原则**：① 特殊但不超模——个人战力绝不碾压全体弟子，避免弟子养成失去意义；② 侧重宗门增益——特殊性主要体现在全局气运 / 宗门 buff，贴合「一宗之主」定位；③ 兼容现有体系——所有天赋均在 §6.2 灵根 / §6.4 资质七档 / §6.9 道心框架内，可正常参与所有养成、战斗、悟道系统。

**专属灵根 · 先天道种灵根（掌门专属，不在常规灵根类型随机池内）**：
- 基础形态：初始为五行均衡灵根，外观近似杂灵根，实则先天道蕴加身、无属性功法排斥；**基准修炼速度对齐普通单灵根标准 1.0×（见 §6.2 灵根系数表，非杂灵根 0.8× 衰减），不继承杂灵根的速度惩罚**；
- 核心特性：修炼任意五行属性功法均无惩罚，且享受 **参悟速度 +10% [PLACEHOLDER]**（在单灵根 1.0× 基准上额外叠加，而非在杂灵根 0.8× 上「豁免惩罚」）；每突破一个大境界（筑基 / 金丹 / 元婴…）灵根纯度自动提升一阶，**进化仅提升属性适配性与参悟加成，修炼速度上限不超过天灵根 1.2×（见 §6.2），最终可进化至「混沌道根」但不超模**；
- 全局微增益：自身存在微量提升宗门全局灵气浓度 **+2% [PLACEHOLDER]**（计入灵气浓度体系，不破 4.1 红线），带动全体弟子修炼提速；
- 视觉：灵根标识为五色流转特殊光效，突破后光效逐步升级（对齐 15.4 赛博国风）。

**专属资质 · 圣骨凡胎（对齐 §6.4 资质七档命名）**：
- 初始档位：初始资质为 **天才上阶**（保底优秀，对齐 §6.4 七档：天才），保证前期宗主有足够战力带队；

- 平衡说明：后期上限等同于旷世弟子，非独一档，玩家仍有动力招募培养其他顶级弟子。

**专属命格 · 宗主道韵（替代普通弟子初始性格，见 §6.6）**：
- 个人效果：突破成功率 **+3% [PLACEHOLDER]**，道心稳固、心魔影响 **-5% [PLACEHOLDER]**；

**专属初始设定**：

**平衡约束**：掌门个人战力始终处于第一梯队但非无敌，后期圣 / 仙品弟子可完全追平甚至超越；所有全局增益均为微量加成、总和不超过 5%，严格计入全局乘区（4.1）；所有养成规则与普通弟子完全一致（装备 / 功法 / 悟道 / 化身等系统全部通用），仅初始天赋有差异，无特殊特权。

#### 6.1.1 职业维度平衡约束（反向约束·风险对等，v2.23 新增）
为对冲强势职业强度、避免单一职业最优解，补充职业维度的反向约束（仅追加负面系数，不改动本小节基础成长数值）：
- 高输出职业（法修）：修炼资源消耗更高 [PLACEHOLDER]、突破风险 / 心魔波动更大；
- 高生存职业（体修）：成长节奏更慢 [PLACEHOLDER]、资源消耗低但战力上限相对受限；
- 道修：综合均衡，无额外增益亦无额外惩罚，作为基准参照。
- **阵容单一堆叠惩罚（风险对等，v2.28 补全）**：宗门出战 / 常驻阵容全员单一职业（或全员同属性灵根）时追加反向 debuff，倒逼多元搭配：
  - 全法修阵容：宗门战防守承伤 +15% [PLACEHOLDER]；
  - 全体修阵容：整体修炼速度 -10% [PLACEHOLDER]；
  - 全道修阵容：整体输出 -12% [PLACEHOLDER]；
  - 全员同属性灵根（纯度维度）：被克制属性敌人伤害 +20% [PLACEHOLDER]；
  - 所有惩罚仅追加负面系数，不改动职业 / 灵根基础成长数值，计入对应乘区、不突破 25% 软上限（4.1）。
原则：收益与风险对等，替代单纯强弱划分；所有系数计入对应乘区、不突破 25% 软上限（4.1）。

#### 6.1.3 新招募弟子初始数值生成规则（v2.33 新增，纯增量）

> 命名对齐：本小节资质档位划分与命名，完全对齐 §6.4 弟子资质七档体系（凡俗 / 平庸 / 优良 / 天才 / 妖孽 / 旷世 / 道胎），系数与倍率基于原有体系增量设计；灵根类型对齐 §6.2，性格对齐 §6.6。

**核心原则**：以「灵根类型 + 资质档位 + 职业方向 + 初始年龄」为核心生成维度，所有初始值为成长基底，严格对齐全局境界、属性、数值红线体系（4.1），上下限可控，不破坏现有平衡。

**一、初始基础设定**
- **初始境界**：经「常规渠道」（招贤阁普通刷新，详见 6.1.6）入宗的弟子统一为 **炼气初期**（= 炼气一层，全局境界体系最低起点，无跳档）；凡俗渠道需先经引气入体（6.1.4），带艺渠道按对应境界（6.1.6）。
- **初始年龄**：少年期（对齐 §6.10 年龄分段视觉迭代体系，具体区间 [PLACEHOLDER]，建议 16–24），对应少年期立绘与初始传记。
- **初始状态**：道心饱满、无心魔、无丹毒、无装备、无习得功法，仅携带基础修行资质与天生禀赋。

**二、核心属性生成基底（指针 → 6.1.5）**
新招募弟子的全部初始属性，由 6.1.5「弟子初始属性通用规则」的通用公式与各维度修正系数表生成；本小节仅界定入宗瞬间的初始状态（炼气初期 / 少年期 / 道心饱满无负面），不重复书写属性基底与系数，避免同一规则多处维护。

**三、属性锁定与可变规则**
- **永久固定（生成后不可更改）**：基础人文属性（姓名 / 性别 / 性格，见 §6.6）；天赋禀赋（灵根类型、资质档位，见 §6.2 / §6.4）；职业方向初始固定，高阶版本可通过转职玩法变更（6.15.2），不属初始生成范畴。
- **动态可变（初始为基底，后续成长叠加）**：所有战斗属性、境界等级；头像 / 立绘 / 传记（见 6.20）；装备 / 功法 / 羁绊 / 道心等后天养成内容（见 6.9 / 6.11 / 6.17）。

**四、数值平衡兜底（对齐 4.1 红线）**
- 初始最高与最低总属性差距控制在 2 倍以内（凡俗 0.9 × 杂灵根 0.95 ≈ 0.855 下限，道胎 1.8 × 变异 1.1 ≈ 1.98 上限），核心差距体现在后续成长倍率，避免低资质弟子完全无用；
- 所有初始属性均属于基础属性池，不计入全局增益乘区；后续功法 / 装备 / buff 等增益在此基础上叠加，严格遵守 4.1 的 25% 软上限；
- 性格、灵根带来的修正均为微量调整，核心潜力差距由资质档位决定，符合玩家对「资质决定修仙上限」的题材认知。

- 资质简化为三档：普通（凡俗 / 平庸合并）、优秀（优良 / 天才合并）、顶级（妖孽 / 旷世 / 道胎合并），合并对应系数，减少配置表工作量；

#### 6.1.4 引气入体前置修行（v2.33 新增，纯增量前置设计）

> 命名对齐：本小节资质档位划分与命名，完全对齐 §6.4 弟子资质七档体系；仅作用于「凡俗渠道」新弟子（见 6.1.6），炼气一层及以上的所有原有境界、属性、修炼、战斗规则 100% 保留不动。

**一、设计价值与核心定位**
完全贴合正统修真世界观：凡人入宗并非直接就是修士，需先修习宗门基础功法、感应灵气、引气入体，才算踏入仙途。既强化「宗门传道授业」经营代入感，也增加招募筛选策略性与随机性，让灵根 / 资质 / 性格差异从入宗第一天就体现。
- 定位：凡俗渠道新弟子入宗后的前置过渡阶段，纯增量内容，所有规则仅作用于「凡俗 → 炼气一层」区间；
- 兜底：引气成功后无缝接入原有炼气期体系，后续所有修炼 / 突破 / 战斗规则一字不改。

**二、新弟子初始状态（凡俗渠道入宗瞬间）**
所有经凡俗渠道（杂役处招募 / 凡俗村镇收录 / 流民收留，见 6.1.6）获取的新弟子，初始均为凡俗无修为状态：
- 境界：无修为（凡俗身），不属于任何修行境界；
- 属性：凡人级基础属性，约为炼气一层基准值的 40% [PLACEHOLDER]，无灵力修行属性；
- 状态：未习得任何功法，默认自动进入「引气修行」状态；
- 视觉：对应少年期凡俗服饰立绘，无修行光效，区别于正式修士。

**三、引气入体核心玩法规则**
**1. 基础流程**：弟子入宗后自动修习宗门统一配发的《基础引气诀》，开始感应灵气；达到引气条件且判定成功后正式晋升炼气一层，成为正式修士，解锁全部养成 / 战斗功能。修行全程自动、无需手动操作，符合放置类核心体验；玩家可通过赐药 / 安排灵脉岗位 / 专人指导等方式干预，提升效率与成功率。

**3. 成功率与风险机制**（非 100% 成功，贴合「有人终其一生无法踏足仙途」）
- **顺利引气（大概率）**：正常耗时结束后判定成功，直接晋升炼气一层，属性对齐原有炼气初期基准值（6.1.5），解锁全部功能；
- **引气受挫（小概率）**：判定失败，弟子受轻微灵气反噬，需休养 5–10 天 [PLACEHOLDER] 才能重新开始引气；**休养期规则**：仅可使用养气类丹药缩短休养时长，灵脉加持 / 长老指导等修行类 buff 不生效；弟子进入「调息」状态，期间不可安排岗位、不可出战，休养结束后自动恢复引气修行；灵根越好 / 资质越高失败概率越低，性格激进（锐意 / 桀骜 / 狂傲）失败概率显著提升；
- **仙路断绝（极低概率）**：仅杂灵根 + 凡俗 / 平庸低资质弟子有概率触发，判定后终生无法引气入体；可安排为宗门杂役弟子或直接遣散出宗，规则如下（归入记名弟子体系，详见 6.12 / 11.1.1）：① **编制独立**——不占用正式弟子编制上限，单独计入记名 / 杂役名额；② **岗位受限**——仅可安排在灵田 / 矿场等后勤岗位，提供 **5%（初版建议值，上线前实测校准）** 岗位产出加成，无战斗 / 修炼 / 突破功能；③ **无养成成本**——不消耗宗门俸禄资源，仅维持基础生计，无额外养成投入；概率上限 **≤5%**（初版建议值，上线前实测校准），仅作用于最低档弟子，不出现招募到好资质却无法修行的恶劣体验。

**4. 玩家可干预手段**（强化经营参与感）
- 赐药：消耗低阶丹药，直接缩短引气耗时 20% [PLACEHOLDER]，同时降低失败率；
- 灵脉加持：将弟子安排在主灵脉周边岗位，享受灵气加成，提速 10%–20% [PLACEHOLDER]（联动 §11.3）；

**四、与现有体系无缝衔接**
引气入体成功瞬间，弟子数据完全对齐原有炼气一层标准：属性 / 成长倍率 / 修炼速度全部复用原有炼气初期规则（6.1.5）；自动解锁功法学习 / 装备穿戴 / 历练出战等全部功能；后续境界突破 / 职业专精 / 悟道定型体系完全不变，零适配成本。

**五、数值平衡兜底**
- 该机制仅延长弟子「上岗周期」，不改变任何最终属性 / 成长倍率 / 战力上限，不触碰全局数值红线（4.1）；

**七、属性数值同源复用逻辑（零新增规则）**

核心原则：不新建任何独立数值模板，100% 复用现有境界体系与修正公式——高阶弟子本质是「直接生成一个正常培养到对应境界的普通弟子」，底层逻辑与玩家手动培养完全一致。

- **基础属性**：生成时按初始境界（筑基初期 / 筑基中期 / 金丹初期等）直接读取原有体系该境界标准属性基准值（气血 / 灵力 / 攻击 / 防御 / 灵力速度 / 悟性），与玩家通过正常修炼升到该境界的弟子基准值完全相等，无任何额外加成。例：生成一名筑基初期弟子，基础属性 = 炼气初期基准值 × 筑基境界成长倍率（公式与原有体系一致）。
- **修正系数**：资质档位（§6.4 七档映射系数）、灵根类型（§6.2）、职业方向（§6.2）、性格特质（§6.6）四项修正系数 100% 沿用 6.1.5 初始生成修正表，计算逻辑完全不变，仅基准值替换为对应高阶境界数值。
- **通用公式**：`最终属性 = 对应境界基准值 × 资质系数 × 灵根系数 × 职业系数 × 性格系数`（与炼气初期弟子完全同源，无第二套算法）。
- **衍生属性**：修炼速度、突破概率、悟道效率、寿元上限等全部复用同境界同资质弟子通用规则，无特殊优待、无独立乘区；入宗后升级 / 突破 / 养成所有逻辑与同境界普通弟子一致，不出现「起步快、成长也快」的叠加优势。
- **配套内容复用现有物品库**：初始自带装备 = 现有物品库「对应境界凡 / 灵品基础装备」，无专属高阶装备；初始自带功法 = 现有功法库「对应境界基础通用功法」，无稀有 / 专属功法；不破坏装备、功法产出节奏（详见 二·3）。

**八、开关式兜底与可回退（零代码改动·一键启停）**

通过配置化管控、统一接口处理、存量数据兼容设计，实现「一键启用 / 关闭」，关闭后自动回落原有规则，无兼容问题，严格符合纯增量可回退约定。

- **配置层·两级开关**：① 全局总开关 `enable_high_level_recruit`（布尔型，总闸）置于全局玩法配置表，开启时全渠道规则生效、关闭时自动回落炼气初期通用规则；② 分渠道独立开关（奇遇 / 宗门大比 / 策反 / 特殊事件），可单独启用关闭，支持灰度测试、逐步上线，风险粒度可控。全部为配置表字段，运营后台可直调，无需改代码。
- **逻辑层·统一接口**：所有渠道弟子生成统一调用同一个「弟子生成接口」，开关逻辑在接口底层统一处理；关闭高阶规则后，接口自动将奖励池替换为原有炼气初期通用弟子池，奖励概率 / 数量完全对齐原有设定，上游奇遇 / 大比等玩法无需修改、无感知、无报错。
- **数据层·存量兼容**：开关关闭前已生成的高阶弟子数据完整保留，不做删除、不强制降级，避免玩家损失；仅关闭后续新产出，不影响已有存档，向前兼容、向后可停；高阶弟子数据结构与普通弟子完全一致，无专属字段，无残留异常数据。
- **入口与奖励自动适配（v2.38 补充）**：关闭总开关时，凡俗渠道招募入口自动隐藏（非仅禁用，避免空入口困惑），高阶渠道（奇遇 / 大比 / 策反）奖励自动回落为常规炼气初期弟子奖励，上游玩法零配置改动、无感知；与数据层存量兼容配合，关闭态下玩家侧表现与原始版本完全一致。
- **落地节奏**：MVP 验证阶段默认关闭总开关，核心玩法完全沿用原有规则，不占用开发资源、不影响闭环验证；核心体系稳定后先开单渠道灰度，验证平衡再逐步放开。

**九、获取难度与实力平衡深化设计**

遵循「境界越高、概率越低、代价越大、上限锁死」四维平衡法则，让高阶弟子成为「节省时间的惊喜奖励」而非「破坏平衡的碾压外挂」。

- **阶段化解锁（新手期零投放）**：宗门品级未达 **灵品**（§11.1 宗门品级）前，所有渠道零投放筑基及以上高阶弟子；达到后按品级梯度逐步放开——**灵品**解锁筑基期高阶弟子、**王品**解锁金丹期高阶弟子、**真品**（小概率）解锁元婴期高阶弟子（初版建议值，原稿用资质名「优良 / 妖孽 / 旷世」，已按 §11.1 宗门品级映射为 灵品 / 王品 / 真品，上线前实测校准），与玩家养成进度强绑定。
- **动态概率调控**：① 战力匹配系数——玩家当前宗门战力越低，高阶弟子产出概率小幅提升；越高则小幅降低，自动平滑运气差异，避免欧皇前期碾压、非酋长期无获；② 数量抑制系数——玩家拥有高阶弟子越多，后续产出概率越低，达周 / 月上限后概率归零，防高阶弟子泛滥。
- **多维度代价体系（收益与成本严格对等）**：① 忠诚度惩罚——筑基弟子初始忠诚度 −20%、金丹弟子 −35%（初版建议值，上线前实测校准），入宗初期道心动摇 / 叛逃概率显著提升（见 6.13.4），需投入资源培养信任；② 磨合成本——入宗前 30 游戏年（境界 ≥ 金丹时延长至 50 游戏年）修炼效率 −10%、宗门贡献获取 −10%（初版建议值，上线前实测校准），对应「适应宗门功法体系」设定，境界越高磨合期越长；**磨合惩罚为独立乘区（磨合系数 = 0.9）**，不采用加减法叠加——`最终修炼效率 = 基础效率 × 资质系数 × 灵根系数 × 宗门灵气系数 × 磨合系数`，所有增益 / 惩罚均连乘、互不稀释不溢出，严格对齐 §4.1 全局乘区规则；③ 资源成本——入宗需消耗对应宗门贡献 / 灵石安置，境界越高成本越高（数值 [PLACEHOLDER]，上线前实测校准）；④ 岗位限制——入宗初期无法担任核心管理岗位，需忠诚度达标后方可任职（对齐 6.12 任职），避免直接影响核心经营节奏。
- **成长限速（起步有优势、后期无差别）**：高阶弟子仅节省前期培养时间，最终成长上限 / 属性天花板 / 悟道上限与同资质同灵根普通弟子完全一致（详见 二·4「无成长优势」），初始自带装备功法均为同境界基础款，高阶稀有内容仍需长线获取，不跳过核心养成循环。
- **双向兜底（抹平极端运气差异）**：① 非酋保底——连续多次触发对应事件未获高阶弟子时，逐步提升产出概率并设保底次数 [PLACEHOLDER]，保障长线产出稳定；② 欧皇封顶——单玩家周产出上限（筑基 ≤2 名 / 周）、月产出上限（金丹 ≤1 名 / 月）（初版建议值，上线前实测校准），**额度按弟子「获取次数」统计，遣散高阶弟子不释放已占额度，杜绝「刷取—遣散」反复套取；周 / 月额度随自然周 / 月重置**，杜绝极端运气造成的阶层断层；③ 全服宏观调控——全服高阶弟子总产出设上限 [PLACEHOLDER]，随服务器进度逐步放开，避免整体节奏失控。
- **成本对标校验（锚定正常养成线）**：所有高阶渠道获取难度 / 资源消耗，均以「玩家从零培养一名同境界同资质弟子的平均时间 + 平均资源消耗」为基准线——被动获取渠道（奇遇 / 奖励）价值略低于基准线，作惊喜补充；主动获取渠道（策反 / 特殊招募）成本略高于基准线，仅作节省时间的选择，不会替代正常养成的核心地位。

**十、高阶渠道与原有规则的边界隔离方式（四维隔离法）**

采用「文档 / 逻辑 / 数据 / 入口」四维隔离，实现两套规则完全解耦、互不侵入，从根源杜绝冲突（与 六 无冲突保障互为表里：六 述原则、本節述结构与落点）。

- **文档边界：单点收拢，只引不改**
  - 规则唯一落点：所有高阶渠道规则完整收拢于本小节（6.1.6），开头已标注适用范围；原有 §6.1、§6.10、§11.6 等章节正文 / 编号 / 交叉引用一字不动，不做任何修改与补充。
  - 交叉引用不复制：奇遇（§10）、宗门大比（6.18.9）、策反（6.13.4）等关联模块，仅添加 1 句指向性说明「高阶弟子奖励规则详见 6.1.6」，不复述、不改写具体规则，彻底避免「同一规则多处书写、后续更新不同步」的维护隐患（v2.33 已实装三处交叉引用）。
  - 边界声明前置：本小节开头第一句即划清适用范围，区分通用规则与补充规则，无二义性。
- **逻辑边界：单节点介入，下游完全复用**
  - 唯一介入点：仅在「弟子生成接口」入口处做渠道分流判定，高阶渠道走专属生成逻辑；生成完成后，下游修炼 / 突破 / 战斗 / 任职等所有系统完全复用原有通用逻辑，无任何针对高阶弟子的特殊判定分支。
  - 无下游依赖：高阶弟子生成后与同境界普通弟子在逻辑层面完全等价，所有系统一视同仁；即使移除高阶渠道模块，下游玩法亦不报错、不缺失。
  - 黑盒式封装：高阶渠道逻辑独立封装为单独模块，对外仅暴露「生成高阶弟子」单一接口，内部规则迭代不影响外部系统。
- **数据边界：复用原生模板，无独立字段**
  - 数值完全同源：属性 / 成长倍率 / 突破概率等所有数值，直接读取对应境界通用模板，不新建独立数值公式、不新增属性维度（详见 七 属性数值同源复用逻辑）。
  - 存储结构统一：高阶弟子与普通弟子共用同一张数据表、同一套字段，无任何专属扩展字段；模块关闭或移除后，已生成弟子数据依然正常可用，无残留异常字段。
  - 配置独立成表：高阶渠道的概率 / 惩罚 / 产出上限等参数，单独存入一张配置表，不混入原有招募配置，修改时不会误触通用规则。
- **入口边界：渠道严格分流，互不交叉**
  - 主渠道完全隔离：招贤阁常规招募 / 基础弟子生成 100% 沿用原有炼气初期规则，全程不触碰高阶逻辑，保证核心招募体验稳定性。
  - 高阶仅走奖励池：高阶弟子仅作为奖励项，挂载于奇遇 / 宗门大比 / 策反等特殊玩法奖励池，属补充获取途径，不侵入主招募流程。
  - 玩家感知分层：玩家认知中是「特殊机缘获得高阶修士」而非招募体系常规产出，世界观与玩法逻辑双重自洽。

**十一、高阶渠道规则的完整性与可维护性保障**

通过单一数据源 / 模块化封装 / 分层校验 / 体系对齐四项机制，兼顾规则完整度与长期维护效率，避免版本迭代混乱。

- **单一数据源原则（规则唯一出口）**：全文档仅本小节（6.1.6）一处存放完整规则，所有关联模块均通过交叉引用指向此处，杜绝多版本规则并存；规则修改 / 数值调整仅在本小节执行，自动同步所有引用场景，不会出现「改了一处、另一处忘了更新」的维护事故；配套配置表仅一份，所有渠道共用同一套参数逻辑，避免多表配置不一致。
- **模块化封装（配置驱动，逻辑解耦）**：所有概率 / 系数 / 惩罚值 / 产出上限全部写入独立配置表，不硬编码在逻辑中，数值调整无需改代码，运营可直接后台配置；功能模块按「入口分流 → 属性生成 → 配套内容 → 平衡约束」分层封装，每层职责清晰，修改某一层不影响其他层；对外接口与原有弟子生成接口参数完全兼容，替换与回退零成本。
- **分层校验机制（防冲突 / 防遗漏 / 防超模）**：① 新增前校验清单——每次补充规则前对照检查：是否修改了原有章节 / 是否新增了独立属性 / 是否突破全局数值红线（4.1）/ 是否与现有体系命名对齐，命中任意一项则调整方案；② 上线前回归校验——开关开启 / 关闭两种状态下，原有核心玩法必须全部正常运行，关闭状态下产出 / 概率与原版本完全一致，确保兜底有效（详见 八 开关式兜底）；③ 版本迭代适配校验——原有境界 / 资质 / 招募规则更新时，高阶模块自动承接新的通用模板，无需单独重写数值，保证长期同步不脱节。
- **命名与体系对齐（降低理解 / 维护成本）**：境界 / 资质 / 属性 / 职业所有命名 100% 对齐文档官方体系（如资质用凡俗 / 平庸 / 优良七档，见 §6.4），不自定义命名，降低团队沟通与理解成本；系数梯度 / 成长逻辑承接原有数值节奏，不新建独立维度，策划无需额外记忆第二套规则；文档结构与原招募章节保持一致，按「定位 → 规则 → 数值 → 平衡 → 落地」排布，查阅与维护效率最高。

**十二、纯增量设计对游戏开发与运营的具体优势**

本模块作为纯增量设计的典型范例，其架构选择为开发与运营两端均带来可量化的风险降低与效率提升。

- **开发端优势**
  - 核心进度零延误，不阻塞主流程：不修改原有代码 / 配置 / 文档结构，不打断核心玩法开发节奏；新增功能可后置并行开发，优先保证 MVP 核心闭环验证（见 八 落地节奏适配 MVP 默认关闭），不会因追加新功能拖慢整体上线节点。
  - 风险可控，试错成本极低：新功能独立封装，出问题只影响自身模块，不会引发「改老功能引出连锁 bug」的大面积返工；可随时暂停 / 砍掉 / 回退新功能，不浪费已有开发资产。
  - 并行效率高，排期灵活：核心团队攻坚主玩法，增量模块可分配给单独人员并行开发，互不阻塞；版本排期可灵活插入或移除新功能，不打乱整体开发计划。
  - 调试成本低，回归测试快：原有功能无需重复回归测试，仅需验证新增模块本身；开关回退机制可快速定位问题来源，排查效率远高于侵入式修改。
- **运营端优势**
  - 灰度上线，平滑验证平衡：支持分渠道 / 分玩家群体逐步开放新功能，不用全服一刀切；可先小范围测试数据与玩家反馈，调整平衡后再全量推送，大幅降低新功能对生态的冲击。
  - 一键回退，故障秒级恢复：出现平衡问题 / 线上 bug 时，直接关闭配置开关即可秒级恢复原有规则，无需停服更新、无需回档，玩家体验几乎无感知，大幅降低线上事故处理成本与负面影响。
  - 版本兼容，数据零风险：新旧版本数据完全兼容，更新不丢档、不报错；老版本客户端也能正常运行，不出现版本迭代推翻存档的情况；长线追加内容风险极低。
  - 运营策略灵活度高：可根据节日活动 / 版本节点临时调整产出概率，配合运营活动；不同服务器可配置不同开关参数，适配不同服生态节奏；增量模块可作为小版本更新点，持续为长线运营提供内容支撑。

- **潜在体验风险（可控）**：① 新手卡顿——引气机制若默认开启，杂灵根弟子长时间无法入体可能导致前期正反馈不足；MVP 默认关闭、后续作为「宗门品级解锁」进阶玩法解锁，有效规避。② 高阶弟子惩罚体感——忠诚度 −20%~−35%、磨合 −10% 若把控失当可能让玩家觉得「高阶弟子没用」；当前幅度属可控范围，实测据反馈微调（见 九）。
- **数值平衡合理性（优秀，风险极低）**：① 长线一致——所有渠道弟子最终成长上限一致，仅起步节奏不同，不破坏付费体系；② 总量可控——产出上限 / 阶段解锁 / 概率梯度有效控制投放节奏，无前期膨胀、后期崩盘；③ 乘区规范——所有增益 / 惩罚均为独立乘区，与 §4.1 全局体系对齐，无数值溢出隐患，调优成本低。
- **工程与运营可行性（极佳）**：纯增量设计 / 单一数据源 / 开关式兜底大幅降低开发与风险成本，可并行开发、灰度上线、秒级回退，技术债务低（详见 十二）。
- **后续优化方向**：① 体验分层——引气入体 / 高阶渠道均做成「宗门品级解锁」进阶玩法，新手期仅保留常规招募；② 反馈强化——引气成功 / 高阶弟子投奔增加专属弹窗与演出，放大惊喜感；③ 玩法延伸——基于杂役弟子 / 带艺拜师延伸「弟子历练回归」「宗门收徒剧情」等内容；④ 数据验证——MVP 阶段重点监控引气成功率 / 高阶弟子产出率 / 玩家培养偏好三项数据，上线后据实微调系数。

**6.10.1.6 突破寿元严谨公式（v2.18 新增，无 bug 版）**
严格遵循「年龄永久增长、突破刷新寿元上限」逻辑，不出现年龄重置 / 寿元计算错误。

```
当前年龄   = 初始年龄 + 已流逝游戏时间
剩余寿元   = 当前境界寿元上限 − 当前年龄
突破大境界后：寿元上限更新为新境界满值，年龄保持不变
```

示例校验：一名 50 岁练气弟子，寿元上限 60 年、剩余 10 年；成功突破筑基后，寿元上限刷新为 120 年、当前年龄仍为 50 岁，剩余寿元 = 120 − 50 = 70 年。
- **边界兜底（v2.20，防负寿元异常死亡）**：若突破后「当前年龄 ≥ 新境界寿元上限」，剩余寿元不直接取负值、不触发异常死亡，强制设为 **10 年** 并触发「寿元垂危」预警（界面红字提示，可立即延寿 / 闭关挽回）；高龄低境界弟子（如 150 岁练气）突破筑基（上限 120）即落入此分支，剩余寿元 = 10 年，避免公式算出负数导致逻辑崩坏。
平衡逻辑：低境界弟子长期卡突破会自然寿尽迭代（消耗定位）；核心弟子突破速度远快于年龄增长，寿元越活越长，正常培养几乎不自然死亡，仅做世界观沉浸。

#### 6.10.2 分层迭代逻辑（从根源避免宗门崩盘）
核心思路：消耗基层、稳定中坚、传承顶层；寿元消耗主要发生在低价值基层弟子身上，核心主力极难自然寿尽，从结构上保证宗门运转永不停止。

**三层弟子消耗定位**

| 弟子层级 | 境界 / 资质 | 寿元特点 | 死亡影响 | 补充难度 | 消耗占比 |
| --- | --- | --- | --- | --- | --- |
| 基层执行层 | 练气～筑基 / 平庸～优良 | 寿元短，迭代快 | 仅影响灵田、杂役等基础产出，可随时替代 | 极低（下山招募、山门访客批量补充） | 90%（主要消耗对象） |
| 中坚主力层 | 金丹～元婴 / 天才～妖孽 | 寿元长，延寿手段充足 | 影响战斗主力、核心岗位，有短期损失 | 中等（招贤阁定向筛选补充） | 9%（少量自然迭代） |
| 顶层传承层 | 化神及以上 | 寿元极长，近乎常驻 | 寿尽后留下顶级传承，反而是长线收益 | 极低（靠奇遇、高阶培养获得） | 1%（长线传承节点） |

**数值平衡校验（产出永远略高于消耗）**
以宝品宗门、50 名弟子基准阵容测算：
- 年均自然死亡人数：练气 30 人 ×(1/60) + 筑基 15 人 ×(1/120) + 金丹 5 人 ×(1/300) ≈ 0.64 人 / 年；
- 年均招募产出（山门 + 招贤阁 + 下山测灵）：年均可收录 10~15 名弟子；
- 结论：产出速度是消耗速度的 15 倍以上，弟子总量稳中有升，绝对不会出现「越死越少」；寿命系统的作用是倒逼玩家筛选优质、淘汰低质，而非削减总量；
- 注：上述基准阵容（练气 30 / 筑基 15 / 金丹 5）为测算假设，实际按宗门名额与质量分布动态变化，[PLACEHOLDER] 待实测校准。

#### 6.10.3 玩家可控的延寿体系
给玩家充足主动操作空间，核心弟子寿元完全可通过正常玩法延续，不出现「辛苦培养完就寿尽」挫败感。
1. **突破境界（最高效）**：突破大境界直接刷新为对应境界满寿元，最核心、最贴合修仙设定的延寿方式；激励持续培养突破，而非依赖道具续命。
2. **延寿丹药（常规手段）**：丹堂产出延寿丹，分低 / 中 / 高三级，分别 +10 / +30 / +80 年寿元 [PLACEHOLDER]；每名弟子一生最多服用 3 颗，避免无限续命，保证寿元系统底层价值；复用丹堂系统，不新增独立养成线。
3. **机缘延寿（惊喜补充）**：秘境探索、珍稀奇遇、远古遗泽事件概率获得天材地宝，单次 +10~50 年寿元 [PLACEHOLDER]；稀有产出，长线惊喜，不做稳定产出。
4. **阵营与基建延寿（被动增益）**：
   - 正道声望崇敬及以上：全宗弟子寿元流逝 -10% [PLACEHOLDER]；
   - 道心值达标：弟子个人寿元流逝 -5%~15% [PLACEHOLDER]；
   - 灵脉 / 护山大阵等级：每级增加全宗 5 年基础寿元 [PLACEHOLDER]，最高 +50 年。

#### 6.10.4 寿尽传承机制（死亡不是纯损失，是宗门积累）
解决「弟子死亡挫败感」的核心设计：寿尽弟子不直接消失，而是转化为宗门传承资产，把沉没成本变成长线正向收益，贴合「宗门建设、世代传承」核心玩法。

**生效方式与平衡规则（分级生效、逐步解锁、边际衰减、全局封顶）**

- **两类增益定位**：① 全局宗门增益（全员生效，计入对应乘区，有全局硬上限）；② 个人传承增益（单弟子参悟后生效，仅加速成长、不提升最终数值天花板，不占全局额度）。
- **基础气运增益**：先贤入驻后自动生效，提供最低限度正向反馈。
- **高阶属性增益**：需每周在藏经阁「参悟先贤心得」逐步解锁，单次参悟推进 10% 进度，满进度后全额生效；避免「弟子一死立刻加战力」的割裂感，同时控制增益生效速度。
- **叠加规则（边际乘算衰减）**：同类型增益采用边际乘算衰减，公式与防御属性叠加逻辑一致——
  `最终增益 = 1 - (1 - 先贤A增益) × (1 - 先贤B增益) × (1 - 先贤C增益) × ...`
  越往后新增的先贤收益越低，理论上永远趋近但绝不突破硬上限。
- **全局硬上限**：先贤堂常驻通用增益最高合计 **5%**（v2.17 定案），叠加掌门（嵌入大阵 / 聚灵）、装备灵兽大阵后总和强制卡 25% 软上限、30% 硬上限（溢出 20% 衰减，详见 4.1 / 11.8.3）；修炼速度、熟练度加成合计最高不超过 10%，仅加速成长、不提升最终数值天花板。
- **边际衰减兜底**：同职业、同类型先贤入驻超过 5 位后，新增增益按 50% 折算生效；超过 10 位后按 20% 折算；达到全局硬上限后，再入驻先贤仅解锁生平传记、提升先贤堂评分，不再提供任何数值收益，彻底锁死膨胀空间。

**个人传承增益（仅降培养成本，不提最终强度）**
- 每名弟子可选择 1 位对应职业先贤进行「专属参悟」，同时只能参悟 1 位，参悟持续 7 游戏日，完成后永久生效。
- 增益内容：初始修为起点提升 15%~25% [PLACEHOLDER]、对应功法熟练度初始等级 +1；核心约束：仅加速成长，不提升最终属性与境界天花板。
- 每名弟子最多从传承中获得 25% 初始修为加成，无叠加空间。

**临时增益补充（不占用常驻额度）**
- 节日祭典、祖师供奉可消耗声望 / 灵材触发临时增益，持续 1 游戏日；效果为常驻增益的 2 倍，冷却每 7 游戏日 1 次；归入临时战斗乘区，不占用常驻通用增益额度，属短期爆发手段。

**沉浸价值**：保留每位弟子完整生平履历（突破记录、战功、奇遇经历），形成宗门史记；节日、祭典可在祖师堂供奉，获得临时 buff，强化宗门传承题材感。

**设计价值**：玩家培养弟子的投入不会完全沉没，只是从「现役战力」转化为「宗门底蕴」；宗门越强、历史越久，传承加成越多，形成正向循环，强化「百年宗门」沉浸感；彻底避免「弟子死了 = 白养了」负面体感。

#### 6.10.5 多重兜底机制（游戏永远不会崩盘）
1. **全周期预警**：寿元不足 50 年黄色标识弱提示；不足 20 年红色标识 + 主界面角标；不足 10 年强提醒弹窗，标注剩余现实天数并给延寿建议。
2. **产出兜底**：宗门弟子数量低于当前品级最低阈值（凡品 5 人 / 灵品 10 人，复用 11.1.1 名额下限）时自动触发——山门访客刷新翻倍且必出可收录弟子、招贤阁免费刷新立即重置且优质概率提升，保证短时间补充基础人手。
3. **新手保护**：开局前 30 游戏年（现实 30 天，对齐「现实 1 天 = 游戏 1 年」），所有弟子寿元流逝减半且不触发自然死亡；新手期内只做寿元展示，不执行死亡逻辑。
4. **回归保护**：玩家超过 7 天未登录，回归时离线期间所有弟子寿元暂停流逝（与 11.7 离线推进放置属性为「反惩罚例外」，不冲突），并赠送 3 名基础弟子 + 一批灵石，帮助快速恢复运转。
5. **最低人数锁死**：宗门弟子数量永远不会低于 5 人，极端情况保留核心弟子与入门弟子，绝对不出现「无弟子可玩」死局。

#### 6.10.6 掌门寿命特殊处理（详见 11.8.10 掌门体系）
玩家扮演的掌门绝对不会因为寿元耗尽导致游戏结束，符合宗门永续经营核心定位。
- **基础寿元**：掌门基础寿元为同境界弟子的 2 倍，且每提升 1 级宗门品级额外 +100 年「宗门气运寿元」[PLACEHOLDER]；正常节奏下掌门寿元远长于同境界弟子，几乎不会自然寿尽。
- **寿尽触发「宗门传承」而非游戏结束**：掌门真的寿元耗尽时，从宗门金丹及以上核心弟子中选择新任掌门；新任掌门继承原掌门 50% 修为、全局增益与道途倾向，保留所有建筑 / 资源 / 弟子；原掌门入驻祖师堂，成为历代祖师提供全宗永久加成（归入先贤传承体系，详见 11.8.10）；游戏正常继续，仅掌门身份更替。
- **意外兜底**：掌门永远不因重伤、走火入魔、战斗失败直接死亡，最多进入「重伤闭关」状态暂停全局增益，不会导致游戏崩盘。

#### 6.10.7 寿元系统与其他系统联动（非孤立机制，闭环复用现有逻辑）
寿元全程嵌入所有核心系统，形成「成长→延寿→消耗→传承」完整闭环，所有联动均复用现有逻辑，零底层重构。延寿手段总览亦见 6.10.3。

1. **与修炼突破系统联动**
   - 突破刷新寿元：弟子每突破大境界，寿元直接重置为新境界满值，是最高效延寿方式，激励推进核心成长线；
   - 强行突破折寿：突破瓶颈选择「强冲」成功率提升，但失败后折损 10~20 年寿元 [PLACEHOLDER]（与 6.10.1 折寿规则一致）；
   - 修为停滞加速衰老：长期卡境界、无突破的弟子，寿元流逝速度额外 +10% [PLACEHOLDER]，符合「不进则退」修仙逻辑。

2. **与丹堂 / 资源系统联动**
   - 延寿丹药体系：丹堂炼制低 / 中 / 高三级延寿丹，分别 +10 / +30 / +80 年寿元 [PLACEHOLDER]，每名弟子一生最多服用 3 颗（详见 6.10.3）；

   - 灵脉等级加成：宗门灵脉等级越高，全宗弟子寿元流逝越慢，最高减速 15% [PLACEHOLDER]（与 6.10.3 灵脉 +5 年 / 级互补，分别作用于流速与基础寿元）。

3. **与奇遇 / 秘境系统联动**
   - 延寿机缘：珍稀及以上奇遇概率触发「仙缘延寿」「灵泉洗礼」「上古传承」事件，直接加寿元或给延寿道具；

4. **与宗门战 / PVP 系统联动**
   - 重伤折寿：宗门战、秘境战败致弟子重伤，单次折损 3~5 年寿元 [PLACEHOLDER]；境界越低、道心越差折损越多；

#### 6.10.8 离线闭关与回归机制（v2.18 新增，对应新稿「五」）
玩家下线对应「掌门闭关」、上线对应「掌门出关」；离线期间宗门正常运转、回归有完整禀报与沉浸文案，同时保障离线放置体验。本机制与手动闭关悟道（11.8.7）**完全独立、不共享次数、不叠加生效**（v2.18 按 Q0 定案）。

**1. 离线被动闭关（放置保底福利，零成本）**
- 玩家退出游戏后自动触发「掌门闭关」叙事态，全宗弟子修炼速度额外 **+5%** [PLACEHOLDER]，无掌门修为奖励、无资源消耗、无次数上限，离线全程生效；
- 所有时间推演、任务派遣、建筑产出、事件触发全部正常执行，与在线完全一致，**离线收益不打折**（对齐 11.7 放置属性）；
- 紧急事件（外敌入侵、珍稀奇遇）自动留存记录，最多累计 7 天未处理，超出不再刷新，避免无限堆积。

**2. 生效优先级与叠加规则（核心，杜绝双算）**
- 优先级：**手动闭关悟道（+10%，11.8.7）> 离线被动闭关（+5%）**；玩家在线期间若开启手动闭关，按 10% 生效并正常消耗次数 / 资源 / 时间，手动结束后回归基础速度，离线时自动切换为 5% 被动；
- 两者**永不叠加**，同一时间仅生效最高档加速，彻底杜绝双算击穿红线（与 4.1 全局铁则「闭关类修炼加速取最高档」一致）；离线被动不占用每日手动闭关 2 次额度、不触发冷却。

**3. 数值平衡校验**
- 离线 5% + 聚灵阵基础 10% + 常规养成 ≈ 修炼加速 18%，远低于 25% 软上限；
- 手动 10% + 聚灵阵满级 15% + 掌门加持 ≈ 22%~24%，刚好触达软上限；
- 两者不同时生效，全局永远不会出现加速溢出 / 击穿红线。

**4. 出关回归文案与禀报**
- 短离线（几小时，对应数月）：*「掌门闭关三月，出关之时，清风拂面，宗门气象井然。弟子修炼不辍，灵田长势喜人，山门处尚有两名散修等候召见。」*
- 长离线（1 天以上，对应 1 年+）：*「掌门闭关一载，出关之日，见护山大阵灵光更盛，丹器堂烟火不息。期间有弟子突破、有新徒入宗、有外敌退散，宗门根基愈发稳固。此乃岁月积淀之效。」*
- 弹窗内分栏展示：弟子突破 / 招募收获 / 资源产出 / 事件记录，玩家可一键处理所有未完成事项；
- 超过 7 天未登录，自动触发回归保护：寿元暂停流逝（与 11.7 离线推进为「反惩罚例外」），赠送 3 名外门弟子 + 一批灵石，保障快速恢复运转（详见 6.10.5 回归保护）。**回归保护与修炼加速互斥（v2.20）**：回归保护期内仅暂停寿元流逝，**不触发任何修炼加速**（含离线被动闭关 +5%），避免「免费加速修炼且不耗寿命」破坏寿元平衡；回归保护解除后，正常离线 / 在线加速规则重新生效。

### 6.11 弟子养成深度机制（v2.17 新增，六大机制，无独立大模块）
以下机制全部基于现有系统做深度延伸（藏经阁 / 器堂 / 丹堂 / 道心 / 三职业），不新增独立大模块、不突破全局数值红线（25% 通用 / 10% 道心，详见 4.1）。目标是丰富「千人千面」养成而不增加数值膨胀。

#### 6.11.1 功法熟练度与功法分支
- 每个职业对应多套功法，弟子修炼不同功法形成差异化偏向（如法修可走「群攻法道」「单杀剑修」「控场符道」）；
- 功法有熟练度等级，随使用时间逐步提升，高熟练度带来技能倍率、命中率提升（熟练度减耗计入 4.3 减耗乘区）；
- 高级功法通过先贤传承（6.10.4）、秘境掉落、宗门兑换获得，形成「收集—修炼—专精」深度养成线。

#### 6.11.2 本命法宝体系
- 金丹期以上弟子可炼化本命法宝，挂靠器堂系统（详见 8. 物品装备系统）；法宝随弟子成长逐步淬炼，提供专属属性与技能，与弟子绑定、不可交易；
- 法宝有不同品阶与词条，差异化培养；词条增益计入通用增益乘区，遵守全局 25% 封顶（详见 4.1）。

#### 6.11.3 道心与心魔深度机制（与 6.9 道心系统衔接扩展）
- 道心设等级，随修炼、奇遇、悟道提升；高道心提供心魔抵抗、寿元减速、突破成功率提升（联动 6.10.1 道心 -5%~15% 寿元减速、11.8.11 突破成功率道心加成）；
- 心魔劫机制：突破大境界时概率触发心魔劫，考验道心；失败则心魔值暴涨、折损寿元，成功则道心大幅提升；
- **职业心魔联动（v2.28 新增，风险对等）**：法修心魔基础增长率 +15% [PLACEHOLDER]、道心跌落更快；体修心魔基础增长率 -10% [PLACEHOLDER]、道心稳固度更高；道修心魔恢复速度 +10% [PLACEHOLDER]、心魔压制最强；叠加 6.2.1 灵根维度反向约束（天品心魔 +30% / 废品 -20%），形成「天赋越高、风险越大」制衡；
- 强化「心性修炼」维度，与单纯堆修为形成互补（道心增益独立乘区 ≤10%，详见 4.1）。

#### 6.11.4 弟子职业专精方向（与 9.2 三职业框架衔接）
同一职业解锁不同专精分支，体现差异化定位：
- 体修：防御坦系 / 狂战输出系；

**后续版本细分专精（v2.28 标注方向，金丹期解锁，暂不实装）**：各职业扩展 2 个专精方向，进一步放大差异化、丰富配队与经营策略（增益计入对应乘区、不破 25% 软上限 4.1）：
- 道修：丹道专精（丹药产出 +25% [PLACEHOLDER]、丹药效果 +15% [PLACEHOLDER]）／阵道专精（宗门防守阵法强度 +30% [PLACEHOLDER]）；
- 体修：护山专精（防御 +20% [PLACEHOLDER]、嘲讽范围扩大）／破阵专精（攻城伤害 +25% [PLACEHOLDER]、破甲效果提升）；
- 法修：符箓专精（范围伤害 +20% [PLACEHOLDER]、灵力消耗 -15% [PLACEHOLDER]）／御兽专精（灵兽战力 +30% [PLACEHOLDER]、可额外契约 1 只灵兽）；
- 与 6.1.2 自创道途、6.15 转职转修同源扩展，长线强化「后天培养权重」、稀释先天决定论。
- 道修：治疗辅助系 / 阵法增益系；
- 法修：爆发群伤系 / 持续控制系；
专精通过功法、法宝、性格共同决定，让同职业弟子有完全不同用法，提升阵容搭配深度。

#### 6.11.5 宗门技艺体系（拓展丹道 / 器道 / 阵道 / 符道）
- 弟子可选择主修一门技艺，在丹堂、器堂等建筑工作时效率更高、产出更优；
- 技艺等级随工作时间提升，高阶技艺可炼制稀有丹药、锻造高阶装备；
- 不直接提升战力，但强化宗门经营深度，贴合宗门建设核心玩法（对应建筑解锁见 11.1.1 / 11.2）。

#### 6.11.6 师徒传承体系
- 高阶弟子可收低阶弟子为徒，师父的功法、技艺会加速徒弟成长；
- 师父寿尽后（详见 6.10.4 先贤堂），徒弟可继承部分功法熟练度与道心值，强化传承感；
- 师徒关系联动先贤堂机制，形成世代传承闭环。

#### 6.12.2 记名弟子体系（广收门徒设定补全，对应新稿九.1）
- 归属：分层最底层，单独名额上限（见 11.1.1），不占正式名额；
- 获取：下山测灵低质弟子（凡俗 / 平庸）默认归入记名，山门访客劣质弟子也可选记名收录；
- 职能：仅负责灵田 / 杂役 / 丹器辅助，提供微量宗门产出加成，无修炼资源倾斜，突破概率极低；（v2.20 明确：记名弟子不可出战、不可入宗门战 / 秘境核心玩法，仅非战斗职务，硬约束见 11.4 / 11.1.1）
- 转正机制：连续工作满 3 游戏年，有 1% [PLACEHOLDER] 概率觉醒灵根 / 提升资质，转为外门正式弟子；掌门祈福 / 特殊奇遇可触发破格转正（惊喜产出）；
- 平衡：低成本、大批量、低质量，仅填充基层人手，不冲击正式弟子核心价值。

#### 6.12.3 弟子任职与技艺匹配机制（对应新稿「八」，产出效率池）
四大技艺（丹道 / 器道 / 阵道 / 符道）与弟子天赋、灵根绑定，任职对应建筑时提供效率加成；人岗匹配度越高产出越强。本机制归入**独立的产出效率池**（详见 4.1 / 全局铁则），**不占用通用战力 25% 软上限**。

**技艺天赋与等级**
- 天赋：弟子生成时随机附带，分平庸 / 优良 / 天才三档，决定技艺成长上限；灵根额外加成：木灵根丹道 +10% [PLACEHOLDER]、火灵根器道 +15% [PLACEHOLDER]、土灵根阵道 +12% [PLACEHOLDER]；
- 等级：入门 → 熟练 → 精通 → 宗师四级，随工作时间自动提升，等级越高对应建筑产出效率越高；每名弟子只能主修一门、辅修一门，避免全能型泛滥。

**任职匹配规则**
- 系统自动人岗匹配：丹道天赋优先入丹堂、器道天赋优先入器堂、高战力优先守大阵、零基础优先去灵田；
- 任职弟子越多、技艺等级越高，对应建筑基础产出效率 / 高阶物品概率越强；
- 职业匹配岗位履职效率额外提升（v2.28 新增）：道修→藏经阁 / 丹房、体修→护山队 / 矿场、法修→符箓堂 / 灵田时，履职效率 +10%~15% [PLACEHOLDER]；与 6.2.1 灵根属性产业适配系数叠加计算、同属产出效率池、不破 30% 总封顶（4.1）；
- 弟子闭关 / 外出 / 重伤时自动撤岗，替补补位，保证建筑永不停工。

**数值平衡（产出效率池，详见 4.1）**
- 单座建筑任职技艺加成最高 **+20%** 产出效率（与建筑基础等级、掌门丹器加持叠加后单建筑最高 +30% [PLACEHOLDER]）；
- 全建筑合计产出效率池最高 **+30%** [PLACEHOLDER]；同类型建筑任职弟子超过 5 人后，新增收益按 50% 衰减，避免无限堆叠导致资源泛滥；
- **所有加成仅缩短资源积累周期，不提升弟子最终战力天花板**，不进入通用战力池、不破 25% 红线。

### 6.13 弟子自主行为逻辑（v2.18 新增，对应新稿「四」）
全程后台自动执行、玩家无需干预，不同境界弟子自动匹配对应阶段行为（低阶打杂、中阶修炼、高阶掌事），复用现有时间推演 / 任务派遣 / 建筑产出底层，符合经典修仙逻辑。

**跨门派社交关系**（弟子个人级交友 / 结仇、历练路线偏好挚友避死敌）详见 6.18；关系事件全自动推演，玩家仅对深度关系事件做三选一决断，日常无操作负担。

**分境界行为细则**

| 弟子境界 | 核心行为（自动优先级排序） |
| --- | --- |
| 练气期 | 1. 完成灵田 / 丹器堂杂务；2. 业余时间基础修炼；3. 低阶宗门任务轮值 |
| 筑基期 | 1. 主力时间修炼冲金丹；2. 可带队下山测灵 / 周边巡逻；3. 参与低阶秘境历练 |
| 金丹期 | 1. 核心精力闭关修炼冲元婴；2. 担任宗门执事、管理外门事务；3. 宗门战替补、带队中阶秘境 |

**补充规则**
- 行为优先级：修炼突破 > 宗门事务 > 派遣任务，保证核心成长节奏不被打断；
- 状态互斥：外出 / 重伤 / 闭关期间不参与其他事务，任务结束自动回归修炼；
- 阵营倾向影响行为：正道弟子多做安民 / 帮扶事务，魔道弟子多做巡察 / 强征事务，与 2.2 道途体系完全联动。

#### 6.13.1 日常作息节律（十二时辰，与游戏时间同步，v2.19 并入新稿「六」）
- 辰时：晨起早课，全体弟子修炼 1 时辰；
- 巳时—申时：各司其职（杂役劳作 / 外门轮值 / 内门修炼 / 长老理事），任务派遣在此期间执行（详见 6.14）；
- 酉时：晚课修炼，总结当日所得；
- 戌时—寅时：多数弟子休息，值守弟子轮班看护山门与大阵；
- 闭关 / 疗伤 / 紧急任务不受作息限制。

**昼夜效率系数（v2.20，[PLACEHOLDER] 待实测）**：作息不仅排班，也量化昼夜对产出的影响——① 修炼效率：酉时后至寅时（夜休时段）非闭关弟子的主动修炼效率 -[PLACEHOLDER]%（闭关不受影响）；② 产出效率：灵田 / 矿场夜间产出 -[PLACEHOLDER]%，丹堂 / 器堂可夜间值守不受影响；③ 事件触发：夜间奇遇 / 外敌事件触发概率 ±[PLACEHOLDER]%（如夜袭类事件夜间概率更高）；④ 值守弟子（戌—寅轮班）在夜休时段效率正常，保障山门不空档。所有昼夜系数仅为体验微调、不进入战力 / 产出效率池的硬上限计算。

#### 6.13.2 行为与宗门状态联动（详见 11.9 宗门财政体系）
- 公库充盈、俸禄按时发放：弟子修炼勤勉、怠工概率低、道心平稳、宗门凝聚力上升；
- 公库空虚、俸禄拖欠（触发 11.9.1 公库预警）：低阶弟子怠工、修炼速度下降，严重时叛逃下山，直至库藏充盈恢复；
- 外敌来犯、大阵预警：暂停日常，自动进入护山状态（值守大阵 / 备战迎敌），战后自动回归岗位；
- 宗门大典 / 收徒仪式：全员参与，短暂提升宗门凝聚力与修炼士气。

#### 6.13.3 弟子自主诉求（玩家仅决断大事，垂拱而治）
- 低阶弟子：自动申请晋升 / 任务 / 参悟功法，达标自动晋升（详见 6.12.2），无需手动操作；
- 中高阶弟子：申请闭关 / 结侣 / 下山历练，玩家可批准或驳回（结侣规则详见 6.16.1）；
- 长老执事：自动处理日常琐事，仅重大事件（弟子叛逃 / 外敌来犯 / 财政危机）上报掌门。

#### 6.13.4 弟子叛逃与策反机制（v2.22 新增，对应玩法扩展模块「二」）

**设计定位**：深化宗门经营风险维度，将「弟子道心、忠诚度」从无感数值转化为可感知经营博弈，并丰富宗门战策略维度（替代原简单「弟子离职」逻辑）。

**叛逃触发条件（满足任意一条即有概率触发，概率随条件严重度递增，[PLACEHOLDER] 待实测）**：
- 弟子道心值低于 30% [PLACEHOLDER] 且宗门连续 30 天财政赤字（见 11.9.1 公库预警）；
- 弟子阵营倾向与宗门主流偏差超 70% [PLACEHOLDER] 且长期受压制（见 2.2 口径）；
- 弟子存在「死敌」同门且死敌职级高于自身（见 6.18 交恶线）；
- 宗门战连续大败，弟子士气跌至谷底（见 11.4 / 6.9 道心）。

**叛逃后果**：普通弟子带走自身低阶法器、少量公库灵材；核心弟子额外带走一部低阶功法残卷，小幅降低藏经阁对应功法参悟进度（见 6.17）；所有叛逃弟子均有概率加入敌对宗门成为对方战力补充（见 6.18.6 敌对联动）。

**预警机制（道心动摇期）**：正式叛逃前设有 [PLACEHOLDER] 天（建议 3 天）游戏时间预警期，期间弟子状态显示「道心动摇」，头像边缘出现红色霓虹预警光效（视觉规范见 15.4）；玩家可通过谈心疏导 / 赏赐丹药 / 调整岗位等方式提升其道心、降低叛逃概率（道心变动归 6.9 独立乘区）。预警期内挽回成功则不触发叛逃，避免出现毫无征兆的核心弟子丢失、保障体验不崩盘。

**策反机制**：宗门战（11.4）胜出时概率策反敌方低道心普通弟子入宗（复用 11.6.8 入宗流程）；秘境偶遇他宗弟子若己方与其为「挚友」关系（6.18.5）概率邀请投奔；友好宗门交流时可互换低阶弟子实现人才流动。（策反所得带艺修士初始境界规则详见 6.1.6）

**玩家干预**：苗头期「赏赐丹药 / 提升职级 / 谈心疏导」提升道心降低叛逃概率（道心变动归道心独立乘区、10% 封顶，见 6.9）；已叛逃可发布追杀令追回部分损失资源，但提升对应宗门敌对度（见 6.18.6）。

**数值约束**：叛逃基础概率低于 5% [PLACEHOLDER]，且有明确预警期与挽回途径，不会出现毫无征兆的核心弟子丢失；策反基础成功率低于 3% [PLACEHOLDER]、投入资源成本高于招贤阁直接招募平均成本，仅作补充途径、不替代核心招募价值（11.6）；所有数值波动均在现有体系内，不新增独立属性乘区。叛逃损失单事件不超过对应总量 1% [PLACEHOLDER]、全局月度损失上限不超过 3% [PLACEHOLDER]，仅作风险警示不毁灭性打击；策反所得弟子战力上限不超过宗门平均战力 80% [PLACEHOLDER]，避免靠策反快速碾压；道心 / 士气变动统一归道心独立乘区，遵守 10% 总封顶。

**赛博视觉适配（形赛博魂传统，对齐 15.4）**：弟子道心动摇时头像边缘红色霓虹预警光效 + 微弱数据紊乱粒子；叛逃 / 策反事件弹窗为红色警示样式、带扫描线动效，文案仍沿用传统修仙表述；跨门派社交页（6.18.12）策反入口对应全息密钥样式图标，符合赛博数据交互视觉逻辑。

**落地优先级**：逻辑层为低优先级，核心社交与道心体系（6.9 / 6.18）稳定后再落地，避免前期增加系统复杂度；视觉层后置，随社交系统（6.18 / 15.4）同步优化。

#### 6.13.5 每日手动巡察（v2.22 新增，对应短板三「玩家决策权重低」）

**设计定位**：给玩家一个固定上线操作点，填充「收菜」之外互动感，强化宗门经营真实体感（5 秒即可完成，不增加日常负担）。

**规则**：玩家每天可手动执行 1 次巡察，巡查过程触发随机小事件（弟子偷懒、发现灵材、外门来访等），对应小奖励 / 小惩罚；纯体验与小额资源变动，不进入数值红线（4.1）。

**后续版本（v2.30+）**：新增「资源分配权」，玩家可手动调整灵材在修炼 / 丹药 / 维护上的分配比例，进一步强化经营决策感（与 11.9 财政体系配合）。

### 6.15 弟子转生与转职扩展（v2.18 新增，对应新稿「九.2 / 九.3」）
对 6.11 弟子养成深度机制的纵向延伸（功法熟练度见 6.11.1、师徒传承见 6.11.6），进一步拉长弟子价值周期，均不突破全局数值红线（25% 通用 / 10% 道心，详见 4.1）。

#### 6.15.1 灵识转世 / 重修机制（强化传承感）
- 触发条件：化神及以上高阶弟子寿尽时，有 5% [PLACEHOLDER] 概率触发「灵识转世」，稀有彩蛋、无强制保底；
- 效果：后续招募新弟子中概率出现转世者，自带前世 10% [PLACEHOLDER] 修为起点与道心值，大幅缩短培养周期；保留前世道途倾向与核心天赋（如前世丹道天才，转世后丹道天赋仍优良以上）；
- 不保留境界 / 装备 / 最终强度上限，仅加速成长，不破坏数值平衡；
- 文案沉浸：入门触发特殊事件——*「此子眉眼间竟与当年的 X 长老有七分相似，测其灵根亦是同源，此乃宗门气运流转之兆。」*

#### 6.15.2 弟子转职 / 转修机制（延长价值周期）
- 解锁条件：金丹期后可选择，每名弟子一生最多转职 1 次 [PLACEHOLDER]；
- 转职方向：
  - **战斗转经营**：放弃战斗修炼，专职丹 / 器 / 阵 / 符技艺，转为对应建筑执事，技艺成长速度翻倍，但修为不再增长（给低战力、高技艺天赋弟子提供价值出口，任职规则见 6.12.3）；
  - **同职业转功法**：如法修从群伤转控场、体修从防御转狂战，更换功法体系、重新积累熟练度（功法分支见 6.11.1），最终强度上限一致但定位不同，丰富阵容搭配深度；
- 平衡规则：转职消耗对应功法残卷与灵材、有冷却周期，仅改变成长方向，不突破原有境界与属性天花板，不造成数值泛滥。

#### 6.15.2.1 转职损耗细则（v2.23 新增，补全 6.15.2 缺口）
- **筑基期前**：可免费转职，基础属性 100% 继承，无损耗；
- **金丹期后**：转职保留基础修为按大类区分（v2.28 细化）——同大类转职（如法修转符箓专精向）保留 70% [PLACEHOLDER] 功法进度、仅掉 30% [PLACEHOLDER] 基础修为；跨大类转职（如体修转法修，需对应属性灵根支撑）仅保留 30% [PLACEHOLDER] 基础修为、功法熟练度进度清零，需重新积累（见 6.11.1 功法分支）；
- **废功重修（极端兜底）**：可重置职业，但掉落 1 个小境界 [PLACEHOLDER]、折损部分修为，作为高成本纠错机制；
- 平衡：所有转职仅改变成长方向，不突破原有境界与属性天花板（对齐本小节平衡规则），不造成数值泛滥。

### 6.16 家族血脉传承体系（v2.19 新增，对应新稿「三」）

#### 6.16.1 道侣与子嗣规制
- 弟子年满十六、境界达标，可与同宗 / 外宗 / 凡俗结为道侣，向宗门报备记入名册；
- 低阶弟子（练气 / 筑基）生育相对容易，金丹后精气内敛难度大幅提升，元婴以上万中无一，符合修仙者生育艰难设定；
- 生育折损母体 3~10 年寿元与少量修为（对齐 6.10.1.4 折寿规则），需产后温养，高阶丹药可弥补；
- 子嗣出生后自动归入宗门**记名弟子**（详见 6.12.2），由宗门统一抚养，至十岁行**测灵礼**（复用 11.6 测灵逻辑），按灵根资质归入外门 / 内门，天赋卓绝者可被长老收为亲传。

#### 6.16.2 血脉与天赋传承（增益归属见 4.1 红线）
- 子嗣有概率继承父母灵根 / 天赋 / 特殊体质（单灵根父母大概率单灵根；剑骨 / 道体 / 妖族血脉等有特殊血脉者，子代有概率觉醒）；
- **职业倾向与初始偏向遗传（v2.28 新增）**：父母职业有概率影响子嗣初始职业倾向——道修家族子嗣初始道心值更高 [PLACEHOLDER]、体修家族子嗣初始体魄（气血 / 防御）属性更高 [PLACEHOLDER]、法修家族子嗣初始灵力 / 攻击属性更高 [PLACEHOLDER]；灵根属性与品级由父母双方灵根共同决定（同属性灵根父母大概率生同属性后代、高品级有概率隔代遗传），归属本小节血脉传承体系、不破 25% 软上限；
- **血脉共鸣**：同一家族弟子一同修炼 / 组队出战，修炼速度 +5% [PLACEHOLDER]、战力 +3% [PLACEHOLDER]；仅组队生效，覆盖率低，等效全局约 1%~1.5%，计入通用战力池（单源子帽，详见 4.1 全局铁则 v2.19 条）；
- **家族传承功法**：家族先辈自创功法（详见 6.17.1），后代参悟速度 +30% [PLACEHOLDER]，且仅针对单一家族传承功法、非全局加速，计入通用战力池修炼加速分支；**（同源说明 v2.20）家族传承功法即「由本族先辈自创并录入藏经阁的功法」，与 6.17.1 自创功法体系同源——其 +30% 后代参悟加速与 6.17.1「自创功法后代参悟 +30%」为同一机制、不双算；仅当后代研习该特定家族功法时生效，不提供额外全局加速，杜绝配置重复与叠加超模。**

#### 6.16.3 宗门家族生态
- 宗门内繁衍三代以上形成家族，可设家族祠堂、供奉先辈牌位，享受少量家族气运加成；
- **家族气运**（全局属性类）：单家族最高 +1% 全局属性、多家族边际衰减、全局合计最高 +2% [PLACEHOLDER]，占用先贤堂 5% 额度内（详见 6.10.4 / 4.1）；（**配置约束 v2.20** 家族气运是「先贤堂全局增益」下的一个子类目，其 +2% 全局合计从先贤堂 5% 额度内支出，配置时归入先贤堂增益表同一字段、不另开额度，从数值底层避免与先贤堂 5% 双算突破硬上限）
- 家族势力有正反两面：强家族提升凝聚力、人才辈出；一家独大则出现派系争斗、把持岗位、排挤外姓，掌门可通过扶持 / 制衡 / 打压调控；
- 家族子弟触犯门规与普通弟子同罪，严重者废修为、逐出宗门，牵连家族声望。
- 跨宗门家族联姻扩展（两宗门家族弟子结道侣共享气运、绑定友好度）预留接口见 6.18.10②，当前版本仅做基础关系值联动。

- 自创成功后自动录入藏经阁，全宗可参悟；创始人亲传 / 后代参悟速度 +30% [PLACEHOLDER]，创始人寿尽后功法归入先贤传承体系（详见 6.10.4）；（**同源说明 v2.20** 若创始人同属某宗门家族，该功法即成为该族「家族传承功法」，与 6.16.2 同源、+30% 不双算，详见 6.16.2）

- **红线归属（v2.19 定案，对齐 4.1）**：功法战力类效果（伤害 / 防御 / 气血 / 减伤 / 暴击等）计入通用战力池（单功法最高 +3% 单属性、等效全局约 2%）；效率 / 经营类（丹道 / 器道 / 产出）计入产出效率池；道心 / 心魔类归入道心独立乘区；寿元类不计入任何增益池。所有功法明细统一标注「增益归属池」字段（见 6.17.2）；（**防御类功法乘区对齐 v2.20，详见 9.4**）防御 / 减伤 / 闪避 / 招架类功法虽标「通用战力池」，其内部须对齐 9.4 战斗防御层——① 减伤类（物理 / 法术 / 全减伤）走「减伤机制独立层」（常驻全减伤硬上限 70%、单系 75%，见 9.4.2.2），不裸堆进战力面板；② 闪避 / 招架类走「规避机制独立层」（闪避硬上限 70%、招架 75%，见 9.4.2.1），互斥取最高；③ 防御增益（防御 +X%）走「防御增益乘区」（加算后乘进基础防御，等效收益计入通用增益 25% 封顶，见 9.4.6 乘区表）。代码实现须按此三层落位，放错层级会击穿 9.4 硬上限。
- **藏经阁管理**：藏经阁（灵品解锁，详见 11.2.1）存储功法 / 心法 / 术法，弟子自动学习对应品阶功法，随宗门品级提升解锁更高品阶与参悟速度。

#### 6.17.3 品阶对齐规则（v2.56 重基线）

- **品阶对齐规则**：功法严格分为凡 / 灵 / 宝 / 王 / 圣 / 真 / 道 7 大品阶，每阶分下 / 中 / 上 / 极品四级，品阶决定可修炼的最低境界与属性成长上限。
- **修炼门槛**：弟子境界不得低于功法对应品阶门槛，否则无法修习；极品功法额外要求灵根纯度达标。
- **层数与等级**：每部功法共 9 层，修炼满层可突破至下一细分品级；大品阶不可跨阶修炼，需逐级修习。
- **属性增益**：功法提供的攻击、防御、气血增益归入对应战斗乘区，与装备、法宝叠加后遵守全局上限。
- **职业适配**：功法按职业分为体修、道修、法修、通用四类，非对应职业修炼效果衰减 50%。
- **冲突规则**：同类型功法仅可同时修炼 1 部，替换需遗忘原有功法，返还 70% 修炼经验。

### 6.18 跨门派弟子社交关系体系（v2.21 新增，对应新稿「跨门派弟子社交关系玩法」）

核心设计原则：**全自动为主、玩家轻干预**（弟子交际后台推演，玩家仅对深度关系事件三选一决断，不增日常操作负担）；**零架构改动、全复用底层**（100% 嵌套进奇遇 / 宗门战 / 声望 / 弟子自主行为系统，不新增独立建筑、不突破 15 座建筑定案、不改现有章节号）；**数值严格对齐红线**（所有增益归入对应乘区，无独立额度，不击穿 25% 软上限）；**分层落地、预留扩展**（当前版本轻量实装基础逻辑与核心玩法，底层预留字段与接口，后续版本无缝升级深度玩法）。

#### 6.18.1 关系分类与等级（双向三级，自动晋级 / 降级）
- **交善线**：泛交 → 挚友 → 生死之交；共同历练 / 互助事件正向积累；
- **交恶线**：摩擦 → 仇怨 → 死敌；资源争夺 / 战斗冲突负向积累；
- **关系值阈值 [PLACEHOLDER]**：泛交/摩擦 50 ｜ 挚友/仇怨 200 ｜ 生死之交/死敌 500（达到阈值自动晋级，跌破降级）；
- **规则补充**：同一对弟子仅生效最高等级关系，不可同时交善与交恶；长期无交互关系值自然衰减（见 6.18.2），避免关系永久固化。

#### 6.18.2 关系值模型与存储层（零重构，仅追加字段）
- **弟子个人层**：`disciple.gd` 追加 `cross_sect_relations` 字典（存储「对方宗门 ID + 对方弟子 ID + 关系类型 + 关系值」），随弟子存档同步读写；不新增核心属性，仅作扩展标记，兼容旧档；
- **宗门全局层**：`game_state.gd` 追加 `sect_diplomacy` 字典（存储「对方宗门 ID + 友好度 / 敌对度数值 + 关系标签」），按阈值自动更新状态，独立于五大阵营声望体系（见 2.1 / 11.5）；
- **事件记录层**：所有交际事件写入弟子履历（复用现有 30 年履历逻辑，详见 6.10.5），不新增独立日志系统；
- **人数限制**：每名弟子最多同时存在 8 组深度关系（挚友 + 死敌合计）[PLACEHOLDER]，避免关系无限膨胀；
- **衰减机制**：连续 30 [PLACEHOLDER] 游戏日无交互，关系值自然衰减 10% [PLACEHOLDER]，深度关系（挚友 / 死敌）衰减速度减半；
- **死亡清算**：弟子陨落 / 叛逃后，其个人关系自动清除，对应宗门关系值按比例折算扣除，不永久残留。

#### 6.18.3 触发与结算机制（全复用奇遇四维判定）
- **触发时机**：弟子执行宗门任务（6.14）/ 下山历练 / 秘境探索 / 宗门战对战（11.4）/ 坊市交易（11.3）时，按固定概率 [PLACEHOLDER] 触发「跨门派交际」子事件；
- **判定逻辑**：根据双方弟子性格四维（10. 奇遇系统）、道途倾向（2.2）、阵营归属自动判定走向——正道倾向 + 性格契合易交善，魔道倾向 + 利益冲突易交恶；
- **结算方式**：事件结束后同步更新双方关系值、弟子心魔 / 道心状态、对应宗门全局关系值，全程后台自动执行，无需玩家操作。

#### 6.18.4 宗门级关系映射（从个人自动聚合，无需玩家外交操作）
- **聚合公式**：宗门友好度 = Σ（所有弟子交善关系值加权）÷ 弟子总数 × 修正系数 [PLACEHOLDER]；敌对度同理；
- **触发阈值**：友好度 ≥30 [PLACEHOLDER] 解锁「友善宗门」标签，≥80 [PLACEHOLDER] 解锁「友好宗门」深度联动（交易 / 援军 / 声望）；敌对度 ≥25 [PLACEHOLDER] 解锁「摩擦宗门」，≥70 [PLACEHOLDER] 解锁「敌对宗门」；
- **边界约束**：宗门关系等级不超过个人关系最高梯度，避免少数弟子决定全宗外交；宗门关系反向影响个人交际概率——友好宗门弟子相遇更易交善，敌对宗门更易冲突。

#### 6.18.5 弟子个人级玩法（全自动运行，无玩家操作）
- **交善正向效果**
  - 历练互助：与泛交以上关系的弟子同场景历练时，任务效率 +5% [PLACEHOLDER]（单组），单弟子合计最高 +10% [PLACEHOLDER]，归入产出效率池，不占战力额度；挚友级概率共享对方宗门低阶功法残卷，加速藏经阁参悟进度（见 6.17 / 6.18.11）；
  - 道心慰藉：挚友定期互通书信，弟子心魔增长率 -5% [PLACEHOLDER]，归入道心独立乘区，合计最高 +5% [PLACEHOLDER]、遵守 10% 封顶；生死之交在对方突破时提供道心加持，小幅提升突破成功率（见 6.18.9 突破专项线）；
  - 资源互通：小概率带回对方宗门特产灵材 / 丹药，直接归入宗门公库（11.9.1），属小额惊喜产出；
- **交恶负向效果**
  - 途中摩擦：遭遇仇怨级对方弟子时，概率发生口角 / 小规模冲突，损失少量灵石 / 灵材，历练效率下降；
  - 心魔滋生：死敌关系弟子相遇后，心魔值小幅上涨；长期存在死敌的弟子，突破走火入魔概率微增；
  - 历练干扰：敌对弟子概率破坏任务进程，导致历练失败率提升，属风险机制而非毁灭性惩罚。

#### 6.18.6 宗门联动级玩法（阈值触发，联动现有系统）
- **友好宗门联动**

  - 声望联动：与友好宗门共同参与秘境、击退外敌时，双方阵营声望（11.5）同步小幅增长；
- **敌对宗门联动**

- 本命法宝：覆盖宝品至道品，每名弟子仅可绑定 1 件，不可交易、不可替换

#### 6.22.3 法宝分类
| 法宝类型 | 定位 | 佩戴数量 | 核心效果 |
| --- | --- | --- | --- |
| 攻击类法宝 | 输出增益 | 最多 2 件 | 提升攻击力、暴击率、伤害加成 |
| 防御类法宝 | 生存增益 | 最多 2 件 | 提升防御、气血、减伤 |
| 辅助类法宝 | 功能增益 | 最多 1 件 | 提升速度、命中、闪避、灵力回复 |
| 本命法宝 | 核心专属 | 1 件 | 专属主动技能 + 高额属性 + 成长词条 |

#### 6.22.4 养成规则
- 普通法宝：可强化、镶嵌，提升细分品级，不可跨大品阶升级
- 本命法宝：通过祭炼提升等级，消耗对应材料解锁技能、提升品阶，随弟子境界同步成长
- 所有法宝属性归入对应战斗乘区，叠加后遵守全局上限
