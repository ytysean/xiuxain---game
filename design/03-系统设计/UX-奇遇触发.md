## 一、设计支柱对齐（防认知过载/支柱漂移）

| 支柱 | 落点 |
| --- | --- |
| 放置省心（§10.1） | 普通(绿)/稀有(蓝) 奇遇**全自动判定无弹窗打断**；仅珍稀(紫)/传说(金) 触发玩家干预弹窗 |
| 决策权重（§10.4 短板三） | 自动结算改为二选一/三选一；每日限定手动奇遇次数，其余自动 |
| 动效令牌（§15.5） | 弹窗严格套用 4 类 11 项动效令牌，零自定义特效 |
| 性能降级（§15.4 七） | 关「高品质动效」→ 稀有/传说降级为静态角标，关全部发光流光 |
| 性格驱动（§2.2/§10） | 分支由「性格四维阈值」判定；无四维时回退性格字符串映射 |

### 1.1 可访问性分级（强制引用 `design/gdd/art/ACCESSIBILITY.md`）

- 本 UX 所有交互挂载可访问性分级，默认 **Standard（默认开启·推荐）**；设置可切 Basic / Standard / Comprehensive。
- **最小触控**：弹窗「选择分支/干预/关闭」条热区 ≥44×44px（Basic 亦须满足，底线）。
- **色盲冗余**：稀有度角标仅靠颜色区分时，须叠加 **形状 + 文字** 双通道（灰/金/紫 角标附带 普/稀/传 字 + 形状轮廓，不纯色编码）；降级静态角标同样保留文字。
- 特性矩阵与动效降级对齐见 ACCESSIBILITY.md；本文件「六、降级开关」三档即对齐落地。

## 二、信息架构（IA）

```
[后台推演/历练] 弟子触发奇遇
   └─ game_state 推送「奇遇禀报」入 待处理队列(§4.5 铁则五：最近≤[PLACEHOLDER:30]条)
        ├─ 普通/稀有：静默入禀报列表，不弹窗（挂机无打断）
        └─ 珍稀/传说：右下角弹窗(§15.5 基础 320×120) + 角标稀有度色
              └─ [奇遇弹窗] 四阶段点击(§15.5.3) → 详情面板
                    ├─ 文本：取奇遇() 模板填充 {地}{人}{妖}{物}
                    ├─ 稀有度角标：灰(普通)/金(稀有)/紫(传说)（§15.5.0）
                    ├─ 性格分支展示（§10.4 全选项化）
                    └─ 玩家干预三档（§10.1.1：放任/暗中相助/亲自出手）
                          └─ [结算] 奖励写履历 + 战报 + (可选)道心值
```

**稀有度映射待统一告警（UX↔art 边界已解）**：`event_quest.rarity` 设计为 3 档(普通/稀有/传说，§15.5 锚点)，但 §10 正文为 4 档(绿/蓝/紫/金)。本 UX 暂按 §15.5 锚点(灰/金/紫) 落地——**UI 侧契约已与 art-lead 闭环**：
- 绑定枚举键（art 已采纳）：`rarity_common`(普通/灰) / `rarity_rare`(稀有/金) / `rarity_legendary`(传说/紫)，三档键与 §15.5 对齐、与 §10 四档抽池层解耦（绿→普通、蓝→稀有、紫+金→传说）。
- 色令牌（art ASSET-奇遇弹窗.md §2 已落地）：`RARITY_NORMAL`=#9AA0AC 中性灰(静态) / `RARITY_RARE`=#F59E0B 金(呼吸发光) / `RARITY_LEGEND`=流光 #C084FC 浅紫 + 发光底 #8B5CF6 深紫。
- **仍待 design 权威拍板（不阻塞 UX/art 联调）**：§10 四档(绿/蓝/紫/金) ↔ §15.5 三档(普/稀/传) 的 roll 层→UI 层映射表，归 `§11.26.6 TODO-①`，由 老大/design 终审。

## 三、触发 → 弹窗 动效令牌（引用 §15.5，强制对齐）

> 所有参数锁定 §15.5；本文件不重定义数值，仅声明调用契约。

### 3.1 入场动效（弹出单次，§15.5.1）

| 稀有度 | 动画组合 | 时长 | 缓动 | 位移 | 缩放 | 透明度 | 额外 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 普通 | 右平移入+淡入 | 200ms | ease-out | X+30→0 | 1.0 | 0→100% | 无 |
| 稀有 | 缩放回弹+淡入 | 250ms | ease-out-back(回弹10%) | 无 | 0.9→1.03→1.0 | 0→100%(100ms) | 金色外发光淡入(模糊8px,峰值20%) |
| 传说 | 全屏闪白+弹性弹入+微震 | 300ms | 闪入ease-out/弹动ease-out-elastic(8%) | 无 | 1.1→0.97→1.0 | 0→100%(50ms) | 全屏淡紫光(50ms,15%) + 屏幕微震(2px,15Hz,150ms) + 紫发光(模糊12px,峰值40%) |

### 3.2 常驻动效（停留循环，§15.5.2，锁 30fps / 仅边缘重绘）

- 普通：无动效静态，仅灰角标。
- 稀有：角标呼吸(2000ms 正弦) + 外发光呼吸(金 #F59E0B，不透明度10%↔30%)。
- 传说：流光边框(紫 #C084FC 顺时针,4px羽化20px) + 外发光呼吸(深紫 #8B5CF6,20%↔60%) + 菱形角标流光(#8B5CF6,70%↔100%)。

### 3.3 点击动效（四阶段，全稀有度统一，§15.5.3）

1. **按下反馈**(100ms ease-in)：缩放 1.0→0.95，填充 85%→95%，外发光衰减20%(稀有/传说)。
2. **松开回弹**(80ms ease-out-back 超调5%)：缩放 0.95→1.03→1.0；传说额外轻震(1px,50ms)。
3. **转场展开**(200ms ease-in-out)：弹窗缩放至 1.8×、透明度100%→0%；详情面板 0%→100% 淡入承接。
4. **关闭消失**(200ms ease-in)：缩放1.0→0.9，X右偏30px，透明度100%→0%（与入场对称）。

### 3.4 反馈动效层（独立层，§15.5.4，4 类 11 项）

- 入场类：平移淡入(全) / 缩放回弹(稀有+) / 全屏闪入(传说) / 微震动(传说)。
- 常驻类：角标呼吸(稀有+) / 外发光呼吸(稀有+) / 流光边框(传说) / 角标流光(传说)。
- 交互类：按压缩放(全) / 底色加深(全) / 无缝转场(全)。
- 消失类：平移淡出(超时) / 缩放淡出(手动) / 向上飘出(领取奖励后正向反馈)。

## 四、性格驱动抉择分支（§10.4 全选项化 + §2.2 四维）

### 4.1 四维模型（设计规则，代码缺口⚠️）

- 四维：`激进度 / 利他度 / 聪慧度 / 贪欲度`，各 0–100。
- 12 标准性格 → 固定四维分值映射（生成弟子时赋值，见配置表 docx）。
- 分支标阈值示例：「高风险硬闯：激进度 80+，贪欲度 70+」。
- **代码现状缺口**：`disciple.gd` 仅有 `性格` 字符串、`lore.gd` 仅有 `性格效果文` 文本查表，**无四维数值字段**。实现性格分支前须 eng-lead 补四维字段（见「七、依赖」）。

### 4.2 分支判定优先级（§10.1.1）

```
玩家干预选择 ＞ 弟子性格四维判定
（玩家选择后直接执行对应分支，不再走性格判定逻辑）
```

### 4.3 选项呈现（全选项化，§10.4）

| 选项档 | 来源 | 展示 |
| --- | --- | --- |
| 分支 A / B / C | 奇遇模板定义（二选一/三选一） | 每支显「风险/收益」文案 + 性格契合度提示（如「契合：行异道·杀伐果断」） |
| 干预三档（珍稀+） | §10.1.1 | 放任自流(无耗) / 暗中相助(贡献·灵石,成功+15%品质+1档) / 亲自出手(高阶道具·声望,强制最优+道心) |

- 每日手动上限：凡品 3 次/日，每升 1 宗门品级 +2 次（§10.1）。
- 数值约束：各选项增益归对应乘区（战力类入通用增益池、资源类入产出效率池，均卡 §4.1 红线），不新增常驻膨胀。

## 五、竖屏单手布局（480×854，引用 §15.5.0 右下角 320×120）

- **弹窗锚点**：右下角 320×120，单手拇指可达；不居中遮挡主内容。
- **角标**：左上角稀有度角标（普通灰静态 / 稀有金呼吸 16×16 / 传说紫流光 18×18 菱形）。
- **详情面板展开**：点开放大至全屏（§15.5.3 转场），底部固定「选择分支 / 干预 / 关闭」条，热区 ≥44px。
- **禀报列表入口**：主界面顶部「禀报(N)」红点（朱砂 §15.4 强调1），点开滑出最近 ≤30 条待处理（§4.5 铁则五）。

## 六、降级开关（§15.4 七·性能约束，强制）

| 开关档（设置项） | 弹窗表现 |
| --- | --- |
| 高品质动效（开） | 全套 §15.5 入场/常驻/点击/反馈令牌 |
| 标准 | 保留入场+点击，常驻流光降帧至 30fps 锁帧（§15.4 锁帧基线） |
| 极简/关闭 | 稀有/传说**降级为静态角标**，关全部发光/流光/呼吸（仅保留灰/金/紫角标识别） |

- **性能基线**：常驻/循环动效锁 30fps；仅重绘变化区域（角标/边框/边缘层），单帧重绘面积 ≤ 面板面积；发光/模糊/流光开启 GPU 硬件加速，禁 CPU 软渲染（§15.4 七）。
- **低端机兜底**：竖屏 480×854 / 30fps 实测掉帧 → 优先降流光帧率与模糊半径（§15.5.5）。

## 八、边缘情况（≥3 类）

1. **越界重 roll**（§10.2）：低于弟子 2 大境界及以下的奇遇自动重 roll（金丹不触发凡品，可触发灵品普通）。→ 抽池前先判境界差，越界不入候选。
2. **四维缺失回退**：弟子无四维字段（旧档/未生成）。→ 回退 `性格` 字符串映射（§15.1.3 映射表）判定分支，记日志；新档强制补四维。
3. **每日干预耗尽**：已达当日手动上限。→ 珍稀+ 奇遇不再弹干预三档，降级为「仅性格自动判定」并显示「今日干预已用尽」。
4. **弹窗堆叠**：同屏多奇遇触发。→ 入禀报队列，仅最新 1 条弹窗，其余静默入列（§4.5 铁则五）。
5. **降级态动效**：关高品质。→ 传说弹窗无全屏闪白/微震/流光，仅紫静态角标 + 文本（§15.4 降级开关）。
6. **网络/异步（§10.3 天道异动）**：全服事件窗口开启。→ 顶部全局灵能广播条（霓虹标题+阵营响应进度），不阻塞单人奇遇弹窗层级。
