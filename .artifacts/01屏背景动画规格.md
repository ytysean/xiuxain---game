# 01 屏背景动画规格

> **适用范围**：Ardot 文件 `712384627196910` 第 01 屏（`2:55` 宗门主城主界面）。
> **前置状态**：01 屏已完成 P0/P1 布局优化，新增「幻形」按钮（`35:3`）与「隐藏 UI」开关（`35:5`），设计冻结中。
> **设计原则**：动画做「似有若无」的氛围感，绝对不能抢 UI 视线、影响点击操作；越慢、越淡、越克制越好。

---

## 1. 核心设计原则

| 原则 | 说明 |
|------|------|
| 不抢 UI | 所有动画必须在视觉层级上低于 UI，玩家第一眼看到的是按钮、资源、Tab，不是背景动效。 |
| 慢速低频 | 单周期 ≥ 25 秒，云雾层 ≥ 80 秒；禁止使用快速循环（如 1–3 秒呼吸）。 |
| 不位移热区 | 禁止通过 Camera2D 或背景整体平移来制造动感，避免按钮点击热区与视觉错位。 |
| 可开关 | 所有动画必须能独立开启/关闭，受性能设置与隐藏 UI 状态影响。 |
| 先 S1 后 S2 | S1 用零美术成本的代码动画先跑通；S2 等分层美术素材到位后再追加。 |

---

## 2. S1 轻量方案（推荐先做）

S1 仅依赖代码与一张可复用的柔边云雾贴图，零新增美术资产，性能友好。

### 2.1 镜头微呼吸动画

**效果**：整张背景以极慢速度做「放大 ↔ 缩小」循环，模拟镜头轻微呼吸感，让静态画面摆脱死板感；玩家几乎察觉不到，但会觉得画面更有生机。

**参数**：

| 属性 | 值 | 说明 |
|------|-----|------|
| 缩放范围 | 1.0 ↔ 1.02 | 极小幅，避免 UI 被裁切或建筑出界。 |
| 周期 | 25–30 秒 | 慢到难以察觉。 |
| 缓动 | `Tween.TRANS_SINE` + `Tween.EASE_IN_OUT` | 平滑非线性，无机械感。 |
| 锚点 | 背景 Sprite 中心 (`0.5, 0.5`) | 防止呼吸时画面偏向某一侧。 |
| 循环 | PingPong，无限循环 | 来回循环，无需重置。 |

**实现方式（Godot 4.7 GDScript）**：

```gdscript
extends Node2D

@onready var bg_sprite: Sprite2D = $BackgroundSprite

func _ready() -> void:
    var tween := create_tween().set_loops().set_trans(Tween.TRANS_SINE).set_ease(Tween.EASE_IN_OUT)
    tween.tween_property(bg_sprite, "scale", Vector2(1.02, 1.02), 15.0)
    tween.tween_property(bg_sprite, "scale", Vector2(1.0, 1.0), 15.0)
```

> **命名注意**：此效果虽被称为「镜头呼吸」，但实现上是「背景 Sprite 缩放」而非 Camera2D 缩放，目的是避免移动 UI 点击热区。落代码时注释需写清。

### 2.2 云雾缓慢平流

**效果**：画面底部、两侧呈现缓慢飘动的云雾错觉，强化仙山缥缈氛围，不破坏建筑结构。

**参数**：

| 属性 | 值 | 说明 |
|------|-----|------|
| 贴图 | 柔边云雾 PNG（建议 512×256 或 1024×512） | 边缘柔和、无硬边，可无缝水平重复。 |
| 重复 | `texture_repeat = CanvasItem.TEXTURE_REPEAT_ENABLED` | 水平循环，无需多张图。 |
| UV 偏移速度 | 约 1–2 px/秒 | 80 秒以上完成一次完整循环。 |
| 混合模式 | `CanvasItemMaterial.BLEND_MODE_ADD` | Godot 4 原生无「柔光」，用 ADD 近似；透明度 15%–20%。 |
| 透明度 | 0.15–0.20 | 越淡越自然，不能盖过 UI。 |
| 区域 | 覆盖底部 60–120px 与两侧边缘 | 不进入中央石阶与主殿主体区域。 |

**实现方式**：

```gdscript
extends Sprite2D

@export var scroll_speed: float = 1.5  # px/s

func _ready() -> void:
    texture_repeat = TEXTURE_REPEAT_ENABLED
    material = CanvasItemMaterial.new()
    material.blend_mode = CanvasItemMaterial.BLEND_MODE_ADD
    self_modulate.a = 0.18

func _process(delta: float) -> void:
    region_rect.position.x += scroll_speed * delta
```

> **技术纠正**：Godot 4 的 2D 混合模式没有 Photoshop 的「柔光(Soft Light)」，不要试图用 Shader 强行还原 Photoshop 混合公式；S1 用 `ADD` + 低透明度即可。S2 若需要更精确的柔光，再由技术美术写自定义 Shader。

## 3. S2 进阶方案（功能稳定后做）

S2 需要美术产出分层素材，不能由程序单独启动。

### 3.1 分层视差滚动

**效果**：背景拆成 3 层独立素材，每层移动速度不同（远景最慢、近景最快），用 `ParallaxBackground` 实现真实景深感；镜头轻微移动时立体感极强。

**分层需求（需美术产出）**：

| 层级 | 内容 | 建议速度比 | 备注 |
|------|------|-----------|------|
| 远景层 | 青黛山脉、天空、云层 | 0.1x | 最慢，几乎不动。 |
| 中景层 | 主殿、二门、山体建筑 | 0.3x | 跟随最轻微。 |
| 近景层 | 山门牌坊、底部云雾、松枝 | 0.6x | 稍明显，但仍克制。 |

**实现节点**：`ParallaxBackground` + 3 个 `ParallaxLayer`，每层放置对应 `Sprite2D`。

> **依赖**：当前 01 屏背景为单张「最终稿-超清.png」，未分层。S2 启动前必须先由美术产出 3 张独立 PNG（边缘需处理，确保无接缝）。

---

### 3.2 局部微动态叠加

**效果**：在背景对应位置叠加独立小动画 Sprite，不改动背景本体；沉浸感提升明显。

**候选元素**：

| 元素 | 位置 | 实现方式 | 美术需求 |
|------|------|---------|---------|
| 主殿窗光微闪 | 主殿窗户区域 | `AnimatedSprite2D` 或 Shader 控制透明度闪烁 | 窗光帧动画或单张贴图 |
| 丹房淡烟 | 丹房/建筑烟囱 | `GPUParticles2D` 或滚动烟雾 Sprite | 轻烟 PNG |
| 松树轻晃 | 山门两侧松树 | `AnimatedSprite2D` 轻微摇摆 2–3 帧 | 松树摇摆帧 |
| 灵气微光 | 场景空旷处 | `GPUParticles2D`，低密度、慢速上升 | 粒子素材 |

**约束**：
- 每个微动态独立节点，可单独开关。
- 粒子数 ≤ 30，生命周期 ≥ 5 秒，避免热闹。
- 必须锚定到背景坐标系，不能随 UI 缩放/移动。

## 4. 与现有功能的联动

### 4.1 幻形（背景皮肤切换）

- 切换皮肤时只替换底层背景 Sprite 的 `texture`。
- **动画层（呼吸 Tween、云雾 Sprite、微动态粒子）必须独立于背景贴图**，切换皮肤后动画继续播放，不重置、不中断。
- 建议封装为独立子场景：`SectBackgroundFX.tscn`，接收 `background_texture: Texture2D` 参数。

### 4.2 隐藏 UI（沉浸式看背景）

- 隐藏 UI 时，背景动画**不应停止**；相反，此时玩家注意力完全在背景上，动画可适当成为主角。
- 隐藏 UI 开关只控制 UI 节点显隐，不控制 `SectBackgroundFX`。
- 隐藏 UI 状态下若触发「弹出弹窗 / 切页 / 旋屏」，按《01 屏隐藏 UI 交互规格》强制恢复 UI，动画层保持运行。

## 5. 性能护栏

| 项目 | 要求 |
|------|------|
| 帧率无关 | 所有动画使用 `delta` 驱动（Tween 内部已处理；自定义 `_process` 必须乘 `delta`）。 |
| 低性能设备降级 | 在设置项中提供「背景动画：关闭/低/高」三档；低档仅保留呼吸，关闭云雾/粒子。 |
| 不可见时暂停 | 节点 `visible = false` 时，应停止 `_process` 更新或禁用粒子发射。 |
| S1 上限 | 同时运行的动画类型 ≤ 2（呼吸 + 云雾），符合「避坑红线」。 |
| S2 上限 | 加上视差与微动态后，单屏粒子总数 ≤ 100，动态 Sprite ≤ 10。 |

---

## 6. 避坑红线（绝对不要做）

1. **禁止镜头上下左右平移**：会导致按钮点击热区错位，也容易让玩家眩晕。
2. **禁止大幅度云雾翻滚**：太抢视觉重心，会盖过 UI 按钮辨识度。
3. **禁止同时叠加超过 2 种动画**：否则画面会显得「闹」，干扰操作。
4. **禁止用 Camera2D 实现呼吸**：Camera2D 会带动整棵树（含 UI），热区全错；必须用背景 Sprite 自身 scale。
5. **禁止在 S1 引入自定义 Shader 做柔光**：增加复杂度且无必要，ADD + 低透明即可。
6. **禁止动画层耦合 UI 显隐**：隐藏 UI 不是暂停动画，切皮肤不是重启动画。

### 7.2 关键 API 备忘

- 呼吸：`create_tween().set_trans(Tween.TRANS_SINE).set_ease(Tween.EASE_IN_OUT)`
- 云雾循环：`texture_repeat = TEXTURE_REPEAT_ENABLED` + 每帧偏移 `region_rect.position`
- 混合：`CanvasItemMaterial.BLEND_MODE_ADD`
- 视差：`ParallaxBackground` + `ParallaxLayer.motion_scale`

## 8. 验收标准

1. S1 呼吸与云雾动画能在 Godot 中稳定循环，不报错、不掉帧。
2. 动画不影响任何 UI 按钮的点击热区与视觉位置。
3. 切换「幻形」皮肤时，动画不中断、不闪烁。
4. 触发「隐藏 UI」时，背景动画继续；触发恢复 UI 时，动画仍继续。
5. 在低档性能设置下，云雾/粒子可被关闭，仅保留呼吸动画。
6. `pre_f5_check.py` 全绿通过，无 Godot 3 遗留语法、无 Node 动态属性报错。
