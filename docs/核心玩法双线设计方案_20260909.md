# 《太玄宗门录》核心玩法双线设计方案

> **文档版本**：v2.0（含闭关离线/时间付费/策略肝度三大补充章节）  
> **生成日期**：2026-09-09  
> **审计范围**：全系统代码审计（game_state.gd 17914行 + 约80个系统文件 + 40个UI页面 + 130+配置CSV）  
> **设计基准**：宗主个人线 + 宗门管理线 双线并行

---

## 一、概述

### 1.1 设计愿景

本游戏的核心设计愿景是构建一个"真实沉浸模拟修仙宗门"，由两条互不冲突、共同演进的主线构成：

- **宗主线（玩家角色线）**：宗主是独立可操控的修炼者，拥有自己的修炼体系（境界/修为/功法/装备/突破）、技艺体系（炼丹/炼器/制符/制毒/傀儡）、探索行为（亲自下秘境）、生产行为（亲自炼丹/炼器）、个人资源。
- **管理线（宗门经营线）**：宗主作为最高管理者，通过管理层级（副宗主→峰主→堂主/殿主/阁主→普通弟子）间接管理宗门；弟子有自主行为；宗主可下达任务给弟子/管理层。

### 1.2 评估方法论

本次审计采用"代码实证法"，所有评估结论均基于实际代码读取，偏离设计处引用具体函数名和行号。评估维度：

1. **符合双线设计的部分**：已实现且支持双线愿景的代码
2. **偏离设计的部分**：具体代码/逻辑偏离双线设计之处
3. **缺失的部分**：双线设计需要但完全未实现的功能

新增评估维度（v2.0）：
4. **离线/闭关机制**：现有系统是否支持离线自动运转、副宗主代管理
5. **付费平衡**：现有付费点是否破坏平衡、时间流速是否统一
6. **策略深度与肝度**：现有系统是否有策略空间、是否支持长时间在线玩法

### 1.3 核心结论（TL;DR）

| 维度 | 现状 | 双线符合度 |
|------|------|-----------|
| 宗主角色化 | 宗主=名字+性别+头像+皮肤，**无任何修炼/技艺/资源数据** | 5% |
| 宗主修炼 | 完全不存在，突破/功法/境界系统仅作用于弟子 | 0% |
| 宗主生产 | 炼丹/炼器/制符均为宗门级操作，无宗主亲自生产入口 | 0% |
| 宗主探索 | 历练系统仅接受弟子ID列表，无宗主亲自前往选项 | 0% |
| 宗主资源 | 所有资源均为宗门公共资源，无宗主个人资源 | 0% |
| 管理层级 | 仅有殿阁负责人+弟子任职，**无副宗主/峰主层级** | 30% |
| 任务下达 | 宗门任务榜=挂榜自接+请命，**无宗主直接指派特定弟子** | 40% |
| 弟子自主AI | 目标驱动/性格/情绪/需求/私库/叛离，深度较好 | 80% |
| 生产模式 | 方针自动+手动批量，**无指派弟子生产模式** | 50% |
| 宗门战力 | 宗门总战力=弟子战力总和，宗主无战力贡献 | 20% |
| 离线/闭关 | 有离线推演+简报+月卡离线加成，**无闭关概念/副宗主代管理/权能范围** | 35% |
| 付费平衡 | 付费增益有上限设计，VIP仅外观，**但修炼加速/殿阁产出等付费点需审视** | 60% |
| 策略深度 | 弟子培养/方针/资源分配有策略空间，**宗主线零策略零肝度** | 40% |

**一句话总结**：当前游戏是一个"纯宗门管理模拟器"，宗主只是挂名UI头像，宗主线几乎完全缺失。管理线已具备相当深度（弟子AI、家族、派系、王朝、商队、离线推演），但管理层级扁平、任务下达不完整、宗主个人线为零。付费系统有上限意识但需细化边界，策略深度集中在管理线而宗主线空白。

## 三、逐系统双线评估

### 3.1 宗主角色系统（核心缺失）

#### 现状代码实证

```
game_state.gd L163-167:
  var 宗主名: String = "太虚道君"
  var 宗主性别: String = "男"
  var 宗主头像: String = ""
  var 当前宗主皮肤: String = ""
  var 已拥有宗主皮肤: Array = []
```

**宗主的全部数据只有5个变量**：名字、性别、头像ID、当前皮肤、已拥有皮肤列表。

#### 符合双线设计的部分

- 宗主有独立的名字/性别/头像/皮肤系统（L163-167）
- 宗主详情页UI已存在（`master_detail_page.tscn`，game_ui.gd L35/L403）
- 宗主头像系统较完善（L176-215），含初始可选+渠道解锁+宗门晋升解锁
- 宗主皮肤系统已实现（L3128-3218），含装备/卸下/获得/全宗加成

#### 偏离设计的部分

- **宗主无境界/修为**：game_state.gd中搜索`宗主境界`/`master_realm`均无结果。弟子有完整的`境界`(disciple.gd L364)、`修炼进度`(L375)、`层数`(L376)，宗主完全没有。
- **宗主无功法/装备/背包**：弟子有`已学功法`(L370)、`装备`(L388)、`背包`(L387)，宗主无对应字段。
- **宗主无技艺等级**：弟子有`炼丹等级`(L341)、`炼器等级`(L342)，宗主无对应字段。
- **宗主无资源**：所有资源（灵石L53、灵草L54、贡献点L79、悟道点L65）均为宗门公共变量。
- **宗主详情页是纯路由页**：game_ui.gd L304注释"宗主详情页：7权责按钮+编辑按钮（P0实装，路由到对应系统页/改名弹窗）"，无宗主个人属性面板。

#### 缺失的部分

- 宗主独立角色数据结构（境界/修为/功法/装备/技艺/资源/年龄/寿元）
- 宗主修炼界面、装备界面、技艺界面、个人背包
- 宗主个人资源账户（与宗门公共资源分离）
- **离线/闭关维度**：宗主无"闭关中"状态，无法区分在线管理与闭关修炼
- **策略/肝度维度**：宗主无任何可操作的个人玩法，零策略零肝度

- **全局战斗增益**：`_pay_reserved_全局增益`(L480)付费buff累加战斗通用增益——虽有25/30%封顶，但付费直接加战力需审视边界。
- **月卡离线加成**：月卡离线+20%（L1608）——离线资源加成，属于付费便利，不影响在线平衡，但需控制比例。

#### 缺失的部分

- 付费边界的明确文档化（哪些可以付费、哪些绝对不能付费）
- 宗主个人线的付费设计（宗主修炼加速/宗主技艺加速是否开放付费）
- 策略玩家与氪佬的差距量化评估
- 付费与策略的关系设计（付费节省时间但不能替代策略）

#### 核心问题

当前游戏的肝度集中在"管理操作"（批量派遣、批量生产、弟子管理），而缺少"角色操作"（宗主亲自做事情的即时反馈）。玩家上线后主要是"收菜+设置方针+批量操作"，然后又可以下线。这更接近"碎片化打卡"而非"深度沉浸模拟"。

#### 4.1.2 与弟子系统的解耦

| 维度 | 解耦方式 |
|------|---------|
| 修炼推进 | 月度推演中新增宗主修炼推进块，独立于弟子循环 |

| 技艺 | 宗主技艺等级独立存储，生产时作为"生产者"传入 |

#### 4.1.3 宗主修炼流程

1. **日常修炼**：月度推演中，宗主根据修炼速度推进`修炼进度`
2. **闭关修炼**：宗主可选择闭关（消耗灵石/时间，修炼速度×2-3，但期间无法管理宗门，由副宗主代管理）
3. **突破**：大圆满后可尝试突破，成功率受心境/道心/装备/功法/丹药影响
4. **渡劫**：元婴及以上突破需渡劫，复用tribulation.gd系统
5. **功法学习**：宗主消耗悟道点学习功法，与弟子共享功法库但独立进度

#### 4.1.4 宗主个人修炼界面

新增`page_master_cultivation.gd`，包含：宗主立绘+境界+修为进度条+突破按钮+功法列表+装备栏+技艺面板+个人背包+闭关按钮

#### 4.4.4 生产深度（肝度设计）

- **火候控制**：宗主亲自炼丹时可选择"稳火"/"急火"/"文火"，影响成功率/品质/速度
- **配方研究**：宗主可通过反复炼制同一配方领悟改良配方（更高品质/更少材料）
- **品质追求**：宗主亲自生产有概率产出"宗主亲炼"标签物品，价值更高
- **批量vs精炼**：批量生产效率高但品质一般；精炼（单次慢炼）品质更高但耗时

### 4.6 战力平衡设计（三种战力各自的影响与制衡）

#### 4.6.1 宗主个人战力

**定义**：宗主自身的境界/装备/功法/技艺/灵兽综合战力。

**影响范围**（严格限定，不可替代其他战力）：

| 场景 | 宗主个人战力的作用 | 不可替代性 |
|------|-------------------|-----------|
| 亲自探索高阶秘境 | 某些秘境设宗主最低境界门槛；宗主亲自去掉落品质+1档 | 弟子再强也进不了宗主专属秘境 |
| 镇压宗门内乱 | 弟子叛乱/派系政变时，宗主个人战力决定镇压成功率 | 弟子战力强但宗主弱时，叛乱可能成功 |
| 个人技艺加成 | 宗主炼丹/炼器等级高时，亲自生产成品品质更高 | 弟子技艺再高，宗主亲炼有"宗主亲炼"标签 |
| 外交威慑 | 宗主境界高时，与其他宗门/王朝外交威慑力强 | 宗门弟子强但宗主弱，外交时被轻视 |
| 突破护法 | 宗主为弟子护法时，宗主战力越高护法成功率加成越大 | sect_manager.gd L320已有"亲自护法+20%" |
| 宗门战争主将 | 宗门战争中宗主可作为主将出战，提供全局战力加成 | 弟子群体战之外，宗主是"定海神针" |
| 天劫威压 | 宗主渡劫引发天地异象，提升宗门声望 | 弟子渡劫不影响宗门声望 |
| 收徒品质 | 宗主境界高时，招募到的弟子资质上限提高 | 弟子强但宗主弱，招不到顶级人才 |

**设计原则**：宗主个人战力是"质"的代表——解决关键单点问题，但不能解决所有问题。宗主个人战力再强，也不能一个人打赢宗门战争，也不能替代宗门整体生产能力。

#### 4.6.2 宗门弟子战力

**定义**：所有弟子战力的总和/聚合。

**影响范围**：

| 场景 | 弟子战力的作用 | 不可替代性 |
|------|---------------|-----------|
| 宗门战争 | 宗门战争/领地战/阵营战役的主力 | 宗主一个人打不过敌方整个宗门 |
| 批量历练 | 同时派遣多支弟子队伍探索多个秘境 | 宗主一次只能去一个地方 |
| 日常巡逻/防御 | 山门巡逻、护山大阵值守、商队护卫 | 宗主不可能24小时巡逻 |
| 秘境争夺 | 多个秘境同时开放时，靠弟子群体战力抢占 | 宗主只能占一个 |
| 弟子独立任务 | 高难任务/调查任务/王朝差事 | 宗主不能分身 |
| 生产人力 | 丹堂/器堂需要弟子作为劳动力 | 宗主一个人产能有限 |

**关键设计：弟子可以比宗主境界高**

这是真实修真界常态，必须支持且产生玩法张力：

- **代码层面**：当前已无限制（disciple.gd境界可独立提升），保持现状
- **玩法层面**：弟子境界>宗主时触发：
  - **功高震主**：该弟子忠诚度每月-1~-3（桀骜/狂傲型减更多）
  - **派系坐大**：该弟子更容易成为派系领袖
  - **叛逃风险**：忠诚度<30时可能叛逃，带走装备/功法/私库
  - **挑战宗主**：忠诚度<20且境界>宗主2阶以上时，可能发起"夺位"挑战
  - **弟子服气值**：新增`对宗主服气值`，基于宗主战力/境界/技艺/威望综合计算
- **玩家策略**：可选择"宗主修炼流"（宗主强，弟子服气）或"宗门经营流"（宗主弱但管理强，靠制度/利益绑定弟子）

#### 4.6.3 宗门综合战力+技艺

**定义**：宗门整体实力，含弟子战力+殿阁等级+科技+阵法+资源储备+技艺水平。

**影响范围**：

| 场景 | 综合战力+技艺的作用 | 不可替代性 |
|------|-------------------|-----------|
| 产出质量数量 | 丹堂/器堂等级高→产出多且品质好 | 宗主个人炼丹再强，产能不如整个丹堂 |
| 宗门声望 | 技艺强的宗门吸引更多优秀弟子加入 | 宗主个人强不代表宗门能培养人才 |
| 外交筹码 | 高阶丹药/法宝作为外交资源 | 宗主个人藏品有限，宗门产能才是持续筹码 |
| 经济优势 | 高阶产品在拍卖行/坊市的利润 | 宗主个人消费不产生经济循环 |
| 宗门防御 | 护山大阵+驻守弟子+阵法堂等级 | 宗主个人守不住整个山门 |
| 传承延续 | 藏经阁+技艺传承+家族血脉 | 宗主陨落后，宗门技艺传承决定能否延续 |
| 赛季排名 | 玄榜/宗门大比/赛季评分基于综合实力 | 个人战力不影响宗门排名 |

#### 4.6.4 三种战力的平衡机制

**不可替代原则**：
```
宗主个人战力 → 解决"关键单点"问题（专属秘境、镇压、威慑、亲炼）
弟子战力     → 解决"规模数量"问题（战争、批量探索、人力）
综合战力+技艺 → 解决"持续发展"问题（经济、声望、传承、防御）
```

**相互促进机制**：
- 宗主强→弟子：宗主境界高→招募资质上限+；宗主技艺高→可收徒传艺；宗主威望高→弟子忠诚度+
- 弟子强→宗主：弟子产出高阶丹药→宗主突破可用；弟子探索获得功法→宗主可学
- 综合强→宗主：丹堂等级高→宗主炼丹成功率+；藏经阁丰富→宗主可选功法多
- 综合强→弟子：殿阁等级高→弟子修炼/生产效率+；科技树→全宗加成
- 宗主强→综合：宗主威望高→宗门声望+；宗主亲炼极品→宗门技艺评级+
- 弟子强→综合：弟子战力高→宗门战争胜→领地+资源+；弟子技艺高→殿阁产出+

**玩家策略分化**：

| 流派 | 核心投入 | 优势 | 风险 |
|------|---------|------|------|
| 宗主修仙流 | 宗主修炼/技艺/装备 | 专属秘境、高品质亲炼、外交威慑、弟子服气 | 宗门发展慢、弟子数量少 |
| 宗门经营流 | 弟子培养/殿阁升级/科技 | 规模大、经济强、综合战力高 | 宗主弱→功高震主、内乱风险 |
| 均衡流 | 双线并行 | 无明显短板 | 无明显长板，资源分散 |
| 技艺宗师流 | 宗主技艺+丹器阵殿阁 | 经济极强、外交筹码多 | 战力不足、易被掠夺 |

#### 4.7.4 转世/夺舍/身外化身机制

**推荐方案：转世重修 + 宗门传承 双轨并行**

**转世重修**（宗主个人线延续）：
- 触发：宗主寿元耗尽或陨落且无保命/替死
- 流程：灵魂保留记忆→转世为新身体（宗门新生婴儿/散修孩童/指定弟子子嗣）→初始练气，但保留前世记忆（功法领悟速度+50%）、前世技艺经验（保留50%）、前世道心/心境（保留80%）
- 丢失：境界/修为/装备/个人物品
- 代价：每转世一次"灵魂损耗"+1，修炼速度-5%（最多-30%）
- 冷却：转世后前10游戏年"魂体未稳"，突破成功率-20%

**宗门传承**（管理线延续）：
- 宗主陨落后，若有指定继承人则继位，无指定则副宗主暂代+议事会选举
- 玩家可选择：A.转世重修（继续扮演原宗主转世之身，变为"太上长老"/隐世前辈）或B.传承继位（扮演新宗主，继承宗门一切）
- 选择A：玩家不再是宗主，可继续修炼/炼丹/探索，可指导新宗主，修炼到一定境界可"重新出山"
- 选择B：玩家扮演新宗主，原宗主进入先贤堂

**身外化身**（高端选项）：
- 化神以上可修炼化身（消耗大量资源/时间），化身拥有本体50%战力
- 本体陨落后化身可作为"备用身体"接续（保留境界但战力衰减50%）

#### 4.7.5 寿命系统对玩法的影响

- **紧迫感**：练气-筑基期有一定紧迫感，金丹后大幅降低
- **修炼动力**：寿命将尽时角色更积极寻求突破
- **避免倒计时**：金丹500年≈200天现实，绝大多数玩家不会玩到寿终；延寿手段丰富；转世不结束游戏

| alchemy.gd 延寿丹药 | 已有基础，新增长生丹等 |
| tribulation.gd 渡劫系统 | 渡劫失败折损寿元 |

### 4.8 闭关/离线机制

#### 4.8.1 核心设定

**玩家下线 = 宗主闭关**：这是修真世界观的自然包装。闭关期间：
- 宗主进入"闭关"状态，修炼速度提升（闭关加成）
- 副宗主代为管理宗门（若已任命副宗主）
- 设定好的方针继续自动执行
- 弟子继续自主修炼/生产/历练
- 宗门正常运转

#### 4.8.2 闭关机制具体实现

**自动闭关/出关**：
- 玩家关闭游戏/切换后台→宗主自动进入"闭关"状态，记录`闭关开始日`
- 玩家重新上线→宗主自动出关，计算闭关期间修炼收益
- 闭关期间宗主修炼速度×1.5（基础闭关加成），可通过阵法/丹药/功法进一步提升

**闭关类型**（玩家可选择）：

| 闭关类型 | 修炼速度 | 管理状态 | 适用场景 |
|---------|---------|---------|---------|
| 清修闭关 | ×1.5 | 副宗主代管理 | 普通下线 |
| 深度闭关 | ×2.5 | 副宗主代管理，部分功能锁定 | 长时间离线（>24小时） |
| 冲击境界闭关 | ×3.0 | 完全锁定，仅紧急事件可打断 | 突破前准备 |
| 普通在线 | ×1.0 | 宗主亲自管理 | 在线游玩 |

#### 4.8.3 副宗主代管理体系

**权能范围设定**（玩家可在"闭关设置"中配置）：

| 事项 | 副宗主可代决 | 必须等宗主出关 |
|------|-------------|---------------|
| 日常资源分配 | ✅ | - |
| 弟子日常任务分配 | ✅ | - |
| 方针内自动生产 | ✅ | - |
| 弟子招募/辞退 | ✅（限额） | 核心弟子辞退需宗主批准 |
| 殿阁升级 | ✅（限额） | 新建殿阁需宗主批准 |
| 商队派遣 | ✅ | - |
| 宗门任务发布 | ✅ | - |
| 弟子任命（执事/堂主） | ✅ | 峰主/副宗主任命需宗主 |
| 对外宣战/结盟 | - | ✅ 必须宗主 |
| 宗门科技研究 | ✅ | - |
| 大型活动参与 | ✅ | - |
| 紧急事件处理 | ✅（先处理后汇报） | - |
| 宗门大额支出（>阈值） | - | ✅ 必须宗主 |

**代管理效率**：
- 副宗主能力（境界/管理技能/忠诚度）影响代管理效率
- 高能力副宗主：代管理效率=宗主亲自管理的90%~100%
- 低能力副宗主：代管理效率=60%~80%
- 无副宗主：离线期间仅方针自动执行，无主动管理决策

#### 4.8.4 方针自动执行的范围

**支持离线自动运转的系统**：
- 弟子修炼（月度推演驱动）
- 方针自动生产（炼丹/锻造/绘符，game_state.gd L7396已实现）
- 方针自动派遣历练（L7408已实现）
- 殿阁资源产出（灵田/矿脉/药园）
- 商队状态更新（到期结算）
- 弟子自主任务接取/执行（L13981已实现）
- 弟子月度事件（奇遇/突破/叛离检查）

**需要宗主在线的系统**：
- 宗主亲自修炼/生产/探索（闭关时只有自动修炼，无亲自操作）
- 宗主直接指派任务
- 重大外交决策（宣战/结盟）
- 紧急事件的抉择（可由副宗主代决，但结果可能非最优）
- 拍卖行手动竞拍（弟子可自动出价，但宗主手动策略更优）

#### 4.8.5 紧急事件推送机制

**事件分级**：

| 级别 | 事件类型 | 处理方式 | 通知方式 |
|------|---------|---------|---------|
| 一般 | 弟子突破/日常产出/普通奇遇 | 自动处理，上线后简报查看 | 上线简报 |
| 重要 | 弟子失踪/商队被劫/殿阁受损 | 副宗主代处理，上线后详细汇报 | 上线简报+红点 |
| 紧急 | 宗门被宣战/弟子叛乱/重大奇遇 | 推送通知玩家，可选择"立即上线处理"或"副宗主代处理" | 后台推送+邮件 |
| 致命 | 宗门被灭门危机/宗主洞府被袭 | 强制推送，游戏内暂停关键流程 | 强推送 |

**推送实现建议**：
- 利用系统通知（移动端）/桌面通知（PC端）
- 推送内容：事件标题+简要描述+可选操作（"立即处理"/"交由副宗主"）
- 玩家可在设置中配置推送级别（仅紧急/紧急+重要/全部关闭）

#### 4.8.6 闭关期间的收益/损耗

**收益**：
- 宗主闭关修炼收益（修炼速度×1.5~3.0）
- 宗门正常产出（弟子修炼/生产/历练/殿阁产出）
- 方针自动执行的所有收益

**损耗**：
- 闭关消耗灵石（基础消耗，可配置）
- 副宗主代管理可能产生非最优决策（资源浪费/机会损失）
- 紧急事件若未及时处理可能恶化

#### 4.8.7 与现有系统的结合点

| 现有系统 | 结合方式 |
|---------|---------|
| main.gd 推演至现在(L3875) | 闭关期间的时间推进复用现有离线推演 |
| main.gd _弹_离山简报(L1081) | 出关简报扩展为"闭关出关简报"，含宗主修炼收益+宗门运转情况+副宗主代管理汇报 |

| disciple.gd 弟子自主AI | 闭关期间弟子继续自主行为（已实现） |

### 4.9 时间流速与付费平衡

#### 4.9.1 时间流速统一机制

**现状**：`现实秒每游戏日=240`（game_state.gd L47），在线/离线使用同一套`推演至现在()`逻辑。

**保持原则**：
- 在线和离线时间流速**绝对一致**，这是模拟游戏的铁律
- 不允许"在线加速"或"离线减速"
- 付费可以加速**特定操作**（如立即完成某次炼丹），但不能加速**全局时间流速**
- 月卡/季卡的"离线加成"是**资源产出加成**，不是时间流速加成

**时间推进逻辑**：
```
玩家上线 → 计算离线时长（现实秒） → 转换为游戏日 → 推演至现在()
         → 宗主闭关修炼收益 + 宗门运转结算 + 离线简报
玩家在线 → 每240现实秒推进1游戏日 → 日度结算 → 月度结算
```

#### 4.9.2 付费设计的边界

**可以付费的（便利/外观/时间节省）**：

| 类别 | 具体内容 | 边界说明 |
|------|---------|---------|
| 外观 | 宗主皮肤、弟子皮肤、宗门幻形、头像、特效 | 纯外观，零数值影响 |
| 便利 | 一键收取、批量操作、背包扩容、自动挂机设置 | 节省操作时间，不影响数值 |
| 时间节省 | 立即完成某次炼丹/锻造/孵化、立即领取殿阁产出 | 跳过等待，但不增加产出总量 |
| 额外次数 | 历练额外次数、商队额外次数 | 增加玩法机会，但有上限 |
| 离线便利 | 月卡离线资源加成、离线上限延长 | 不影响在线平衡，比例受控 |
| 付费活动 | 战令、限时礼包、活动通行证 | 奖励为资源/外观，不直接加战力 |

**绝对不能付费的（核心数值/战力/境界）**：

| 类别 | 说明 |
|------|------|
| 境界/修为 | 不能直接购买境界或修炼进度（"立即完成N天修炼"需重新审视） |
| 核心战力 | 不能直接购买战力/装备/法宝（可购买材料但需自己生产） |
| 弟子品质 | 不能直接购买顶级弟子（可增加招募次数/刷新，但资质随机） |
| 突破成功率 | 不能直接购买突破成功（可购买辅助丹药，但成功率有上限） |
| 核心资源 | 不能直接购买灵石/灵草等核心资源（可通过礼包获得少量，但不可无限购买） |
| 策略优势 | 不能购买"必胜""自动最优决策"等破坏策略的功能 |

#### 4.9.3 现有付费点审视与调整建议

- 商队收益+15%
- 专属头像

**永久卡（道统卡）**：
- 季卡全部权益
- 永久皮肤
- 终身日供翻倍
- 离线上限24小时（原设计）
- 专属称号

**设计原则**：月卡/季卡/永久卡的权益集中在**便利和资源加成**，不直接加战力。加成比例控制在15%~25%，且不叠加超过30%。

#### 4.9.5 付费与策略的关系

**核心原则：付费节省时间，但不能替代策略。**

- 氪佬可以更快获得资源/更高品质材料，但**生产配方优化、弟子培养路线、战斗阵容搭配、贸易时机选择**等策略层面的优势是付费买不到的
- 策略玩家通过深入理解机制，可以在相同资源下获得更高产出（如：优化方针减少浪费、选择高性价比配方、利用行情套利、培养互补型弟子团队）
- 设计"策略溢价"：某些高收益玩法（如商队贸易套利、拍卖行低买高卖、秘境路线优化）需要玩家理解机制才能获得高收益，单纯付费无法自动获得最优解
- 付费玩家与策略玩家的差距控制在：付费玩家进度快30%~50%，但策略玩家可以通过优化缩小到10%~20%

### 4.10 策略向与肝度设计

#### 4.10.1 策略深度的体现

**已有策略空间（深化方向）**：

| 系统 | 现有策略 | 深化方向 |
|------|---------|---------|
| 弟子培养 | 资质/灵根/道途选择 | 弟子团队搭配（道途互补/性格互补/血脉联动）、功法build优化、装备词条搭配 |
| 方针设定 | 修炼风格/风险偏好/供给阈值 | 多方针方案切换（战争期/发展期/休养生息期）、阈值精细化管理 |
| 资源分配 | 灵石/贡献点分配 | 资源调度策略（短期收益vs长期投资）、宗主个人资源vs宗门资源的博弈 |
| 历练探索 | 路线选择/队伍配置 | 秘境层数策略、风险收益权衡、宗主亲自vs派遣的选择 |
| 生产系统 | 配方选择 | 产能分配（哪些丹药自己炼/哪些买）、品质追求策略、订单优先级 |
| 商队贸易 | 路线/货物选择 | 行情套利（低买高卖）、商单优化、黑市利用、贸易路线垄断 |
| 派系管理 | 忠诚度/核心弟子 | 派系平衡术、管理者任命策略、权能分配、功高震主的防范 |
| 管理层级 | 人事任命 | 峰/殿架构设计、管理者能力搭配、代理管理效率优化 |

**新增策略空间（宗主线）**：

| 系统 | 策略内容 |
|------|---------|
| 宗主修炼 | 修炼路线选择（稳扎稳打vs激进突破）、功法搭配、闭关时机 |
| 宗主技艺 | 技艺专精选择（炼丹/炼器/制符主修哪个）、配方研究优先级 |
| 宗主探索 | 亲自探索vs派遣的决策、专属秘境攻略、战斗战术选择 |
| 宗主资源 | 个人资源与宗门资源的调度、个人物品捐献时机 |
| 双线平衡 | 投入宗主线还是管理线的资源分配决策 |

#### 4.10.2 "肝"的设计

**玩家长时间在线可以做什么**：

**宗主个人操作（新增核心肝度）**：
1. **宗主亲自炼丹/炼器**：选择配方→控制火候→追求品质→研究改良配方，每次操作有即时反馈（成功/失败/品质/领悟）
2. **宗主亲自探索秘境**：进入秘境→选择路线→遭遇事件→实时选择分支→战斗战术选择→获得战利品，持续反馈
3. **宗主闭关修炼**：在线时可选择"在线修炼"（比闭关慢但可同时管理），观察修为增长
4. **宗主技艺训练**：通过反复生产提升技艺等级，有明确的经验条和等级提升反馈

**管理微操（深化现有肝度）**：
5. **弟子任务微操**：逐个弟子查看状态→分配最合适的任务→调整任务优先级→查看执行进度
6. **生产优化**：查看库房→选择最优配方→批量生产→品质筛选→出售/留用决策
7. **贸易套利**：查看坊市行情→低买高卖→商队货物配置→利用行情波动获利
8. **弟子互动**：与弟子互动提升忠诚度/好感度、指导弟子修炼、调解弟子矛盾
9. **方针调优**：根据当前状态微调方针参数、切换发展方案

**收集/研究（中长期肝度）**：
10. **配方/丹方收集**：通过领悟/购买/秘境获得新配方，完善配方库
11. **图录/收藏**：收集丹药/装备/符箓图鉴，追求全收集
12. **功法研究**：学习/升级功法，研究功法搭配和词条优化
13. **弟子培养**：精心培养核心弟子，追求极致build

#### 4.10.3 持续反馈机制

**即时正反馈（秒级~分钟级）**：
- 宗主炼丹：每次炼丹立即显示成功/失败/品质/纹数/领悟
- 宗主探索：每个事件立即显示选择结果，每场战斗立即显示战报
- 弟子互动：每次互动立即显示忠诚度/好感度变化
- 生产操作：每次生产立即显示产出和经验增长

**中期反馈（小时级）**：
- 技艺等级提升：累计经验后升级，显示新能力解锁
- 弟子突破：弟子突破成功时弹出通知
- 商队归来：商队到期结算，显示收益
- 秘境通关：秘境首通显示奖励和评级

**长期反馈（天级~周级）**：
- 宗主境界突破：修为积累后的大里程碑
- 宗门等级提升：综合实力增长后的阶段性反馈
- 赛季结算：宗门战争/玄榜的周期性反馈
- 七载大典：长期叙事性反馈

#### 4.10.4 成长感设计

**双重成长曲线**：

| 维度 | 宗主个人成长 | 宗门成长 |
|------|------------|---------|
| 短期（天） | 技艺经验增长、修为进度、单次生产高品质 | 弟子突破、资源积累、殿阁产出 |
| 中期（周） | 境界突破、功法升级、技艺等级提升 | 宗门等级、殿阁升级、弟子团队成型 |
| 长期（月） | 大境界跨越、专属秘境通关、技艺宗师 | 宗门声望、领地扩张、赛季排名、传承 |

**成长感的关键**：
- 宗主个人成长让玩家感受到"我在变强"
- 宗门成长让玩家感受到"我的宗门在壮大"
- 两条线的成长相互促进（宗主强→宗门强→资源多→宗主更强）
- 每个操作都有可见的数值/进度变化，不是"石沉大海"

#### 4.10.5 与碎片化打卡的区别

**为什么这个游戏不是"上线5分钟做完日常就下线"**：

1. **宗主个人线提供持续操作内容**：宗主亲自炼丹/探索/修炼是可以持续进行的，不是"做完就没了"的日常任务
2. **策略深度需要时间研究**：配方优化、贸易套利、弟子搭配需要玩家深入理解和反复尝试
3. **生产/探索有随机性和追求空间**：高品质产出、稀有领悟、秘境隐藏内容提供反复挑战的动力
4. **管理线有持续的决策需求**：弟子状态不断变化，方针需要根据情况调整，不是"设置一次就永远不用管"
5. **离线与在线互补**：离线时宗门自动运转（收菜），在线时玩家做"只有在线才能做的事"（宗主亲自操作、策略调优、微操管理），两者不重复
6. **长线目标驱动**：宗主境界提升、宗门壮大、赛季排名、收藏图鉴等长线目标提供持续游玩动力

**在线vs离线的分工**：
- **离线**：宗门自动运转，弟子自主修炼/生产/历练，方针自动执行→上线收菜
- **在线**：宗主亲自操作（炼丹/探索/修炼）、策略调优（方针/配方/贸易）、管理微操（任务分配/弟子互动）→深度沉浸

### 4.11 两条线的资源交互设计

#### 4.11.1 资源双轨制

| 资源类型 | 宗主个人 | 宗门公共 | 流转规则 |
|---------|---------|---------|---------|
| 灵石 | 宗主个人灵石 | 宗门灵石 | 宗主可从宗门支取（限额）；可捐入宗门（+贡献+威望） |
| 物品 | 宗主储物戒 | 宗门库房 | 宗主亲自获得→个人；弟子获得→宗门；宗主可支取/捐献 |
| 贡献点 | 宗主个人贡献 | - | 宗主通过捐献/完成宗门目标获得 |
| 悟道点 | 宗主学习消耗 | 藏经阁产出 | 悟道点为宗门公共资源，宗主和弟子都消耗同一池 |
| 技艺经验 | 宗主个人技艺 | 弟子个人技艺 | 各自独立 |

#### 4.11.2 资源交互场景

1. **宗主炼丹**：消耗个人材料→产出个人物品→可捐宗门换贡献
2. **宗主历练**：获得个人战利品→稀有留用，普通捐宗门
3. **宗主支取**：从宗门库房取材料炼丹/取装备穿戴（每月限额，超额需副宗主审批）
4. **弟子产出**：弟子炼丹/历练产出→宗门库房→宗主可支取使用
5. **宗主赏赐**：宗主将个人物品赏赐给弟子→弟子忠诚度+，宗主威望+
