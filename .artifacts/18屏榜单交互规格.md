## 3. 信息架构
```
玄榜
├ 顶部分类栏：个人修士榜(激活) / 宗门势力榜
├ 子分类页签：功勋(激活) / 战神 / 探索 / 商道 / 名望
├ 范围切换：本服(激活) / 赛区 / 全服
└ 榜单列表
   ├ 前三名：冠(金高亮) / 亚 / 季（立绘/徽章，金色高亮+流光）
   ├ 其他排名（第 12/28/35/41 名 + 称号标识）
   └ 自身排名（#42 太玄宗·高亮底色 + 追赶提示）
```

## 4. 交互规则
- **分类切换**：个人/宗门 Tab、子分类 chip、范围（本服/赛区/全服）三栏联动过滤。
- **行点击**：GDD §7.2④ 任意玩家/宗门弹「详情弹窗」（基本信息/称号/成就徽章墙/核心数据/操作按钮）——本稿未画该弹窗，列为后续。
- **自身排名**：默认定位玩家自身，高亮底色（画布用 `#182D37`），上下展示相邻名次 + 差距提示。
- **前三展示**：冠亚季军金色高亮（画布以名次文本金色 + 卡片底色区分示意，真实流光特效待实装）。
