# 《太玄宗门录》风云榜（排名系统）设计

> 版本：v1.0 ｜ 来源：2026-07-18 用户投稿底稿（见 `design/03-系统设计/_inbox/2026-07-18_投稿_新手引导与风云榜.md` §19 归位整理）｜ 用途：风云榜（排名系统）开发依据
> 体系对齐：成就系统全量配置、称号 / 外观体系、五大阵营设定、全局成长线（`design/01-总纲/太玄宗门录_核心设定总览.md`）。
> 守铁律：**单一数据源原则**——所有排名得分完全基于现有成就、战斗、经营系统的业务字段，不新增独立数值源，不设第二套计价体系；排名奖励以荣誉、外观、特权为主，不突破全局数值乘区上限。
> 全局红线：正文统一使用正式名《太玄宗门录》；严禁在数值 / 配置 / 正文出现对外宣传名；全部数值保留整数，未做"优化"改写；本系统依赖但 design/ 暂无 GDD 的系统见 §十。

## 一、定位与世界观包装

### 1.1 设定背景

玄洲风云榜，由玄洲正道盟牵头、五大阵营共同核定，碑石立于中州灵域核心，收录全洲修士与宗门的功绩、实力、财富、名望，每月由各方势力共同核验更新，是玄洲地界最权威的实力排名。玩家宗门所在的青峰山脉虽偏居一隅，但修士功绩、宗门实力会自动录入榜单，随成长逐步提升排名，最终可跻身全洲前列。

### 1.2 核心设计原则

1. **荣誉优先，数值为辅**：排名核心价值是身份荣誉与展示特权，奖励以限定称号、专属外观、效率特权为主，不投放大额数值属性，避免排名造成严重内卷与数值失衡。
2. **全维度覆盖**：榜单对应所有核心玩法与成就分类，成长、战斗、探索、经营、社交均有对应排名，满足不同类型玩家的目标感。
3. **强联动闭环**：深度绑定成就系统与称号系统，排名得分源于成就，排名奖励反哺称号 / 成就，形成「玩法 → 成就 → 排名 → 称号 → 强化目标」的完整闭环。
4. **赛季制长线运营**：常驻总榜 + 赛季榜结合，常驻榜承载长线荣誉，赛季榜提供短期目标，持续激活玩家活跃度。

## 二、榜单分类体系

分为「个人修士榜」与「宗门势力榜」两大类，每类下设总榜、分类榜、赛季榜，全部榜单均支持「本服 → 赛区 → 全服」三级范围切换查看。

### 2.1 个人修士榜

**常驻总榜：**

| 榜单名称 | 核心排名依据 | 对应成就分类 | 目标用户 |
|---|---|---|---|
| 玄洲功勋总榜 | 成就总加权点数（普通 ×1 / 稀有 ×3 / 传说 ×10） | 全品类成就 | 全量玩家，通用核心排名 |
| 修为成长榜 | 弟子最高境界 + 成长类成就加权 | 成长类成就 | 养成向玩家 |
| 玄洲战神榜 | PVE/PVP 总战绩 + 战斗类成就加权 | 战斗类成就 | 硬核战斗玩家 |
| 问道探索榜 | 地图探索度 + 奇遇数量 + 探索类成就加权 | 探索类成就 | 剧情 / 探索玩家 |
| 商道致富榜 | 累计灵石收入 + 经营类成就加权 | 经营类成就 | 经营 / 商业玩家 |
| 四海名望榜 | 五大阵营声望总和 + 社交类成就加权 | 社交 / 阵营成就 | 社交向玩家 |

**赛季限时榜**（每月 1 号重置，当月最后 1 天结算，投放赛季限定奖励，是短期活跃度的核心抓手）：

- 月度功勋竞速榜：本月新增成就点数排名
- 论剑赛季榜：PVP 论剑段位积分排名
- 秘境竞速榜：当月秘境通关最快速度排名
- 商道赛季榜：当月商路总收益排名

### 2.2 宗门势力榜

所有宗门榜为集体排名，奖励发放给全宗门成员，强化宗门凝聚力：

| 榜单名称 | 核心排名依据 | 对应玩法 |
|---|---|---|
| 宗门实力总榜 | 宗门等级 + 弟子平均境界 + 宗门成就总加权 | 宗门综合成长 |
| 宗门战积分榜 | 宗门战赛季积分 + 胜率 | 宗门战 PVP |
| 宗门财富榜 | 宗门公共资产累计值 + 产业总产出 | 宗门经营 |
| 联盟势力榜 | 联盟宗门数量 + 总实力 + 通商收益 | 宗门社交 |

## 三、核心排名规则

### 3.1 排序优先级（三级）

所有榜单采用「核心指标 → 次位指标 → 达成时间」三级排序规则，避免并列争议，杜绝刷低级内容冲榜：

1. **第一优先级**：核心加权数值（如功勋总榜的总加权点数）。
2. **第二优先级**：高阶内容数量（如传说成就数量、秘境通关层数）。
3. **第三优先级**：首次达成当前数值的时间，先达成者排名靠前。

> 示例（玄洲功勋总榜排序逻辑）：总加权点数 → 传说成就数量 → 稀有成就数量 → 首个达到当前点数的时间戳。

### 3.2 双轨点数体系（底层数据同源、上层用途分离）

排名系统核心得分 100% 读取成就系统原生字段，通过事件回调实时同步，不单独维护统计数据，从根源保证数据一致性；一套点数服务成长福利（成就原生点数），一套点数服务榜单排序荣誉（排名加权功勋分），各司其职。

**（1）核心定义：**

| 指标名称 | 归属系统 | 作用 | 取值来源 |
|---|---|---|---|
| 成就原生点数 | 成就系统 | 累计解锁里程碑奖励 | 配置表 point_num 字段，普通 10 / 稀有 30 / 传说 100 |
| 加权功勋分 | 排名系统 | 榜单排序的核心依据 | 成就原生点数 × 等级权重系数 × 场景系数 |
| 补正分 | 排名系统 | 分类榜的次要排序依据 | 对应玩法系统原生字段（如境界、击杀数） |

**（2）等级权重系数（同源，沿用成就系统原有等级权重，不新增独立计价）：**

| 成就等级 | 原生点数 | 等级权重系数 | 单成就计入排名得分 |
|---|---|---|---|
| 普通成就 | 10 | 1 | 10 |
| 稀有成就 | 30 | 3 | 90 |
| 传说成就 | 100 | 10 | 1000 |

> 设计逻辑：1 个传说成就等价于 100 个普通成就（1000 分 vs 10 分），大幅拉高高阶内容的排名权重，从规则上杜绝「刷低阶成就冲榜」行为，引导玩家追求深度玩法。

**（3）核心公式：**

> 总加权分 = Σ（单成就原生点数 × 等级权重系数 × 场景系数） + 补正分

**（4）场景系数（区分常驻榜 / 赛季榜计入比例）：**

| 成就类型 | 常驻总榜系数 | 赛季榜系数 | 设计逻辑 |
|---|---|---|---|
| 常驻永久成就 | 1.0 | 1.0 | 全额计入所有榜单 |
| 赛季限时成就 | 0.5 | 1.0 | 赛季内全额算排名；赛季结束后仅 50% 计入常驻总榜，既保赛季活跃度，又不破坏长期公平 |
| 隐藏 / 彩蛋成就 | 1.0 | 1.0 | 全额计入，鼓励探索 |
| 交易 / 购买类成就 | 0.5 | 0.5 | 靠花钱就能达成的成就权重减半，避免氪金碾压排名 |

> ⚠️ **CONCERN-01（C-N1，高优先，待主理人终裁）**：§19.3.2 旧表述写「赛季限时成就：权重系数 2（仅计入赛季榜，不计入常驻总榜）」，与上方场景系数模型「赛季限时成就 常驻系数 0.5 / 赛季系数 1.0」直接冲突（系数 2 vs 0.5/1.0）。本 GDD 正文**采用详细计分版（0.5/1.0）为权威口径**，旧「系数 2」表述留待主理人终裁是否删除。详见 §十一 CONCERN-01。

### 3.3 分类榜补正分（占比 ≤ 10%）

分类榜仅统计对应分类的成就得分，搭配少量玩法补正分，补正分占比最高不超过总分的 10%，核心排序依据仍为成就：

> 分类榜得分 = 对应分类成就加权分 × 90% + 玩法补正分 × 10%

| 分类榜单 | 补正字段（读取原生系统） | 补正逻辑 |
|---|---|---|
| 修为成长榜 | 掌门最高境界、弟子平均境界 | 境界每高一个大等级，补正分 +50 |
| 玄洲战神榜 | 累计击杀数、秘境最高层数 | 每多 10 万击杀 / 10 层秘境，补正分 +30 |
| 问道探索榜 | 全地图探索度、奇遇触发数 | 探索度每满 1 张地图，补正分 +20 |
| 商道致富榜 | 累计灵石收入、建筑满级数 | 每满 100 万收入，补正分 +40 |
| 四海名望榜 | 五大阵营总声望、好友数量 | 每满 1000 总声望，补正分 +25 |

> 补正字段均直接读取对应系统的原生业务字段，不新增参数。

### 3.4 边界场景计分处理

| 边界场景 | 计分规则 |
|---|---|
| 成就回收 / 撤销 | 扣除对应全部加权得分，榜单实时同步更新 |
| 成就补发 / 补领 | 到账当日计入得分，不回溯时间戳，不影响历史排名 |
| 单日得分上限 | 普通成就单日计入排名上限 50 分，超出部分不计；稀有 / 传说无上限 |
| 新账号保护期 | 注册 7 天内的账号不计入全服榜单，仅本服可见，防止工作室小号冲榜 |
| 违规刷分处罚 | 扣除对应违规成就得分，严重者清零赛季排名，永久取消上榜资格 |

## 四、与成就系统深度联动

排名系统完全以成就系统为底层数据基础，联动覆盖「计分底层、分类对应、详情展示、反向触发、赛季绑定」五个维度，形成双向闭环。

### 4.1 计分底层同源：单一数据源零额外开发

- 所有排名得分直接读取成就系统的 `achievement_point` 字段，按固定权重自动计算，排名系统不单独维护统计数据，从根源保证数据一致性。
- 成就的新增、回收、补发，自动同步到排名得分，无需单独处理，避免数据不同步的 bug。
- 同步机制：成就达成 / 回收的瞬间，自动抛出事件，排名系统异步更新得分，每 5 分钟同步到榜单；每次进入排行榜自动校验成就总点数，避免「成就已达成、排名未更新」异常。

### 4.2 分类榜精准对应：每类榜单匹配一类成就

- 成长榜 = 成长类成就总加权 + 弟子境界数值补正
- 战神榜 = 战斗类成就总加权 + PVE/PVP 战绩补正
- 探索榜 = 探索类成就总加权 + 探索度 / 奇遇数补正
- 经营榜 = 经营类成就总加权 + 产业 / 财富数值补正
- 社交榜 = 社交类成就总加权 + 阵营声望数值补正

> 补正数值均读取对应系统的原生字段，不新增独立参数。

### 4.3 榜单详情联动：成就墙同步展示

- 点击榜单任意玩家头像，弹出详情页，包含：基本信息、当前佩戴称号、成就徽章墙（展示已解锁的传说 / 稀有成就）、核心成就完成率。
- 传说成就数量在榜单列表直接外露，作为玩家实力的直观标识，强化成就的收藏与展示价值。

### 4.4 反向成就触发：排名里程碑计入成就体系

排名进度本身对应成就系统的「社交 / 战斗类成就」，形成双向闭环：

| 对应成就 ID | 成就名称 | 达成条件 | 成就等级 |
|---|---|---|---|
| ach_rank_001 | 初登风云榜 | 首次进入任意榜单前 1000 名 | 普通 |
| ach_rank_002 | 百名之列 | 进入本服功勋总榜前 100 名 | 普通 |
| ach_rank_003 | 玄洲前十 | 进入全服功勋总榜前 10 名 | 稀有 |
| ach_rank_004 | 榜首独尊 | 登顶任意榜单全服第一 | 传说 |
| ach_rank_005 | 赛季之王 | 拿下任意赛季榜冠军 | 稀有 |
| ach_rank_006 | 三榜同魁 | 同时登顶成长、战斗、经营三类榜单 | 传说 |

> 排名成就的点数正常计入总功勋池，进一步强化排名的目标感；但控制成就数量与强度，避免无限叠加滚雪球。

### 4.5 赛季内容联动：赛季成就 = 赛季榜核心依据

- 每个赛季新增的限时成就，直接作为赛季功勋榜的计分依据；赛季结束后成就绝版，对应赛季榜也同步封存，成为永久荣誉记录。
- 赛季成就与赛季榜同步更新，无需额外开发配置，支撑长线内容迭代。

## 五、与称号系统联动

排名奖励完全接入现有称号体系，形成「排名档位 → 称号品级 → 展示体系」的完整链路，称号是排名奖励的核心载体，区分永久成就称号与限时排名称号，互补不冲突。

### 5.1 档位对应：排名层级匹配称号品级

严格对齐称号的「普通 / 稀有 / 传说」三级体系，不同排名档位对应不同品级的称号：

| 排名区间 | 称号品级 | 获取规则 | 有效期 |
|---|---|---|---|
| 全服第 1 名 | 传说级 | 赛季结算发放 | 本赛季内有效 |
| 全服 2-10 名 | 稀有级 | 赛季结算发放 | 本赛季内有效 |
| 全服 11-100 名 | 稀有级 | 赛季结算发放 | 本赛季内有效 |
| 本服前 10% | 普通级 | 每日结算自动激活 | 保持排名期间有效 |

### 5.2 全榜单专属称号配置

每个榜单对应独立的专属称号，命名贴合修仙世界观，无重复感：

| 榜单名称 | 榜首传说称号 | 前十稀有称号 |
|---|---|---|
| 功勋总榜 | 玄洲道尊 | 功勋卓著 |
| 战神榜 | 上古战神 | 百战百胜 |
| 探索榜 | 万宝阁主 | 寻幽探秘 |
| 财富榜 | 陶朱再世 | 日进斗金 |
| 名望榜 | 四海皆友 | 故交遍天下 |
| 宗门实力榜 | 玄洲第一宗 | 威震一方 |
| 宗门战榜 | 宗门之巅 | 常胜之师 |

### 5.3 展示体系共用：一套体系双类称号

- 排名称号与成就永久称号共用同一套佩戴、展示系统，玩家可同时佩戴「1 个永久成就称号 + 1 个限时排名称号」，分别展示在不同位置，兼顾永久荣誉与赛季荣誉。
- 所有排名称号附带专属聊天气泡、名字框、头像框，和外观体系打通，满足玩家的社交展示需求。

### 5.4 隐藏称号彩蛋：成就 + 排名组合解锁

特定成就条件 + 排名名次组合，可解锁隐藏传说称号，强化深度玩家的专属感：

- **「万道独尊」**：集齐全部成就 + 登顶功勋总榜，解锁隐藏传说称号，附带专属流光特效。
- **「太玄正统」**：宗门命名为太玄宗 + 宗门实力榜登顶，解锁宗门专属隐藏称号与山门特效。
- **「不败传说」**：论剑赛季 100 连胜 + 登顶战神榜，解锁隐藏 PVP 专属称号。

## 六、阵营排名

阵营排名作为独立子体系加入，总榜规则不受影响，新增阵营内部榜与阵营势力榜两类子榜单，展示层新增阵营维度的分类与风格差异化，深度绑定阵营声望与阵营成就，完全贴合五大阵营世界观。

### 6.1 两类阵营榜单（规则独立，不冲突总榜）

| 榜单类型 | 排名依据 | 更新频率 | 对应玩法 |
|---|---|---|---|
| 阵营内部榜 | 对应阵营内玩家 / 宗门的成就加权分 + 阵营声望 | 实时更新 | 阵营成长、阵营任务 |
| 阵营势力总榜 | 五大阵营各自的总实力、总声望、总战绩 | 每日更新 | 阵营攻防战、阵营博弈 |

- **阵营内部榜**：每个阵营单独排名，仅统计加入该阵营的玩家，排名依据为「对应阵营成就加权分（60%）+ 阵营声望值（40%）」，给阵营内玩家明确的身份与目标。
- **阵营势力总榜**：五大阵营整体实力 PK，按全服所有阵营成员的总贡献、总战绩、总声望综合排名，对应主线阵营博弈设定，影响阵营剧情走向与全服阵营福利。

### 6.2 阵营排名的专属规则

1. **阵营门槛**：仅加入对应阵营、声望达到友善及以上的玩家，才可进入该阵营内部榜；中立玩家不参与任何阵营排名。
2. **对立阵营屏蔽**：对立阵营的玩家不可互相查看对方阵营榜的详细信息，仅可查看势力总榜的排名，强化正邪对立的阵营设定。
3. **阵营排名奖励**：
   - 内部榜前列奖励：阵营专属称号、阵营商店额外折扣、阵营专属道具，仅可在阵营内使用，不影响全局平衡。
   - 势力总榜优胜奖励：赛季结束后，排名第一的阵营全服成员发放阵营福利（buff、材料、声望），强化阵营集体荣誉感。
4. **总榜不受影响**：阵营排名为独立子体系，所有得分仅在阵营榜内生效，不影响功勋总榜的计分规则，总榜仍以全成就加权分为唯一依据，避免多套计分造成第二数值原点。

### 6.3 与成就系统的联动补充

- 新增「阵营专属成就」，仅加入对应阵营的玩家可解锁，计入对应阵营榜得分，同时正常计入总榜得分。
- 新增「阵营贡献成就」，按阵营贡献值分档达成，是阵营内部榜的核心得分项，强化阵营玩法的目标感。

### 6.4 展示层阵营内容（差异化风格）

- **界面结构**：榜单顶部增加「总榜 / 阵营榜」一级页签，切换到阵营榜后，二级页签对应五大阵营（正道盟 / 散修盟 / 丹器师公会 / 玄幽魔宗 / 万灵古族）；每个阵营榜单采用对应阵营视觉风格（正道盟金白正气、散修盟青灰潇洒、丹器公会棕褐沉稳、玄幽魔宗暗紫邪魅、万灵古族青绿灵动）。
- **列表标识**：总榜每条排名增加阵营徽标，中立玩家显示「无门无派」；阵营内部榜展示玩家阵营职位（普通弟子 / 核心弟子 / 长老 / 供奉），与阵营声望等级绑定。
- **详情页扩充**：玩家详情页新增「阵营信息」板块（所属阵营、声望等级、阵营职位、阵营贡献值、阵营成就完成率）；阵营势力总榜详情页展示该阵营总人数、总声望、战绩胜率、代表玩家及当前赛季福利。
- **专属称号（阵营榜首）**：正道盟第一「正道首座」、散修盟第一「逍遥盟主」、丹器公会第一「丹器圣手」、玄幽魔宗第一「魔宗圣子 / 圣女」、万灵古族第一「万灵少主」；榜首在对应阵营 NPC 处有特殊交互待遇，解锁专属对话彩蛋（阵营 NPC 引用见 `GDD-新手引导.md` §五，待 lore 角色表确认）。

## 八、公平性与防刷

采用「规则层前置约束 + 技术层实时拦截 + 运营层人工审核 + 数据层追溯回收」四层闭环，从根源、过程、结果全链路防控刷分行为，确保公平性可落地、可验证、可追溯。

### 8.1 规则层：前置规则约束，从根源抬高刷分成本

1. **单日得分上限**：普通成就单日计入排名的得分上限为 50 分，超出部分不计入排名；稀有、传说成就无单日上限。目的：限制玩家批量刷低阶普通成就冲榜，引导玩家追求高阶内容，同时不影响正常玩家成长节奏。
2. **高阶权重倾斜**：传说成就权重为普通的 10 倍（得分倍数 100 倍），低阶成就刷量性价比极低，正常推进玩法的玩家排名天然高于纯刷低阶的玩家。
3. **境界分段排名**：所有个人榜按大境界分段（练气 / 筑基 / 金丹 / 元婴），同境界玩家共同排名，既避免新手被高阶玩家碾压，也防止高玩开小号去低分段刷榜。
4. **可交易道具成就限制**：通过购买、交易获取道具达成的成就（如收集类、图鉴类），权重减半计入排名（系数 0.5）；玩法类、操作类成就（如无伤通关、极限反杀）全额计入，引导靠实力而非财力冲榜。
5. **新账号保护期**：注册 7 天内账号不进入全服榜单，防止工作室小号冲榜。

### 8.2 技术层：实时风控拦截，自动识别异常行为

**异常行为判定规则：**

| 异常类型 | 判定标准 | 触发处理 |
|---|---|---|
| 短时间批量达成 | 1 小时内达成超过 20 个普通成就 | 自动冻结排名权限，触发人工审核 |
| 同 IP 多账号联动 | 同 IP 下 5 个以上账号互刷成就 / 道具 | 关联账号全部暂停排名资格 |
| 道具倒货刷成就 | 短时间内频繁交易同类型道具刷收集成就 | 扣除对应成就得分，回收排名 |
| 漏洞异常触发 | 通过 bug 触发的非正常成就 | 自动回收成就与对应排名分 |
| 数据不一致 | 排名得分与成就总点数差值 ＞ 5% | 自动校准修正，标记异常账号 |

- **数据一致性校验**：每小时自动全量校验排名得分与成就系统数据，出现差值自动修正，确保两边完全一致，杜绝卡数据刷分。
- **设备与账号风控**：新注册账号 7 天内不进入全服榜单；设备异常、频繁换号的账号，自动标记为高风险，排名暂不展示。

### 8.3 运营层：人工审核 + 申诉通道，处理边界场景

1. **分级巡检机制**：全服榜前 100 名每日人工巡检，核查成就达成路径是否正常；赛季榜前 10 名每 3 天复核一次；玩家举报 24 小时内完成核查反馈。
2. **玩家申诉通道**：对排名、处罚有异议可提交申诉，附相关截图 / 记录，后台 24 小时内反馈核实结果；误判、系统异常导致的排名损失，可手动补回对应排名与奖励。
3. **赛季重置机制**：月度 / 季度赛季定期重置排名，给新玩家追赶机会，避免老玩家永久垄断榜单，保持长期公平性与新鲜感。

### 8.4 数据层：全链路可追溯，违规可回收

- **全操作留痕**：所有成就达成、排名变动、道具交易、账号登录全链路留痕，包含时间、IP、设备、操作路径，出现争议可完整回溯。
- **分级处罚规则：**

| 违规等级 | 处罚方式 |
|---|---|
| 轻度异常（误触 bug、少量刷分） | 扣除对应排名得分，回收违规成就 |
| 中度违规（刻意刷分、倒货） | 赛季排名清零，禁赛 1 个赛季 |
| 重度违规（工作室批量刷号、利用恶性 bug） | 永久取消上榜资格，封禁对应功能 |

- **全服公示**：违规处罚结果全服公告，起到警示作用，同时保障普通玩家的知情权。

### 8.5 隐私与人性化设置

- **匿名上榜开关**：玩家可选择匿名上榜，隐藏个人 ID 与宗门信息，仅展示排名与核心数据，兼顾隐私需求。
- **排名屏蔽开关**：可选择不参与公开排名，仅自己可见排名进度，满足佛系玩家需求。
- **申诉通道**：对排名有异议可提交申诉，后台核实后 24 小时内反馈与调整（见 §8.3）。

### 8.6 奖励价值控制

- 所有排名奖励严格控制数值强度，永久属性增益不超过全局乘区软上限的 10%，主要价值集中在称号、外观、特权等荣誉维度（注：与 §19.7.4「不超过全局乘区的 1%」表述存在数值口径冲突，详见 §十一 CONCERN-04）。
- 赛季限时称号不带任何属性加成，仅为展示荣誉，彻底避免排名造成的数值不平衡。

### 8.7 防刷机制落地案例（七类，均经运营验证）

| 编号 | 问题背景 | 落地方案要点 | 对应本游戏设置 |
|---|---|---|---|
| 案例 1 | 批量刷低阶成就冲榜 | 普通成就单日排名分上限 50 分；传说权重相对普通 100 倍，刷低阶性价比极低 | 普通单日上限 50 分，传说权重 10 |
| 案例 2 | 高玩开小号虐菜冲榜 | 按大境界分段排名；新注册账号 7 天保护期不进全服榜；境界提升后自动升段，历史低段排名保留 | 境界分段榜单，新号 7 天保护期 |
| 案例 3 | 交易倒货刷收集类成就 | 交易获道具对应收集成就权重减半；同 IP / 同设备交易不计入；24 小时内同类型道具频繁交易自动冻结 | 交易类成就权重 0.5，交易流水风控 |
| 案例 4 | 利用 bug / 漏洞刷成就 | 全链路留痕可溯；短时间批量解锁自动冻结审核；bug 成就一键回收 + 全服公告；全服补偿 | 全操作留痕、异常自动冻结、可追溯回收 |
| 案例 5 | 老玩家永久垄断榜单 | 常驻总榜 + 赛季榜双轨；每月重置赛季功勋榜按当月新增点数排名；前 100 名更迭率 ＜ 30% 时调整赛季奖励 | 月度赛季榜 + 常驻总榜，赛季限定外观 |
| 案例 6 | 工作室多账号批量刷分 | 设备指纹 + IP 风控，同 IP 下 5 个以上账号标高风险暂不上榜；头部账号人工巡检；排名奖励绑定不可交易 | IP / 设备风控、头部每日巡检、奖励绑定 |
| 案例 7 | 氪金玩家碾压式冲榜 | 可购买道具类成就权重减半；高权重传说成就均为玩法挑战类（无伤通关、极限反杀、全探索）不可氪金获取；奖励偏荣誉外观 | 交易类成就权重减半，传说均为挑战类，奖励偏荣誉外观 |

> 有效性验证：核心监控指标为刷分举报量、榜单头部异常行为占比、赛季排名流动性（前 100 名更迭率）；正常情况下赛季前 100 名更迭率 ≥ 30% 说明防刷有效，若 ＜ 10% 则需调整规则。

## 九、全游戏规则一致性保障

从「数据、数值、经济、世界观、配置、校验、运营」七个维度建立全链路一致性机制，确保排名规则完全融入游戏整体体系，不出现逻辑冲突、数值失衡、设定出戏等问题。

### 9.1 数据层：单一数据源，字段直读无重复

- 核心原则：排名系统不单独维护任何统计数据，所有得分、进度 100% 读取对应系统的原生业务字段：
  - 成就得分 → 读取成就系统 `point_num` 字段；
  - 战斗战绩 → 读取战斗系统 `kill_count`、`damage_total` 字段；
  - 阵营声望 → 读取阵营系统 `faction_level` 字段；
  - 经营数据 → 读取经济系统 `stone_total`、`output_total` 字段。
- 事件回调触发：各系统操作完成时抛出标准事件，排名系统监听事件自动更新，不做二次统计，从根源保证数据一致。
- 兜底校验：每小时全量对账，两边数据差值超过阈值自动修正，确保永远同步。

### 9.2 数值层：乘区统一，增益强度对齐全局规则

- 排名奖励的所有永久属性增益，全部归入全局对应的乘区（攻击乘区、防御乘区、通用增益乘区），严格遵守「软上限 80%、硬上限 100%」的全局规则。
- 强度控制：所有排名奖励的属性增益总和，不超过全局乘区软上限的 10%，排名仅做锦上添花，不成为战力核心来源。
- PVP 与 PVE 增益严格拆分，排名的 PVP 专属增益仅在竞技场景生效，不影响 PVE 数值体系，两边平衡独立管控，互不干扰。
- ⚠️ 与 §8.6 / §19.7.4「永久属性增益不超过全局乘区的 1%」存在口径冲突，详见 §十一 CONCERN-04。

### 9.3 经济层：总量管控，奖励纳入全局额度

- 排名奖励的所有资源、道具、货币，全部统一换算为灵石价值，纳入「任务奖励」渠道的产出总额度，占比不超过该渠道的 5%，不挤占核心玩法的产出配额。
- 稀有道具、限定外观全部设置唯一获取渠道，仅排名可产出，不投放其他路径，既保证稀缺性，又控制总量不泛滥。
- 排名奖励的消耗类道具，全部纳入经济闭环（如丹药可消耗、材料可合成），不新增孤立资源，避免破坏货币流通与通胀节奏。

### 9.4 世界观层：命名包装统一，贴合修仙宗门设定

- 所有排名、榜单、奖励全部采用修仙化包装，不出现「排行榜」「积分」「段位」这类现代游戏黑话：
  - 排名系统 → 玄洲风云榜、功勋碑
  - 排名积分 → 功勋值、名望值
  - 赛季结算 → 月度核榜、赛季评功
  - 排名奖励 → 功勋赏赐、宗门荣光
- 阵营排名完全对应五大阵营世界观设定（正道榜由正道盟评定、散修榜由散修盟排行），榜单风格、文案、奖励都贴合对应阵营气质，绝不出现设定冲突。

### 9.5 配置层：统一入口，全系统共用一套 ID 体系

- 所有成就、排名、奖励配置走统一的配置表管理，道具 ID、称号 ID、外观 ID 100% 对齐全局资源库，不存在排名专属的游离 ID。
- 新增玩法同步新增对应排名成就，配置模板统一，规则逻辑复用，无需单独开发排名逻辑，保证新内容排名规则和整体体系一致。
- 阵营排名、分类排名的计分规则统一复用总榜的加权公式，仅调整分类范围，不单独做新的计分逻辑，避免多套规则造成混乱。

### 9.6 校验层：自动化检查，版本更新前置拦截

配置上线前，自动运行一致性校验工具，检查三项核心规则：

1. 奖励 ID 是否在全局资源库中存在，不存在则拦截；
2. 属性增益是否突破乘区上限，超阈值则预警；
3. 总奖励价值是否超出对应阶段的经济额度，超额度则拦截。

每次版本更新，同步校验排名规则与对应玩法规则的匹配度（如新增秘境时，检查秘境成就、秘境排名的规则是否和秘境本身的难度、奖励匹配），避免出现断层。

### 9.7 运营层：规则同步迭代，调整全链路生效

- 玩法规则调整时，排名规则同步更新（如秘境难度调整，对应秘境成就的难度、排名的权重同步调整），保持相对公平。
- 赛季、活动的排名规则，复用通用计分框架，仅调整限时系数与奖励，不新增独立规则，保证玩家理解成本低、规则体感一致。
- 所有规则调整全服公告，说明调整原因与影响，透明化运营，提升玩家信任度。
