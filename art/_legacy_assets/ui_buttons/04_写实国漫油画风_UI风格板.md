## 二、风格板核心要素

### 1. 色彩系统（锁定）

| 用途 | Hex | 说明 |
|------|-----|------|
| 底板主色（中心亮部） | `#2C5F52` | 主绿，微亮，偏青玉 |
| 底板边缘/阴影 | `#1E2B28` | 项目墨青，压重 |
| 描边/金属高光 | `#C8A86A` | 项目暗金 |
| 旧铜/深描边 | `#6E5A45` | 青铜旧色，做第二层描边 |
| 选中高亮 | `#E8DCC8` | 亮金，rim light 色 |
| 灵气微光 | `#6E8F88` | 青黛，做 subtle aura |
| 朱砂 ritual 点缀 | `#B3423D` | 仅丹火/警告/高阶标识 |
| 文字色（Godot Label） | `#F4EFE3` | 宣纸米白，**不烧进图** |

### 2. 材质语言（锁定）

- **底板**：哑光青玉/玄青金属，带细微磨砂颗粒，**不是镜面反光塑料**
- **描边**：暗金/青铜金属浮雕，双层线：外侧粗、内侧细，转角处有轻微高光
- **暗纹**：浮雕式祥云、回纹、云雷纹，仅做凹陷/凸起质感，**不抢眼**
- **光影**：顶光微亮、边缘暗、四角压黑，整体有油画厚涂的体积感
- **边缘**：如意云头 / scalloped 中式花角，替代普通圆角

### 3. 不可出现的元素

- ❌ 纯扁平矢量感
- ❌ 高饱和糖果色
- ❌ 镜面反光塑料感
- ❌ 文字、汉字、数字、符号（一律 Godot Label 后加）
- ❌ 现代几何图标（按钮底板本身不带图标）
- ❌ 白底、黑底、纯色无纹理

## 四、图标层说明（与底板分离）

按钮底板**只出底板**，不放任何图标或文字。图标在 Godot 中作为 `TextureRect` 子节点叠加：

- 方形入口：底板 `sq_base_N.png` + 子节点 `icon_sq_*.png`
- 底部 Tab：底板 `nav_base_N.png` + 子节点 `icon_nav_*.png` + 子节点 `Label`
- 主操作按钮：底板 `rect_pos_N.png` + 子节点 `Label`

图标风格也应与立绘一致：**写实国漫油画风的修真符号**，而不是扁平线稿。例如：

- 经营：太极宗徽 + 祥云
- 弟子：道冠剪影 / 修士侧影
- 历练：飞剑御空 + 灵气尾迹
- 纪事：玉简仙卷
- 建筑：对应建筑的写实小景（正殿、山门、丹炉等）

图标可单独走同一套 AI 提示词生成，或用项目已有素材。

## 六、Godot 落地备注

1. **文字用 Label**：所有中文文字都通过 Godot `Label` 显示，颜色 `#F4EFE3`，**绝不烧进底板图**。
2. **底板与图标分离**：AI 只出底板；图标用 `icon_*.png` 作为子节点叠加。
3. **MipMap 关闭**：UI 纹理 `Mipmaps` 关闭，`Filter` 用 `Linear`。
4. **压缩**：PC 用 BC7，移动用 ASTC 4×4。
5. **如意云角底板**：拉伸时优先固定宽度；若必须可变宽度，请用 `NinePatchRect` 并手调 Patch Margins，保护四角云头。
6. **状态复用**：
   - 正向 8 动作共用 `rect_pos_N/H/P.png`
   - 负向 5 动作共用 `rect_neg_N/H/P.png`
   - 方形 17 个入口共用 `sq_base_N/S.png` + 不同图标子节点
   - 底部 5 Tab 共用 `nav_base_N/S.png` + 不同图标子节点
