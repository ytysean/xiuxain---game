## 1. 三秒判读（应见 / 实见 / 差距）

**问题**：玩家打开首页，第一眼应该看到什么？现在实际看到什么？

### 1.1 应见（目标层级 · 三秒内三段式）

| 序 | 应见 | 层级角色 |
|---|---|---|
| 1 | **我是谁** —— 宗门名 + 等级 + 四资源（顶栏） | 常驻坐标（Tier1） |
| 2 | **现在有什么事** —— **一条**「待宗主裁决队列」（含数字） | 瞬时焦点（唯一） |
| 3 | **我该点什么** —— **一个**主行动钮 | 行动落点（唯一） |
| 4 | **我在哪、什么时节** —— 山门场景（背景）＋ 时令 | 氛围/节奏 |

### 1.2 实见（现行 `ui/sect_home_page.gd` 盘上实况）

### 1.3 差距（★ 本页信息层级的三条硬伤）

| # | 差距 | 实证 | 后果 |
|---|---|---|---|
| **D1** | **同一条「待批复传讯」在 3 处重复** | 气象带红点（`ui/sect_home_page.gd:755-768`）＋ 快照第 3 栏（`:583-588`）＋ 主 CTA 副文（`:876-878`） | 眼球在三个"待办数字"间跳，**没有唯一焦点**（违「信息层级＝一眼抓住重点」） |
| **D2** | **左右入口列 6 项占主轴**，与 dock「更多」功能重叠 | `ui/sect_home_page.gd:24-33` 六项 vs `:109-146`「更多」36 项索引（含同名 id） | 主视觉窗两侧被"贴边竖排按钮"夹住 —— 背景（主角）被挤小 |
| **D3** | **快照 4 栏密度过高** | 门中弟子 / 司职在任 / 待批复传讯 / 宗门气运（`:583-588`）＝4 类异质信息横排 | 数字栏无主次，读作"仪表盘"，与"3 秒判读"冲突 |

> **一句话定性**：现行首页 = **信息齐全但无层级** —— 缺「唯一焦点」与「唯一行动」。修法**不是加块，是收块**（减块数、并同质、去重复）。

## 2. 现有版块优先级重排（逐块裁定）

> 记法：**保留 / 前置（上移/加强） / 后置（下移/弱化） / 合并 / 降级 / 删**。理由一律一句话。

| 块 | 裁定 | 一句话理由 |
|---|---|---|
| **顶栏**（0–69.3） | **保留** | 身份+资源＝常驻坐标，规范要求由边角承载；**位置不动**，只按 §3 降噪 |
| **① 时令胶囊**（74.7–108.7） | **保留 + 前置** | 时令＝每日节奏入口，已在黄金位，且是「时令必须首页可见」的唯一承载 |
| **②③ 左右入口列**（各 3 项） | **合并 + 降级** | 6 项是「更多」面板的镜像（同 gating 源），应收进 dock/更多，把两侧还给场景 |
| **④ 隐藏 UI 浮标** | **保留** | 沉浸浏览开关，贴边待机；位置不动（守 §0-2 约束语义） |
| **⑤ 宗门气象带**（476–506） | **合并** | 心念轮播＝氛围信息（Tier3），与快照条同质，可并为**一条**信息带，减一块 |
| **⑥ 快照条 4 栏**（516–554） | **保留 + 去重 + 降级** | 删与主 CTA 重复的「待批复传讯」栏（D1），余 3 栏降为**概览（仅色/字重/位置；字号 ≥ font 10）** |
| **⑦ 主 CTA**（564–660） | **保留 + 前置（唯一焦点）** | 「一屏一个主行动」的落点，必须唯一；由它**独占**待裁决数字（D1 收口于此） |
| **⑧ dock**（684–758） | **保留 + 承接** | 底部拇指热区；承接②③合并来的入口（经「更多」，不膨胀一级项） |
| **⑨ 底部 5 Tab**（765.1–854） | **保留** | 导航骨架（宗门/弟子/殿阁/历练/纪事），铁律 #11 与其绑定，不动 |

**重排后的「信息层级」链（目标形态）**：

```
顶栏坐标（谁/资源） → 时令（时节节奏） → ──主视觉窗：山门场景+匾额（主角）──
                                    → 一条信息带（气象 心念 ＋ 快照 3 栏，同质合并）
                                    → 唯一主 CTA（待裁决数字只此一处）
                                    → dock（承接并入的入口）→ 5 Tab
```

## 3. 信息密度与字级方向（不涉具体文字内容）

> 只给「该密 / 该疏」与「该用第几级字」的方向；**字号具体值归视觉线**（art-director-2）。

| 块 | 密度方向 | 字级方向 | 说明 |
|---|---|---|---|
| 顶栏 | **疏→中**（去噪） | 宗门名＝**一级（最大）**；4 资源＝**三级**；中历＝三级 | 4 资源 + 历法是"常驻坐标"，不该与宗门名争视觉权重 |
| 时令胶囊 | **疏** | 时令名＝**二级**；倒计时＝**三级** | 单行胶囊，一条信息 |
| 左右入口列（若保留） | **疏** | 标签＝**四级（最小）** | 入口不承载信息，只承载"可达" |
| 气象带 / 快照带（合并后） | **中**（一条带内分区） | 栏目名＝**三级**；数值＝**二级**；辅助小字＝**四级**（**语义级，非字号档**；字号一律 **≥ font 10**） | 同质信息并带后，靠"栏目名小、数值大"分主次 |
| 主 CTA | **疏（留白最大）** | 主文＝**一级**；副文＝**三级** | 全屏留白最多的一块，强对比突出"唯一行动" |
| dock | **中** | 标签＝**四级** | 7 项等距，标签最小化 |
| 5 Tab | **疏** | ＝**二级** | 导航层级固定，不动 |

**密度铁律复述**（沿用 P0-5 判据 3）：移动端同屏控件 **≤5–6**、信息密度 ≈ PC 的 50–60%；**同屏异质信息块数 ≤4** 为安全区。

## 4. 可删 / 并可移清单（★ 纯结构 · 老大要的"看得出来"最有效一类）

> **不含任何文案改写**；全部为「块 / 栏 / 条目」层面的增删移。

| # | 动作 | 对象 | 依据 | 风险/前置 |
|---|---|---|---|---|
| **S1** | **删（一栏）** | 快照条第 3 栏「待批复传讯」 | 与主 CTA 副文 1:1 重复（D1）；收口到主 CTA 独占 | 无（主 CTA 已承载同数） |
| **S2** | **并（两块→一块）** | 宗门气象带 ＋ 快照条 → 一条「宗门信息带」 | 同质（氛围+概览）；减块数 2→1 | 需守：**时令（时令胶囊）与传讯（主 CTA 副文）仍首页可见** |
| **S3** | **并可移（6 项→0 一级项）** | 左右入口列 6 项 → 收进 dock「更多」 | 「更多」已含同名 id（`ui/sect_home_page.gd:109-146`），重复入口 | ★ **须先过 harness**：`tests/headless_ui_decouple_check.gd` 有双列连续性断言（见 `ui/sect_home_page.gd:34-35`）；删除入口列前须与工程线确认断言改法 |
| **S4** | **降级（视觉权重）** | 快照 3 栏 → 概览（**仅色 / 字重 / 位置**；不删、**不降字号**） | 数字仍在但不与新焦点争位；**字号下限 font 10** | 归视觉线执行 |
| **S5** | **合（3 处红点→1 处）** | 待裁决数字红点（气象带 / 快照 / CTA） | 见 §5；与 S1/S2 同批做 | 见 §5 |

**去重后的净效果**：首屏**独立视觉块数**由 **8 → 5**（顶栏 / 时令 / 信息带 / 主 CTA / dock+Tab），**主视觉窗（背景）随之扩大**。

## 5. 红点 / 待裁决队列语义对齐（★ 必守既有语义）

### 5.1 铁则（`red_dot_init.gd:10-17` 原文复述）

> 红点 = **宗主待裁决队列**的可视化，不是「弟子进度提醒」。
> 判据一句：「这件事宗主不做，弟子 AI 会不会替自己做？」——**会自决的，一律不产生红点**。
> 会自决的弟子行为（自穿装备 / 自服丹药 / 自行突破 / 自寻机缘）→ 走**纪事/传讯告知**，绝不红点催办。

### 5.2 现行首页红点**未走统一真源**（★ 本页一致性硬伤）
