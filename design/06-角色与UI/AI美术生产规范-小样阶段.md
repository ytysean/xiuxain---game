## 五、分辨率与输出

| 类型 | 比例 | 草稿 | 定稿 |
| --- | --- | --- | --- |
| UI 面板 / 弹窗 | 竖版 9:16 | 1K | 2K~4K |
| 图标 | 1:1 | 1K | 2K |
| 背景 | 16:9 | 1K | 2K~4K |
| 立绘半身 | 1024×2048 | 1K | 4K |
| 立绘全身 | 2048×4096 | 1K | 4K~8K |

- 输出 PNG 透明背景（除背景类）；后续抠图 / 9-patch 切片 / 导入 Godot 由工程侧处理
- 落盘目录：`assets/ai_art/2026-07-22/`

## 六、迭代纪律

1. 草稿 1K 快速定方向，不纠结细节（对应拍板第 2 步风格锚点）
2. 选定主方向后，小 diff 调整 prompt，filename 每次换新
3. 定稿 4K 仅在 prompt 锁定后
4. 出图后放同一画布校验材质 / 光影 / 色值统一，修正偏差
5. 实机替换验证（Godot 本地 F5）后再固化进 §六规范沉淀
