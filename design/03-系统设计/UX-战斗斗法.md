### 1.1 可访问性分级（强制引用 `design/gdd/art/ACCESSIBILITY.md`）

- 本 UX 所有交互挂载可访问性分级，默认 **Standard（默认开启·推荐）**；设置可切 Basic / Standard / Comprehensive。
- **最小触控**：底部行动四键 ≥44×44px（Basic 亦须满足，底线）；自动模式「自动中…」小条同样可点。
- **色盲冗余**：职业/五行/克制仅靠颜色区分时，须叠加 **形状 + 文字** 双通道（职业图标带 剑/拳/卦 字、五行带 金木水火土 字、克制浮标带「克制」二字 + 轮廓，不纯色编码）。
- 特性矩阵与动效降级对齐见 ACCESSIBILITY.md；本文件「三、竖屏单手布局」热区 ≥44px 即基线落实。

## 二、信息架构（IA）

```
[斗法入口：历练/秘境/宗门战/PVP]
   └─ 阵容编排（出战弟子 1–N，站位 前/中/后）
        ├─ 职业/灵根/五行可视化（克制提示预览）
        └─ 协战/循环增益预判（三才/五行是否触发）
             └─ [战斗界面]（§9.7 回合流程）
                  ├─ 顶部：回合计数 / 速度排序提示 / 投降·自动切换
                  ├─ 敌方列（上）：站位 + 血条 + 灵力条 + 状态图标
                  ├─ 我方列（下）：站位 + 血条 + 灵力条 + 技能 CD
                  ├─ 底部：行动条（当前单位高亮）+ 技能/普攻/防御/道具 四键
                  └─ 五行克制浮标（攻击命中时弹「克制/+20%」或「被克/-15%」）
                       └─ [战报]（§9.7.5 结算 + 回看）
```

## 四、核心流程（进入 → 回合 → 战报）

### 4.1 阵容编排（战前）

1. 选取出战弟子（默认按战力/职业均衡推荐）。
2. **职业克制预览**：UI 读敌方阵容，显「我方 X 修克制敌方 Y 修」提示（§9.2 铁三角）。
3. **五行克制预览**：读双方灵根，显五行循环箭头（金→木→土→水→火→金，§9.6.1）。
4. **协战/循环预判**：若 道/体/法 三职业齐全 → 标「三才协战 已激活 +5%」；若 五行齐全 → 标「五行循环 已激活 +7%」（§9.2.1/§9.2.2）。

### 4.2 回合流程（§9.7，状态机）

```
[S0 进场准备]
   ├─ 双方按站位排布，加载装备/法宝/灵兽/阵法常驻属性
   ├─ 触发进场被动（本命法宝祭炼/灵兽先手）
   └─ 按速度值高→低排序，生成本回合行动顺序

[S1 回合开始]
   ├─ 结算持续 buff/debuff 回合数（灼烧/中毒/控制）
   ├─ 灵力自动回复（每回合 +10 基础灵力，§9.7.1）
   └─ 检查控制状态（冰冻/眩晕优先结算，被控跳过行动条）

[S2 单位行动]（按 S0 顺序）
   ├─ 当前单位高亮 + 底部四键激活
   ├─ 可选：普攻(0蓝) / 释放技能(耗蓝+CD) / 防御 / 使用道具(每战每类限1,§8.2.4)
   ├─ 命中 → 五行克制浮标 + 伤害数字霓虹跳动 + 受击微光碎裂(§15.4 六)
   └─ 触发受击反馈/反击/追击(体修磐石/裂山反击)

[S3 回合结束]
   ├─ 检查双方存活；一方全灭 → [S5]
   └─ 回合数+1；≥30 回合未分 → 防守方胜(§9.7)

[S4 30回合上限] → 防守方获胜

[S5 战斗结算]（§9.7.5）
   ├─ 判定胜负，计算奖励（经验/材料/声望）
   ├─ 结算弟子状态（伤亡/灵力/耐久）
   └─ 生成战报，支持回看
```

### 4.3 战斗结算 → 战报

- 胜/负/平（30 回合防守胜）判定；奖励写履历 + 战报弹窗。
- 战报含：双方阵容、回合轴、关键技能、五行克制触发次数、三才/五行增益生效记录。
- 支持回看（滚动时间轴）。

| 机制 | 数值（设计值，[PLACEHOLDER] 待实测） | UI 呈现 |

| 五行克制 | 克制 +20%（单灵根+25%/杂灵根+15%）／被克 -15%（单-18%/杂-10%）／同属性 1.0 | 命中弹「克制 +20%」紫霓 / 「被克 -15%」灰 / 同属性无标（§9.6.1/§9.6.2） |

| 风险 | 判定 | 处置 |
| --- | --- | --- |
| **主导策略**：玩家全堆单一最强职业/灵根 | 🔴 须防 | §9.2 铁三角 + §9.2.1 三才协战（三职业齐全才触发）刻意奖励**混编**；§9.6.2 五行循环奖励五行齐全。单一堆叠反而吃不到协战/循环增益。UI 须把「混编增益」做成可见正反馈，而非隐藏。 |
| **经济失衡**：攻击增益破 §4.1 | 🔴 须校验 | §9.5.1 攻击加成乘区软上限 80%（×1.8），独立于通用增益 25%/30%；五行克制为独立乘区不受上限影响。战斗临时增益不计入面板战力（§4.1 临时战斗乘区）。 |
| **认知过载**：480×854 同屏显 速度序+双列血条+技能CD+五行浮标 | ⚠️ 中风险 | 五行/克制浮标限时 0.6s 淡出；协战/循环预判仅在战前显，战斗中收为微角标；技能 CD 用环形进度非数字堆。 |
| **支柱漂移**：战斗数值与 §4.1 乘区脱节 | 🔴 须对齐 | 伤害公式 §9.5 的乘区划分必须 1:1 映射 §4.6 全局乘区归属总表（装备/灵兽/功法/三才/五行各有归属），新增增益先占坑（§4.6 强制规则①）。 |

## 八、边缘情况（≥3 类）

1. **30 回合上限**（§9.7）：回合耗尽未分胜负 → 强制防守方胜，结算不卡死。
2. **控制链**（§9.7.2）：单位被冰冻/眩晕 → 本回合跳过行动条，不空转不崩溃。
3. **灵力耗尽**（§9 灵力子系统）：灵力不足 → 仅普攻且普攻 -30%，不卡技能释放。
4. **五行/职业缺失**：阵容不全（无三职业/无五行齐）→ 协战/循环增益不触发，UI 显「未激活」灰标，不报错。
5. **单灵根 vs 杂灵根**：克制加成按 §9.6.2 纯度修正，UI 注小字差异；无灵根（理论边界）→ 按同属性 1.0 处理。
6. **自动战斗 AI 死循环**：AI 逻辑异常 → 超时强制按 §9.7 回合上限结算，记日志不冻结。
