# 25 屏装备穿戴交互规格

## 页面定位

从弟子详情页或背包页点击装备槽后弹出的「穿戴装备」面板。承载功能：展示当前弟子已穿戴的三类装备（法器 / 神兵 / 法宝），并列出来自宗门库房、可供该弟子穿戴的候选物品。

> 设计意向声明：弟子可穿戴槽位（`fa_qi` / `shen_bing` / `fabao`）已在项目铁律中锁定，本弹窗据此构建；候选列表、装备战力折算与穿戴规则按通用 RPG 装备系统合理假设，实装前需策划确认具体数值与互斥规则。

## 信息架构

1. **顶部标题区**：标题 + 关闭
2. **弟子信息区**：弟子名 + 当前战力（穿戴后实时刷新）
3. **当前装备区**：法器 / 神兵 / 法宝 三槽，展示当前装备名与品阶色
4. **候选列表区**：来自背包的可穿戴物品，每件右侧配「装备」快捷按钮
5. **底部操作**：取消 / 确认穿戴

---

## 交互规则

| 元素 | 交互 | 状态/反馈 |
|---|---|---|
| 关闭 ✕ | 点按 | 关闭弹窗，不保存任何更改 |
| 候选「装备」按钮 | 点按 | 将该物品预填到对应槽位；若槽位已有装备，则原装备回到候选列表 |
| 槽位行 | 点按 | 展开/折叠该槽位候选（S2 可选）；S1 默认展开候选列表 |
| 取消 | 点按 | 关闭弹窗，不应用更改 |
| 确认穿戴 | 点按 | 应用三套槽位变更，刷新弟子战力，关闭弹窗并返回弟子详情 |
| 不可穿戴项 | 置灰 | 境界不足、职业不符、性别不符的物品置灰并显示锁定原因 |

## 代码映射

- 入口：建议从 `ui/page_disciple.gd` 装备槽点击、`ui/page_storage.gd` 物品「穿戴」选项触发。
- 数据层：弟子三槽已在 `disciple.gd` 定义为 `fa_qi` / `shen_bing` / `fabao`；候选列表从 `Game.宗门库房` 过滤「可穿戴」物品。
- 战力刷新：穿戴变更后调用 `disciple.gd::get_final_combat_attr()` 重新折算攻防血速。
- 新增脚本建议：`ui/popup_equip.gd`（纯展示/交互），数据写回由 `game_state.gd` 提供 `equip_item(disciple_id, slot, item_uid)` 接口。
