## 二、主题架构（程序化 Theme，全局级联）

入口 `main.gd::_ready()` → `theme = 造主题()`，主题挂到根节点，**级联到所有子控件**（局部 `add_theme_*_override` 仍优先生效，互不影响）。

### 2.1 调色板对齐 v2.0 锁定值
`main.gd` 顶部常量重对齐为美术规范：`宣纸米白 #F4EFE3`、`墨青 #1E2B28`、`暗金 #C8A86A`，新增 `青黛 / 玉石绿 / 朱砂 / 青玉 / 青玉亮 / 墨底半透`。

### 2.2 `造主题()` 扩展的控制样式（灰模→皮肤的关键）
| 控件 | 样式 |
| :--- | :--- |
| PanelContainer | 宣纸米白半透 + 暗金描边 + 圆角（卷轴形制） |
| Panel | 墨青半透 + 暗金描边（状态栏/底框默认） |
| Button | 青玉底 + 暗金框（normal/hover/pressed/disabled 四态） |
| Label / RichTextLabel | 墨青正文 |
| HSeparator / VSeparator | 暗金细线 |
| ScrollBar | 暗金圆角抓柄 |
| TabBar | 未选青玉 / 选中暗金填充（主界面 弟子/待抉择/御兽/纪事 分页直接受益） |

### 2.3 现实皮肤纹理层（守卫式）
`_皮肤纹理装填(t)` 以 `ResourceLoader.exists` 守护，把 AI 方向稿作 9 宫格切片挂到 Panel/Button：
- 缺资源 → 静默回退扁平风，不崩。
- **一键回退开关**：`main.gd` 顶部 `const 启用皮肤纹理: bool = true`，置 `false` 即零成本切回纯扁平 v2.0 风（满足方案 Stage 5「回滚保障」）。
- 主界面远景底图同样以 `启用皮肤纹理` + `ResourceLoader.exists` 双守护，低透明度（0.12）叠加于纸底，不抢前景、`mouse_filter=IGNORE`。

## 三、纪事分类 UI 分栏筛选（S1 低风险内容）

- **入口**：`main.gd::刷新纪事()`，原「仅看异闻」单 bool 开关泛化为 5 栏分类筛选。
- **分类**：`全部 / 宗门大事件 / 宗门岁纪 / 日常庶务 / 异闻`（与 `_年结评分`/`_七载大考` 写入的 `category` 枚举完全一致）。
- **交互**：顶部 `HBoxContainer` 标签栏，每栏显示实时计数 `分类(n)`；选中项 `toggle_mode` 高亮（暗金填充），点击即筛选对应 `category`；默认「全部」。
- **零底层改动**：复用既有 `category` 字段，不改数据结构、不动存档、不影响其他界面。
- **清理**：移除了一处 `return` 之后不可达的死代码（`小标题("—— 宗门纪事 ——")`）。

## 五、待美术精修项（留给正式版本，不在最小包范围）

1. **9 宫格边距微调**：面板 `margin=48`、按钮 `margin=80` 为经验值，AI 方向稿含装饰纹理，正式美术应据实际切片重设，避免拉伸变形。
2. **头像框接入**：`圆形弟子头像框.png` 预留给弟子/灵兽详情头像，本次未接（避免动布局）。
3. **图标占位**：资源/境界/品阶/建筑入口基础图标仍为 emoji/文字，待正版素材库补。
4. **动效**：当前仅基础样式，点击/弹窗过渡动效留待 S1 统一规范。

## 六、回退与风险

- 视觉回归风险：本环境无 Godot 运行器，无法渲染验证；纹理层全部守卫，置 `启用皮肤纹理=false` 即纯扁平风，秒级止损。
