> 暗金三值冲突：`#C8A86A`（主题规范/写实规范/绘图强制/图标清晰度/AI生产规范 共用，标注「用户锁定的权威暗金」）vs `#B89B5A`（`UI硬性约束规范.md §3.2` 按钮暗金）vs `#C9A865`（`UI设计令牌v1.0`/`组件视觉走查清单`）。三者差 ≤12/255，但跨文档不统一即风格漂移。

**对齐建议（供主理人拍板）**：
1. **单一 SSOT**：以「用户终裁 + 最近落地」的 `写实修仙UI可执行规范` + `绘图强制规范` 为默认对齐基准（浅底最小包方向，因 v1.2 明确把浅底定为「修复文字看不清的核心动作」）。`太玄UI主题规范.md` 的深底方向、`UI设计令牌v1.0` 的大字号/异色板，须在拍板后一次性收敛，禁止并行生效。
2. **单一暗金**：全游戏锁定 **`#C8A86A`** 为全球唯一暗金（主题规范已标注权威）；`#B89B5A`/`#C9A865` 两处改为引用同一常量。
3. **字号是否整体放大**：令牌 v1.0 的 {40,32,26,24,20,18} 更贴近大厂移动端可读性，但与已锁 type scale {22,17,18,16,15,13}（已满足 ACCESSIBILITY ≥15px 下限）冲突。若采用大字号，属全量 breaking change，须 design-strategist 重写 `ui_theme.gd` + engineering-lead 重做 `main_theme.tres` + 全页回归，排期需单列。

## 3. 三态规范（空 / 加载 / 错误）设计方案

> 现状：UI 有 Toast/红点/弹窗入场，但**无系统化的空/加载/错误态规范**；审计发现「天下空绿带」「纪事截断」「坊市资源语义不明」等属三态缺口。

### 3.1 空状态（Empty）

| 场景 | 设计方案 |
|---|---|
| 空名录 / 空接引池 | 居中「玉牌」占位：图标(`弟子` 线稿) + 一句引导文案(如「宗门初立，尚无弟子来投」) + 主按钮「前往接引」；禁纯空白页 |
| 空坊市货架 | 仙城告示风占位 + 「市集暂未开张」+ 倒计时(每日 08:00 刷新) |
| 空成就 / 空纪事 | 淡青玉卡 + 「暂无事迹可录」；禁留空列表行 |
| 无搜索/筛选结果 | 顶部 Toast「未寻得相关事物」+ 清空筛选次按钮 |
| 空弟子池(新档首月) | 已由 P2-1 保底(引一名散修)，仍须空态兜底文案 |

统一规范：空态 = 图标(48–64) + 主文案(15–16px 正文色) + 可选主按钮(青底金边)；占满内容区垂直居中；不出现「只有标题没有内容」的半页。

### 3.2 加载状态（Loading）

| 场景 | 设计方案 |
|---|---|
| 首屏启动(2650ms PC) | 启动骨架屏：墨青底 + 远景虚化 + 宗门牌坊占位 + 进度(灵韵进度条，禁荧光)；异步化(先首页骨架后数据，P2-6 排期) |
| 分页切换 | 一级页淡入(0.14s) 即够；重页(功绩堂等)续建用列表错峰入场，无需转圈 |
| 列表增量续建 | 底部「加载更多」微提示或自动续建(已落地分批渲染)，禁整页 spinner |
| 立绘/大图加载 | 先显占位圆框(暗青描边) + 淡入(透明度 tween)，加载完替换；禁闪白 |
| 资源/数值刷新 | 数值滚动(0.45s) 替代硬跳变 |

统一规范：加载态**不阻断阅读**（骨架/淡入优先于 spinner）；转圈仅用于 >1s 的明确阻塞操作；灵韵进度条统一视觉(§6 修真细节)。

### 3.3 错误状态（Error）

| 场景 | 设计方案 |
|---|---|
| 资源/纹理加载失败 | 占位图回退：图标缺 → 静默隐藏(已落地)；立绘缺 → 圆形暗青占位框 + 头像框；禁豆腐块/报错红字 |
| 操作失败反馈 | 底部 danger Toast「此举未成 · 缘由…」(≤1.5s)；危险操作二次确认弹窗(遣散/交宗/拆除) |
| AI 出图批次失败 | 外批次(豆包)交付验收不通过 → 回退到程序化占位(StyleBoxFlat) 或上一版资产，禁残缺图入树 |
| 离线/存档异常 | 单机版：设置弹窗展示「上次存档时间」；异常 → 阻断式提示(非静默泄漏，呼应 P1-3 退出清理) |

统一规范：错误态须**可恢复、可感知、不崩渍**；danger 色 `#E07878` 仅用于文字/低透底，不刺眼；禁开发期报错栈上屏。

## 4. 动效与反馈（Game Feel）规范

> 已落地基础层见 `UI动效与手感层_规范 v1.1`（§1 已列）。本节省略已落地项，聚焦上线前需补齐的 game feel 闭环。

### 4.1 已统一（验收 PASS，保持）

按钮按压、一级页淡入、二级页滑入、列表错峰入场、数值滚动、红点三态动效、弹窗/抽屉入场 —— 全部「零调用点优先、不碰布局、可断言」。

### 4.2 待补齐（P1，上线前闭环）

| 项 | 方案 | 优先级 |
|---|---|---|
| 进度条缓动 | `ProgressBar.value` 直赋值无钩子；对「升级/经验/修为」等玩家盯看条，接 `UITween` 或自定义控件做 0.3s 缓动；其余条保持瞬切 | P1 |
| 切页转场重级 | 当前淡入+滑入；更重转场(缩放/翻页) 须先在手机端验证帧率预算(禁掉帧) | P2 |
| reduce-motion 设置页落点 | `UITheme.动效强度` 已是统一开关，但**当前无设置页**；须 design-strategist 在设置弹窗加「高品质动效 三档(极简/标准/关闭)」+ 接 OS `reduce-motion` 自动映射至极简 | P1 |
| 加载态动画 | 见 §3.2；首屏骨架 + 立绘淡入落地 | P1 |
| 空状态入场 | 空态组件淡入(0.14s)，与页面级一致，禁硬切 | P2 |
| 反馈音/震动 | 震动独立开关(前庭/触觉敏感)；传说奇遇微震、点击轻震受开关约束；音效不在本域 | P1(开关)/P2(接线) |

### 4.3 动效纪律（沿用，禁回归）

- 只动 `modulate/scale/position` 渲染态，不碰 `Container` 托管子节点布局。
- 动画在 `refresh()` 之后播；缩放前显式 `pivot_offset = size*0.5`。
- anchor 定位弹窗禁补间 `position`（用 `弹窗入场`）；绝对定位用 `抽屉入场`。
- 所有动效须可被 headless 探针量化断言（不靠「看起来差不多」）。

## 8. Top 风险与跨域协同项

### 8.1 Top 风险（3–5 条）

1. **视觉标准三套并存 + 暗金三值未归一（P0·治理）**：`太玄UI主题规范`(深底) / `写实修仙UI可执行规范`+`绘图强制`(浅底) / `UI设计令牌v1.0`(深底异色板+大字号) 同时有效；暗金 `#C8A86A`/`#B89B5A`/`#C9A865` 三值。不拍板单一 SSOT，上线即全量视觉漂移。**须主理人冲刺前裁决。**
2. **资产治理「降显存」与「图标清晰」冲突（P1）**：盲按 `godot-texture-vram-budget` 全量转 mode=2 会毁图标边缘(须豁免 icons 保 mode=0)；且 `characters/` 改名 lossless 显存爆至 ~1.9GB(手机不可承受，须保 mode=2)。治理须按用途分级、工程逐项核对，禁一刀切。
3. **可访问性设置页缺失（P1·合规缺口）**：Standard 级要求的文本缩放/高对比/reduce-motion/震动开关全部依赖设置页，当前无设置页承载 → 特性无法触达用户。
4. **超大图/非4倍数/缺.import/冗余归档（P1–P2）**：`danfang_sheet` 8640×4242、array 2048²×8、103 非4倍数(masters_circle 598²)、160 缺.import(archive 残留)、avatar legacy 冗余 → 包体/启动/潜在崩渍风险；改后必跑探针比对防布局副作用。
5. **立绘结构性欠采样（P2·成本风险）**：masters 显示2806/纹理1216(放大2.3×)、home_bg_season 显示486/纹理1920(3.95×) 为真·模糊源，非导入参数可解，需重出高分辨率立绘或降放大倍数，工作量/预算大。
