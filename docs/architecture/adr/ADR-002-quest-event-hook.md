# ADR-002 奇遇事件接入点

> 状态：提案（性格四维表已裁决，见 design/gdd/DESIGN-RULINGS-P5.md 裁决③；CSV 结构已核对，核心池待建）｜ 作者：eng-lead（程基岩）｜ 阶段：Phase 4 收口
> 关联：奇遇系统落地规范.md、太玄宗门录_核心设定总览.md §10/§11.21、lore.gd、game_state.gd:124、csv_validator.gd、config/quest_random.csv·random_entry_pool.csv·quest_reward_pool.csv
> 决策影响：奇遇系统 Epic；依赖 ADR-001 战力（奖励含装备）/ 存档兼容。

---

## 1. 背景与问题

**现状**：
- `lore.gd` 已实现 `取奇遇(等阶)`（game_state.gd:275），但 `game_state.gd` **从未调用**——`推演一月→_弟子月度事件` 只调了 `Lore.取历练(d.境界, d.性格)`（game_state.gd:133）。
- `取奇遇` 仅按境界随机抽 56 条模板（7 境界×8），**无稀有度 / 无 8 大类 / 无性格四维分支 / 无玩家干预**。
- `config/` 已存在候选数据源：`quest_random.csv`、`random_entry_pool.csv`、`quest_reward_pool.csv`、`quest_reward_pool.weight` 等，但**无引擎接线**。

**规范（奇遇系统落地规范.md）要求**：
- 四档稀有度（普通/稀有/珍稀/传说）总权重 10000；低于弟子 2 大境界自动重 roll。
- 8 大类 ×25 = 200 则；每则多分支由**性格四维**（激进度/利他度/聪慧度/贪欲度，0-100）阈值判定。
- 珍稀(紫) 以上触发掌门干预弹窗；三档干预（放任/暗中相助/亲自出手）；优先级：玩家选择 > 性格四维。
- 奖励：灵石/贡献/灵材/装备/功法/道心值；奇遇版道具数值增幅 20%-50%。

**缺口**：接口存在但未接线 + 实现度远低于规范；性格驱动抉择分支未接入；奖励结算无。

## 2. 决策（Decisions）

### D1 — 接入点：在 `_弟子月度事件` 内新增「奇遇」并行分支
保留既有 `Lore.取历练`（历练），在 `game_state.gd:124` 的 `_弟子月度事件(d)` 中**新增奇遇触发**（与历练并列，独立概率）：
```gdscript
# _弟子月度事件(d) 内（伪代码）
var 文本 := "【%s】" % d.姓名
if randf() < 历练概率: 文本 += Lore.取历练(d.境界, d.性格)   # 既有
if randf() < 奇遇触发概率(d):                                 # 新增
    var q := 奇遇引擎.抽取(d)                                  # 见 D2
    文本 += q.文案
    if q.需干预: 奇遇待抉择.append(q.干预包)                    # 紫+ 进干预队列
    else: 结算奇遇奖励(d, q)                                    # 普通/稀有 自动
```
- **与月度事件关系**：奇遇与历练共用同一「月度事件」入口与成败判定（`_判定成败` 已用 `总战力()`，奇遇奖励装备经 ADR-001 自动进战力），不另开循环。

### D2 — 新建纯逻辑模块 `quest.gd`（数据 + 接口，仿 `lore.gd` 叶子结构）
- 职责：稀有度 roll（10000 权重四档）→ 场景匹配池 → 子池等概率抽条目 → **性格四维判定分支** → 产出奖励包。
- 数据源：优先读 `config/quest_random.csv` + `random_entry_pool.csv`（含 rarity/trigger_weight）；`Lore.取奇遇` 降级为「无配置时的兜底文案」。
- 不依赖 `Game` 单例；输入 `Disciple`（取其 `性格`/`境界`/`命格`），输出 `QuestResult`（文案/稀有度/分支/奖励/是否需干预）。

### D3 — 性格四维：派生查表，不新增 disciple 字段
- GDD §10 区域明确「12 种固定性格直接映射三大阵营倾向，代码复用性格四维模型，无需新增字段」。
- 在 `quest.gd`/`lore.gd` 建 **`性格四维表`**（12 性格 → {激进度,利他度,聪慧度,贪欲度} 固定分值），由 `性格` 字符串查表，判定分支阈值。
- 分支规则：奇遇正文自由标签 → 四维阈值（如「高风险硬闯」：`激进度≥80 且 贪欲≥70`）。
- **已裁决（裁决③）**：12 性格→四维固定分值表已由 design-lead 锚定（见 §6 表，来源 §2.2/§6.6/§10 第2863–2864行），标记 `[DESIGN_BASELINE, 待 奇遇系统配置表及性格判定.docx 录入校准]`；阈值判定用此表，玩家未干预时走四维分支。
- ⚠️ **与「五性格」区分**：`personality_config.csv` 的五性格行为标签（勤勉/慵懒/…）是**沙盘行为权重层**，驱动弟子走动/互动，不进奇遇分支阈值；`quest.gd` 四维表必须映射 **12 标准性格**（§6.6），不可混用。

### D4 — 玩家干预：复用并扩展 `待抉择` 机制
- 现有 `Game.待抉择` 是 `{弟子, 物品, 文本}` 队列（极品/特殊道具抉择）。奇遇紫+ 干预**新建 `奇遇待抉择` 队列**（结构相似：`{弟子, 奇遇包, 选项}`），UI 新增干预弹窗（灰模，art-lead 后续出美术）。
- 三档选项 `放任自流 / 暗中相助(耗贡献或灵石) / 亲自出手(耗高阶道具或声望)`；每日干预上限随品阶提升（凡 3 次，每升 1 品 +2）。

### D5 — 奖励结算与 `item` 扩展
- 奖励写入弟子：灵石/贡献直接加 `Game`；装备/灵材生成 `Item` 入 `背包`（经 ADR-001 战力自动生效）；道心值（待道心系统，先记 `履历`）。
- **`item.gd` 新增 `奇遇版` 标记**（bool/flag）：奇遇版道具数值增幅 20%-50%、突破率 +5%~10%。属 item 字段扩展，须走 §11.21 三原则（只新增+默认 false）。
- 奖励写入弟子 **30 年履历**（新增 `履历: Array` 字段，§11.21 扩展；圣阶以上计入大道传记——后续）。

### D6 — 存档兼容
- `奇遇待抉择` 为会话内瞬时队列（同 `待抉择`，可不落盘，但需在 load 时清理）。
- `item.奇遇版`、`弟子.履历` 为新增字段，默认 `false`/`[]`，满足 §11.21 三原则。

| 方案 | 描述 | 取舍 |

## 4. 性格 → 抉择分支 数据流

```
d.性格 (string, 12 选 1)
   └─ 性格四维表.查(性格) → {激进度,利他度,聪慧度,贪欲度}
        └─ 奇遇分支.判定(四维, 奇遇标签阈值)
             ├─ 玩家未干预 → 性格四维判定分支（默认）
             └─ 紫+ 且玩家干预 → 玩家选项 > 性格判定（规范优先级）
                  └─ 结算奖励(分支结果)
```

## 7. 验收标准

- **AC1 接线**：登录推演中，弟子月度事件可按概率产出奇遇文案（不再只有历练）。
- **AC2 稀有度**：奇遇四档稀有度按权重 10000 抽取；低于弟子 2 大境界自动重 roll（边界：恰差 2 界不重 roll）。
- **AC3 性格分支**：同一奇遇在不同性格弟子下走向不同分支（四维阈值判定）；紫+ 时玩家选项优先级高于性格判定。
- **AC4 干预**：珍稀(紫) 以上进 `奇遇待抉择` 队列，UI 可呈现三档干预（灰模即可）。
- **AC5 奖励**：奖励（灵石/贡献/装备/道心值）正确入账；奇遇版装备标记 `奇遇版` 且增幅生效；经 ADR-001 自动进战力。
- **AC6 存档**：`奇遇版`/`履历` 字段新增走 §11.21 三原则；旧档读取无丢失。

## 8. 风险

- **R1（已解除）**：design-lead 已核对 `quest_random.csv`/`random_entry_pool.csv`/`event_quest.csv` 均非 §10 核心池（见 §6.2）。奇遇引擎改用新建 `config/adventures.csv` 作核心池；`Lore.取奇遇` 仍作无配置时兜底。落地前 B1 退化为兜底属预期。
- **R2**：性格四维若 design 改为「需 disciple 存四维而非查表」，则需改 D3（新增字段，仍走 §11.21 默认）。
- **R3**：奇遇奖励装备经 ADR-001 进战力，依赖 ADR-001 先落地；排期上装备穿戴 Epic 须先于奇遇 Epic（见 epics-gap-systems.md 依赖图）。
