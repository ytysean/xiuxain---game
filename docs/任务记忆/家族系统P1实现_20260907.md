## 二、P1实现内容

### 2.1 家族宝库系统

#### 核心功能
| 函数名 | 功能 | 权限 |
|---|---|---|
| `存入家族宝库(弟子, 物品, 数量)` | 弟子从背包存入物品到家族宝库 | 所有家族成员 |
| `从家族宝库取出(弟子, 物品ID, 数量)` | 弟子从家族宝库取出物品到背包 | 核心及以上可直接取，其他需要审批 |
| `查看家族宝库(家族ID)` | 查看家族宝库所有物品 | 所有家族成员 |

#### 存取规则
- **存入**：所有家族成员都可存入，每件物品获得10点家族贡献
- **取出**：
  - 老祖/长老/核心：可直接取出，每件消耗20点家族贡献
  - 内门/外门/附庸：需要长老及以上审批（当前简化版直接拒绝）
- **家族贡献**：存入+10/件，取出-20/件，贡献不足无法取出

#### 修真世界设定
- 家族藏宝阁由长老把守，珍贵物品需要审批
- 家族成员贡献越多，在家族中的地位越高
- 家族宝库是家族传承的重要组成部分

| 函数名 | 功能 |
|---|---|
| `学习血脉功法(弟子, 功法ID)` | 弟子学习血脉功法（需要血脉匹配+觉醒） |

#### 学习规则

- **不外传**：血脉功法只有对应血脉的弟子能学习，其他血脉无法学习
- **可叠加**：一个弟子可以学习多种血脉功法（如果血脉匹配）

#### 数值红线
- 血脉功法单源子帽≤1.5%（全局等效）
- 所有血脉功法的修炼/战力加成都有上限检查

### 2.4 功法不外传机制完善

#### 家族功法保护（P0已实现）
- 家族功法只有家族成员能学习
- 学习家族功法需要家族职位权限（内门及以上）
- 退出家族时，自动清除所有家族功法
- 家族解散时，所有成员的家族功法自动清除

#### 血脉功法保护（P1新增）
- 血脉功法只有对应血脉的弟子能学习
- 必须先觉醒血脉才能学习
- 血脉功法天然不外传（其他血脉无法学习）

#### 宗门功法保护（预留，P2实现）
- 宗门功法只有宗门弟子能学习
- 学习宗门功法需要宗门职位权限
- 叛出宗门时，自动清除所有宗门功法

## 四、接入点

### 4.1 战力系统接入
`disciple.gd` 计算战力()函数新增：
```
主体 = base × 资质系数 × 灵根系数 × 道途系数 
     × (1 + 通用增益) × (1 + 道心增益) 
     × (1 + 血脉共鸣增益) × (1 + 血脉增益) × (1 + 家族功法增益)
     × (1 + 家族秘宝增益) × (1 + 血脉功法增益)
     × (1 + 套装增益)
```

### 4.2 修炼系统接入
`game_state.gd` 推演一月中的宗门加成pct计算新增：
```
宗门加成pct = clamp(灵脉加成pct + 负责人修炼pct + 藏经阁pct 
                + 彩蛋修炼加成 + 大阵pct + 血脉共鸣pct + 血脉pct 
                + 家族秘宝pct + 血脉功法pct, 0, 1)
```

### 4.3 UI显示接入
`ui/disciple_detail_page.gd` 社交关系网格：

- 🩸 血脉卡片：血脉类型·纯度 + 觉醒状态 + 血脉功法数量

### 8.4 功法不外传机制的设计
- 家族功法：退出家族自动清除
- 血脉功法：只有对应血脉能学习，天然不外传
