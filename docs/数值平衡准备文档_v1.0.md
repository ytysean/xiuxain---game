**实际产出公式**：
```
产出值 = 成员数 × 经营基数 × (1 + 经营加成) × 气运乘区 × (1 + 产出buff + 彩蛋产出加成 + 产出池加成) × 等级乘区 × 宗主灵石系数 × 殿阁等级乘区
```

### 2.2 产出加成系数

| 加成类型 | 系数 | 说明 |
|----------|------|------|
| 负责人全局buff | 可变 | 汇总负责人全局buff().get("产出", 0.0) |
| 经营型命格加成 | 0~0.20/殿阁 | 单殿阁经营加成封顶20% |
| 全殿阁经营加成汇总 | 0~0.30 | 全殿阁汇总封顶30% |
| 气运产出加成 | 可变 | 天品灵根弟子触发，持续7天 |
| 宗门等级乘区 | 1.0 + 0.02×(门派等级-1) | 每级+2%，最高+18% |
| 宗主皮肤全宗灵石加成 | 可变 | 取决于当前宗主皮肤 |
| 殿阁等级乘区 | 可变 | 取决于殿阁等级 |
| 彩蛋产出加成 | 可变 | 彩蛋系统加成 |
| 产出池加成 | 可变 | 产出池系统加成 |

### 2.3 殿阁保底津贴（Lv.2+）

```
保底津贴 = 殿阁等级 × 殿阁保底津贴常量
```

**设计意图**：Lv.2+殿阁有保底津贴，与成员产出叠加，结构性产出。

### 2.4 弟子人头费

```
人头费 = 弟子列表.size() × 2
```

**设计意图**：每个弟子每月贡献2灵石，基础收入。

## 七、数值校准方案

### 7.1 校准目标

1. **前期（0~30游戏日）**：玩家能顺利完成新手引导，弟子达到练气大圆满/筑基
2. **中期（30~365游戏日，1年）**：弟子达到筑基/金丹，殿阁升级到3~5级
3. **后期（365~1825游戏日，5年）**：弟子达到金丹/元婴，殿阁升级到5~8级
4. **终局（1825+游戏日，5年+）**：弟子达到元婴/化神，殿阁升级到8~10级

### 7.2 校准维度

#### 维度1：弟子成长速度
- **检查点**：练气→筑基所需时间、筑基→金丹所需时间
- **校准方法**：调整每层所需日基准值、灵根品阶速度倍率
- **预期**：凡品灵根弟子练气→筑基约3年，天品灵根约1.2年

#### 维度2：经济产出/消耗平衡
- **检查点**：月灵石产出、殿阁升级消耗占比
- **校准方法**：调整经营基数、升级消耗公式
- **预期**：10弟子宗门月产出约100~200灵石，殿阁1→2级可在1~2月内完成

#### 维度3：突破成功率
- **检查点**：筑基突破成功率、金丹突破成功率
- **校准方法**：调整突破成功率、资质突破系数
- **预期**：优良资质弟子筑基突破成功率约70%，金丹约50%

#### 维度4：炼器/功法/阵法数值
- **检查点**：炼器成功率、功法修炼加成、阵法效果
- **校准方法**：调整基础成功率、修炼加成、阵法系数
- **预期**：凡阶炼器成功率约80~90%，功法修炼加成累计不超过100%

### 7.3 校准流程

1. **阶段1：静态校验**
   - 检查数值公式是否正确
   - 检查数值范围是否合理
   - 检查数值之间的逻辑关系

2. **阶段2：模拟测试**
   - 模拟100游戏日，记录弟子成长、经济产出
   - 模拟365游戏日（1年），记录弟子境界分布、殿阁等级
   - 模拟1825游戏日（5年），记录弟子境界分布、殿阁等级

3. **阶段3：真机测试**
   - 实际游玩，记录体验感受
   - 记录卡点位置（资源不足、突破失败等）
   - 根据体验调整数值

4. **阶段4：迭代优化**
   - 根据测试结果调整数值
   - 重新测试，验证调整效果
   - 循环迭代，直到数值平衡

### 7.4 风险点

1. **境界膨胀**：弟子成长过快，导致高境界弟子过多
   - **应对**：增加最低突破年龄、稳固期、突破失败率

2. **经济通胀**：灵石产出过多，导致资源贬值
   - **应对**：增加灵石消耗渠道（殿阁升级、炼器、功法学习等）

3. **经济通缩**：灵石产出不足，导致玩家卡关
   - **应对**：增加基础产出、保底津贴、人头费

4. **炼器/功法/阵法数值失衡**：某一系统过强或过弱
   - **应对**：统一数值基准，交叉验证各系统数值
