# 《太玄宗门录》战斗与道心细则
> 版本：v1.0 ｜ 对齐总览v2.2 ｜ 用途：战斗系统、道心成长开发依据
> 职业体系：道修/体修/法修三职业定案

## 一、灵力战斗核心规则
### 1. 战斗基础模式
- 类型：半即时回合制，单位按攻速独立行动
- 组队：最多5弟子 + 2灵兽，站位自动分配：体修前排、法修中排、道修后排
- 胜负：一方全灭则败；20回合未分胜负按剩余战力占比判定

### 2. 三职业定位框架
| 职业 | 核心定位 | 主堆属性 | 技能分类 | 灵力消耗梯度 |
|------|----------|----------|----------|--------------|
| 道修 | 辅助续航、护盾防御、净化解控 | 灵力上限、治疗量、护盾值 | 治疗、护盾、增益、净化 | 低：辅助 < 防御 < 治疗 |
| 体修 | 承伤坦克、近战爆发、反击反伤 | 气血、防御、暴击 | 输出、嘲讽、炼体、反击 | 中：承伤 < 输出 < 爆发 |
| 法修 | 术法爆发、范围伤害、debuff控制 | 术攻、暴伤、控制时长 | 单体、范围、控制、元素共鸣 | 高：控制 < 范围 < 单体爆发 |

### 3. 灵力规则
- 开局满灵力，被动技能无消耗
- 回合回复公式：
- 水/木灵根额外+20%回复，天灵根+15%
- 灵力低于30%时，心法被动回复翻倍
- 低灵力惩罚：灵力不足放技能时，仅普攻且伤害-30%
回合灵力回复 = 境界基础回复 × 资质系数 × 灵根系数 × (1 + 心法增益) × (1 + 装备增益)

### 4. 伤害计算公式
最终伤害 =
攻击方基础攻击
× 职业技能倍率
× (1 + 通用增益总和)
× (1 + 道心增益)
× 属性克制系数（1.2/1.0/0.8）
防守方基础防御 × (1 + 防御增益)
× 暴击系数（暴击时生效）
- 五行相克，变异灵根按主属性计算
- 战斗临时buff计入通用增益，不突破25%封顶

### 2. 道心获取途径
1. 悟道台挂机：主要稳定来源，效率受资质、性格影响
2. 境界突破：每突破大境界一次性获得大量道心
3. 奇遇事件：优质分支奖励，传说奇遇大幅提升
4. 典籍参悟：藏经阁高阶功法参悟成功获得
5. 心魔渡劫：成功渡过心魔劫大幅跃升

## 三、心魔机制
### 1. 心魔累积渠道
- 突破失败：境界越高增量越大
- 丹毒超标：超过80%后每日持续增长
- 高风险历练：秘境、高危奇遇失败增加
- 邪道功法：修炼魔道功法持续增长

### 2. 惩罚梯度
1. 轻度（0-30%）：修炼-10%，突破率-5%
2. 中度（30%-60%）：修炼-20%，突破率-15%，战斗概率失控
3. 重度（60%-90%）：修炼-35%，突破率-30%，失控概率大幅提升
4. 心魔劫（90%+）：触发走火入魔判定，失败境界跌落，成功道心大涨

### 3. 心魔清除途径
- 悟道台静修、洗髓池净化、演武场切磋
- 道心类丹药、特定奇遇化解

## 9.1 系统定位与核心原则
9.1.1 定位
战斗是弟子养成的核心验证环节，承接装备、法宝、功法、灵兽、灵根等所有养成模块的数值落地，同时支撑历练、秘境、宗门战争、PVP 等核心玩法循环。整体采用回合制半即时制，兼顾策略深度与托管效率，支持全自动战斗、半自动托管、手动操作三种模式。
9.1.2 核心设计原则
1.乘区统一：所有增益、减益严格归入对应战斗乘区，遵守全局硬上限规则，与养成系统数值一一对应，无独立战斗数值体系。
2.职业差异化：体修、道修、法修三职业定位明确，前排 / 中排 / 后排分工清晰，不存在全能职业，组队搭配具备策略性。
3.五行强关联：伤害、克制、技能效果与弟子灵根深度绑定，灵根纯度直接影响战斗收益，强化灵根养成价值。
4.托管友好：默认支持全自动战斗，AI 逻辑合理；手动操作仅提升上限，不形成碾压，适配佛系与硬核两类玩家。

## 9.4 防御属性溢出治理（对齐 4.4 红线，原 §9.4 保留）
9.4.1 核心设计原则
设计意图：闪避 / 招架 / 减伤 / 免疫类属性本质是「防御端数值溢出」，与攻击端战力膨胀同源。根治 = 统一叠加规则 + 硬上限兜底 + 边际收益衰减 + 对应属性制衡，并严格区分「常驻属性」与「临时技能效果」。
1. 常驻属性永不允许 100%：闪避、招架、减伤、抵抗等所有防御类属性，常驻堆叠永远达不到 100%，设置明确硬上限。
2. 叠加用乘算/衰减，不用线性加算：线性加算是数值失控的万恶之源，所有同类属性叠加采用边际衰减公式，越往上收益越低。
3. 互斥原则：闪避、招架、格挡等规避类效果互斥，同一伤害只触发其中一种，禁止多重叠加变相达成 100% 无伤。
4. 制衡原则：有防御就有对应穿透属性——闪避对应命中、减伤对应穿透、免疫对应效果命中，形成动态制衡，不会出现「堆到满就无解」。
5. 区分常驻/临时：常驻属性卡严上限；临时技能效果可放宽，但必须有回合数/次数限制，不能全程覆盖。

9.4.2 分类落地规则与计算公式
结算顺序（单次伤害）：① 规避判定（招架 > 闪避 > 命中，互斥单次判定）→ ② 命中后按 9.5 公式结算基础伤害 → ③ 应用减伤%（乘算衰减后）→ ④ 最低伤害兜底（≥1 点气血）。状态抵抗独立于伤害结算，作用于负面效果施加阶段。
#### 9.4.2.1 概率规避类：闪避、招架、格挡
问题根源：线性加算最容易失控（装备 15% + 心法 15% + 灵兽 10% + 大阵 10% + 职业被动 10%，轻松堆到 60%+，后期逼近 100%）。
定案规则：
- 叠加方式：采用边际乘算叠加，公式为：
```
最终规避率 = 1 - (1 - 基础值) × (1 - 词条A) × (1 - 词条B) × (1 - 词条C) × ...
```
每新增一份规避属性，只对「剩余未规避的部分」生效，理论上永远趋近但达不到 100%。
- 硬上限兜底：即使公式算出更高，最终生效值强制封顶。闪避率硬上限 70%、招架/格挡率硬上限 75%（体修专属，承伤定位略高）。
- 互斥判定：同一次伤害只做一次判定，优先级 招架 > 闪避 > 命中，不会「先闪避失败再招架」双重判定。
- 制衡属性：命中百分比直接降低对方最终闪避率。例：对方 70% 闪避、己方 30% 命中，则实际闪避率 = 70% × (1 - 30%) = 49%。
示例：体修基础招架 20% + 装备 20% + 心法 15% + 护山大阵 10%：
```
最终招架率 = 1 - (1-0.2)×(1-0.2)×(1-0.15)×(1-0.1) ≈ 51.3%
远低于 75% 上限，体感有收益但远不到无敌。

#### 9.4.2.2 伤害减免类：物理减伤、法术减伤、全伤害减免
问题根源：减伤线性叠加到 90%+，实际承伤锐减到可忽略；到 100% 即物理/法术免疫，战斗失效。
定案规则：
- 分类上限：常驻全减伤硬上限 70%；常驻单系减伤（物理/法术）硬上限 75%；战斗内临时减伤（技能/符箓/法宝）硬上限 90%，持续回合 ≤ 3，不可全程覆盖。
- 叠加方式：同类型减伤先加算，达阈值后进入衰减区；全减伤与单系减伤为乘算关系，避免叠加失控。
- 衰减规则（可选更丝滑方案）：减伤堆到 60% 之前全额生效，60%~80% 部分按 50% 折算，80% 以上部分按 20% 折算，最终强制卡上限。
- 制衡属性：护甲穿透/法术穿透 = 无视对应比例减伤。例：对方 70% 物减、己方 20% 物穿，实际减伤 = 70% × (1 - 20%) = 56%。
- 最低伤害兜底：无论减伤多高，单次伤害最低强制扣 1 点气血，杜绝「0 伤害」。
示例：体修常驻物理减伤 基础20% + 装备25% + 心法15% + 大阵10% = 70%，再叠加临时减伤技能 20%，按乘算：
```
最终物减 = 1 - (1-0.7)×(1-0.2) = 76%
常驻已达单系安全线，临时减伤单独算最高至 90%，此处 76% 安全，远达不到免疫。

#### 9.4.2.3 状态免疫类：毒免、控免、debuff 免疫
问题根源：「100% 免疫中毒」「100% 免疫控制」会直接废掉对应职业/玩法核心机制（毒系功法、控制型法修彻底失业）。
定案规则：绝对不做常驻 100% 免疫，全部转化为「抵抗率 + 效果衰减」双维度：
1. 状态抵抗率：概率完全抵抗该负面效果，硬上限 85%，永远留 15% 命中可能。叠加方式同闪避（乘算衰减），由装备/心法/道心提供；制衡属性「效果命中」降低对方抵抗率，逻辑同 命中 vs 闪避。
2. 效果强度衰减：即使未抵抗成功，也按抗性比例降低效果。例：50% 毒抗 = 50% 概率抵抗中毒；若未抵抗，则毒伤降低 30%、持续时间缩短 20%。
3. 「免疫」仅允许三种形式：① 短时效技能（如「接下来 2 回合免疫控制」，明确回合限制）；② 境界压制（高一个大境界对低一阶负面状态 100% 免疫，同阶无效，符合修仙世界观且不破坏平衡）；③ 特定低阶免疫（如「免疫凡品以下毒素」，高阶毒依然生效）。
示例：弟子丹毒抗性 基础10% + 洗髓池15% + 道心10% + 装备10%：
```
最终抵抗率 = 1 - (1-0.1)×(1-0.15)×(1-0.1)×(1-0.1) ≈ 38.7%
有明显收益，但远做不到全程免毒，丹毒系统依然有效。

9.4.5 防御属性等效战力折算（生存时间等价法）
设计意图：防御属性（减伤 / 闪避 / 招架 / 抵抗）不直接提升伤害，但延长单位有效生存时间；把「生存时间提升比例」等价换算为战力增益比例，使攻防在同一战力体系下可比价，避免防御堆高后战力虚标、突破红线。
核心公式：
```
等效战力增益系数 = 1 / (1 - 综合生存减免率) - 1
综合生存减免率 = 综合减伤 × (1 - 综合规避率)   # 即“最终实际承伤占比”
```
分类计算细则：
- 减伤类（物理 / 法术 / 全减伤）：减伤等效增益 = 1 / (1 - 减伤率) - 1。示例：30% 常驻减伤 → 1/0.7 - 1 ≈ 42.9%。约束：等效增益需折算后计入通用增益乘区，遵守 25% 全局封顶，而非让减伤无限堆叠。
- 规避类（闪避 / 招架 / 格挡）：规避等效增益 = 规避率 / (1 - 规避率)。示例：40% 闪避 → 0.4/0.6 ≈ 66.7%。互斥修正：闪避 / 招架互斥、单次仅判定一次，最终取等效增益最高项计入，不叠加。
- 状态抵抗类：不直接折算常驻战力，仅计入战斗临时乘区，按实际生效回合计收益；等效收益 = 控制时长减免比例 × 敌方控制技能占比。
面板战力折算规则（对齐 25% 封顶）：
- 基础防御值（装备 / 境界 / 灵根提供的防御数值）：直接计入基础属性乘区，无封顶，随成长自然提升。
- 百分比防御增益（心法 / 大阵 / 灵兽羁绊的防御 +X%）：先换算为等效战力增益率，再计入通用增益乘区，与攻击类增益共同占用 25% 总额度。
- 减伤率 / 规避率本身不直接乘进战力面板，仅作战斗内机制；其等效收益已通过「防御百分比增益」体现在战力中。
数值校验示例（对齐上限）：常驻全减伤上限 70% → 理论等效增益约 233%，但受 25% 通用增益封顶限制，玩家实际能堆到的常驻等效防御增益最高 25%，对应常驻减伤约 20%，远低于 70% 硬上限；70% 硬上限仅为机制兜底，正常养成触达不到，保证红线有效。

9.4.6 防御独立乘区架构
设计原则：① 攻防对称——攻击端有多少层乘区，防御端对应设多少层，避免单边膨胀；② 红线统一——所有常驻百分比增益归入通用增益乘区，共享 25% 封顶，不单独开例外；③ 机制独立——减伤 / 规避 / 抵抗属战斗机制层，单独设独立计算层，各有硬上限，不参与战力乘区放大。
四层防御乘区架构：
| 乘区层级 | 包含内容 | 计算规则 | 是否占用 25% 通用封顶 | 硬上限 |
| --- | --- | --- | --- | --- |
| 基础防御乘区 | 境界基础防御、资质系数、灵根系数、职业基础系数 | 连乘计算基础防御值 | 否（基础属性，自然成长） | 无 |
| 防御增益乘区 | 装备词条、心法被动、宗门大阵、灵兽羁绊提供的「防御 +X%」 | 加算后统一乘进基础防御 | 是（等效收益计入通用增益） | 随全局 25% 封顶 |
| 减伤机制独立层 | 物理减伤、法术减伤、全伤害减免 | 同类加算、跨类乘算；常驻与临时分开 | 否（机制层，有自身硬上限） | 常驻 70% / 临时 90% |
| 规避机制独立层 | 闪避、招架、格挡 | 同类乘算衰减，不同类互斥取最高 | 否（机制层，有自身硬上限） | 闪避 70% / 招架 75% |
| 临时战斗防御层 | 战斗内技能、符箓、法宝、援军提供的护盾 / 减伤 / 规避 | 单局生效，同类取最高 | 否（临时乘区，局内结算） | 单回合最高 90% |
完整防御结算公式：
```
最终实际承伤 =
  原始伤害
  × (1 - 防御增益乘区折算减伤)
  × (1 - 减伤机制层常驻减伤)
  × (1 - 临时战斗层减伤)
  × (1 - 最终规避率)   # 规避成功则伤害为 0
  - 护盾吸收值
```
其中「防御增益乘区」的百分比加成先提升基础防御值，再通过防御公式转化为减伤，避免直接叠减伤导致指数级膨胀。
代码落地建议：在 disciple.gd 新增两个结算接口，统一所有防御属性计算入口：
```gdscript
# 获取面板等效防御战力（用于总战力计算，遵守 25% 封顶）

    var base = realm_base_def * quality_factor * spirit_root_factor
    var bonus = min(common_defense_bonus, 0.25)  # 对齐通用增益封顶
    return base * (1 + bonus)

# 获取战斗内最终减伤与规避（机制层，有独立硬上限）
func get_battle_defense() -> Dictionary:
    return {
        "damage_reduce": min(resident_reduce + temp_reduce, 0.9),
        "dodge_rate": min(dodge_final, 0.7),
        "parry_rate": min(parry_final, 0.75)
    }
```

## 9.5 伤害计算公式
9.5.1 通用乘区规则（强制遵守）
- 攻击加成乘区：包含装备、法宝、功法、灵兽等所有攻击增益，软上限 80%（×1.8 封顶），超出部分收益减半。**＞ 层级注记：本上限为「战斗攻击子乘区」专属封顶，与 §4.1 通用增益池（软 25% / 硬 30%）为独立计算层——前者约束攻击向增益的堆叠空间，后者约束全局增益总额度，二者互不占用、分别结算。实现时须保证两套上限独立命中。**
- 减伤乘区：包含防御、技能、套装、阵法等所有减伤效果，硬上限 70%，超出部分直接无效。
- 五行克制乘区：独立乘区，不受上述上限影响。
- 真实伤害：无视防御与减伤，直接扣除气血，不计入任何乘区。
9.5.2 物理伤害公式
```
最终伤害 =
基础伤害 × 攻击加成乘区 × (1 - 防御减伤率) × 五行克制乘区 × 暴击倍率 × 最终增伤乘区 × (1 - 最终减伤乘区)
```
参数说明：
1. 基础伤害 = 攻击者攻击力 × 技能伤害倍率
2. 攻击加成乘区 = 1 + 所有攻击类增益之和（上限 1.8）
3. 防御减伤率 = 防御值 / (防御值 + 60 × 目标等级)，最高不超过 70%
4. 五行克制乘区：克制 = 1.2，被克制 = 0.85，同属性 = 1.0
5. 暴击倍率：基础 1.5 倍，受暴击伤害加成提升
6. 最终增 / 减伤：独立乘区，包含技能、阵法、法宝特效，增减分别计算
9.5.3 法术伤害公式
与物理伤害公式结构一致，仅将「攻击力」替换为「法术强度」，「防御减伤」替换为「法抗减伤」；法抗值由弟子灵力、功法、装备共同提供。
9.5.4 治疗与护盾公式
```
治疗量 = 基础治疗值 × 治疗加成乘区 × (1 - 目标受治疗衰减)
护盾值 = 基础护盾值 × 护盾加成乘区
```
护盾优先于气血承受伤害，多个护盾按释放顺序依次抵扣；护盾持续时间结束后自动消失。

## 9.6 五行克制数值体系
9.6.1 基础克制关系
金 → 木 → 土 → 水 → 火 → 金，形成闭环克制：

2. 多段伤害技能每一段单独判定克制。
3. 真实伤害、固定伤害不触发五行克制。

1. 进场准备阶段
   - 双方单位按站位排布，加载所有装备、法宝、灵兽、阵法的常驻属性
   - 触发所有进场被动效果（如本命法宝祭炼特效、灵兽先手加成）
   - 按单位速度值从高到低排序，生成本回合行动顺序
2. 回合开始阶段
   - 结算所有持续型 buff/debuff 的回合数
   - 结算灼烧、中毒等持续伤害 / 治疗
   - 灵力自动回复（每回合回复 10 点基础灵力）
3. 单位行动阶段
   - 按行动顺序依次行动，每个单位可选择：普攻、释放技能、防御、使用道具
   - 行动结束后，触发受击反馈、反击、追击等被动效果
4. 回合结束阶段
   - 检查双方存活单位
   - 若一方全灭，直接进入结算
   - 回合数 + 1，进入下一回合
5. 战斗结算阶段
   - 判定胜负，计算奖励（经验、材料、声望）
   - 结算弟子状态：伤亡、灵力消耗、耐久损耗
   - 生成战斗战报，支持回看
9.7.2 结算优先级规则
buff/debuff 结算顺序：持续伤害 → 控制状态 → 增益 buff → 减益 buff → 灵力回复
控制状态（冰冻、眩晕）优先结算，被控单位本回合无法行动，跳过其行动条。

## 9.8 敌方 AI 逻辑
按敌方类型分为 4 档 AI，难度与行为模式逐级提升：
9.8.1 普通小怪 AI
- 攻击目标：优先攻击敌方前排单位，前排阵亡后依次攻击中排、后排
- 技能逻辑：冷却结束即释放，无目标选择策略
- 适用场景：低阶历练、普通矿脉妖兽、巡逻小怪
9.8.2 精英怪 AI
- 攻击目标：优先攻击血量最低的单位，集火收割
- 技能逻辑：技能循环释放，血量低于 30% 时释放防御 / 回血技能
- 适用场景：秘境精英怪、高阶历练首领、邪修小头目
9.8.3 BOSS 级 AI
- 阶段式机制：血量每降低 30% 进入新阶段，技能组升级
- 攻击逻辑：
  - 常规阶段：随机攻击 + AOE 技能循环
  - 暴怒阶段：释放高伤害全屏技能，附加减益效果
  - 濒死阶段：释放大招，有概率秒杀低血量单位
- 适用场景：秘境最终 BOSS、宗门战争首领、上古传承守卫
9.8.4 邪修专属 AI
- 攻击目标：优先攻击我方战力最低、品质最差的弟子，逐个击破
- 技能逻辑：附带心魔、减防等负面效果，持续削弱我方
- 适用场景：邪修入侵、魔道据点、PVP 敌对宗门弟子
9.8.5 自动战斗我方 AI
- 基础逻辑：优先释放冷却好的高伤害技能，灵力不足时普攻
- 智能规则：
  - 体修血量低于 50% 优先释放护盾 / 防御技能
  - 敌方多单位存活时法修优先放群体技能
  - 敌方仅剩 1 个单位时优先单体高伤技能
- 手动操作优势：可精准控技能节奏、集火目标，整体输出比自动高约 10%-15%

## 9.9 与现有养成系统的对接规则

### §9.11 战斗系统设计详解与落地附录（扩展）

一、战斗系统职业差异化定位
采用经典「铁三角」分工模型，三职业在站位、职能、成长曲线、适配场景上形成明确区隔，无全能职业，组队搭配具备策略刚性；同时单职业可独立应对日常低难度玩法，不强制组队。
| 职业 | 站位 | 核心定位 | 核心属性 | 适配灵根 | 不可替代价值 | 核心短板 | 适配玩家类型 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 体修 | 前排 | 承伤坦克、反击副 C | 气血上限、防御力、反击率 | 土、金 | 承伤阈值最高，可吸引敌方火力，保护后排输出 | 单体输出偏低，无群体能力，控制手段少 | 稳健型、偏好防守反击 |
| 道修 | 中排 | 单体爆发、功能辅 C | 攻击力、暴击率、灵力 | 金、水 | 单点爆发上限最高，可附加破甲、增益等功能性效果 | 群体输出乏力，续航能力一般 | 均衡型、偏好精准点杀 |
| 法修 | 后排 | 群体输出、状态控制 | 法术强度、效果命中 | 火、水 | 群体清怪效率最高，可附加灼烧、冰冻等持续控制 | 身板脆弱，怕突进，技能冷却周期长 | 输出型、偏好 AOE 清场 |
补充定位规则：
1. 同战力下，体修生存能力是法修的 1.8 倍，法修群体输出是体修的 2.2 倍，道修单体爆发为三者最高，形成明确数值差。
2. 日常单人历练可单职业通关，高阶秘境、宗门战必须三职业搭配才能最优效率通关，强制组队策略。
3. 职业由弟子主灵根与初始资质决定，可通过转职道具重置，但成本极高，避免职业同质化。

二、战斗系统技能体系设计
采用「境界解锁层级 + 品阶决定数值」的双层架构，全职业共享统一技能框架，同时保留鲜明职业特色，所有技能数值严格对齐全局 7 品 4 级品阶标准。
1. 技能层级与解锁节奏
技能体系共分 4 层，与弟子境界强绑定，随境界提升逐步解锁，控制前期复杂度：
- 普攻：初始自带，无冷却、无灵力消耗，是战斗的基础输出手段
- 基础技：筑基期解锁，冷却 2 回合，低灵力消耗，承担常规输出 / 防御功能
- 核心技 + 职业被动：金丹期解锁，核心技冷却 3 回合，是职业特色的核心体现；被动天赋永久生效，强化职业定位
- 终结技：元婴期解锁，冷却 5 回合，高灵力消耗，具备扭转战局的高收益效果
2. 技能数值梯度规则
所有技能以「宝品下品金丹期」为基准值，按全局品阶倍率同步缩放，确保和装备、法宝数值同尺度：
- 同大品阶内，细分品级每提升 1 级，技能效果线性提升 15%
- 跨大品阶时，技能效果按全局属性基准倍率跃迁（灵品≈凡品的 2 倍，宝品≈灵品的 2 倍，以此类推）
- 技能等级可通过功法修习提升，每级提升 5% 效果，上限 9 级
3. 职业技能差异化逻辑
- 体修技能：围绕「护盾、减伤、反击、嘲讽」设计，所有技能服务于承伤与反打，无纯输出大招
- 道修技能：围绕「单体爆发、破甲、暴击、增益」设计，主打精准点杀与功能辅助
- 法修技能：围绕「群体伤害、持续灼烧、冰冻控制」设计，主打范围压制与状态干扰
4. 技能释放与 AI 规则
- 手动模式：玩家可自由选择释放时机与目标，操作上限约比自动高 10%-15%
- 自动模式：遵循「高伤技能优先 → 状态技能补全 → 普攻兜底」的逻辑，体修血量低于 50% 优先放防御技能，敌方多单位时法修优先放群体技能
- 所有技能冷却、灵力消耗全局统一尺度，避免某职业技能循环碾压其他职业

三、战斗系统五行克制数值体系
五行克制为独立伤害乘区，不受其他增益 / 减伤乘区上限影响，是灵根资质的核心战斗价值体现；数值强度可控，不击穿基础平衡。
1. 基础克制关系与核心数值
闭环克制链：金 → 木 → 土 → 水 → 火 → 金
| 攻防关系 | 伤害修正系数 |
| --- | --- |
| 攻击方克制防御方 | 伤害 × 1.2 |
| 攻击方被防御方克制 | 伤害 × 0.85 |
| 同属性 / 无属性 | 伤害 × 1.0 |
2. 灵根纯度修正系数
| 灵根类型 | 克制伤害加成 | 被克制伤害减免 |
| --- | --- | --- |
| 天灵根（单灵根） | +25% | -18% |
| 双灵根 | +20% | -15% |
| 三灵根（杂灵根） | +15% | -10% |
| 四灵根及以上 | +10% | -5% |
3. 生效范围与判定规则
1. 判定优先级：技能自带属性时，以技能属性为准判定；无属性普攻以弟子主灵根属性为准。
2. 多段伤害：每一段伤害单独判定克制关系。
3. 真实伤害、固定伤害：不触发五行克制，保持数值稳定。
4. 群体技能：对每个目标分别判定克制关系，同一技能对不同目标伤害可不同。
4. 数值边界约束
- 五行克制为独立乘区，不占用攻击、减伤乘区的额度
- 极端情况下（天灵根克制杂灵根），最高伤害修正为 1.4 倍，最低为 0.72 倍，差距控制在合理范围，不会出现属性克制直接秒杀的情况

五、确保战斗系统对齐 7 品 4 级标准的方法
通过「基准锚定 + 倍率映射 + 自动校验」三重机制，保证所有战斗相关内容严格对齐全局品阶体系，不出现独立数值标尺。
1. 基准锚定规则
选取「凡品下品练气期弟子」为全局数值基准单位，所有战斗数值均以此为锚点：
- 凡品下品普攻伤害 = 100% 基础攻击力
- 凡品下品技能伤害 = 130% 基础攻击力
- 所有更高品阶的技能、属性、伤害，均以此基准按固定倍率缩放
2. 品阶倍率映射公式
战斗数值严格遵循全局统一的品阶倍率，不单独设置成长曲线：
- 同大品阶内，细分品级每级倍率 = 上一级 × 1.15
- 跨大品阶倍率：灵品≈凡品 ×2，宝品≈灵品 ×2，王品≈宝品 ×2，以此类推
- 技能效果、属性成长、敌方数值全部套用同一套倍率，确保全体系数值统一
3. 配置表强制校验规则
在 csv_validator.gd 中新增战斗相关校验规则，从工具层面杜绝数值越界：
- 技能倍率校验：同品阶技能伤害倍率不得超出基准值的 ±20% 区间
- 品阶断层校验：高品阶数值不得低于低品阶极品数值，避免数值倒挂
- 乘区上限校验：所有增益效果叠加后，攻击乘区不超 80%、减伤乘区不超 70% 硬上限
- 配置导入前必须通过校验，不通过无法进入游戏
4. 全链路对齐校验点
从养成到战斗全链路验证对齐：
1. 装备、法宝、灵兽的属性数值 → 对齐品阶标准
2. 技能基础数值、成长系数 → 对齐品阶标准
3. 敌方单位属性、技能数值 → 对齐对应品阶的玩家战力基准
4. 战斗最终伤害结果 → 符合乘区规则与品阶倍率预期

一、技能体系：技能层级与解锁节奏详细设计
1. 核心设计原则
采用「境界解锁层级 + 品阶决定数值」的双层架构，技能功能随弟子境界逐步开放，前期控制操作复杂度，后期逐步释放策略深度；所有技能数值严格对齐全局 7 品 4 级品阶标准，无独立成长曲线。
2. 四级技能层级与解锁节点
技能体系共分为 4 个固定层级，与弟子境界一一绑定，不可越级解锁，确保成长节奏清晰可控。
| 技能层级 | 解锁境界 | 技能类型 | 核心定位 | 冷却规则 | 灵力消耗 | 战斗数值占比 |
| --- | --- | --- | --- | --- | --- | --- |
| 普攻层 | 初始自带（练气期即可用） | 普通攻击 | 战斗基础输出兜底，无门槛循环 | 0 冷却，每回合可释放 | 0 消耗 | 前期 60%，后期 30% |
| 基础技层 | 筑基期解锁 | 主动技能 | 补充职业特色基础效果，建立技能循环 | 固定 2 回合冷却 | 低消耗（约占灵力上限 15%） | 前期 30%，中期 25% |
| 核心技层 + 职业被动 | 金丹期解锁 | 主动核心技 + 永久被动 | 职业差异化核心体现，构建核心战斗循环 | 固定 3 回合冷却 | 中消耗（约占灵力上限 25%） | 中期 35%，后期 30% |
| 终结技层 | 元婴期解锁 | 大招主动技 | 高收益扭转战局技能，长线战斗的爆发点 | 固定 5 回合冷却 | 高消耗（约占灵力上限 40%） | 后期 25%-35% |
各层级设计细节
1. 普攻层：全职业统一结构，均为单体无消耗攻击，是灵力不足、技能全冷却时的兜底输出手段。普攻自带对应职业的主灵根属性，直接参与五行克制判定。品阶提升仅放大普攻伤害数值，不改变普攻机制。
2. 基础技层：作为职业特色的入门技能，体修偏向护盾 / 小幅度减伤，道修偏向单体破甲，法修偏向小范围群体伤害。2 回合冷却的设计，保证每 2 回合可释放 1 次，形成「普攻→技能→普攻→技能」的基础循环，上手门槛极低。解锁节点放在筑基期，对应弟子度过新手期，开始接触职业差异化玩法。
3. 核心技层 + 职业被动：核心主动技是职业定位的核心载体：体修开启反击姿态、道修获得高额暴击爆发、法修附加控制效果，是战斗策略的核心。职业被动为永久生效效果，无需手动释放，从机制层面强化职业差异（如体修永久减伤、道修永久暴伤、法修永久属性伤害提升）。3 回合冷却，和基础技形成错峰循环，保证每回合都有技能可释放，避免空窗期。金丹期解锁，对应游戏进入中期，玩家开始接触组队、秘境等深度玩法，需要职业搭配。
4. 终结技层：高投入高回报的大招，具备扭转战局的能力：体修群体控制 + 承伤提升、道修高额单体斩杀、法修全屏群体爆发。5 回合长冷却 + 高灵力消耗，避免频繁释放，保证大招的稀有感和爽感。元婴期解锁，对应游戏进入后期高阶玩法，战斗时长增加，大招的释放时机成为策略点。
3. 技能等级成长节奏：每一个技能都有 9 个等级，通过修习对应功法提升技能等级。成长规则：每提升 1 级，技能基础效果提升 5%，冷却与灵力消耗保持不变。等级上限受技能品阶限制：凡品技能最高 3 级，灵品最高 6 级，宝品及以上最高 9 级。
4. 品阶数值映射规则：所有技能以「宝品下品金丹期」为数值基准，严格对齐全局品阶倍率：同大品阶内，细分品级每提升 1 级，技能伤害 / 效果数值提升 15%；跨大品阶跃迁：灵品技能数值≈凡品的 2 倍，宝品≈灵品的 2 倍，王品≈宝品的 2 倍，以此类推。低品阶技能永远无法在数值上超过高品阶技能，保证品阶成长的价值。
5. 解锁节奏设计目的：① 新手友好：练气期只有普攻，筑基期仅加 1 个技能，玩家逐步接触操作，不会一上来就技能过多产生混乱。② 成长感明确：每突破一个大境界，就解锁一个新的技能层级，突破反馈直接可感。③ 策略渐进：从单技能循环，到双技能搭配，再到大招加入，策略深度随玩家理解同步提升。

二、五行克制数值体系：基础克制与修正系数计算规则
1. 整体计算逻辑：五行克制为独立伤害乘区，不占用攻击加成、减伤等其他乘区的额度，最终克制系数 = 基础克制系数 × 灵根纯度修正系数。在完整伤害公式中，位置如下：
最终伤害 = 基础伤害 × 攻击加成乘区 × (1 - 防御减伤率) × 最终五行克制系数 × 暴击倍率 × 最终增伤乘区
2. 基础克制系数计算：闭环克制链：金克木，木克土，土克水，水克火，火克金。
| 攻防属性关系 | 基础克制系数 | 伤害效果 |
| --- | --- | --- |
| 攻击方属性 克制 防御方属性 | 1.2 | 伤害提升 20% |
| 攻击方属性 被克制 防御方属性 | 0.85 | 伤害降低 15% |
| 同属性 / 无属性 / 无克制关系 | 1.0 | 伤害无变化 |
判定规则：技能自带明确属性时，以技能属性为准判定克制关系；无属性普攻、通用无属性技能，以攻击者的主灵根属性为准判定；多段伤害技能，每一段单独判定克制系数；防御方的判定属性，以自身主灵根属性为准。
3. 灵根纯度修正系数计算：灵根纯度会对基础克制的幅度进行二次缩放，灵根越纯，克制与被克制的幅度都越大；杂灵根的克制波动更小，表现更平稳。
| 攻击者灵根类型 | 克制时幅度修正 | 被克制时幅度修正 | 最终克制系数 | 最终被克制系数 |
| --- | --- | --- | --- | --- |
| 天灵根（单灵根） | 1.25 倍 | 1.2 倍 | 1.25（+25% 伤害） | 0.82（-18% 伤害） |
| 双灵根 | 1.0 倍 | 1.0 倍 | 1.2（+20% 伤害） | 0.85（-15% 伤害） |
| 三灵根（杂灵根） | 0.75 倍 | 0.67 倍 | 1.15（+15% 伤害） | 0.9（-10% 伤害） |
| 四灵根及以上 | 0.5 倍 | 0.33 倍 | 1.1（+10% 伤害） | 0.95（-5% 伤害） |
标准计算公式：
- 克制场景（攻击方属性克制防御方）最终克制系数 = 1 + 0.2 × 纯度幅度修正系数。示例：单灵根金攻击木属性目标 最终系数 = 1 + 0.2 × 1.25 = 1.25
- 被克制场景（攻击方属性被防御方克制）最终克制系数 = 1 - 0.15 × 纯度幅度修正系数。示例：单灵根火攻击水属性目标 最终系数 = 1 - 0.15 × 1.2 ≈ 0.82
4. 数值边界与计算示例：
极端值边界：最高克制系数：单灵根攻击被克制目标 = 1.25（伤害 + 25%）；最低克制系数：单灵根攻击克制自己的目标 = 0.82（伤害 - 18%）。克制收益差距控制在合理范围，不会出现属性克制直接秒杀的情况，保证基础属性、装备养成的主导地位。
完整计算示例：已知：道修（金单灵根）攻击力 1000，使用无属性普攻攻击木属性目标，目标防御减伤 30%，无其他加成。
1. 基础伤害 = 1000 × 100% = 1000
2. 防御减伤后伤害 = 1000 × (1-0.3) = 700
3. 五行最终克制系数 = 1.25
4. 最终伤害 = 700 × 1.25 = 875
5. 生效范围说明：生效：物理伤害、法术伤害、技能伤害、普攻伤害，均触发五行克制。不生效：真实伤害、固定伤害、护盾吸收量、治疗量，不触发五行克制。附加规则：控制效果的命中概率也受五行克制小幅影响，克制时控制命中 + 10%，被克制时控制命中 - 10%。

一、技能等级成长、品阶数值映射规则及设计目的
1. 核心架构逻辑：技能数值采用「技能等级线性成长 + 品阶层级跃迁」的双层架构，两者完全解耦：技能等级是同一品阶内的纵向养成深度，只放大数值，不改变技能机制；品阶层级是跨品阶的横向品质跃迁，既放大数值，也决定技能机制上限与等级上限。所有规则严格复用全局「7 大品阶 × 4 细分品级」标准，与装备、法宝、灵兽等养成体系共用同一套数值倍率，实现单一数据源。
2. 技能等级成长规则：
- 等级上限与品阶绑定：品阶越高，技能可升级的上限越高，低品阶技能无法通过等级追平高品阶数值。
| 技能品阶 | 最高等级 | 解锁要求 |
| --- | --- | --- |
| 凡品 | 3 级 | 练气期即可修习满级 |
| 灵品 | 6 级 | 筑基期可修习满级 |
| 宝品及以上 | 9 级 | 金丹期后逐步修习至满级 |
- 成长数值：每提升 1 级，技能的伤害、护盾、治疗等基础效果提升 5%；技能冷却、灵力消耗、机制逻辑保持不变。
- 成长方式：通过修习对应功法、消耗技能点 / 秘籍提升等级，属于长线养成内容。
设计目的：① 提供长线养成空间；② 降低理解成本（只提升数值不改变机制）；③ 品阶价值保底（等级成长有上限，低品阶技能即使满级，数值也低于高品阶初始技能）。
3. 品阶数值映射规则：以宝品下品金丹期技能为全局基准值，所有品阶技能均以此为锚点按固定倍率缩放。
- 同大品阶内，细分品级映射：从下品→中品→上品→极品，每提升一级细分品级，技能基础效果提升 15%。例：凡品中品 = 凡品下品 × 1.15；凡品极品 = 凡品下品 × 1.15³ ≈ 1.52 倍。
- 跨大品阶，层级跃迁映射：灵品下品 ≈ 凡品极品 × 1.3 ≈ 凡品下品 × 2 倍；宝品下品 ≈ 灵品极品 × 1.3 ≈ 灵品下品 × 2 倍；以此类推。
- 机制边界规则：低品阶技能永远不会拥有高品阶的机制，数值 + 机制双重保证品阶价值；严格禁止数值倒挂：高品阶下品技能数值，必然高于低品阶极品技能。
4. 整体设计目的：① 全局体系统一（复用同一套品阶倍率）；② 成长节奏清晰；③ 平衡可控（数值按固定倍率缩放，不超模）；④ 内容扩展性强（新增技能只需标定品阶与品级，自动套用倍率生成数值）。

二、各层级技能在冷却、消耗、占比上的具体区别
| 技能层级 | 解锁境界 | 冷却回合 | 灵力消耗占比（占灵力上限比例） | 输出占比（前期） | 输出占比（后期） | 核心定位 |
| --- | --- | --- | --- | --- | --- | --- |
| 普攻 | 初始自带 | 0 冷却，每回合可释放 | 0% | 60% | 30% | 基础兜底输出，技能空窗期填充 |
| 基础技 | 筑基期 | 2 回合 | 15% | 30% | 25% | 建立基础技能循环，补充职业特色 |
| 核心技 + 职业被动 | 金丹期 | 3 回合 | 25% | 10% | 30% | 职业差异化核心，构建主力输出循环 |
| 终结技 | 元婴期 | 5 回合 | 40% | 0% | 15% | 高爆发大招，扭转战局的爽点 |
分项设计说明：1. 普攻：零成本兜底，前期占比最高，后期占比下降但仍为技能冷却期稳定填充，自带主灵根属性。2. 基础技：2 回合短冷却，形成简单循环，低灵力消耗，效果偏向基础职业特色。3. 核心技：3 回合冷却，与基础技错峰，是职业差异核心载体，配套职业被动永久生效固化职业定位。4. 终结技：5 回合长冷却 + 高灵力消耗，后期占比逐步提升，是战斗爽感核心来源。

三、五行克制数值体系的数值确定依据
所有数值均围绕「有感知、不碾压、强关联、控边界」四大原则确定。
1. 基础克制系数的确定逻辑：基础克制设定为克制 + 20%、被克制 - 15%。
- 感知强度适配：20% 的伤害提升处于「玩家可明显感知，但不会导致战局一边倒」的区间。
- 不对称设计：克制收益（+20%）略大于被克制损失（-15%），鼓励主动搭配属性。
- 乘区兼容性：作为独立乘区，20% 幅度不会和其他增益叠加后导致数值失控。
2. 灵根纯度修正系数的确定逻辑：
| 灵根类型 | 克制最终系数 | 被克制最终系数 | 梯度差 |
| --- | --- | --- | --- |
| 单灵根 | 1.25（+25%） | 0.82（-18%） | 最高档，体现稀有度 |
| 双灵根 | 1.2（+20%） | 0.85（-15%） | 基准档，对应主流弟子 |
| 三灵根 | 1.15（+15%） | 0.9（-10%） | 均衡档，波动更小 |
| 四灵根及以上 | 1.1（+10%） | 0.95（-5%） | 稳定档，几乎无波动 |
- 灵根价值分层：每档约 5% 的克制收益差，梯度清晰。
- 极端值收敛：最高克制 1.25 倍、最低被克制 0.82 倍，波动控制在 ±25% 以内。
- 世界观契合：灵根越纯，对五行法则掌控力越强。
3. 整体边界管控原则：① 独立乘区不溢出；② 非全覆盖生效（真实伤害、固定伤害、治疗、护盾不触发）；③ 可策略抵消（玩家可通过组队搭配多属性弟子、更换技能属性来规避被克制）。
