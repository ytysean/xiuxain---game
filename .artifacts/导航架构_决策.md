## 一、导航总原则

底部5Tab = 全局功能分类导航（管理向、列表式）；侧边快捷栏 = 高频/沉浸功能入口（场景化）。权责分离，不重叠，玩家认知成本最低。

## 五、山门定位决策（升级A方案 · 2026-08-09 拍板）

### 5.1 决策结论

宗门内外总出入口（升级A方案）：底部「宗门」Tab 管内部经营，侧边「山门」管外部探索，权责完全分离，不重叠。

### 5.2 分阶段落地路径

**S1 阶段（无大地图，先做功能收口）**

- S1：点击山门 → 「外出探索」子页，收口历练（底部历练Tab沉浸入口）+ 秘境探索 + 预留凡间城镇/据点占位；
- 底部「历练」Tab 保留为快捷管理页（领奖/次数/扫荡），与山门沉浸探索互补不重叠。

**大地图阶段（无缝升级）**

- 大地图上线后：山门 → 世界大地图切换枢纽（历练点位 / 秘境洞府 / 凡间城镇 / 敌对势力 / 己方分据点），成为宗门主城↔大世界唯一切换点。
- 历练关卡 / 秘境洞府 / 凡间城镇 / 敌对势力 / 己方分据点 在大地图点位化呈现。
- 山门成为「宗门主城 ↔ 大世界」唯一切换枢纽。

### 5.3 方案取舍说明

- **放弃 B 方案**：B方案（回城/刷新）冗余：底部第一个Tab即宗门主城，无需重复入口。
- **放弃 C 方案**：C方案（场景热区总入口）层级错位：场景热区载体应是背景画面本身（点主殿进殿阁/点丹房进炼丹），侧边栏是全局快捷入口，不应混用。

### 5.4 视觉与战斗铁律

- 视觉暗示：视觉稿可给山门按钮加轻微「向外延伸」暗示，强化出门探索语义。
- 战斗铁律：所有历练/秘境均为放置/管理向地图点位选择，不涉及即时战斗操作，符合 S1 零战斗触碰铁律。

### 5.5 设计/工程落地节奏

- P0 结构稿不动山门文本/位置；P1 交互标注统一写「点击进入世界探索界面，S1开放历练/秘境，后续迭代大地图」，工程侧预留路由扩展。
- **工程侧路由预留**：山门入口须预留路由扩展位（S1 指向「外出探索」子页；大地图上线后改为指向世界大地图），入口逻辑切换无需改动导航结构。
