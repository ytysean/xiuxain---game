## 1. 弹窗定位
- 居中模态：半透明遮罩（ColorRect）+ 面板（PanelContainer）+ 内容（VBox）。
- 用途：物品/装备详情、弟子属性（命格/灵根/性格/职业）详情。
- 单一外壳 `_new_detail_popup(标题, 标题色=暗金)`，样式改一处全量生效。

## 3. 信息架构
```
[遮罩]
└ [面板]
   ├ 标题（暗金）：物品详情
   ├ 物品名（七品阶染色）：玄铁剑 · 凡
   ├ 属性行：类别 / 品阶 / 攻防 / 来源 / 描述
   └ 操作：知悉（主按钮）
```

## 4. 交互规则
- **关闭**：①「知悉」按钮；② 点击遮罩区域（透明全屏 Button 置于面板下）；③ ESC 键（遮罩获焦接收键盘）。
- **入场**：面板 0.15s 淡入 + 轻微缩放（绕中心 `pivot_offset=(190,210)`，不移位）。
- **长内容**：滚动区高度 `min(340, 视口高×0.7)` + EXPAND_FILL，超视口 80% 自动滚动。
