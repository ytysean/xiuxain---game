# 《太玄宗门录》UI 绘图强制规范 · v2.0 正式版（出图唯一强制基准）

> **本文件定位**：后续**所有 UI 美术出图（含 AI 绘图 / 手绘 / 切片参考）的唯一强制基准**。**永久沿用**，画师 / AI 出图时逐条对照，**违反直接重绘**。

> **来源与权威**：本 v2.0 正式版以**用户 2026-07-24 最终定夺**为最高权威，整合 docx《新建 DOCX 文档 (2)》写实修仙出图规范内容与既有规范（v1.1 / 写实修仙UI可执行规范 / UI硬性约束规范）而成。

> **铁律**：凡本文件的「必须 / 禁止」与 AI 自由发挥、旧习惯、零散出图冲突，**一律以本文件为准**。**本文件不修改任何代码（`main.gd` 一律不动）**，也不修改 `写实修仙UI可执行规范.md` / `UI硬性约束规范.md`；如遇与另两份规范的分歧，仅在回传中提请主理人裁决，**不擅自改写另两份规范**。

## 1. 信息架构总览（三级层级 · 5 Tab 唯一基准）

> **终裁要点（用户 2026-07-24 终裁）**：底部主导航固定 **5 个一级 Tab（宗门 / 弟子 / 御兽 / 历练 / 纪事）**；「宗门」页承担**主屏首页**职能（顶部资源状态 + 宗门全景/经营数据 + 快捷入口网格 + 底部 5 Tab）；洞府、修炼**不再作为一级导航**，下沉为「宗门」页快捷入口网格内的功能入口；坊市/任务/建筑/账册/洞府视图/修炼设施为**二级功能页**，由「宗门」页快捷入口进入；历练为**独立整页 5 Tab 之一**（非弹窗）；弟子详情/离线收益/奇遇/秘境战斗/七载大典为**弹窗**。

### 1.1 三级层级
- **一级**：5 个底部 Tab（宗门 / 弟子 / 御兽 / 历练 / 纪事），点击 = 整页切换。
- **二级**：功能页（坊市 / 任务 / 建筑 / 账册 / 洞府视图 / 修炼设施等），由「宗门」页快捷入口网格进入，左上角「← 返回」回宗门页。
- **弹窗**：弟子详情、离线收益、弟子奇遇、秘境遭遇/战斗、七载大典等，叠在底层主界面之上的半透明遮罩弹窗。

### 1.2 五个一级 Tab 固定顺序与职责
| 顺序 | Tab | 一句话职责 |
| --- | --- | --- |
| 1 | **宗门** | 宗门主页（=主屏首页）：顶部资源状态栏 + 宗门全景/经营数据 + 快捷入口网格（洞府/修炼/坊市/任务/建筑/账册等）+ 底部 5 Tab |
| 2 | **弟子** | 弟子名录与接引（二级 Tab：名录/接引）；点弟子进「弟子详情」弹窗 |
| 3 | **御兽** | 灵兽列表 / 培养 / 出战管理（二级 Tab：灵兽/繁育/出战） |
| 4 | **历练** | 历练地图 / 战斗 / 探索入口（独立整页，非弹窗） |
| 5 | **纪事** | 宗门纪事分类浏览（全部/宗门大事件/宗门岁纪/日常庶务/异闻） |

### 1.3 二级功能页清单（统一由「宗门」页快捷入口进入）
- 坊市（交易买卖，独立二级页，见 §8.2）
- 任务（师门任务 / 活动领取）
- 建筑（建筑总览与建造/升级，见 §8.3）
- 账册（实时产出速率 / 收支构成）
- 洞府视图（宗门经营详情子视图，由快捷入口或建筑页进入）
- 修炼设施（突破台 / 闭关之所子视图，由快捷入口或建筑页进入）
- 离线收益简报（上线自动弹出，见 §8.9）

> 二级页一律从「宗门」页快捷入口网格进入，**左上角「← 返回」回宗门页**；底部仍显示全局 5 Tab 且「宗门」高亮；底部**绝不显示**独立坊市、洞府、修炼 等一级导航入口。

### 1.4 弹窗清单
- 弟子详情（卷宗：突破/派遣历练/发付下山）
- 离线收益简报（上线自动弹出）
- 弟子奇遇（事件选择）
- 秘境遭遇 / 战斗场景（从历练页「派遣」进入）
- 七载大典（周期结算，自动写入纪事）

### 1.5 灰锁 / 未解锁态
- **必须** 未解锁 / 未开放功能采用**置灰（灰度降低）不隐藏**，禁直接消失；与 §3 按钮禁用态视觉一致（灰度降 40%）。

### 1.6 整页切换定义
- 5 个一级 Tab 之间 = 整页切换，每页独立承载自身布局（见 §8）。
- 二级页（坊市/任务/建筑/账册等）从「宗门」页快捷入口进，左上角「← 返回」回宗门页；平级一级 Tab 间直接切换、无返回键。
- 弹窗（弟子详情 / 离线收益 / 奇遇 / 秘境战斗 / 七载大典）= 叠在底层主界面之上的半透明遮罩弹窗，不铺满全屏（七载大典为全屏仪式弹窗例外）。

## 2. 通用强制基准（所有界面通用，最先粘贴，杜绝画风/分层/布局翻车）

### 2.1 画布比例
- **必须** 出图比例为**手机竖屏 9:16**（实机逻辑分辨率 480×854）。
- **禁止** 宽屏、横版概念原画；**禁止** 把横图背景裁切后伪装竖屏。
- 出图视角 = **游戏实机 UI 截图视角**（带真实 UI 面板 / 按钮 / 文字的成稿参考），不是纯氛围概念图。

### 2.2 分层铁则（三层 + 暗叠层，后者 z 序在上）【最重要】
- **底层远景图（z_index -100）**：写实修真**云海宗门远景**原画（仙山、云海、远山、古建筑），**高斯虚化**、降低饱和度，`alpha 0.25~0.35`（**默认 0.30**），只做氛围、不抢信息。
- **中间暗叠层（z_index -99）**：纯色 `暗叠层 #16221D`，**固定 alpha 0.50**；压暗底层、保证不透明 UI 层文字/按钮对比，不随场景图变化。
- **中层面板层（z_index 0 及以上）**：所有**圆角 UI 面板 + 控件**（面板 / 按钮 / 列表卡片 / 文字 / 图标），**一律不透明**，叠在两层背景之上。
- **顶层文字图标层**：文字、图标清晰可读，对比充足。
- **禁止** 背景图案穿透面板（远景图不得从面板镂空处或透明度缝里冒出、干扰信息）；**禁止** 背景元素遮挡文字与按钮；**禁止** 远景图 alpha 超出 0.25~0.35（默认 0.30）、暗叠层 alpha 偏离 0.50。

### 2.3 美术基调
- **必须** 写实清雅修真 UI：**深原木底色面板 + 青绿色云纹边角装饰 + 细淡金色描边**（`木色`/`青黛`/`暗金`）。
- 配色柔和，无刺眼强光、无炸裂特效，长时间游玩视觉不易疲劳。
- 色调沉稳青绿灰调，禁止高饱和刺眼色、禁止科技感发光。

### 2.4 排版铁则
- **必须** 功能分区清晰、控件网格对齐，按钮尺寸标准化。
- **必须** 文字层级分明，正文清晰可读；字号锁 `{22,17,18,16,15,13}`（标题22 / 面板17–18 / 小标题15–16 / 正文15下限 / 辅助13），正文 ≥15px，禁止擅自新增字号档。
- **禁止** 界面信息过度拥挤（❌ 禁信息拥挤）；模块边界清晰、留白充足。

### 2.5 五条禁止项（来自 docx 通用强制基准，逐字保留）
- ❌ 禁止背景图案穿透面板（分层铁则，底层远景不得透出干扰）。
- ❌ 禁止背景元素遮挡文字与按钮（❌ 禁背景遮挡文字）。
- ❌ 禁止所有模块堆在首页（❌ 禁模块堆首页，必须分页跳转）。
- ❌ 禁止背景强行拉伸铺满画面（❌ 禁背景拉伸铺满，必须居中、适度虚化降低饱和度）。
- ❌ 禁止控件不对齐（❌ 禁控件不对齐，按钮统一尺寸、网格对齐）。

## 3. 组件统一标准（沿用并细化）

> **铁律**：四类 hex 为终裁锁死值（沿用 `写实修仙UI可执行规范.md §4`），将落地为 `main.gd` 顶部常量。出图引用用常量名；下表 hex 为唯一真值来源，禁止画师另造裸 hex。

### 3.1 面板材质
- 深原木底色 + 青绿色云纹边角 + 细淡金色勾边，圆角矩形。
- 面板底 `宣纸`/`面板底`，边 `青黛` 1–2px，圆角 8（卡片/按钮）/ 10（弹窗主框），文字 `宣纸亮`/`暗金`。
- 弹窗遮罩统一 `弹窗遮罩 #0E1714@0.62`（半透明暗色遮罩，不铺满全屏，七载大典全屏例外）。

### 3.2 按钮四类精确 hex（主绿次棕 · 锁死）
| 按钮类型 | 底色 hex（常量） | 描边 hex（常量） | 文字 hex（常量） | 高度 | 圆角 | 描边 | 适用场景 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **主按钮** | `#2C5F52` 深青玉（`主按钮底`/`玉石绿`） | `#B89B5A` 暗金（`暗金`） | `#F0E6D2` 米白金（`主按钮字`/`宣纸亮`） | **46** | **8** | **2** | 确认 / 领取 / 突破 / 接引等核心正向操作 |
| **次按钮** | `#4A3B2A` 深原木（`次按钮底`/`木色`） | `#3E6B5E` 暗青（`次按钮边`/`青黛`） | `#E8DCC8` 浅米黄（`次按钮字`/`墨黑`） | **40** | **8** | **2** | 返回 / 取消 / 查看 / 派遣等中性操作 |
| **标签 / 筛选按钮** | `#3A6F6080` 半透青玉（`标签底`/`青玉`） | `#5A8B7D`（`标签边`/`玉石绿`） | `#D4E5DE`（`标签字`/`青玉亮`） | **≥44** | **8** | **2** | 分类 Tab / 筛选标签 / 二级切换（白底青玉镶边风；≥44 满足可点击触摸目标下限） |
| **危险按钮** | `#5C3333` 暗红棕（`危险底`） | `#8B5A5A`（`危险边`/`暗金`） | `#E8C8C8`（`危险字`/`宣纸亮`） | **40** | **8** | **2** | 遣散 / 拆除等高风险操作（不在主界面常规栏出现） |

### 3.3 按钮四态（保证可用性，程序落地可直接对应）
| 状态 | 视觉规则 |
| --- | --- |
| **正常态** | 基础样式，颜色沉稳（上表 hex） |
| **悬停 / 选中态** | 底色提亮 10%，描边加粗到 2px，亮度轻微提升 |
| **按下态** | 底色压暗 10%，轻微内缩，模拟按压效果 |
| **禁用态** | 整体灰度降低 40%，文字变灰，描边虚化，视觉不可点击（呼应 §1.5 灰锁不隐藏） |

### 3.4 结构细节（精致感来源）
- **圆角统一**：大圆角 8（面板/卡片/按钮；弹窗主框沿用规范 10，同属大圆角档，本次不改动）/ 小圆角 6（目标条·气泡·Toast）/ 0（通栏分隔条、特定底栏等无需圆角处，保持方正）。**禁止** 有的方有的圆、该圆不圆。
- **内外边距**：按钮文字距左右边框 **24px**、距上下边框 **12px**；面板与组件间距沿用锁定栅格 **{4/6/8/10/12}**。**禁止** 文字贴边。
- **装饰克制**：仅按钮上下边缘加极细云纹 / 回纹，或左右两端加小型玉佩、祥云点缀；**禁止** 满按钮雕花、复杂图案。
- **轻微厚度**：按钮底部加 **1px 深色内阴影**，模拟轻微凸起实体按键感，不用纯扁平。
- **描边**：统一 **2px**（`暗金`/`青黛`/`玉石绿` 按类型）。

### 3.5 字体层级
- 页面大标题 **22** 金色古风宋体（`暗金`/`宣纸亮` 描边）。
- 模块标题 **17–18** 深青色（`青黛`）。
- 正文 / 数值 **15** 深灰黑（`墨黑`/`宣纸亮`）。
- 辅助 **13**。
- 数值档并入 16–18（深底 `暗金` / 浅底 `墨黑`）。正文 ≥15px，禁止擅自新增字号档。

### 3.6 颜色收口
- 所有颜色取自 `main.gd` 顶部常量 + 本文件 §3.2 四类 hex 锁死表；规范色表外新色先入 `main.gd` 常量与 `写实修仙UI可执行规范.md §7`，再出图。

### 3.7 绝对禁忌（避开廉价感）
- ❌ 禁止高饱和纯色填充、彩虹渐变、荧光发光。
- ❌ 禁止按钮加厚重投影、立体浮雕效果，保持轻薄素雅。
- ❌ 禁止每个按钮样式都不一样，同类型按钮必须完全统一。
