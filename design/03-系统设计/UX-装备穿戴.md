### 1.1 可访问性分级（强制引用 `design/gdd/art/ACCESSIBILITY.md`）

- 本 UX 所有交互挂载可访问性分级，默认 **Standard（默认开启·推荐）**；设置可切 Basic（默认关）/ Standard / Comprehensive。
- **最小触控**：所有可点击热区 ≥ 44×44px（Basic 亦须满足，底线要求）。
- **色盲冗余**：品阶/职业仅靠颜色区分时，须叠加 **形状 + 文字** 双通道（品阶角标带 品阶字 + 轮廓，不纯色编码）。
- 特性矩阵与降级对齐见 ACCESSIBILITY.md；本文件「三、竖屏单手布局」热区 ≥44px 即基线落实。

## 二、信息架构（IA）

```
主界面
 └─ 弟子（列表页：圆点/缩写显道途，见 §15.1.6）
     └─ 弟子详情页（6 标签页：属性/装备/功法/灵兽/道心/传记）
         └─ [装备] 标签页  ← 本 UX 主舞台
              ├─ 顶部：弟子名/境界/当前总战力(实时) + 一键最优穿戴按钮
              ├─ 中部：8 槽位网格（4×2 竖屏自适应）
              └─ 底部：已筛选背包（可穿戴物列表）
```

**8 槽位（引用 A1 目标 `EQUIP_SLOTS` 枚举，art ASSET-装备穿戴 §1）**：
slot_weapon(武器) / slot_robe(法袍) / slot_head(头盔) / slot_bracer(护腕) / slot_belt(腰带) / slot_boots(靴子) / slot_accessory(饰品) / slot_artifact(本命法宝)

> 注：A1 重构前代码 `item.gd.穿戴位名` 为 9 槽（含长裤），属 A1 (P0) 重构前；本 UX 与 art 对齐，**统一按 A1 目标 8 槽枚举落地**，不引用旧 9 槽名（衣袍→法袍、配饰→饰品、弃长裤）。5 个高辨识部位映射《角色与UI美术规范》§2.1 的 5 外观槽位（3D 渲染用），UI 面板展示全部 8 槽。

**槽位↔物品映射契约**：
- `法器` 类（类别=`fa_qi`）：穿戴位 ∈ {slot_weapon,slot_head,slot_robe,slot_bracer,slot_belt,slot_boots,slot_accessory}
- `神兵` 类（类别=`shen_bing`）：穿戴位=武器；**额外受 `职业` 约束**（道修/体修/法修，引用 `disciple.职业` 与 `§9.2`）
- `法宝` 类（类别=`fabao`）：穿戴位=本命法宝（唯一，不与其它槽互斥）

## 四、核心流程（穿戴 → 战力实时刷新）

### 4.1 总流程（状态机）

```
[S0 装备页空闲]
   ├─ 点击某槽位(空/已装) → [S1 槽位聚焦]
   └─ 点击「一键最优穿戴」  → [S3 批量结算]

[S1 槽位聚焦]
   ├─ 弹该槽位可穿戴物筛选列表（引用 §4 佩戴限制：仅≤自身境界品阶）
   │     ├─ 选择物品 → [S2 预览对比]
   │     └─ 取消 → [S0]
   └─ 若该槽已装有物品 → 显「卸下」按钮 → [S0 卸下]

[S2 预览对比]
   ├─ 左：当前装；右：候选（含 战力加成/词缀/极品）
   ├─ 实时显「战力 Δ」(候选−当前)
   ├─ 确认穿戴 → [S3]  └─ 取消 → [S1]

[S3 批量结算 / 单次穿戴]
   └─ 写装备映射 → 重算 总战力() → 头条文数字跳动+霓虹光效(§15.4 升级/突破反馈)
       → [S0 刷新]
```

### 4.2 穿戴/卸下 时序

1. 玩家点槽 → UI 调 `Game.穿戴(弟子, 槽key, 物品id)`（**待 eng-lead 补，见七**）
2. 引擎写 `弟子.装备[槽key] = 物品id`，从 `物品` 数组标记 `已装备` 标志
3. 触发 `弟子变动` 信号 → 重算 `总战力()`（**须改为仅计穿戴项，见七**）
4. 战力头条文数字滚动 + 青霓脉冲（§15.4 六·升级反馈，1s 内）
5. 槽位图标刷新为物品缩略 + 品阶色边框（§4.4 边框纹样）

### 4.3 一键最优穿戴

- **定义**：遍历 8 槽，对每槽从「已拥有且未装备且品阶≤境界」的物品中，按 `战力加成` + 词缀折算择优填入；神兵按 `职业` 过滤。
- **约束**：不突破 §4 佩戴限制；不自动消耗/合成；不覆盖玩家手动锁定槽（预留「锁定」态，v2 后做）。
- **反馈**：逐槽级联刷新（可 0.3s 错峰动画），末位弹「战力 +N」总览。

| 风险 | 判定 | 处置 |
| --- | --- | --- |
| **主导策略**：一键最优使所有玩家趋同配装，挤掉策略空间 | ⚠️ 中风险 | 一键最优仅按 `战力加成` 贪心，不读套装/五行/协战协同；**深度玩家仍靠手动凑套装(§8.3.3)/三才协战(§9.2.1)/五行循环(§9.2.2)**。文档明示：一键=省心基线，非最优解。 |

| **支柱漂移**：品阶命名三套并存 | 🔴 须对齐 | 见 INDEX「五、一致性告警 ①」；UI 文案用核心总览 `品` 体系，色值指针美术规范 §4.4。 |

## 六、边缘情况（≥3 类，强制）

1. **佩戴越界**：候选物品品阶 > 弟子境界（§4 佩戴限制）。→ 筛选列表**直接隐藏**越界物，不进入可选池；若玩家经其它途径获得越界物，穿戴时弹「境界不足，需先突破」拦截。
2. **槽位冲突（神兵职业）**：道修神兵Attempt穿戴到非道修弟子。→ 按 `disciple.职业` 校验，不符显灰不可选，tooltip「需 X 修」。
3. **装备映射损坏/空指针**：存档加载后 `装备[槽]` 指向不存在物品 id（§11.21.5 自修复）。→ 载入时 `game_state` 遍历 `装备` 映射，失效 id 自动卸下并归还 `物品` 数组，记日志，不空指针崩溃。
4. **本命法宝唯一性**：法宝已装本命法宝槽，再穿戴第二法宝。→ 先触发「替换？原法宝退回背包」确认，不静默覆盖。
5. **总战力负值/溢出**：词缀极端叠加导致 `战力加成` 异常。→ `总战力()` 下限夹 0；超出 §4.1 部分由数值层衰减，UI 仅显示最终值。
6. **一键最优无可用物**：弟子无未装备可穿戴物。→ 按钮置灰，tooltip「暂无可穿戴物」。
