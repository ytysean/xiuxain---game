## 3. 信息架构

1. **顶部栏**：统一深青底 `#11212A`。
2. **头部面板**：一句话点题。
3. **分类 chips**：4 个（大事件 / 岁纪 / 庶务 / 异闻），默认「大事件」激活（金色描边 + 金字）。
4. **条目列表**：按当前分类展示；每条含 `第N日 · 稀有度 · 名称` 行 + 文案描述。
5. **稀有度高亮**：`天品` / `异闻` 条目行金色加粗，绝不用红色（§6 铁则）。

## 6. 与代码映射

- `ui/page_chronicle.gd`：`_build` 搭头部 + 4 chip + 滚动列表；`_populate` 合并 `Game.宗门纪事` ∪ `Game.传承史册` 并按 `_classify()` 分流。
- 信号：`纪事分类切换(分类)` / `纪事条目详情(索引)`。
- 分类映射（§4.1，UI 侧规则，零 Game 写；未命中→庶务）：
  - `异闻` 稀有度 / category → 异闻
  - `天品` / `宗门` 稀有度 / `传承` category → 大事件
  - 名称含「岁 / 七载 / 大典 / 晋升」→ 岁纪
  - `琐事` / `普通` / `殿阁被动` → 庶务
  - 兜底 → 庶务
- 数据来源：`Game.宗门纪事`（Array）、`Game.传承史册`（Array）。
- 零写入：读数经 `is_instance_valid(Game)` + `.get()` 守卫；chip / 条目仅 emit 占位信号。
