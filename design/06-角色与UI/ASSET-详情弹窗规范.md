# ASSET-详情弹窗 · 调用规范与品阶染色规则（S0 收口）

> 版本：v1.0 ｜ 域：UI / 技术美术 ｜ 阶段：S0 详情弹窗模块收口
> 单一数据源：main.gd（`_new_detail_popup` / `_弹出物品详情` / `_弹出弟子属性弹窗` / `get_rarity_color` / `open_detail` / `open_detail_by_url`）
> ⚠️ 本文件为**开发参考规范**（非铁律）。具体改动以 main.gd 实代码为准；新增系统/实体类型时统一遵循此规范，避免各自实现造成风格不统一。

---

## 1. 弹窗调用规范

### 1.1 当前 S0 可用入口（main.gd）

| 场景 | 调用函数 | 参数 | 说明 |
| --- | --- | --- | --- |
| 物品 / 装备详情 | `_弹出物品详情(物品: Item)` | 物品实例（装备即 Item 实例，复用此函数） | 入参 null → toast「（暂无详情）」后返回 |
| 弟子属性（命格/灵根/性格/职业） | `_弹出弟子属性弹窗(类型, 内容文本, 弟子)` | 类型名 + 详情文本 + 弟子实例 | 入参空弟子 → toast 后返回 |
| 统一外壳（内部） | `_new_detail_popup(标题文本, 标题色=暗金)` | 返回 `{遮, 内容, 关}` | 所有详情弹窗复用，样式改一处全量生效 |

### 1.2 S1 统一分发入口（已预埋，S0 不调用）

| 函数 | 作用 | 现状 |
| --- | --- | --- |
| `open_detail(type, id)` | 类型+ID 统一分发（item/equip→物品弹窗，disciple→弟子弹窗，`_`→toast） | 经 `_解析实体(type, id)` 占位（现恒返 null），S1 接入真实数据源后填实 |
| `open_detail_by_url(url_str)` | 解析 `type:id` 转发 `open_detail` | 战斗日志/奇遇文本富文本点击直接复用 |
| `var _attr_line_pool: Array` | 属性行控件对象池 | S1 内容区复用优化用 |

> ⚠️ 偏差报备：文档原设计假设 `ItemManager.get_item_data` / `Game.取弟子(id)`，但项目当前无 id→实体解析器（弟子甚至无 `id` 字段）。S0 用 `_解析实体` 占位缝，编译零风险，S1 只需填实该函数，存量代码零返工。

### 1.3 关闭方式（全弹窗通用）

1. 「知悉」按钮
2. 点击弹窗外半透明蒙版区域（透明全屏 Button 置于面板之下）
3. 按下 **ESC** 键（遮罩获焦后接收键盘事件）

### 1.4 入场动效 / 长内容兜底

- 入场：面板 0.15s 淡入 + 轻微缩放（绕中心 `pivot_offset=(190,210)`，不移位）
- 长内容：滚动区高度 `mini(340, 视口高×0.7)` + `EXPAND_FILL`，超视口 80% 自动滚动

## 2. 品阶染色规则（全局统一入口）

所有实体的品阶染色**统一调用 `get_rarity_color(品阶: String) -> Color`**，禁止各处硬编码颜色值。

> ⚠️ 偏差报备：物品采用**七品阶**（`item.gd` 的 `品阶` 字段：凡/灵/宝/王/圣/仙/道阶），与奇遇四档稀有度（普通/优秀/稀有/传说）是**两套独立数值体系**，不可强行对齐。染色按物品自身品阶映射。

### 2.1 七品阶色标（代码实值）

| 品阶 | `get_rarity_color` 返回值 (RGB 0~1) | 视觉 |
| --- | --- | --- |
| 凡阶 | `(0.85, 0.85, 0.82)` | 浅灰 |
| 灵阶 | `(0.40, 0.85, 0.45)` | 绿 |
| 宝阶 | `(0.38, 0.68, 1.00)` | 蓝 |
| 王阶 | `(0.70, 0.52, 1.00)` | 紫 |
| 圣阶 | `(1.00, 0.72, 0.32)` | 橙 |
| 仙阶 | `(1.00, 0.42, 0.52)` | 红 |
| 道阶 | `(1.00, 0.85, 0.22)` | 金 |
| 未知/兜底 | `暗金 (0.64, 0.49, 0.22)` | 暗金 |

> 映射常量 `品阶色: Dictionary` 定义在 main.gd 顶部；新增实体类型（功法/丹药等）的品阶染色直接 `get_rarity_color(其实体品阶)` 即可，无需新增颜色定义。

## 3. 降级不崩铁律（对齐项目「解析失败不崩档」）

1. 弹窗入参实体为 null → `_toast("（暂无详情）")` 后 return，不崩溃
2. 物品名为空 → 显示「未知物品」占位
3. S1 `open_detail` 遇未知类型 / 解析失败 → 一律 toast「（暂无详情）」，绝不抛 null.property
4. `_解析实体` 仅在 `OS.is_debug_build()` 下 `push_warning` 告警，正式发布不输出，玩家无感知

---

## 4. 工程实现备注

- 弹窗为纯代码 Control 节点（`ColorRect` 遮罩 + `PanelContainer` 面板 + `VBoxContainer` 内容），无预制 scene、无 AutoLoad 单例，全部挂在 main.gd。
- S1 升级路径：① 把 `_解析实体` 接真实数据源；② 富文本 `[url=type:id]` 绑定 `meta_clicked → open_detail_by_url`；③ 详情内操作按钮（穿戴/派遣历练）复用 `_new_detail_popup` 外壳。底层无需改动。
