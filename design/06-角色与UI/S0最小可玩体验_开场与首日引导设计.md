# S0 最小可玩体验（FTUE）设计方案：开场 · 首日引导 · 主界面信息层级

> 一句话目标：**进来不懵、知道干啥、能跑通核心循环（推演→产出→招徒→养成→考评）。**
> 本文档所有界面/交互/文案/状态均可在现有 GDScript 架构上直接落地；不新增系统、不改动数值平衡、不依赖写实美术成品（用占位+代码 UI）。

---

## 0. 范围与定位（先读这节）

### 0.1 本方案解决什么
真实测试者反馈：「完全没有开场、没有指引、全是各种选项一头雾水、不像能玩的游戏」。根因是主界面**开发者视图**：无标题屏、无引导、所有系统按钮平铺且等权、后期系统（坊市/历练/御兽/玄玉）直接暴露。

### 0.2 设计支柱对齐（防认知过载 / 支柱漂移 / 经济失衡——角色红线）
| 红线 | 本方案处置 |
|---|---|
| **认知过载** | 首日仅暴露 2 个主操作（推演 / 招徒）+ 常驻信息；坊市/任务/历练/御兽 **灰锁**，FTUE 完成后才展开；目标条单屏只显当前 1 步。 |
| **支柱漂移** | 五步目标全部映射到核心循环（推演→产出→招徒→养成→考评），不夹带任何离题系统。 |
| **经济失衡** | FTUE **不发任何资源奖励**（仅正反馈文案），不触碰 §13.1 经济红线；解锁不送灵石。 |
| **主导策略** | 不制造「某一步最优」的捷径依赖；五步为顺序引导，无数值激励倾斜。 |

### 0.3 与既有代码的继承关系（不重写，只演进）
- main.gd 已有 `_引导_初始化 / _引导_开场 / _引导_推进 / _引导_刷新 / _引导_显示气泡 / _引导_收尾 / _引导_跳过 / _引导_清除`（1497–1732 行）与 `引导_步骤文案 / 引导_开场文本` 数据。本方案**复用该状态机骨架**，做三件事：① 补齐缺失的「推演」核心步；② 重排为五步并接入「常驻目标条」；③ 把高亮色从赛博青霓收敛到 v2.0 暗金。
- game_state 已有 `引导阶段: int = 0`（177 行），`load_game` 老档默认 `data.get("引导阶段", 5)`（2058 行）。本方案**复用该字段**，仅扩展阶段语义并微调默认值（见 §5.2），保证存档兼容。

### 0.4 不做（范围克制）
- 不做完整剧情 / 不做捏脸 / 不做宗门命名输入（宗门名固定「太玄宗」，命名是 S1）。
- 不新增任何玩法系统、不加付费、不做 7 日周期 / 红点 / 成就。
- 不接入写实美术成品；所有视觉用代码 UI + 占位（灰模可降级）。

## 2. A. 开场（Title / 开宗）

### 2.1 启动分流（新增 `_显示标题()`，在 `_ready` 最前拦截）

| 启动条件 | 标题屏呈现 | 点击后流向 |
|---|---|---|
| **无存档**（`user://save.json` 不存在） | 仅显示 `[开新宗门]` | → 序章叙事（§2.3）→ 引导阶段置 0 → 主界面 + 目标① |
| **有存档** | 显示 `[开新宗门]` + `[继续]` | `[继续]` → `load_game()` → 主界面；`引导阶段<6` 则恢复目标条+气泡，`>=6` 正常界面 |
| `[开新宗门]`（无论有无存档都显示） | 二次确认弹窗「确定重开宗门？当前进度将清空」→ `new_game()` → 序章 | 覆盖式重开，防呆 |

> **关键改动**：`Game.推演至现在()` 的自动推演**必须延后到标题屏被关闭之后**（点「继续」或序章「开始治宗」后）再执行，否则新档一开机就空推一天。

### 2.2 标题屏（Title）

- **容器**：全屏 `ColorRect` 遮罩（墨青 `#1E2B28` alpha 0.92）+ 居中 `PanelContainer`（玉石/宣纸半透明面板，暗金描边——复用 `新面板()` 形制）。
- **背景**：若 `res://art/_references/ai_art/.../仙山宗门远景_...png` 存在（代码已有 `启用皮肤纹理` 加载逻辑，145 行），以 alpha 0.12 叠加；否则纯宣纸底 + 暗金框，**缺资源静默跳过**，不报错。
- **内容**：
  - 宗门名（暗金，18–22 号，加粗）：`太玄宗`（固定；命名输入留 S1）
  - 标语（石灰，14 号，口语化）：`执掌太玄宗——从一座破落山门，重振仙宗。`
  - 按钮区：`[开新宗门]`（主按钮：暗金框+青玉底）/ `[继续]`（次按钮：木石纹+浅金描边；无存档时隐藏）
  - 角注（石灰，12 号）：`又名：开局接手太玄宗`
- **美术依赖**：仅一张通用水墨远景（可选，缺失则占位）。**无 CG / 无视频**。

### 2.3 开宗序章（轻量多段文字卡，复用 `_引导_开场` / `_引导_开场渲染`）

> 形式：2–3 屏文字卡 + 通用水墨背景（同 §2.2 背景），无动画资产。每屏一「继续 / 开始治宗」按钮推进。复用既有 `引导_开场文本` 结构（修仙化包装），文案口语化、降门槛。

**第 1 屏（钩子）**
- 说话人：`【序章·继位】`
- 文案：`老宗主已然仙去，临终把这座破落山门托付于你。太玄宗虽已式微，根基尚在——重振山门，就在此一举。`

**第 2 屏（内务指引）**
- 说话人：`苏清禾`
- 文案：`掌门莫慌，妾身会一路帮衬。咱宗门的家底就那几样：灵石、灵草、矿石、灵气。先认清它们，日后才好经营。`

**第 3 屏（外事+行动邀请）**
- 说话人：`吴伯`
- 文案：`山下青峰一带妖兽作乱，正可遣弟子去历练长进。不过不急——掌门先推演几日、收点产出、再开接引大典广招门徒，宗门便转起来了。`
- 按钮文案：末屏显示 `开始治宗`（非「继续」）。

> 说明：序章人物「苏清禾 / 吴伯」沿用 GDD-新手引导 既有设定（NPC 人设补全属 S1，本方案仅复用其引导台词，不新增人设字段）。若主理人希望 S0 完全去 NPC，可改为「宗门传承玉简」第一人称口吻——见 §8 待拍板。

### 2.4 分流小结
- **新档**：标题屏 → 序章（3 屏）→ `引导阶段=1`（目标①），主界面显示目标条 + 第①步气泡。
- **老档（引导阶段≥6）**：标题屏 → `[继续]` → 主界面，**无**目标条/气泡（已熟手）。
- **老档（引导阶段 1–5 中途）**：标题屏 → `[继续]` → 主界面，**恢复**目标条 + 当前步气泡（接续引导，内容按新语义，见 §5.2 兼容说明）。

## 3. B. 首日引导（First-day 指引）

### 3.1 五步目标链（强制但不打断）

| 步 | 目标（目标条文案） | 对应真实点击 | 完成条件（代码 Hook） | 复用/新增 |
|---|---|---|---|---|
| ① | 认清顶上家底：灵石·灵草·矿石·灵气是宗门命脉 | 点顶部「状态栏」面板 | 状态面板被点开（`gui_input`） | 新增 Hook：`_引导_推进("资源")` |
| ② | 点「推演汇总」，宗门自行运转、产出资源 | `推演汇总` | `_on_推演` 触发（**核心循环教学，原缺失步**） | 新增 Hook：`_引导_推进("推演")` |
| ③ | 点「开启接引大典」，收录第一名弟子 | `开启接引大典` | `_on_测灵根` 已接 `_引导_推进("招收")` | 复用 |
| ④ | 在「弟子」页点开一名弟子，看境界/灵根/养成 | 弟子 Tab → 任一弟子卡 | `_on_选弟子`（953 行，原 `_引导_推进` 缺失此步） | 新增 Hook：`_引导_推进("查看弟子")` |
| ⑤ | 看「离山汇总」——宗门每岁末考评、每七载大考，成绩越好家底越厚 | 点 `离山汇总` 面板（信息步，非强制点） | 离山汇总面板被点开 / 气泡「知道了」 | 新增 Hook：`_引导_推进("考评")` |

> **步骤 ③/④ 对调说明**：用户原始清单为「③查看弟子 / ④招徒」，但初始 `弟子列表` 为空（§1 事实），无弟子可看。逻辑上**必须先招徒后查看**，故实现时 ③=招徒、④=查看（见 §8 待主理人拍板）。若主理人坚持原顺序，则需 `new_game` 播种 1 名开局弟子（改动弟子生成逻辑，超出纯 UX 范围）。

### 3.2 每步交互细节
- **强制但不打断**：沿用现有 `_引导_层`（`MOUSE_FILTER_IGNORE` 点击穿透），高亮框圈住目标按钮 + 气泡指向，**不阻挡**玩家点其他东西。暗化遮罩 alpha 从现 0.55 调至 **0.35**（更轻，减少「被挡」感）。
- **气泡文案**（修仙化 `【宗门传承指引】` 前缀，口语化）：
  - ①：`【宗门传承指引】先戳一下顶上的家底——灵石、灵草、矿石、灵气，皆是宗门命脉。`
  - ②：`【宗门传承指引】点「推演汇总」，时辰流转，堂口自会产出灵石灵草。这就是宗门运转的根本。`
  - ③：`【宗门传承指引】点「开启接引大典」，收录第一名弟子入门，宗门方有传人。`
  - ④：`【宗门传承指引】到「弟子」页点开一人，看看他的境界、灵根与养成去处。`
  - ⑤：`【宗门传承指引】这「离山汇总」记着你离山期间宗门变化。宗门每岁末考评、每七载大考，考得越好，灵石越多。`
- **收尾**（步⑤达成 → `引导阶段=6`）：弹出苏清禾结语（复用 `_引导_收尾`，文案补一句考评指引）：
  `【苏清禾】掌门已初窥门径，宗门自此运转。往后岁末考评、七载大考的成绩，便是咱宗门的脸面。更深的事务（坊市、历练、御兽）也已为你敞开，自行探索便是。`
  随后目标条隐藏、灰锁按钮点亮、跳过按钮消失。

### 3.3 常驻「当前目标」提示条（新增控件 `引导_目标条`）
- **形态**：`PanelContainer`（墨青底 + 暗金描边，`custom_minimum_size = Vector2(0, 44)`）+ `Label`（宣纸亮字，14 号）。
- **位置**：钉在顶部状态栏**下方**、按钮行**上方**（作为 `main.gd` 根 `Control` 的直接子节点，`PRESET_TOP` 锚定，不被 `外滚` 滚动带走；需把 `外滚` 顶部 margin 让出 48px，见 §5.1）。
- **文案**：`当前目标 · 第 X/5 步：<对应步文案（去前缀）>`；X 由 `引导阶段` 映射（1→① … 5→⑤）。
- **生命周期**：`引导阶段∈[1,5]` 时可见；`==6`（完成/跳过）时 `queue_free` 或隐藏。
- **可访问性**：点击区 ≥44×44px；状态不只靠颜色（步数「第 X/5」为文字 + 进度，满足色盲冗余）。

### 3.4 弱化干扰（引导期收束）
- 引导未完成（`引导阶段<6`）时，**坊市 / 任务 / 历练 / 御兽 Tab** 全部灰锁不可点（见 §4.3 矩阵），仅留 推演 / 招徒 / 建筑总览 / 弟子·待抉择·纪事 可见，确保首屏只有「该做的事」。
- 右上角常驻 `跳过引导` 按钮（已有，1572 行逻辑复用），点后 `引导阶段=6` → 立即解锁全部、隐藏目标条。

## 4. C. 主界面信息层级

### 4.1 四类职责与视觉权重

| 类别 | 成员 | 视觉权重 | 位置 | 说明 |
|---|---|---|---|---|
| **主操作** | 推演汇总、开启接引大典 | 最高（主按钮：暗金框+青玉底） | 状态栏下第一行 | 驱动核心循环，永远最显眼 |
| **常驻信息** | 状态栏（资源/宗门等级/声望/繁荣）、离山汇总面板 | 中（文字为主，不抢操作） | 顶部 + 主视图中段 | 让玩家随时知道「家底与变化」 |
| **引导层** | 当前目标条、跳过引导、高亮气泡 | 中高（引导期临时叠加） | 状态栏下 / 右上 / 全屏覆盖 | 仅 FTUE 期出现，完成即隐 |
| **次操作** | 建筑总览、坊市、任务、历练、TabBar（弟子/待抉择/御兽/纪事）、详情面板 | 低（次按钮：木石纹+浅金描边；灰锁态更低） | 按钮行二/三、TabBar、底部 | 深度系统，按进度解锁 |

### 4.2 竖屏布局区块顺序（480×854，自上而下）

```

├─────────────────────────┤
│ 状态栏：时间/宗门Lv/声望/ │ ← 常驻信息（资源+等级）

│ 灵气·贡献 ｜ 弟子数       │
├─────────────────────────┤
│ [推演汇总] [开启接引大典] │ ← 主操作（最高权重）
├─────────────────────────┤

├─────────────────────────┤
```

### 5.2 引导阶段模型重定义（存档兼容）
- **新语义**：`0`=序章中；`1`=资源栏；`2`=推演（核心）；`3`=招徒；`4`=查看弟子；`5`=周期考评；`6`=完成/跳过。

## 6. 边缘情况（≥3 类）

1. **首推演产出为 0**：新档开机真实流逝≈0 日，`推演至现在` 产出≈0，引导感弱。→ 建议 FTUE 首次推演保底推进 **1 游戏日**（仅首次、仅 FTUE，调 `Game.推演一月(1)` 或在 `_on_推演` 内特判）；非 FTUE 用原逻辑。
2. **中途离线多日回来**：`[继续]` 读档 → 自动推演追上离线时间（已在 `_ready` 逻辑），引导阶段按存档续接，不回退、不重播序章。
3. **跳过引导**：点「跳过引导」→ `引导阶段=6` → 立即 `_刷新功能解锁()` 点亮所有、目标条隐藏、序章/气泡清场；后续深度系统首次进入仍可弹一次性讲解（S1 扩展，本方案仅留口）。
4. **老档无 `引导阶段` 字段**：`load_game` 默认 6 → 不弹引导、全功能可见，无崩溃（§5.2）。
5. **灰锁被强点**：`disabled=true` + tooltip 拦截，不进功能；不报错。
6. **查看弟子时无弟子**（异常兜底）：若 `引导阶段==4` 但 `弟子列表` 为空（理论不该发生，因步③已招徒），气泡改指「弟子」页并提示「先去开启接引大典招徒」，防止卡步。
7. **目标条文案裁切**：宣纸亮字 14 号 + `autowrap`，宽度取屏宽 85%，不超框。
