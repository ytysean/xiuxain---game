## 一、项目概述

### 1.1 优化目标

将现有拍卖行从"纯PVE资源获取点"升级为"有博弈、有惊喜、有成长、有代入感"的核心玩法系统，核心围绕：

1. **信息不对称的博弈** — 弟子私藏、查抄抉择、战力异动之谜
2. **弟子自主性的惊喜** — 弟子自己竞拍、自己穿戴、战力悄悄提升
3. **长期成长的动力** — 拍卖行等级、VIP权益、声望积累
4. **经济流通的活力** — 玩家寄售、弟子寄售、物品在系统内流通
5. **事件驱动的惊喜** — 神秘商人、鉴宝赌石、压轴至宝
6. **异步友好的体验** — 委托竞拍、离线结算、错过补偿，任何时候上线都能玩

### 1.2 核心设计原则

- **零战斗触碰铁律**：拍卖行不涉及战斗操作，仅做战前/战后资源配置
- **修真世界观一致性**：所有文案、设定、UI风格符合修真世界
- **放置类友好**：异步拍卖，不需要玩家同时在线
- **信息不对称乐趣**：弟子私库、未知拍品、鉴宝赌石
- **渐进式落地**：分三阶段，每阶段都有可玩的完整功能

## 三、P0 核心体验提升（3-4天）

### P0-1：私库物品自动使用机制

**任务描述**：让弟子私库中的物品"活"起来，弟子会自动使用私库中的装备、丹药、功法、符箓，形成信息不对称的乐趣。

**涉及文件**：
- `disciple.gd` — 新增自动使用逻辑
- `game_state.gd` — 月度推演时触发弟子私库自动使用

**详细功能**：

#### P0-1.1 装备自动穿戴
- 触发时机：弟子月度推演时、获得新物品入私库时
- 逻辑：遍历私库中所有可穿戴装备，对比当前装备
  - 如果私库装备 `战力加成 > 当前装备战力加成`
  - 且 `品阶 ≤ 弟子境界品阶`（穿戴限制）
  - 则自动穿戴，旧装备留在私库
- 不通知宗主（信息不对称）

#### P0-1.2 丹药自动服用
- 触发时机：弟子月度推演时、突破瓶颈时、受伤时、心魔过高时
- 丹药类型与触发条件：
  | 丹药类型 | 触发条件 | 效果 |
  |----------|----------|------|
  | 突破丹 | 弟子处于突破瓶颈期 | 提升突破成功率 |
  | 疗伤丹 | 弟子受伤剩余 > 0 | 加速恢复 |
  | 修炼丹 | 弟子正常修炼时 | 临时提升修炼速度 |
  | 清心丹 | 弟子心魔 > 50 | 降低心魔 |
  | 培元丹 | 弟子生命值低 | 恢复生命 |
- 服用后丹药从私库消失，属性提升，不通知宗主

#### P0-1.3 功法自动学习
- 触发时机：弟子月度推演时
- 逻辑：私库中有功法秘籍，且弟子未学习该功法，且品阶≤境界，则自动学习
- 学习后功法从私库消失，加入弟子已学功法

#### P0-1.4 符箓自动使用
- 触发时机：弟子历练/战斗时（宗门战、历练秘境）
- 逻辑：弟子私库中有符箓，在战斗中根据情况自动使用
  - 攻击符：弟子攻击时概率触发
  - 防御符：弟子受击时概率触发
  - 治疗符：弟子生命值低时触发
  - 传送符：弟子生命危急时概率触发（逃离战斗）
- 使用后符箓从私库消失

#### P0-1.5 信息不对称的体现
- 宗主看到的现象（但不知道原因）：
  - 弟子战力突然提升了 → 可能是私藏了好装备自动穿戴了
  - 弟子突破突然成功了 → 可能是私藏了突破丹自动服用了
  - 弟子心魔突然降低了 → 可能是私藏了清心丹自动服用了
  - 弟子历练突然无伤归来 → 可能是私藏了符箓自动使用了
- 宗主可以猜测，但无法确认，直到查抄私库的那一刻

**验收标准**：
- [ ] 弟子私库中的装备会自动对比并穿戴更优装备
- [ ] 弟子在对应状态下会自动服用私库中的丹药
- [ ] 弟子会自动学习私库中的功法
- [ ] 弟子在历练/战斗中会自动使用私库中的符箓
- [ ] 自动使用过程不通知宗主（信息不对称）
- [ ] 查抄私库时能看到剩余未使用的物品

**工作量**：1.5天

### P0-2：拍品种类扩充

**任务描述**：将现有拍品从"主要是装备/材料"扩充为修真界完整品类，增加修真感和选择丰富度。

**涉及文件**：
- `game_state.gd` — `_造拍卖物品()` 函数扩充
- `config/auction_config.csv` — 新增品类权重配置
- `item.gd` — 确保各品类物品可正常生成

**拍品种类与权重**：

| 品类 | 权重 | 说明 | 品阶范围 |
|------|------|------|----------|
| 法器/法宝/神兵 | 25% | 现有装备类，保留 | 凡~道 |
| 功法秘籍 | 15% | 体修/法修/道修各品阶功法 | 灵~仙 |
| 丹药 | 15% | 突破丹/疗伤丹/修炼丹/清心丹等 | 凡~圣 |
| 符箓 | 10% | 攻击符/防御符/治疗符/传送符等 | 凡~王 |
| 灵材/矿石 | 10% | 炼丹炼器材料 | 凡~圣 |
| 灵兽蛋/灵兽契约 | 8% | 各品阶灵兽蛋 | 灵~仙 |
| 阵法/阵图 | 7% | 护山大阵/聚灵阵/杀阵阵图 | 宝~仙 |
| 奇物/秘宝 | 7% | 储物法宝/隐身斗篷/替身傀儡等特殊物品 | 宝~道 |
| 秘境名额/传承信物 | 3% | 大拍专属，稀有 | 圣~道 |

**生成逻辑**：
- 常驻拍卖行：按权重随机抽取品类，再在品类内随机抽取具体物品和品阶
- 大拍：提高稀有品类权重（功法/灵兽/奇物/秘境名额），品阶下限提高到宝阶
- 每件拍品生成时附带：名称、品阶、描述、基准估值、起拍价、保留价

**验收标准**：
- [ ] 拍卖行中出现功法秘籍类拍品
- [ ] 拍卖行中出现丹药类拍品
- [ ] 拍卖行中出现符箓类拍品
- [ ] 拍卖行中出现灵兽蛋/契约类拍品
- [ ] 拍卖行中出现阵法/阵图类拍品
- [ ] 拍卖行中出现奇物/秘宝类拍品
- [ ] 大拍中出现秘境名额/传承信物类拍品
- [ ] 各品类按配置权重合理分布
- [ ] 所有拍品可正常竞拍、结算、入库

**工作量**：1天

### P0-3：拍卖行声望与等级系统

**任务描述**：新增拍卖行声望积累和等级体系，给玩家长期参与的成长动力和尊贵感。

**涉及文件**：
- `game_state.gd` — 新增声望变量、等级计算、权益应用
- `ui/page_auction.gd` — 新增声望进度条、等级标识、权益展示
- `config/auction_config.csv` — 新增等级阈值、权益配置

**等级体系**：

| 等级 | 名称 | 声望阈值 | 佣金率 | 优先看货 | 预留拍品 | 赊账额度 | 上架数量 |
|------|------|----------|--------|----------|----------|----------|----------|
| Lv.1 | 普通客人 | 0 | 5% | 无 | 无 | 无 | 3件 |
| Lv.2 | 熟客 | 500 | 4.5% | 普通拍品提前1小时 | 无 | 无 | 5件 |
| Lv.3 | 贵宾 | 2000 | 4% | 稀有拍品提前2小时 | 无 | 无 | 5件 |
| Lv.4 | 黑金贵宾 | 8000 | 3.5% | 所有拍品提前4小时 | 可预留1件 | 5万灵石 | 10件 |
| Lv.5 | 至尊贵宾 | 30000 | 3% | 压轴拍品专属预览 | 可预留3件 | 50万灵石 | 20件 |

**声望获取**：
- 竞拍成功：获得 `成交价 × 1%` 声望
- 委托拍卖成功：获得 `成交价 × 0.5%` 声望
- 大拍消费：声望获取 ×2
- 每日首次登录拍卖行：+10声望（日常激励）

**权益应用**：
- 佣金率：结算时自动应用对应等级的佣金率
- 优先看货：高等级玩家可以在拍品正式上架前提前看到并出价
- 预留拍品：黑金以上玩家可以对感兴趣的拍品支付10%定金预留，他人不可竞拍
- 赊账额度：黑金以上玩家灵石不足时可以赊账，7天内还清，逾期加罚10%
- 上架数量：玩家委托拍卖时的同时上架数量上限

**视觉标识**：
- 拍卖行页面顶部显示玩家等级名称和图标
- 不同等级有不同颜色的边框/标识（普通灰色、熟客绿色、贵宾蓝色、黑金紫色、至尊金色）
- 声望进度条显示当前声望和下一等级所需声望
- 大拍期间高等级玩家有专属VIP包间UI（P2实现）

**验收标准**：
- [ ] 玩家竞拍成功后获得对应声望
- [ ] 玩家委托拍卖成功后获得对应声望
- [ ] 声望达到阈值后自动升级
- [ ] 不同等级享受不同佣金率（结算时自动应用）
- [ ] 等级标识和声望进度条在UI中正确显示
- [ ] 大拍消费声望×2
- [ ] 赊账额度功能正常（黑金以上）
- [ ] 上架数量限制正确应用

**工作量**：0.5天

### P0-4：时间轴优化

**任务描述**：将拍卖行时间轴从"实时拍卖"改为"异步持续拍卖"，符合放置类游戏特点。

**涉及文件**：
- `config/auction_config.csv` — 修改时间参数
- `game_state.gd` — `_推进拍卖会_S34()` 逻辑调整
- `ui/page_auction.gd` — 倒计时显示调整

**新时间参数**：

| 参数 | 旧值 | 新值 | 说明 |
|------|------|------|------|
| 常驻拍品数 | 6 | 8 | 选择更丰富 |
| 单件时长 | 5游戏日（20分钟） | 30游戏日（2小时） | 给玩家足够时间参与 |
| 常驻刷新逻辑 | 每7天批量刷新 | 单件到期单件补充 | 持续开放，不空窗 |
| 大拍周期 | 90游戏日（6小时） | 365游戏日（约24小时） | 每天一次，有期待感 |
| 大拍时长 | 7游戏日（28分钟） | 30游戏日（2小时） | 盛会持续2小时 |
| 大拍预告期 | 无 | 90游戏日（6小时） | 大拍前6小时开始预告 |
| 大拍拍品数 | 8 | 12 | 盛会更丰富 |
| 大拍基准倍率 | 1.6 | 1.8 | 大拍物品更稀有 |

**常驻拍卖行逻辑**：
- 保持8件拍品在拍
- 每件拍品持续30游戏日（2真实小时）
- 到期后立即结算，并立即补充1件新拍品
- 玩家任何时候上线都有8件可拍，不会"空窗"

**大拍逻辑**：
- 每365游戏日（约24真实小时）一次
- 大拍前90游戏日（6真实小时）开始全服预告
- 预告内容：大拍时间、压轴至宝名称、部分稀有拍品预览
- 大拍持续30游戏日（2真实小时）
- 大拍期间：12件稀有拍品、声望×2、佣金-1%、全服播报竞价
- 大拍结束后：结算、自动入库、通知玩家

**验收标准**：
- [ ] 常驻拍卖行保持8件在拍，任何时候上线都有货
- [ ] 单件拍品持续2小时，到期立即结算并补充
- [ ] 大拍每天一次，前6小时开始预告
- [ ] 大拍持续2小时，12件拍品
- [ ] 大拍期间声望×2、佣金折扣
- [ ] 倒计时显示正确（游戏日/真实时间双显示）

**工作量**：0.5天

### P0-5：委托竞拍（核心异步机制）

**任务描述**：实现委托竞拍功能，玩家设置最高委托价后离线，系统代玩家自动出价。这是解决"玩家在线时间不一致"的核心机制。

**涉及文件**：
- `game_state.gd` — 新增委托管理、自动出价逻辑
- `ui/page_auction.gd` — 新增委托出价UI
- `config/auction_config.csv` — 新增委托相关配置

**功能设计**：

#### P0-5.1 设置委托价
- 玩家对任意在拍拍品可以点击"委托出价"
- 输入最高委托价（必须 ≥ 当前价 + 最小加价步进）
- 确认后：
  - 冻结委托价金额的灵石（防止出价后灵石不足）
  - 记录委托信息（拍品ID、委托价、设置时间）
  - 拍品显示"您已委托（上限：XXXX）"

#### P0-5.2 系统代出价逻辑
- 触发时机：其他玩家/AI对该拍品出价后
- 逻辑：
  - 如果 `新当前价 + 最小加价步进 ≤ 委托价`
  - 则系统代玩家出价 `新当前价 + 最小加价步进`
  - 出价显示"XX（委托中）出价XXXX灵石"
  - 更新冻结金额（释放旧冻结，冻结新金额）
  - 如果 `新当前价 + 最小加价步进 > 委托价`
  - 则不再代出价，委托自动失效，释放冻结灵石
  - 记入"委托被超过"记录

#### P0-5.3 最小加价步进
- 步进 = max(10, 当前价 × 10%)
- 当前价1000 → 步进100
- 当前价100 → 步进10
- 配置化，可在CSV中调整

#### P0-5.4 委托管理
- 玩家可以在"我的委托"页面查看所有活跃委托
- 可以修改委托价（调高或调低）
- 可以取消委托（释放冻结灵石）
- 委托到期自动结算（竞得则扣款发货，未竞得则解冻）

#### P0-5.5 弟子委托竞拍（P1详细实现，P0预留接口）
- 弟子是AI，天然使用委托机制
- 弟子设置好自己的最高出价后，系统代弟子自动出价
- P0先预留接口，P1完整实现弟子AI决策

**验收标准**：
- [ ] 玩家可以对任意拍品设置委托价
- [ ] 设置委托后冻结对应灵石
- [ ] 其他玩家出价后，系统在委托价内自动代玩家出价
- [ ] 超过委托价后自动失效，释放灵石
- [ ] 玩家可以修改/取消委托
- [ ] 委托到期自动正确结算
- [ ] 出价记录正确显示"委托中"标识
- [ ] 离线期间委托正常生效

**工作量**：1天

### P0-6：延时结算与结算通知

**任务描述**：实现延时结算（防秒拍）和离线结算通知，确保公平性和异步友好。

**涉及文件**：
- `game_state.gd` — 延时结算逻辑、结算通知
- `ui/page_auction.gd` — 结算通知弹窗、记录页面

#### P0-6.1 延时结算（防秒拍）
- 规则：
  - 拍卖结束前最后1游戏时（10真实秒），如果有人出价，则自动延长1游戏时（10真实秒）
  - 每次出价都触发延长
  - 直到连续1游戏时（10真实秒）无人出价才结算
  - 最多延长1游戏日（4真实分钟），防止无限延长
- 意义：
  - 给后上线的玩家几秒钟反应时间
  - 防止"掐秒秒杀"，更公平
  - 增加竞价的紧张感和戏剧性

#### P0-6.2 结算通知
- 拍卖结束后，结果立即记入"拍卖行记录"
- 竞得的物品自动进入宗门库房（或玩家预设的交付目标）
- 未竞得的委托自动解冻灵石
- 玩家下次上线时：
  - 弹出"拍卖行结算通知"（列出离线期间的所有拍卖结果）
  - 通知格式：
    ```
    【拍卖行结算通知】
    ✅ 竞得：青云剑（3200灵石）→ 已入宗门库房
    ❌ 未竞得：紫霞衣（被超过，委托价5000，成交价6800）
    ✅ 竞得：清心丹×3（800灵石）→ 已入弟子·张三私库
    ❌ 流拍：上古玉匣（未达保留价）
    ```

### P1-2：弟子AI竞拍决策系统

**任务描述**：实现弟子AI参与拍卖的决策系统，弟子根据自己的需求、偏好、性格、灵石余额自主决定是否竞拍、出价多少。

**涉及文件**：
- `disciple.gd` — 新增竞拍决策方法
- `game_state.gd` — 月度推演时触发弟子检查拍卖、设置委托
- `config/auction_ai_config.csv` — 弟子AI参数配置

**详细功能**：

#### P1-2.1 弟子参与时机
- 常驻拍卖行：弟子每游戏日检查一次（月度推演时批量处理）
- 大拍：大拍开启时弟子集中参与一次
- 弟子不会频繁出价，而是设置委托价后由系统代拍（复用P0委托机制）

#### P1-2.2 拍品兴趣评估
弟子对每件拍品计算"兴趣值"（0-100），兴趣值>阈值才考虑参与：

| 因素 | 影响 |
|------|------|
| **物品类型匹配** | 体修对武器/防具兴趣+30，法修对法器/功法兴趣+30，丹修对丹药/丹方兴趣+30 |
| **品阶适配** | 品阶=境界品阶：兴趣+20；品阶=境界品阶+1：兴趣+10（有挑战）；品阶>境界品阶+2：兴趣-50（用不了） |
| **当前需求** | 对应装备槽位为空：兴趣+30；当前装备品阶低于拍品：兴趣+20；当前装备品阶相同或更高：兴趣-30 |
| **稀缺性** | 圣阶以上：兴趣+20；仙阶：兴趣+30；道阶：兴趣+50 |
| **性格偏好** | 贪婪弟子对所有物品兴趣+10；淡泊弟子对所有物品兴趣-10；谨慎弟子对高溢价物品兴趣-20 |

#### P1-2.3 出价决策
- 兴趣值>60的拍品，弟子考虑参与
- 弟子计算自己的"心理估值"：
  - 基础估值 = 拍品基准估值 × (0.8 + 兴趣值/200)
  - 性格修正：浮躁弟子×1.2（容易冲动溢价），沉稳弟子×0.9（精打细算），狡诈弟子×0.85（尽量压价）
- 弟子设置委托价 = 心理估值 × (0.9~1.1随机波动)
- 灵石限制：委托价不超过私库灵石的80%（留余地）
- 如果多件感兴趣拍品，按兴趣值排序，灵石优先分配给兴趣最高的

#### P1-2.4 弟子委托执行
- 弟子设置好委托价后，复用P0的委托竞拍机制
- 系统代弟子自动出价，显示"弟子·XX（委托中）出价XXXX灵石"
- 弟子竞得后：物品直接入弟子私库，灵石从私库扣除
- 弟子未竞得：委托失效，灵石解冻
- 整个过程宗主不可见（信息不对称），只能看到弟子灵石减少/战力变化

#### P1-2.5 弟子竞价台词
- 弟子出价时（如果是大拍且弟子在线模拟），有概率播放竞价台词
- 台词按性格分类：
  - 正直："此物与我有缘，还望各位道友割爱。"
  - 狡诈："嘿嘿，这宝贝我要定了。"
  - 浮躁："加价加价！谁也别跟我抢！"
  - 沉稳："此物我出价XX，各位请斟酌。"
  - 孤僻："……（沉默出价）"
- 增加代入感和趣味性

**验收标准**：
- [ ] 弟子每天检查拍卖行，对感兴趣的拍品设置委托
- [ ] 兴趣评估正确考虑道途/品阶/需求/性格

  - "适合"定义：品阶≤玩家最高弟子境界品阶，类型匹配玩家宗门主流道途
  - 该拍品标注"珍品"，起拍价略低（给玩家捡漏机会）
- 竞得后保底计数重置
- 防止玩家一直脸黑，提升体验

### P2-2：暗拍玩法

**任务描述**：新增暗标拍卖玩法，部分特殊拍品采用暗拍，增加策略性和紧张感。

**涉及文件**：
- `game_state.gd` — 暗拍逻辑、密封出价、结算
- `ui/page_auction.gd` — 暗拍UI、密封出价输入
- `config/auction_config.csv` — 暗拍参数配置

#### P2-2.1 暗拍规则
- 部分特殊拍品（大拍压轴至宝、神秘商人拍品）采用暗拍方式
- 暗拍特点：
  - 玩家不知道其他人的出价（所有出价密封）
  - 玩家只能出价一次（不能反复加价）
  - 到期后揭晓所有出价，最高价者得
  - 暗拍佣金+1%（比明拍高，因为更刺激）
- 暗拍时长：比明拍短（15游戏日=1真实小时），因为不需要反复竞价

#### P2-2.2 暗拍流程
1. 拍品上架，标注"暗拍"标识
2. 玩家在暗拍期内可以提交密封出价（只能提交一次，提交后不可修改）
3. AI竞拍者也提交密封出价
4. 暗拍期结束，揭晓所有出价（从低到高排列）
5. 最高价者得，扣除灵石+佣金，物品入库
6. 未中标者灵石解冻

#### P2-2.3 暗拍策略
- 玩家需要判断物品真实价值，一次性出到心理价位
- 可以参考物品的基准估值、市场行情、同类物品历史成交价
- 信息不对称：不知道对手出价，需要博弈
- 这是修真小说中"暗标拍卖"的经典玩法

#### P2-2.4 委托竞拍与暗拍
- 暗拍不支持委托竞拍（因为只能出价一次）
- 但支持"预约出价"：玩家可以提前设置出价，暗拍开始时自动提交
- 弟子也参与暗拍（AI一次性出价）

**验收标准**：
- [ ] 特殊拍品标注"暗拍"标识
- [ ] 暗拍期内玩家只能提交一次密封出价
- [ ] 玩家看不到其他人的出价
- [ ] 到期后揭晓所有出价，最高价者得
- [ ] 暗拍佣金+1%正确应用
- [ ] 暗拍时长比明拍短
- [ ] 预约出价功能正常
- [ ] 弟子AI参与暗拍

**工作量**：1天

### P2-3：鉴宝玩法

**任务描述**：新增未知拍品和鉴宝功能，玩家可以花钱鉴定，也可以不鉴定直接竞拍（赌石玩法）。

**涉及文件**：
- `game_state.gd` — 未知拍品生成、鉴定逻辑、真实价值
- `ui/page_auction.gd` — 未知拍品UI、鉴定按钮、鉴定结果展示
- `config/auction_config.csv` — 鉴宝参数配置

#### P2-3.1 未知拍品
- 部分拍品上架时显示为"未知物品"（如"神秘木箱"、"上古玉匣"、"尘封铁盒"）
- 未知拍品只显示：外观描述、品阶范围（如"疑似宝阶~圣阶"）、起拍价
- 不显示真实名称、真实品阶、真实属性
- 未知拍品出现概率：常驻10%，大拍20%，鉴宝大会100%

#### P2-3.2 鉴定功能
- 玩家可以对未知拍品点击"鉴定"
- 鉴定费 = 起拍价 × 20%
- 鉴定后：
  - 玩家可以看到该拍品的真实信息（名称、品阶、属性、基准估值）
  - **其他玩家看不到**（信息不对称，鉴定者有信息优势）
  - 鉴定结果永久有效（该玩家下次上线还能看到）
- 鉴定师技能（P2-1）可以免费鉴定一件

#### P2-3.3 赌石玩法
- 玩家可以选择不鉴定，直接竞拍未知物品
- 可能的结果：
  - **捡漏**：花低价买到高价值物品（如用宝阶价格买到仙阶物品）
  - **吃亏**：花高价买到低价值物品（如用圣阶价格买到凡阶物品）
  - **正常**：物品价值与价格相当
- 真实价值分布：
  - 20%概率：品阶+1（捡漏）
  - 60%概率：品阶不变（正常）
  - 20%概率：品阶-1（吃亏）
- 这是修真小说中"赌石"、"鉴宝"的经典乐趣

#### P2-3.4 鉴宝大会事件
- 每3游戏月（6真实小时）一次"鉴宝大会"
- 鉴宝大会期间：
  - 所有拍品都是未知物品
  - 鉴定费减半
  - 捡漏概率提升到30%
  - 专属拍卖师主持
- 增加特殊事件的乐趣和期待感

**验收标准**：
- [ ] 未知拍品正确显示为"神秘XX"，不显示真实信息
- [ ] 玩家可以花钱鉴定，鉴定后看到真实信息

- [ ] 不鉴定直接竞拍，结算时揭晓真实价值
- [ ] 捡漏/正常/吃亏概率正确分布
- [ ] 鉴宝大会事件正确触发

## 十、落地建议

### 10.1 分阶段落地顺序
1. **先做P0**：核心体验提升，让拍卖行先"好玩"起来
2. **再做P1**：弟子参与和玩家寄售，让拍卖行"活"起来
3. **最后做P2**：氛围和惊喜感，让拍卖行"有灵魂"

### 10.2 每个阶段内部顺序
- 先做数据结构和配置表
- 再做核心逻辑（game_state.gd）
- 再做UI（page_auction.gd）
- 最后做测试和调优

### 10.3 风险控制
- 每个功能完成后立即测试，不堆积
- 数值参数全部配置化，方便后续调优
- 旧档兼容是硬要求，每个新增字段都要有默认值
- 弟子AI决策不要太复杂，避免性能问题
