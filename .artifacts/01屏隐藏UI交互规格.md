## 3. 幻形（背景皮肤切换）

### 3.1 触发
- **位置**：右侧按钮组第 4 位（`35:3`）。
- **触发方式**：点击按钮。
- **样式约束**：完全复用右侧现有按钮的尺寸、圆角、底色、字体风格，**禁止自定义新样式**。

### 3.2 弹窗规格
- 弹出**独立 Overlay 弹窗**，不替换首页。
- 弹窗内容：
  - 宗门主页背景皮肤列表（≥2 项：当前宗门仙山皮肤 + 其他洞天皮肤候选）。
  - 每项支持预览（缩略图 / 实时背景试穿）。
  - 选中确认 + 取消按钮。
- 弹窗层级：高于首页所有 UI，但低于系统级弹窗（设置 / 邮件等）。

### 3.3 选择 / 预览
- 预览态在弹窗内实时切换背景，**不立即**生效到首页（或提供"试穿"态）。
- 确认 → 应用选中皮肤到首页背景（`2:55` 的 IMAGE fill / Godot `TextureRect.texture`），关闭弹窗回到首页。

### 3.4 关闭 / 取消
- 关闭方式：关闭按钮 / 点击空白 / 取消按钮。
- 关闭后：回到正常宗门首页，UI 全部保持显示态。

### 3.5 状态持久化
- 选中皮肤需持久化（存档 / 配置），下次进入首页沿用。
- 默认值：当前宗门仙山皮肤。

### 3.6 与隐藏 UI 的关系
- 幻形弹窗出现时，视为"首页弹出任意弹窗"，触发 **第 5 章强制防护**（自动恢复全部 UI 显示）。

## 4. 隐藏 UI / 显示 UI（沉浸式开关）

### 4.1 常态（UI 全部显示）
- 右上角显示「眼睛图标」按钮（`35:5`）。
- 点击 → 执行隐藏逻辑。

### 4.2 隐藏逻辑（点击眼睛）
受控**隐藏对象清单**（仅隐藏以下，其余保持不变）：

1. 顶部资源栏（`2:181`）
2. 左侧全部按钮（`2:206` 整组）
3. 右侧全部按钮（`2:215` 整组，含幻形 `35:3`）
4. 活跃度进度条（`2:222`）
5. 底部 5Tab 栏（`2:226`）

- **保留**：底层宗门背景图（`2:55` IMAGE fill）——其他首页 UI 全部隐藏，只剩背景。
- 隐藏后：屏幕**同一右上角位置**，替换为「显示 UI」悬浮小按钮（眼睛+斜杠 / 睁眼图标语义）。

### 4.3 隐藏态（显示按钮）
- 位置：与原隐藏按钮同一右上角坐标。
- 样式：同 `35:5` 小型悬浮控件，图标切换为"显示"语义。
- 点击 → 恢复全部 UI 可见。

### 4.4 恢复逻辑
- 将被隐藏 UI（`2:181` / `2:206` / `2:215` / `2:222` / `2:226`）全部 `visible = true`。
- 复位隐藏按钮状态（回到眼睛图标态）。
- 回到正常游戏首页。

## 5. 强制防护逻辑（防卡死，必须实现）

所有防护路径共用同一 `restore_all_ui()` 函数：还原可见性 + 重置隐藏按钮状态，**不改动位置 / 尺寸**。

### 5.1 弹窗触发
- 首页弹出**任意弹窗**（含幻形弹窗、邮件、设置、成就等）→ 自动强制恢复全部 UI 显示。
- 同时重置隐藏按钮状态为"显示态"。
- 目的：避免隐藏态下弹窗与沉浸式冲突、用户迷失。

### 5.2 页面切换
- 切换到其他页面（弟子 / 殿阁 / 历练 / 纪事）→ 自动强制恢复全部 UI 显示。
- 离开首页即复位；回到首页时默认显示态。

### 5.3 窗口尺寸变更 / 屏幕旋转
- 监听 viewport 尺寸变更 / 旋转事件 → 自动强制恢复全部 UI 显示。
- 防止布局错乱导致按钮 / 背景错位。

### 5.4 复位规则统一
- 所有防护路径调用同一 `restore_all_ui()`。
- 复位内容：可见性还原 + 隐藏按钮状态重置；**绝不**触碰位置 / 尺寸 / 背景。

## 6. 状态机

```
        ┌─────────────┐
        │   显示态     │◄──────────────────┐
        │  (normal)    │                   │
        └──────┬──────┘                   │
               │ 点击眼睛 (35:5)          │ 任意防护事件触发
               ▼                          │ (弹窗 / 切页 / 旋屏)
        ┌─────────────┐                   │
        │   隐藏态     │                   │
        │ (immersive) │                   │
        └──────┬──────┘                   │
               │ 点击显示 (35:5')         │
               ▼                          │
        ┌─────────────┐                   │
        │ 恢复→显示态  │───────────────────┘
        └─────────────┘

幻形：显示态下点击 35:3 → 弹出皮肤弹窗（叠加层）
         皮肤弹窗关闭 → 回到显示态（走 5.1 防护）
```

## 7. 边界与异常处理

| 场景 | 处理 |
|------|------|
| 隐藏态下点击幻形 | 不允许：隐藏态右侧按钮不可见，无法触发；若异常可达，先触发 5.1 恢复再弹窗 |
| 快速连点眼睛 | 防抖：单次点击切换一个状态，忽略 300ms 内重复触发 |
| 多弹窗叠加 | 任一弹窗关闭不解除其他弹窗防护；所有弹窗关闭后保持显示态 |
| 隐藏态下收到系统通知弹窗 | 视为 5.1 弹窗触发，强制恢复 UI |
| 背景皮肤切换中切页 | 5.2 触发恢复，皮肤选择状态保留 |

## 9. 设计约束（不可违反）

- **只新增，不改动**：不移动、不缩放、不修改现有 UI（顶部资源栏、左右侧边按钮、活跃度条、底部 Tab、背景图）。
- **背景图不变**：本次不重绘建筑 / 云雾 / 石阶 / 山门 / 主殿；隐藏 UI 仅控制显隐，不修改背景内容。
- **样式复用**：幻形完全复用右侧按钮样式；眼睛按钮为小型悬浮控件。
- **UI 层级**：新增控件浮于首页 UI 之上，但不破坏现有层级关系。

> **细节备注**：`35:5` 眼睛按钮位于 `(448, 16)`，与资源栏最右"声望"数字右侧边缘约有 15px 重叠。若需完全不碰资源数字，可左移 2–3px 或上移；当前按"右上角资源栏旁独立悬浮"已满足约束。
