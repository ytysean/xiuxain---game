# 《太玄宗门录》全局 UI 主题规范（Godot 4.7 Theme）

> 配套文件：`res://ui/themes/taixuan_theme.tres`（本机 `E:\Xiuxian\taixuanzongmenlu\ui\themes\taixuan_theme.tres`）
> 适用范围：竖屏 480×854 修仙放置经营游戏；定位为「全游戏唯一视觉基准」，与 `UI硬性约束规范.md` 配套、约束力同级。

## 0. 本 Theme 的目的与应用方式

**目的**：从根源统一全游戏 UI 风格。只要本项目挂上这个 Theme，任何场景里拖出的 `Panel / Button / Label / TabBar / LineEdit / ProgressBar / HSeparator` 都会自动套用同一套「墨青底 + 暗金描边 + 思源宋体」修仙视觉，**不再出现每个界面样式各异、随手改色导致的风格漂移**。

**应用方式（二选一，推荐 A）**：

- **方式 A · 全局（推荐，小白最省心）**
  编辑器顶部菜单 `Project → Project Settings → GUI → Theme` → 点击右侧输入框，选择 `res://ui/themes/taixuan_theme.tres`。
  保存后，**所有场景、所有控件**自动套用本主题，无需逐个设置。
- **方式 B · 局部（仅某棵 UI 树）**
  选中根 `Control` 节点，在 Inspector 找到 `Theme` 属性，把 `taixuan_theme.tres` 从文件系统面板拖进去。
  该节点及其子节点套用本主题（常用于弹窗/二级页单独覆盖）。

> 注意：本项目 `UI硬性约束规范.md §4.6` 已裁定「启用皮肤纹理=false 维持；4 张 AI PNG 不可用，纯 StyleBoxFlat 落地」。因此本 Theme **全程程序化绘制（StyleBoxFlat），不引用任何位图 PNG**，既能自动套用任意控件，也规避了不可用素材。

## 2. 字体（default_font 真实路径 + 字号映射表）

`art/fonts/` 下**真实存在**的字体文件（已用 Glob/Bash 确认，均带 `.import`）：

| 文件 | 路径（Theme 引用） | 用途 |
| --- | --- | --- |
| 霞鹜文楷（完整版） | `res://art/fonts/LXGWWenKai-Regular.ttf` | **default_font**（开源免费商用、全字库、楷体带古风，修仙调性适配）✅ 已锁定引用 |
| 站酷庆科黄油体（完整版） | `res://art/fonts/ZCOOLQingKeHuangYou-Regular.ttf` | 备用古风手写体；圆润 POP 感，偏活泼，当前不作为默认 |
| 思源黑体 CN 完整版 | `res://art/fonts/SourceHanSansCN-Regular.otf` | 备用正文黑体；笔画端正清晰，可局部覆盖 |
| 思源宋体 CN 完整版 | `res://art/fonts/SourceHanSerifCN-Regular.otf` | 备用宋体；思源宋体「门」左侧点画过短易被误认为横，当前不作为默认字体 |
| 思源宋体（子集） | `res://art/fonts/NotoSerifSC-Subset.otf` | 旧子集字体，不再作为默认字体，保留备用 |
| 马善政毛笔楷体（子集） | `res://art/fonts/MaShanZheng-Subset.ttf` | 主标题可选毛笔感（在标题 Label 上用 `theme_override_font` 单独指定）✅ 真实存在；**缺字（如「门」），不可全局默认** |

> `.tres` 中 `default_font = ExtResource("1")` 指向 `LXGWWenKai-Regular.ttf`。
> 
> **为什么用完整版而不是子集？** 项目原有子集字体只包含扫描过的文案字符，「门」等常见字缺失会导致界面显示错误（方框/缺字）。完整版覆盖大陆常用汉字，彻底规避缺字风险。
> 
> **关于「门」字封口的事实**：简体「门」（U+95E8）国家标准写法就是**左边点+竖、右边横折钩封口**，所有规范简体字体（黑体/宋体/文楷）都如此显示，这**不是错字**。若要「门」字**不封口**的古风效果，纯字体方案只有用**繁体「門」**（Label 的 Text 写 `門`，全字库字体直接支持，零下载）。

### 2.1 字体使用分层原则（用户拍板：全用字体，不做图片）
| 文本类型 | 用什么 | 说明 |
| --- | --- | --- |
| **大标题 / 按钮文字 / Logo** | `LXGWWenKai-Regular.ttf`（全局默认即可） | 霞鹜文楷直接显示，古风端正，无需做图 |
| **正文 / 数值 / 长文本 / Tab 文字** | 同上（全局默认） | 全汉字覆盖、无缺字错字 |
| **「门」字要古风不封口时** | 该 Label 的 Text 改用繁体 **`門`** | 如底部 Tab「宗门」→ Text 填 `宗門`，全字库字体直接渲染不封口的繁体门 |

## 7. 小白步骤：新建并应用 Theme（从零也不怕）

1. 把 `taixuan_theme.tres` 放到 `res://ui/themes/`（已就绪）。
2. 编辑器顶部 `Project → Project Settings → GUI → Theme`，点右侧选 `res://ui/themes/taixuan_theme.tres`。
3. 随便开一个 `.tscn`，拖一个 `Panel`：立刻看到墨青底 + 暗金描边圆角框。
4. 拖一个 `Button`：自动是深青玉底 + 暗金边 + 宣纸亮文字（主按钮样式）。
5. 拖一个 `TabBar`、设 5 个 Tab 文字（宗门/弟子/建筑/历练/纪事）：选中项自动暗金高亮。
6. 想做「次按钮/危险按钮」：选中该按钮 → Inspector `Theme Overrides → Styles → Normal` 点 `New StyleBoxFlat`，按 §4 填值；Hover/Pressed 同理。
7. **不要**在节点上手动改颜色/字号到锁定值之外——所有视觉都来自本 Theme，保证全游戏统一。

> 提示：若某控件要临时特例（如弹窗圆角 10），用它的 `Theme Overrides` 局部覆盖，**不要**改全局 `.tres` 的锁定值。
