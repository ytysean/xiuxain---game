## 通用负向词（每次出图必带）

- 中文：`赛博朋克、霓虹、数据流、机械义体、现代都市、重金属、夸张妆容、Q版、卡通、纯玻璃拟态、杂乱背景、真人照片感、毛笔字正文、低分辨率、多余手指、肢体畸变`

## 背景 / 构图 / 普通档 统一规则（工业化，全部提示词已内置）

- 背景：深灰纯色暗背景，微弱环境轮廓光（资质只改灵气强度，不换背景）

- 构图：严格半身构图锁，1024×1536，头顶留白约10%，头位于画面上部15%–25%，头高占图高22%–28%，面部无俯仰、头部不歪，发髻/冠饰不遮眉眼，下摆至腰下胯部，人物居中（头像裁切齐平）

- 普通档袍服：素色无纹道袍 + 宗门制式领缘，去凡人粗布感，五灵根普通档均保修仙制式感


## 差异化变体（方案A：降低同组同质化，批量脚本随机选注）

> 同灵根+同资质+同性别的小组内视觉趋同属正常现象。每条原型在 JSON 的 `variants` 字段提供候选池，批量出图时从中随机选注，即可同组不全一样，且主 prompt 仍是确定性基线（可审核）。

- **发型变体 hair**（替换主发型，3 选）：

  - 沉稳（chen）：高束发加玄色发带 / 束发嵌玉簪 / 半披发束于脑后

  - 温润（wen）：低挽发髻木簪斜插 / 侧分柔顺披发 / 双辫垂肩

  - 狡黠（jiao）：高扎马尾斜挑 / 短卷发微蓬 / 不对称半扎发

- **面部弱特征 face_feature**（追加 1 项，轮廓/骨骼类，不与神态冲突）：清晰下颌线 / 高挺鼻梁 / 立体颧骨 / 饱满天庭 / 清瘦面颊

- **配饰材质 accessory_material**（追加 1 项）：镶玉点缀 / 鎏金描边 / 银丝缠绕 / 木纹肌理 / 宝石嵌饰
