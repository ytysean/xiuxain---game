## 二、P2实现内容

### 2.1 家族阵法系统

#### 5种家族阵法配置
| 阵法ID | 名称 | 类型 | 修炼加成 | 战力加成 | 防御加成 | 特殊要求 |
|---|---|---|---|---|---|---|
| family_zhen_001 | 家族护山阵 | 防御 | 0.5% | 0.5% | 1% | 无 |
| family_zhen_002 | 聚灵引气阵 | 辅助 | 1% | 0.3% | 0.2% | 无 |
| family_zhen_003 | 七杀诛魔阵 | 攻击 | 0.3% | 1% | 0.2% | 无 |
| family_zhen_004 | 九宫八卦阵 | 综合 | 0.8% | 0.8% | 0.8% | 无 |
| family_zhen_005 | 太古周天阵 | 特殊 | 1.2% | 1.2% | 1.2% | 家族等级5以上 |

#### 核心功能
| 函数名 | 功能 | 权限 |
|---|---|---|
| `布置家族阵法(家族ID, 阵法ID, 布置者)` | 布置家族阵法 | 老祖/长老 |
| `加入阵法驻守(家族ID, 弟子)` | 加入阵法驻守 | 所有家族成员 |
| `计算家族阵法加成(弟子)` | 计算阵法修炼/战力/防御加成 | - |

#### 阵法威力计算
```
人数系数 = 1.0 + min(驻守人数 × 0.1, 1.0)  （每多1人+10%，最多+100%）
等级系数 = 1.0 + (阵法等级 - 1) × 0.2        （每级+20%）
加成 = 基础加成 × 人数系数 × 等级系数
```

#### 修真世界设定
- 家族护山大阵，家族成员共同催动
- 人数越多威力越大（最多10人满效）
- 阵法等级可提升，威力同步提升
- 特殊阵法（太古周天阵）需要家族等级5以上

#### 数值红线
- 家族阵法单源子帽≤1%（全局等效）
- 所有加成都有上限检查

### 2.2 家族培养体系

#### 4级家族学塾配置
| 等级 | 名称 | 修炼加成 | 突破加成 | 描述 |
|---|---|---|---|---|
| 1级 | 家族蒙学 | 0.3% | 1% | 基础启蒙教育 |
| 2级 | 家族书院 | 0.5% | 2% | 系统修炼教育 |
| 3级 | 家族学宫 | 0.8% | 3% | 高等修炼教育，长老授课 |
| 4级 | 家族道院 | 1% | 5% | 顶级修炼圣地，老祖传道 |

#### 核心功能
| 函数名 | 功能 | 说明 |
|---|---|---|
| `升级家族学塾(家族ID, 操作者)` | 升级家族学塾 | 消耗家族贡献池，老祖/长老操作 |
| `家族试炼(家族ID, 弟子)` | 家族试炼选拔 | 消耗100贡献，成功晋升核心+200贡献 |
| `计算家族培养加成(弟子)` | 计算学塾+资源倾斜加成 | 核心弟子享受1.5倍效果 |

#### 家族试炼规则
- **条件**：境界≥筑基，家族贡献≥100
- **消耗**：100点家族贡献
- **成功概率**：30% + 资质系数×40%
- **成功奖励**：晋升核心弟子 + 200点家族贡献
- **失败安慰**：50点家族贡献

#### 资源倾斜机制
- 核心弟子及以上享受1.5倍学塾效果
- 体现修真世界"家族资源向优秀子弟倾斜"的设定

#### 数值红线
- 家族培养单源子帽≤1%（全局等效）
- 突破加成上限5%

### 2.3 宗门功法不外传机制

#### 核心功能
| 函数名 | 功能 | 说明 |
|---|---|---|
| `学习宗门功法(弟子, 功法ID)` | 学习宗门功法 | 在宗弟子可学，需要职位权限 |
| `清除宗门功法(弟子)` | 清除所有宗门功法 | 叛出/逐出宗门时调用 |

#### 不外传机制
- 只有在宗弟子能学习宗门功法
- 学习宗门功法需要宗门职位权限（简化版：所有在宗弟子可学基础功法）
- 叛出/逐出宗门时自动清除所有宗门功法
- 符合修真世界"宗门功法不传外人"的设定

## 四、接入点

### 4.1 战力系统接入
`disciple.gd` 计算战力()函数新增：
```
主体 = base × 资质系数 × 灵根系数 × 道途系数 
     × (1 + 通用增益) × (1 + 道心增益) 
     × (1 + 血脉共鸣增益) × (1 + 血脉增益) × (1 + 家族功法增益)
     × (1 + 家族秘宝增益) × (1 + 血脉功法增益) × (1 + 家族阵法增益)
     × (1 + 套装增益)
```

```
                + 彩蛋修炼加成 + 大阵pct + 血脉共鸣pct + 血脉pct 
                + 家族秘宝pct + 血脉功法pct + 家族阵法pct + 家族培养pct, 0, 1)
```

## 八、经验教训

### 8.1 修真世界设定的细节
- 家族阵法需要成员共同催动，人数越多威力越大
- 家族学塾分等级，从蒙学到道院，体现家族底蕴
- 家族试炼选拔核心弟子，资源向优秀子弟倾斜
- 宗门功法不传外人，叛出宗门自动清除

### 8.2 多维度加成的平衡
- 家族系统提供修炼、战力、防御、突破等多维度加成
- 每个维度都有独立的数值红线，避免某一维度过强
- 全宗加成都有上限，避免多个家族叠加导致平衡崩坏

### 8.3 分阶段实施的好处
- P0基础架构 → P1宝库/秘宝/功法 → P2阵法/培养 → P3社交 → P4UI
- 每阶段都可独立验证，不影响其他系统
- 玩家可以逐步体验新功能，不会一次性信息过载
