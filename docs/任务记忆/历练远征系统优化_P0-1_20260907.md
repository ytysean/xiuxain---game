## 一、优化背景

### 现有系统问题（三标准评估）
1. **符合修真世界观**: 命名基本符合，但事件池较薄，缺少历练故事感
2. **符合玩家操作习惯**: 派遣流程简单，但缺少过程干预和实时展示
3. **不止能玩而是好玩**: ❌ 零玩家决策点——派遣后完全自动，玩家只能等结果

### 优化目标
- 增加玩家决策点（路线选择/奇遇选择/风险决策）
- 增加随机性和重玩价值（多结局/多奇遇）
- 增加叙事感和代入感（历练叙事/结局描述）
- 不破坏现有系统（新增增强层，原有功能完全保留）

## 二、新增系统清单

### 1. 历练路线选择系统
**文件**: expedition.gd
**常量**: `历练路线配置`
**函数**: `获取关卡可用路线(关卡ID)`

三条路线：
| 路线 | 名称 | 成功率加成 | 奖励倍率 | 奇遇概率 | 风险等级 |
|------|------|-----------|---------|---------|---------|
| 稳妥 | 稳妥而行 | +15% | 0.8x | 5% | 1 |
| 冒险 | 冒险深入 | 0% | 1.2x | 15% | 2 |
| 神秘 | 探秘寻幽 | -15% | 1.8x | 35% | 3 |

关卡可用路线：
- 日常关卡(daily): 稳妥 + 冒险
- 境界关卡(realm): 稳妥 + 冒险 + 神秘
- 秘境关卡(secret): 冒险 + 神秘

### 2. 历练奇遇事件系统
**常量**: `历练奇遇池`（8种奇遇）
**函数**: `随机触发奇遇(路线)`, `处理奇遇选项(奇遇, 选项索引, 弟子ID列表)`, `_应用奇遇效果(效果, 弟子ID列表)`

8种奇遇：
1. **偶遇前辈** - 虚心请教/切磋比试/恭敬让路
2. **发现上古遗迹** - 深入探索/谨慎探查/标记离开
3. **遭遇灵兽** - 尝试收服/疗伤观察/绕道离开
4. **遭遇险境** - 硬闯而过/谨慎绕行/原地休整
5. **发现灵草** - 直接采集/小心移植/留下养护
6. **散修交易** - 查看交易/讨价还价/婉言拒绝
7. **天地异象** - 参悟异象/远离异象/记录观察
8. **发现妖兽巢穴** - 突袭巢穴/暗中观察/不惊扰

每个奇遇2-3个选项，每个选项有不同成功率和效果（成功/失败效果不同）。

### 3. 历练风险决策系统
**函数**: `历练风险决策(实例ID, 决策)`

两种决策（历练进度30%-100%时可选择）：
- **见好就收**: 提前结束，按进度比例获得部分奖励（20%-90%）
- **继续深入**: 继续历练，奖励可能增加，但风险也随之增加

### 4. 历练多结局系统
**函数**: `获取历练结局(实例ID, 成功, 评级)`

7种结局：
| 结局 | 条件 | 额外奖励 |
|------|------|---------|
| 完美 | 成功+S评级+奇遇≥2次 | 声望+20, 贡献+10, 道心+3 |
| 大捷 | 成功+S评级 | 声望+10, 贡献+5 |
| 深入 | 成功+选择继续深入 | 道心+2, 修为+100 |
| 稳妥 | 成功+选择见好就收 | 道心+1 |
| 普通 | 成功 | - |
| 险归 | 失败+奇遇≥1次 | 道心+2, 心境+3 |
| 失败 | 失败 | - |

### 5. 历练叙事增强
**函数**: `生成历练叙事(实例ID)`

生成叙事数组：
- 【启程】弟子们辞别宗门，前往「关卡名」，选择了「路线」
- 【路线】路线描述
- 【奇遇】每个奇遇的纪事
- 【决策】见好就收/继续深入的决策描述

### 6. 增强版开始历练
**函数**: `开始历练增强(关卡ID, 弟子ID列表, 路线="稳妥")`

- 调用原有`开始历练`
- 添加路线信息、奇遇记录、决策状态
- 神秘路线额外增加2天历练时长

### 7. 获取历练进度（UI用）
**函数**: `获取历练进度(实例ID)`

返回进度信息：实例ID/关卡ID/路线/路线名称/进度/已历练天数/总天数/剩余天数/奇遇记录/提前结束/继续深入/可决策

## 六、设计原则回顾

1. **符合修真世界观**: 奇遇/遗迹/前辈/灵兽/天地异象等元素，命名贴合修真小说
2. **符合玩家操作习惯**: 选择直观（2-3个选项），反馈清晰（成功率/效果描述），决策有意义
3. **不止能玩而是好玩**: 分支选择增加重玩价值，风险决策增加紧张感，多结局增加成就感，叙事增加代入感

## 七、关键技术决策

1. **新增增强层而非修改原有系统**: 所有新功能都是新增函数，原有`开始历练`/`_结算单个历练`等完全保留，确保向后兼容
2. **奇遇效果应用复用现有弟子方法**: `增加道心`/`增加心境`/`增加心魔`等，不新增弟子字段
3. **多结局额外奖励复用现有资源**: 声望/贡献点/道心等，不新增资源类型
4. **存档兼容优先**: to_dict和from_dict都做了旧存档兼容处理
