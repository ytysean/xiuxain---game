## 0. 文档定位与产出边界

本规格是**美术侧对「方案 B 中度模块化」重构的视觉约束与资产交付清单**，职责边界：

- **产出**：视觉层级 / 配色 token / Hero 块 / Logo / 背景压暗 / 6 格网格 / 图标缺口预案 / `grid_lz.png` 出图预案。

> 铁律继承：`UI硬性约束规范.md` §3.5 反风格漂移——所有颜色取自 `ui_theme.gd` 常量；新增色须先入常量再写代码，禁止裸 hex/裸 `Color(...)`。

> **暗金占位色建议值（重点结论）**：资源空值「—」比正常数值低一视觉层级。
> - 正常数值色 = `COLOR_TEXT_GOLD #FFD77A`（亮金）或 `COLOR_TEXT_BODY_GOLD #D4B86A`（暗金）。
> - 占位色建议 = **`#BFA06A` / `Color(0.749,0.627,0.416)`**，位于二者之下、之上于禁用灰，肉眼可辨「此处本应有值但暂缺」。
> - **代码动作（待 engineering-lead）**：在 `ui_theme.gd` 新增 `const COLOR_TEXT_PLACEHOLDER: Color = Color(0.749,0.627,0.416)` 与 getter `color_text_placeholder()`，业务调用 `UITheme.color_text_placeholder()`，禁止在场景内联此 hex（§3.5）。
> - **对比校验**：`#BFA06A` 与 `COLOR_TEXT_BODY_GOLD #D4B86A` 的 R 通道 0.749 < 0.831，确认更暗一档，满足「低一视觉层级」。

## 3. Hero「宗门进境」块视觉规范

信息锚点：宗门等级 / 繁荣度 / 核心收益速率。

| 属性 | 规格 | 取值/依据 |
|---|---|---|
| 位置/尺寸 | 内容区顶部卡片，w=456（12px 边距），h≈104–120 | 对齐 `宗门首页线框规范 §3.2 C1` |
| 底色 | 深墨带半透明 Panel | `BG_OVERLAY_COLOR #16221D` @ **alpha 0.88**（= `Color(0.086,0.133,0.114,0.88)`） |
| 描边 | 金色描边 | `COLOR_BORDER_GOLD #C9A656`，**2px** |
| 圆角 | **8**（面板/卡片默认，合法集 {10,8,6,0}） | ⚠ 现有 `make_dynamics_panel_stylebox` 用 radius=12（**非法值**，待 reconcile，见 §8 #2） |
| 内边距 | content margin L/R12·T/B10 | `UITheme.PAD_PANEL` / `GRID` |
| 标题「宗门进境」 | 字号 **18**（面板标题档，收敛自任务书≈20）· `COLOR_TEXT_TITLE1 #E6C778` | §3.3 合法集 |
| 数值（等级/繁荣度/速率） | 字号 **18** · 正常 `COLOR_TEXT_GOLD #FFD77A`；异常/负向 `COLOR_TEXT_RED #E07878` | `ui_theme.color_value(abnormal)` |
| 标签（等级/繁荣度/速率名） | 字号 **15** · `COLOR_TEXT_BODY_GOLD #D4B86A` | 小标题/正文档 |
| 空值「—」 | 字号 18（同数值档）· **`COLOR_TEXT_PLACEHOLDER #BFA06A`**（新增常量） | 比正常数值低一视觉层级，见 §1.2 |

> **暗金占位色用法**：当某指标暂无数据（如新宗门「核心收益速率」未解锁）时，显示「—」而非数字，颜色用 `#BFA06A`（非亮金、非禁用灰），传达「此处待填」而非「功能禁用」。

> **与现有 helper 的偏差（风险，见 §8 #1）**：任务书确认 Hero 块 = `#16221D`@0.88 + `COLOR_BORDER_GOLD`；但 `ui_theme.gd::make_dynamics_panel_stylebox` 当前实现为 `Color(COLOR_PANEL_BG=#2C3E45, 0.82)` + `COLOR_BORDER_GOLD` + radius 12。两处基色/alpha/圆角均不一致——**须由 engineering-lead 对齐为一处**，建议新增 `make_home_hero_panel_stylebox(alpha=0.88, border=COLOR_BORDER_GOLD, radius=8, border_w=2)` 统一收口。
