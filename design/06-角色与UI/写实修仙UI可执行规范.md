## 0. 与现有工程的关系（落地前提，必读）

1. **当前运行状态**：`main.gd` 顶部 `const 启用皮肤纹理: bool = false`，即当前界面由 `造主题()` 的 `StyleBoxFlat` 主题驱动（暗青玉面板 + 深青玉主按钮 + 深原木次按钮 + 宣纸亮字）。本规范**保持纯 StyleBoxFlat 落地**，不依赖问题纹理层。
2. **问题纹理层现状**：`_皮肤纹理装填(t)` 会把 4 张 AI PNG 以 `StyleBoxTexture` 9 宫格挂到 Panel / Button。实测这 4 张 PNG **全部为 RGB 不透明模式（无 alpha 通道）的完整成稿**，直接 9 宫格会拉伸变形、镂空透底（详见 §8）。**结论：在 §8 要求重绘前，保持 `启用皮肤纹理 = false`，不要开启。**
3. **本次方向相对紧急热修的调整**：
   - 面板由「暗青玉半透」改为「**温润木色 / 宣纸米白浅底 + 青绿描边**」；信息区用「略深底色带」保证文字清晰。
   - 正文文字由「宣纸亮（浅色字）」改为「**墨黑（深墨字）**」写在浅底面板上 —— 这是修复「文字看不清」的核心动作。
   - 按钮保留「主绿（深青玉）主按钮 / 次棕（深原木）次按钮」双套，强化描边与轻微厚度；危险按钮单列暗红棕。
   - 背景沿用「仙山远景」PNG，但重新定遮罩透明度，让氛围服务于信息而非抢戏。
4. **范围边界**：仅覆盖核心通用 UI 框架 + 主界面 + 核心弹窗（弟子 / 灵兽 / 坊市 / 纪事 / 七载大典）。弟子/灵兽立绘、场景背景细化、过场动画、皮肤主题等明确排除（见 v2.0 §6）。

## 1. 主界面背景风格

**方向**：写实修真宗门场景（云海、远山、古建筑、庭院广场）；低饱和青绿 / 灰蓝 / 暖木；背景服务氛围，不抢 UI 信息。

### 1.1 背景图规格
| 项 | 值 |
| --- | --- |
| 资源 | `res://assets/ai_art/2026-07-22/仙山宗门远景_云雾半透明_古建木石_青黛色调_低饱和度_水墨_2026-07-22T15-19-56.png` |

| 层 | 颜色（Godot Color / Hex） | 透明度 | 说明 |

| 背景叠层（全局氛围遮罩） | `Color(0.086,0.133,0.114,0.50)` / `#16221D`@0.50 | α=0.50 | 青墨色均匀压暗，保证浅色面板与文字对比；**替代原 `Color(0.08,0.10,0.10,0.42)`（α 0.42 偏弱）** |

> **暗角/暗化遮罩**：纯代码 UI 无径向渐变节点。最小包做法 = 单张全屏 `背景叠层` ColorRect（α0.50）。若 S1 想要真实暗角，另出一张 480×854 径向渐变 PNG（中心透明、四角 `#0E1714`@0.55）作 `TextureRect` 叠在最底 UI 之下、背景图之上，或写一个轻量 `CanvasItem` 着色器。本规范不强制。

### 1.3 竖屏安全区域（480×854）
| 区域 | 边距 / 尺寸 | 依据 |
| --- | --- | --- |
| 顶部预留 | 上 48px（常驻目标条，`外滚.offset_top = 48`） | `main.gd::_ready()` 现状 |
| 左右安全边距 | `margin_left/right = 8` | `根` 容器现状 |
| 上下安全边距 | `margin_top/bottom = 8` | 同上 |
| 底部留白 | 内容区底部 ≥ 8px；若增固定底栏再留 ≥64px | 触摸目标 ≥44px（ACCESSIBILITY §2） |

### 1.4 层级关系（add_child 顺序即 z 序，后者在上）
```
背景图 TextureRect (IGNORE)
  └ 背景叠层 ColorRect (IGNORE, α0.50)
      └ 外滚 ScrollContainer (offset_top=48)
          └ 根 VBoxContainer (margin 8)
              ├ 顶部标题 + 状态栏（状态栏用 _暗墨面板 深色带）
              ├ 按钮行 / 底部主操作区
              ├ 离山汇总面板
              ├ TabBar
              └ 滚动内容区（弟子/待抉择/御兽/纪事）
```
> 弹窗（`_new_detail_popup`）以 `add_child(遮)` 挂到根之后，天然置顶；遮罩 `弹窗遮罩`（α0.62，见 §3）覆盖全屏。

### 1.5 是否需要美术资源
- **背景图**：✅ 现成可用（仙山远景 PNG），无需重绘，仅调 `modulate.a` 与遮罩。
- **暗角/聚焦遮罩 PNG**：❌ 最小包不需要；S1 可选（见 1.2）。
- **工程实现提示**：在 `main.gd::_ready()` 把现有 `景.modulate = Color(1,1,1,0.85)` 改为 `0.55`，把 `暗罩.color = Color(0.08,0.10,0.10,0.42)` 改为 `Color(0.086,0.133,0.114,0.50)`。其余结构不变。

## 2. 底部功能栏样式（主界面底部 / 主操作按钮区）

**方向**：深青玉绿 / 深原木棕为主（主绿次棕）；主操作（主按钮）做更大视觉权重；按钮边缘清楚描边、有轻微厚度、非纯扁平。

### 2.1 结构建议
当前主界面按钮排在滚动区内的多行 `HBoxContainer`（推演/招收/建筑/快进/存读/历练/坊市/任务…）。参考图要求「底部功能栏」，最小包做法：**样式分层 + 推荐固定底栏（非阻塞增强）**。
- **主按钮（深青玉绿）**：`推演汇总`、`离山汇总·一键领取`、标题屏 `开新宗门/确定重开` —— 视觉权重最高。
- **次按钮（深原木棕）**：招收、建筑、坊市、任务、历练、存/读、快进等常规操作。
- 实现：`_主按钮样式()` 返回 StyleBoxFlat 挂到主按钮；`_次按钮样式()` 挂到次按钮。

### 2.2 尺寸 / 间距 / 圆角
| 项 | 主按钮（深青玉绿） | 次按钮（深原木棕） |
| --- | --- | --- |
| 高度（逻辑 px） | **46**（≥44 触摸目标） | **40** |
| 最小宽度 | 自适应，`custom_minimum_size.x ≥ 64` | 自适应，`≥ 56` |
| 圆角 corner_radius | 8 | 8 |
| 按钮间距 separation | 6（行内） | 6 |
| 内边距 content_margin | L/R 14，T/B 8 | L/R 12，T/B 6 |
| 描边 border_width | **2**（暗金） | **2**（青黛） |
| 视觉权重 | 更大：深青玉绿底 + 暗金描边 + 轻微投影 | 常规：深原木棕底 + 青黛描边 |

### 2.3 主/次区分做法（工程实现提示）
- **主按钮四态**见 §4 主按钮表；**次按钮四态**见 §4 次按钮表。
- **内发光/厚度**：StyleBoxFlat 用 `shadow_color = 墨底@0.35`、`shadow_size = 4`、`shadow_offset = (0,2)` 模拟「轻微厚度」；hover 时 `shadow_size=6` 增强浮起感（按 §15.4 动效降级开关约束，Standard 级可保留）。
- **固定底栏（推荐增强，非最小包必需）**：把两个主按钮移入一个 `PRESET_BOTTOM` 的 `HBoxContainer`（高 52，底部 margin 8，底色用 `背景叠层`@0.6 的聚焦条），`mouse_filter=STOP`。最小包若不改布局，仅在原行内对主按钮套 `_主按钮样式` 并加大字号至 15 即可。

### 2.4 是否需要美术资源
- ❌ 纯 StyleBoxFlat 可完成，无需切片。纹理（木纹/鎏金）留待 S1 按 §8 重绘后叠加。

### 3.3 弹窗出现层级（遮罩）
| 项 | 值 |
| --- | --- |
| 遮罩色（弹窗外全屏） | `Color(0.055,0.090,0.078,0.62)` / `#0E1714`@0.62（**新增 `弹窗遮罩` 常量**） |

| 入场动画 | 淡入 + 轻微缩放（现状 `modulate.a 0→1`、`scale 0.95→1`，0.15s），受动效降级开关约束 |

### 3.4 工程实现提示（GDScript 可直接套）
```gdscript
# 在 造主题() 中把 PanelContainer 默认改为浅底青黛框：
var p := StyleBoxFlat.new()
p.bg_color = 宣纸                       # #F4EFE3 浅底
p.border_color = 青黛                   # #6E8F88 青绿描边
p.set_border_width_all(2)
p.set_corner_radius_all(10)
p.content_margin_left = 12; p.content_margin_right = 12
p.content_margin_top = 10; p.content_margin_bottom = 10
t.set_stylebox("panel", "PanelContainer", p)

# 弹窗遮罩（替换原 _new_detail_popup 里的 遮.color = 墨底）：
遮.color = 弹窗遮罩                     # #0E1714@0.62
```
> 注意：弹窗内「信息区底色略深」用 `_暗墨面板()`（深青玉带 + 宣纸亮字）承载状态/详情文字，保证高对比；浅底面板只作外框与标题区。

### 3.5 是否需要美术资源
- ❌ 最小包纯 StyleBoxFlat 完成。角花/云纹边角（参考图「云纹边角」）需 S1 美术切角花 PNG（见 §8 资源清单），本规范不强制。

### 6.3 标题描边做法（工程实现提示）
Godot `Label` 支持主题 `outline_size` / `outline_color`：

标题.add_theme_constant_override("outline_size", 1)

## 8. 九宫格切片建议（现有 4 张 AI PNG 审计 + 资源需求清单）

### 8.2 按钮四态是否需要单独图
- **最小包（本规范执行方式）**：❌ 不需要。按钮四态全部由 `StyleBoxFlat` 参数（§4）生成，无贴图依赖，零变形风险。
- **S1 精修（可选）**：若想要「木纹/鎏金浮雕」真实材质，需美术重绘 **4 态按钮源**（normal/hover/pressed/disabled）各为 **无缝平铺材质方图 256×256（带 alpha，中心纯材质、无边框）**，再 `StyleBoxTexture` 9 宫格（`expand_margin` 各 24）+ `StyleBoxFlat` 负责描边/圆角。当前单枚成稿无法 4 态复用。

### 8.3 面板是否需要角花 / 云纹切片
- **最小包**：❌ 不需要。圆角 + 青黛描边 + 暗金 hairline 已满足「圆角卡片、少量金属边框」。
- **S1 精修（参考图「云纹边角」）**：需美术切 **4 张角花 PNG（左上/右上/左下/右下，128×128，带 alpha，青黛/暗金云纹）**，以 `TextureRect` 定位到面板四角（`mouse_filter=IGNORE`）。当前面板成稿的云纹是画死的，不能拆出干净角花。
