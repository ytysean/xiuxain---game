# 23 屏设置交互规格

## 页面定位

宗门主界面侧边入口「规制」（显示名「设置」）的设计稿，集中管理音频、画面、通知、推演速度、账号与版本信息，并提供退出登录入口。

> 设计意向声明：本屏无现成 `page_*.gd` 或 GDD 可对照，按通用手游设置页惯例设计；具体开关默认值、画质档位、推演速度档位需后续确认。

## 信息架构

1. **顶部导航**：返回 + 标题
2. **音频**：背景音乐 / 音效 开关
3. **画面**：画质 档位值
4. **通知**：推送总开关
5. **推演**：自动推演速度 档位
6. **账号**：账号绑定状态入口
7. **关于**：版本号入口
8. **退出登录**：危险操作按钮

---

## 交互规则

| 元素 | 交互 | 状态/反馈 |
|---|---|---|
| 返回按钮 | 点按 | 返回 01 主界面 |
| 音乐/音效/推送开关 | 点按切换 | 开 → 关：开关滑到左侧，底变灰 `#182D37`；关 → 开：滑到右侧，底变金 `#C8A86A`；即时生效 |
| 画质行 | 点按 | 弹出选择器：高 / 中 / 低；切换后画质值更新，并可能触发资源重载提示 |
| 推演速度行 | 点按 | 弹出选择器：1× / 2× / 3×；影响自动推演的回合间隔 |
| 账号行 | 点按 | 进入账号管理页（绑定/解绑/切换账号） |
| 关于行 | 点按 | 进入关于页（版本号、版权、用户协议、隐私政策） |
| 退出登录 | 点按 | 弹出二次确认弹窗 → 确认后回到登录/创角页；本地存档保留 |

## 代码映射

- 无现有 `page_settings.gd`，本屏为新增。
- 建议新建 `SettingsData`（或扩展 `Game`）保存：
  - `music_on: bool`
  - `sfx_on: bool`
  - `push_on: bool`
  - `quality: Enum {HIGH, MEDIUM, LOW}`
  - `sim_speed: Enum {X1, X2, X3}`
- 音频开关需对接 `AudioManager`；画质/推演速度为运行时变量。
