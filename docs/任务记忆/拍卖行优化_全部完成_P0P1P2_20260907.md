## 四、各阶段功能详解

### P0 核心体验提升
1. **私库物品自动使用**：弟子私库装备自动穿戴、丹药自动服用，宗主不可见（信息不对称乐趣）
2. **拍品种类扩充**：数据结构新增品类字段，为9大类扩展做准备
3. **声望等级系统**：5级（普通客人→至尊贵宾），佣金率5%→3%
4. **时间轴优化**：常驻持续开放8件、单件2小时；大拍每天一次、12件、2小时
5. **委托竞拍**：离线自动出价，灵石冻结/解冻，解决在线时间不一致
6. **延时结算与通知**：防秒拍延长10秒，离线结算通知，物品自动入库

### P1 弟子参与与玩法深度
1. **弟子灵石系统**：私库灵石变量+序列化，月例发放（练气10→渡劫8000，职位+50%）
2. **弟子AI竞拍决策**：0-100兴趣值（道途+30、品阶适配、稀缺性、性格修正），兴趣≥60自动委托
3. **弟子委托拍卖**：月度检查背包，出售重复/用不上物品，所得入私库
4. **宗主管控系统**：全局开关/个人权限/预算上限，禁止时自动取消所有委托并解冻
5. **玩家寄售系统**：背包物品上架，设起拍价和时长，佣金10%，显示"玩家寄售"品类
6. **错过补偿机制**：拍卖行回放（历史拍品）、求购系统（发布求购自动通知）
7. **关注与预约提醒**：关注拍品，剩余1游戏日时自动生成提醒通知

### P2 氛围与惊喜感
1. **拍卖师角色系统**：3位拍卖师（常驻钱掌柜/大拍金仙人/神秘玄衣人），各有话术和技能
2. **暗拍玩法**：密封出价，一次性出价，最高价得，其他人看不到出价
3. **鉴宝玩法**：未知拍品，消耗灵石鉴定，70%正常/20%增值(1.5-3倍)/10%贬值(0.3-0.7倍)
4. **特殊拍卖事件系统**：6种事件（神秘商人/跨界拍卖/压轴至宝/限时抢购/宗门专场/商会大促），月度随机触发
5. **UI全面优化**：声望显示/委托按钮/我的委托/结算通知/切换栏（已完成P0部分，P2特效待后续）

## 六、设计决策与经验教训

### 6.1 委托竞拍的灵石冻结机制
- 设置委托时立即扣除灵石，代出价时调整冻结金额，结算时扣款或解冻
- 经济系统必须有明确的资金流向，每一步都要有对应的扣减/返还

### 6.2 弟子AI竞拍的兴趣值设计
- 0-100兴趣值系统，道途/品阶/稀缺性/性格各有加权，兴趣≥60则参与
- AI决策用数值化的兴趣值比硬编码条件更灵活可扩展

### 6.3 鉴宝玩法的概率设计
- 70%正常/20%增值/10%贬值，增值倍率1.5-3倍，贬值倍率0.3-0.7倍
- 赌石玩法需要有足够的惊喜感，但不能让玩家觉得被坑，概率需要平衡

### 6.4 特殊事件的触发概率
- 6种事件各有不同概率（2%-8%），每月检查一次，已有事件时不触发新事件
- 事件持续7游戏日，结束后自动清除，添加纪事记录

### 6.5 Edit工具匹配问题
- Edit工具在匹配含特殊缩进的行时频繁失败
- 改用PowerShell直接修改文件，更可靠
