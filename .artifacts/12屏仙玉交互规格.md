## 3. 信息架构
```
顶栏（返回 + 标题）
余额（绑定仙玉 / 仙玉）
反馈行
滚动区：
  ├ 每日签到【主按钮】
  ├ 仙玉兑换（标题）
  │   ├ 灵石 / 战功 / 传承积分 / 宗门贡献（4×次按钮）
  ├ 购买月卡【主按钮】
  └ 限时礼包（标题）
      └ 新手启航礼 / 宗门大兴礼（示例 2×次按钮）
```

## 4. 交互规则
- **每日签到**：`Game.仙玉签到()` → 反馈 + 刷新余额 + emit `仙玉变更`。
- **仙玉兑换（类型）**：`Game.仙玉兑换(类型, 10)`（每次 10 仙玉，受每日上限约束）。
- **购买月卡**：`Game.购月卡()`（价格 `XianyuShop.月卡价`）。
- **限时礼包（p）**：`Game.购礼包(p)`（来源 `XianyuShop.限时礼包库`）。
- **返回**：emit `返回主页`。
- 兑换/礼包按钮为动态生成（数量随 `Game.仙玉兑换表` / `XianyuShop.限时礼包库` 变化），画布为静态示意。
- 所有读值经 `is_instance_valid(Game)` + `.get()` 守卫；失败显示「数据未就绪」。

## 6. 代码映射
- `ui/page_xianyu.gd`：`_build()` 顶栏+余额+反馈+Scroll；`_populate()` 动态生成签到/兑换/月卡/礼包。
- 信号：`返回主页`、`仙玉变更`。
- 数据：`Game.仙玉_绑定` / `Game.仙玉_非绑定` / `Game.仙玉兑换表`。
- 库：`XianyuShop.月卡价` / `XianyuShop.限时礼包库`。
- 方法：`Game.仙玉签到()` / `Game.仙玉兑换(类型, 数量)` / `Game.购月卡()` / `Game.购礼包(p)`。
