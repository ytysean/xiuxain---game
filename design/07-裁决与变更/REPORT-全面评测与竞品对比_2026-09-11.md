> 方法：代码实况盘点 + 设计文档索引 + 公开竞品资料。定性判断为主，所有强弱结论附证据来源；涉及具体数值调优处一律标 `[PLACEHOLDER]`，未做 playtest 前不伪装成已验证结论。

## 〇、一句话结论

**《太玄宗门录》的系统纵深已经摸到 PC 标杆《了不起的修仙模拟器》的门槛，但它当前最大的风险不是"玩法不够"，而是玩家在前 30 分钟看不到这些内容——设计投入集中在长线层，决定前 7 天留存的瞬间层却最薄弱。**

## 二、Fun Hypothesis 检验

**设计的 hypothesis**（据 00-INDEX 核心体验推导）：
> "我是在经营一个会自己运转、会世代传承的修真宗门——我今天的每个决策，会在三代弟子之后仍然产生影响。"

**判定：hypothesis 本身极强，且是同类里唯一的。**
竞品《最强祖师》的弟子是"抽卡英雄"（无寿元、无世代）；《了不起的修仙模拟器》是"一次飞升的单局沙盒"；只有《修仙家族模拟器》碰了血脉世代。你的"寿元→兵解/飞升/转世→家族血脉→先贤堂→宗门史记"是完整闭环，这是可以打广告语的差异化。

**但前端兑现度不足**：玩家每小时实际在做的事是"派弟子→看数字涨→点确认→收资源"。**瞬间的感受与"世代传承"的宏大承诺不匹配**——这是本作最核心的体验断裂。

## 四、核心循环三层诊断

| 层 | 当前玩家在做什么 | 判定 |
|---|---|---|
| 瞬间（0-30s） | 看数字跳变、点确认、历练派出去等战报 | ❌ 最弱，无操作过程 |
| 单局（5-30min） | 日供刷新、堂口派遣、任命、建筑、六个休闲玩法 | ⚠️ 中等，够撑一局 |
| 长线（数周-数月） | 世代传承、寿元兵解、宗门史记、四结局、正魔中立 | ✅ 独一档 |

**结论：设计重心（长线）与体验重心（瞬间）错位。**

## 五、经济 Sources / Sinks

| Sources（产出） | Sinks（消耗） |
|---|---|
| 堂口产出、历练掉落、商队贸易、拍卖、日供、凡人香火 | 建筑升级、丹器炼制消耗、弟子俸禄、宗门开支、拍卖税 |
| **S46-S51 六个休闲玩法（灵钓/探秘/饲灵/卜算/药圃/论道）——全部为产出** | — |

**通胀风险：中高。**
新加的六个休闲玩法**全部是 source，没有引入任何一个新 sink**。每上线一个玩法，资源通胀压力加一档。项目已有「经济增益上限红线」机制（正确方向），但红线只压增益，不消耗存量。

**建议**：每新增一个产出玩法，必须配套一个 sink（例：灵钓→饵料消耗+钓具耐久；药圃→灵肥/引灵露持续投入；论道→入场资源门槛）。配比建议 **[PLACEHOLDER：source:sink ≈ 1:1，待经济专项审计验证]**。

### 6.2 逐款点评

- **《最强祖师》**（最直接的对手，手游放置 + 水墨工笔）：它的弟子是"随机词条英雄"，战斗是 6v6 回合演出，日活只要 40 分钟。**你的系统深度远超它，但它赢在"卖相 + 看得见的战斗 + 不累"**。被吐槽点：后期肝度爆炸、氪金压制——这两点恰恰是你可以正面打的差异化位（长线传承 + 非抽卡）。
- **《了不起的修仙模拟器》**（PC 标杆，TapTap 4.7/126 万下载）：内容最厚、自由度最高，但**手机端操作繁琐、中低端卡顿、学习曲线陡峭致新手入魔弃坑**。你的机会：同为深度沙盒，但竖屏 1080×1920 原生手游形态是它的结构性弱点。
- **《修仙家族模拟器》**（世代玩法唯一对手）：血脉世代玩法已占位，你的差异化必须做在"宗门"而非"家族"——史记、阵营路线、四结局。
- 其余轻量竞品（修仙模拟器、蜀山掌门、我的门派等）：内容量级不在一个档次，不构成威胁，但会分流泛用户。

## 七、你强在哪 / 弱在哪

### 强（可打广告语的真差异）
1. **世代传承闭环**：寿元→死亡→家族→先贤堂→转世，同类唯一完整闭环。
2. **沙盒式宗门心智**：无固定最优解（军事扩张/丹道致富/隐逸/商业世家），对标 RimWorld。
3. **四结局 + 正魔中立阵营路线**：宿命感与话题性，天然适合社区传播。
4. **内容密度**：234 表 / 76 UI / 283 成就 / 253 事件任务，手游同品类超配。

### 弱（必须正视）
1. **卖相**：22 个美术文件对战竞品全套水墨工笔——**第一眼就输**。这是投放转化的致命伤。
2. **上手门槛**：系统密度比被吐槽"学习曲线陡峭"的《了不起》还高，而你没有 300 万 Steam 口碑托底。
3. **战斗无演出**：`BattleManager` 已接入，但历练是"派出去→看战报"。玩家对"战力投资"的感知为零。
4. **瞬间层无操作**：放置推演下玩家容易"上线没事干"。
5. **内容有效率**：29 死表 / 352 无调用方函数 / 44 UI 待集成——广度 ≠ 有效内容，且是持续负债（维护成本 + 玩家困惑）。

### 11.3 我不同意豆包的一句话（必须顶回去）

> 豆包原话："新手指引还没做，**需要等所有功能落地后再做**。"

**这是全篇最危险的一句话，属于典型的"上线后再调"。**

1. 新手引导不是最后刷的一层漆，它是**决定系统暴露顺序的架构约束**。等功能全做完再做，等于所有功能默认全可见，届时做洋葱式解锁要回头改 76 个 UI 入口。
2. 成本对比：现在定一张「系统解锁顺序表」CSV ≈ 1 小时；功能全做完再改 ≈ 76 页返工。
3. 失败信号 A（前 30 分钟流失 >50%）只有真机跑才知道。等到最后才发现，重做成本 ×5。

**裁决**：现在就定解锁顺序表（一张 CSV 即可），功能落地时按表接入。零成本、高杠杆、不可推迟。

### 11.4 P0 排序分歧：按"发病时刻"排，不按"严重程度"排

| 豆包排序 | 我的排序 | 发病时刻 |

### 11.6 豆包漏了、我认为更重要的两条

**① 美术定位其实是你的隐藏优势（我上一版低估了）**
你的 UI 定位是「赛博国风：形赛博·魂传统」——八卦 / 符箓 / 玉简 / 祥云这些都是**几何符号，纯代码可画**；而竞品的水墨工笔恰恰是最难用代码生成的。所以"零美术"对你的伤害比对水墨竞品小，**第一眼差距能靠工程手段补到 70 分**。真正补不了的是角色/场景立绘——建议用"文字 + 符号"风格化规避，而不是硬凑立绘。

**② 200 弟子是认知问题，不是性能问题**
玩家记不住 200 个弟子。现有 `占用编制弟子数()` 已区分外门（不占编制），分层设计已有雏形。建议：**核心弟子（前 10）全属性展示，其余走批量管理 + 筛选**。一个设计改动同时解决性能、认知负荷、UI 密度三个问题。
