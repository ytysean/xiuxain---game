## 一、重大根因：389 张"伪 PNG"（解释历史反复"某图标不显示"）

- 现象：page_shop 等报 `Failed loading resource: xxx.png / Not a PNG file / ERR_FILE_CORRUPT`，文件与 .import 都在，但 .import 标 `valid=false`、.godot/imported 只有 .md5 缺 .ctex；`--headless --import` 因缓存判断跳过、不重导。
- 根因：AI 生图返回的是 **JPEG 字节流（文件头 FF D8 FF）却被存成 .png 后缀**，Godot 按扩展名当 PNG 解析必失败。
- 全量扫描：扩展名 .png 共 2389，其中 JPEG 伪 PNG 390、WEBP 伪 PNG 6、真 PNG 1993；**游戏资源伪 PNG 389**（art/icons 273、art/characters 91、art/ui 25），其余 7 张在 temp_check/_temp_/preview 等临时目录。
- 修复流程（脚本均在 .workbuddy/，可复跑）：
  1. `_scan_fakepng.ps1` 按**文件头**而非扩展名扫描（真 PNG=89 50 4E 47；JPEG=FF D8 FF；WEBP=RIFF..WEBP）。
  2. `_check_uid.ps1` 确认 581 异常图在 gd/tscn/tres 中**无 uid:// 引用**（全走 res:// load），删 .import 重导零风险。
  3. 原图备份到 `backup/伪PNG转码_20260909/`（保留相对目录）。
  4. `_convert_fakepng.ps1` 用 System.Drawing（PS5.1 Add-Type）MemoryStream→Image.FromStream→Save(Png)，JPEG 解码重编码为真 PNG，校验文件头 89 50 后写回，**路径/文件名不变，389 张 0 失败**（System.Drawing 不支持 WebP，6 张 webp 都在临时目录无需处理）。
  5. `_purge_bad_import.ps1` 删所有 valid=false 的 .import + .godot/imported 同名缓存，再 `_full_import.ps1` 重导，valid=false 清零、.ctex 生成、无 Not a PNG。
- 遗留（美术质量，非崩溃）：JPEG 无 alpha，转出的 PNG 也**无透明通道**；若要无底色透明图标需美术重出带 alpha 的真 PNG。

## 二、GDScript 类型/API 易错点（本段实修，后续严防）

1. **TextureRect 没有 .color**：要纯色底用 ColorRect（它有 .color），TextureRect 改色用 modulate/self_modulate。
   - 修了 page_puppet / page_library / page_herb_garden / page_pill_formula / page_equipment_blueprint：`var _bg: TextureRect` + `_bg=TextureRect.new()` + `_bg.color=` → 改 ColorRect。
2. **Node/Container（VBox/Grid/HBox）没有 .clear()**：清空子节点统一用 `for c in 容器.get_children(): c.queue_free()`（get_children 返回副本可边遍历边删）。修了上述 5 文件共 6 处（herb_garden 2 处）。
3. **Object/RefCounted/Node 无 has()**，查成员用 `"x" in obj`；`Object.get(name)` 只收 1 参（Dictionary.get(k,默认) 才收 2 参）。
4. **信号重复 connect 会 push_error "already connected"**：connect 前先 `if not 信号.is_connected(callable): connect`。
   - game_ui.gd `_open_disciple_detail` 复用同一缓存详情页实例，玩家逐个点弟子会重复连 `返回列表`/`仙衣阁请求`，已加 is_connected 守卫。
5. **call_deferred 的匿名 lambda / await 回调要防野指针**：页面被 remove_child/queue_free 后，排队的 deferred/await 仍可能执行。统一守卫：
   - lambda：`if is_instance_valid(self) and self.is_inside_tree(): 再调()`
   - 函数入口：`if not is_inside_tree(): return` + 成员节点 `is_instance_valid` 判断。
   - disciple_detail_page.gd 的 `_apply_portrait_cover`、`_set_attr_fill_width` 已加（此前一帧连开多页+quit 触发 signal 11 段错误，backtrace 在 _apply_portrait_cover 的 deferred lambda）。
6. **信号回调参数数量必须匹配（含 CONNECT_DEFERRED）**：main.gd `_刷新红点()` 无参，却同时连了无参信号（弟子变动/新手目标更新/邮件变动）和**带 1 参**的 `战报更新(文本:String)`，deferred 触发报 `Method expected 0 argument(s), but called with 1`，红点刷新静默失败。改 `func _刷新红点(_ignored: Variant = null)` 用可选参数吸收。其余回调（_on_战报(文本) 等）签名本就匹配。
