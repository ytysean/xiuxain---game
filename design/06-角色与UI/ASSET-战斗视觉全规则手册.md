# 修仙战斗场景设计与动效实现全规则手册

> 状态：S1/S2 视觉层权威 spec。战斗背景素材已归档至 `assets/battle_scenes/reference_source/`（豆包AI生成的10张参考图 + 1段战斗视频，按 §一.3 的6类模板对应命名）。P0 阶段（S0 v1.0）不实现视觉层，本手册用于 S1 接入时对齐美术与动效。

## 一、战斗场景AI生成标准提示词体系

### 1. 核心7层公式（权重从高到低，越靠前对画面影响越大）
1. **核心主体**：身份、外形、着装、法宝装备，明确职业定位与外形特征
2. **精准战斗动作**：肢体姿态、攻防状态、运动趋势，区分近战/远程/辅助的动作差异
3. **特效细节**：法术属性、法宝光效、粒子氛围，对应职业技能的视觉特征
4. **战场环境**：地点、地形、天气、时间，决定场景差异化
5. **美术风格**：画风、色调、笔触，是批量统一的核心
6. **构图与画质**：镜头、视角、清晰度
7. **负面提示词**：规避崩坏、低质、违和元素

### 2. 通用基准母版模板

固定风格层（所有场景通用，全程不改动）：
> 国风厚涂原画，写实仙侠风格，冷青与暗金主色调，光影对比强烈，游戏原画质感。
> 中景动态构图，第三人称平视视角，轻微运动模糊增强速度感，8K，超精细细节，体积光，全局光照。

通用负面提示词：
> 畸形，肢体扭曲，手指错位，面部崩坏，比例失调，低分辨率，模糊，噪点，水印，文字，现代物品，Q版，卡通

可变层模板（批量生成仅替换此部分）：
- `{战斗主体与职业组合}`
- `{站位阵型+攻防动作描述}`
- `{对应法术/法宝/妖兽特效细节}`
- `{战场环境+天气氛围}`

## 二、批量生成规范与风格统一方法

### 1. 核心沿用逻辑
基准母版90%的风格、画质、光影参数完全固定，仅替换「战斗主体、站位阵型、攻防互动、特效分层」4个可变维度，保证所有战斗素材画风、色调、质感高度统一，无风格割裂。

### 2. 四大可变维度库

| 维度 | 可替换选项 |
|---|---|
| 主体构成 | 单人/双人/3人队/5人队；法修/体修/器修/阵修/丹修/御兽师；普通妖兽/巨型BOSS/兽潮 |
| 站位阵型 | 三角攻坚阵、前后梯队阵、合围包夹阵、分散游击阵、一字防御阵 |
| 攻防互动 | 对峙蓄力、远程对轰、防守反击、追击逃窜、大招对撞、近身缠斗 |
| 特效分层 | 前排护体光、中排法术弹道、后排辅助buff、范围爆炸特效、环境交互 |

### 3. 风格统一操作方法
1. **固定随机种子**：沿用基准母版的随机种子，仅替换主体与场景文字，光影、构图、色调高度一致
2. **风格参考对齐**：以基准母版图作为风格参考图，强制新图对齐画风
3. **参数完全一致**：采样器、步数、CFG、分辨率与基准图保持一致，仅修改提示词可变部分

## 三、战斗动效与法术特效实现方案

### 1. 三级落地路线（匹配版本节奏）

**P0首发（轻量低成本，1-2天落地全套基础技能）**
- 核心逻辑：静态战斗图为背景，角色层做微小位移，上层叠加粒子特效+光效切片
- 分层结构：背景层→地面特效层→飞行特效层→角色层→命中特效层→UI反馈层
- 反馈强化：屏幕震动、闪光、颜色滤镜、伤害数字跳字
- 优势：零美术重制成本，配置表驱动，性能开销低，适配轻量化自动回合制战斗

**S1进阶（品质升级，中等开发量）**
- 核心逻辑：AI生成2-3秒施法/受击动态片段，切成序列帧导入引擎，对应高阶功法与大招
- 内容：通用特效序列帧、职业专属大招演出、过渡补间动画
- 适配：核心技能、BOSS大招、顶级功法做专属动态演出

**S2深度（长线迭代，重品质时落地）**
- 核心逻辑：角色立绘骨骼绑定，特效挂载到骨骼节点，实现完整普攻/施法/受击/闪避动作
- 适配：长线版本品质升级，动作丰富度拉满

### 2. 五类核心技能特效实现规则

**① 法术类（雷/火/冰/毒/土）**
- 结构：弹道飞行阶段 + 命中爆炸阶段 + 持续范围阶段
- 批量方法：1套通用弹道模板 + 1套通用爆炸模板，修改颜色、粒子数量、大小适配全属性
- 属性色值统一：雷=蓝紫、火=橙红、冰=青白、毒=墨绿、土=土黄、木=青绿

**② 法宝类（飞剑/丹炉/玉印/阵旗）**
- 御器类：法宝飞出→旋转加速→命中爆炸→飞回施法者，搭配环绕光效粒子
- 镇守类：法宝悬浮旋转，周身循环播放属性粒子，持续生效
- 撞击类：空中变大砸下，带重力拖尾，命中后大范围震波+碎石飞溅

**③ 符箓类**
- 完整流程：符箓飞出→悬浮放大→符文逐笔亮起→炸开化为法术→符纸碎屑飘散
- P0简化版：符箓缩放闪光后直接切换为对应爆炸特效，省略逐笔细节

**④ 普通攻击**
- 近战：弧形刀光/剑影序列帧 + 角色前冲 + 目标后退+屏幕微震
- 远程：小型灵力弹/小飞剑 + 短拖尾 + 命中轻微闪光
- 妖兽：利爪爪痕光效 + 妖兽微位移

**⑤ 功法差异化分层**
按品级从低到高，从粒子数量、特效范围、持续时间、反馈强度四个维度区分，不单独重做全套特效：

| 品级 | 粒子量 | 范围 | 持续时间 | 反馈强度 |
|---|---|---|---|---|
| 低阶 | 少、清淡 | 仅命中点 | 0.3-0.5秒 | 无震动/微震 |
| 中阶 | 中等、饱满 | 小范围 | 0.8-1秒 | 轻震动+闪光 |
| 顶级 | 多、华丽 | 大范围 | 1.5-2秒 | 强震动+屏幕变色+慢放 |

### 3. Godot引擎落地规范

**战斗场景分层架构（渲染从下到上）**
1. 背景层（静态战斗场景图）
2. 特效下层（地面光环、阵法、烟尘）
3. 特效中层（弹道、飞行法宝）
4. 角色层（立绘/剪影，带Tween补间动画）
5. 特效上层（爆炸、命中特效）
6. UI层（伤害数字、技能名称）

**通用特效管理器**
封装单例调用接口，CSV配置驱动，新增技能无需改代码：
```gdscript
EffectManager.play_effect("thunder_explode", target_position, 1.0)
```

**回合制技能播放时序**
1. 施法者前移+发光（0.2秒，起手动作）
2. 播放弹道/飞行法宝特效（0.3-0.8秒）
3. 命中瞬间：爆炸特效+屏幕震动+伤害数字跳字
4. 受击者后退+闪白（受击反馈）
5. 双方回归原位，回合结束

**零成本打击感优化**
- 施法瞬间屏幕微闪对应属性色
- 高阶技能命中时屏幕震动幅度放大
- 伤害数字带缩放弹跳动画
- 大招播放时全局时间慢放0.5秒

4. 配套屏幕震动、闪光、伤害数字反馈
