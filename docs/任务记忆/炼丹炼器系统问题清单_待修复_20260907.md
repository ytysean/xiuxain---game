# 炼丹炼器系统问题清单（待修复）

**记录日期**：2026-09-07

## 一、炼丹系统问题

### P0 - 严重世界观问题
1. **丹方材料不符合修真世界观**：炼丹用凡铁、玄精铁、星辰精金等矿石/金属，应该用灵草、灵药、灵果等植物类材料
   - 聚气丹：凡铁×2 + 初阶灵石×1
   - 凝金丹：玄精铁×2 + 百年灵草×5
   - 化神蕴神丹：星辰精金×1 + 千年灵草×5
   - 旷世悟道丹：道韵灵根×1 + 星辰精金×2
   - 万载道果丹：道韵灵根×3 + 星辰精金×5

### P1 - 内容不足
2. **丹方数量太少**：只有8个，缺少疗伤丹、解毒丹、增力丹、回灵丹、隐身丹、飞行丹、培元丹等
3. **丹药效果太单一**：主要是突破辅助和临时buff，缺少战斗类、功能性丹药

### P2 - 系统深度不足
4. **炼丹过程太简单**：只有成功率判定，没有火候控制、材料投放顺序、炼丹时间等
5. **没有炼丹失败的不同结果**：炸炉、废丹、低品质丹等
6. **没有丹方解锁/学习系统**：一开始全部可见

## 二、炼器系统问题

### P1 - 内容不足
1. **装备部位太少**：只有武器（剑）和衣服（甲），缺少头盔、靴子、腰带、项链、戒指、手镯、护符等
2. **所有武器都是剑**：缺少刀、枪、棍、扇、拂尘、幡、印、镜等武器类型
3. **低阶装备命名太普通**："铁剑"、"布衣"、"锁子甲"等太凡俗，不够修真风格

## 三、共同问题

### P1 - 体验问题
1. **即时完成，缺少时间等待**：点一下就完成，修真世界观中应该需要时间
2. **缺少专门的UI页面**：集成在page_building.gd中，没有专门页面
3. **缺少材料获取途径说明**：玩家不知道去哪里获取材料
4. **丹方/配方解锁系统缺失**：所有配方一开始就全部可见
