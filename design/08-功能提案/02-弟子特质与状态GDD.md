# 《太玄宗门录》弟子特质与状态系统 GDD（提案 B · F4/F5/F8/F9）

> **核心定位**：让弟子千人千面（特质）+ 鲜活（身心状态/情绪）。全部为养成/状态类，**零战斗结算**，S1 可交付；仅特质「好胜·大比伤害」涉及战斗，标 `[S2-战斗放开]`。
> **诚实标注总原则**：特质/状态需**新增字段 + CSV 配置 + 效果应用逻辑**（非纯配置）；自主行为/情绪 buff 复用现有纪事/buff 模式（轻量代码）。

---

## F4. 弟子特质（1-2 永久道心特质）

### 1. 定位
每名弟子绑定 1-2 个永久「道心特质」，影响修炼/战斗/社交/事件概率；CSV 加 `traits` 字段。

### 2. 核心规则与数值（提案 B·P0）
| 特质 | 效果 | 类型 | 战斗? |
|---|---|---|---|
| 勤学 | 修炼速度 +5% / 心境耗 -10% | 养成 | 否 |
| 孤僻 | 独修效率 +8% / 好感获取 -30% | 养成/社交 | 否 |
| 重情 | 羁绊互赠收益 ×2（与 F1 仙侣翻倍叠加口径一致）/ 关系增益 +50% | 社交 | 否 |
| 好胜 | 大比伤害 +10% / 落败心境降 | 战斗 | **是 → `[S2-战斗放开]`** |
| 稳心 | 修炼速度 -3% / 突破走火概率 -40% | 养成 | 否 |
| 丹道天赋 | 丹道产出 +15% | 产出（产出效率池） | 否 |

> 大比 = 比武/宗门小比（`GDD-活动系统.md` §3.1），属战斗结算 → 好胜「大比伤害+10%」标 `[S2-战斗放开]`（S2-1）；其余特质 S1 生效。

### 3. 复用现状 · 诚实标注
- ⚠️ **需轻量代码 + CSV**：新增 `traits` 字段（disciple.gd additive，仿 `阶位` 字段写法，全 `.get` 兼容）；新增 `traits.csv` 配置表（traits 名 / 效果类型 / 数值）；新增效果应用逻辑（修炼速/心境耗/好感/产出/事件概率）。**非纯配置**。
- ✅ 字段兼容：沿用 `disciple.gd` 现有 `性格`（`GDD-弟子养成.md` §二）作为相邻维度；特质 ≠ 命格（`destiny_id`），独立新增。

### 4. S1/S2 分期
- **S1 交付**：勤学/孤僻/重情/稳心/丹道天赋（非战斗部分）。
- **[S2-战斗放开]**：好胜「大比伤害 +10%」→ S2-1（S2 阶段二，大比伤害结算走战斗层，S1 仅记录特质、不接伤害）。

### 5. UI 入口规范（对齐 B2）
- 特质展示：弟子详情弹窗「道心特质」行（复用详情弹窗，非首页按钮，B2 合规）。
- 无编辑入口（特质为生成时固定/永久），不新增导航项。

### 6. 跨文档一致性
- 修炼速/心境 → 入通用增益乘区（`数值体系细则.md` §4.6），丹道产出 +15% 入产出效率池（单建筑≤20%/全≤30%）。
- 突破走火 → disciple.gd `突破()` 心魔 hook（L635）复用。
- 战斗项 → `[S2-战斗放开]`，不接 `BattleCalculator.gd`。

### 7. 边缘情况（≥3）
- **EC-1 旧档无 traits 字段**：`.get("traits", [])` 默认空，不崩。
- **EC-2 特质数 >2（异常数据）**：取前 2，多余截断并纪事告警。
- **EC-3 好胜特质在 S1 期**：仅记录，不接伤害；S2 放开后由战斗层读取。
- **EC-4 traits.csv 缺行**：loader 容错，缺则特质无效（不报错）。

### 8. 验收标准
- 弟子生成绑定 1-2 特质；非战斗特质 S1 生效并卡乘区；好胜仅 S2 接伤害；无悬空 ID；旧档兼容。

## F5. 身心状态 / 心境系统（4 项每日结算）

### 1. 定位
4 项每日结算（灵气饱和度 / 精力 / 心境 / 归属感），作为系数乘基础收益。

### 2. 核心规则
- 每日结算更新 4 项状态（0~100 量程）。
- 状态作为**乘区系数**作用于基础收益（修炼/产出/事件概率）。
- 心境为核心：低心境 → 修炼/突破受阻；高心境 → 效率提升（与 F9 情绪连锁联动）。

### 3. 数值与配置
| 状态 | 作用 | 系数范围（建议） | 配置载体 |
|---|---|---|---|
| 灵气饱和度 | 修炼效率系数 | 0.8~1.2 | `身心状态.csv`（提议新增） |
| 精力 | 自主行为/事件触发率 | 0.8~1.2 | 同上 |
| 心境 | 修炼/突破/社交系数 | 0.7~1.3 | 同上 |
| 归属感 | 忠诚/叛逃抵抗系数 | 0.9~1.1 | 同上 |

> 全部 `[PLACEHOLDER]` 待数值 GDD 校准；系数乘算，不突破乘区红线（§4.6）。

### 4. 复用现状 · 诚实标注
- ⚠️ **需轻量代码**：新增 4 状态字段（或复用现有 `好感度`/`忠诚度` 相邻维度）+ 每日结算乘区应用逻辑。**非纯配置**。
- ✅ 结算锚点：复用 `推演一月` / 每日结算循环（game_state 现有月循环）。

### 5. S1/S2 分期
- **S1 交付**：全功能（4 状态 + 乘区系数）。无战斗结算。

### 6. UI 入口规范（对齐 B2）
- 状态展示：弟子详情弹窗「身心状态」行（非首页按钮，B2 合规）。

### 7. 跨文档一致性
- 乘区系数 → `数值体系细则.md` §4.6（归「性格乘区」或新增「状态乘区」，须登记）；不突破软 25%/硬 30%。
- 与 F9 情绪连锁 buff 共用心境轴。

### 8. 边缘情况（≥3）
- **EC-1 状态越界（<0 或 >100）**：clamp 至量程，防系数异常。
- **EC-2 旧档缺状态字段**：`.get` 默认中值（如 50），不崩。
- **EC-3 弟子坐化/离宗**：停止结算，状态冻结。

### 9. 验收标准
- 每日 4 状态更新；作为系数乘基础收益；卡乘区红线；旧档兼容。

## F8. 自主行为日常事件池

### 1. 定位
弟子按特质/状态/关系自主行为，自动结算进纪事（鲜活度，非玩家操作）。

### 2. 核心规则
- 每日结算按弟子 `traits`（F4）/ 状态（F5）/ 关系（F6）抽取自主行为（论道/独修/访友/炼丹…）。
- 行为结果自动写 `宗门纪事` + `_加推演条目`，可带微收益/微好感。

### 3. 数值与配置
| 项 | 值 | 配置载体 |
|---|---|---|
| 自主行为池 | 按特质/状态/关系加权 | `自主行为.csv`（提议新增） |
| 反馈 | 纪事 + 微收益/微好感 | 复用现有纪事/buff |

### 4. 复用现状 · 诚实标注
- ⚠️ **需轻量代码**：自主行为触发 + 纪事写入（复用 `宗门纪事.append` game_state L59 / `_加推演条目`）。
- ✅ 复用现状：纪事/推演条目体系已建。

### 5. S1/S2 分期
- **S1 交付**：全功能。无战斗结算。

### 6. UI 入口规范（对齐 B2）
- 无入口（全自动）；结果在「纪事阁」回看（主导航「纪事」页，B2 合规）。

### 7. 跨文档一致性
- 纪事 → `GDD-活动系统.md` 纪事联动；关系 → F6。

### 8. 边缘情况（≥3）
- **EC-1 弟子无特质/关系**：走默认行为池（中性），不空转。
- **EC-2 同日多行为冲突**：按权重抽 1，不重复。
- **EC-3 行为引用缺失配置**：容错跳过，不崩。

### 9. 验收标准
- 每日按特质/状态/关系抽自主行为 → 自动纪事；无战斗；旧档兼容。

## F9. 情绪连锁 buff（心境高涨 / 心绪不宁 / 心魔）

### 1. 定位
心境达阈触发正向/负向情绪 buff，连锁影响修炼/突破。

### 2. 核心规则与数值（提案 B·P1）
| 情绪 | 效果 | 持续 |
|---|---|---|
| 心境高涨（正向） | 修炼速度 +10% / 突破率 +5% | 3 天 |
| 心绪不宁（负向） | 修炼速度 -X% / 事件概率降 | debuff |
| 心魔滋生 | 突破负面（心魔标记/属性临时降/突破冷却延长） | 突破时判定 |

### 3. 数值与配置
| 项 | 值 | 配置载体 |
|---|---|---|
| 心境高涨 | +10% 速 / +5% 突破 / 3 天 | `情绪buff.csv`（提议新增） |
| 心绪不宁 | 负向 debuff（值待校准） | 同上 |
| 心魔 | 突破负面（复用 hook） | disciple.gd L635 |

### 4. 复用现状 · 诚实标注
- ⚠️ **需轻量代码**：复用 `设置气运buff(修炼加,产出加,天数)`（game_state L937）做正向/负向 buff；心魔复用 disciple.gd `突破()` hook（L635）。
- ✅ 复用现状：buff 体系 / 心魔 hook 已建。

### 5. S1/S2 分期
- **S1 交付**：全功能（心境高涨/心绪不宁/心魔均为非战斗状态，S1 生效）。心魔=突破负面（非战斗结算）。

### 6. UI 入口规范（对齐 B2）
- 情绪展示：弟子详情弹窗「情绪状态」行（非首页按钮，B2 合规）。

### 7. 跨文档一致性
- buff → `设置气运buff`（L937），入通用增益乘区（软 25%/硬 30%）。
- 心魔 → disciple.gd L635 hook（`GDD-弟子养成.md` §四 走火入魔）。

### 8. 边缘情况（≥3）
- **EC-1 正负情绪同时触发**：取绝对值高者，或叠加（须数值定，建议取高）。
- **EC-2 心魔触发时弟子已突破成功**：hook 在 `突破()` 顶部判定，失败路径生效，成功不触发。
- **EC-3 buff 持续到期**：自动清除，不残留。

### 9. 验收标准
- 心境达阈 → 正负情绪 buff；心魔在突破时判定；入乘区；旧档兼容。
