### 2.4 诚实点破（针对「零重构/纯配置落地」声称）

- 唯一可称「纯配置」的是 A类三项（事件分级 CSV / 品级权益展示 / 纪事扩展）——但它们也需轻量代码接弹窗钩子/查询面板（见 §四 M 级）。

**现有真实框架（非凭空）**：
- `game_state.gd` L78-80 **统一增益数值红线**：`增益单条上限=5%` / `增益永久全局上限=3%` / `增益限时全局上限=8%`（彩蛋/付费/活动/小建筑统一）。
- `数值体系细则 §4.1 产出效率池`：单建筑产出效率 ≤+20%、全建筑 ≤+30%。
- `数值体系细则 §4.6`：通用增益(战斗) 软25%/硬30%；道心独立 ≤10%。
- `economy_balance.gd` F2 ±15%：**仅作用于结算输出节点 `灵石增量`**（灵石净额），非单源增益帽。
- `game_state.gd` **修炼乘区聚合点**：`_藏经阁修炼乘区`(+10%) / `_宗门大阵修炼乘区`（L292/298）。

**冲突根因**：15 稿数值（区域+8~12%、大阵翻倍→24%、节气+15%、政策+10%）**全部超过统一增益单条 5% 红线**；且若都进产出效率池加算，和=49% >> §4.1 全建筑 30% 帽。另需澄清：项目**无「单增益 15% 硬上限」**——「15%」实为 F2 输出阀（±15%），与单源增益帽是两回事。

**具体规则建议（固化）**：
1. **轴分离（先归类再叠）**：区域buff+大阵覆盖 → **产出效率池**；节气修炼+15% → **修炼乘区**；政策闭关令+10% → 归「政策组」。
2. **产出效率池 clamp（§4.1）**：区域组+大阵覆盖加算后，单建筑 ≤+20%、全宗 ≤+30%；大阵覆盖翻倍机制本身须新建（❌），且翻倍结果必须 clamp 回 ≤+20% 单建筑。
3. **修炼乘区 clamp（§4.6 类比）**：节气(+15%) 与 藏经阁(+10%) 加算后 ≤ 软25%/硬30%；若再叠加大阵修炼，超额 clamp 至 30%。
4. **同时生效上限**：定义「生产增益源同时生效上限 = 3（区域组1 + 节气1 + 政策1）」，全部加算后强制 clamp 全宗产出效率池 ≤+30%（§4.1）。
5. **组内互斥**：区域组 / 节气组 / 政策组 三组间允许共存（分属不同轴或已各自 clamp），但**每组内互斥**（如大阵覆盖开启 vs 不开启）；任何加算超 §4.1 30% 一律 clamp，绝不突破。

**红线合规声明**：单系统产出增益 ≤+20%（§4.1 单建筑），全宗合计 ≤+30%（§4.1 全建筑）；修炼类 ≤+30%（§4.6）。统一增益红线(5%/8%) 仅约束彩蛋/付费/活动/小建筑类，结构性生产增益须走 §4.1/§4.6 各自帽。

### 3.2 物品品质极品 +100% 效果（品质倍率轴 vs 产出增益轴）

**现有真实框架**：`item.gd` 品阶(7档：凡→道) + 极品(`var 极品=false`，仙/道阶 roll 传奇极品词条，如 `机缘护体：秘境稀有资源掉落倍率永久+15%`)。极品是**物品自身效能词条**，非平铺产出增益。

**具体规则建议（固化）**：
1. **轴定义**：品质倍率 = **「物品效能轴」(item efficacy)**，独立于经济增益轴与 F2 输出阀。
2. **与 F2 ±15% 的关系**：F2 阀作用于 `灵石增量` 结算节点；品质倍率作用于物品自身效果（治愈/掉率/词条），**二者正交，天然不冲突**——品质倍率**不计入** F2 ±15% 输出阀。
3. **与统一增益红线/通用增益的关系**：品质倍率**不计入** 统一增益红线(5%/8%) / 通用增益(25%/30%)。
4. **仅当极品物品是「生产工具」时**（如极品灵田产出丹炉），其品质倍率经「产出效率池」结算，须受 §4.1 单建筑≤20%/全建筑≤30% 约束，并与区域/节气/政策生产增益加算后全宗 ≤30%。
5. **物品效能倍率自管**：单词条增幅上限由 `item.gd` 品阶/极品规则自管（建议单词条 ≤+30%、物品总效能倍率设硬帽）；当用于生产工具时须 ≤§4.1 30%。

**红线合规声明**：品质倍率是「物品效能轴」，不计入任何增益上限与 F2 ±15% 输出阀；故「极品+100%效果」单列为**合规**，只要它作用于物品自身效能而非灵石结算。用于生产工具时受 §4.1 30% 同池约束。

### 3.3 政策多开（闭关/开源/厉兵/安民）

**现有真实框架**：政策四令 = ❌ 零框架（代码 0 命中），须新建。

**具体规则建议（固化）：单生效互斥（同一时刻仅 1 令 active）**。理由：
1. 四令是宗门级 decree，改变全局运营模式；若四令可叠加，闭关(+修炼)/开源(+产出)/厉兵(+战斗)/安民(+凝聚力声望) 组合效应无模型、易破零通胀与 §4.1/§4.6 帽。
2. 对齐「玩家轻量干预」原则：单令切换比四令同拉更符合宗主轻量调控，且单令资源效应可建模、可经 F2 阀钳制。
3. **放宽例外**：仅允许「安民」（走凝聚力/声望轴，非产出轴）与任一其他令共存；其余两两互斥。
4. 每令 Effect 须在各自轴内 clamp：闭关(+修炼)→修炼乘区软25%/硬30%；开源(+产出)→产出效率池≤30%；厉兵(+战斗)→通用增益≤30%；安民(凝聚力/声望)→独立轴。
5. 切换即时生效，下一结算周期应用；存档兼容。

**红线合规声明**：单令各自轴内 ≤对应帽（修炼30%/产出30%/通用30%）；互斥保证不跨令叠加破帽。

### 5.2 轻量过度乐观（框架在但需 ❌/⚠️ 轻量接线，M 级，非「纯配置/零重构」）
物品品质四级（结算消费者❌）、二十四节气庆典（节气历法❌接修炼乘区）、里程碑传承树（先贤传承❌仅展示）、灵兽栖息地/亲密度（字段❌）、访客满意度（评分传导❌）、收藏图鉴（增益触发❌）、堂口星级（评级❌）、求道者接待（分支❌）、密谋事件链（专属逻辑❌）、定期集市（定时刷新❌）。
