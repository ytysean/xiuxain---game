# 《太玄宗门录》UI 硬性约束规范

> **定位**：本规范是 UI 层**不可违反的硬性约束**，是后续一切 UI 代码整改的**唯一验收基准**。
> 它与两份文档配套使用，但**约束力高于**它们：
> - `写实修仙UI可执行规范.md` v1.1 —— 视觉**参数层**（颜色值/字号/边距/圆角/四态），本规范的参数引用源。
> - `信息架构与导航硬性约束.md` —— 布局/导航的**展开版细节**（页面树 GDD 级描述），本规范 §1 的详版。
>
> **铁律**：凡本规范的「必须 / 禁止」与任何旧实现、旧习惯、AI 自由发挥冲突，**一律以本规范为准**。

## 0. 适用范围与铁律定位

1. **约束对象**：UI 页面划分、导航跳转方式、首页内容、背景渲染与层级、组件视觉参数（颜色/字号/间距/圆角/描边/按钮尺寸/四态）。
2. **不约束**：`game_state.gd` 任何玩法/数值/存档逻辑；非 UI 的引擎机制。
3. **约束力**：本规范 MUST / MUST NOT 清单逐条可核对；任何 UI 代码改动若违反本规范任一条，质量门（quality-lead）判 **FAIL**，不得合入。
4. **唯一参数源**：所有视觉参数以 `写实修仙UI可执行规范.md` §4/§5/§6/§7 + `main.gd` 顶部常量为准，禁止在代码各处零散硬编码偏离规范的样式值。

## §1 布局信息架构硬性约束（5-Tab 分级导航 · 最终定夺 2026-07-24）

> 最终定夺：底部主导航固定 **5 核心 Tab（宗门 / 弟子 / 御兽 / 历练 / 纪事）**，「宗门」页承担**主屏首页**职能（顶部状态+引导目标条+宗门全景概要+快捷入口网格+底部 5 Tab）；洞府、修炼功能下沉至「宗门」页内快捷入口网格，**不作为一级独立分页**；坊市为**二级独立页面**，由宗门页快捷入口进入（底部 5Tab 仍显示且「宗门」高亮，左上角返回按钮）；历练为**独立一级 Tab**，不是弹窗，不从弟子详情进入；主动「推演」(推时间) 为**纯调试功能**，玩家正式版移除，改「离线收益简报」上线弹窗 + 周期结算 + 宗门账册。
> 详版布局/导航细节见 `信息架构与导航硬性约束.md`（该文档仍按 9 页旧模型撰写，**已作废**，导航架构以本规范 §1 最终定夺的 5 Tab 为准）。

### 1.1 主着陆页 = 「宗门」页（承担主屏首页职能）白名单
「宗门」页 **ONLY** 允许出现：
- W1 顶层状态带（固定、不滚动）：门派等级/声望/繁荣/灵石(+灵草/矿石/灵气/贡献)/时间。
- W2 引导_目标条（条件可见，仅 `引导阶段 ∈ [1,5]`，高 44）。
- W3 宗门全景概要区：资源产出概览 + 核心经营数据（简洁卡片，非明细列表）。
- W4 **快捷入口网格**（受控）：洞府 / 修炼 / 建筑 / 坊市 / 任务 / 账册 等子功能**图标入口**（统一图标+文字，网格排布，**禁止**扩成滚动按钮墙）。
- W5 底部主导航栏（常驻，复用 `标签栏` TabBar，5 Tab：宗门/弟子/御兽/历练/纪事）。
- W6 竖屏安全边距（左右 8px、上下 8px）。
- 顶部角落图标：设置（含单机版存读）、调试（推演中心，Debug 可见），以小图标置于状态带角落，**不占主导航**。

### 1.2 禁止清单（MUST NOT）
- B1 弟子列表 / 弟子卡 / 弟子页头（迁「弟子」页）。
- B2 任何**无组织的功能按钮群**（推演/招收/建筑/快进/存读/历练/坊市/任务/新游戏/推演N日…散排首页）。
- B3 离山汇总面板 / 战报 inline 常驻（改「离线收益简报」上线弹窗 + 周期结算弹窗）。
- B4 主动「推演」类按钮（推演汇总/推演7天/强制天品…）出现在玩家任何页面（纯 Debug，仅推演中心可见）。
- B5 次级 ScrollContainer 嵌套（废除 `中区` 内再套 `滚动`）。
- B6 引导气泡锚定的业务按钮实例（改锚定对应页面入口）。
- B7 「宗门」页快捷入口网格**禁止**塞超过 4 个无分组入口、或退化为滚动按钮墙（保持受控网格）。

### 1.4 导航机制硬约束
- **必须** 底部主导航栏复用 `标签栏`(TabBar) 作常驻主导航，**5 个 2 字 Tab**（宗门/弟子/御兽/历练/纪事），`tab_changed` → 新 `_on_主导航切换(i)`（替代旧 `_on_切页`）。
- **必须** 「分页跳转」= **整页切换**：`当前页容器.queue_free()` → `_建_页_X()` 重建并挂入固定「内容区」锚点。
- **禁止** 同滚内用 `visible` 切 Tab（废除旧 `页控[k].visible`）；一滚内堆叠多页；嵌套 ScrollContainer。
- **必须** 每核心 Tab = 独立内容容器（ScrollContainer+VBox）+ 独立滚动；二级页（S1–S6）从 T0 宗门入口进，**左上角「←返回」**回 T0；平级核心 Tab 间直接切换、无返回键。
- **必须** 引导自动进页由 `_引导_刷新()` 调 `_on_主导航切换(对应索引)`（替代旧 `标签栏.current_tab=0`）。
- **必须** 切回 T1 弟子页时**保留上次二级 Tab 选中状态**（名录/接引），不强制复位；空名录时强制跳「接引」Tab。

### 1.5 与灰锁矩阵（_功能解锁）协同
- **必须** 保留 `_功能解锁` / `_灰锁提示` / `_刷新功能解锁` 判定逻辑不变。
- **必须** 受锁**核心 Tab**（御兽/历练）`set_tab_disabled(i, not _功能解锁(名))` + `set_tab_title(i,"🔒 "+名)` + `tooltip_text=_灰锁提示(名)`（**置灰可显，禁止隐藏**）。
- **必须** 受锁**二级页入口**（坊市/任务）在 T0 宗门网格中 `disabled`+🔒+tooltip；点击锁定项不产生跳转。
- 判定：坊市=引导≥6 或 Lv≥3；任务=Lv≥2 或 引导≥6；御兽=引导≥6 或 Lv≥3；历练=引导≥6 或 Lv≥3。

### 1.6 推演 / 存读 的硬性定位（关键决策）
- **必须** 玩家正式版**移除所有主动「推演」按钮**（推演汇总/推演7天/强制天品等）。放置类底层为实时自动运转，时间自然流逝，手动推时间违背核心体验。
- **必须** 「汇总」能力无感化嵌入：①上线自动弹「离线收益简报」（替代原推演汇总的玩家价值）；②年度/七载结算弹窗自带完整周期明细；③「宗门账册」(S4) 满足深度经营查看。
- **必须** 存读档：联机版=云端自动存档（玩家无按钮，设置页仅展示「云端已同步·上次存档时间」）；单机/测试版=设置弹窗或 D0 推演中心（Debug）内存放读，绝不占首页/主导航。
- **必须** 主动推演/调试指令仅存于 D0 推演中心（顶部角落图标，`OS.is_debug_build` 包裹），正式版随入口隐藏。
- **禁止** 在玩家可见页面出现任何「推演」「存读」「强制天品」等调试感入口。

## §2 背景渲染硬性约束

> 代码事实锚点（仅作整改依据，本规范产出未改代码）：`景.modulate=Color(1,1,1,0.85)`（违规，远景图应 alpha 0.25~0.35 默认 0.30）、`暗罩.color=Color(0.08,0.10,0.10,0.42)`（违规，应为 `背景叠层` #16221D@0.50 固定）。

### 2.1 背景层 z 序铁律
主界面必须维持四层严格顺序（后者在上）：
```
背景底 ColorRect（墨底兜底, IGNORE）
  └ 景 TextureRect（仙山远景 PNG, IGNORE）
      └ 暗罩 ColorRect（背景叠层 #16221D@0.50, IGNORE）
          └ 主布局 / 所有 UI 容器（StatusBar / 面板 / 卡片 / 按钮 / 弹窗）
```
- **必须** 背景三节点 `mouse_filter` 一律 `IGNORE`，永不接收点击。
- **必须** 背景层物理上永远位于 UI 层之下。底层远景图 `z_index = -100`、中间暗调叠层 `z_index = -99`；UI / 弹窗层 `z_index ≥ 0`。推荐将远景图与暗叠层挂入独立 `CanvasLayer`（layer=-1），使任何后续 `add_child` 的 UI / 弹窗在 z 序上必然在其上，杜绝「背景覆盖 UI 面板」。
- **必须** 背景层不得包含任何 `Panel`/`Button`/`Label` 等 UI 控件；背景仅是装饰底，不参与交互。

### 2.2 适配铁律（竖屏 480×854）
- **必须** `景`（底层远景图）使用 `STRETCH_KEEP_ASPECT_COVERED`，居中取景（云海+远山居中）、高斯虚化。图 1216×832（横）对屏 480×854（竖），`COVERED` 仅左右裁切、纵向完整保留远景。
- **必须** `景.modulate.a` 锁定 **0.25~0.35**（默认 0.30），让 UI 浮起、背景弱化若隐若现。
- **必须** `暗罩`（中间暗调叠层）`color = #16221D` 且 `alpha` **固定 0.50**（z_index -99），统一压暗背景、保证 UI 文字对比度。
- **禁止** 使用 `STRETCH_SCALE`（比例失真拉伸）。
- **禁止** 使用 `STRETCH_KEEP_ASPECT_FIT` 或其他导致背景被裁切到丢失远景、或溢出/穿透覆盖 UI 面板的模式。
- **禁止** `景.modulate.a > 0.35`（含当前代码 0.85）。

### 2.3 隔离铁律
- **必须** 所有 UI 面板 / 弹窗 / 卡片容器与背景**不同层**；弹窗出现时其遮罩必须盖住背景。
- **必须** 弹窗全屏遮罩统一使用常量 `弹窗遮罩 = #0E1714@0.62`（`mouse_filter=STOP`），取代当前散用的裸 `墨底` / `Color(0.10,0.09,0.08,0.60)` / `0.55` / `0.80` 等内联值。
- **禁止** 任何 UI 面板 / 弹窗以 `z_index` 或 `add_child` 顺序落入背景层之下。

### 2.4 MUST / MUST NOT（背景）
- [ ] **MUST** 背景三节点 `mouse_filter = IGNORE`。
- [ ] **MUST** 背景层 z 永远低于 UI 层（独立 CanvasLayer 或 `z_index=-100`）。
- [ ] **MUST** `景` = `STRETCH_KEEP_ASPECT_COVERED` 居中。
- [ ] **MUST** `景.modulate.a` 锁定 **0.25~0.35**（默认 0.30）；`暗罩.color = #16221D@0.50`（固定）。
- [ ] **MUST** `暗罩.color = 背景叠层 #16221D@0.50`。
- [ ] **MUST** 弹窗遮罩统一 `弹窗遮罩 #0E1714@0.62`。
- [ ] **MUST NOT** 使用 `STRETCH_SCALE` / 比例失真拉伸。
- [ ] **MUST NOT** `景.modulate.a > 0.35`。
- [ ] **MUST NOT** 背景裁切丢失远景 / 溢出覆盖 UI。
- [ ] **MUST NOT** 在背景层内放置任何 UI 控件。
- [ ] **MUST NOT** 弹窗遮罩使用裸 `墨底` / 任意内联 `Color(...)` 替代 `弹窗遮罩`。

## §3 组件与视觉规范统一硬性约束

> 代码事实锚点（仅作整改依据，未改代码）：`造主题()` 面板圆角8/边宽1、`font_color` 全局 `宣纸亮`、`_主按钮样式` 返回青玉(绿)、`_次按钮样式` 返回木色(棕)、`_危险按钮样式` 不存在、全局 Button 无 `custom_minimum_size.y`（默认高≈27px）、字号散用 11/12/14/20、裸色泛滥（`_评级色`/`_奇遇弹窗`/bbcode 等）。

### 3.1 组件唯一参数源
