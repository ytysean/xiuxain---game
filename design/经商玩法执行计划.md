# 经商玩法（商道系统扩展）执行计划

> 基于 `design/经商玩法加强设计_商道系统扩展.md`，经代码核实后制定的落地计划。
> 铁则：不升 SAVE_VERSION / 不碰商队核心派遣·结算流程（只加乘区）/ 全部修真化文案 / 数值 [PLACEHOLDER] 待实机调。

## 〇、复用前提核实（已验证，非假设）
`caravan_system.gd`（1804行，`class_name CaravanSystem`）已具备全部抓手，无需新建系统：
- `派遣商队(567)` / `结算商队(763)`：结算核心，P0 加乘区处
- `刷新商队行情(1001)` / `_刷新行情事件(1692)` / `_行情事件倍率(1653)`：P1 行情可视化
- `黑市*(1435-1446)` / `_读特殊商单表(406)` / `_结算特殊商单(955)`：P3 稀有商品
- 商路声望函数(1560-1583)、`to_dict(1716)`/`from_dict(1748)`：存档
- `game_state.gd` 坊市 `坊市实价(5181)`：可选挂点（P0 暂不加，避免误胀买入价）
- CSV：仅 `caravan_vehicle_config.csv`(灵舟) / `caravan_post_config.csv`(驿站) 两张；行情/商单/声望等以 `商队*` 内存表 + `trade_event_config.csv` 等承载，无独立大表，**复用现有数据结构**。

## 一、执行顺序（沿用文档 P0→P3）
阶段一 商道境界(P0) → 阶段二 行情可视化(P1) → 阶段三 商铺经营(P2) → 阶段四 护卫+稀有(P3)。
每个阶段遵循：**查已实现 → 备份 → 注入（纯加乘区/加字段）→ gate_all 全绿 → 单元结束写记忆**。

## 二、各阶段文件落点与注入点
### P0 商道境界（本轮执行）
- 文件：`caravan_system.gd`（单文件，game_state 透传不动）
- 新增：`var 商道经验` / `var 商道境界` / `const 商道境界表`（4 重境）
- 新增函数：`获取商道境界加成()` / `获取商道风险减免()` / `增加商道经验(收益, 接商单)`
- 挂钩：
  - `结算商队` L786 后：`价差加成 += 获取商道境界加成()`
  - `结算商队` L805：`风险减免` 并入 `获取商道风险减免()`
  - `结算商队` L927 后：`增加商道经验(实际收益, 商队.接商单)`（含境界突破纪事）
  - `to_dict`/`from_dict`：序列化 `商道经验`/`商道境界`（旧档缺键默认初值）
- UI（P0 收尾项）：坊市页「商道」Tab 显示境界+经验进度+加成/减免。

### P1 行情可视化
- 复用 `刷新商队行情`/`_行情事件倍率`；新增 `获取城市行情(城市ID)` / `获取行情一览()`
- UI：坊市页「行情一览」区，低迷绿/暴涨红，趋势箭头，低买高卖提示

### P2 商铺经营
- 新增 `var 商铺列表` / `const 商铺配置`（6 类，解锁绑商道境界）
- 函数：开设/升级/补货/关闭；每日推演结算产出（接 `每日推演` 钩子）
- UI：商铺管理页；存档 to_dict/from_dict

### P3 护卫强化 + 稀有商品
- `计算商队风险(弟子列表,商路)` / `计算商队收益加成(弟子列表)` 挂靠 `结算商队`
- `稀有商品表` 配置 + 结算按概率触发 + 捡漏机制（复用 `特殊商单表` 机制）
- 护卫战力/专长影响风险与收益；伤员「养伤」状态

## 三、不可触碰红线（执行中死守）
1. **不升 SAVE_VERSION**：新增字段旧档缺键默认初值兼容。
2. **不碰核心流程**：只在 `结算商队` 加乘区，不重写派遣/结算逻辑。
3. **经济阀门**：价差加成/商铺产出/稀有概率一律过 `EconomyBalance` 阀门，防通胀（B10 红线）。
4. **修真化文案**：禁"经商/商店/金币/进货"，用"行商/坊市/灵石/收货"。
5. **性能**：行情按日刷新、商铺按日结算，无每帧计算。
6. **UI 三连规范**：复用现有组件/颜色、`audit_uitheme_calls --strict` 0 臆造。

## 四、本轮交付（P0 后端）
- 商道境界数据 + 三函数 + 结算挂钩 + 存档序列化
- gate_all 全绿（门0/1/2/3）
- UI 为 P0 收尾项，紧随其后
