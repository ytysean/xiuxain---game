## 二、灵钓 S46（首个休闲，图录现成，交互已验证）

### S46-P0 · 核心钓鱼闭环
**目标**：能选灵渊→抛竿→hold/release 张力模拟→判定四分层钓获→六维数值→入图录→入库房。
- **图录接入关键约束（已核实，必踩坑）**：`Game._记录图录(匹配名, 来源)`(game_state.gd:15689) 只在 `图录配置`（即 `config/收藏图录分类.csv`）中存在对应「匹配名」行时才收录。所以灵钓钓获名必须**先注册**到 `收藏图录分类.csv`（新增「灵钓」类别行 + 每种鱼的「匹配名」行），否则钓到了也不进图录。S46-P0 必须同时建 `收藏图录分类.csv` 的灵钓段。
- 新增 `config/fishing_catch.csv`（字段：`catch_id,名称,分层(灵鱼/浊物/奇巧/秘匣),品阶,五行,灵韵,重量区间_低,重量区间_高,长度区间_低,长度区间_高,钓获难度,描述,用途,掉落权重`）+ `config/fishing_tackle.csv`（字段：`阶,钓道门槛,灵杆,灵线,灵饵,解锁水域,可钓,断线率,套装加成`）。
- 新增 `fishing_system.gd`（class_name FishingSystem，挂 Game 聚合，参照 caravan_system 范式）：
  - `func 开始灵钓(灵渊id, 钓具配置) -> Dictionary`（返回张力参数）
  - `func 结算钓获(张力表现:float, 钓具配置) -> Dictionary`（按权重+钓具+灵饵抽四分层→生成六维→`Game._记录图录(名,"灵钓")`→生成 `Item` 入 `Game.宗门库房`）
  - `var 钓道经验 / var 钓道境界 / const 钓道境界表`（初窥→小成→大成→圆满→通玄）
- UI：新增 `ui/page_fishing.gd`（竖屏 1080×1920）：上半屏水域+鱼影+进度环，下半屏张力条+全屏 hold 热区（长按收线/松开放线），进度环满自动入篓。最简首版可用按钮模拟，后续接真触屏手势。
- gate 收绿。
