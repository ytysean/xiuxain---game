15. UI 美术规范（摘要，详见 UI和美术提示词.docx）
结构：顶部资源栏 (灵石 / 贡献 / 弟子) → 中间内容区 (宗门俯瞰 / 弟子流) → 底部 5 导航 (弟子 / 宗门 / 修炼 / 秘境 / 背包)。
品阶色标：凡灰 / 灵白 / 宝绿 / 王蓝 / 圣紫 / 真鎏金 / 道赤金道纹。
动效：全息淡入 0.3s、获得道具金点散开、突破灵光脉冲、常驻灵纹微呼吸反馈。
弟子详情：圆形头像 (品阶边框)+ 属性 +8 装备位+ 标签页 (属性 / 装备 / 功法 / 灵兽 / 道心 / 传记)。
宗门建筑界面：赛博国风俯瞰全景，15 座建筑错落仙山，未解锁灰色虚影、已解锁青霓彩光，等级越高越恢弘。

## 15.1 弟子标签命名与分层规则（身份标签 / 道途倾向标签）
本规范是 2.2「弟子阵营倾向」的 UI 落地细则：将「身份归属」与「阵营倾向（道途）」两套标签在显示层彻底分离，消除「宗门里有散修」的违和感，并定义分场景、分优先级、复用现有布局的显示与代码方案。所有色值、字号、概率阈值为设计假设，待美术与竖屏（480×854）实测后标 [PLACEHOLDER] 调优。

### 15.1.1 两套标签严格区分（永不混用）
| 标签类型 | 命名（UI 显示文案） | 属性性质 | 是否随入宗变化 | 显示场景 |
| --- | --- | --- | --- | --- |
| 身份标签 | 散修 / 宗门弟子 / 客卿长老 | 身份归属 | 是（入宗后变更） | 仅招募界面、访客列表 |
| 倾向标签 | 守正道 / 尚中立 / 行异道 | 性格阵营倾向，永久固定 | 否 | 弟子详情、战斗信息、奇遇战报 |

关键：「散修」只作为「未入宗访客的身份」出现；弟子入宗后身份标签直接替换为「宗门弟子」，仅保留倾向标签，从根源上消除「宗门里有散修」的违和感。

**视觉区分规则（对齐赛博国风色板·形赛博魂传统）**
- 身份标签：弱色调（月白灰底 + 墨黑细字），次要信息，不抢视觉重点；
- 倾向标签：低饱和区分色（守正・青灰、尚中・月白、行异・赭石），搭配极简小图标，视觉权重与「性格标签」持平；
- 严格和品阶色标（凡灰 / 灵白 / 宝绿 / 王蓝 / 圣紫 / 真鎏金 / 道赤金道纹）做区隔，避免和装备 / 境界颜色混淆。

### 15.1.2 分场景 UI 落地细则（适配竖屏 480×854）
**场景 1：招贤阁・招募访客界面**
- 核心目的：让玩家一眼看清「身份 + 风格」，符合招募认知。
- 布局：访客卡片顶部、头像右侧、姓名下方，分两行弱显示。
- 显示示例：
```
【姓名】
身份：散修 ｜ 道途：尚中立
资质：优良 ｜ 灵根：双木灵根
```
- 逻辑：仅招贤阁未入宗访客显示「身份：散修」；正道宗门来访 / 客卿候选人显示「身份：宗门来客」；倾向标签常驻，便于招募前判断是否符合宗门路线。

**场景 2：弟子列表页（批量展示）**
- 核心目的：信息精简，不挤占竖屏列表空间。
- 布局：弟子卡片性格标签旁，极小图标 + 文字缩写。
- 显示示例：`【头像框】 姓名・境界 ｜ 性格：沉稳守道 | 守正`
- 简化：可仅显示倾向图标（不显示文字），点击弹 tooltip。
- 避坑：绝对不在列表页显示「散修」字样，已入宗弟子统一归属宗门。

**场景 3：弟子详情页（最核心页面）**
- 核心目的：信息分层清晰，兼容现有 6 标签页架构（属性 / 装备 / 功法 / 灵兽 / 道心 / 传记），不新增大区块。
- 布局：放在「属性」标签页顶部基础信息区，与性格 / 资质 / 灵根并列。
- 显示示例：
```
基础信息
姓名：XXX  境界：筑基初期
资质：天才  灵根：雷灵根
性格：桀骜不羁  道途：行异道
```
- 补充交互：点击「道途」弹极简说明（如「行异道：行事激进，修炼速度与攻击加成更高，心魔增长更快，奇遇偏向高风险高收益」）。
- 避坑：不用「阵营」二字（改用「道途」避免与「五大阵营」「宗门阵营声望」混淆）；不单独开标签页，复用属性页基础信息区。

**场景 4：奇遇战报、宗门战等文案场景**
- 核心目的：叙事自然，不生硬贴标签。
- 不在战报头部硬加「中立弟子」「魔道弟子」，而是融入文案：
  - 正道倾向：「弟子 XXX 心性沉稳，稳妥行事，选择了上前相助」
  - 中立倾向：「弟子 XXX 行事活络，审时度势，选择了绕道而行」
  - 魔道倾向：「弟子 XXX 杀伐果决，锐意进取，选择了硬闯夺宝」
- 仅结算明细用弱提示标注倾向对应数值影响（如「心魔 +5」「道心 +3」），不突出身份标签。

### 15.1.3 代码实现与字段复用（适配纯代码 UI 架构）
**复用现有字段，存储层零新增**：直接通过性格 ID 映射出道途倾向枚举，运行时计算显示，不存额外字段。

```gdscript
# disciple.gd 中新增只读属性
enum DaoTu { SHOU_ZHENG, SHANG_ZHONG, XING_YI }

func get_dao_tu() -> DaoTu:
    match personality:
        "沉稳守道", "仁心济世", "守礼尊师", "恬淡悟道":
            return DaoTu.SHOU_ZHENG
        "锐意争先", "谨慎多疑", "豪迈仗义", "孤僻清修":
            return DaoTu.SHANG_ZHONG
        "桀骜不羁", "杀伐果断", "贪心逐缘", "狂傲绝世":
            return DaoTu.XING_YI
```
UI 层直接调用该属性渲染标签，零存档成本，100% 兼容旧档（读取自动生成，无迁移成本）。

**封装通用标签组件**：写通用 `TagLabel` 控件，传入类型（身份 / 道途 / 品阶）自动匹配样式、颜色、图标，所有页面复用同一套，保证视觉统一。

**宗门声望与弟子倾向视觉区隔**：宗门界面五大阵营声望统一叫「XX 声望」（如正道声望、妖兽声望）；弟子个人叫「道途」。一个是宗门层面阵营关系，一个是弟子个人行事风格，命名完全区隔。

**逻辑层复用四维模型**：道途本质是 12 性格的聚合分类，所有底层判定完全复用原有四维分值（aggressiveness 激进度等），不单独写阵营判定逻辑；奇遇分支 / 战斗 AI / 心魔速率 / 道心成长继续读四维字段，道途仅作外层快速分类、UI 显示、声望联动的快捷标识。

**系统联动复用声望接口**：触发事件时通过道途映射调用现有声望增减接口，不新增字段与方法。例：弟子奇遇正向分支 → 读道途 → 正道倾向则加正道声望 → 直接调用 `game_state.gd` 的 `add_faction_rep()`。整套逻辑复用现有声望系统，仅新增一层映射判断。

### 15.1.4 复用现有布局（不新增区块、不改垂直高度）
核心原则：所有道途标签塞进现有布局空余位置，不打破原 UI 结构，零新增节点。

| 场景 | 复用位置 | 复用方式 |
| --- | --- | --- |
| 弟子列表页 | 复用「性格行」 | 性格文本后追加「· 守正」，中间点分隔，道途用 80% 透明度弱区分；不改节点结构 |
| 弟子详情页 | 复用「基础信息网格」空位 | 道途插入性格行右侧空单元格，字号小一号；点击弹 tooltip |
| 招贤阁访客页 | 复用「身份信息位」 | 原「身份：散修」扩展为「身份：散修 ｜ 道途：尚中立」，仅调文本控件宽度 |
| 通用控件 | 复用现有标签组件类 | 仅传不同色值（守正青灰 / 尚中月白 / 行异赭石），不重写样式逻辑 |

极端小屏兜底：屏幕宽度 < 420px 时，自动隐藏道途文字仅保留性格；同一行超宽时自动省略道途，点击详情再查看。

### 15.1.5 信息优先级与冲突兜底（强制对齐）
道途统一归第三级补充信息，优先级严格低于核心成长属性。

| 优先级 | 信息类型 | 显示要求 |
| --- | --- | --- |
| 一级（核心） | 头像、姓名、境界品阶 | 最大字号、加粗、品阶色高亮，视觉焦点 |
| 二级（重要） | 资质、灵根、性格 | 常规字号、高对比度，必看信息 |
| 三级（补充） | 道途倾向、命格 | 小字号、低饱和、弱对比，辅助参考 |
| 四级（详情） | 具体属性数值、传记、履历 | 折叠 / 分页，不常驻 |

**视觉权重差异化**：字号差（一级 16 号加粗、二级 14 号、三级 12 号轻量，至少差 2 号）；三级统一 80% 透明度低饱和；色值隔离（品阶金 / 紫 / 蓝强对比，道途青灰 / 月白 / 赭石弱色系，绝不与品阶色混淆）。

**场景分级显示**：列表页极简（缩写 / 16×16 小图标）；详情页完整名称 + 悬浮说明；战报 / 奇遇文案融叙事不贴标签；招募页完整身份 + 道途。

**冲突兜底规则**：空间不足优先砍道途显示、保留性格 / 资质等核心；绝不因新增道途挤压 / 上移核心属性位置，保证原信息层级不变。

### 15.1.6 弟子列表页极简展示方案
核心原则：不增加单卡高度、不打断纵向浏览节奏、信息可识别但不抢核心焦点；三个梯度方案按需选用，全部复用现有性格行布局，零布局改动。

1. **圆点标识法（最轻量，优先推荐）**：在性格文本末尾加 1 枚 6px 实心小圆点，颜色区分三道途，几乎不占横向空间。
   - 守正：青灰低饱和 ｜ 尚中：月白浅灰 ｜ 行异：赭石暖灰
   - 实现：性格 Label 后拼接 TextureRect / ColorRect 圆点，同行排列，不新增行高；老玩家可快速识别，480px 竖屏不拥挤。
2. **两字后缀法（兼顾识别度）**：复用性格文本行，末尾「・」分隔追加两字缩写，字号小 2 号、透明度 70%，无背景胶囊。
   - 示例：性格：沉稳守道 · 守正 ｜ 缩写统一：守正 / 尚中 / 行异
   - 优势：无需记忆颜色含义，完全同行复用，不增加卡片高度。
3. **隐式交互法（极致极简）**：列表默认完全不显道途，和原布局 100% 一致；仅长按弟子卡片弹悬浮气泡显示道途与简要说明。适合追求极致整洁、多数场景不需频繁看倾向的玩家。

**适配降级规则**
| 屏幕宽度 | 显示方案 |
| --- | --- |
| ≥460px | 圆点 + 两字缩写同时显示 |
| 420–460px | 仅保留圆点 |
| <420px | 默认隐藏，长按触发悬浮提示 |

### 15.1.7 避免道途标签与其他标签视觉混淆
核心思路：从形态、色值、位置、权重四个维度和现有标签彻底错峰，从根源杜绝混淆。

**视觉差异化对照表**
| 标签类型 | 现有视觉特征 | 道途标签差异化设计 |
| --- | --- | --- |
| 品阶标签（境界 / 装备） | 圆角胶囊、粗描边、高饱和强色（金 / 紫 / 蓝 / 绿）、高视觉权重 | 永不用胶囊背景 / 描边；只用纯色圆点 / 弱色文字；饱和度压低至 30% 内；权重降为三级信息 |
| 职业标识（道 / 体 / 法） | 方形小图标、高对比、固定头像右下角 | 不进头像区；不图标化；固定文字行内，位置完全区隔 |
| 性格 / 资质文字 | 常规字号、墨黑、无背景、左对齐 | 字号小 2 号、透明度 70%、带弱色调；永远跟在性格文本末尾，不单独成行 |

**三条视觉铁则**
- 形态不撞品阶：品阶用「描边胶囊」强标识，道途全程不用背景容器，只用「圆点 + 文字」轻量化，玩家一眼区分「品质等级」与「倾向属性」。
- 色值不碰品级：品阶色高饱和绿 / 蓝 / 紫 / 金，道途三色全低饱和灰调（青灰 / 月白 / 赭石），绝不出现亮金、亮紫等品级专属色。
- 位置固定不越界：道途信息永远只出现在「性格同行末尾」，不跑头像周围、不占卡片顶部、不单独起行，位置固定后玩家形成肌肉记忆，不会和其他信息混淆。

### 15.1.8 折叠 / 悬浮提示的实现方案（纯代码 UI）
做一套全局通用组件，所有页面复用，零重复开发。

1. **全局悬浮提示（Tooltip）通用实现**：全局单例 Tooltip 节点，挂载 UI 根 CanvasLayer，所有控件统一调用。
   - 节点结构：半透墨黑圆角背景 + 白字 Label，内边距统一，默认隐藏。
   - 触发规则：桌面端鼠标进入目标显示、离开隐藏；移动端手指按下目标 0.3s 显示、抬起隐藏。
   - 边界适配：弹位置默认控件上方，超屏幕边缘自动向内偏移，避免裁切。
   - 极简 GDScript 示例：
```gdscript
# 挂载在 UI 根节点，全局单例
var tooltip_panel: Panel

func show_tip(target: Control, text: String) -> void:
    if not tooltip_panel:
        tooltip_panel = Panel.new()
        tooltip_panel.add_theme_stylebox_override("panel", create_tip_style())
        var lb = Label.new()
        lb.text = text
        lb.add_theme_font_size_override("font_size", 12)
        tooltip_panel.add_child(lb)
        add_child(tooltip_panel)
    tooltip_panel.visible = true
    var pos = target.rect_global_position
    pos.y -= tooltip_panel.rect_size.y + 4
    tooltip_panel.position = pos

func hide_tip() -> void:
    if tooltip_panel:
        tooltip_panel.visible = false
```
   - 道途应用：列表页给圆点 / 缩写挂载提示，内容「道途：守正 \n 行事稳妥，道心成长快，心魔风险低」；详情页给「道途：守正」挂载点击 / 长按弹完整说明（性格映射 + 行为特点 + 阵营声望影响）。

2. **折叠式详情设计**：针对详情页三级补充信息，用「标题 + 展开」默认收起不占空间。
   - 实现：Button 做折叠标题，文案「道途与性格 ▸」，点击切换箭头方向与内容显隐；内容区默认 visible=false，放属性页底部，不挤占境界 / 资质 / 灵根等核心信息空间。
   - 折叠规则：核心信息（境界 / 资质 / 灵根 / 职业）永远展开；三级补充（道途 / 命格 / 履历摘要）默认折叠；记忆用户操作——展开过一次后下次进入详情页保持展开状态。

### 15.2 自定义命名规制（v2.19 新增，对应新稿「四」）

玩家可为宗门内建筑 / 弟子 / 灵兽自定义名称，强化「这是我的宗门」的归属感（禀赋效应 / endowment effect）。所有命名为**显示层覆盖**，不进入数值体系、不触碰任何增益红线（4.1），存档同步读写，底层零架构改动（各实体新增一个 `display_name` 字段即可）。

#### 15.2.1 建筑与地名自定义
- 玩家可为宗门主建筑、关键地标（主峰 / 灵脉 / 护山大阵 / 秘境入口等）自定义名称；
- 仅显示层覆盖，**不改变权威建筑树**（见 11.2 的 15 座实体建筑唯一树；新手指引中的主殿 / 库房 / 修炼室等为叙事用名，见第 13 章，不在此重定义）；
- 规则：解锁条件（建宗即开放主殿命名，高阶建筑随对应解锁开放）、长度与违禁词限制、改名冷却 [PLACEHOLDER]；长老可提议、掌门拍板。

#### 15.2.2 弟子赐名与道号
- 掌门可为亲传 / 内门弟子赐「道号」（字 + 号），记名 / 外门用本名；道号载入宗门名册（6.12）、藏经阁创始人署名（6.17）、先贤堂留名（6.10.4）；
- 赐号触发「赐号大典」小事件，提升该弟子忠诚度、道心微涨 [PLACEHOLDER]（情绪驱动，非数值增益）；
- 命名空间：避免与历史先贤重名（查重），道号影响徒子徒孙称谓（师徒传承 6.11.6）。

#### 15.2.3 灵兽命名
- 玩家为契约灵兽（出战 / 持有，见 7.1–7.3）自定义昵称，显示在战报 / 兽栏；孵化时可选手动命名或系统随机名；
- 重名不冲突（各弟子灵兽独立命名空间）；纯显示层，不影响灵兽任何属性与增益（见 7.4）。

### 15.3 视觉表现力优化（v2.22 新增，对应短板二「视觉表现力弱」）

#### 15.5.4 反馈动效层特效总览（独立层，4 类 11 项，按稀有度逐级解锁）
反馈动效层独立于内容层与背景层，复用 §15.4 全局动效组件，无自定义特效。

**1. 入场类（弹出单次）**
- **平移淡入**：全稀有度基础，右侧平移 + 同步淡入（轻量无打扰）。
- **缩放回弹**：稀有及以上，中心缩放带轻微回弹。
- **全屏闪入**：仅传说，全屏低透明紫光一闪。
- **微震动**：仅传说，屏幕轻微短震，触觉强化。

**2. 常驻循环类（停留循环）**
- **角标呼吸**：稀有及以上，角标明暗循环。
- **外发光呼吸**：稀有及以上，面板外围发光强度循环。
- **流光边框**：仅传说，紫色流光沿边框循环流动（最高稀有度核心标识）。
- **角标流光**：仅传说，菱形角标流光闪烁。

**3. 交互反馈类（点击触发）**
- **按压缩放**：全稀有度，点击缩小反馈。
- **底色加深**：全稀有度，点击底色轻微加深。
- **无缝转场**：全稀有度，小弹窗平滑放大到详情面板。

**4. 消失类（关闭触发）**
- **平移淡出**：超时收起，向右平移 + 淡出（与入场对称）。
- **缩放淡出**：手动关闭，缩小 + 淡出。
- **向上飘出**：领取奖励后关闭，向上轻飘消失（正向反馈）。
