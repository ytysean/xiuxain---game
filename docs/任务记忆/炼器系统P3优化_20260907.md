**日期**：2026-09-07

## 实现内容

### 1. UI武器类型细分筛选
- 选择"武器"筛选时，显示武器类型下拉菜单
- 支持20种武器类型筛选：剑、刀、枪、棍、扇、拂尘、琴、印、塔、鼎、钟、镜、珠、环、索、鞭、锏、锤、斧、钩
- 筛选状态自动保存

**修改文件**：`ui/page_building.gd`
- 新增变量 `_武器类型筛选`
- 新增函数 `_on_武器类型筛选()`
- 添加OptionButton下拉菜单
- 修改筛选逻辑，支持武器类型细分

### 2. 器纹系统（对应炼丹的丹纹系统）
炼器成功时概率生成器纹，器纹等级越高，装备战力越强。

**器纹等级与名称**：
| 等级 | 名称 | 战力加成 |
|---|---|---|
| 0 | 无纹 | 100% |
| 1 | 凡纹 | 105% |
| 2 | 灵纹 | 110% |
| 3 | 宝纹 | 115% |
| 4 | 王纹 | 120% |
| 5 | 圣纹 | 125% |
| 6 | 仙纹 | 130% |
| 7 | 道纹 | 135% |
| 8 | 神纹 | 140% |
| 9 | 天纹 | 145% |

**出纹率**：
- 凡阶10% → 灵阶20% → 宝阶35% → 王阶50% → 圣阶65% → 仙阶80% → 道阶90%
- 器堂等级每级+3%出纹率

**修改文件**：
1. `item.gd` - 新增器纹属性
2. `forge.gd` - 新增器纹名称、器纹战力加成、掷器纹函数；修改装备创建逻辑，炼器成功时掷器纹并应用战力加成
