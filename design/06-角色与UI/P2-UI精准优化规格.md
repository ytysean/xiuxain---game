# P2 · UI 精准优化规格（基于用户四节规范）

> 来源：用户贴出的《UI优化精准提示词》四节（字体统一 / 顶部导航 / 底部Tab / 二级交互）。
> 目标：在**保留现有深青墨绿底+淡金描边+古风水墨背景**视觉风格前提下，仅修复四类问题，不重做整体框架。
> 红线：零 GameState 写入；不触碰战斗素材（已移出 `assets/battle_scenes/`）。

## 一、全局字体统一规范
1. 字体分层（禁止现代无衬线/黑体系统字体）：
   - 标题 / 按钮文字 / Tab名称 / 大字号 → 古风楷体（MaShanZheng，`UITheme.apply_title_font`）
   - 正文 / 列表名称 / 辅助小字 → 古风宋体（NotoSerifSC，`UITheme.apply_body_font` / `apply_aux_font`）
   - 数值（战力/资源）→ 古风等宽数字（`UITheme.apply_number_font`，无独立字体时回落 body + `font_keep_to_baseline`）
2. 字号阶梯（统一常量，写在 `ui_theme.gd`）：
   - 大标题 TITLE 28-32 / 二级标题 H2 22-24 / 正文 BODY 18-20 / 辅助 AUX 14-16
3. 同层级字体/字号/颜色 100% 统一，单模块内不得跳变。

## 二、顶部导航栏布局规整化
- 固定高度 `TOPBAR_H = 64`，半透明深青底 + 底部 1px 淡金分隔线。
- 三区横向排布（均垂直居中）：
  - 左：时辰文字 + 宗门入口，左对齐，间距 16px
  - 中：3 个功能图标，大小一致、间距相等、垂直居中
  - 右：设置 + 调试 按钮，样式/圆角/内边距完全统一，右对齐
- 视觉权重统一，无突兀放大/缩小、无错位。

## 三、底部 Tab 栏优化
- 固定高度 `TAB_H = 72`，深青面板底 + 顶部 1px 淡金分隔线，5 个 Tab 横向均匀。
- 每 Tab「图标在上 + 文字在下」：
  - 图标 26×26 线性古风，选中填充淡金
  - 文字 14px 古风字体，位于图标正下方；五 Tab 名：宗门、弟子、建筑、历练、账册
- 状态：未选中=暗金；选中=亮金 + 底部细金线高亮。
- 点击热区覆盖整栏高度（整 Tab 可点，非仅图标）。

## 四、二级界面可交互性修复
- 列表条目（弟子/建筑等）：单条高度 ≥64px，整行点击热区；四态反馈：
  - 正常 / 悬浮（背景轻微提亮）/ 按下（轻微缩放+描边高亮）/ 选中（背景加深+边框高亮）
- 按钮/Tab/下拉箭头/排序按钮均具明确按钮视觉形态，禁止与纯文本混淆。
- 弟子详情/建筑详情的 Tab分页、操作按钮、装备槽位均具可交互控件形态，点击区域充足。
- 禁止纯静态无交互感平面文字排版。

## 全局约束
- 间距/内边距遵循 8px 网格（`UITheme.GRID=8`），同类型元素大小/间距 100% 统一。
- 所有元素对齐严谨，无错位、无大小不一、无疏密不均。

## 验收自检（交付前逐条核对）
- [ ] 全界面无字体混用，均为古风字体体系，无现代普通字体
- [ ] 顶部导航左中右三区清晰、对齐规整、无混乱
- [ ] 底部 5 Tab 均有图标+文字，大小适中、辨识清晰
- [ ] 所有列表/按钮/Tab 均有明确可交互视觉形态，非纯静态文本
