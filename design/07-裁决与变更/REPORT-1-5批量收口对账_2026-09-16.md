### ★ P0：`_toast` 只有 `print` ⇒ 全项目提示玩家 100% 看不到

```
Game.添加提示(text) → Game.提示 信号 → ui/game_ui.gd::_toast(text)
                                        └─ 原文只有一行 print  ⇒ 最后一米是断的
```
- 而 `ToastManager`（autoload / CanvasLayer）**早就可用**，`ui/disciple_detail_page.gd` 早已在正确使用 ⇒ **一行接入，零新增资产**。
- 修法：`_toast` **保留 `print`**（验收探针依赖 `[GameUI]` 日志断言）**并追加** `ToastManager.show_tip(text)`。

### 典型「结果落在不可见处」

`ui/page_world_map_visual.gd::_回显缩放()` 用 `get_node_or_null("ZoomLabel")` 按**页面根**查找；
而顶栏重排后 `ZoomLabel` 已下沉为右下 `ZoomBar` 的**子节点** ⇒ 恒 `null` ⇒ 缩放数值永不回显。
修法：`find_child("ZoomLabel", true, false)`。

### ★ 真 bug 5 个（同族：`Item` 是 RefCounted，双参 `.get()`）

`Invalid call to function 'get' in base 'RefCounted (Item)'. Expected 1 argument(s).` ⇒ **当场中断所在函数**。

| 文件 | 处数 | 症状 |
|---|---|---|
| `ui/page_storage.gd` | 3 | **库藏详情整块不渲染**（`_刷新详情` 中断） |
| `ui/page_shop.gd` | 3 | `_make_出售_card` 中断 |

| `ui/page_sect_manager.gd` | 1 | 商队灵材备货统计中断 |

修法范式（照抄本页既有 `_名称()` / `_品阶()`）：
```gdscript
var v: Variant = it.get("类别")
var 类别: String = String(v) if v != null else ""
```
> 注意 `if it is Object:` **不构成保护** —— 每个 RefCounted 都是 Object，arity 该错还是错。

## 五、任务 4 · #008 P1 拍卖双币切换 / 分池冻结

| 层 | 改动 |
|---|---|
| UI | 拍卖卡内**独立**双币切换钮；输入框按汇率同步换算 |
| `Game` | 透传 `货币: String = "灵石"` |
| `dynasty_system` | 透传同参 |
| `auction_system` | 等价比价 + 分池冻结 + 按原币成交 |

**关键设计**
- **灵石等价比价**：`等价 = 出价 × R`（**原始汇率，不加溢价**）；`当前价` 恒以**灵石口径**记账 ⇒ **AI 应价链路零改动**
- **分池冻结**：仙玉出价只校验仙玉池，不占灵石额度
- **按原币扣款**：拍品级 `玩家出价货币` 决定扣仙玉/灵石；仙玉额 = `灵石折仙玉(应付)`
  ⇒ 因汇率不落盘，**跨日不会「显示价 ≠ 实扣价」**；不足则流拍
- **三层透传必须每层显式加参**：不加则第 4 实参因「参数过多」直接抛错
- **lambda 按值捕获**：可变状态放 `Array` 容器、货币存 LineEdit `meta`
- 仙缘阁商品反显「灵石等价」`%d 仙玉（≈%d 灵石）`

**既有行为零改动** —— 默认「灵石」路径逐字节等价。

## 六、任务 5 · 两套按钮皮肤 API 收敛 —— 「只拆障碍，不换观感」

**关键真相**：新 9-patch API（`应用主/次按钮皮`）调用点**只有测试脚本** `tests/headless_p0_3_check.gd`（生产零启用）；
旧平肤 API 是 **259 处**的事实主力。

**硬障碍**：纹理皮 `content_margin = PATCH_MARGIN["btn_frame"] = 40`，那是**源图切片宽**，
9-patch 正确拉伸**依赖它**（注释明言「改资产尺寸必须同步改这里」）⇒ 不能改小；
平肤 = `GRID` = 12 ⇒ 按钮**高差 56 逻辑像素** ⇒ 259 处**无法互换**。

**修法**：新增 `_按钮皮_归一()` ⇒ `texture_margin` 保持 40、**仅把 `content_margin` 压回 `GRID`**；
按压态 `top = GRID + 3 / bottom = GRID - 3` 做位移手感；两个 `应用*按钮皮` 全部改走它；
**整函数删除**已被取代的 `_按钮状态皮`（保留会撞门3 死函数水位）。
⇒ 两套皮肤**几何逐像素一致**，259 处**理论上可互换**。

**未做（诚实记录）**：259 处**未全部切换** —— 切换是视觉决策（金框 vs 素面），
无截图视觉验收不敢宣布；且 40+ 页换肤属 **P0-4 换肤阶段**。本轮只拆障碍，不改观感。
