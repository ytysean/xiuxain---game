## 一、当前机制实测（根因定位，全部来自代码）

### 1.1 修炼推进核心（`disciple.gd::推进修炼`）
```
修炼进度 += 日 × 修炼速度 × 灵脉buff / 层基准日
年龄 += 日 / 360.0        # 360 游戏日 = 1 游戏年年龄
```
- `层基准日`（每层所需游戏日，speed=1.0）：`{"练气":25, "筑基":60, "金丹":120, "元婴":240, "化神":480}`
- 每层→满则升层；10 层大圆满→尝试突破下一境界。

### 1.2 修炼速度乘区（当前）
`修炼速度 = 资质表[资质]["速度"] × 灵根品阶加成 × 命格加成`
- **资质表["速度"]（当前主驱动）**：`fan_su:1.0 / pingyong:1.4 / youliang:1.8 / tiancai:2.5 / yaonie:3.5 / kuangshi:4.8`
- 灵根品阶加成：天品 ×1.2、极品 ×1.1（仅天/极给微量）
- 命格（修行·修炼）乘入（当前无实例）

### 1.3 宗门修炼 buff（`game_state.gd::推演一月`）
`灵脉buff = 1 + min(门派等级,10)×0.02`（Lv10→×1.2）
`修炼buff = (1 + 负责人全局buff["修炼"]) × 藏经阁乘区(×1.05)`
→ 最终乘区 = `灵脉buff × 修炼buff`（**乘性叠加，无上限**）

### 1.4 突破成功率（当前仅按境界，资质/灵根完全不参与）
`突破成功率 = {"练气":1.0, "筑基":0.70, "金丹":0.50, "元婴":0.35, "化神":0.20, "仙阶":0.10}`
失败：回退层数 + 进度清零 + 冷却（筑基30日/金丹60日…）。

### 1.5 初始年龄
`年龄 = randi_range(10, 16)`（下山测灵招募）。

## 二、问题量化（"1年金丹"是否属实？——属实，且更严重）

以「离宗后不操作、登录自动推演」折算：1 游戏日 = 240 现实秒；1 游戏年(360日) ≈ 24 现实小时。

### 2.1 当前最快金丹（kuangshi 资质×4.8 + 天灵根×1.2 + 宗门Lv10×1.2 + 藏经阁×1.05 ≈ 7.26×）
| 阶段 | 每层日÷速度 | 10层合计 |
|------|------|------|
| 练气 | 25/7.26 | 34.4 日 |
| 筑基 | 60/7.26 | 82.6 日 |
| 突破筑→金 | 70%成功率 | ~3 日 |
| **合计** | | **≈121 游戏日 ≈ 0.34 游戏年 ≈ 8 现实小时（离宗）** |
| 到达年龄 | 初始10~16 + 0.34 | **10~16 岁即可金丹** ✅ 与反馈一致 |

### 2.2 当前普通弟子金丹（fan_su×1.0 + 宗门Lv10×1.2 + 藏经阁×1.05 ≈ 1.26×）
炼气198日 + 筑基476日 + 金丹(~960日) ≈ **1634 游戏日 ≈ 4.5 游戏年 ≈ 4.5 现实天（离宗）**，年龄约 14~20。

**结论**：根因是**双重叠加**——①`层基准日`基准过低（炼气仅25日/层）；②`资质速度`最高 4.8× 且宗门 buff 乘性无上限。两者相乘，天才 8 现实小时破金丹。

## 三、新模型设计（对齐用户提案，标注与现有体系的冲突）

### 3.1 修炼速度乘区改为「灵根主导」（⚠️ 与现有 资质主导 反向）
用户提案明确：「灵根是唯一影响修炼速度的先天属性，资质不影响修炼速度，仅决定突破成功率与境界上限」。这与当前 `资质表["速度"]` 驱动模型**完全反向**，属刻意设计变更（用户在 7-22 偏科提案后再次确认）。

> 落实动作：废弃 `资质表[资质]["速度"]` 的修炼速度用途；新增 `灵根速度倍率表`；`资质` 仅保留「境界上限」(已有) + 新增「突破成功率系数」(见 3.4)。

| 灵根品级 | 新·修炼速度倍率 |
|------|------|
| 杂灵根 / 下品灵根 | ×1.0 |
| 中品灵根 | ×1.3 |
| 上品灵根 | ×1.8 |
| 极品 / 天灵根 | ×2.5 |

### 3.2 层基准日重基线（核心 P0）
将每层基准日拉长到符合「凡资·下品·无加成」普通弟子的世界观周期。

| 境界 | 用户提案·总周期(speed1.0) | → 折算每层日(÷10层) | 当前每层日 | 放大倍数 |
|------|------|------|------|------|
| 炼气 | 3 年 | 108 | 25 | 4.3× |
| 筑基 | 8 年 | 288 | 60 | 4.8× |
| 金丹 | 20 年 | 720 | 120 | 6.0× |
| 元婴 | 50 年 | 1800 | 240 | 7.5× |
| 化神 | 100 年 | 3600 | 480 | 7.5× |

> ⚠️ **层数口径冲突**：用户写「炼气 1-9 层」(9层)，代码实为 **10 层/境界**。本草案按代码 10 层折算（保持代码稳定）；若改 9 层需同步改 `推进修炼` 升层上限与 `突破()` 重置逻辑。

### 3.3 宗门加成改「加法叠加 + 总上限 100%」（P1）
替换当前乘性无上限：所有宗门加速（聚灵阵/讲道/丹药/属性功法）**加算**，总提升封顶 +100%（即最终 ×2）。
极限速度 = 天灵根×2.5 × 满配×2 = **×5**（用户提案上限）。

### 3.4 资质 → 突破成功率（P1，新增）
当前突破率仅看境界。新增 `资质突破系数`，让「凡俗资质+极品灵根」的偏科天才真正「突破难」，呼应 7-22 偏科提案。

| 资质 | 突破系数（草案，待定） |
|------|------|
| fan_su 凡俗 | 0.60 |
| pingyong 平庸 | 0.75 |
| youliang 优良 | 1.00 |
| tiancai 天才 | 1.00 |
| yaonie 妖孽 | 1.10 |
| kuangshi 旷世 | 1.20 |

`实际突破率 = 境界基础率 × 资质突破系数`（封顶 1.0）。

### 3.5 最低突破年龄（P0，硬兜底）
| 突破至 | 最低年龄 |
|------|------|
| 筑基 | ≥14 |
| 金丹 | ≥22 |
| 元婴 | ≥50 |
（炼气圆满 ≥10 已由初始年龄覆盖，不另设）

> 落实：`尝试突破()` 开头加 `if 年龄 < 最低突破年龄[目标境界]: return false`（**无回退、无冷却**，仅不突破），避免卡在 大圆满 时每日误触失败惩罚。

## 四、数值验算表（新模型：入场→金丹大圆满所需时间）

`speed = 灵根倍率 × 宗门加成(无=1.0 / 满配=2.0)`；年龄按初始 12 计；金丹 gate=22。

| 灵根 | 宗门 | 总倍率 | 炼气(日) | 筑基(日) | 至金丹大圆满(游戏年) | 到达年龄 | 金丹gate22 |
|------|------|------|------|------|------|------|------|
| 下品×1.0 | 无×1 | 1.0 | 1080 | 2880 | 11.0 | 23 | ✅ 通过 |
| 下品×1.0 | 满×2 | 2.0 | 540 | 1440 | 5.5 | 17.5 | ⚠️ 卡22→空等至22 |
| 上品×1.8 | 无×1 | 1.8 | 600 | 1600 | 6.1 | 18.1 | ⚠️ 卡22→空等 |
| 上品×1.8 | 满×2 | 3.6 | 300 | 800 | 3.1 | 15.1 | ⚠️ 卡22→空等 |
| 天灵根×2.5 | 无×1 | 2.5 | 432 | 1152 | 4.4 | 16.4 | ⚠️ 卡22→空等 |
| 天灵根×2.5 | 满×2 | 5.0 | 216 | 576 | 2.2 | 14.2 | ⚠️ 卡22→空等 |

### 4.1 ⚠️ 核心冲突：最低突破年龄 vs 层基准日（必须裁决）
除「下品+无加成」外，**所有组合都在年龄 <22 时达到筑基大圆满，被金丹 gate 卡住空等 6~10 年**。
- 若按用户原值（金丹≥22），天才 14 岁满筑基后需「空修」至 22 岁才破金丹——期间修炼停滞（但仍可历练/任职/战斗，符合「少年卡瓶颈」叙事）。
- **三种解法待选**：
  - **(D) 接受空等**：天才少年筑基大成后卡瓶颈 8 年，靠历练/悟道消磨，叙事自洽（推荐）。
  - **(A) 拉长层基准日**：让 ×5 天才也在 ~22 岁才满筑基（筑基需 ~10 游戏年@×5=50 年@×1，即每层 1800 日，是用户值的 6.25×）——会令普通弟子过慢，不推荐。
  - **(B) 下调金丹 gate 至 14~16**：与用户「金丹需打磨数载」的世界观弱冲突，但消除空等。

### 4.2 与现有《数值体系细则》的冲突
- 细则 §一 把「灵根系数、资质系数」列为**基础属性乘区（无封顶）**；本方案将「资质速度」剥离、灵根改为主驱动、宗门加成加算封顶——需回写细则。
- 细则未定义「最低突破年龄」「瓶颈期」「丹毒」，属新增机制（P1/P2）。

## 七、裁决冻结（2026-07-23 用户拍板，开发唯一依据）

1. **修炼驱动切换**：彻底落地「灵根主导修炼速度」——剥离 `资质表[资质]["速度"]` 的修炼用途，新增 `灵根品阶速度` 表（凡1.0/良1.3/上1.8/极2.5/天2.5）；`资质` 转向「突破成功率系数」(`资质突破系数`) + 境界上限（已有）。原速度系数平移到灵根档位，数值等价过渡。
2. **最低突破年龄 + 空等墙 → D 方案（瓶颈打磨机制）**：保留金丹≥22 硬底线；筑基大圆满后进入「瓶颈打磨期」，修为停涨、累计 `瓶颈打磨值`，满 1.0 解锁突破；自然增长按资质、每日上限锁死，最快突破不早于 22 岁；历练/讲道/丹药/奇遇可主动加速（活动增量受 `年龄/22` 上限夹制）。需可视化进度条 + 纪事联动（UI 后续切片）。
3. **层数口径**：维持 10 层/境界，代码稳定。
4. **范围**：P0+P1 一次性闭环（层基准日重基线 + 年龄锁 + 灵根驱动 + 资质突破率 + 宗门加成加算封顶 + 稳固期 + 轻量丹毒 + 老档兼容）。
5. **宗门加成**：统一加法叠加，总上限 +100%（×2）。
6. **稳固期/丹毒**：P1 只落基础规则（突破后强制稳固期：筑基+365日/金丹+1095日，期间效率×0.5；丹毒累计降突破率、每月-1）。深度心境/淤积留 P2。
7. **开关兜底**：`const 新修炼规则 := true`，false 回退旧规则（资质驱动速度/旧层基准日/无年龄锁）。
8. **存档兼容**：老档新字段默认 0；超限数据归一天花板 + 告知（本专项不弹邮件，落日志即可）。
9. **断言覆盖**：全档位全境界数值校验（普通/极限/满加成边界），配套 python 数值验算脚本。
